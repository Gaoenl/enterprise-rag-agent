# 项目开发文档

> 核对日期：2026-09-09。依据当前工作区代码、配置、SQL 与已有设计文档编写，包含尚未提交的修改。描述代码快照，不代表已完成部署验收。

项目是多租户知识库问答系统：Java 负责业务、权限与入库，Python 负责模型和 RAG 编排，React 提供聊天与管理界面。当前正在迁移会话记忆，聊天数据契约存在不兼容，首次运行前请阅读「当前差异与限制」。

## 使用约定

说明性章节解释运行机制，参考章节保留当前声明。「实现」指存在代码调用；「设计/预留」不表示接口可用。操作命令是开发指引，本次整理不执行迁移、真实模型调用或部署，也不修改业务代码。

推荐顺序：01 → 12 → 02，再按模块阅读 03–09，用 10–11 完成交付。静态参考不替代运行时 OpenAPI、Flyway 历史或集成测试。配置只展示占位符，不包含真实凭据。
