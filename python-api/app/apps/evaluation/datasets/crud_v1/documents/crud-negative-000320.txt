2023-08-08 16:45，正文：原标题：河湖长制进校园，湿地保护在行动极目新闻记者 潘锡珩通讯员 陈昱 冯莉为了让更多少年儿童认识和了解河湖保护的重要性，增强保护河湖生态环境的责任感和使命感，8月7日上午，武汉市江汉区河湖长制办公室联合菱角湖公园管理中心、唐家墩街道香江新村社区、武汉爱我百湖志愿者协会，在江汉区菱角湖公园开展“河湖长制进校园”志愿服务活动。上午9时，江汉区河湖长办的工作人员在菱角湖畔为来自香江新村社区的30余名孩子们讲解湿地涵养水源、净化水质、调蓄洪水、控制土壤侵蚀、补充地下水等生态功能，并带领大家现场观察菱角湖公园湿地的特性和水生植物。活动现场，江汉区湖泊管理所和菱角湖公园管理中心的工作人员通过提问、互动等方式，分享了近年来菱角湖的治理过程和重要举措。了解到如今优美宜人的环境来之不易后，孩子们主动申请加入“河小青”队伍，想要通过自己的努力，为河湖保护贡献一份力量。随后，在民间河湖长的带领下，新晋“河小青”们沿路巡湖，向市民、游客发放河湖长制宣传资料，普及防溺水知识。活动结束后，孩子们纷纷表示，保护河湖刻不容缓，要积极行动起来，从自身做起，从现在做起，从身边的小事做起，共同携手保护美丽的河湖，共同维护美丽的生态环境。（来源：极目新闻）返回搜狐，查看更多责任编辑：
