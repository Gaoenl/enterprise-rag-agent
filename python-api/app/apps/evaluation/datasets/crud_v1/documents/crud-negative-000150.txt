“激发人力资源动能，汇聚强国建设力量”。第二届全国人力资源服务业发展大会于11月22-23日在深圳市举办。本次大会活动包括研讨交流、供需洽谈对接和展示、创新创业和技能大赛，以及青年人才招聘等。在大会的供需洽谈对接和展示活动中，144家人力资源服务企业和用人单位参展交流，进行项目洽谈签约，搭建起人力资源服务业展示交流、对接合作的平台。锐仕方达作为人力资源服务业代表参与大会，与中国长城科技集团股份有限公司、重庆市紫建电子股份有限公司、深圳市鹏瑞发展控股集团有限公司等3家企业成功签署了战略合作协议。在签约仪式上，锐仕方达深闽区域执行总裁金明慧表示，与三家知名企业的合作是重大战略决策，意味着公司将在人力资源服务领域进一步提升影响力、扩展服务范围，为客户提供更全面、更专业的服务。此次合作也反映出人力资源服务业市场的蓬勃发展，和企业客户对锐仕方达服务专业度的认可。在大会中，锐仕方达进行了为期两天的参展交流。经过15年的发展，锐仕方达目前在全国设有220余家分公司，拥有超过4000名员工，服务于来自高端装备制造、新一代信息技术、新能源、生物医药等核心产业的超过65000个企业客户，为其提供核心人才招聘等全方位人力资源服务，助力超10万海内外人才的职业成长。锐仕方达的数字化布局日趋完善。其自主研发的数字化管理系统RNSS，致力于通过对大数据、人工智能技术的不断创新应用，努力构建人才寻猎生态服务网络，并且正在将技术能力迁移至企业端、人选端；旗下的企业招聘Saas产品“锐湃”，为中小微企业提供招聘全流程服务；旗下的“海斗网”致力于推动全行业信息与资源的高效转化，助力打造产业互联网平台。金明慧表示，未来锐仕方达将持续优化服务质量，借助于自身的平台和资源优势，加大对人才服务的投入，创新供给方式，以此为企业提供更高质量的人力资源服务，为中国企业的全球业务发展提供强有力的人才支持；同时，助力人力资源服务业提升效率，更大激发市场活力。【纠错】【责任编辑:黄海荣】
