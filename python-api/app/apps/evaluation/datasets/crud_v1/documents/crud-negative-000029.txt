2023-07-25 09:30，正文：                原标题：外媒：伊拉克外交部要求欧盟国家采取措施预防焚烧宗教典籍行为                            参考消息网7月25日报道据俄罗斯卫星社7月25日报道，伊拉克外交部在一份声明中表示，伊拉克强烈谴责在丹麦首都哥本哈根的伊拉克大使馆前焚烧《古兰经》的行为。  据报道，21日，丹麦一名男子在哥本哈根一处广场上焚烧了一本据称是《古兰经》的书，而广场对面就是伊拉克大使馆。一个自称“丹麦爱国者”的团体在社交媒体上直播了这一事件。  丹麦政府随后称这是一种挑衅，并谴责了激进分子的行为。本周一，两名“丹麦爱国者”成员再次在丹麦首都的伊拉克大使馆前放火焚烧了《古兰经》。  报道称，伊拉克外交部表示：“伊拉克外交部强烈谴责再次在伊拉克共和国驻丹麦大使馆前焚烧《古兰经》的行为。”  声明强调，这些行为让极端主义和仇恨对社区的和平共处构成真正的威胁。  伊拉克外交部还补充称：“伊拉克外交部要求欧盟国家当局迅速审查所谓的言论自由和示威权，并明确集体立场，以避免在其领土上的伊拉克共和国大使馆大楼前发生这些侮辱性的行为。”返回搜狐，查看更多                        责任编辑：
