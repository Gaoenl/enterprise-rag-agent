2023-07-29 12:20，正文：原标题：热搜第一！全网下架，立案调查#上海一咖啡厅命名Doi被指低俗营销#话题 冲上上海同城热搜第一28日上午，黄浦区市场监管局发布情况通报，商品名称中含有违背公序良俗的内容，已立案调查。28日媒体在现场看到，当事咖啡店的外部招牌已被拆除。事件回顾近日，有网友反映上海一家名为“Doi Coffee”的咖啡厅的店名及商品名不雅，有用三俗主题进行营销的嫌疑。该店位于上海市黄浦区，门店LOGO为红色唇印。平台团购类目显示，店铺招牌推荐和品牌主推商品分别为 “Doi美式”和“后入拿铁”，另还有“情趣浓缩”等商品在售。 该店评价共15条，其中一条最新的评论称： “这是什么风气，不知道这样命名的咖啡都是什么人在喝”。店家回应称，该网友未到店买过咖啡，是恶意差评或同行差评，只有低俗的人才会想到低俗文化。26日，该咖啡店一店员表示，取名是个人爱好，没有别的意思。不少网友直言太低俗了，这种“擦边”营销真的很影响社会风气。企查查APP显示，Doi Coffee经营企业即上海市黄浦区向阳红烟酒店成立于2013年。7月14日，位于黄浦区的该门店新增一食品经营许可证，经营项目包含预包装食品销售、自制饮品制售。近期热门视频更多精彩视频，尽在沈阳晚报视频号，欢迎关注来源：新闻晨报编辑：董隽子 责编：闫继伟 高薇 返回搜狐，查看更多责任编辑：
