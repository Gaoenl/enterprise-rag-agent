为进一步加强消防安全工作,预防火灾事故发生,保障全院干警生命财产安全,近日,院党组成员、副院长刘俊华带领综合办、法警大队负责人和督察室相关同志组成检查组对院机关大楼开展消防安全检查。审委会专职委员江彪陪同检查。检查组对机关大楼进行全方位、无死角检查,重点对食堂、干警办公室、审判法庭、消防控制室、配电设备房、消防安全通道等重点区域开展排查。逐一检测安全通道是否畅通,消防水泵能否正常启动,消防栓(箱)功能是否正常,灭火器材能否正常使用。检查组针对检查中发现的隐患,逐一提醒全院干警规范使用各种电器,及时更换或维护老旧电器设备,及时关闭审判庭仪器,做好卷宗、档案的存放管理。隐患险于明火,防范胜于救灾。通过此次检查,对全院存在的消防安全隐患问题做到了早发现早整改,确保安全有序的工作环境。下一步,丰都法院将牢固树立安全发展理念,坚持人民至上、生命至上,时刻紧绷安全弦,常态化开展消防安全监督检查和隐患排查,为法院各项工作开展提供强有力的安全保障。原标题:《刘俊华副院长带队开展机关消防安全检查》阅读原文
