2023-08-05 15:11，正文：这几天，薛之谦“天外来物”巡回演唱会宜昌站在宜昌奥体中心举行，一路看下来，有一种全城都好像在给他铺“花路”的感觉。为什么这么说？绝对不是夸张，因为宜昌文旅局是真的给来宜昌听薛之谦演唱会的歌迷设立了两条专属线路。坐飞机来的，刚落地进三峡机场就能看到演唱会在到达厅出口的打卡点，再往前，航站楼进站出口处的咨询点也被布置上了演唱会的主视觉效果；赶高铁去的，宜昌东站东出站口的站前广场也一样设立了打卡点。不仅如此，宜昌文旅局还专书“宜昌（0717）致谦友的一封信”，提前为歌迷们做好落地观赏指南。喊话歌迷的同时列出各项当地专属的歌迷福利政策，200台百万豪车接送，听众持薛之谦演唱会门票免费坐车，说是举全城之力在为薛之谦的演唱会打call也不为过。这不是第一个“偏爱”薛之谦的地方城市，早在上个月的湖南衡阳，薛之谦连唱三场正好赶上7月17日的生日，衡阳官方就给他个人放了7分17秒的烟花，路过的网友都要说一句：它超爱。这几年，官方跟知名公众人物合作文化活动的情况越来越频繁，一位优质的合作对象，不仅能在刺激消费上带来直接影响，也能反哺地方，使城市印象在大众心中的“软着陆”。譬如这次薛之谦来宜昌举办演唱会，宜昌文旅局就拿出了十成十的重视，目的就是为了借助官方、歌手和歌迷之间的三向奔赴，打响本地的影响力。话不多说，一起期待接下来的两天，薛之谦给我们带来的精彩表演吧！
