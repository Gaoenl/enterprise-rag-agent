，正文：下周三（8月23日）24时，我国将进行新一轮的油价调整。目前，油价已经从上涨转为下跌，距离搁浅仅剩10元/吨，上调幅度降至60元/吨，逼近搁浅线（50元/吨），预计本轮油价将搁浅。  近三个工作日的油价行情如下：8月15日，预计汽柴油上调105元/吨，折算为0.08-0.09元/升。8月16日，预计汽柴油上调80元/吨，折算为0.06-0.07元/升。8月17日，预计汽柴油上调60元/吨，折算为0.05元/升。  尽管上周美国商业原油库存环比大幅下降，但由于需求前景不明朗，美联储加息预期升温，以及美元保持强势等因素，国际油价承压，连续第三个交易日下跌。其中，纽约油价跌破每桶80美元整数关口。  油价上涨自然会增加出行成本。据浙江省的消息，由于国内成品油价格调整，浙江省92号汽油最高零售价已超过油运价格联动调整的启动点，并持续30天以上。因此，自2023年8月18日起，市区巡游出租车（电动车除外）将收取每车次1元燃油附加费，也就是说，乘客每次打车需要多付1元钱。本文属于原创文章，如若转载，请注明来源：油价又要降了！92号汽油价格恐破60元/升https://news.zol.com.cn/829/8290315.html
