2023-08-15 06:32，正文：8月12日，美国夏威夷拉海纳城镇中心的前街海外网8月15日电据哥伦比亚广播公司（CBS）14日报道，美国夏威夷州毛伊岛野火死亡数增至96人。夏威夷州长格林表示，当地救难人员每天可能会寻获10至20具死者遗体，这代表美国一个世纪来最严重野火灾情的死亡人数预计还会大幅攀升。格林在CBS当天播出的受访内容中表示，因本次野火的火势很大，很难辨认遇难者，预计“死亡数还会增加”。格林解释称，拉海纳这座历史悠久的城镇在大火中首当其冲，所有居民要么逃出，要么在火灾中丧生，官方可能需要10天才能确定全部死亡人数，因为工作人员可能每天会发现大概10到20名遇难者遗体，直到完成搜寻。广告 他只是个小司机，伺候的却是一个富太太，小人物一步步平步青云扶摇直上！ ×8月9日，美国夏威夷拉海纳城镇中心的前街据介绍，夏威夷拥有全州范围的户外警报系统，可用于在自然灾害或人为事件发生前通知居民，包括海啸、飓风、大坝决口、洪水、野火、火山爆发、恐怖威胁和危险物质事件。但居民表示，此次野火爆发时，他们均没听到警报声。格林对此表示，将调查为何没有启动警报器等问题，但调查的目的“不是发现谁应负责，而发现为何没生效”。（海外网 侯兴川）
