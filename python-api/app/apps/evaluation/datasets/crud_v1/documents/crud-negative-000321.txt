2023-08-11 17:24，正文：原标题：危险！违法！汽车后备箱居然装了三个娃娃后备箱里装的不是灭火器、土特产、行李箱……居然是三个娃娃。8月4日22时30分许，贵阳交警双龙分局在龙腾路开展“飙车炸街”等违法行为专项整治集中统一行动时，发现一辆小轿车车内拥挤，存在超员违法行为，更让民警吃惊的是，该车后备箱内竟然挤着三个孩子。驾驶人徐某称，当天，她的兄长和家人在外就餐，就餐完毕乘坐地铁出站后，因时间较晚，孩子有些犯困，想着地铁站离家没多远，她便抱着侥幸心理在明知超员的情况下，冒险将大大小小8人全部载上，由于车内座位实在坐不下，便让三个孩子挤在了后备箱。经核查，该车核载5人，实载8人，超员3人。民警对该车驾驶人和车上乘客进行了严厉地批评教育，耐心解释超员和后备箱载人存在的安全隐患，并依法给予其驾驶证记6分、罚款50元的处罚。交警提醒：汽车后备箱空间狭小，空气流通不畅，孩子蜷缩在后备箱狭小的空间里容易发生窒息等危险情况，且后备箱处于车尾，一旦发生后车追尾等交通事故，后果不堪设想；加之后备箱内并无固定座位和安全带等安全措施，当车辆遇情况采取刹车和转向措施时，容易被甩出车外，十分危险。贵州日报天眼新闻记者 蒋孟娇编辑 罗华二审 熊瑛三审 李中迪返回搜狐，查看更多责任编辑：
