河北高温破纪录!中央气象台继续发布双预警2023-06-23 15:42来源:澎湃新闻·澎湃号·政务字号▼▼▼河北高温破记录昨天(6月22日),廊坊、香河、固安、高碑店、遵化等14个站最高气温破6月历史同期极值,玉田、大厂追平6月历史同期极值。廊坊、固安、遵化、丰润4个站破有观测史以来历史极值,香河、玉田2个站与观测史极值持平。具体天气预报河北省气象台2023年06月23日11时继续发布高温红色预警信号!预计今天下午,除坝上和东部沿海地区以外,全省大部分地区最高气温将达到37~39°C,其中保定中东部、雄安新区、廊坊、石家庄中东部、沧州、衡水、邢台北部可达40~42°C。请防范!天气预报:今天下午到夜间,张家口东部和南部、承德、唐山北部、秦皇岛北部多云间阴有雷阵雨,雷雨时局地伴有短时大风等强对流天气,其他地区晴间多云。最高温度,张家口北部、承德北部、唐山东部、秦皇岛、保定西北部32~36°C,其他地区37~39°C,局地可达40~42°C。最低温度,张家口北部、承德北部、保定西北部17~20°C,其他地区21~27°C。明天白天,唐山、秦皇岛多云转晴,张家口、保定西部晴转多云,其他地区晴间多云。明天夜间到25日,张家口、承德、保定和沧州、衡水多云,其他地区晴间多云。25日夜间到26日,西北部地区多云转阴有雷阵雨,其他地区晴间多云。明天白天,除坝上和东部沿海地区以外,全省大部分地区最高气温仍将达到37~39°C,其中唐山北部、保定中东部、雄安新区、廊坊、石家庄、沧州、衡水、邢台北部的部分地区可达40~42°C。今明两天,全省大部分地区有偏南风4到5级,阵风6级。气温较高,风力较大,请注意防火。中央气象台继续发布双预警中央气象台6月23日06时继续发布高温橙色预警预计6月23日白天,华北、黄淮等地将继续出现35°C以上的高温天气,其中,北京、天津、河北、山东、河南北部和东部等地最高气温有37~39°C,北京、天津、河北中南部、山东北部等地的部分地区最高气温可达40°C左右;此外,新疆吐鲁番和南疆盆地、内蒙古西部和中部偏北地区等地也有35~38°C的高温天气,吐鲁番局地最高气温可达40°C左右。防御指南:1.有关部门和单位按照职责落实防暑降温保障措施;2.尽量避免在高温时段进行户外活动,高温条件下作业的人员应当缩短连续工作时间;3.对老、弱、病、幼人群提供防暑降温指导,并采取必要的防护措施;4.有关部门和单位应当注意防范因用电量过高,以及电线、变压器等电力负载过大而引发的火灾。中央气象台6月23日06时继续发布暴雨黄色预警预计,6月23日08时至24日08时,浙江大部、安徽南部、江西东部和南部、福建西部、广东中北部、广西东部和南部、云南中东部和西北部等地的部分地区有大到暴雨,其中,浙江中西部、江西东北部、福建西北部、湖南南部、广西东北部、广东北部等地部分地区有大暴雨(100~180毫米)。上述部分地区伴有短时强降水(最大小时降雨量40~60毫米,局地可超过80毫米),局地有雷暴大风等强对流天气。防御指南:1.政府及相关部门按照职责做好防暴雨工作;2.交通管理部门应当根据路况在强降雨路段采取交通管制措施,在积水路段实行交通引导;3.切断低洼地带有危险的室外电源,暂停在空旷地方的户外作业,转移危险地带人员和危房居民到安全场所避雨;4.检查城市、农田、鱼塘排水系统,采取必要的排涝措施。据中国气象局网站消息,预计未来10天,华北东部、黄淮大部将持续高温天气,高温日数有8天左右。经综合研判和应急会商,中国气象局于6月23日9时启动高温四级应急响应。中国气象局各有关单位在做好暴雨应急响应的同时,加强值班值守,强化国省联动,滚动做好高温天气监测预报预警服务。北京、天津、河北、山东、河南、内蒙古等地及可能受影响的省级气象局根据实际研判启动或调整相应级别应急响应。原标题:《河北高温破纪录!中央气象台继续发布双预警》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布,仅代表该作者或机构观点,不代表澎湃新闻的观点或立场,澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
