2023-08-07，正文：原标题：黑龙江省委书记：毫不迟疑做好人员转移安置，宁听骂声不听哭声据黑龙江日报官微消息，8月6日晚，黑龙江省委书记、省人大常委会主任许勤主持召开全省防汛救灾工作电视电话会议，深入学习贯彻习近平总书记关于防汛救灾工作的重要指示精神，贯彻落实张国清副总理在我省指导抗洪抢险救灾时讲话精神，研究部署下步工作。他强调，各级党委政府、各级防指、各地各部门各单位要坚决贯彻落实习近平总书记重要指示精神，认真落实党中央、国务院工作部署，落细落实各项防范处置措施，坚决打赢防汛救灾“遭遇战”“主动仗”，全力维护人民群众生命财产安全。省委副书记、省长梁惠玲作工作部署。张安顺、刘惠、张巍、王一新、杨博、何良军、于洪涛、余建、李毅、王岚、韩圣健、徐向国等出席会议。会议通报了我省近期雨情、水情、汛情、气象预测和抢险救灾情况。会议指出，在全省防汛抢险救灾的关键时刻，受习近平总书记委派，张国清副总理代表党中央、国务院到黑龙江指导抗洪抢险救灾工作，充分体现了习近平总书记对黑龙江的亲切关怀、对受灾转移安置群众的深情牵挂，为我省做好抗洪抢险救灾工作增添了信心决心、注入了强大动力。我们要切实提高政治站位，坚持人民至上、生命至上，以打赢防汛救灾硬仗的实际行动坚定拥护“两个确立”、坚决做到“两个维护”，不辜负习近平总书记的亲切关怀。会议强调，本次降雨过程影响尚未结束，6号台风“卡努”极有可能北上影响我省，再次引发局地强降雨，且松花江、牡丹江、拉林河等将于近日出现洪峰，龙凤山、磨盘山等水库仍超汛限水位，防汛救灾形势异常严峻。
