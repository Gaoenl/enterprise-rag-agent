2023-08-07，正文：50多岁驾校教练猥亵女学员被行拘！近日，内蒙古呼和浩特，网友发视频称在科目三训练时，一50多岁驾校教练伸出咸猪手猥亵女学员长达9分钟。拍摄者杜先生表示，当时去熟悉考点，听到教练说女孩上次考试没过，也没让教练摸手摸腿，这次他就主动上手去摸了，女孩也敢不吱声。据知情人透露，这名女孩在科目三考试中没有通过。可能是担心如果反抗，教练会对她有所报复。8月5日，据“平安青城”微信公众号消息，内蒙古呼和浩特市公安局玉泉区分局发布警情通报：日前，呼和浩特市公安局玉泉区分局发现“某驾校教练猥亵女学员”的视频在网络平台传播，经查未收到相关报警信息。玉泉区公安分局按照工作规则立即开展调查，查明某驾校科三教练李某某于2023年7月28日在驾校场地练车期间，对女学员王某实施猥亵行为。2023年8月4日，根据《中华人民共和国治安管理处罚法》第四十四条之规定，李某某被依法予以行政拘留。8月4日，呼和浩特市交通运输局发布消息称，该涉事教练员归属于呼和浩特市顺达汽车驾驶员培训有限责任公司，顺达驾校已将涉事教练员开除。驾校教练猥亵学员被行拘属于侵害他人人身权利的行为，涉及到侵犯他人的名誉、尊严和身体自主权。根据《中华人民共和国刑法》第237条，犯罪嫌疑人利用职务上的便利实施性骚扰，情节严重的，将被判处拘役或者三年以下有期徒刑。驾校教练猥亵学员被行拘！(责任编辑：卢其龙 CN070)
