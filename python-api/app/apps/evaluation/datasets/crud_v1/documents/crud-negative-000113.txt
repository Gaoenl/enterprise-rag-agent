，正文：2023年9月，东京电玩展将再度拉开帷幕。卡普空公司已经公布了其在展会上的游戏阵容，其中包括即将推出的增强现实游戏《怪物猎人Now》。对于虚拟现实游戏爱好者来说，他们更加期待的是之前在索尼发布会上预告过的《生化危机4：VR模式》。  《生化危机4：VR模式》作为最受期待的PSVR2游戏之一，将提供完整的游戏流程，类似于《生化危机8》的VR模式。《生化危机4：重制版》于今年年初发售，以其现代化的标准，让这款近20年前的游戏在全球范围内广受好评。  在2023年的东京电玩展上，《生化危机4：VR模式》将首次公开亮相，参会者还有机会上手体验。这款游戏与Armature Studio的Meta Quest 2上的《生化危机4》移植类似，都是以第一人称视角进行游戏。这种视角将使得游戏的恐怖感更加强烈，动作更加真实。玩家可以使用里昂的刀来架开攻击，还可将刀与手枪配合使用，进行双持组合。  卡普空公司已经确认，VR模式将作为免费DLC发布。目前尚未公布在东京电玩展上可以体验多久的流程。2023年东京电玩展将于9月21日至24日举行，还将通过TGS VR为全球玩家提供在线展会服务。更多细节将在接下来的时间里揭晓。本文属于原创文章，如若转载，请注明来源：生化危机4:VR模式东京电玩展见！https://news.zol.com.cn/829/8293363.html
