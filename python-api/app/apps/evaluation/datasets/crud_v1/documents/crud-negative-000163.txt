5月14日，2023年辽宁省暨沈阳市城市节约用水宣传周启动仪式在沈水湾公园云飏阁举行。获得2022年沈阳市节水型企业（单位）、节水型社区、先进集体和先进个人的代表获颁牌匾及证书。近年来，沈阳市开展了一系列卓有成效的节水工作：截至2022年底，全市工业用水重复利用率达到86.45%，农业灌溉水有效利用系数达到0.596，再生水利用率达到23.12%，顺利通过国家节水型城市第三次复查。2022年更新改造供水管网144公里，管网漏损率降到8.92%。在推进智能水务建设方面，全市二次加压泵站全部安装了智能远传水表，智慧水务一体化综合管控平台入选国家住建部18项智慧水务典型案例。沈阳市的节水精品工作从可借鉴、可复制、可推广的角度选取了生产性企业、事业单位、医院、学校、社区10家不同的样本，从水的循环使用，雨水的收集利用、先进的测漏防漏系统、农业的节水灌溉、VR节水实践等不同侧面展示了节水的实际效果。沈阳市水务事务服务中心节水部副部长李广文介绍，今年沈阳市将改造供水管网160公里，重点实施曹仲配水厂、长白配水厂扩建、首府新区给水配套、西部区域供水工程。落实海绵城市建设理念，构建“一轴四芯”蓄排体系。完善城镇污水再生利用设施，因地制宜开展城镇污水在工业用水、城市杂用、生态用水等方面的再生利用。辽沈晚报记者 王琳
