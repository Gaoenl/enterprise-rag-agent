，正文：吉利汽车近日公布了其新款车型银河L6的详细信息。该车将提供60km和125km两种纯电续航版本，共有AIR、PLUS、MAX及星舰四个版本供消费者选择，预计将在成都车展上开启预售。  银河L6的设计与已经上市的银河L7类似，采用了封闭式前脸和贯穿式LED灯带，灯带在左右两侧形成了断点样式，看上去更加时尚，提高了车辆的辨识度。该车定位于紧凑型轿车，车身长宽高分别为4782/1875/1489mm，轴距为2752mm。车身设计上，采用了双色车身和类似溜背的造型，配合隐藏式门把手、低风阻轮圈和上扬的腰线，整体设计十分吸引人。  内饰方面，银河L6采用环抱式座舱设计，配备全新样式的多功能方向盘，装备了10.25英寸窄条幅式液晶仪表配合13.2英竖状中控大屏。同时，取消了L7上所配备的副驾驶娱乐屏。该车搭载了高通骁龙8155芯片，提升了用户的数字交互体验，还配备了生成式AI产品——Wow壁纸和依托AI智能语言搜索引擎而来的车外语音交互功能。  动力系统方面，银河L6搭载了e-CMA智能电混架构以及新一代雷神智能电混8848和神盾电池安全系统，由雷神1.5T混动专用发动机以及P1+P2双电机组成。发动机热效率达到了44.26%，最大功率为120千瓦，与之匹配的为3挡DHT Pro变速箱。据官方数据，新车零百加速6.3s，百公里亏电油耗4.55L，WLTC综合续航1370km，且全系标配快充和对外放电功能。本文属于原创文章，如若转载，请注明来源：吉利银河L6曝光：1370km续航 预售开启https://news.zol.com.cn/829/8292077.html
