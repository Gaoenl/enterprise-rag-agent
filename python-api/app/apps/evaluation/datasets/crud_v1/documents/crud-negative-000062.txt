原标题:广州举办“母乳快闪”活动 20多名妈妈当众喂奶以“母乳快闪”为主题的公益活动3日首次在广州举行,母乳妈妈们以集体哺乳的行为艺术倡议母乳喂养。 刘烨 摄以“母乳快闪”为主题的公益活动3日首次在广州举行,母乳妈妈们以集体哺乳的行为艺术倡议母乳喂养。 刘烨 摄20余名妈妈整齐而坐,怀抱着自己的宝宝淡定地当众喂奶......3日,以“母乳快闪”为主题的公益活动首次在广州举行,母乳妈妈们以集体哺乳的行为艺术倡议母乳喂养,吸引大量路人“围观”。8月1日至7日是第22个世界母乳喂养周,这项由世界母乳喂养行动联盟组织发起的全球性活动,旨在促进社会和公众对母乳喂养的正确认识并支持母乳喂养。此间在广州举行的“母乳快闪”活动由母乳爱志愿服务队等机构联合发起。在长隆野生动物世界的活动现场,参与快闪行动的妈妈们在喂奶时十分坦然,有些妈妈使用哺乳遮巾,有些则熟练地利用侧身位进行遮挡,以免“走光”。母乳爱志愿服务队发起人徐靓介绍,目前中国的母乳喂养率总体偏低,很多人被奶粉广告洗脑,认为母乳没有奶粉营养丰富,但实际上母乳喂养是妈妈给孩子的“特供餐食”,对于孩子健康成长非常有益。记者了解到,母乳中含有婴儿所需的所有营养和抗体,可保证婴儿的正常、健康发育。此外,通过哺乳还能增强母婴之间的感情。“母乳快闪”活动当日,多位妈妈还进行了母乳捐献,这些母乳将送至广州市妇女儿童医疗中心母乳库,用以救助重症婴幼儿。从澳洲回国的母乳妈妈秋千,专程带着8个月大的宝宝前来参加活动,秋千介绍,她已经捐献了4次母乳,每次的捐赠量都在280ml至350ml,“把富余的母乳捐献出来是非常有益的事,希望妈妈们能转变旧观念,更多地参与进来。”母乳爱志愿服务队于2013年5月20日在广州成立。服务队由处于哺乳期的妈妈和来自各行各业的支持母乳喂养的热心人士组成,目前核心成员近200位。截至8月1日,志愿服务队成员已累计捐献母乳554次,共计84196毫升,已有15名患病早产儿、重症幼童接受母乳营养治疗。(刘烨)
