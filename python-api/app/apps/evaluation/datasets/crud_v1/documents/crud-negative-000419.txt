2023-08-07 10:13，正文：原标题：头屯河农场：兵地互融送健康 义诊服务暖民心中新网兵团新闻8月5日电（田浩楠、苟敏）“一出单元门就有专家检查身体，医院开展的这次上门服务太好了。”8月2日，新疆生产建设兵团第十二师头屯河农场同和·幸福城社区居民朱进国，在兵团医院、经济技术开发区第二人民医院联合开展的“兵地互融送健康 义诊服务暖民心”义诊活动上说。义诊现场人头攒动、热闹非凡，医生为每一位前来就诊的社区居民提供量血压、测血糖、耳穴压豆等服务，耐心寻问居民身体状况，解答居民的各种疾病问题，对其健康症状进行相关的讲解并给予饮食建议，让他们及时了解自己的身体状况及相关疾病的预防。“刚才我找心血管科的专家给我看了看，他说我身体挺好的，让我保持好的心态，有时间去医院做做检查，然后还测了测血压和血糖，总体来说身体还可以。”小区居民李昌德说。前来义诊的专家覆盖多个临床科室，其中包括内分泌科、心血管科、神经内科、中医科等，与以往不同的是，这次带来了多名儿科专家，为居民提供更加全面、系统的健康检查以及医疗咨询。“看到这里还有儿科专家，就带孙子过来看看，我们家孙子脾胃不太好，医生说就补一下维生素A和D就行了，检查结果也挺好的，谢谢他们了。”小区居民邓秀英说。据了解，此次义诊活动是头屯河农场医院与经济技术开发区第二人民医院签署医联体协议后开展的第一次进小区义诊活动，是促进兵地融合共建的一次有效措施，在双方加强学术沟通交流的同时，构建了分级医疗、急慢分治、双向转诊的诊疗模式，形成分工协作、合理利用资源，方便群众就医的服务体系。通过开展此次活动也让居民切身感受到了医联体服务带来的便利和好处，受到了广大居民的认可和欢迎。“此次义诊活动，是我们和兵团医院、经开区第二人民医院加强沟通交流和相互学习的好机会，也是促进兵地共建的有效措施，下一步，我们会继续通过联动的医疗资源，为居民搭建一个健康服务平台，提供更多的医疗服务，切实把健康送到居民手中。”头屯河农场医院副院长许长海说。翻译搜索复制返回搜狐，查看更多责任编辑：
