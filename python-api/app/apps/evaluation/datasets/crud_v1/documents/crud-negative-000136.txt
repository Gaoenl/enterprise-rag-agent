11月5日，全国“扫黄打非”办从各地近期破获或办结的“护苗”类重点案件中，筛选3起公布简要案情，曝光危害少年儿童的不法行为。北京破获“曼陀SP山庄”网站传播虐童淫秽色情信息案2019年7月，根据群众举报，北京市文化执法总队发现，一个名为“曼陀SP山庄”的网站中含有大量虐童色情视频和图片。9月26日，专案组执法人员实施收网行动，现场抓获网站实际经营者、网站管理员以及骨干分子等犯罪嫌疑人5名，收缴涉案电脑等工具20部。经查，“曼陀SP山庄”网站成立于2005年，起初是一个普通博客类网站，主站内容正常，但隐蔽的二级域名内有少量色情虐待类小说。该网站通过实行会员制、租用海外服务器等方法躲避监管，经十余年隐蔽发展，成为国内SP（spanking性虐待）圈的标志性网站。网站包含影音自拍类、同城交友类、文章类及视频类等14个子模块，有海量虐童及儿童色情视频、图片、小说等内容。目前，案件在进一步办理中。浙江杭州查获系列色情漫画网络平台传播淫秽物品案浙江杭州市公安机关通过互联网巡查，发现紫漫、啃漫星族、偷阅公众号、圣灵论坛等8个色情漫画网络平台涉嫌传播淫秽物品。警方立即调查取证，迅速查清色情漫画网络平台的组织架构、资金流向，获取关键证据。2019年8月中旬，专案组共对19名犯罪嫌疑人采取刑事强制措施，缴获涉案淫秽色情漫画数据近3T（信息计量单位，1T=1024G）。经查，紫漫等色情漫画网络平台犯罪团伙，在境外服务器上搭建网站，并在境外漫画网站获取淫秽色情漫画，通过在小说、电影、游戏等各种网络平台植入弹窗广告进行推广，以诱导网民充值付费阅读的方式牟利。8个色情漫画网络平台拥有注册会员近百万人，其中70%为18周岁以下的未成年人，涉案资金超2000万元。在被抓获的犯罪嫌疑人中，90后占大多数，其中有人在互联网公司工作，下班后兼职运营色情漫画平台。目前，案件在进一步查办中。 内蒙古包头宣判“9·11”马某某录制传播淫秽色情视频案2017年9月，内蒙古自治区包头市公安机关接到群众举报线索，一网民利用QQ涉嫌传播涉未成年人淫秽色情系列视频，视频录制地点位于包头市某酒店内。经查，视频录制者马某某从2015年开始，通过在QQ群中加好友等途径，以涉世未深的男性未成年人为目标，利用给受害人充手机话费、发微信红包等诱骗手段，录制相关淫秽色情视频并出售牟利。期间，马某某向网民“XX棒哥哥”以每部1000元的价格出售20部，非法获利2万元。2017年9月，马某某被抓捕归案，犯罪事实被查清。随后，贵州公安机关锁定并刑拘李某某，查明其传播涉未成年人淫秽色情视频的违法事实。2019年5月底，内蒙古自治区包头市东河区人民法院审结包头“9·11”马某某录制传播淫秽色情视频案，马某某犯猥亵儿童罪被判处有期徒刑4年。安全上网及时举报全国“扫黄打非”办公室负责人指出，上述3起案件案情典型，不法人员利用网络直接侵害未成年人，或将未成年人作为主要传播对象传播有害信息，危害严重、影响恶劣。也提醒广大家长和未成年人，注意安全上网，提升网络安全意识，积极防范网络风险。遇到色情、低俗、暴力、恐怖、残酷等有害内容网上传播情况，可及时向“扫黄打非”部门举报。举报/反馈
