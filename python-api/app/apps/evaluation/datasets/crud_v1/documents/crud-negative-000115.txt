新华社乌兰巴托8月30日电(记者阿斯钢 苏力雅)由中国内蒙古自治区人民政府新闻办、中国驻蒙古国大使馆、蒙古国文化部共同主办的“感知中国”・内蒙古文化周系列活动30日晚在蒙古国首都乌兰巴托拉开序幕。据介绍,系列活动将持续到9月3日,包括文艺演出、中国电影周、蒙医义诊、歌曲比赛等多项活动,旨在推动中蒙两国人文交流与互动,增进人民了解和友谊。中国内蒙古自治区政府新闻办主任江新辉、中国驻蒙古国大使馆公使衔参赞张木星、蒙古国文化部国务秘书恩赫阿木古楞等中蒙两国官员及各方代表等数百人出席了开幕式。江新辉表示,“感知中国”・内蒙古文化周活动已在蒙古国连续举办多届,一直秉持中蒙友好的初心使命和根本遵循,坚持促进民心相通、增进传统友谊这一根本目的,让蒙古国朋友进一步感知中国、了解内蒙古。恩赫阿木古楞表示,近年来蒙中两国各领域合作不断深入,尤其是人文合作取得长足发展。很高兴“感知中国”・内蒙古文化周系列活动再次在蒙古国启动。30日晚,《武魂》少林武术专场演出在乌兰巴托上演。32名武僧演员轮番登台,先后表演少林集体镇山棍、童子功、象形拳、硬气功、八段锦等节目,展示中华传统武术的艺术魅力。“感知中国”是国务院新闻办公室创设的品牌活动,是国外公众在本国直接了解中国、感受中国、体验中国的一个重要平台。自1999年以来,“感知中国”已在法国、美国、德国、巴西、南非、日本等多个国家成功举办。(责编:贾文婷、徐祥丽)分享让更多人看到
