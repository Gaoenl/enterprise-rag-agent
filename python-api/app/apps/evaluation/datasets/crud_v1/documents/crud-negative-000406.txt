2023-08-06 07:01，正文：原标题：让戏剧走进儿童青少年中国儿童青少年戏剧艺术普及推广中心深圳市福田区推广中心授牌仪式上，孩子们进行戏剧艺术表演。 （受访者供图）【深圳商报讯】（记者 赵玉）日前，中国儿童青少年戏剧艺术普及推广中心深圳市福田区推广中心授牌仪式在福田区城市云客厅举行。文化和旅游部全国公共文化发展中心主任白雪华在致辞中表示，福田在青少年美育上做了很多探索，青少年公共文化研学基地等走在全国前列，戏剧基地的落脚点是推广青少年美育，相信福田能够以本次授牌为契机，为福田戏剧孕育更美好的未来。中国儿童艺术剧院院长冯俐在视频致辞中，对中国儿童青少年戏剧艺术普及推广中心深圳市福田区推广中心授牌表示祝贺，双方将加强联动，共同推动青少年戏剧发展。广东省文化和旅游厅二级巡视员屈其仁表示，本次中国儿童青少年戏剧普及推广中心深圳福田推广中心的成立，不仅标志广东省对儿童青少年戏剧艺术普及推广工作的进一步深化，更是广东省儿童青少年戏剧艺术事业发展的一个重要里程碑，能让更多孩子接触、了解戏剧艺术，深度挖掘省内优质戏剧力量，让向上向善、刚健朴实的文化融入生活日常。未来，广东将继续依托全国公共文化发展中心和中国儿童艺术剧院，借助平台优势，用力、全域推进文化强省建设。据介绍，福田将以本次授牌为起点，促进青少年戏剧艺术的传承、普及和创新，为福田青少年戏剧美育拉开崭新的一幕，让孩子和家长们通过戏剧美育深切触摸“首善文明”。福田区公共文体中心作为首批13家中国儿童青少年戏剧艺术普及推广中心试点单位之一，接下来将从资源整合、平台搭建、团队组建、阵地拓展“四个维度”，采取“十四项举措”，进一步推动福田儿童青少年戏剧发展。 返回搜狐，查看更多责任编辑：
