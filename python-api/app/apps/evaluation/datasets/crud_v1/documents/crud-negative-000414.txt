2023-08-07 17:03，正文：原标题：浙江温州货车改装“房车”10人横卧车厢央视网消息：车辆非法改装、超员、人货混装都属于违法行为，存在严重的安全隐患。8月3日，温州高速交警在平阳收费站查获一辆违反规定载客的货车，车厢内除货物外，竟还藏了10个人。当日19时13分许，温州高速交警六大队民警在G15沈海高速平阳收费站外广场对过往车辆进行检查时，发现一辆浙C牌照的红色中型厢式货车，驶出收费通道后明显加快了行驶速度，便立即示意该车靠边停车接受检查。经检查，该车核载5人，驾驶室前后并无异样。随后民警让驾驶员打开车厢门进一步检查，只见车厢被分成了上下两层，下面一层塞满了渔货，上面则用铁架、木板、草席搭成了“通铺”，躺满了人。经过现场清点，狭小的车厢上层挤入了10名成年男子，他们无任何安全措施直接躺在上面。驾驶员邱某交代，该车辆是从苍南海鲜市场开往平阳菜市场，车上的14人全都是海鲜商贩，为了出行方便，直接将车厢临时改成了双层车厢，并未意识到其中的危险性。高速交警责令邱某将车厢内乘客进行安全转运，消除安全隐患，而邱某因“驾驶载货汽车违规载客”的违法行为，将面临500-2000元的罚款，驾驶证记3分的处罚。（报道员吴日尧）来源：央视网返回搜狐，查看更多责任编辑：
