“近3个交易日，花生期货近远期合约价格整体出现下滑，其中在昨日还出现了较大跌幅，主力合约期价则一度接近10000元/吨整数关口，引起了市场较为强烈的关注。”河南省郑州市一家花生期货投资机构负责人陈起力告诉期货日报记者，当前市场供需偏紧的格局较为确定，现货普通米通货价格保持稳定，年内进口花生数量较为有限，油厂收购仍较为积极。在如此市场背景之下，花生市场却出现了一波较大的下行行情，这自然受到了大家的重视。陈起力认为，市场出现看似异常的行情只是一个表面现象，从本质上来讲，无论市场供需关系偏紧到何种程度，当前及今后花生价格的涨跌主要还是看油厂的“脸色”。这主要是由花生市场的需求结构所决定的，实际上昨日花生价格的下行尤其是近几个交易的持续走低均与油厂下调收购价有很大关系。据记者了解，当前国内花生的消费主要分为食用与油厂压榨两大部分，其中食用花生由于分级多、品类杂而导致价格也分为“三六九等”，每一个品类均对花生市场主流价格形不成决定性作用，但用于油厂压榨的油料米就不同了，不但数量多，在花生下游需求市场占据的份额大，而且衡量质量高低、确定价格涨跌的标准均较为统一，其市场价格的高低水平，即油厂特别是大型油厂采购油料米的价格就成为整体花生市场的主流价格。“昨日，一家跨国粮油集团企业分别在国内不同地区下调了所属油厂花生到厂价，估计这是搅动市场情绪的主要原因之一。”陈起力告诉记者，这家公司位于山东的一家油厂油料米收购价下调150元/吨至9900元/吨，位于河南的一家油厂油料米到厂价则下调了100元/吨。油厂调价引起整个市场情绪出现了较大的波动，进而又引起了花生期货投资者交易行为的变动。在此之前，这家企业已经下调过油料米到厂价格。来自北京市的一位粮油市场资深分析人士告诉记者，当前年度我国花生市场供需偏紧比较确定，明年新季花生种植面积预计也难以出现大幅增加。因此，他认为花生市场普通米收购价未来在10000—11000元/吨区间振荡的概率较高。从当前的国内现货市场情况分析，除了花生剥壳厂在积极出售前期存货以外，农户的销售还是没有上量，部分农民依然较为惜售，市场上普通米通货收购价仍维持在10600元/吨左右，部分产区如河南南阳市场的收购价还出现了小幅上涨。不过，在广东省东莞市油脂批发商秦保军看来，由于下游产品如花生油库存高、需求疲软，即便原料供应偏紧、农民惜售，但在近期豆粕、菜粕与花生粕持续下行之际，花生价格难以上涨。秦保军告诉记者，花生下游终端消费情况处在近年来较差的水平，部分花生油品的销售总量下降了30%以上，如果再考虑到当前棕榈油、豆油、菜油三大油脂仍呈现下滑态势，粕类价格也存在进一步下行的空间，自今年新季花生上市以来一直居高不下的市场价格昨日出现较大跌幅也不难理解。部分业内人士表示，当前决定花生价格涨跌的核心市场因素已转移到了需求端，如果未来市场仍然缺少核心的来自消费方面的支撑，预期价格前景不是十分乐观，但市场也的确存在较多的不确定性因素在影响着消费预期。与此同时， 随着疫情防控政策的优化调整，也许市场消费会重新走上增长的轨道。（文章来源：期货日报）
