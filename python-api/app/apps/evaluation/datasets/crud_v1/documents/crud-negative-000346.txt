图集新华社第比利斯4月2日电(记者李铭)巴库消息:阿塞拜疆、哈萨克斯坦和格鲁吉亚三国铁路运输部门1日在巴库签署跨里海国际运输通道协议。这标志着三国联合推动的欧亚大陆交通走廊建设又向前迈出一步。当天,三国相关部门代表签署协议,明确了加入该协议的资格条件,确认了推动该通道建设的联合工作组成员,并制定了2017年行动计划。跨里海国际运输通道东起哈萨克斯坦的多斯特克,西至阿塞拜疆的巴库,全长约3500公里。这条连接欧亚的运输通道主体是陆上铁路,其间一段需从哈萨克斯坦的阿克套港乘渡轮穿过里海抵达巴库。格鲁吉亚加入后,通道进一步向西延伸至格鲁吉亚的黑海港口。2015年8月,由中国发车的首趟实验国际列车经由跨里海运输通道顺利抵达巴库港。2016年10月,阿塞拜疆、哈萨克斯坦和格鲁吉亚成立跨里海国际运输通道协会,以吸引更多国际货物经该通道运往中国或欧洲。阿塞拜疆方面认为,与海运相比,经跨里海国际运输通道运输货物将更加便捷。通过跨里海国际运输通道,来自中国的货物可继续西行,经格鲁吉亚北上乌克兰或南下土耳其,让货物流通更为便利。+1【纠错】责任编辑:张明宇
