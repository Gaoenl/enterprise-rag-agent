今年上半年全球央行购金量创历史同期新高。8月1日，世界黄金协会发布最新的《全球黄金需求趋势报告》（简称《报告》）显示，得益于今年上半年全球央行购金量创历史同期新高，以及全球黄金投资和金饰消费需求的持续增长，全球黄金市场势头良好。《报告》显示，二季度黄金需求（不含场外交易）为921吨，同比略降2%；不过，包含场外交易的黄金需求总量却同比增长7%，表明全球黄金市场依旧稳健。上半年全球黄金总需求（不含场外交易）为2062吨，同比下降6%；而包含场外交易的上半年黄金需求总量则达到了2460吨，同比增长5%。购金需求方面，二季度央行购金需求与去年同期相比减少至103吨，主要由于土耳其央行大量出售黄金。即便如此，全球的央行购金需求依旧在整个上半年达到了创纪录的387吨，二季度的需求从长期来看也表现出明显的积极态势，这预示着官方购金需求很有可能在2023年整年都将保持强劲。全球黄金投资方面，得益于包括美国和土耳其在内的关键市场的增长，二季度金条和金币需求达277吨，同比增长6%；上半年金条与金币需求总量达582吨。二季度全球黄金ETF流出21吨，显著低于2022年同期的47吨；整个上半年累计净流出量为50吨。具体到中国市场来看，今年二季度中国国内的金饰需求和黄金投资需求环比均出现了明显下跌。但受去年低基数因素影响，2023年二季度中国国内金饰需求同比仍增长了28%至132吨。据世界黄金协会分析，与去年较低的基数相比，2023年二季度中国国内金饰需求同比实现反弹；但由于季节性因素、国内金价上涨等因素，二季度金饰需求较一季度环比出现下降。但总的来看，上半年中国国内金饰需求同比增长17%至328吨。不过，世界黄金协会也表示，中国国内金饰需求尚未恢复至2021年或10年来的平均水平。这主要是因为，一方面创历史新高的金价影响了金饰需求；另一方面，消费者在旅游和其他娱乐方式上的支出增加也抢占了金饰的消费空间。世界黄金协会的数据显示，二季度，中国市场黄金ETF再次流出，资产管理规模（AUM）降至220亿元人民币（50.2吨）；上半年共流出约合5.21亿元人民币，相当于持仓减少1.3吨。“金价上涨2%引发的投资者获利了结可能推动了本季度的黄金ETF的流出。”世界黄金协会认为，但幅度有限，因为黄金避险需求和人民币金价的出色表现仍令大部分投资者持有其黄金ETF份额。此外，在央行购金方面，6月，中国官方黄金储备已连续第八个月增加。截至6月底，中国官方黄金储备为2113吨，二季度增量为45吨；上半年，中国央行累计报告购金103吨，而在最近的八个月期间累计增储165吨。展望后市，世界黄金协会中国区CEO王立新表示，季节性因素预示二季度后黄金需求或将回升。鉴于2022年的基数较低，2023年的年同比增幅有望达到两位数。金饰方面，各类消费刺激政策或将有助于金饰需求增长，但国内金价的高企等因素可能会对金饰需求的增长造成阻碍。黄金投资方面，市场避险情绪或将为黄金零售投资提供助力。(本文来自澎湃新闻，更多原创资讯请下载“澎湃新闻”APP)举报/反馈
