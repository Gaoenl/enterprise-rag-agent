据俄罗斯《共青团真理报》网站报道，俄罗斯外交部发言人扎哈罗娃当地时间5月18日在吹风会上透露美国在乌克兰生物实验室活动的新证据，并称这些证据“令人震惊”。视频截图扎哈罗娃指出，美国人为五角大楼的利益而进行这些活动，在乌克兰14个居民点的30个实验室同时研究最危险的病原体。美国国防部与乌克兰国防部和卫生部间的协议为这些研究提供法律基础。2014年乌克兰发生政变后，拥有外交豁免权的美国生物武器专家抵达该国并负责监督工作。在此期间，美方为相关研究拨款15亿美元。报道称，俄罗斯开始特别军事行动后，美国和基辅下令紧急销毁搜集的病原体。然而，匆忙之中并未销毁干净。俄方在马里乌波尔发现一个霍乱菌株数据的收集和鉴定中心，还在顿巴斯发现两个2020年运至此处的移动实验室。扎哈罗娃表示，对变异禽流感（对人类致死率达50%）威力的研究尤其受到关注。美国驻基辅大使馆的美国专家为此牵头研究了东欧国家、乌克兰和俄罗斯间鸟类、蝙蝠和爬行动物的迁徙路线。报道指出，尤其令人愤慨的是，美国利用包括军人和住院病人在内的乌克兰公民进行病原体实验。哈尔科夫实验室的研究导致至少20名军人死亡，约200人送医治疗。哈尔科夫第三医院、哈尔科夫州第一精神病院及其他一些医疗机构进行过人体实验。这些实验主要针对斯拉夫人。俄外交部发言人称，根据已掌握信息，2020年在卢甘斯克一些地区，美国利用经过专门处理的假钞人为传播重症结核病。这就解释了，为何乌克兰难民在进入欧盟国家时，除接受新冠核酸检测外，还须通过结核病检测。此外，俄方还掌握了基辅当局发出的关于应对实验室研究的病毒暴发的命令，其中要求“甩锅给”似乎“开火摧毁了医疗科研中心”的俄军。来源：参考消息流程编辑：TF063如遇作品内容、版权等问题，请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话：010-85202353下载“北京日报”客户端 阅读体验更佳哦扫描二维码下载手机客户端扫描二维码下载手机客户端
