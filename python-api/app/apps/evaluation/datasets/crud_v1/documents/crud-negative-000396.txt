原标题:省见义勇为基金会来我市开展慰问活动本报讯(记者梁立新)7月19日至20日,省见义勇为基金会来我市开展“大义无悔扬正气 翰墨丹青颂壮举”见义勇为慰问活动,先后举行见义勇为爱心企业授牌暨慰问仪式、慰问见义勇为模范仪式,省内外知名书画家为见义勇为模范现场作画题字。省见义勇为基金会理事长陈光、秘书长孙伟参加慰问;市委副书记、政法委书记杨旭东,市见义勇为基金会理事长韩国祥陪同有关活动。陈光对我市见义勇为事业呈现出善行义举蔚然成风、凡人英模层出不穷的良好局面予以充分肯定。他指出,这次慰问的15名见义勇为模范代表为全省干部群众树立了学习的榜样,全社会要认真学习他们无私奉献、临危不惧、富有正义的情操、胸怀和品质,大力弘扬见义勇为精神,在更大范围凝聚社会正风正气。各级各部门要进一步拓宽见义勇为行为的发现途径,创新表彰奖励机制,扩大表彰范围。要全力为见义勇为人员提供援助,帮扶救助好见义勇为困难家庭,切实解决他们的后顾之忧。要广泛宣传社会善行义举,不断提高先进事迹的感染力、凝聚力和影响力。要加强组织领导,整合资源力量,不断提高推动见义勇为事业的能力水平。杨旭东表示,将以此次活动为契机,持之以恒完善见义勇为工作体系,推进基金会科学规范管理,以更高标准、更实举措、更大力度推动见义勇为事业再上新台阶,为平安淄博、法治淄博建设作出新的更大贡献。原标题:《省见义勇为基金会来淄博市开展慰问活动》阅读原文
