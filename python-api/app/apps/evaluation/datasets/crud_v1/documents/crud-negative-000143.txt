2023-07-28，正文：7月25日，济南公布打击整治网络谣言5起典型案例。其中，孙某某在微信公众号发布“暴雨过后小女孩看见超市无数冤魂聚集”的谣言信息，已被处以行政处罚，并关停公众号。谣言内容显示：在商场修建好了之后，有一位小女孩跟着妈妈一起来到了该商场，小女孩却突然问她的妈妈，地上面为什么会躺着那么多的人。这句话一说出来，这位妈妈直接就被吓惨了，赶忙就拉着小女孩从商场冲了出去。目前，公安机关依法对孙某某处以行政处罚，对其微信公众号采取关停措施。其他典型案例：吴某某编造“她人卖淫”网络谣言案2023年5月，长清区吴某某因和减肥训练营的室友杜某发生矛盾，在微信朋友圈编造并发布“她人卖淫”图文谣言信息。济南公安机关依法调查，吴某某对其违法行为供认不讳。目前，公安机关依法对吴某某处以行政处罚，对其发布的造谣信息已及时清理。岳某某编造“发生命案”网络谣言案6月17日，历城区岳某某为吸引眼球博取关注，在网络平台发布“出大事了人命案”谣言信息，引发网民关注评论和传播，扰乱社会公共秩序。济南公安机关依法调查，岳某某对其违法行为供认不讳。目前，公安机关依法对岳某某处以行政处罚，对其发布的谣言信息已及时清理。孙某某编造“小女孩看见超市无数冤魂聚集”网络谣言案
