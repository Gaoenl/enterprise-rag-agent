原创 清远妇联 清远妇联为深入开展“巾帼就业创业促进行动”，促进女大学生更高质量更充分就业，助力我市“百县千镇万村高质量发展工程”，近日，市妇联副主席罗允迎率队到被命名“2023年广东省女大学生创业实践和就业实习基地”的广东融湾人才发展有限公司进行走访调研并进行授牌。市妇联一行参观了基地，与基地负责人进行座谈交流。座谈会上，基地负责人介绍了基地的人员架构，“1+N”高校创业孵化基地的推进情况，以及如何为省职教城大学生群体特别是女大学生提供更多创业就业服务、促进高校毕业生留清就业的工作计划。目前，市妇联已走访调研了新一批3个女大学生创业实践和就业实习基地。罗允迎希望这些基地提高政治站位，彰显责任担当，结合就业实习，为女大学生提供创业孵化和人才引育平台；积极举办或参与各类大学生创新创业大赛，彰显巾帼力量，助力“百千万高质量发展工程”；做好工作计划，打造亮点项目和优势品牌，在女大学生群体中进一步提升影响力，带动更多的女大学生创新创业。原标题：《百县千镇万村高质量发展工程|市妇联为新一批广东省女大学生创业实践和就业实习基地授牌》阅读原文
