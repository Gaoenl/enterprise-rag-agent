2023-08-08 17:48，正文：原标题：大象帮丨村民闹纠纷垃圾堵门！业主很受伤有家难回大象新闻记者 汤磊8月7日，不少家住郑州市惠济区新城路中原宸院二期的业主求助大象新闻·大象帮，称自家小区门口被倾倒了大量建筑垃圾，严重影响出行。业主多次向物业、街道办事处、环境监察大队等相关单位反映，希望能尽快解决问题。大象帮记者赶到该小区，看到小区门口的建筑垃圾堆宛如一座小山坡，几十米宽的小区正门只留出了一个车道通行。“这都是胖庄村的人倒的，之前他们也在这倒垃圾，但没这么多。”据求助业主介绍，中原宸院二期征用了胖庄村的土地，因为村民和相关单位的矛盾未解决，村民们就以垃圾堵路这种方式进行抗议。“东门被胖庄村堵死了出不去，现在西门也用垃圾堵着，我们招谁惹谁了？”记者绕行至中原宸院二期东门，看到有几间临时搭建的简易房将东门堵了个严实，屋内有人居住的痕迹，东门外道路也处于未开发断行状态。中原宸院二期一路之隔的就是胖庄村的安置房小区，“这个地是2018年征收的，我们村民的过渡费到现在也没发，2021年（惠济）区里和（新城路）办事处的领导承诺我们2022年3月底给我们发放，到现在都没兑现。”一位年过七旬的胖庄村村民告诉记者，征地时村委会曾承诺每亩地每年给村民6000元租金，直到征地补偿款全额补偿到位为止，但是截至目前只给过一年租金，其他的没有再支付过。随后，记者将小区业主诉求和胖庄村村民的问题反映给新城路街道办事处，办事处工作人员称垃圾堵门是因为中原宸苑二期和胖庄村安置区一期拖欠垃圾清运公司清运费用，垃圾清运公司拒绝清理这两个小区的垃圾。目前这两个小区已经和垃圾清运公司达成一致，该公司同意继续对这两个小区的垃圾进行清理。关于业主反映中原宸苑二期东门道路未开发这一问题，现已自北向南进行正常施工，关于东门外简易房拆迁问题也已经达成一致意见，预计本月15号完成搬迁。截至8月8日记者发稿前，小区门口的垃圾已被清理完毕。但对于村民反映过渡费未及时发放问题，新城路街道办事处暂未回应。如果你有任何问题你的“急难愁盼”河南广电全媒体记者和相关部门一起为您解决返回搜狐，查看更多责任编辑：
