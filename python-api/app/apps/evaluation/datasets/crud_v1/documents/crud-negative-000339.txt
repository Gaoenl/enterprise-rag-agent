2023-08-16 09:09，正文：原标题：重庆电力部门开展首个全国生态日宣传教育活动中新网重庆新闻8月15日电(记者 周毅)15日是首个全国生态日，国网重庆市电力公司开展了相关宣传教育活动。据了解，本次活动围绕“传播沟通”“交流互动”两条主线进行，“传播沟通”方面，国网重庆市电力公司员工通过在当地各大商圈、工业园区、公益项目实施地等场所，摆放宣传资料，向外界介绍国家电网公司建设资源节约，环境友好绿色电网的各项举措，以及构筑候鸟迁徙保护网络，保护生物多样性的生动实践和生态保护成效。“交流互动”方面，国网重庆市电力公司员工以“武隆野外科学观测站志愿宣讲助力全国生态日”“候鸟生命线”“园区‘碳’秘 绿色发展”“‘绿水青山就是金山银山’在特高压线路工程落地”“电网报废物资循环利用”“服务新能源发展”等主题活动为载体，深度链接政府相关部门、重点园区客户、环保专家、公益项目实施地居民等，通过志愿服务、场景展示、现场宣讲等多种形式，全方面展示该公司在电网线路与自然和谐共生、精细化碳管理、特高压生态建设、优化电网报废物资循环利用、实施屋顶光伏项目等方面的绿色实践，让社会感知国家电网公司为美好生活充电，为美丽中国赋能的责任担当。当天，在金上至湖北±800千伏特高压直流输电工程合川建设现场，工作人员为参观者发放了绿色环保宣传手册，并讲解了特高压金上线路工程绿色建造实施举措和成效。国网重庆建设公司金上线业主现场项目经理易莹鑫以建设人的身份就特高压建设中环境保护、水土保持等与现场铁塔基础建设的深度融合进行了重点讲解。从表土剥离厚度、余土处置方式、植被恢复措施等15个方面，展示了特高压绿色建造实施举措与成效。此外，通过此次全国生态日的宣传，促进了生态环境保护等方面的交流，提升了员工生态环境保护意识。(完)返回搜狐，查看更多责任编辑：
