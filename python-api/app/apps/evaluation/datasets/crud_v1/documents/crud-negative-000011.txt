深圳新闻网2023年9月3日讯(深圳晚报记者 邱志东 通讯员 郭成海 邱宇晖) 深晚记者从深圳铁路部门获悉,今年暑运,铁路旅客出行需求十分旺盛,学生、探亲、旅游等多种客流叠加,使得客流持续火爆、热度不断,成为最“热”暑运。为期62天的暑运,深圳铁路累计到发旅客3362.22万人次(其中发送1801.72万人次、到达1560.5万人次),同比去年增加1753.12万人次,增幅达108.95%,较2019年增加94.6万人次,恢复到2019年的102.89%。其中,深圳北站日均到发旅客达38.9万人次,累计到发旅客2411.74万人次(发送1278.09万人次、到达1133.65万人次),同比去年增加1215.45万人次,增幅达98.42%,较2019年增加256.56万人次,恢复到2019年的111.9%,发送客流最高峰出现在7月8日,达26.63万人次。市内其他高铁站客流较往年也大幅攀升,福田站每日跨境旅客超6000人次,深圳坪山站每日到发双向客流均破万。▲2023年暑运期间,深圳北站持续迎来较大客流。 深圳晚报记者 严文婷 摄今年暑运客流量是近年之最,初期客流以学生为主、旅游探亲为辅,进入中期之后,逐渐转变为旅游探亲为主、商务出行为辅,广州、潮汕等省内地区和广西、湖南、福建等省外地区是深圳地区铁路旅客出行的热门方向。今年暑运的运力投入也是近年来最大的,日均开行列车1100余列。同时,深圳铁路还累计加开前往广州、潮汕、长沙等热门方向的临时列车近2100列,其中包括夜间动车组列车57列。暑运期间●深圳北站日均到发旅客达38.9万人次●累计到发旅客2411.74万人次●同比去年增加1215.45万人次 增幅达98.42%●较2019年增加256.56万人次●恢复到2019年的111.9%
