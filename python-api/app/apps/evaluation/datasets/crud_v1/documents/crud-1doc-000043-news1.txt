2023-08-09 18:38，正文：继多名美国高官今年访问越南后，拜登日前也宣布将“很快”开启越南之行，并称越南“希望成为美国的合作伙伴”。据路透社8月9日报道，美国总统拜登当地时间8月8日晚间在新墨西哥州的一场政治筹款活动上表示自己将“很快”访问越南，并称越南希望成为“美国的合作伙伴”。白宫方面目前没有透露拜登访问越南的具体行程。拜登 视觉中国 资料图拜登曾于7月28日透露接到了“越南首脑”的电话，并称越方希望将美国“提升为与俄罗斯、中国一样的主要合作伙伴”。路透社援引分析人士的话称，拜登提到的“越南首脑”可能是指越共中央总书记阮富仲，两人此前曾于今年3月通过电话。在拜登之前，美国副总统哈里斯、财政部长耶伦分别于近期出访越南，多次提及越南是美国“印太地区的重要合作伙伴”，寻求提升美越关系。在4月访问越南时，美国国务卿布林肯还曾表示，安全问题是美越关系的“重要组成部分”。目前美国官员并未透露美越关系的进一步提升将在哪些领域带来影响，但有专家认为，美国将加强与越南的军事合作，并向越南提供更多武器装备。另据彭博社报道，拜登还在8月8日新墨西哥州的活动上表示，“其他国家也渴望加强与美国的关系”，并提到了他即将在戴维营与韩国、日本领导人举行的会面。此前白宫曾在一份声明中表示，在8月18日的戴维营美日韩三边峰会中，三国领导人将讨论“扩大印太地区内外的三边合作、应对朝鲜威胁、加强与东盟及太平洋岛国关系”等问题。
