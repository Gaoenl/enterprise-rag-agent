2023-08-10 16:11:55，正文：中新社福州8月10日电(叶秋云)10日，第三届海峡两岸(福州)名校电竞营总决赛在位于福州市马尾区琅岐岛的海峡青年交流营地举行，武汉大学代表队夺冠，亚军、季军分别是台湾交通大学代表队、台湾政治大学代表队。“这是我第一次来大陆，算是为了圆自己的电竞梦而来吧。”台湾大学学生赖扬天是此次赛事选手之一，他告诉记者，两岸青年学子透过共同的兴趣、爱好，很容易找到共同话题，面对面交流很快就拉近了彼此距离。第三届海峡两岸(福州)名校电竞赛是第十一届海峡青年节集中活动之一，今年是首次推行线下电竞赛和现场交流。据悉，此次比赛吸引了北京大学、武汉大学、台湾大学等两岸8支高校战队参赛，通过海选赛、淘汰赛、四强赛、总决赛进行“面对面切磋”。比赛之余，来自两岸的电竞选手还一起参观了福州三坊七巷、烟台山历史风貌区等景点。赖扬天表示，参访过程中和大陆学生一起交流学习和生活，并感受福州当地的历史和人文景观，感觉轻松愉快。福州市电竞协会相关负责人表示，此前两届电竞营已累计吸引20余所两岸高校的近50支战队约300人参与。该协会希望借名校电竞赛搭桥，吸引更多两岸高素质人才关注、投身电竞这一新兴行业。(完)
