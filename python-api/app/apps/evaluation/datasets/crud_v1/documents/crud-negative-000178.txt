2023-08-08 14:36:02，正文：为贯彻落实总局《工业产品生产单位落实质量安全主体责任监督管理规定》《工业产品销售单位落实质量安全主体责任监督管理规定》，8月2日，闵行区市场监管局龚明红副局长带队至危化品生产企业——上海申星化工有限公司开展检查，产品质量监管科陪同检查。上海申星化工有限公司是一家持有工业产品生产许可证的生产工业用甲醛溶液的危化品生产企业，是落实工业产品生产单位质量安全主体责任的重点单位。检查中，龚明红副局长听取了企业关于质量安全主体责任贯彻执行的情况介绍，并查看了企业质量安全总监、质量安全员责任、“日管控、周排查、月调度”质量安全制度建立情况及相关记录，并要求企业必须牢牢树立“企业是质量安全第一责任人”主体责任意识，严格按照总局“二个规定”的要求，健全企业质量安全管理机制，落实好“日管控、周排查、月调度”的质量隐患排查制度，确保危化品生产质量安全。产品质量科就工业产品主体责任“二个规定”向企业进行了解读，并就企业执行中碰到问题予以讲解。下一步，区局将进一步加大落实工业产品主体责任“二个规定”宣贯和督查指导工作，帮助重点产品生产和销售单位建立完善质量管理机制，提高质量安全主体责任意识，确保质量安全。
