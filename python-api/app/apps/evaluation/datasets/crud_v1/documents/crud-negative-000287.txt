"调查研究是我们党的传家宝，是获得真知灼见的源头活水。习近平总书记近日在内蒙古考察，再次就主题教育发表重要讲话，对“以学正风”提出明确要求，强调要大兴务实之风，抓好调查研究，在察实情、出实招、求实效上下功夫。做好调查研究，不能“走马观花”，更不能“糊弄敷衍”。广大党员干部必须使出“求真务实”的精气神，拿出“吹糠见米”的眼力劲，紧盯问题不放手，实“调”之、细“查”之、精“研”之、深“究”之，真正把情况摸清、把问题找准、把对策提实，以实际行动将调查研究发扬光大。要坚持群众路线，不能让群众“被调研”。党的十八大以来，习近平总书记的足迹遍布大江南北，了解基层群众所思所想所盼，发现问题的痛点难点堵点，为我们做好调查研究树立了光辉榜样。我们要带着使命、带着责任、带着感情，扑下“真身”走进基层一线、带着“真心”扎进群众心窝，才能获取大量“沾满泥土味”的有效数据，在听民声、察民情、解民忧中增进同人民群众的感情。要大力弘扬我们党的好传统、好作风，自觉向群众学习、向实践学习，到群众家中揭开锅盖唠唠家常、到厂矿车间生产一线一同劳动，以“真心”换“真情”，才能把存在的问题难题摸清楚、摸到位，才能把老百姓心中的堵点痛点解决好。要坚持问题导向，但不能搞“问题秀”。要带着问题出发，哪里有问题就到哪里去调研，有什么问题就调研什么问题，才能有的放矢；否则，就会像“无头苍蝇”，只会到处乱窜、迷失方向。调研中，既要善于把问题当“特殊敌人”对待，对一些具有普遍性、制度性的重点问题、突出问题，以及涉及本地区本部门的难题积案和顽瘴痼疾，必须毫不手软地直击问题“心脏处”，彻底地把问题分解、难题化解；又要善于跟问题交“朋友”，看到问题不回避、遇到问题不躲避，多进“肺腑之言”、多下“苦口良药”，在直面问题中成熟、在处理问题中成长，努力将简单问题化之于无形。要坚持攻坚克难，不能让调研“走过场”。调查中，占有资料只是走好了“第一步”，对于各种线索、各种难题，还需要去粗取精、去伪存真、由此及彼、由表及里，全面地思考它、系统地研究它，最终将调查资料升华为研究成果、转化为对策策略。面对调查中发现的各种难题，要坚持运用好习近平新时代中国特色社会主义思想的世界观和方法论以及贯穿其中的立场观点方法，以“解剖麻雀”的方式、以“敢于斗争”的精神，对难题进行全面系统的“核磁共振”，从而找到解决难题的“善策良方”，确保把调研成果转化为促进工作的实际成效。【责任编辑：胡庆章】",
