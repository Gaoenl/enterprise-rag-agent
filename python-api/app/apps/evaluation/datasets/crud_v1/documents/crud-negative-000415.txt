2023-07-25 17:01:32，正文：7月25日上午，黄浦区委副书记、区长沈山州走进《2023夏令热线：区长访谈》直播间，通过与记者现场连线、接听热线电话等方式，回应百姓呼声，介绍民生发展热点，为市民群众解决“急难愁盼”问题。直播期间，沈山州聚焦燃气使用、违法搭建、防汛防台等当前市民比较关心的城区安全问题提出了工作要求。沈山州强调，要切实增强系统观念，以“时时放心不下”的责任感，进一步完善应急体系、基层应急联动机制、火灾风险防范化解机制，强化应急处置，加强预报预警，提升防灾减灾救灾能力。要层层压紧压实安全生产责任，以最严格的措施加强安全监管，着力保障城区运行安全。随后，沈山州先后与3位现场记者进行直播连线，接听了10位市民打进的热线电话，围绕小区绿化过度修剪、地下空间消防安全存在隐患、手机维修遇“李鬼”、老城厢非机动车充电难、黄浦滨江饮水点设置不合理、宾馆泳池水质差、酒吧噪音扰民、门禁安装缺乏人性化、空调室外机架老化等投诉问题一一进行回应，及时协调解决。沈山州强调，要深入践行以人民为中心的发展思想，加快建设更高品质、更有温度、更具安全感的“人民城市”黄浦样板。要聚焦群众的“急难愁盼”问题，完善基本公共服务体系，全心全意增进民生福祉，使人民群众对美好生活的期盼和向往，在黄浦得到最好的回应。一要强化公共服务，着力提升城区环境品质。对于群众关心的绿化建设、生态环境保护、滨江岸线打造等工作，要在加强硬件发展的同时，进一步提升服务的精准度和有效性。要在大力发展夜间经济的同时，为周边居民营造一个安全舒适的休息环境。二要加强重点领域监管，着力保障城区运行安全。要试点安装沿街非机动车智能充电桩，坚决消除地下空间安全隐患，维护城区消防安全。要切实加强宾旅馆的环境卫生监管和老化空调外机的巡查，坚决防范遏制安全事故发生。
