2023-08-16 06:50，正文：广告 四川绿森林化工-主营各类化工原材料-欢迎前来咨询~ ×富尔顿县检察官威利斯（右图）对特朗普提起刑事诉讼海外网8月16日电 据美国公共电视网（PBS）15日报道，在14日晚间因涉嫌推翻佐治亚州2020大选结果遭该州检方起诉后不久，美国前总统特朗普及其盟友对此案均予以回应。特朗普在一封竞选筹款电邮中批评这一起诉，称此案是民主党干涉大选的第四次行动，目的就是让白宫处于该党控制之下，并把该党参选人在2024年大选中最大的对手关进监狱。支持特朗普的超级政治行动委员会称，检察官们正一起起诉特朗普，“唯一的目的就是逮捕特朗普”。特朗普竞选团队也批评，此案是“有偏见的检察官在民主党占多数的司法管辖区进行的一次打压，这不仅背叛美国人的信任，也暴露其捏造指控的真实动机”。当地时间8月14日，美国佐治亚州大陪审团决定对特朗普等人提起诉讼，指控他们涉嫌推翻2020年大选佐治亚州的选举结果。这也是特朗普第四次遭到刑事起诉。当地检察官威利斯（Fani T. Willis）说，被起诉的特朗普及其盟友是试图推翻佐治亚州选举结果的“犯罪集团”一部分。除了最新的这起诉讼，特朗普还面临纽约州起诉其涉嫌商业诈骗、海湖庄园机密文件案以及国会骚乱案三个案件共计78项刑事指控。他对所有指控均不认罪，并多次批评检方和美国司法部，指责检方将联邦政府武器化以阻止他参加2024年美国大选。（海外网 侯兴川）海外网版权作品，未经授权不得转载。
