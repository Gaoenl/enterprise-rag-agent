2023-08-16 12:00:24，正文：     入住出租屋的第二天，何某因燃气爆炸导致大面积烧伤，后抢救无效死亡。事后，房东刘某因不堪压力选择了自杀。今年3月，何某的妻儿将燃气公司和房东女儿刘女士起诉至法院，索赔70余万元。近日，四川江油市人民法院作出调解，燃气公司补偿何某亲属20余万元，何某亲属放弃要求刘女士承担赔偿责任。   据了解，2022年8月17日，年过五旬的四川绵阳人何某及其妻子在江油租下一自建房居住。没想到入住第二天，一场意外发生了——8月18日凌晨5时左右，何某在卫生间洗澡时，屋内突然发生燃气爆炸。受伤的何某随即被送往医院，但因伤势过重，何某在抢救十余天后不幸身亡。   事后，房东刘某因家中发生事故，担心赔偿太多，不堪压力自杀身亡。   2023年3月，何某的妻子、儿子将燃气公司、房东刘某的女儿刘女士起诉至江油市人民法院，请求判令其赔偿各项损失共计70余万元。   面对起诉，刘女士第一次接受法庭传唤时表示：“我们赔偿了原告的损失，谁又来赔偿我父亲自杀身亡的损失？”   8月15日，承办法官向红星新闻记者介绍，为妥善处理本案，以扎实的法律理论为依据说理述情，法院将法理和情理相结合，耐心倾听双方当事人的诉求，体谅双方失去亲人的悲痛，经庭后反复调解，最终于近日促使双方达成和解：燃气公司补偿何某亲属20余万元，何某亲属放弃要求刘某女儿承担赔偿责任。   杨江 红星新闻记者 汤小均   编辑 张莉 责编 李彬彬
