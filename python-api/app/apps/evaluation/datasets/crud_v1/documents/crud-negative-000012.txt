2023年08月05日，正文：                                                                 记者从黑龙江省水文水资源中心获悉，受降雨影响，雅鲁河水位快速上涨，8月4日21时，雅鲁河碾子山站水位217.56米，比早8时上涨0.51米，超警戒水位1.56米，流量3270立方米/秒，呈上涨趋势。根据当前雨水情，综合分析预计：雅鲁河碾子山站（齐齐哈尔市碾子山区跃进街道）8月5日下午出现洪峰，洪峰水位218.10米上下，超警戒水位（216.00米）2.10米，超保证水位（216.50米）1.60米，流量4500立方米/秒。（总台记者 张艺馨）                                  【责任编辑：陈戈辉】
