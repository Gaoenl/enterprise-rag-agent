12月9日，记者获悉，每年冬季时节，都是各大花卉基地备战年宵花市场的关键时期，在镇江丹阳市司徒镇下邳村一处新落成的蝴蝶兰种植基地里，第一批蝴蝶兰开得正好，朵朵“致富幸福”花，只待在今年的年宵花市场里，绽放自身的“美丽经济”。来到镇江丹阳花友园艺的种植大棚，棚外天气寒冷，棚内却是温暖如春，培育的蝴蝶兰里有很多已抢先绽放，花香沁人心脾，造型优雅别致，不少顾客专程来到基地，亲手挑选自己钟意的花卉。市民王女士告诉记者：“我今天来就是主要儿子还有两天结婚了，挑个两盆蝴蝶兰，那个粉红的，还有那个紫红的，都很好看，我准备挑个两三盆回去，让我儿子的新房增添一些色彩。”据花友蝴蝶兰基地负责人介绍，今年三月份在这里进行大棚改造，五月份进场生产，到现在为止第一批蝴蝶兰已经开始产出了，采收的蝴蝶兰里面一共有五十几个品种，专供今年的年宵花，从明年开始春夏秋冬可以进行常年的不间断的供应蝴蝶兰。蝴蝶兰花姿优美，色彩华丽，有“洋兰皇后”之美誉，对种植环境要求也相当之高，但在基地智能大棚的调控下，不仅蝴蝶兰的成活率显著提高，人工成本也大大降低，品质更上一层。丹阳花友园艺有限公司总经理张鸣峰介绍：“我们对大棚进行全面改造，装了很多传感器，对它实行了光照、温度、湿度以及通风的全方位的控制，这样子我们花卉生长出来都比较健壮，每一朵的花都比较长，都达到了A级和特级的品质。”蝴蝶兰作为节日花卉之一，每逢节庆都会迎来热销，据介绍，这里的蝴蝶兰本月开始对外销售，预计到春节前全部售完。张鸣峰介绍：“ 今年的话这边的蝴蝶兰是十万株，如果我们正常全部销售的话，应该在三百万元左右。”（《零距离》记者/胡艳 镇江台 编辑/玉洁）
