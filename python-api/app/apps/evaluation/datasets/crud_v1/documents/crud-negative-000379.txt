上证报中国证券网讯 据水利部消息，为落实《水利部关于全面加强水资源节约高效利用工作的意见》（以下简称《意见》），进一步加强珠江流域水资源节约高效利用，近日，珠江水利委员会印发《珠江水利委员会落实<水利部关于全面加强水资源节约高效利用工作的意见>若干措施》（以下简称《若干措施》）。《若干措施》以珠江水利委员会印发的节水顶层设计文件和现有工作成效为基础，聚焦《意见》提出的水资源节约高效利用新要求，提出了坚持“四水四定”、完善节水标准等八条水资源节约高效利用措施，明确了工作职责和责任分工，强调要充分发挥流域管理机构的统筹协调作用，推动流域全面加强水资源节约高效利用。在刚性约束方面，珠江水利委员会组织开展农业实际灌溉面积复核与典型重点河湖生态断面遥感监测等工作，推动水资源刚性约束制度实施与监管；率先印发《珠江流域县域节水型社会达标建设管理办法实施细则（试行）》。在此基础上，《若干措施》提出了坚持“四水四定”、完善节水标准等措施，明确严格水资源刚性约束，推动建立流域统一协调的用水定额体系；在流域重大水利工程前期工作中严格合规性审查，严控无序调水和人造水景工程。在技术创新方面，珠江水利委员会以点带面，逐年推进和深化流域非常规水源调查及配置试点研究;自主研发的作物环境多因子驱动的低功耗节水灌溉控制系统等入选国家成熟适用节水技术目录。在此基础上，《若干措施》提出了开发利用非常规水源、强化科技支撑等措施，明确非常规水源利用量目标考核，推进粤港澳大湾区典型地区再生水利用配置试点；推动节水技术研究和设备研发，系统梳理珠江流域农灌用水定额管理研究、计量设备研发等成果推荐申报节水相关科技奖项，依托第二届全国节水创新发展大会鼓励委属单位积极参展。在管理机制方面，珠江水利委员会将节水工作纳入委属单位年度绩效考核指标体系中；编制完成《珠江水利委员会节水教育社会实践基地试点建设方案》，拓宽公众参与节水途径。在此基础上，《若干措施》提出了完善节水激励机制、健全公众参与机制等措施，明确对珠江水利委员会节水工作突出的集体和个人，按照有关表彰要求开展推荐工作；联合珠江水利委员会直属机关团委等多部门建立珠江水利委员会机关志愿服务支队，支持志愿者开展节水志愿服务活动；开展珠江水利委员会节水教育社会实践基地试点建设，为社会公众学习体验节水文化提供窗口平台。《若干措施》的印发实施，既贯彻落实了水资源节约高效利用的新要求，又推动珠江水利委员会在已有节水工作成效基础上，保持力度、延伸深度，走好水资源高效利用的节约集约发展之路。下一步，珠江水利委员会将不断巩固现有工作成果，锚定目标、压实责任，贯彻落实全面节约战略，扎实推动各项措施落实落地，加快推进节水型社会建设，为珠江流域经济社会高质量发展提供有力的水资源保障。
