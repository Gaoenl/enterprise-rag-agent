今天，一列满载柴油发电机组等货物的中欧（厦门）班列从厦门海沧车站发出，一路向西前往中亚。这是中欧（厦门）班列开行以来发出的第1213列出口班列，全国首条自贸区中欧班列出口也由此突破10万标箱。从海沧铁路白礁货场出发，经过4天的“跋涉”抵达霍尔果斯口岸，再出境驶往哈萨克斯坦和乌兹别克斯坦——这是一条厦门始发国际货运班列的“行走足迹”。无数条这样的足迹相叠加，就组成了无缝衔接“海丝”与“陆丝”的国际物流大通道。自2015年8月开行以来，中欧（厦门）班列稳定运行中欧、中亚、中俄三条国际货运干线，并通过与“丝路海运”班轮对接，形成了具有独特优势的过境货物海铁联运，为“一带一路”互联互通“穿针引线”。如今，泰国、越南、印尼等周边国家（地区）的货物借道厦门完成过境运输，原本需要三四十天的运输时间，可以压缩到二十天以内。厦门建发保税物流有限责任公司口岸服务部经理 欧吓平：接下来，我们还会大力发展跨境电商，新能源产品及冷链运输，不断丰富班列的运营模式，促进班列的多元化，特色化发展。据厦门海关统计，作为全国首条由自贸试验区始发的国际班列线路，中欧（厦门）班列至今已累计开行1213列出口班列，载货100009标箱，货值达45.03亿美元，货物种类涵盖电子、机械、日用品、生物医药制品等，细分产品超过千种，有力保障供应链和产业链的协调发展。海沧海关物流监管二科副科长 杨希婧：为班列开辟绿色通道，确保出口班列的货物可以“即到、即验、即放、即转”，采用了便捷的转关模式，保证我们出口班列可以一次报关，一次查验，全线放行，提高通关效率，确保班列可以充分地发挥它的运输优势。
