2023-08-06 18:31，正文：原标题：河南盛佳食品捐赠百余万元罐头驰援涿州8月5日，河南盛佳食品有限公司4辆装满罐头的冷藏车缓缓驶出公司大门，经过近12个小时的长途运输，行程700多公里，把价值105万元的罐头送到了灾区。 由于近期涿州市遭受了严重的洪水灾害，许多地区受到了严重的损失。当地的一线工作者和受灾群众正面临着生存的困境，急需食品等基本生活物资。“我看到这个消息以后，了解到灾区急需食品，当天晚上就通知所有工人加班加点，在8月4日加工出来一批罐头，连夜装车发往灾区。”虞城县盛佳食品有限公司董事长贾天运说。 据了解，河南盛佳食品有限公司以专业生产食品类产品而闻名，2022年投资5亿元新建以现代化的肉制食品深加工为主的，位于虞城高新区，与原公司盛源食品有限公司业务形成相互的增链、补链、强链效应，并被列为省重点项目。目前盛佳食品已建立两条生产线，均已投产。项目全部投产后，年仓储、配送货物可达20万吨，年加工罐头3万吨，培根、烤肠5万吨，年产值可达10亿元，向社会提供2500余个就业岗位，将成为集肉食品加工、仓储、贸易、全球配送于一体的综合性企业，将出口非洲和东南亚地区。 河南盛佳食品有限公司也是一家爱心企业，郑州720大水发公司采购了100万元的水、面、肉等生活物资，连续多年资助贫困学生，助力乡村振兴。初步统计，河南盛佳食品有限公司在慈善公益事业方面累计捐款捐物达500余万元。返回搜狐，查看更多责任编辑：
