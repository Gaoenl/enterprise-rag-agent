，正文：在最近的《堕落之主》预览活动中，编辑有幸亲自体验了这款由Hexworks开发、CI Games发行的类魂游戏，并在游戏结束后与创意总监Cezar Virtosu和执行制作人Saul Gascon进行了深入交谈。  据了解，《堕落之主》在PS和Xbox主机上都将提供性能模式和质量模式两种选择。性能模式将以每秒60帧的速度运行，分辨率为1080P，这是业内的标准。而画质模式则是2K升频，以每秒30帧的速度运行。尽管如此，官方表示，即便是60FPS模式，游戏的画面效果也相当出色。  值得一提的是，《堕落之主》将是首批采用虚幻5的3A游戏之一。开发团队在采访中强调了虚幻5的强大能力，并特别提到Lumen是虚幻5对团队影响最大的功能。他们表示：“我们刚开始这个项目的时候，虚幻5还没有发布，但我们一直都有一个分支，其中包含了任何可用的虚幻5预发布版本，我们始终确保游戏是兼容的。当游戏准备就绪后，我们就将整个游戏切换到了UE5。最强大的、可以说是改变游戏的技术是Lumen，因为它让我们放弃了光贴图这种老式的环境照明方式。”  此外，团队还表示，除了Lumen，Nanite也是一个非常出色的功能，它可以提高各处的质量。除了这两项功能外，虚幻5还有其他一些元素。团队表示虚幻5在技术方面是一个巨大的飞跃，未来还会变得更好。本文属于原创文章，如若转载，请注明来源：《堕落之主》游戏实机测试：60帧画面效果出色https://news.zol.com.cn/828/8288855.html
