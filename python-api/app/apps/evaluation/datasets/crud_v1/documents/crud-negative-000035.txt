2023-07-29 21:10，正文：原标题：李湘王岳伦同时晒女儿绘画作品，二人齐回北京，陪王诗龄共度暑假7月29日，李湘和王岳伦同时晒出了女儿王诗龄的近照及其绘画作品。两人的发文地址都是北京。李湘透露这是女儿暑假里刚画的，主题是桃子。王诗龄在家穿得相当休闲随性，绿色的睡衣看起来有种东南亚度假风的感觉，搭配的淡粉色裤子显得十分宽松，大概是吃了脸大的亏，所以王诗龄看起来并不算很瘦，而且脖子显得也比较粗，不过还是比小时候匀称很多的。绘画作品很大，王诗龄是用手里的刷子刷出来的，真是多才多艺。王诗龄对镜抿嘴微笑，看起来颇具亲和力。这幅画乍一看还以为是花，直到看到李湘的文案，透露主题是《桃子》，才越看越像。背景的渐变色被王诗龄处理得很自然很漂亮。想必此刻的王诗龄是在北京豪宅。李湘在7月24日的时候，刚晒出过北京的家，透露自己回北京了。李湘在与王岳伦离婚后，就带着女儿去了上海生活，估计平日里很少回到北京。王岳伦在7月27日发文否认新恋情，透露金发女子只是一大帮朋友中的一个，当时发文也是北京。当时父女俩在钢琴前抱在一起，十分亲密。可见夫妻俩都在北京陪孩子。在女儿面前，王岳伦和李湘可以放下任何恩怨。王诗龄在绘画方面极具天赋，当然后天的栽培也很重要。据悉，王岳伦的父亲就是一名画家，而王诗龄从小就跟着爷爷每周画一幅画。每年爷爷也都会给王诗龄画一幅肖像，记录孙女的变化，画得十分逼真。不得不说爷爷是一个高手。王诗龄去年作品《花园》还在第一届《小莫泊桑杯》国际艺术联创巡展活动中获得了金奖，后来作品还被拿到了法国卢浮宫进行巡展。估计这个奖项为她申请世界名校加分不少。李湘时不时地就会分享女儿的绘画作品，有具象的，也有抽象的。王诗龄在英国留学期间，还拿到了设计奖学金，而且竞争相当激烈，有网友爆料称该奖学金的金额多达六七十万，不知可信度是否高，但荣誉是实打实的，说明王诗龄是优中选优。在王诗龄进入名校前，李湘多年来被吐槽富养女儿不合适，如今王诗龄各方面都非常优秀，还瘦身成功，网上几乎一片赞美声，自称要是有钱也会这么养孩子，舆论瞬间有了极大的转变。李湘说女儿的大学目标是牛津大学，到时候王诗龄如果真的能被录取的话，那么母女俩更要被夸上天了。期待那一天的到来。 返回搜狐，查看更多责任编辑：
