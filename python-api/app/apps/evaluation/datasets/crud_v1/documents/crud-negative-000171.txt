2023-08-15 15:11，正文：原标题：安阳市三名专家获批河南省政府特殊津贴安阳市三名专家获批河南省政府特殊津贴 日前，经河南省政府批准，安阳市三名专家获批河南省政府特殊津贴，分别为翔宇医疗高级经济师何永正、安阳工学院教授张勇和安阳市高级技工学校高级技师李利军。至此，安阳市享受河南省政府特殊津贴专家达到15人。据悉，河南省自2014年开始实行的政府特殊津贴制度，是河南省政府对于高层次专业技术人才、高技能人才和民营经济领军人才的一种奖励制度。由省人社厅组织，每2年选拔1次。每人一次性发给省政府特殊津贴1.8万元（免征个人所得税），并由省政府颁发“河南省政府特殊津贴证书”。为广泛动员各行业人才积极申报，安阳市人社局通过政策宣传平台推介了河南省政府特殊津贴人员的选拔频次、入选待遇、推荐条件、推荐程序等内容，并通过组织、人社、科技、工信等部门广泛发动。下一步，安阳市人社局将创新工作方式，结合全市人社系统“三包三联”活动，将政策送到各行各业人才身边。深入贯彻落实省市人才激励政策，加强人才培育，增加人才数量，提升人才质量，提高荐才水平，力争安阳市的享受河南省政府特殊津贴专家数量再创新高，为建设新时代区域中心强市提供坚强的人才保障。（来源：安阳市人民政府网站） 【投稿、区域合作请邮件 信息新报 3469887933#qq.com24小时内回复。】 返回搜狐，查看更多责任编辑：
