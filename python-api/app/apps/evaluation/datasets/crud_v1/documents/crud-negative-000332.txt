2023-08-18 21:42，正文：原标题：中外青年沉浸式寻访金陵：以“Z世代”视角打开南京城市名片中新网南京8月18日电(杨颜慈 韩怡宁)观文脉、游秦淮、学非遗、访古建……8月18日，参加“同行中国·走进南京可持续发展训练营”中外实践活动的中外青年结束近一周的参访活动，在南京“世界文学客厅”参加结营仪式。“同行中国·走进南京可持续发展训练营”中外实践活动举办。泱波 摄 本次活动由南京和平论坛组委会和清华大学联合举办，共有20多名来自美国、德国等国家和地区以及国内一流高校的跨学科优秀青年学生走进南京，在经济、社会、文化多个领域发展空间开展沉浸式调研实践。中外青年沉浸式寻访南京，开启金陵探索之旅。泱波摄 从南北朝到唐宋明清，从诗词歌赋到散文小说戏剧……以南京鸡笼山脚下的南京“世界文学客厅”为出发点，中外学生沿着山路走上一条长约2.1公里的文学小路，沿途园林亭台都设置了艺术化的文学小景、文学标识、休憩设施等，通过现代科技“勾勒”出南京1800余年源远流长的文脉。“在充满中国古典风情的小亭子里，我听到了来自遥远古代的诗歌《河中水之歌》。用手机扫一扫二维码，就可以拍一张有动漫效果和人文气息的留念照。”美国留学生沈慧琅展示手机里的照片，开心地说“中国的传统文化以这种方式来展现，让我们年轻人更有兴趣去体验和感受了。”探索研究城市文化形象及如何助力城市可持续发展，正是此次中外青年实践活动中的话题焦点。美国耶鲁大学的Sandy Kahaliah对于南京的佘村明清建筑群印象深刻。“它们比现代建筑还漂亮，而且承载了深厚的文化底蕴。这里最大程度地保留了传统建筑的特色，可以看出当地政府的保护力度。”来自美国斯坦福大学的李明对非遗技艺体验非常有兴趣。他说：“我很享受在这里做手工的过程。这些技艺是南京传统文化的代表，是手工艺者匠心的浓缩。”数据层面，山东男篮3人得分上双，陈培东爆砍30分，高诗岩23分，贾诚17分。吉林队2人得分上双，姜伟泽22分，姜宇星18分。8月19日晚上19:30，山东男篮将与吉林男篮移师滨州，再打一场热身赛。返回搜狐，查看更多责任编辑：
