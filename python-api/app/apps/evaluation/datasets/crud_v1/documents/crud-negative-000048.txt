2023-08-10 09:44，正文：乐居财经 王敏  8月10日，佛山市蓝箭电子股份有限公司登陆创业板，证券简称为“蓝箭电子”，证券代码为“301348”。发行价格18.08元/股，发行市盈率为55.29倍。截止9：30，N蓝箭电子(SZ:301348)涨203.37%，现报54.85元，成交额1.05亿元，总市值109.70亿元。蓝箭电子成立于2012年6月，是一家从事半导体封装测试业务，为半导体行业及下游领域提供分立器件和集成电路产品的国家级高新技术企业。招股书显示，2020年至2022年度，蓝箭电子实现营业收入分别约为5.71亿元、7.36亿元、7.52亿元；净利润分别约为1.84亿元、7727.06万元、7142.46万元。另外，蓝箭电子在招股书中表示，预计2023年1-6月实现营业收入3.78亿元至4亿元之间，同比增长2.16%至8.11%，预计收入规模整体保持稳定增长。预计扣除非经常性损益后归属于母公司所有者的净利润为3550万元至3700万元之间，较上年同期增长5.61%至10.07%之间，预计保持稳定增长。股权方面，王成名、陈湛伦、张顺三人合计直接持有公司44.32%的股份，上述三人为一致行动人，系公司的共同控股股东及实际控制人。王成名为蓝箭电子董事长，于1944年11月生，中国国籍，毕业于北京理工大学无线电工程技术专业，本科学历，高级工程师，享受国务院特殊津贴专家。据招股书披露，经过多年发展与积累，蓝箭电子客户已经遍布华南、华东、西北、西南等多个区域，产品广泛应用于家用电器、信息通信、电源、电声等诸多领域。公司服务的客户来自五大领域，包括拓尔微、华润微、晶丰明源等半导体行业客户；美的集团、格力电器等家用电器领域客户；三星电子、普联技术等信息通信领域客户；赛尔康、航嘉等电源领域客户；漫步者、奥迪诗等电声领域客户。
