8月9日，澎湃新闻（www.thepaper.cn）记者从上海市静安区获悉，近期，广场公园（静安段）改造基本完成，已于7月1日起向市民试开放，随着公园改造一起登场的，还有一座新建成的公共厕所。广场公园（静安段）公厕  “上海静安”微信公众号 图广场公园（静安段）即静安延安中路绿地公园，占地面积35300平方米。在广场公园的改造提升中，该公厕的新建旨在更好地满足市民们的如厕需求。公厕整体外观不同于传统公厕，在设计建设环节中将园林设计理念贯穿其中。公厕外观公厕的每一个厕间都安装了助力的扶手，同时还安装了除臭设备并保障通风。门外的洗手台不仅设置了便于幼儿使用的低洗手盆，还安装有适老化的助力扶手。到了秋冬季节，还有暖水宝为市民提供热水服务。在公厕中的第三卫生间内，不仅有成人座椅和宝宝座椅，还安装了供宝妈使用的婴儿板，各类适老适幼设施更是一应俱全。公厕内部的适老设施第三卫生间内的婴儿板邻近公厕的大沽路汇聚了众多餐饮店，夜间经济同样繁荣。为满足市民们的夜间如厕需求，广场公园公厕实行24小时开放。截至目前，静安已有21座公厕实行24小时开放，静安区也将进一步结合区域实际需求，进一步实现24小时开放公厕数量上的拓展。
