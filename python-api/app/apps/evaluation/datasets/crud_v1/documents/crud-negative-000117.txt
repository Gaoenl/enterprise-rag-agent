2023-07-27，正文：小女孩被困4楼窗外“远亲不如近邻”。近日，四川绵竹一位“好邻居”，就冒险救下一个被困4楼窗外的小女孩。7月24日18时许，四川绵竹市龙岭华府小区，一名5岁女孩被困4楼窗外，情况紧急。发现险情后，小区业主接力施救，保安和业主们拿来床单撑在楼下，随时准备接住孩子。看到这惊险一幕，有高空作业经历的邻居唐长江挺身而出，徒手爬楼营救女孩。就在他即将靠近小女孩时，孩子在求生欲望的驱使下，突然伸手准备抓住他。这一幕让楼下邻居看得直冒冷汗，“不要怕！你站好，抓稳栏杆，叔叔马上来抱你！”唐长江一边稳住小女孩，一边继续靠近她，最终成功将小女孩救下。唐长江勇救小女孩的视频在网上传开后，许多市民和网友纷纷为他的救人义举点赞。“这只是举手之劳，没什么大不了。”7月25日，53岁的唐长江在接受红星新闻记者采访时，讲述了救人一事。他说，自己只是做了一件很普通的事情……惊险一幕：小女孩被困4楼窗外他徒手爬楼救下孩子7月24日18时许，绵竹市龙岭华府小区发生惊险一幕：有业主发现，一名小女孩爬到4楼窗外，双手抓着护栏，天气炎热，孩子没有自我保护能力，随时都有坠楼危险。后来，有人把孩子被困照片发到业主群，顿时在群里炸开了锅。随即，小区保安、业主纷纷展开救援，有人拨打119，有人联系小孩家长。大家自发拉开床单棉被，准备在楼下接住孩子……
