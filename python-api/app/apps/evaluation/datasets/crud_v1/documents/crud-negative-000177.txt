2023-08-18 16:15:39，正文：第六个“中国医师节”来临之际，《健康脱口秀·第三季》向全国各级各类医疗卫生机构的健康科普达人发出邀请：一起登上这个闪亮的舞台，共同打造健康中国科普创新品牌！此次活动由中国医师协会健康传播工作委员会指导，上海市卫生健康委、上海市健康促进委员会办公室、上海教育电视台、上海市健康促进中心等机构联合主办，将在前两季成功热播“出圈”的基础上，以更丰富的内容、更好玩的方式、更新鲜的“血液”，让健康脱口秀持续“升级”，为全民提供源源不断的“健康多巴胺”！《健康脱口秀》是继《人间世》《急诊室故事》等具有全国影响力的现象级作品之后，上海健康传播又一次创新突破，也是提升城市软实力的一大举措。据统计，前两季的全网观摩人次超过22亿。尤其第二季面向长三角海选，并通过凤凰卫视辐射全球华人圈，实现更广的覆盖面、更大的传播度、更深的影响力。今年，万众瞩目的第三季正式启动，隆重推出全国邀请赛，向全国各级各类医疗卫生机构和相关健康行业的健康科普达人发出“英雄帖”，一起汇聚健康脱口秀这个星光熠熠的大舞台，以有趣、有质感、接地气的医学知识为佐料，以沉浸式“代入”百姓日常生活场景的科普视角，描摹健康生活百态，拓宽健康科普形式，实现丰富地域特色的健康文化同频共振。《健康脱口秀·第三季》全国邀请赛将于8月21日09：00开启线上的海选报名通道，9月22日24:00报名截止。报名参赛选手需在线上平台递交海选申报，同时提交一个3分钟的个人健康脱口秀科普短视频。9月下旬，经海选评选与主办方推荐，第三季的全国参赛总阵容将亮相线下。主办方将联合凤凰卫视、百视TV、喜马拉雅、阿基米德、医学界、健康云、优酷视频、腾讯视频、B站、小红书、澎湃新闻、抖音、快手、新浪健康、新浪微博、西瓜视频、今日头条等全国各大主流媒体与新媒体平台广泛宣传，不断推陈出新，持续文化引领，打造更富有冲击力、更加提升质感的健康科普新爆款，掀起全民关注健康科普新热潮。期待更多有志健康科普、品牌锻造的有为医者积极报名、接受挑战，让更多有趣、有爱、有价值的健康知识成功飞进平常百姓家，同时也希望更多人关注、支持、喜爱健康脱口秀，在笑声中走出“健康误区”，在欢乐中掌握“健康密码”，共同拥抱高品质健康生活，助力健康中国建设。
