2023-08-07 08:09，正文：原标题：兰州市2023年第二季度诚信“红黑榜”发布8月6日，记者从市文明办获悉，为加快推进“诚信兰州”建设，按照中央、省、市文明委有关推进诚信建设制度化的工作安排和创建全国文明城市工作总体要求，兰州市精神文明建设指导委员会办公室、兰州市社会信用体系建设领导小组办公室会同兰州市中级人民法院、国家税务总局兰州市税务局、兰州市农业农村局等单位联合发布兰州市2023年第二季度诚信“红黑榜”。市中院对于此次发布的64家失信被执行人（法人、自然人），根据最高人民法院《关于限制被执行人高消费及有关消费的若干规定》，对纳入失信被执行人名单的被执行人，将对其采取限制消费措施。被执行人违反限制高消费令进行消费属于拒不履行人民法院已经发生法律效力的判决、裁定的行为，经查证属实的，依照《中华人民共和国民事诉讼法》第一百一十一条的规定，予以拘留、罚款；情节严重，构成犯罪的，追究其刑事责任。在此次的“红黑榜”中，国家税务总局兰州市税务局发布了10户纳税“黑榜”企业。其中有7户企业因虚开增值税发票、3户企业因骗取出口退税将面临相应的惩罚。推进诚信建设制度化，是中央文明委安排部署的一项重点工作，也是创建全国文明城市的重要内容。发布诚信“红黑榜”是推动诚信建设制度化的重要措施。下一步，市文明办将继续联合相关部门大力推进诚信建设制度化，切实提高全社会对诚信建设的关注度。兰州日报社全媒体记者 李晓霞编辑丨孙悦返回搜狐，查看更多责任编辑：
