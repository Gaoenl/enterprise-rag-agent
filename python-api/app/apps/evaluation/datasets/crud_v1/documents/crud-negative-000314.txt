5月29日-6月1日,国家发展改革委综合司副司长张焕腾一行及上海等5省市发展改革委有关同志来陕调研构建新发展格局有关情况,省发改委副主任刘迎军参加调研座谈会,西安市、榆林市政府有关领导陪同调研。 5月30日上午,调研组在我委主持召开加快构建新发展格局座谈会,刘迎军代表省发改委介绍了我省构建新发展格局、我省经济运行有关情况,同时结合我省实际,提出了未来一段时期加快构建新发展格局的意见建议,上海、江苏、广东、湖北、四川省发展改革委有关同志介绍了本省(市)构建新发展格局实践成效等有关情况。下午,调研组及参加座谈会的同志,一同赴西安法士特高智新科技有限公司等企业开展实地调研,了解装备制造、3D打印等行业发展情况。 随后,调研组一行赴榆林市开展实地调研,深入国能榆林化工公司、陕煤榆林化学公司等企业调研煤化工产业发展情况,并召开座谈会,听取了榆林市关于构建新发展格局和当前经济形势情况,以及陕西未来能源化工有限公司等6家能源相关企业的生产经营情况及发展诉求。最后,调研组表示,加快构建新发展格局,是党的二十大提出的一项战略任务,针对此次调研中了解掌握的新情况新进展和相关意见建议,将进一步会同有关方面深入研究,努力把意见建议转化为构建新发展格局的具体举措。省发改委综合处负责同志参加调研。
