2023-08-15 16:53，正文：原标题：助力建筑工人安全生产 渝北区开展工伤预防培训8月15日，渝北区总工会联合渝北区人社局、渝北区住建委、渝北职工帮扶基金会、中建八局西南公司重庆分公司等单位在鲁能城三期项目共同开展了“抚伤济困·益路守护”工伤探视暖心行动2023年启动仪式暨渝北区一线建筑工人工伤预防培训会。本次活动旨在加强维权工作，预防和减少工伤和职业伤害问题，近百名建筑工人参与了本次活动。活动现场。主办方供图启动仪式上，渝北区总工会的相关负责人总结了过去一年的成绩，并为下一步的工伤职工帮扶工作指明了方向。与会人员共同推动启动仪式，为“抚伤济困·益路守护”工伤探视暖心行动开启新的篇章。在仪式上，建筑工人代表获赠了防暑安全包。接着，重庆科技学院教授伍培为全体一线建筑工人开展了工伤预防培训。培训内容结合理论和案例，旨在全面提升建筑工人的安全生产意识和能力，预防减少工伤事故的发生。活动现场。主办方供图据悉，“抚伤济困·益路守护”工伤探视暖心行动是渝北区总工会联合渝北职工帮扶基金会开展的面向渝北工伤职工的渝工安康专项项目，项目实施一年来，累计为近300名工伤职工送去了工伤慰问、心理疏导等服务。现场相关负责人表示，作为职工的“娘家人”，工会将进一步做实做细工伤探视工作，积极创新工作方法，精准化服务职工，擦亮工伤探视品牌，让广大受伤职工充分感受到党委政府和工会的关怀，同时进一步加大对工伤职工的后续帮扶力度，提升企业和职工安全生产意识，督促企业改善生产条件，积极维护职工合法权益。(马春鹏)返回搜狐，查看更多责任编辑：
