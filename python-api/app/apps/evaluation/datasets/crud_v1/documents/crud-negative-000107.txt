2023-08-04 14:08，正文：原标题：引众怒！“我只能躺，不能坐……”老太声称腿不好乘坐火车一人霸三座本文转自【上海新闻广播】；7月31日，辽宁一火车上，一位老太太霸占了三个座位，任凭列车员如何劝说也不肯起身，此事引发网友热议。网传视频中，这位老太太横躺在三个并排座位上，列车员过来劝阻时，她称自己腿不好，只能躺着，要去北京挂号治病，“我只能躺，不能坐，一坐就废了。”老太太对列车员说。列车员表示她占座影响其他乘客，按规定要让乘警把她带到下一站。紧接着又请老太太出示身份证，表示自己可以想办法帮她调整一下，老太太既不愿起身也不愿出示身份证，只是表示自己心脏不好。对此，广大网友纷纷表示不解。“如果真的要躺着，可以买三个位置的票，怎么能侵害他人权益”还有网友认为，这种行为应该被惩治。“对号入座”是乘坐高铁等交通工具的基本规则，既保障了购票乘客的应有权益，也有利于维护交通出行秩序。“不认字”“行李多”“年纪大”……这些都不能成为霸座的理由。根据《民法典》规定，霸座是违法行为，乘运员有权更有责任对霸座者追究法律责任，杜绝此类现象再次发生。法律界人士建议，旅途中若遇到霸座，可以向车厢工作人员求助，并拍视频取证交由警方处理。上海新闻广播综合返回搜狐，查看更多责任编辑：
