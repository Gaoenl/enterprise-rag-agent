【来源：武汉广播电视台】2022年7月15日，经过15个月的孕育和7个小时的分娩，武汉野生动物王国自主繁育的第一只“汉籍”长颈鹿“十一”顺利出生。刚出生时，“十一”就有1.8米，体重约50多公斤。8月15日，“十一”首次外出和游客朋友见面。经过了整整一年的成长，“十一”现在身高接近3米，体重有342公斤，为我们带来更多的欢乐和惊喜。【长颈鹿“十一”的成长大事记】2022年7月15日“十一”在今天出生啦，长颈鹿妈妈经过7个小时的分娩，“十一”才顺利出生。又经过了两个多小时的不断尝试，在晚上7点30分的时候，它才完成了首次独立站立。一生出来个子高大，一米八高，50多公斤。8月15日“十一”在妈妈的带领下第一次来到室外运动场活动，整个过程“十一”没有任何的恐惧和抗拒，反而对外面的世界非常的好奇。在铺满阳光的草坪上，长颈鹿妈妈带着“十一”奔跑玩耍，由于外面太过新奇好玩，到了回家时间我们的宝宝任性地表示拒绝！9月28日“十一”和爸爸的第一次见面，爸爸不断用头轻轻与它互动，并且舔舐它的小脑袋。“十一”对于整个过程也表示十分享受，被家人宠爱的感觉真好。10月1日和大家一起过“百日宴”，在族群的家人陪伴下，“十一”终于有勇气迈出第一步，学着去和游客互动。12月5日6个月的“十一”已经适应了大家族中的生活，在大家庭里，每一位成员都在尽职尽责地育儿。“十一”已经半断奶，可以和家人们一起吃苜蓿草料。2023年2月10日武汉野生动物王国繁育的第二只“武汉籍”长颈鹿宝宝顺利诞生。“十一”第一次当上了哥哥，两个“表兄弟”嬉戏打闹好不快活。7月15日“十一”已经一岁了，身高接近3米，体重有342公斤，在这个充满爱的家族里茁壮成长。希望这只小长颈鹿的故事给你更多的爱和治愈~   声明：此文版权归原作者所有，若有来源错误或者侵犯您的合法权益，您可通过邮箱与我们取得联系，我们将及时进行处理。邮箱地址：jpbl@jp.jiupainews.com举报/反馈
