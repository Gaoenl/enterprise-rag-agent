"中新社香港七月二十六日电(记者　文青)香港第十七届“美食博览”，将于八月十七至二十一日于香港会展中心举行。今届共有三百二十五家食品制造商及供应商参展，比去年上升百分之八。除了香港的参展商外，还有来自澳大利亚、加拿大、中国内地、德国、印度、印尼、意大利、美国及越南的参展商为市民带来环球美食。主办单位香港贸发局表示，除了让市民品尝和购买各国美食之外，大会亦同时推广注重健康的观念，于“美食博览”期间，将首次举办“香港国际医疗及保健服务展”和第五届“国际现代化中医药及健康产品展览会暨会议”。展览会去年吸引超过三十万人入场参观。为了吸引旅客入场参观，当局推出了访港人士优惠，持有效旅游证件的访港人士可享有半价门票优惠，并可以用特别通道进场，省却轮候时间。(完)",
