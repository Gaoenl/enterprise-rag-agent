2023-08-19 07:03，正文：原标题：运营盗版游戏非法牟利六十余万元被判刑本报综合 随着网络游戏市场规模的不断扩大，因经营私服游戏发生的犯罪行为不断涌现。日前，岳阳市岳阳楼区人民法院审结了一起侵犯著作权案。经审理查明，杭州某网络公司于2013年依法取得《梦幻西游2》游戏软件V3.0.0的著作权。2020年6月，刘某某从某网民处购买《梦幻西游2》“私服游戏”（即未经著作权人授权，私自架设服务器安装的游戏）客户端安装程序，并租用服务器，由该网民通过电脑远程操作架设，命名《逍遥西游》。后刘某某付费对外发布该盗版游戏的广告，并将其上传至新建QQ群文件，供玩家下载。刘某某通过支付宝账户直接收取和第三方资金结算平台中转后转账至其支付宝账户两种方式收取玩家充值费用，非法获利67.5万元。经司法鉴定，《逍遥西游》游戏与网络公司的《梦幻西游2》游戏具有实质同一性。另查明，刘某某在经营私服游戏期间，利用第四方支付平台，以充值抽奖为由在个人支付宝账户接受玩家充值，以及向玩家出售游戏装备的方式牟利。2021年4月，岳阳市公安局经济技术开发区分局扣押其作案工具台式电脑1台。同年7月，刘某某主动投案。案发后，刘某某向公安机关退缴违法所得50万元，案件审理过程中，向法院退缴违法所得17.5万元。法院审理认为，刘某某以营利为目的，未经著作权人许可复制发行计算机软件，违法所得数额巨大，其行为构成侵犯著作权罪。遂依法判处被告人刘某某有期徒刑二年六个月，缓刑四年，并处罚金人民币68万元。打击山寨盗版游戏维护知识产权法官提醒打击山寨盗版游戏，不仅是对网络游戏的全方位保护，更是对知识产权的有力维护，推动游戏产业健康发展。当知识产权受到侵犯时，可及时搜集证据向知识产权主管部门举报、报警或提起诉讼。同时，作为普通消费者，切莫贪图价格便宜购买盗版商品，给不法分子非法牟利的空间，以实际行动共同维护行业健康有序发展。返回搜狐，查看更多责任编辑：
