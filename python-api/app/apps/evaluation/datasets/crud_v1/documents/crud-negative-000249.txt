2023-08-18 10:29，正文：原标题：中山建行：以实际行动严守人民群众的“钱袋子”当前，电信诈骗案件仍然存在多发、高发态势，为保障客户资金安全，建设银行中山市分行坚持主动作为，组织系统赋能、服务优化等措施，全力保障客户资金安全。制定专项工作方案，完善反诈工作流程，不断提高员工和客户的安全防范意识，主动沟通配合公安机关打击诈骗犯罪。从源头堵住犯罪账户资金流动，切实守住老百姓的钱袋子。近日下午临近关门时，一名中年妇女走进了建设银行中山市分行，手里提着一个深蓝色花提包。经客户经理询问后得知该客户需要开卡。最近一年冒名开户频发，珠三角又是网络诈骗的重灾区，因此开户必须谨慎对待。该客户表示自己开店日常经营需要开卡，并拿出自己袋子里的营业执照。在工作人员查看后，该营业执照是2019年注册的，并且查询了企查查并无发现高风险事项。紧接着又查询了红绿灯和手机号码入网时间及实名情况后，指引客户在智慧柜员机开卡。开卡后大堂经理在协助客户激活手机银行的过程中发现客户手机下载了“建行惠懂你”APP，该软件是企业贷款用的，一般客户很少会下载。因此，大堂经理怀疑客户可能通过金融中介进行贷款。在简答询问中，客户神色慌张，并表示是以前找中介下载的。可是该软件在排版最后一个，明显是最近下载的，因此判断该客户在掩饰什么。紧接着与客户交谈发现该客户是经营早餐生意，并向她建议开一个建行收款二维码，尽管是全免费用，客户都坚决反对，显得异常紧张。但是由于没有什么实质性的证据，还是没有进一步上报，仅仅是做了限额处理。但是，第二天下午2点，该客户又来银行要求开立对公账户。结合昨天交谈的内容，该客户是开早餐店的，并无开立公账的需求。大堂经理察觉到不对劲，借着审核的借口与客户交谈，得知客户并不了解对公账户的主要用途，并且承认了是别人让她来开户的，主要是想贷款经营周转。此时，建设银行中山市分行工作人员向客户讲解了外部金融人员的借贷风险，并了解客户情况添加微信，方便客户咨询银行业务。中山建行将坚持不懈普及金融知识宣传，推动落实好金融消费者权益保护工作，携手大家共同构建和谐稳定、绿色的金融消费环境，营造浓厚的绿色金融氛围，保护好人民群众的钱袋子，打好这场‘防范打击电信网络诈骗犯罪’的长期战役”。返回搜狐，查看更多责任编辑：
