2023-08-16 22:21，正文：原标题：百家商铺 千人光顾 青岛这个市集成就全龄友好社区中国山东网-感知山东8月16日讯 8月15日，青岛市市南区湛山社区举办首届“湛山网市欢乐夜未央”公益嘉年华活动，超过百家社区商铺参与活动，1200余人次居民纷纷走出家门熟络起来，从“陌邻”转变成“睦邻”。“欢迎大家到湛山社区下沉广场，一起欢乐夜未央”。拥有1280余万名粉丝的微博网红“黑猫的黑”现场发动粉丝参与到此次市集活动中。据悉，此次活动得到了市南区新联会和网联会的大力支持，众多网络大咖亲临现场，宣传推介活动，线上支持商铺吸引人流。据统计，各商铺首日营业额总计突破5万元，社区通过与市南区新阶层群体的携手，共同为辖区消费活力提升、坚定商铺信心贡献力量。活动现场，来自湛音琴行·湛音艺术学校、社区舞蹈社的6支文化队伍表演了精彩的文艺节目，社区乐队根据居民投票喜好，带来了《平凡之路》《夜空中最亮的星》等20首脍炙人口的歌曲。活动现场还陆续开展了群众强烈期盼的喝啤酒大赛、吃饺子大赛、吃西瓜大赛，活动现场一次又一次的推向高潮。为充分彰显湛山人的乐善好施品格，社区现场组织了辖区企业商铺为对口帮扶的甘肃省陇南市沙湾镇开展捐款捐物活动，汇聚爱心，传递温情，现场收到爱心企业捐赠的价值1万元物资。下一步，湛山社区将以此次市集作为新开端，不断密切群众联系，扩大共治朋友圈，持续做优“细服务”，让社区有温度，让企业促发展，让群众得实惠，为构建全龄友好型社区，提升群众满意度久久为功，绵绵用力。中国山东网记者 刘淑红 通讯员 张晓 报道返回搜狐，查看更多责任编辑：
