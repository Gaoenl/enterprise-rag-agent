为进一步净化网络空间，增强网络文明意识，倡导网络文明新风，不断提高群众网络文明素养，12月14日，双桥区委网信办组织网络文明志愿者走进山庄社区党群服务中心开展“共享网络文明 共建清朗空间“网络文明宣传活动活动中，网络文明志愿者们通过现场宣讲、发放宣传单等方式向社区干部细致讲解文明上网规范和网络安全的重要性。向办事群众普及网络文明和网络安全基本知识以及相关法律法规，提醒群众谨防个人信息泄露和防范电信网络诈骗，增强网络安全防范意识，引导居民群众依法上网、文明上网、理性上网。号召广大职工和群众坚决抵制网络谣言、积极监督各种网上违法违规行为，共同维护健康有序的网络传播秩序。通过此次宣传活动，进一步传递了网络文明风尚，宣传了网络安全知识，普及了文明上网意识。下一步，双桥区委网信办将进一步加大网络文明宣传力度，持续开展网络辟谣、不良信息网络举报等专项宣传活动，为营造健康向上、清朗文明的网络空间贡献力量。原标题：《【“双争”在行动】共享网络文明 共建网络空间——双桥区委网信办开展网络文明宣传活动》阅读原文
