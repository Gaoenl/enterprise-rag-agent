7月25日上午，以“共建数字强省 共享智慧山东”为主题的“2023山东数字强省宣传月”活动在济南正式启动。启动仪式现场，进行了《2023山东数字强省宣传月方案》、“鲁通码”“爱山东移动端4.0”“实景三维山东”等平台上线和数字强省建设优秀成果等一系列重要发布，通报表扬了一批典型应用场景，举行了《山东省机关工作人员大数据基础知识读本》首发式及赠书仪式。今天20时，山东16市还将联合开展“点亮数字山东”主题灯光秀活动，并同步进行线上直播。本届宣传月活动自7月25日开始，持续到8月下旬，分为展“数”向未来、送“数”进万家、论“数”集众智、创“数”惠民生四个板块。围绕展“数”向未来，将开展大数据主题展览、“2023黄河流域生态保护和高质量发展”省级党报全媒体行、“数字强省融媒体之旅”融媒体记者行暨融媒体夏令营、“数字强省绘蓝图”系列政策发布宣贯、“爱山东”系列宣传等活动。围绕送“数”进万家，将组织送“数”四进活动、送“数”四行活动、开展公务员数字化素养提升专题研修班、开展大数据科普知识竞赛等系列活动。围绕论“数”集众智，将组织《数字会客厅》云端连麦、“数字强省 智慧有我”征文比赛和“情系桑梓‘数’向未来”大学生暑期实践、“话数山东”等相关活动。围绕创“数”惠民生，开展“绿意赛道——数字应用慧治创新”系列竞赛活动。具体活动安排将在“爱山东”政务服务平台、山东省大数据局微信公众号及各大媒体平台同步公布。据悉，此次宣传月活动将坚持线上线下相结合，通过举办一系列通俗易懂、喜闻乐见的宣传科普活动，让人民群众更好地认识大数据、懂得大数据、运用大数据。同时，更加注重共建共享，深入基层一线，走到群众身边，倾听群众心声，回应群众关切，进一步增强社会各界对数字强省建设的参与度和获得感，全面提升整体建设成效。（大众日报客户端记者 王鹤颖 王世翔 任戌盈 报道）举报/反馈
