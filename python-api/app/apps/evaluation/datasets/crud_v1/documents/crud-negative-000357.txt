12月13日,有网民发布视频消息称,辽宁大连沙河口区星海广场附近,疑似有人从酒店高层裸身坠楼,砸中轿车。该事件引发关注。13日晚,大连市公安局星海湾分局就此事发布警情通报,称死者符合高坠死亡特征,已排除刑事案件。通报内容如下↓↓2023年12月13日8时52分许,市公安局110指挥中心接到报警称,在沙河口区中山路某酒店有一男子坠楼,落到该酒店楼下停放的一车辆顶部。接警后,属地警力立即临场处置,经120医护人员现场确认,该男子已当场死亡,现场未造成其他人员伤亡。经公安机关现场勘验、调取监控、走访调查,初步查明,死者万某(男,46岁)于当日独自入住该酒店后,用房间内一茶几将房间窗户砸碎,后坠楼身亡。死者符合高坠死亡特征,已排除刑事案件。目前,事件原因调查和善后处置工作正在进行中。此前,网传视频显示,停靠在该酒店前方的一辆小车上,有一人卧在车顶。车顶已有明显塌陷,酒店高层有一扇窗户破裂。13日上午,事发点附近的大厦工作人员告诉记者,“现在现场处理结束了,公安已经走了。”当日下午2时许,涉事酒店工作人员在接受记者采访时表示目前酒店正常营业。涉事房间窗户破损。图源:网络大连市公安指挥中心工作人员告诉记者,此事目前已经在处理,以后续官方通报为准。据初步掌握,坠楼者为男性,已无生命体征。综合:星海湾分局、潇湘晨报、大皖新闻catalogs:115814;contentid:12136868;publishdate:2023-12-14;author:季爽;file:1702531954671-67b17f69-371b-4fa8-ac97-e44e977eb6a8;source:29;from:新晚报;timestamp:2023-12-1413:32:32;[责任编辑: ]
