2023-08-02，正文：暑期“博物馆热”持续升温，为更好地满足公众参观需求，自8月1日起，包括苏州博物馆在内的苏州9家博物馆将服务时间延长至21时，并以线上线下同步的方式，推出各类展览、讲座及体验活动共40余场。记者从苏州市文化广电和旅游局获悉，本次延时服务的博物馆包括苏州博物馆、中国苏州评弹博物馆、苏州碑刻博物馆、苏州丝绸博物馆、张家港博物馆、常熟博物馆、太仓博物馆、吴江苏州湾博物馆、吴文化博物馆。为丰富夜间文旅产品供给，满足市民、游客夜游博物馆需求，苏州在夜间延时开放的基础上，还推出各类展览、讲座，开辟各馆与周边文旅资源联动的“博物知旅”线路，其中包括“青州龙兴寺佛教造像展”“马家塬遗址出土文物展”“芥子须弥——云冈特展”等展览10余场，以及3D马车打印体验活动、“碑刻传拓”研学游、“非遗体验季”等讲座与体验活动20余场。据悉，江苏现有备案博物馆349家，其中国家一、二、三级博物馆70家。暑假期间，除苏州延长博物馆开放时间外，无锡博物院、常州博物馆、宿迁市博物馆等多个博物馆定期在夜间延长开放时间，为市民、游客的夜间休闲、出游、参观提供更多选择。声明：本网站所提供的信息仅供参考之用,并不代表本网赞同其观点，也不代表本网对其真实性负责。您若对该稿件内容有任何疑问或质疑，请尽快与上海热线联系，本网将迅速给您回应并做相关处理。联系方式:shzixun@online.sh.cn
