2023-07-31 16:10:38，正文：东方网记者曹磊7月31日报道:2023·中国盐湖城昆仑文化旅游节7月30日晚在市体育场圆满落幕。青海省委宣传部一级巡视员刘伟，格尔木市委副书记、市长冉清，格尔木市委副书记孔庆吉，格尔木市委常委、宣传部部长吴龙出席闭幕式。据悉，2023·中国盐湖城昆仑文化旅游节期间举办的“昆仑球王”三人篮球挑战赛圆满落幕，近30支队伍、100余名篮球爱好者经历了一场现实版的“灌篮高手”追梦之旅，最终由民康村代表队获得总冠军，摘下“昆仑球王”桂冠。同时，首届“昆仑之星”全民器乐才艺大赛中，格尔木爱韵艺术学校的选送作品《战台风》、克莱德曼音乐艺术学校的选送作品《运动员进行曲》获得一等奖。此外，“多彩昆仑·瑶池盛宴”2023年首届“瑶池杯”昆仑美食节在昆仑天街如期举办，并最终评选出团体奖优胜奖4家、金奖6家、特金奖3家、鼎级金奖1家（格尔木允升和湘粤海鲜楼）。祁生鹏获得厨王争霸赛个人奖冠军。格尔木市人民政府副市长张效勇说，此次盛会，文艺、诗歌、美食相互交映，文化、经济、人文精彩纷呈，故交、新朋、挚友再续友谊，开放、包容、大气的格尔木再展新颜，各界人士共享了一场昆仑文化的饕餮盛宴，取得了圆满成功。张效勇表示，本次昆仑文化旅游节是继三年疫情后的又一次重启，充分展示了格尔木这座高原新城的文化魅力、生态定力、旅游引力，展现了高原人民的淳朴与热情，收获满满、精彩纷呈。一位位文坛大家、诗坛大咖、专家学者齐聚高原，以昆仑文化为桥，以诗为名，以文会友，通古今畅未来，向世界展示了昆仑文化的魅力，传递了格尔木声音。“瑶池杯”美食盛宴，开启了一段美食与文旅融合的美妙旅程，点亮了城市“夜经济”。“昆仑文化旅游节已然成为格尔木重要的文化符号，记载着城市发展的脉络与痕迹，丰富了群众精神文化生活，为更好推进经济社会发展积聚了人气、凝聚了心气、提振了士气。”
