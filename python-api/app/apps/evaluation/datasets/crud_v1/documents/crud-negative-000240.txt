，正文：2D卡通横版Rogue-Lite游戏《失落城堡2》已在Steam上线，并即将推出抢先体验版本，支持简体中文和多人联机，发售时间尚未确定。  据官方描述，抢先体验版本将包括5个主路线关卡和完整的流程体验，11个随机关底Boss，约100种被分为5个大类的随机武器，约100种不同造型的装备，以及约50种带随机效果的宝藏。  官方还计划在完整版本中增加4个额外的分支路线关卡和1个隐藏关卡，补充一个完整的故事，设计两个新的武器分类及基于这个新分类约50种新武器，增加约10-20套不同外观的装备，以及增加约10-20种带随机效果的宝藏。  《失落城堡2》是一款动作冒险游戏，拥有超过200种不同的武器和防具，带来变化多样的动作机制，丰富独特的武器技能。游戏中有超过50种效果各不相同的宝藏，收集的宝藏越多，自身就会越强大，让每局游戏都充满变化和新鲜刺激。同时，游戏中有多样的关卡场景和超过10种各具特色的强大BOSS等待玩家挑战。  游戏的背景设定在一座位于边境群山深处的神秘城堡——黑城堡。据宝藏猎人报告，该城堡被各种异常独特的环境围绕，附近的生物出现奇怪的变异现象，甚至发现了神秘的虚灵和魂晶。新的冒险正在召唤着宝藏猎人们，加入宝藏猎人公会，前往神秘的黑城堡开始新的寻宝之旅。  值得一提的是，前作《失落城堡》的评价为“特别好评”，在17136条评测中有88%为好评，支持在线及本地最多四人同玩，4人联机进行合作及对抗模式。本文属于原创文章，如若转载，请注明来源：游戏介绍：失落城堡2抢先体验版将出 支持多人联机https://news.zol.com.cn/828/8286256.html
