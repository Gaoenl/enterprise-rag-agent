2023-08-01 10:27，正文：湖北日报全媒记者 王成龙 通讯员 张晓亮近日，省税务局货物和劳务税处党支部开展“强党性·铸忠诚·促担当”支部主题党日活动。党支部书记宋长军以《扛稳“第一责任”，答好“第一考题”，奋进新时代湖北货物劳务税现代化新征程》为题讲党课。曾在全省税务系统专项工作中获得嘉奖的支部青年党员张忍，分享了自己将党建要求融入业务实际、实现党建与业务互融互促的经验和感悟。在省税务局货物和劳务税处党支部，支部书记讲党课、先进典型做分享、全体党员谈收获，是每次支部主题党日活动的“必选动作”，目的是营造比学赶超的浓厚氛围，锻造高素质的党员队伍。该党支部坚持“学在深处、落到实处”，扎实开展“周讲、月考、季赛、年评”等系列活动，大力发挥教育、引导、熏陶作用，充分激活“三种效应”——激活“头雁效应”。宋长军充分发挥“头雁”作用，在管党治党、钻研业务、攻坚克难等方面当先锋、作表率，荣获“荆楚楷模·最美税务人”等荣誉称号。在他的影响下，支部培育形成创先争优的“雁阵”。激活“争先效应”。在榜样力量的影响和感染下，支部全体党员对标先进勇于担当。在去年增值税大规模留抵退税工作中，支部全体党员攻坚奋战7个月圆满完成任务，留抵退税“精简达”创新项目作为省优化营商环境先行区典型经验复制推广，支部组织委员王良风被国家税务总局减税办授予“退税减税二等功”。激活“星火效应”。青年党员是建强党支部的潜力所在。省税务局货物和劳务税处党支部点燃青年党员比拼赶超的星星之火，青年党员王弘毅成长为全省增值税管理工作的“排头兵”，在年度考核中多次被评为优秀等次。青年党员王超多次参加税务总局专项工作，在落实组合式税费政策的过程中取得显著成绩，被省税务局授予“退税减税三等功”，并获得该局“青年理论学习标兵”等荣誉。
