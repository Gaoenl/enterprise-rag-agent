2023-08-04 20:50，正文：原标题：突袭！乌克兰无人艇载450公斤炸药进入俄黑海海军基地据俄罗斯塔斯社报道，当地时间4日凌晨，乌克兰方面利用2艘无人舰艇企图袭击俄黑海沿岸城市新罗西斯克的一处海军基地，来袭无人舰艇均被摧毁。俄国防部发言人科纳申科夫4日通报说，当天凌晨，乌方试图用两艘无人艇袭击新罗西斯克海军基地，但无人艇被俄军发现并遭摧毁。俄克拉斯诺达尔边疆区州长康德拉季耶夫在社交媒体上说，乌方无人艇对新罗西斯克海军基地的袭击没有造成人员伤亡和财产损失。路透社报道称，新罗西斯克港是俄罗斯在黑海的主要港口。报道同时引述乌克兰情报消息人士称，乌安全部门和乌海军对俄罗斯新罗西斯克港发动海上无人艇袭击，造成俄罗斯“奥列涅戈尔斯克矿工”号大型登陆舰严重损坏，已无法执行战斗任务。俄罗斯“奥列涅戈尔斯基·戈尔尼亚克”号大型登陆舰（资料图）美国有线电视新闻网（CNN）报道称，尽管俄罗斯国防部早些时候声称无人艇已被击退，但社交媒体上的视频和图片显示，受损的俄军舰出现严重倾斜，随后被运到新罗西斯克海军基地附近。美国有线电视新闻网援引乌克兰消息人士指，一架携带450公斤炸药的无人艇袭击了俄军舰，并声称船上约有100名俄罗斯军人。图源：美国有线电视新闻网俄罗斯当地负责运营石油管道的里海管道集团公司则表示，该公司因此次袭击临时禁止船舶在新罗西斯克港口航行，但袭击并未造成该公司基础设施受损，向油轮输送石油的作业也正常进行。此外，塔斯社还引述俄罗斯国防部的说法指出，俄军防空部队4日上午在克里米亚半岛上空击落10架乌克兰无人机，并利用电子反制手段压制另外3架无人机。另据俄媒4日报道，俄国防部长绍伊古视察了前线指挥部，听取指挥官汇报并对官兵在红利曼地区成功实施作战行动表示感谢。来源丨综合（来源：直新闻）返回搜狐，查看更多责任编辑：
