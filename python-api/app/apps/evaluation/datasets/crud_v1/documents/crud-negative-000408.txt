中国青年报客户端讯（中青报·中青网记者 张渺）7月18日，北京市朝阳区青年联合会第七届委员会第一次全体会议召开。大会听取北京市朝阳区青年联合会第六届委员会常务委员会所作的《踔厉奋发 守正创新 在中国式现代化的朝阳实践中汇聚青春力量》工作报告，审议通过《关于北京市朝阳区青年联合会六届委员会工作报告的决议》《关于北京市朝阳区青年联合会委员管理细则（修正案）的决议》，选举产生北京市朝阳区青年联合会第七届委员会主席、副主席、常务委员会委员。会议现场。主办方供图今年是朝阳区建区65周年，围绕进一步做好全区青年工作，朝阳区委书记文献强调，要在高质量发展中主动作为，聚焦朝阳科技创新和人才强区战略，着力打造青年人才“生态圈”，充分发挥各界别青联委员的带动作用，让更多青年在数字经济、人工智能、新材料、金融服务等重点领域脱颖而出、施展才华。在服务社会中主动作为，针对基层社会治理的重点难点问题，深入开展调查研究，推动“美好朝阳”“分小萌”等青年品牌提质升级，努力形成高质量的研究成果。当天下午，北京市朝阳区青年联合会第七届委员会第一次全体会议圆满完成各项议程。闭幕式后，北京市朝阳区青年联合会第七届委员会召开第一次常委会，审议通过了区青联七届委员会秘书长名单以及各界别主任委员、副主任委员、秘书长名单。来源：中国青年报客户端举报/反馈
