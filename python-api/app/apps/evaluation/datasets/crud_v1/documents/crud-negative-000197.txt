2023-08-02，正文：一小伙离奇失踪半月曾发信息：爸，我今天被仙人选中了！近日，云南昆明。王先生在网上发布信息寻找20岁儿子，一小伙离奇失踪半月引发网友关注。7月17日凌晨2时许，20岁的王蔚通过微信给爸爸王宗洪发送了一条诡异信息：“爸，我今天被仙人选中了，我要去一个凡人都去不了的世界，仙人说给我30年时间，我可以回来，如果30年后，我没有回来，那就证明我死在仙人的世界了，再见了，勿寻勿念！”这条信息让家人感到不安，又感到不解，而自此王蔚也离奇失踪。为了找到儿子，王宗洪带着几十名亲朋好友从昭通威信老家来到昆明，四处寻找，然而半个月过去，仍没有一丝一毫的线索。救援队伍仔细搜寻了小树林周边的水域，还动用声纳等设备进行了水下探测，小树林并不大，但经过近十天的搜寻，并未找到失联者。一小伙离奇失踪半月！除了搜寻以外，工作人员和王先生还了解了王蔚日常工作和生活的环境，根据酒店的其余工作人员表示，王蔚失联之前并没有表现出任何异常，同事之间也没有什么矛盾，一切都挺正常的。20岁小伙子在滇池附近离奇失踪7月31日上午，记者见到了小伙子的姑姑王宗凤，她介绍，侄子王蔚家住云南昭通威信县麟凤镇柏香村，半年前侄子来到昆明，在五华区的一家酒店做前台收银工作。
