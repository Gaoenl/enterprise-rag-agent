2023-08-18 20:01，正文：原标题：俄媒：两架俄军伊尔-38反潜机从日本海飞向东海，日本战机紧急起飞【环球网报道 见习记者 黄泽佳】据塔斯社当地时间18日报道，两架俄军伊尔-38反潜巡逻机当天飞越日本海并经对马海峡抵达东海上空并折返，日本防卫省统合幕僚监部声称，日方紧急出动战机应对。 公开资料显示，伊尔-38是苏联伊留申设计局在伊尔-18型民航机基础上改装而成的反潜和海上巡逻机。该机曾是苏联的主要岸基航空反潜兵力，1967年首飞，1970年服役。伊尔-38起飞重量63吨，装有4台发动机，可装载10人及9吨武器，续航时间可达10小时，与美国的P-3反潜巡逻机规格类似。 塔斯社报道称，日本防卫省周四曾表示，5艘俄罗斯海军舰艇和6艘中国军舰当天首次通过冲绳本岛和宫古岛之间的宫古海峡北上，日方称，这是中俄两国海军舰艇首次在这一海域展开联合训练。 报道还提到，中国国防部新闻发言人吴谦此前曾就日方派舰机近距离跟踪中俄舰艇一事回应称，根据中俄两军年度合作计划，两国海军舰艇编队在太平洋西部和北部相关海域举行海上联合巡航。此次行动不针对第三方，与当前国际和地区局势无关。巡航过程中，中俄双方舰艇严格遵守国际法，全程位公海航行。日方近距离跟踪监视是非常危险的，极易引发误解误判和海空意外事件，我们敦促日方停止这些毫无实际意义的干扰，停止影响中日双边关系健康发展，损害地区和平稳定的不负责任言行。 返回搜狐，查看更多责任编辑：
