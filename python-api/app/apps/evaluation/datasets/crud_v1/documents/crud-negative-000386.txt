出席香港浙联会第十三届理事会就职典礼的贵宾合影11月11日晚,香港浙江省同乡会联合会举办庆祝国庆74周年暨浙联会成立25周年及第十三届理事会就职典礼。中共浙江省委书记、浙江省人大常委会主任易练红,中共浙江省委副书记、浙江省人民政府省长王浩发来贺信。香港特别行政区行政长官李家超、中央政府驻港联络办副主任何靖、外交部驻港公署署理特派员李永胜、香港特别行政区前行政长官林郑月娥、全国人大常委会委员李慧琼、香港特别行政区行政会议召集人叶刘淑仪、香港特别行政区政制及内地事务局局长曾国卫、香港特别行政区民政及青年事务局局长麦美娟、全国人大常委会原委员范徐丽泰及香港社会各界人士近千人出席。浙江省政协副主席叶正波、省委统战部常务副部长徐旭率代表团赴香港出席。易练红、王浩在贺信中,代表中共浙江省委、浙江省人民政府和6500万家乡人民,向浙联会举办典礼表示热烈祝贺,并向广大旅港浙江乡亲致以亲切的问候,希望香港浙联会在新时代新征程上,继续发扬爱国爱港爱乡优良传统,充分发挥自身优势,团结带领广大旅港浙江乡亲,一如既往地关心浙江、支持浙江,为推进“一国两制”行稳致远、助力家乡发展、实现民族复兴作出新的更大的贡献。香港特别行政区行政长官李家超致辞李家超在致辞中表示,浙江是国家的重要生产和出口基地,拥有许多世界知名的民营企业,在工业、贸易和物流等方面都有巨大的发展潜力。浙江杭州刚刚成功举办亚运会和亚残运会,向世界展示国家举办国际大型、高水平体育盛事的强大能力。香港在“一国两制”下具备“背靠祖国、联通世界”的独特优势,在金融贸易、专业服务和高等教育等多方面都位居世界前列。今年六月,他和访港的浙江省委书记易炼红共同见证香港特区政府与浙江省政府签署了多项合作协议,商定12个共同合作领域。他相信,浙港两地共谋发展,必定能优势互补,相辅相成,达致互惠共赢。李家超指出,浙联会成立25年以来,一直秉持爱国爱港的宗旨,带领上百个浙籍社团,积极团结在港乡亲和企业,促进浙港两地人民交流与合作,对香港保持繁荣稳定贡献良多。浙联会也热心社会事务,关爱弱势社群,努力推广家乡文化,加强市民的国民身份认同。浙联会多年来大力支持特区政府,为建设社区尽心尽力,成绩有目共睹。目前在港的浙籍乡亲多达数十万人,他们都是浙港共同发展的坚实支持者。希望浙联会继续带领浙籍乡亲,发挥乡情纽带作用,促进两地人民感情,深化浙港合作与融合,共同为中华民族伟大复兴作出贡献。省政协副主席叶正波致辞叶正波在致辞中表示,浙联会成立25年来,始终高举“爱国爱港、情系桑梓”旗帜,在特区和家乡政府的关心关怀下,在历任会长的卓越领导下,在广大浙籍旅港乡亲的积极支持下,取得了长足发展。在坚定维护“一国两制”、推动香港长期繁荣稳定、助推浙港交流合作和家乡高质量发展等方面干在实处、走在前列、勇立潮头。他向香港浙联会成立25周年、向新一届理事会表示热烈祝贺,希望新一届理事会充分把握香港历史机遇,在维护香港繁荣稳定上奋力先行;充分把握家乡发展坐标,在促进浙港交流合作上奋力先行;充分把握社团建设方位,在增强团结力服务力影响力上奋力先行。省委统战部常务副部长徐旭上台向香港浙联会赠送纪念品,并见证了印鉴移交仪式。原标题:《香港浙江省同乡会联合会第十三届理事会就职典礼在香港隆重举行 省委省政府发贺信 省代表团赴港出席》阅读原文
