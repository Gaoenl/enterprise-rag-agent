2023-08-08 10:29，正文：原标题：“蓝马甲”志愿者进社区开公益课堂，教老年人如何防范被诈骗扬子晚报网8月8日讯（记者 梅建明）为了帮助老年人学习熟练使用智能手机，同时提高警惕防范被诈骗，8月5日上午，南京江宁天云社区联合“蓝马甲”助老公益行动开展了一场主题为“蓝马甲行动进社区公益课堂——懂健康知识 享健康生活”的公益讲座活动。图为志愿者教老年人使用手机在此次活动中，“蓝马甲”志愿者为老年人们深入浅出地就智能手机的使用进行了详细讲解。他们细致耐心地向老年人们讲解了手机的各项基本操作，从开关机到拨打电话、发送短信，一一进行了演示和指导。随后，志愿者们向老人们展示了一系列手机的使用技巧，包括手机丢失应急处理等等，让老人们对手机的实际应用有了更加清晰的认识。更为重要的是，志愿者们通过讲解，帮助老人们认识到了防范诈骗的重要性。他们详细介绍了常见的诈骗陷阱，如电话诈骗、网络诈骗等，告诉老人们如何辨别和规避这些风险。同时，志愿者们还倾听了老人们在生活中遇到的困难和问题，为他们提供了有关生活、安全等方面的实用建议。图为志愿者教老年人使用手机参加该活动的一位老年人表示，“老年人对待智能手机，是想用但不会用，怕用错而不敢用，甚至害怕遭遇诈骗。而蓝马甲公益小课堂解决了我们许多的疑问，希望这类讲座可以多举办一些。”据介绍，下一步，该社区将继续为老年居民提供针对性强、服务品质高的活动，加大对诈骗陷阱等知识的宣传力度，保障社区居民的财产安全，进一步提升老年居民生活安全感、幸福感。校对 王菲返回搜狐，查看更多责任编辑：
