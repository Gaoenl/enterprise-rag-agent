外商投资在江苏经济社会发展中发挥着重要作用,今年1至10月,全省实际使用外资达226亿美元,继续保持全国首位。《江苏省促进和保护外商投资条例》将于2024年1月1日起施行,12月13日省人大常委会召开贯彻实施座谈会,省商务厅、省外办、知识产权局等相关部门对照条例拿出具体举措,以最大诚意“招商待客”。今年省重大工业项目清单中,外商投资项目达108项,截至11月底,已完成投资占全年计划投资的116.2%,超序时进度24.5个百分点。省工信厅二级巡视员李健介绍说,目前正在编制的2024年省重大工业项目清单中,拟列入外资及合资项目的预计增加至120项,项目总投资占全部项目投资的比重将超过20%:“积极引导外商投资先进制造业,推进服务外资工业项目建设。”省发改委表示,将发挥省重大项目建设协调机制作用,对符合我省产业发展重点方向的重大外资项目,强化要素保障。吸收外资不仅要增量,更要提质增效。《条例》强化了对外商投资的鼓励引导,如鼓励和引导外资在本省参与制造业集群、优势产业链建设,鼓励跨国公司设立地区总部和功能性机构,支持外资在本省设立和发展研发中心,支持外企在中国境内利润再投资等。省商务厅副厅长孙津介绍,江苏早在2012年便出台第一份外资总部鼓励政策,并于2015、2018、2021年完成修订,今年正在开展新一轮政策修订工作,即将出台:“明年,我厅将修订完善鼓励外资企业利润再投资政策,引导存量外资增资扩产,实现“增量-存量-增量”的转化;建立重点产业链重点环节、目标跨国公司清单,持续推进外资补链延链强链行动;认真落实外资研发中心鼓励措施,统筹推进外资研发中心相关工作。”省发改委表示将加快推进我省列入“一带一路”国际合作高峰论坛成果清单等重大外资项目建设,围绕进一步推动长江经济带高质量发展和长三角更深层次更宽领域一体化,积极拓展国际经济合作新领域新渠道。省外商投资企业协会在宣传贯彻《条例》时发现,目前外资企业重点关注实践中的国民待遇及知识产权保护等问题,同时不同产业、不同行业和不同企业的关注点有所区别。《条例》也明确了外企平等适用各项政策,保障平等参与市场竞争。省发改委表示,正在协调推动外资企业平等参与招投标、政府采购、首台(套)政策的使用等;省税务局表示,对内外资企业执行统一的税收政策,特别是在落实减税降费举措方面,积极对外资企业落实留抵退税、高新技术企业、研发费加计扣除等优惠政策。省税务局一级巡视员陈茂锋说:“积极落实外国投资者从中国企业分配的利润用于境内直接投资下,股息所得税递延政策,自2018年该政策实施以来,江苏各项指标连续多年保持全国第一,截至今年三季度,合计吸引利润再投资1455.8亿元,延迟缴纳税款144.4亿元。”省知识产权局表示,我省在十四五规划中明确了建设知识产权快速协同保护体系目标,目前仅在省知识产权保护中心备案的外资企业已达528家,为其提供了高效的专利快速审查、快速确权、快速维权服务。下一步将更高标准提升知识产权保护效能、提升公共服务机构能力水平,深化与世界知识产权组织等机构的合作。《条例》还提出优化政府服务,如建立健全外商投资企业投诉工作机制、政务服务事项可以依法容缺受理等。省外办副主任金尚军介绍,今年已成功协调解决74批次342人次的外国重要经贸团组人员来华办理签证难问题,并及时调整APEC商务旅行卡申办条件,扩大企业类别受理范围,“需办尽办”,全省共受理上报APEC商务旅行卡申请5205人次:“《条例》实施后,我办将在全省推广一体联办工作,每年可为企业和群众提供约8万余份涉外文书的‘一站式’办理服务,有效打通外事政务服务‘最后一公里’。”省商务厅已建立起我省外商投资企业投诉工作网络,建立了外商投资企业圆桌会议制度等,听取企业意见建议,从个案上切实有效地保护外商投资者合法权益。(江苏新闻广播/丁凤云 编辑/高若婷)
