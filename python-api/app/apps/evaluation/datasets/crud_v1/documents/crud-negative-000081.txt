2023-08-18，正文：近期，一起涉及吸毒驾车致人死亡的案件引起了人们的广泛关注。据报道，一名17岁的女孩在社交媒体上夸耀自己大量吸毒后仍然活着，然而在吸食大麻和迷幻蘑菇后，她驾车时速达160公里与男友和友人相撞，造成两人死亡。这起悲剧发生在2022年7月的一天凌晨，当时女孩麦肯齐·希里拉在吸食大麻和迷幻蘑菇后驾车，不幸与她的男友和友人发生严重车祸，导致两人当场丧生。事故现场发现了大麻和迷幻蘑菇的残留物，以及女孩的拖鞋被放在油门上，显示她没有刹车痕迹。经过调查，女孩被控四项谋杀罪和其他罪名，最终被判处重刑，可能面临至少15年的监禁。她的涉案TikTok账号已转为私人，视频中她吹嘘自己吸毒耐受性的内容引起了人们的关注。尽管女孩的家人坚称这是一场意外，但检察官认为她的行为构成谋杀。检察官以谋杀罪起诉希里拉，他们认为希里拉想谋杀鲁索，弗拉纳根只是被附带的受害者。本周，希里拉被定罪后，一段TikTok视频流露出来。希里拉在视频中化着浓妆，戴着夸张的假睫毛，视频中配上的音频说道：“我一点也不酷，我只是那些吸食大量毒品却不会死的女孩之一。”她这是在吹嘘自己的药物耐受性。目前，尚不清楚希里拉发布这段视频时，是在车祸发生前，还是车祸发生后。这个账号已经转为私人账号，无法查看。希里拉的母亲要求上诉，她上周作证称，希里拉患有直立性心动过速综合征（POTS），这种病会导致她晕倒，这可能是车祸的原因。据美国国家神经疾病和中风研究所的数据，POTS的主要症状是头晕或昏厥。本周，希里拉因四项谋杀罪、四项重罪袭击罪和两项严重车辆杀人罪被定罪，这意味着她至少15年内不得假释。她的宣判将于下周一进行。(责任编辑：张佳鑫)
