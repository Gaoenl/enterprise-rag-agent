"千龙网讯(记者 刘美君)自疫情防控以来,很多社区居民都积极配合防疫工作,但也有个别人在执法人员忙于防疫之时,萌生了造房子、搭棚子等念头。为防止疫情期间新增违建发生,北京市朝阳区望京街道综合行政执法队在开展疫情防控的同时,坚持控违治违不放松,对新增违建持续保持高压严管态势,近期连续拆除制止了5起新增违建,共40余平方米。即查即拆,快速治理。针对巡查发现和群众反映的望京西园四区、花家地西里、南湖渠西里的楼顶违建、阳台扩建等新增违建问题,执法人员第一时间进行现场勘验取证,快速对接社区负责人和违建当事人,积极入户做当事人工作,耐心讲解相关法律法规和政策,对其抢建违建问题进行了批评教育,并依法依规拆除了违建,有效打击了疫情期间的顶风违建行为。强化巡查,严密防控。采取一查多效的综合执法模式,按照责任区片划分,将防疫检查与环境治理、拆违控违同步进行,加大每日巡查频次,依托社区巡逻队、志愿者队伍、网格员等多方力量严密防控,快速查处新增违建、私搭乱建等问题,有效遏制了违建苗头。广泛宣传,长效治理。街道召开拆违启动会,对拆违工作进行了全面部署,执法队联合各社区开展广泛宣传动员,发动居民群众积极参与拆违治违,及时提供违建线索。同时建立综合行政执法队、公安、社区联动拆违机制,将“即查即拆”机制常态化、制度化,以"零容忍"态度多渠道、多形式打击违法建设,为市民营造和谐、有序的生活环境。千龙网讯(记者 刘美君)自疫情防控以来,很多社区居民都积极配合防疫工作,但也有个别人在执法人员忙于防疫之时,萌生了造房子、搭棚子等念头。为防止疫情期间新增违建发生,北京市朝阳区望京街道综合行政执法队在开展疫情防控的同时,坚持控违治违不放松,对新增违建持续保持高压严管态势,近期连续拆除制止了5起新增违建,共40余平方米。即查即拆,快速治理。针对巡查发现和群众反映的望京西园四区、花家地西里、南湖渠西里的楼顶违建、阳台扩建等新增违建问题,执法人员第一时间进行现场勘验取证,快速对接社区负责人和违建当事人,积极入户做当事人工作,耐心讲解相关法律法规和政策,对其抢建违建问题进行了批评教育,并依法依规拆除了违建,有效打击了疫情期间的顶风违建行为。强化巡查,严密防控。采取一查多效的综合执法模式,按照责任区片划分,将防疫检查与环境治理、拆违控违同步进行,加大每日巡查频次,依托社区巡逻队、志愿者队伍、网格员等多方力量严密防控,快速查处新增违建、私搭乱建等问题,有效遏制了违建苗头。广泛宣传,长效治理。街道召开拆违启动会,对拆违工作进行了全面部署,执法队联合各社区开展广泛宣传动员,发动居民群众积极参与拆违治违,及时提供违建线索。同时建立综合行政执法队、公安、社区联动拆违机制,将“即查即拆”机制常态化、制度化,以"零容忍"态度多渠道、多形式打击违法建设,为市民营造和谐、有序的生活环境。",
