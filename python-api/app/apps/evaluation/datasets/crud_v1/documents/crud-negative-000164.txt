2023-07-31，正文：黄晓明新剧扮演三面卧底特工《潜行者》开播即燃！《潜行者》是由高寒执导，黄晓明、蒋欣、吴晓亮领衔主演，万茜特别出演，王志飞友情出演的近代谍战剧，讲述1941年抗战时期为时空背景，讲述了有着多重身份的男主，在潜伏进汪伪76号后，周旋于各方势力，最终和同一战线的女主完成潜伏，为最后的胜利获取情报，实现了自我价值和使命的故事。该剧于2023年7月27日在央视八套黄金档播出，并在腾讯视频同步播出。7月27日，这部期待已久的谍战剧《潜行者》原名《潜伏者》终于和大家见面了，能够获得央八青睐，想必《潜行者》看点十足，质量过硬。相比奇道7年磨一剑的烧脑剧《无间》，这部《潜行者》显然要简单许多，观众们看起来也不需要考虑太多，只要剧情不拉垮，演员演技在线，那么基本可以成为热门剧。不知为何，网上对于黄晓明的评价始终有点苛刻。虽说这些年，黄晓明的确变得有些油腻，但在这部《潜行者》里的表现还是可圈可点的。故事一开头，谍战剧的氛围就出来了。黄晓明饰演的方嘉树为我方高级特工代号“杜鹃”，但他已经被76号处长李力行（冯晖饰）怀疑，故而在这次在审讯自己的同志李正勋时，李力行是有意安排情报处处长叶兴城（吴晓亮饰）来监督，顺便观察一下方嘉树的反应。可以说一开始方嘉树就和叶兴城在斗智斗勇了，如果不是叶兴城心狠手辣拿枪对着李正勋胸口补了一枪，或许李正勋还有希望被方嘉树偷龙转凤救出去。为了避免李正勋的头部被叶兴城射击，方嘉树立马拦下随机找了个借口阻止了叶兴城的“疯狗”式行为。
