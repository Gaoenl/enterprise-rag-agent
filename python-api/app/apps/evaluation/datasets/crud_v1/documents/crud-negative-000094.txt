7月27日，第31届全国图书交易博览会(以下简称“书博会”)在济南山东国际会展中心开幕。北京出版集团携2300余种精品出版物亮相“北京馆”及“线上书博”元宇宙数字展馆，精心举办15场丰富多彩的文化活动，并在集团线上店铺同步启动“京版书香沁盛夏”系列展销。本次参展的重点产品包括“北京文化书系”、《清风北京：党史中的清廉故事》等精品主题类出版物，《北上》《云中记》《远去的白马》《平安批》《宝水》等近年来获得重大奖项的精品图书；《长江运河图卷》《九边图》《阅古楼 御刻三希堂石渠宝笈法帖》《孟兆祯园林三书》以及“大家小书”、“老北京述闻”丛书、“名典名选丛书”大家读系列、等精品古籍整理、传统文化普及类图书；还有《西高地行记》《金墟》《瓦屋山桑》《北斗牵着我的手》《伍连德画传》《西班牙黄金时代》等各类新品力作。在“线上书博”元宇宙数字展馆，展示叶广芩京味儿童年三部曲“耗子丫丫的故事”以及“共和国脊梁”系列、“北京自然观察手册”系列等重点品种50余种，以优质图书展销、精彩阅读活动为泉城济南奉上京版书香。其中，最新出版的“北京文化书系”首次从古都文化、红色文化、京味文化和创新文化四个角度全方位挖掘和阐释北京文化内涵，是一套凸显北京文化价值，充分展现首都风范、古都风韵和时代风貌的大型文化系列丛书。《长江运河图卷》《九边图》《阅古楼 御刻三希堂石渠宝笈法帖》《京津冀古地图集·国图卷》《北京史地风物书录全编》等一系列精品古籍整理类图书，以及“大家小书”、“老北京述闻”丛书、“名典名选丛书大家读”、《孟兆祯园林三书》、《天地中和：北京中轴线文化遗产》等传统文化普及类图书，彰显集团近年来精心做好北京历史文献和文化典籍整理出版，以出版之力传承发展中华优秀传统文化的丰硕成果。茅盾文学奖得主、著名作家阿来最新散文集《西高地行记》，讲述山乡少年自强故事的《瓦屋山桑》，反映生态文明建设成果的《中国西南野生动物图谱》《动物与人》，《十月》《十月少年文学》等各类精品期刊，以及《曹雪芹风筝艺术》《食物本草图谱》《庆赏昇平图谱》等融中华优秀传统文化与设计巧思于一体的文创产品深受现场读者欢迎。为体现新时代下出版业的“破圈”与“融合”，突出数字化赋能出版产业发展，本次书博会打造“线上书博”元宇宙数字展馆。集团在线上“北京馆”集中展出 “耗子丫丫的故事”“北京自然观察手册”等50余种精品好书，通过云发布、云优惠、云阅读、云观展等方式，让读者不到现场也能感受书展的精彩。本届书博会，北京出版集团还邀请专家学者、资深出版人通过线上、线下组织举办十余场丰富多彩的特色阅读体验活动。其中，北京工艺美术出版社“一起玩泥彩塑”手工体验活动，由北京市级非物质文化遗产“北京彩塑”代表性传承人张忠强现场带领各位读者一起“花式玩泥巴”，感受这项古老民俗艺术的独特魅力。《少年科学画报》杂志社举办了“一起发现昆虫”主题讲座，资深科普编辑刘佳瑀通过自己探索自然的见闻与感受，带领读者一起了解昆虫的奥秘。举报/反馈
