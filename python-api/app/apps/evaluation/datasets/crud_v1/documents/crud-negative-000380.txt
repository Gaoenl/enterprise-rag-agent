时隔10天，又一场大暴雨袭击重庆。2023年7月14日，据@重庆发布 消息，今日重庆多个区县发布暴雨预警，其中，北碚、万州、江津发布暴雨红色预警；忠县、云阳、石柱发布暴雨橙色预警。@重庆天气 7月14日上午发布统计数据显示，7月13日8时—14日8时，重庆市西部大部地区大雨到暴雨，局地大暴雨，中部及东北部地区中雨到大雨，部分地区暴雨到大暴雨。其中，万州区等20个区县及两江新区的108个雨量站出现大暴雨，30个区县及两江新区、重庆高新区的395个雨量站出现暴雨，最大雨量为219.0毫米（万州区龙宝），最大小时雨量90.6毫米（万州区五桥，14日5时）。7月14日6时30分，北碚区气象台升级发布暴雨红色预警称，目前龙凤桥街道、歇马街道累计雨量已超过100毫米。预计未来6小时降水仍将持续。14日5时10分，江津区气象台升级发布暴雨红色预警，该区防汛抗旱指挥部会商研判，决定7月14日5时30时起，将江津区江河洪水、山洪灾害和渍涝灾害橙色预警提升为红色预警。雨情最严重的是万州区。7月14日5时30分，万州区防汛抗旱指挥部发布紧急通知称，预计未来3小时该区大部地区仍将有60—120毫米，局部150毫米的短时强降水。万州区防汛抗旱指挥部表示，为有效防范应对本轮强降雨，按照区委区政府统一部署，决定于7月14日5时30分起将防汛Ⅲ级应急响应升级为Ⅱ级应急响应。请各镇乡（街道）、区防指成员单位按照Ⅱ级应急响应相关规定做好防范应对工作，切实做好断道、停工、停学、停业、停运、停游、停航等措施。此前在7月3日-4日，万州区曾遭遇一轮特大暴雨袭击。长滩镇降下了万州区1956年有完整气象记录以来的最大暴雨，引发山体滑坡等次生灾害。据新华社7月6日消息，截至目前，万州洪涝地质灾害已造成17人死亡、2人失踪。7月14日，万州区抗震救灾和地质灾害防治救援指挥部表示，根据《重庆市万州区地质灾害应急预案（暂行）》规定，经会商研判，决定于14日5时起将地质灾害Ⅲ级应急响应升级为Ⅱ级应急响应。此外，重庆市抗震救灾和地质灾害防治救援指挥部也发布通知，决定于7月14日5时，启动全市地质灾害Ⅱ级应急响应。重庆市水利局和重庆市气象局7月14日6时联合发布中小河流涨水风险提示：预计7月14日7时至7月14日13时，重庆24个区县部分中小河流有涨水风险，其中风险较高的为垫江县，风险高的包括忠县、梁平区、万州区、云阳县、奉节县、石柱县。据“重庆发布”消息，重庆市抗震救灾和地质灾害防治救援指挥部表示，经市防汛抗旱指挥部会商研判，决定于7月14日5时起，将渝北区、长寿区、垫江县、忠县、梁平区、万州区、开州区、云阳县、奉节县、巫溪县、巫山县等11个区县防汛Ⅳ级应急响应升级为防汛Ⅲ级应急响应。重庆市应急局相关负责人介绍，各区县专业救援力量目前已前置备勤，其中长寿前置3个重点乡镇35人，万州前置3个重点乡镇29人（含渝东北支队10人），巫溪前置1个乡镇10人（渝东北支队10人）；其他重点区县的专业救援队伍全员均为备勤状态。举报/反馈
