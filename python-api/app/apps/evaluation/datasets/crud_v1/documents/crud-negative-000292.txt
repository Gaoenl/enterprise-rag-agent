2023-08-10 19:38，正文：原标题：北京因灾受损车辆保险定损理赔已完成65%北京日报客户端 | 记者 潘福达记者从国家金融监督管理总局北京监管局获悉，截至8月10日10时，北京保险行业累计收到因灾报损案件2.74万件，其中1.16万件已完成理赔或预付赔款，占比超过42%，赔款金额共计3.8亿元。本次受灾较重的房山区和门头沟区因灾报损案件数量及赔付金额约占全市的一半。北京地区车辆因灾报损约1.7万辆，其中超1.1万辆已完成定损、理赔或预付赔款，占比近65%。已报案全损车辆的定损、理赔或预付赔款完成率超过75%。北京地区农业保险估损金额3265.6万元，已定损、理赔或预付赔款金额2102.8万元，约占全部估损金额的64%。暴雨及洪涝灾害期间，北京地区累计有215家银行保险机构网点因避险或不具备营业条件而临时停业，目前已复业191家，占比89%。24家未复业网点全部位于房山、门头沟两区，均系因供电中断、道路不通等暂不具备营业条件，待环境恢复后将及时恢复营业。据了解，北京监管局向全行业发出“路通到哪里，保险就到哪里”的动员令。针对受灾严重地区受损车辆积压、急需救援支持的情况，北京监管局组建由局班子成员连续驻守、现场指挥，保险行业一致行动派出联合救援突击队，集中力量解决车辆清运问题，累计组织北京及周边地区保险机构1020名查勘定损工作人员、327台清障救援车辆，分别赴房山区、门头沟区及其他受灾区域，不区分投保机构及有无保险开展无差别车辆清运，全力协助当地政府清理路面车辆。对于仍不具备通行条件的地区，主动协助政府开展清淤处理，优先开展受损车辆转运工作，避免受损车辆堆积。在8月5日、6日“周末攻坚战”中，北京保险行业共清运房山区、门头沟区河道（沟）、路边和地下车库遗留受损车辆757辆。人保北分工作人员在门头沟水峪嘴村查勘定损清路北京监管局还组织在京财险机构召开专项调度会，明确要求统一理赔标准，互认查勘定损结果，对河道车辆等水淹车按全损进行全额赔付，对其他部分损失车辆按“就高不就低”原则尽快预付赔款，真正做到“应赔尽赔、能赔快赔”。下一步，北京监管局将督促保险行业集中力量完成遗留车辆清理、紧盯重点领域做好保险服务、加快推进保险理赔进度，分区域、分行业、分步骤扎实做好后续救灾理赔工作。返回搜狐，查看更多责任编辑：
