为庆祝中国共产党成立98周年,加强精神文明建设,激发广大党员干部立足新税务、建功新时代,加快推进团结、奋进、和谐的税收干部队伍建设,近日,东营市东营区税务局举办了“不忘初心跟党走 牢记使命建新功”主题诵读活动。活动中,对2018年度先进基层党组织、优秀共产党员和党员先锋岗进行了表彰。受表彰的党员干部纷纷作出承诺,要继续以身作则,充分发挥共产党员先锋模范作用,展现税务人的赤诚党心。本次活动十个支部共选送14个节目,诵读活动过程高潮迭起,各位选手紧扣主题、精神饱满、语言流畅,以富有感染力的诵读,情真意切地讲述了对中国共产党的深厚感情,分享了自己为税收事业奋斗的心路历程,全面展现了税务干部向上向善、克己奉公、忠诚担当的精神风貌和良好形象,增强了全体党员干部的内心认同和自觉践行传承中国税务精神的行动自觉。
