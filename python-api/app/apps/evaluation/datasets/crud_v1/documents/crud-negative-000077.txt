2023-08-09 18:18，正文：据韩联社9日报道，韩国最大在野党共同民主党决定向联合国人权理事会提交请愿书，要求阻止日本福岛核电站核污染水排海。在国会举行的签字仪式上，党首李在明等人签署了请愿书。报道称，共同民主党在请愿书中表示，日本排放核污染水不仅在安全方面缺乏科学措施，而且违反了各种国际协议。他们强调，没有进行严格的辐射风险评估就排放核污染水的行为是不可接受的。党首李在明表示，尹锡悦计划将美日韩首脑会议作为同意核污染水排海的借口，这是公然的意图。他质问道，如果将韩国的安全交给日本决定，韩国政府存在的意义是什么？他敦促尹锡悦就日本核污染水排海明确表示反对的立场。报道还称，共同民主党议员禹元植表示，我们不能再相信总统，将我们的国民和海洋的安全交给他。他表示，应该通过国际社会的常识和国际机构的专业程序来应对污染海洋的行为，因为这不仅关乎韩国的未来，还关乎人民生活的基础。该党最高委员朴赞大批评称，尹锡悦的态度让人怀疑他是哪个国家的总统。他说，绝大多数国民都反对的事，总统却保持沉默。据韩联社此前报道，8月7日，日韩两国政府举行视频会议，就日本福岛核污染水排海问题进行磋商。但在向民众通报磋商情况的记者会上，韩国国务调整室第一次长朴购然表示，核污染水何时排海应由当事国（日本）定夺，而非韩日协商决定。来源：环球网爆料、维权通道：应用市场下载“晨视频”客户端，搜索“帮忙”一键直达“晨意帮忙”平台；或拨打热线0731-85571188。政企内容服务专席19176699651。
