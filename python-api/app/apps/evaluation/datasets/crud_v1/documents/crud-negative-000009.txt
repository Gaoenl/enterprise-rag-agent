美国西南部地区近期持续遭遇热浪炙烤。亚利桑那州首府凤凰城及周边成为这一波热浪的中心。凤凰城周一终于结束了连续31天最高气温超43°C的高温记录。但更多的热浪仍在后面。据凤凰城国家气象局在社交媒体上发布的消息,周一凤凰城天港机场的高温达到了108华氏度(约合42.2摄氏度)。在周一之前,凤凰城已经连续31天每天最高气温都超过110华氏度(约合43.3摄氏度)。此前当地连续高温天数的纪录出现在1974年,当时连续18天最高气温超110华氏度。更多热浪将来袭气象局在周二发布的公告中表示,虽然高温暂缓非常受欢迎,但周三气温将再次开始攀升。“周三将标志着变暖趋势的开始,预计到周五,大部分低地沙漠地区的高温最终将再次突破110华氏度。亚利桑那州中南部大部分地区已经为周五到周日发布了高温预警。” 气象局表示。凤凰城是美国西南部地区的“火炉”城市之一。根据世界天气归因(World weather Attribution)科学家的研究,凤凰城历来夏季炎热,但全球变暖趋势加剧了高温。该组织的科学家们发现,由于气候变化,7月份美国西南部的热浪几乎要比以往高出4华氏度。亚利桑那州气候学家Erinanne M. Saffell表示,城市热岛效应使得凤凰城夜间气温升高,整个7月份,有19天夜间气温没有降至90华氏度(约合32.2摄氏度)以下,并创下了97华氏度的‘最高’低温记录。数据显示,凤凰城的7月成为美国城市有记录以来最热的月份,平均气温达到了102.7华氏度。之前的全国最高气温是1996年7月亚利桑那州哈瓦苏湖市创下的,当时平均气温为 102.2华氏度。长时间的极端高温是危险的。根据凤凰城所在的马里科帕县最近的高温死亡报告,已经确认有25人死于高温。另外249人的死亡仍在调查中,以确定是否因高温造成。(文章来源:财联社)
