2023-08-10 20:03，正文：原标题：暑期，孩子们反诈知识库“更新升级”扬子晚报网8月10日讯（通讯员 李澳 记者 薛玲）“贴心”的客服、“丢失”的快递，小心有诈……在南京市鼓楼区湖南路街道马台街社区新时代文明实践站开展的“未成年人暑期防诈骗宣传活动”中，湖南路派出所社区民警不仅给孩子们上了一堂生动的反诈防骗安全课，更让孩子们的反诈知识库“更新升级”。防诈骗宣传活动现场如何防范电信网络诈骗？不少人觉得只要不随意转账就行了，但随着骗术的不断“升级”，大家的防骗知识库也需要“更新升级”。当天活动中，湖南路派出所社区民警就通过宣传片播放、辖区典型案例通报、现场答疑等方式，给孩子们上了一堂生动的反诈防骗安全课。孩子们向沿街商户发放“谨防电信网络诈骗”宣传单接到客服谎称快递在运输中丢失，并以全额赔款诱导扫二维码或者点击网址链接进行“退款验证”的，100%是诈骗；凡是涉及高收益的网络理财，100%是诈骗；不查征信、无抵押、秒到账，这样的“贷款”100%是诈骗……随后，孩子们还化身反诈小志愿者，为沿街商户及市场商贩发放“谨防电信网络诈骗”宣传单，让更多人加强自我防范，提高防骗意识。校对 盛媛媛返回搜狐，查看更多责任编辑：
