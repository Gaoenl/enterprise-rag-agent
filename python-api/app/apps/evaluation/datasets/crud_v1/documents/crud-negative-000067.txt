2023-07-19 14:20，正文：7月19日，网上传来一个令人悲痛的消息，23岁的网红丹宁于7月19日凌晨3:15，因脑出血发作抢救无效离开了人世，母亲在网络上为她发出了悼念，表示她一直都是一个孝顺父母、努力上进的女孩，她这一生活得非常自由和精彩。母亲还晒出女儿生前的一张照片，照片上的丹宁笑脸面对镜头，反差令人唏嘘，她的去世也让网友悲痛不已，纷纷进行悼念。丹宁才23岁的年纪就突然离开人世，也让不少网友直呼很突然，根据丹宁此前发布的短视频来看，她并没有异样，近期视频中和友人合照，一脸快乐。而在6月初，丹宁也发出了自己身穿学士服，和其他好友合影留恋的视频，她手捧花束，庆祝毕业，还用手抚摸着一只小猫咪。根据丹宁透露，她在2019年到2023年完成了学业，并且即将在九月份奔赴新学校，开启自己新的研究生生活，然而现在她还没有开启新生活，幸福就突然戛然而止，这更是让人感到万分惋惜。丹宁平常的生活非常丰富多彩，据她所言，她在准备写论文、完成区赛和答辩，偶尔还会在网络上晒出自己旅游或回乡的照片，以及各种营养美食照，是个热爱生活的女孩。至于丹宁突然脑出血发作的原因，有网友猜测跟2年前的一场车祸有关，在2021年8月，丹宁曾经遭遇了一场车祸，腿骨折内脏受损，在ICU插满管子进行抢救之后，才活了下来，之后丹宁像正常女孩一样坚强的活过了两年时间。丹宁还有另外一个较为特殊的身份，她被一些网络媒体报道为“王丽云的干女儿”，而王丽云是演员车晓的母亲，同时也是一位国家一级演员，曾主演过《鱼水情》、《手机》等众多作品，还获得过新农村电视艺术节最佳女配角奖。虽说王丽云并没有正面回应过两人的关系，但是丹宁和王丽云两人平常有很多的互动，可以看得出她们之间的关系很好，比如，丹宁曾经在母亲节晒出车晓和王丽云的母女合影，艾特了王丽云，还给王丽云送上了绘制爱心的视频，俨然把王丽云当成了一位敬爱的长辈。王丽云在丹宁出车祸之后，也第一时间为她录制了一段视频进行鼓励，在视频中她提到，丹宁是个聪明伶俐、善良的好孩子，不幸发生了车祸，让大家都替她感到悲伤，希望她能够好好的养伤，早日回归，她们都在为丹宁祈祷，希望丹宁自己也要加油。丹宁的早逝令人感到无比惋惜，她本来马上就要读研究生了，还是明星王丽云所喜爱的小辈，年华却无情的凋谢于盛开之前，希望她能够一路走好，也希望大家都注意健康，珍惜生命。
