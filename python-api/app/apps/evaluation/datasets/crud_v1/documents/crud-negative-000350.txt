2023-08-10 13:51，正文：原标题：商户联盟聚合力 居民家门口得实惠中新网新疆新闻8月10日电（杨文静）一块钱的西瓜、低于市场价的清油、免费的推拿……这不是商场超市的促销活动，而是8月4日新疆乌鲁木齐市米东南路街道常乐社区商户互助会成立后开展的首场惠民活动。前期，在社区推动下，辖区128家商户成立“商户互助会”，建立自治公约，参与社区治理，努力实现资源共享、发展共赢、治理共建和成果共享。“‘商户互助会’成立，就是为了把辖区商户团结起来，目的就是降低商户的运营成本，促进商户更好的发展，更好的给居民提供更优质的商品和惠民的服务。”互助会负责人王强说。目前，辖区已经有128家商户加入了“商户互助会”，此次活动吸引了20多家商户参加，包括蔬菜、水果、粮油、日用品及养生保健类。活动中，全场惠民产品均低于市场价，居民不仅享受了很多惠民福利，还能在家门口体验便民服务。“买的清油比平时便宜了十几块钱，特别划算，让我们在家门口就得到了实惠，挺不错的！”居民魏红说。常乐社区辖区居民通过志愿服务获得积分，达到一定积分可以按照星级等次兑换相应物品，也可以凭借社区发放的“志愿者星级”兑换劵在指定商户进行物品兑换。“今后社区将依托社区现有的各项资源，定期开展惠民活动，促进社区、商家、居民之间的互动交流，多元共治和谐幸福社区。”常乐社区党总支书记马兰说。返回搜狐，查看更多责任编辑：
