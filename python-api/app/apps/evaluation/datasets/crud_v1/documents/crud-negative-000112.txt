，正文：近日，江苏淹城野生动物世界有限公司因违反广告法，被常州市武进区市场监督管理局罚款25万元。据了解，该公司今年4月曾策划一项宣传活动，声称与虎同住1小时将奖励10万元。 据悉，4月1日当天，动物园原计划将白虎控制在指定区域，确保体验者安全，并邀请相关部门到场评估。然而，在测试中，由于白虎本身属于野生动物，保留着野性，不可控性强，排斥新物件，瞬间将帐篷撕碎，导致活动无法开展。因此，当天并未实际实施该活动。 4月2日，该公司发布了活动暂停公告。然而，该公司利用高额奖金诱导游客参加危险性文体活动，造成不良社会影响，有悖社会公序良俗。随后，当地市场监管部门表示，该短视频涉嫌违反《广告法》相关规定，已责令该公司停止发布，予以删除，并对其涉嫌违法情况作进一步调查处理。如今，3个月之后，处罚终于尘埃落定。 专家提醒，虽然圈养状态下的狮子和老虎通常不具有对人类天然的恐惧，给了游客“虚假的安全感”，但“对野生动物缺乏警惕和尊重会付出非常高昂的代价，有时甚至是生命”。本文属于原创文章，如若转载，请注明来源：常州动物园被罚款25万元！奖励10万的活动被撤销https://news.zol.com.cn/826/8268227.html
