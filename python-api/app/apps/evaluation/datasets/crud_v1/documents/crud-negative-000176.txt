当地时间2022年11月13日，西班牙马德里，人们聚集在西贝莱斯广场参加抗议废除公共卫生初级保健的示威活动。  视觉中国 图当地时间11月13日，数十万示威者在西班牙首都马德里举行集会，反对右翼地方政府削减当地公共卫生开支，并警告称，相关计划将“摧毁”当地的医疗保健事业。据法新社11月13日报道，当天下午，示威者在马德里的四个地点举行集会，并前往马德里市政厅游行。示威者的诉求是：“支持公共医疗保健，反对破坏初级医保服务的计划。”一条巨型绿色横幅上写着“你的健康不应取决于你的钱包”，还有横幅上写着：“医疗保健不是用来出售的，必须捍卫。”示威者说，由于缺乏资源和人员，马德里的初级医保服务多年来一直面临巨大压力，而当地的管理不善又使情况进一步恶化。马德里地方政府一名发言人表示，13日有20万人走上了街头。但据阿纳多卢通讯社报道，组织者声称，参加抗议的有67万人。另据阿纳多卢通讯社报道，近一周以来，在马德里24小时诊所工作的医生也一直在罢工，谴责一项增加诊所，但并不雇用足量新员工的计划造成了“混乱”。西班牙左翼政府对抗议者给予了支持，首相府、议会关系和民主记忆大臣费利克斯·博拉尼奥斯（Felix Bolanos）表示，这场危机是由中右翼人民党领导的马德里自治区政府对公共医疗的“灾难性管理”造成的。尽管马德里是西班牙经济最发达的地区之一，却也是“人均卫生投资最少的地区，全国人均（卫生投资）1700欧元（约合人民币1.25万元），而马德里是1300欧元”。此外，马德里还是“人均医生和护士最少的地区”。一些抗议者要求马德里自治区主席伊莎贝尔·迪亚斯·阿尤索（Isabel Diaz Ayuso）辞职。11月21日，当地近5000名家庭医生和儿科医生也将因“工作超负荷”等理由举行抗议。
