8月8日晚,第31届世界大学生夏季运动会将在成都露天音乐公园举行闭幕式。广东选手在赛场上争金夺银之后,来自华南师范大学的9名师生将登上闭幕式的舞台,通过音乐和舞蹈点亮未来。“破圈”的青春嘉年华成都大运会闭幕式总导演甲丁,曾担任2001年北京大运会闭幕式总导演。此次再度执导,他坚持要“破圈”。这是一场公园里的闭幕式,是世界大型体育赛事闭幕式走出场馆的一次突破。甲丁表示,他看到的成都有两个关键词,一个是公园城市示范区,一个是国际音乐之都。因此,舞台的形式呈现公园城市特点,舞台的内容则解读国际音乐之都的内涵。整场闭幕式将以梦想为主线,以篇章的形式致敬生命、青春与世界,共同道出未来的殷殷希望与美好愿景。8月7日,“成就梦想”歌舞晚会在成都大运村艺术中心大剧场举行,成都大学的学子用歌舞为参加大运会的中外代表团送别。新华社发与此同时,在呈现形式上也有所突破。整场表演将通过直播,打破单一表演空间的平衡。届时,央视直播间将会搭建在舞台的正中央,当观众进入直播间后,实时发送的弹幕和点赞也将投射到演出现场。只要观众贡献出精彩的内容,都有机会在闭幕式的现场得以呈现。此外,整场演出处处都体现出巴蜀独有的文化内涵。利用技术手段,东汉时期的说唱俑将在舞台上“复活”,流行女团歌者将与说唱俑梦幻联动,来一场古今和鸣。8月7日,“成就梦想”歌舞晚会在成都大运村艺术中心大剧场举行,成都大学的学子用歌舞为参加大运会的中外代表团送别。新华社发“把欢乐进行到底、把告别深情化。”甲丁透露,闭幕式基于他对成都人“创新”和“乐观”特质的挖掘,通过巴蜀地区文化与当下年轻群体中的流行表演形式进行混搭融合,碰撞出符合青年审美的艺术形式,同时用音乐表达成都人的自由浪漫。学生乐队在世界舞台首秀在闭幕式的舞台上,9名来自华南师范大学的师生将登台,他们把广东的“声音”带到大运之城,在“青春主场”用梦想点亮未来。几个月前,华南师范大学音乐学院声乐教授张学樑得知有机会参加闭幕式表演时,心情很激动。他将参演第二篇章《致青春》,在其中扮演一个川菜大厨,手捧菜谱,向观众介绍四川名菜麻婆豆腐。华南师范大学音乐学院声乐教授张学樑将参加闭幕式表演。“我扮演的厨师是大运村中必不可少的一个角色,他需要保障所有运动员、教练员的饮食。我们的表演就是致敬这些在大运会背后默默付出的工作人员。”张学樑表示。他认为,这个表演很好地诠释了“梦想点亮未来”这一主题。“每个人都有自己的梦想。只要大家在各自的行业里做到最好,未来必定可期。”华南师范大学音乐学院声乐教授张学樑将参加闭幕式表演。本闭幕式的暖场环节上,将有来自全国东南西北的四支高校乐队带来表演。华南师范大学星空乐队将作为高校的代表,唱响青春之歌。星空乐队。星空乐队的指导老师张镇介绍,乐队一共有7位成员,都是华师的在校学生。这次演出,他们将会参与两个节目,包括本届大运会的推广曲《城市的翅膀》。“四个乐队的主唱一起,站在主舞台上为大家演奏主题曲,这也是中国大学生团结的一种表现。”张镇表示。张镇透露,这将是星空乐队在舞台上的首秀。“之前我们大多是参与一些小型的演出,乐队也没有正式的名字。起这个名字,是希望我们的乐队能够像满天繁星一样,一直长长久久地存在。在大运会闭幕上这样的世界舞台上迎来首秀,也是一个非常好的开始。”采写:南方日报见习记者 许仪 特派记者 彭博 发自成都图片:受访者供图
