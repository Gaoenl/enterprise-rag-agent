2023-08-12，正文： 光明日报北京8月11日电（记者陈海波）中央气象台11日发布消息称，今年第6号台风“卡努”北上，即将进入我国辽宁省境内，其外围云系已经给东北地区东部带来强降雨，预计该风雨影响将持续至13日，辽宁、吉林、黑龙江将有大到暴雨，局地大暴雨。 据中央气象台介绍，8月11日下午至13日，辽宁、吉林、黑龙江等地部分地区有大到暴雨，局地有大暴雨；大部地区累计雨量30至80毫米、局地100至150毫米，辽宁东部局地将超过200毫米。 气象专家提醒，松辽和海河流域目前江河湖库水位较高，多地遭受洪涝灾害。此次强降雨过程将使汛情发展、水位复涨，部分地区可能重复受灾，建议上述地区强化防汛救灾工作，防范可能造成的洪涝、城乡内涝和山洪、地质灾害。 目前正值东北地区作物产量形成关键期。未来几天，“卡努”风雨影响区域与前期受渍涝灾害地区高度重叠，将加重渍涝。同时，大风可能导致玉米等作物倒伏。专家提醒，相关地区要加强防范，做好田间管理。 《光明日报》（2023年08月12日 03版） 					                                                                                    	[                      	责编：王宏泽 ]
