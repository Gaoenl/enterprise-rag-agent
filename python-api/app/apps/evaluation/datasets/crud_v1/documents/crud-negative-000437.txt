2023-07-28 18:58，正文：原标题：生活报青年志愿者在行动 小志愿者捐出压岁钱 助困境姐姐继续学业23日，生活报青年志愿者、生活报党员、记者一同来到哈尔滨南岗区，为两名困难学生送去了助学金和慰问品。据悉，生活报青年志愿者团队爱心助学活动已持续14年，共捐助600多名特困学生，今年预计捐助近100名特困学生。此次助学是今年生活报青年志愿者的第九次助学活动。23日清晨，天空依然下着雨，但是生活报青年志愿者们却依然冒雨提前到达集合点。记者看到有的志愿者身上都已经湿透，但他们脸上还是洋溢着笑容，“好久没见孩子们了，无论什么天气我都得来。”志愿者吕凤娟告诉记者。“胜男（化名）的家庭生活挺困难的，父母靠捡废品供她上学，但是孩子特别懂事上进，现在在重点高中读书，成绩很优秀。”生活报青年志愿者的队长田桂玲和记者介绍胜男的情况，“孩子开学就高三了，即将迎来她人生中的一个转折点。希望我们的帮助能让她安心高考，为自己的未来努力。”介绍完胜男的情况后，田桂玲告诉记者，帮助胜男的小组中有四位也是初高中重点学校的孩子，他们是孔维嘉、高敬琪、安瑞和谭清元，“他们今天没来，因为他们学习任务也比较重。”这几位小志愿者都是从小就跟随父母一起做公益的，后期渐渐地用自己的零用钱和压岁钱来做助学活动，“他们几个都给我打电话嘱咐我，让胜男姐姐安心备战高考，他们以姐姐为学习榜样。”活动当天由志愿者吕凤娟代表小组成员将助学金交到胜男手里。告别了胜男，志愿者们又来到了浩博（化名）家，“浩博今年高中毕业单招考入了哈职院。”在去的路上，田桂玲队长和记者介绍起了浩博的情况，“他母亲靠打零工供他读书，生活困难，这些年他一直是志愿者崔鸿颖一对一帮扶的，这孩子懂得感恩，说等到了学校也要参加志愿者，为同学们服务，等到了社会为人民服务。”“田姨、丽丽姐、张姨……你们来了！”浩博见到志愿者后，高兴地和大家打招呼，收到志愿者们带给他的助学金和牛奶后，浩博感恩地表示，“这么多年都有志愿者的帮助，我上大学后会更加努力学习，为自己和家人的未来努力，也不辜负志愿者叔叔阿姨的帮助。”龙头新闻·生活报 记者：刘维娜返回搜狐，查看更多责任编辑：
