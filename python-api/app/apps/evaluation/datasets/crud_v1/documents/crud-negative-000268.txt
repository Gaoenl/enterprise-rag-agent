2023-08-02 13:01，正文：新华社北京8月2日电 沙特阿拉伯官员8月1日披露，沙特政府已批准向也门政府提供12亿美元赠款，用于扶持几乎陷入瘫痪的也门经济。两名不愿公开姓名的沙特官员告诉法新社，也门的财政部长、中央银行行长和沙特驻也门大使将于当天晚些时候在沙特首都利雅得出席援助协议的签字仪式。一名也门官员说，沙特这笔援助款将主要用于购买进口食品、发电厂燃料和给公务员发放工资。法新社援引沙特官方资料报道，沙特已向也门援助总额数亿美元的石油衍生品作为发电燃料，并捐款资助也门开发住房、医疗等公共项目，今年早些时候还向也门央行注入10亿美元存款。2022年1月25日，车辆在也门萨那街头排队等待加油。新华社发（穆罕默德摄）由于连年战乱，加之货币贬值、物价飞涨，也门经济凋敝，基本生活物资和公共服务难以保障。该国超过三分之二的人口依赖人道主义援助维持生活。去年年底，也门反政府武装胡塞武装对也门政府控制的油田设施发动无人机袭击，导致原油出口中断，使得严重依赖石油创收的也门经济雪上加霜。胡塞武装2014年9月占领也门首都萨那，之后控制也门大片地区。沙特领导的多国联军2015年3月发起打击胡塞武装的军事行动，试图帮助也门政府收复失地。去年4月，在联合国调停下，也门冲突方同意停火，敌对行为大幅减少。尽管停火协议去年10月到期后未续签，但大体得到遵守，和平进程出现积极进展。今年4月，也门政府高级官员在利雅得与沙特国防大臣哈立德·本·萨勒曼举行会谈，商议全面恢复也门和平路线图，讨论组建包含胡塞武装在内的联合政府可行方案。同月，沙特驻也门大使穆罕默德·贾比尔率领的代表团在萨那与胡塞武装官员举行会谈。（王宏彬）
