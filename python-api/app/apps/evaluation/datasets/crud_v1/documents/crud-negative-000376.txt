2023-08-11 19:30，正文：原标题：北约军事援助乌克兰现疲态 德国用“豹1”坦克充数外媒近日报道称，德国军工企业莱茵金属公司已从一家比利时私营防务公司处购得50辆“豹1”主战坦克。莱茵金属公司计划对这些坦克进行翻新，并将其中的30辆交付给乌克兰。英国《卫报》报道截图“豹1”坦克是20世纪60年代德国研制的一种主战坦克，比“豹2”坦克轻，有多种类型主炮。报道称，比利时公司所出售的这批型号的“豹1”坦克，最后一次升级是在20世纪90年代。除了莱茵金属公司之外，德国弗伦斯堡汽车公司也正在准备向乌克兰提供约70辆“豹1”主战坦克，预计今年将交付其中的第一批。中央广播电视总台环球资讯广播军事评论员魏东旭分析指出，德国开始大量援助老旧的“豹1”坦克，主要是为了凑数。“豹1”主战坦克是上世纪60年代的技术和工艺水平，已经非常落后和老旧。即便对其进行翻新和技术升级，在复杂的作战环境中，也很难发挥大作用。针对乌克兰进行武器装备的援助，北约成员国都是有各自的任务的，德国压力比较大。德国以前主要是援助“豹2”系列的主战坦克，性能比较先进，但持续供应“豹2”，德国也承受不了，现在是打算利用“豹1”来凑数。路透社报道截图魏东旭进一步分析指出，乌军后续在战场上，将主要把“豹1”坦克作为自行火炮使用。“豹1”火控系统落后，机动性和防护能力整体较差。如果和先进的主战坦克进行较量，“豹1”取胜的几率非常小。在进攻作战中，“豹1”也不太可能打头阵，而是跟在比较先进的、新式的主战坦克后面，作为一个后备力量去使用。此外，“豹1”也可以作为移动炮台去协助防御己方阵地；或者作为装甲火力支援平台协助作战。素材来源丨环球资讯广播《直播世界》总台记者丨魏东旭编辑丨邵一平 林维签审丨侯晨 江爱民返回搜狐，查看更多责任编辑：
