首页>>新闻>>滚动>>正文“心迹——赵孟君李志双人作品展”在柏林开幕2018-01-25 15:31:33|来源:国际在线|编辑:王涛更多史明德大使在开幕式上致辞国际在线报道(中国国际广播电台记者 阮佳闻):当地时间24日,“心迹——赵孟君、李志双人作品展”在德国柏林中国文化中心拉开序幕。本次展览将持续至2月7日,展出赵孟君、李志两位中国艺术家不久前在德国西部城市波鸿创作的51幅作品。中国驻德国大使史明德在当晚的开幕式上致辞。他指出,中德双方日益深入的文化交流活动对促进双边关系的持续发展、增进两国人民的相互理解和友谊发挥了不可替代的作用。史明德说,赵孟君和李志刚刚移居德国柏林这座迷人的文化之都,以中国艺术家的独特视角观察德国历史与现实、体验风土人情、寻找创作灵感。他们身处东西方的不同文化背景和双重语境之下,将所思所感通过视觉和绘画语言加以展现。而两人的最新作品更是从侧面反映出当下东西方文化相互交流相互借鉴的成果。开幕式合影(从左至右):赵孟君、史明德、李志、陈建阳赵孟君表示,在德国生活、游览、工作了近一年时间,让两人深切地感受到了中西方文化的博大精深,也体悟到了其中的差异与共通点。尤其在绘画的认识与表现上,德国的表现主义和随性涂鸦式的绘画风格,与中国传统的得意忘形的大写意绘画可以说是异曲同工。他与李志始终认为,艺术是人类共同的智慧结晶,无疆界、无止境。所以他在创作中追求的是“唯心”,一颗慈悲没有界分的心,而李志则是通过画表现万物皆有生命之色彩,天人合一之境界。当天开幕的画展是柏林中国文化中心2018年的开年首展。中心主任陈建阳告诉记者,赵孟君、李志两位旅德艺术家从小受中华传统文化的熏陶,在热爱本国文化的同时又不因循守旧:在文化自信的基础上,能够带着批评的眼光,对外来文化保持开放、积极的态度。他说,从两人的作品中,观众可以感受到他们对当代德国社会的深入观察、体验以及东西方两种文化对他们内心世界的剧烈冲击,相信本次画展将带给大家独特的艺术体验。史明德大使边参观展览边与赵孟君交流当天的开幕式吸引了200多名当地民众,大家的观展反馈也都十分正面与积极,对赵孟君和李志在抽象表现主义艺术领域的创作和探索赞叹不已。李志与史明德大使分享自己创作的感受许多民众驻足画作前许久观展人群中有不少年轻的身影当地民众们参观展览标签:
