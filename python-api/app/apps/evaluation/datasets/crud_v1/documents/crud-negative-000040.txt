2023-07-22 13:47，正文：原标题：韩国总统尹锡悦岳母当庭被逮捕！伪造证明攫取巨额利益被判刑南都记者获悉，当地时间7月21日，韩国总统尹锡悦76岁的岳母崔恩顺涉嫌伪造银行存款余额证明书案二审宣判，法庭驳回被告人方面提出的上诉，维持一审判决，判处崔恩顺一年有期徒刑，并将其当庭逮捕。据悉，现任总统的岳母当庭被逮捕，在韩国宪政史上尚属首次。7月21日，崔恩顺前往二审法庭。据韩联社报道，崔恩顺被控于2013年4月1日至10月11日期间，在京畿道城南市岛村洞购买土地的过程中，伪造余额证明，谎称分次存入总计349亿韩元（约合1.95亿元人民币）。同年8月7日，她还涉嫌与他人合谋，就这块地皮提起诉讼，要求退回首付款，并向法院提交了约100亿韩元（约合5600万元人民币）的伪造存款余额证明。此外，在2013年10月，崔恩顺将购买的岛村洞的房地产一半所有权转让至一名商业伙伴的女婿名下，涉嫌借名登记，违反不动产实名登记法律。2021年12月，一审法院裁定崔恩顺伪造证明罪成立，判处她一年监禁。崔恩顺认为量刑不当，提起上诉。京畿道议政府市地方法院在2023年7月21日的二审判决中表示，崔恩顺因犯罪行为攫取巨额利益，犯罪情节严重，遂下令将其当庭逮捕。二审结束后，崔恩顺的律师离开法庭，没有发表任何评论。同日，21日，韩国总统室官员也在采访中表示，对于总统岳母崔恩顺当庭被逮捕一事，总统室不宜对司法部门作出的判决结果置评。采写：南都记者 翁安琪返回搜狐，查看更多责任编辑：
