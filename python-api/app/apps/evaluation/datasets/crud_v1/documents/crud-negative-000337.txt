2023-07-24 14:18，正文：原标题：一堂科普课 让凉山州孩子走进“科技世界”华西社区报记者 程玥 街道供图“什么是芯片？”“芯片是怎么制造出来的呢？”伴随着一系列提问，一堂生动有趣的科技课在成都高新综合保税区园区党群服务中心热烈地进行着。7月22日，综合保税区园区党委携手西门子工业自动化产品（成都）有限公司和英特尔产品（成都）有限公司，安排30余名来自大凉山的孩子们参加了“爱心助学·科技筑梦”科技课。“大家知道什么是半导体吗？”来自新芯党支部的王于豪作为本次课堂的授课老师，用实物展示和风趣易懂的语言从芯片的功能作用、制造原理以及芯片在科技领域的发展格局和未来趋势进行了讲解，并现场回答了孩子们的各种稚嫩而有趣的提问。在老师的耐心指导下，孩子们用电路积木动手制作出搭载芯片的电脑主板。大家为自己亲手制作的作品兴奋不已，纷纷表示通过这次上课领略了科技的魅力，在未来要认真学习各种本领，用自己的力量推动科学技术的发展。“科学技术是第一生产力，本次活动让山区孩子们体验到科学的趣味性，更提高了大家的动手实践能力。”西园街道尚锦社区相关负责人介绍，社区将坚持为群众办实事、办好事，为更多的孩子插上梦想的翅膀。返回搜狐，查看更多责任编辑：
