石家庄市赵二街学校举行“厚植国防情 共筑中国梦”国防教育活动发布时间：2023-12-09 18:32:49来源：无线石家庄2023年12月8日，石家庄市赵二街学校举行了“厚植国防情 共筑中国梦”国防教育活动。石家庄财经职业学院的国旗护卫队展示了升旗仪式，他们口令铿锵有力、步伐整齐划一、动作规范严谨，带给学生们极大的震撼。赵二街学校党支部书记、校长史志利发表讲话，希望让赵二街学校成为传承红色基因的高地。活动在节目《少年中国说》中落下帷幕，相信我们新一代的少年一定会让国家更加美好。活动结束后，石家庄财经职业学院的国旗护卫队对赵二街学校国旗护卫队进行了指导。希望通过这次活动，赵二街学校的学生在未来的日子里，能够将国防教育的精神内化于心，外化于行，不断追求卓越，勇攀高峰！编辑：齐永涛责编：孟鹏博
