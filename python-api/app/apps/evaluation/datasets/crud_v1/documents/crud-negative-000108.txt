2023-08-01 13:55，正文：原标题：女子好奇体验“笑气”上瘾与男友同被抓近日，常州市薛家派出所民警在夏季治安打击整治行动中，抓获吸食“笑气”违法嫌疑人4名，收缴已用笑气225瓶、未开封金属瓶1134瓶、吸食工具奶油发泡机4个。据了解，常州薛家派出所民警接到举报线索，某出租房内疑似有人吸食笑气。民警立即对该出租房进行检查，发现屋内四周全是散落的金属小瓶子，并当场抓获4名吸食“笑气”的违法嫌疑人。嫌疑人陈某（化姓）被查获时还有些精神恍惚，喃喃道：“没想到你们来的这么快……”嫌疑人赵某（化姓）是陈某的女朋友，称自己因男朋友一直沉迷吸食“笑气”导致两人经常吵架，她好奇想看看是什么让她男朋友无法自拔，没想到尝试后自己也逐渐上瘾，最终成为了聚众吸食“笑气”的一员。民警依法将四名嫌疑人带所审查。目前，该案件仍在进一步调查中。警方提示：医学资料显示，“笑气能使吸食者大脑缺氧，浓度越高、剂量越大越容易出现窒息死亡。吸食者早期会出现手脚麻木无力，随后会出现走路不稳、经常性跌倒、踩棉花感等，如果不及时治疗，严重的会导致瘫痪甚至死亡。”广大市民要清醒认识“笑气”的危害性，自觉抵制并做到不好奇、不尝试、不滥用，如发现有人贩卖“笑气”供人吸食，请及时向公安机关报警。徐正华 包康悦 张斌校对 徐珩返回搜狐，查看更多责任编辑：
