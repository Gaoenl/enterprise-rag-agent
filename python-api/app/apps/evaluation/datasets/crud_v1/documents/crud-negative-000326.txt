2023-08-18，正文：重庆一男子地铁上偷拍被制服：保安与健身教练一起出手！8月16日，有网友爆料称，在重庆渝中区某地铁站内，一男子疑似偷拍被两名男子出手制服。据网传视频显示，在一地铁站内的靠墙处，一名穿黑色上衣、白色鞋子的男子被另外两名男子合力制服在地，脸涨得通红，一直死死按住手里的白色包。男子地铁上偷拍被制服，一旁有围观者说：“有人偷拍别个，被逮住了。”据知情人士透露，事发时一名轨道集团保安队员发现了这一变态行为，并立即大声制止并上前准备控制偷拍男子。不料，偷拍者竟然拒捕并挣扎反抗，这时一位健身教练路过此地，见状立即伸出援手，男子地铁上偷拍被制服。两人联手将偷拍者控制住，并将其送至地铁站的安保室。事发后，民警迅速赶到现场进行处理，而据有关部门的消息，目前这名偷拍男子已经被行政拘留。▲视频截图该视频发出后，立即在网上引起热议。红星新闻记者在抖音平台上联系到上述视频里两名参与制服的男子之一。对方告诉红星新闻，他姓刘，是一名健身教练。16日上午，另一名参与制服的男子率先留意到一名穿黑色上衣、白色鞋子的男子疑似有偷拍女性的行为，“直到出站时，他才向疑似偷拍者索要手机，让其证明自己没有偷拍。而疑似偷拍者拒绝了他，并且想离开现场。”刘先生说，当时，他刚下地铁站（大坪地铁站），看到两人在争执，起初以为是朋友吵架，后来“听到他喊‘来人帮忙，偷拍人’，我才意识到可能有人在地铁站偷拍”。于是，刘先生上前帮忙，两人将疑似偷拍者制服在地，并将其扭送到地铁的安保室，“当时带他下去（安保室）的时候，他就不反抗了，（周围）人也多了，他一直拿包挡住自己的脸。”16日，红星新闻记者就此事致电重庆市渝中区大坪地铁站，接线的工作人员表示当日上午确实有这样的事发生，但具体情况不清楚。据极目新闻报道，记者从当地有关部门了解到，偷拍的男子目前已经被行政拘留。男子地铁上偷拍被制服！(责任编辑：卢其龙 CN070)
