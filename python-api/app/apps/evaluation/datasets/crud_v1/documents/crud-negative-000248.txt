2023-08-14 20:32，正文：8月14日，“辽宁日报”微信公众号发布消息：融合十年，再启新章。辽宁报刊传媒集团（辽宁日报社）倾力打造的北国客户端更名为辽望客户端，8月14日精彩上线。消息回顾：2013年8月，辽宁日报微信公众号首发推文；2015年6月，辽宁日报新闻客户端萌新上线；2020年5月，北国客户端开启新视界；今天，我们跃迁升维，更名“辽望”，从“新”出发。对于更名后的辽望客户端，“辽宁日报”微信公众号透露，新客户端将聚焦辽宁振兴发展，记录时代恢弘篇章。以追求“原发性、独家性、原创性”为目标，专注优质内容生产。做强“新闻+”，连政声民意，通网上网下，传递社会力量的共振，让正能量澎湃大流量。视野更宽广。据北国网介绍，由辽宁报刊传媒集团（辽宁日报社）倾力打造的北国客户端，以打造东北地区最权威最强大新闻信息源为目标，已经成为辽宁省委、省政府政策宣传重要阵地、信息发布重要平台、对外宣传重要渠道、展现形象重要窗口。去年5月，北国客户端3.0版发布时曾介绍：这一版本的客户端突出3个“更”：更焕新，新字体、新标签、新布局带来更富层次感、更时尚简洁的阅读体验，优质新闻内容呈现更灵动、更智慧、更流畅。更沉浸，强化互动体验、厚植用户价值，新增话题投票、记者主页、多视角直播、弹窗海报等功能模块，解锁不一样的新闻信息新“玩法”。
