9月11日,2023年国家网络安全宣传周开幕式在福州海峡国际会展中心举行。今年的网络安全宣传周以“网络安全为人民,网络安全靠人民”为主题,围绕党的十八大以来网络安全领域取得的重大成就开展主题宣传活动,深入宣传《网络安全法》《数据安全法》《个人信息保护法》《关键信息基础设施安全保护条例》等重要法律法规、政策文件、国家标准。今年网安周期间,除开幕式外,还将举行网络安全博览会、网络安全技术高峰论坛、网络安全微视频征集,以及主题日、进基层等活动。随着互联网科技的飞速发展,网络已经渗透到我们生活的方方面面。8月28日,中国互联网络信息中心(CNNIC)在京发布第52次《中国互联网络发展状况统计报告》。《报告》显示,截至2023年6月,我国网民规模达10.79亿人,较2022年12月增长1109万人,互联网普及率达76.4%。在这个信息化、网络化的时代,网络安全问题变得越来越重要,“网络安全为人民,网络安全靠人民”为我们指明了工作重点和方向,我们需要把握“四个关键”步骤,共筑网络安全防线。把握网络安全教育“大方向”。网络安全与我们每个人息息相关,需要加大宣传力度,深入开展网络安全进社区、进农村、进企业、进机关、进校园、进家庭、进军营等活动,提高他们的网络安全意识和技能。学校和教育部门应该将网络安全教育纳入教育体系,开展网络安全知识和技能的课程和培训,提高学生对网络安全的认知和理解。此外,政府和社会组织也可以通过各种渠道宣传网络安全知识,提高公众对网络安全的重视和认识。我们每个人都应当成为网络安全的参与者,通过学习网络安全知识,提高自身的防范能力,从而在信息化时代中保障自身的权益。抓住核心技术研发“牛鼻子”。“建设网络强国,要有自己的技术,有过硬的技术”“核心技术是国之重器。要下定决心、保持恒心、找准重心,加速推动信息领域核心技术突破。”信息领域关键核心技术是网络安全和信息化工作的“命门”,对于保障网络安全具有关键作用。只有抓住了核心技术研发“牛鼻子”,我们才能够在网络安全领域取得主动权。需要加强自主创新,研发出更加安全、可靠、高效的核心技术。政府和企业应该加大对核心技术研发的投入,支持优秀的科研团队,推动技术创新和发展,掌握核心网络安全技术,降低网络安全风险。打好网络法治建设“主动仗”。随着网络技术日新月异,网络安全也会遇到新问题。需要不断建立健全网络安全法律法规。近年来,我国先后出台了《网络安全法》《数据安全法》《个人信息保护法》《关键信息基础设施安全保护条例》等多部网络安全相关法律法规,明确了网络空间各方的权利和义务,规范了网络行为,维护了网络秩序。通过制定和实施相关法律法规,对网络空间的行为进行了明确的规定和约束,保障了网络空间的合法性和安全性。同时,加强网络安全执法力度,加大对网络违法犯罪行为的打击力度,为网络安全提供强有力的法律保障,保障网络空间的公共秩序和安全。拧紧网络安全管理“总阀门”。需要建立完善的网络安全管理制度,拧紧网络安全管理“总阀门”,加强对网络设备和信息系统的监管和保护。政府和企业应该加强对网络安全的投入,建立专业的网络安全团队,采用一些先进的技术和工具,如防火墙、入侵检测系统、数据加密等,加强对网络安全事件的监测和处理。同时,还需要加强国际合作,共同应对全球性的网络安全威胁。“网络安全为人民,网络安全靠人民”,网络安全不仅是政府和企业的责任,更是每个人的责任。我们每个人都应当成为网络安全的守护者,共筑网络安全防线,营造清朗网络空间,共创网络美好未来。(金羊网 文/章平周)
