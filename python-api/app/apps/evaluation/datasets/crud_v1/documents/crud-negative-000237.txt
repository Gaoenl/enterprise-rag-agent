2023-08-10，正文：目前我国有3000多所高校，各种专业无奇不有，其中有些非常冷门，也非常新奇。 近日，一位在湖南长沙民政职业技术学院就读殡葬服务专业的尹姓大一新生，晒出了自己的课程表，让人大开眼界。这份课表上，周一到周五都排得满满当当，包括殡葬心理分析、殡葬礼仪、丧葬花艺、丧葬习俗、火化设备与技术、殡葬社会工作、殡葬应用设计、公墓陵园管理等等。甚至，还有周易知识、劳动者权益保护这样的课程，其中周易知识确实是看风水的，不过更多是应用到殡葬系里面的另外一个小专业——陵园专业。尹姓同学说，殡葬专业是学校里最热门的专业，也是最难报考的，学费一年三四千。他也是偶然看到了这个专业，并产生兴趣，深入了解后觉得各方面都很合适，目前倾向于专业中的管理与服务分支，薪资水平较高，不过也没有网传那么夸张。他说，刚开始学的时候有一点心理压力，但慢慢就适应了，更多的是学习尊重这份专业、这份职业。据了解，殡葬行业人才一直紧缺，仅仅是殡仪馆每年人才缺口就有1万人左右，而全国只有8所中高职院校开办殡葬类专业，毕业生每年不足千人。有殡葬专业老师称，就业率基本上能够达到100％，只不过薪资并不像外界传言的那么高，只是略高于平均水平，但并无显著差距，同时报考门槛并不低，连续三年都超过本科录取分数线。图源：Pixabay(责任编辑：王毅 CN096)
