2023-08-17 14:37，正文：五步工作法  全过程管理本报讯 记者李仑 通讯员董万营报道   重大事故隐患专项排查整治2023行动开展以来，山西省长治市安委办创新提出五步工作法，进一步完善安全风险预判和风险预警管控机制，努力实现问题源头治理和过程管控。长治市安委办坚持“源头上分析、系统上排查、根本上整改”理念，提出“述情、析因、追责、即改、治源”五步工作法，要求企业建立健全隐患排查制度，对排查出的各类隐患立整立改，不能立即整改的要明确整改期限，对重复出现的一般隐患和重点隐患要从隐患整改措施、整改质量、整改效果、责任单位、责任人验收等环节进行追溯，强化隐患源头治理。同时，推行“发现隐患、移交办理、信息公开、督导巡查、考核通报”全过程闭环管理，严格执行重大隐患整改销号，对照重大隐患情况逐条进行复查，确保重大隐患真正消除。在安全风险预判和风险预警管控方面，长治市安委办强化超前预判和安全风险管控，在煤矿、非煤矿山、危化品和冶金工贸等重点行业领域开展安全风险和重点自然灾害风险市级部门季预判、县级部门月预判、企业单位周预判和班组车间日预判管控工作。长治市还成立市级督导检查组，深入各县区、部门和企业开展督导检查。该市应急管理部门与市纪检监察部门出台《长治市安全生产行政执法与纪检监察衔接协作工作机制（试行）》，构建安全生产行政处罚与党纪政务处分衔接、安全生产法律法规与纪检监察法律法规衔接的工作格局，加大对应急管理部门在日常监管履职过程中发现的违规违法行为问责力度，把问责程序启动在事故发生之前，变“事后追责”为强化“事前问责”。
