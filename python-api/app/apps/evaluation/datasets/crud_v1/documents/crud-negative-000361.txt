2023-07-27 18:32，正文：原标题：湖南绥宁：开展残疾人增收技能培训7月27日，由湖南邵阳绥宁县残疾人联合会举办，绥宁县润泽职业培训学校承办的2023年度绥宁县农村残疾人“阳光增收计划”培训班在绥宁县润泽职业培训学校开班，来自全县各乡镇的100名有劳动能力的残疾人参加培训。培训现场（孙芳华 供图）此次农村残疾人阳光增收计划农业实用技术培训是绥宁县开展“我为群众办实事”的具体举措之一，是助力残疾人提升技能、致富创业、推荐就业的实招。旨在引导该县农村残疾人掌握一技之长，切实提高残疾人自我发展和创业增收的能力，促进农村残疾人的家庭经济增收，从而提升残疾人的获得感、幸福感。培训班邀请绥宁县农业农村水利局高级农艺师刘坚到场讲授优质稻种植技术。教学采取集中授课（课堂教学）+基地实训（田间教学）及课后经验交流相结合的方式进行。为绥宁县“农村残疾人阳光增收计划”培训班学员送上一场理论与实践的知识盛宴。培训将突出实用性、实效性，强化实训实践，组织学员到现代农业园区、家庭农场、农民合作社、养殖场、园艺场、种植场进行现场教学，实操演练、观摩交流提高培训质量。据了解，绥宁县残联还将为参加此次培训的残疾人发放一定的生产扶持资金，用于购买种苗、化肥、饲料、设施设备等生产资料。培训机构将根据残疾人的自身特点需求和当地优势产业、就业形势等，有针对性地开展好培训。（孙芳华 陈玉成）返回搜狐，查看更多责任编辑：
