，正文：AMD RX 7900 GRE公版显卡已在国内上市，售价5299元，这是AMD RX 7000系列显卡中唯一一款在国内上市的公版型号。 AMD RX 7900 GRE公版显卡采用了AMD最新的设计语言，三风扇散热，配备全尺寸背板，长度为28cm，双8pin供电，显示输出接口除了DP和HDMI还有全功能USB-C。 该显卡采用了80CU计算单元，拥有5120流处理器，加速频率最高可达2245 MHz，拥有80个光线加速器，单精度计算性能为46 TFLOPs，板卡功耗为260 W。显存为16GB 256bit GDDR6，无限缓存容量为64MB。 AMD RX 7900 GRE公版显卡的主要特性和功能包括：AMD RDNA 3架构，配备采用了统一的光线追踪和AI加速器且经过重新设计的计算单元，以及第二代AMD Infinity Cache（AMD高速缓存）技术，AMD RDNA 3架构可以为AAA和电竞游戏提供超快的游戏性能和极其流畅的游戏体验。 此外，AMD Radiance Display引擎可以为特定型号的DisplayPort 2.1显示器和HDMI 2.1a显示器提供先进的支持以实现超高分辨率、超高刷新率的游戏和内容创作工作负载。它还具有12位HDR和完整的REC2020色域，可在高达8K的视频播放中实现令人难以置信的色彩精度。 超高清编码功能，其编码/解码媒体引擎可提供卓越的性能，凭借完整的AV1编码/解码支持、宽色域和高动态范围增强功能带来了全新多媒体体验。 AMD表示，这款显卡可通过中国大陆主要电商零售商和全球特定的SI合作伙伴购买。本文属于原创文章，如若转载，请注明来源：AMD RX 7900 GRE公版显卡国内上市：售价5299元https://news.zol.com.cn/827/8270215.html
