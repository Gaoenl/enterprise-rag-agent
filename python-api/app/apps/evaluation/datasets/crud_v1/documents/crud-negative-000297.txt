2023-08-17，正文：最近热度很高的网红“铁头惩恶扬善”又一次站在了舆论的旋涡上，在打假三亚海鲜、举报杭州新东方违规补课后，14日铁头为新疆农产品带货，结果被网友疯狂嘲讽，直播只能草草结束。多个商家对封面新闻记者表示，在直播前并不知道铁头这个人。16日，铁头发布视频，承认自己直播翻车，并承诺不收取一分佣金，待粉丝达到500万时再来新疆助农直播。在直播后多个商家被网友私信，指责为何与“铁头”合作，有店铺被恶意差评掉星，商家几乎下架全部商品，纷纷宣布停止与“铁头”合作，“本来是好事，没有想到会这个样子。”张先生告诉记者，还有客服被骂哭写道歉信。至于对此事件的损失，有商家表示自己认栽，也有商家表示已经走法律程序了。01直播一小时草草收场被多家店铺取消合作“兄弟们，很荣幸接到邀请，我将开启直播助农！”在曝光杭州新东方后，网红“铁头”发布视频，称自己接到邀请，将前往新疆直播带货。8月14日晚，“铁头”在新疆进行了第一次带货直播，没想到严重“翻车”。当晚，他为多个商家的产品进行广告代言，直播间内挤满了网友，但网友却唱起反调，“支持新东方”“现在敢卖货，以后就敢收钱”……不难看出网友评论矛头剑指“铁头”曝光杭州新东方事件，在相关视频的评论区，还有很多网友表示：“买了两份，一份退货，一份送检”……最终，“铁头”开播一个小时后草草收场，一名维护“铁头”的工作人员和网友还发生了口角，吵了起来。
