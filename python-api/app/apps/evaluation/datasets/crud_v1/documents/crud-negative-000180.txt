2023-08-06 23:51，正文：原标题：200多个家庭“爱心集结” 浦江镇举行仲夏夜护苗亲子慈善嘉年华活动8月4日夜晚，闵行区浦涛市民健身中心足球场、篮球场上空灯火通明，场内人声鼎沸，热闹非凡。一场浦江镇“萌娃‘嬉’夏 快乐‘暑’数不尽”仲夏夜护苗亲子慈善嘉年华活动，吸引了200多个亲子家庭欢聚一堂，一起为慈善事业贡献爱心，共同体会亲情快乐，感受幸福生活。浦涛市民健身中心足球场被分成了南北两个区域。北半个场地上正在举行2023年“奔跑吧少年”上海体育联赛——竞技类活动。活动项目有“合纵连横”“誉满全球”“百步穿杨”“投桃报李”“八面玲珑”。每个项目前众多亲子家庭排起了队伍，有序进行着游戏大比拼，以快乐健身的方式，在游戏中创智慧、在运动中获健康、在竞争中善合作。足球场南半场搭建的大舞台上，浦江小囡们正在表演着精彩的节目。小演员们的一举手一投足让台下的观众们一会儿飞跃千里，穿越时空，去领略西域塞上的灿烂文化；一会儿去感受夸张的舞步，力量感实足的肢体表演带来对未来的无限憧憬，表现出无所畏惧、勇往直前的精神；小演员们演奏的架子鼓、陶笛、古筝，阵阵乐声时而铿锵有力、时而委婉舒展，赢得台下观众们阵阵掌声。活动上，浦江镇党群办主任徐慧、浦江镇文体中心主任王逸娜为参加本次慈善捐赠的太古可口可乐上海申美、六号工厂、上海新体文化发展有限公司等7家爱心企业颁奖。浦江镇党群中心书记张丽和浦江镇文明办副主任瞿钧为浦江小囡爱心小画家颁奖。爱心企业与小画家们慈善画作拍卖所得款项将全部捐给浦江镇慈善工作站。篮球场上南、北两边摆满小摊位，形成了一个小市集，各位摊主奇思妙想用尽招数招揽着顾客……据悉，每个摊位小摊主所获利润也将捐赠给浦江镇慈善工作站。（浦江镇供图）返回搜狐，查看更多责任编辑：
