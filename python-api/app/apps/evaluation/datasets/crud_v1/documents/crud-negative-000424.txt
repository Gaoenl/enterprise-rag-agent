2023-08-18 14:30，正文：原标题：燕赵山海·公益检察 | 曲阳县检察院检察长到党校作专题授课为进一步落实最高检关于“公益诉讼进党政机关、进学校”的工作部署，深入推进“燕赵山海·公益检察”护航美丽河北建设专项监督工作走深走实，近日，曲阳县检察院检察长史明巍应邀来到曲阳县委党校，为2023年曲阳县青年干部培训班60名副科级青年干部开展公益诉讼检察专题授课。课上，史明巍以《以“益心向阳”之笔，描绘美丽河北建设之曲阳场景》为题，从公益诉讼检察制度出台的背景、公益诉讼检察制度确立和发展的历程、公益诉讼检察的分类、公益诉讼检察的法定领域等方面深入浅出地介绍了公益诉讼检察制度，并结合该院近几年办理的公益诉讼保护典型案例，向听课学员全面介绍了六年以来曲阳县检察院公益诉讼检察在护航美丽曲阳建设方面的成就。同时聚焦检察机关正在开展的 “燕赵山海·公益检察”护航美丽河北建设专项监督活动，就如何辩证看待检察机关与行政执法机关之间形成良性互动、有效监督、合作共赢进行了深层次的交流。史明巍表示，公益保护，谁都不是旁观者，检察公益诉讼所取得的成果，也必然是在共建共治的基础上实现利益和生态的共享。检察机关开展公益诉讼检察工作离不开党委政府的支持，需要各行政机关的理解与支持，希望在座的优秀青年干部对公益诉讼检察工作有更深入的了解，更加关注和支持公益诉讼检察工作，携手做好公共利益的守护者，坚持守护曲阳百姓幸福美好生活的目标，共同描绘美丽曲阳新画卷。听课学员纷纷表示，通过史明巍检察长的专项讲座，对检察机关公益诉讼检察工作有了全面的了解，史明巍检察长的授课内容丰富、脉络清晰，既有理论深度，又有视野宽度，重点突出，通俗易懂。在今后的工作中，一定会依法行政，积极配合检察机关公益诉讼检察工作，为建设经济强县、美丽曲阳共同努力。曲阳县检察院将以此次专题授课为契机，持续加强公益诉讼检察宣传力度，不断扩大公益诉讼检察影响力，讲好曲阳公益诉讼检察好故事、传递曲阳公益诉讼最强音，让公益诉讼检察更加贴近人民群众，深入人心。为“燕赵山海·公益检察”护航美丽河北建设专项监督营造浓厚的舆论氛围，为守护公益、建设美丽河北贡献检察力量。返回搜狐，查看更多责任编辑：
