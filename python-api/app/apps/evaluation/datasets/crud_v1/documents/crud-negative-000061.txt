2023-08-08 09:18，正文：原标题：碧江区坝黄镇：送“反诈电影”到村入寨 村民“沉浸式”体验诈骗套路“现在的诈骗手段真是让人防不胜防啊!今天学到了很多，非常感谢你们!”近日，在坝黄镇龙井社区，坝黄镇司法所、综治办、派出所联合区联通公司推出的“反诈露天电影”，吸引了不少村民观看。为进一步扩大反诈宣传的深度和广度，构建多方位、全覆盖的防诈骗体系，工作人员借助微影院多媒体在各村(社区)巡回放映露天电影的契机，扎实开展反电信网络诈骗宣传活动。工作人员为村民播放了《冒充公检法》《套路贷》等一系列反诈短视频，影片以通俗易懂的方式，揭露了冒充公检法、网络刷单、网络贷款、冒充客服、虚假购物、注销“校园贷”等多种典型诈骗的常用伎俩，潜移默化中让群众了解各类诈骗手段的惯用伎俩，掌握识诈防诈技巧。在场村民一边拿着手机拍摄学习，一边互相讨论剧情。在“反诈露天电影”放映前，工作人员还通过发放防范电信网络诈骗宣传资料、面对面讲解等形式，向群众介绍了最近兴起的电信诈骗方式，提醒大家警惕各种电信网络诈骗陷阱，拒绝利益诱惑，并指导群众下载安装国家反诈中心APP，帮助大家提高识骗能力。“这种宣传方式生动又新颖，时时刻刻提醒我们防范电信诈骗。防范打击电信网络诈骗不仅是党委政府的事，我作为新时代大学生，也要积极为反诈宣传出力!”暑假回家的大学生杨鹏说道。下一步，坝黄镇将持续在辖区各个村落巡回放映“反诈露天电影”，让反诈知识入心入脑、人人皆知，不断增强群众防范电信网络诈骗的意识和能力，为群众的财产安全保驾护航。(碧江区人民政府网)返回搜狐，查看更多责任编辑：
