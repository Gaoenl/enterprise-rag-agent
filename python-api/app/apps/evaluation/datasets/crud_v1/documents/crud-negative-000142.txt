记者：高倩，正文：昨天，中国爱乐乐团正式公布2023-2024音乐季21场演出安排。这将是乐团位于朝阳区工体东路的新团址启用前的最后一个音乐季。9月2日至4日，音乐季开幕系列音乐会将由艺术总监、首席指挥余隆执棒，在国家大剧院音乐厅连续3天上演，届时，左章、鲍杨、王致仁、鞠小夫、王雅伦5位青年钢琴家将接力演绎拉赫玛尼诺夫全部钢琴协奏曲，致敬拉赫玛尼诺夫诞辰150周年。他们展现出的“青春之力”是贯穿音乐季的主线之一，林冰、莫漠、周颖、金郁矿等一系列受到乐坛瞩目的青年演奏家、指挥家将首次与中国爱乐乐团合作。曾在上个音乐季里惊艳亮相的柏林爱乐乐团中提琴首席梅第扬将再次回归，带来音乐史上最著名的中提琴作品之一施尼特凯《中提琴协奏曲》。随着国际文化交流的快速恢复，“世界之声”将成为音乐季中另一条备受关注的主线。指挥大师克里斯托弗·艾申巴赫、钢琴家斯蒂芬·霍夫、小提琴家莱昂尼达斯·卡瓦科斯与丹尼尔·霍普、男中音歌唱家马蒂亚斯·格内、女高音歌唱家佩列佳特科等国际音乐家将重返北京，带来马勒、贝多芬、勃拉姆斯、肖斯塔科维奇、谭盾等作曲家的名篇。此外，张国勇、水蓝、张昊辰、吕思清、王健、张立萍、濮存昕等华人艺术家也将齐聚音乐季，绽放不同艺术形式的动人色彩。来源：北京日报 记者：高倩流程编辑：u060                             如遇作品内容、版权等问题，请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话：010-85202353
