2023-08-09 15:01，正文：原标题：南奥塞梯外长：俄罗斯15年前作出的关于保卫南奥塞梯的决定是正确的【南奥塞梯外长阿赫萨尔∙焦耶夫对卫星通讯社称，俄罗斯2008年8月关于保护南奥塞梯免受格鲁吉亚军队攻击的决定是正确的。】南奥塞梯外长提到，2008年8月，在全世界观看北京夏季奥运会开幕式的同时，按照北约标准训练的格鲁吉亚军队试图占领南奥塞梯。他说：“凭借俄罗斯和奥塞梯维和人员、军人和民兵的勇敢精神和坚韧不拔，南奥塞梯挺住了。俄罗斯联邦领导人的唯一正确决定——迫使侵略者实现和平和承认南奥塞梯共和国独立——是其稳定发展和对安定未来信心的保证。俄罗斯是南奥塞梯和平与安全的可靠保证方。”外长焦耶夫指出，过去这些年来，俄罗斯和南奥塞梯间形成了坚实的双边条约法律基础，涵盖了所有合作领域——国防、对外政策、执法、社会经济、文化等。他强调称：“为修复被格鲁吉亚侵略完全破坏的共和国基础设施进行了大量繁重工作，南奥塞梯的社会经济发展项目正在投资计划框架内实施。”格鲁吉亚2008年8月8日凌晨用“冰雹”火箭炮炮轰南奥塞梯，格鲁吉亚军队袭击了共和国并破坏了其首都茨欣瓦利的一部分。俄罗斯为保护其中许多获得了俄罗斯国籍的南奥塞梯居民，派军队进入共和国，并在五天战斗行动后将格鲁吉亚军人赶出该地区。2008年8月26日，莫斯科承认阿布哈兹和南奥塞梯的主权。俄罗斯领导人多次表示，承认两个前格鲁吉亚自治共和国的独立反映了当前的现实，不应重新考虑。格鲁吉亚依然不承认阿布哈兹和南奥塞梯为独立国家，并视其为自己的地方。返回搜狐，查看更多责任编辑：
