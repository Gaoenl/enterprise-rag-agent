2023-08-07 11:06，正文：原标题：5名游客自驾被困涵洞 民警及时赶到救出“你好，是正蓝旗车站派出所吗？我和家人被困在涵洞了，眼看暴雨越下越大，涵洞积水越来越深，你们能过来帮帮忙吗？.......”电话那头焦急求助的是一位名叫王湘灿的湖南湘乡游客，接电话的是锡林浩特铁路公安处正蓝旗所民警仝仲帅，接报后，仝仲帅立即请示所领导，并在所领导的带领下立即赶赴报警人所说的塔锡线217公里111米涵洞内。到达现场后，民警不顾暴雨合力将涵洞内的车辆推出，在保证人员和车辆安全后，民警详细了解了情况：2023年8月2日，王灿湘（男，33岁，湖南省湘乡人）租赁车辆陪同家人4人自驾到草原游玩，当日19时20分，突遇暴雨天气被困在塔锡线217公里111米涵洞内，因暴雨一直未停，且涵洞积水越来越深，担心车辆无法驶出，遂通过报警标识拨打正蓝旗所电话请求帮助，民警如此迅速赶到并帮助他们一家人脱困，让他们充满了感激。与王灿湘一家人告别后，民警将该涵洞积水情况通知正蓝旗线路车间，要求及时整改涵洞积水隐患。铁路警方温馨提示：夏季草原降雨频繁，切勿盲目强行通过不熟悉的积水路段，更不要到涵洞内躲避，以免出现险情，如遇危险，第一时间通过报警标识电话求助，等待救援。来 源：锡林浩特铁路公安处通讯员： 张媛返回搜狐，查看更多责任编辑：
