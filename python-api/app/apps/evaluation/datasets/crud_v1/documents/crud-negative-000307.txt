2023-08-16，正文：工作人员疑似用弹弓驱赶猴子引争议 官方回应：为空打吓唬，并无实质伤害近日，网友发布视频，画面中贵州黔灵山公园的工作人员拿着弹弓对远处的猴子进行“射击”驱逐，猴子受到惊吓后快速逃离。部分网友认为猴子为保护动物，此举欠妥，景区回应为了保证游客的安全，驱赶猴子有时会用弹弓，是空打吓唬它们，并没有造成实质伤害。贵州黔灵山公园中的猴子种类为猕猴，属国家二级重点保护野生动物，对于视频中景区工作人员的行为，评论区有网友认为此举不太妥当，视频发布者则称工作人员是在保证游客安全和旅游体验的前提下施行驱赶，再加上距离相隔较远，只是为了吓唬猴子。如果没有工作人员，猴子会跑下来扒游客的书包，很容易误伤旅客。九派新闻联系黔灵山景区热线，工作人员表示为了保护游客的日常安全，有时确实会在驱赶猴子时使用弹弓，但都是空打吓唬，起到警示驱逐的作用，并没有对猴子造成实际伤害，感谢公众关心。我们应该理性看待中国景区工作人员使用弹弓驱赶猴子的行为。保护游客的安全是合理的，但在驱赶猴子时应该注意使用合适的方法，避免过度使用武力或虐待动物。同时，保护生态环境和加强公众教育也是解决猴子问题的重要途径。只有综合考虑各方面的因素，我们才能更好地处理与猴子相关的问题，实现人与自然的和谐共存。(责任编辑：黄昱植)
