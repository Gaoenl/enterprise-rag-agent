2023-08-10 14:45，正文：原标题：紫云县白石岩乡持续开展“进村入户”禁毒宣传活动为了进一步加大禁毒宣传教育的力度，增强辖区群众拒毒防毒的意识。以“禁毒宣传进万家”为主线，8月9日，紫云县白石岩乡禁毒办组织禁毒志愿者和平安专干开展进村入户禁毒宣传活动，旨在加强禁毒宣传教育力度，筑牢群众拒毒、禁毒思想防线，汇聚全民力量共同抵御毒品危害。禁毒志愿者向群众发放禁毒资料。活动中，通过发放禁毒宣传册、禁种铲毒宣传资料、禁毒法知识手册等方式向广大村民群众宣传禁毒法律知识，并运用通俗易懂的语言让群众了解毒品替代品的危害，同时，号召广大群众一定要养成健康的生活方式，远离毒品，减少和毒品的接触，不让毒品害自身，不让毒品毁家庭，人人争当禁毒宣传员，积极参与到禁毒斗争中，为维护家庭幸福、构建和谐社会共同努力。本次活动共发放宣传资料200余份，为群众解答疑惑60余人次，受教育人数达300余人次。禁毒宣传进村入户，扩大了禁毒宣传覆盖面，让辖区村民群众对毒品有了更加深入的了解，提升他们禁毒、识毒、防毒和拒毒能力，调动他们参与打击毒品犯罪的积极性，增强“禁种铲毒，人人有责”的社会责任感。(图/文 王应昌)返回搜狐，查看更多责任编辑：
