2023-07-28 07:01，正文：原标题：外媒炒“中国利用云壤军事基地对抗美国”，柬埔寨官员：不实信息【环球时报综合报道】英国《金融时报》日前称中国援助柬埔寨建设的云壤军事基地即将完工，“可以停泊航空母舰”。该报由此对基地的用途进行无端揣测。27日，“美国之音”报道称，柬埔寨国防部发言人春速杰否认了“中国将利用该基地在该地区对抗美国”的猜测。该发言人向“美国之音”证实，云壤军事基地的工作将很快完成，但他表示不清楚正式启用的日期。对媒体有关基地用途的部分猜测，春速杰表示，“我很遗憾有这些不真实的信息。柬埔寨很小。他们（一些国家）对我们国家有恶意。”“某些国家不承认真相，而且它们还散布不真实的信息。”美西方媒体从2019年就开始炒作云壤军事基地，称“中国海军将使用该基地”。对此，柬埔寨国防部数度出面驳斥不实报道，之后又史无前例地开放云壤海军基地，允许包括来自美、英、法等国主要媒体在内的记者团，前往云壤海军基地参观，以证明基地建设并不存在允许中国海军使用的情况。2021年，柬埔寨首相洪森对美方炒作基地一事不满，表示基地不再欢迎美国。2022年，柬埔寨再次重申“没把中国军队藏在云壤海军基地”2020年，柬埔寨拆除了云壤军事基地中美国修建的一些设施。2022年，中国援建柬埔寨云壤海军基地升级改造项目正式开工。（文简）返回搜狐，查看更多责任编辑：
