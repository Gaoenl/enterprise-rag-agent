2023年07月20日，正文：                                                                 今天（7月20日）开始至23日，北方新一轮降雨过程将发展起来，华北、黄淮和东北地区将自西向东出现降雨，河北、辽宁等地可能出现暴雨。北方此轮降水持续时间较长、雨势明显，相关部门需警惕降雨可能带来的次生灾害，公众需密切留意临近预警预报信息，做好防范措施。另外，四川盆地、江淮南部等地的雨势也比较强劲。其中，今天安徽中部、江苏中部、湖北东部、四川东南部、重庆中西部等地部分地区有暴雨。                                  【责任编辑：侯歆钰】
