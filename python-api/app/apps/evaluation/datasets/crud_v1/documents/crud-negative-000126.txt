2023-07-31 19:58，正文：原标题：广州地铁站一男子持水果刀挟持过路女子，两分钟被制服，警方：女子无大碍极目新闻记者 余渊 实习生 余立天7月31日，有网友发视频称，广州某地铁站内一男子持刀挟持一名女子，此事引发关注。7月31日下午，辖区警方告诉极目新闻记者，被挟持女子并无大碍，具体情况正在调查中。视频显示，一名男子从背后环抱住一名女子，疑似手持刀具进行挟持，现场有工作人员正在处置此事。有网友发帖称，被挟持女子曾喊“他有刀”，后人群开始疏散。男子持刀挟持过路女子（来源：视频截图）极目新闻记者就此事致电广州地铁，客服人员表示，该事件为治安事件，具体情况可咨询警方。31日下午，辖区派出所工作人员告诉极目新闻记者，被挟持女子并无大碍，案件具体情况正在调查中，稍后会进行通报。广州市公安局公共交通分局就此事通报称，7月31日8时53分许，嫌疑人陈某（男，25岁）在广州地铁7号线员岗站G口安检门外，持便携式水果刀胁迫1名过路女子。广州警方接报后立即启动应急处置机制，于8时55分快速将嫌疑人制服。事件中无人受伤，车站运营秩序未受影响。目前，嫌疑人陈某已被公安机关依法刑事拘留。案件正在进一步侦办中。河南泽槿律师事务所主任付建认为，男子在公共场合持刀挟持女子可能涉嫌绑架罪。根据《刑法》第239条规定，以勒索财物为目的绑架他人的，或者绑架他人作为人质的，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产；情节较轻的，处五年以上十年以下有期徒刑，并处罚金。（来源：极目新闻）返回搜狐，查看更多责任编辑：
