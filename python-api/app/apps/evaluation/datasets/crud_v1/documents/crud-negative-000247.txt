近日,在怀集站候车室内发生惊险一幕,一名女子在候车室突然晕倒,怀集站派出所执勤民警李军及时发现后对其救助。2021年2月19日,怀集站正是客流返程高峰期间,候车室人流涌动,怀集站派出所民警接到安检员的报称:一名女性旅客突然晕倒在候车室,民警迅速赶往现场,到场后发现,一名女性旅客瘫倒在地上,只见她面无血色、嘴唇发白、意识模糊,经向在一旁陪同的亲人了解,晕倒旅客是封开县人,计划是搭乘C6941次列车前往广州南站,因今天早上行程匆忙,未来得及吃早餐,进而引发低血糖导致晕倒。民警李军得知情况后,马上带来一些糖果及蜂蜜水给该名旅客,并搀扶到一旁休息,经过20多分钟后,该名旅客逐渐清醒,并能站立,后在民警和车站工作人员的护送下,顺利搭乘上C6941次列车。警方提示:广大旅客在乘车前提前合理安排时间,在出行前,应根据自己个人的身体状况,适当进食,以免影响自己的身体健康,从而耽误行程。如在出行过程中感到身体不适,请及时向民警或现场人员求助。通讯员:肖坤友 温朝鑫
