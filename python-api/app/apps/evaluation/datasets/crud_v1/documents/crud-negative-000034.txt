2023-08-14 09:45，正文：活动现场。深圳新闻网2023年8月14日讯（记者 凌安儿 通讯员 李繁）为扎实开展安全宣传“五进”工作，充分发挥基层党组织的战斗堡垒作用和在职党员的先锋模范作用，近日，大鹏新区规划土地监察局以“大鹏新区应急日”为契机，深入南隆社区开展党员志愿服务暨安全宣传进社区、进家庭活动。派发手册。活动中，新区规划土地监察局的党员们积极向社区居民普及如何正确使用燃气、燃气安全检查、灭火器的使用方法，以及在不同情况下发生初期火灾的处理方式，重点向居民介绍了家庭日常用火、用电、用气安全，私拉乱接电源线路的危险性和私自占用楼道、堵塞消防通道的危害，热心解答群众关心的安全生产问题。现场派发了《家庭安全隐患自查清单》《应急疏散与紧急逃生知识指导手册》等安全知识手册共计300余份，接受群众咨询120余人次，充分引导群众树牢安全理念、提升安全意识，共建幸福家园。“防火必须人人有责，自救必须人人都懂。”党员志愿者李繁提出消防安全的重要性，倡导各位居民朋友提升消防安全意识，掌握消防自救本领。此次宣传活动，从思想上提升了居民群众的消防安全意识，提高了大家的自防自救能力，真正将消防安全知识宣传到户、深入民心，掀起了消防安全宣传热潮，营造了浓厚的安全氛围，对全面构筑平安、和谐的消防安全环境起到了积极作用。下一步，新区规划土地监察局将持续结合“普直联”“党员志愿”“全国法制宣传日”等形式载体，“零距离”“全覆盖”深入社区开展安全宣传活动，进一步提高居民家庭消防安全意识和隐患自查自纠能力，全力维护辖区安全稳定的生产生活秩序，切实筑牢消防安全“防火墙”。
