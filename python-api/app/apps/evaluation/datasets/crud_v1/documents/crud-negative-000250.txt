中新经纬客户端6月23日电 塑料拖鞋,是每个家庭最平常的物品,也是生活的必需品。深圳市消费者委员会网站23日发布《2020年塑料拖鞋比较试验报告》,报告显示,有拖鞋样品的邻苯二甲酸酯类含量超标上百倍,涉及回力、快鹿、集美三个品牌。图片来源:深圳市消费者委员会网站据介绍,本次比较试验样品选择参考前期消费调查及各大电商平台销售情况中消费者关注度高、销量好的塑料拖鞋产品,由工作人员以普通消费者的身份在天猫、京东、网易严选、唯品会、淘宝、考拉海购、拼多多、小米有品等网络电商平台和深圳miniso、天虹、山姆、沃尔玛等线下实体店进行匿名购买。本次15款样品中,8款为一体式鞋底拖鞋,涉及品牌为:回力、南极人、快鹿、上舒、POSEE(朴西)、集美、miniso、卡骆驰。7款为组合式鞋底拖鞋,涉及品牌为:科柔、鞋博士、菲尔芙、宝人、网易严选、利达妮、george.。从比较试验结果看,15款塑料拖鞋所检的使用性能及感官指标均符合我国现行轻工行业标准及化工行业标准要求,部分产品的化学安全性未满足欧盟法规的相关要求,例如邻苯二甲酸酯类、短链氯化石蜡等指标,使用性能整体表现优秀。具体来看,6款塑料拖鞋样品被检出含邻苯二甲酸酯类塑化剂,4款样品超出欧盟标准限量要求。据悉,邻苯二甲酸酯类物质迁移性高,很容易从产品中释放,可通过呼吸道、消化道、皮肤等途径进入人体,具有类似荷尔蒙的内分泌干扰特性,生殖毒性,可能干扰内分泌,影响生殖和发育。目前我国现行标准暂未对拖鞋产品中邻苯二甲酸酯类做限量要求,本次比较试验参考欧盟REACH法规对邻苯二甲酸酯类进行检测。结果显示,15款塑料拖鞋样品中,有9款样品显示“未检出”,2款样品有检出,但远低于标准的限值要求,符合相关标准要求。有4款塑料拖鞋样品中邻苯二甲酸酯类含量未能满足欧盟REACH法规要求(<1000mg/kg),其中检出值最高为淘宝电商平台购买的月销售43w+,累计评论105w+的集美拖鞋,其被检出的邻苯二甲酸酯类含量(313015mg/kg)是标准限量要求的313倍。其次为快鹿拖鞋、回力休闲鞋、上舒家居防滑漏水拖鞋,被检出含量分别是290640 mg/kg、195286 mg/kg、2123mg/kg。另外,15款样品多环芳烃含量测试均符合欧盟标准要求,表现优秀。2款塑料拖鞋产品被检出含有短链氯化石蜡,其中于天猫超市购买的快鹿拖鞋被检出含量是标准限量要求的15倍。据介绍,短链氯化石蜡具有生物毒性且有累积性,长期存在于环境中的短链氯化石蜡会在动物和人类体内积蓄,可能影响人体以及生物的免疫系统和生殖系统,并造成环境污染。此外,比较试验结果显示,在防滑性能方面,15款塑料拖鞋防滑性能整体远高于澳大利亚和新西兰地面安全摩擦系数安全等级要求,表现优异。深圳市消费者委员会提醒,尽量选购一些无气味或气味较淡的拖鞋;注重防滑的消费者可在选购时注意鞋底材质及纹路设计;选择拖鞋以长度刚刚塞满足部为好,避免行走过程中因鞋过长被绊倒;建议至少一年更换一次拖鞋,且鞋底磨损严重应提前更换避免打滑摔伤。(中新经纬APP)(责任编辑: HN666)
