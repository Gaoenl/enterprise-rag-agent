2023-07-26 18:57，正文：原标题：张家港高新区（塘桥镇）：党建聚合力，护航青少年茁壮成长为弘扬爱国主义精神，在辖区青少年心中播撒下爱国爱党的种子，张家港高新区（塘桥镇）何桥村党委组织开展丰富多彩的活动，激励他们树立远大理想，传承红色精神，争做新时代好少年。感悟初心，传承红色基因“小英雄王二小从容地把日本鬼子引入八路军的包围圈，自己却献出了宝贵的生命，我非常敬佩他，他的机智，勇敢，不怕牺牲的精神值得我们学习!”在“红色经典润童心 书香陪伴共成长”亲子阅读会上，张钰瑶小朋友在听完党员志愿者讲述的《小英雄王二小》的故事后说道。围绕未成年人红色教育，何桥村党委开展“红色经典润童心 书香陪伴共成长”亲子阅读会，“党的光辉照我心 学习二十大精神”红色宣讲会，“小小护旗手 向祖国致敬”等活动，通过红色系列活动，引导一片童心齐向党。磨炼意志，打好人生底色何桥村党委组织策划“我是小兵我爱国”训练营活动，穿上军装，戴上军帽，孩子们兴奋而好奇地跟着教官学习立正、稍息、列队、蹲姿、坐姿、停止间转法等训练项目，虽然有些动作还不够标准，但是孩子们认真、努力保持平衡力求笔挺的身影，成了最亮丽的一道风景。通过艰苦军训，孩子们少了份娇气，多了份坚强，在刻苦训练中磨练了意志，也在孩子们心里种下了一颗颗坚毅的种子。点滴积累，争做时代新人“不一会儿，八路军都到齐了，鬼子知道受骗了，开出一排排子弹.....”塘桥中心小学三8班钱嘉乐同学声情并茂地讲述着《鸡毛信》这个党史小故事。何桥村组建了青少年红色宣讲团，他就是其中的成员之一。通过开展红色宣讲、品读名人优秀家风家训等活动，何桥村给孩子们搭建展示舞台，也让孩子们在宣讲中表达了他们对党和祖国的无限热爱。下一步，何桥村党委将结合青少年成长实际，开展更加丰富多彩的实践活动，引导青少年们感党恩，听党话，跟党走，让红色基因代代薪火相传。扬子晚报/紫牛新闻记者 黄玉琴校对 陶善工返回搜狐，查看更多责任编辑：
