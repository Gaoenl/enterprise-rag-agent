2023-08-02 12:02，正文：原标题：兴业银行济南分行多举措开展防范非法集资宣传活动记者 李孟霏 通讯员 许淑霞为严厉打击非法集资，从源头上遏制非法集资多发态势，提高社会公众的金融风险意识，兴业银行济南分行多举措开展防范非法集资宣传活动，其辖内兴业银行威海分行按照工作部署，认真做好宣传活动。该行以营业网点为宣传主阵地，各营业网点电视滚动播放防非法集资宣传片，在厅堂显著位置摆放“防范和打击非法集资活动宣传册”及宣传展架，方便公众阅览，并由大堂经理对等待业务办理中的客户进行宣讲，重点对非法集资的特征、主要表现形式、常用手段及社会危害等进行全面宣传，充分发挥营业网点的宣传阵地作用。对老年群体开展专项宣传教育和风险提示，提醒老年人要牢记“三要三不要”，使群众进一步树立遵法守法的意识和观念，引导群众正确认识非法集资的风险和危害。为进一步拓展宣传范围，调度群众主动学习防范非法集资知识和参与宣传的积极性，提升防范非法集资宣传教育的精准度和普及率，增强社会公众风险防范意识，我分行营业部及社区支行，联合驻地社区、派出所，走进小区、健身广场、商超、集市等，开展主题为“守住钱袋子 护好幸福家”的宣传活动。宣传人员通过悬挂条幅、发放宣传折页等多种方式，向过往居民介绍非法集资的特征和惯用手段，对显示生活中的典型案例“兼职刷单诈骗”、“冒充客服诈骗”、“交易网游装备诈骗”等进行深入剖析、现场答疑解惑。通过户外宣传，共发放宣传手册、折页等共计800余份，有效增强了居民的风险意识和辨别能力。此外，为加强对员工的培训教育，该行积极组织全员参加全国防范非法集资线上知识答题赛活动，推动全员参加防非法集资线上知识竞赛，学习了解防非知识。持续加大 “员工行为十三条禁令”宣贯力度，通过规章制度学习、合规案防知识测试等多种形式，引导员工自觉远离和抵制非法集资等各类违法违规行为。下一步，该行将持续开展“防范非法集资”宣传活动，不断扩张活动覆盖面，实现公众金融知识教育的常态化和长效化，让社会公众真正了解金融知识，实现金融普惠理念，在全辖范围内营造良好的防范打击非法集资活动的舆论氛围。同时，持续完善和健全防范非法集资的体制机制，通过反洗钱监测预警系统的日常排查，加大对疑似集资账户的排查力度，建立健全风险管控的长效机制，从源头和根本上预防和减少非法集资风险事件发生。返回搜狐，查看更多责任编辑：
