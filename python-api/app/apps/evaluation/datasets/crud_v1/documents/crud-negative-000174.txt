2023-08-08 18:12，正文：原标题：安全警示丨压线抢道“驶不得” 发生事故负全责！高速行车压线抢道隐患大然而不少驾驶人并未意识到这种行为的危害性▼安全警示8月5日，信阳高速交警支队五大队接报警：大广高速寨河站上站口，一辆小型普通客车与一辆半挂货车发生剐蹭。执勤民警迅速达到现场，看见寨河收费站上站匝道口处，一辆晋L半挂货车与一辆浙A小型客车车头碰在一起，车身处都有不同程度损坏。两名驾驶员站在车旁各执己见，相互争吵指责对方，民警上前询问事情原委时，两人的情绪都很激动，争吵不休。民警通过调取收费站监控录像，查明了事发经过: 半挂车从左侧车道驶向收费站，准备上高速，提前压着分离车道的导流线变道，却没注意观察右侧车道小车正开过来，两车就这样撞上了。民警批评教育了半挂车驾驶员，半挂车驾驶员看过监控录像，态度转变，主动承认是自己分心驾驶、压线抢道酿成事故，自愿承担事故的全部责任。驾车行驶在高速公路上经常要通过收费站一起学习过收费站的注意事项吧！河南高速交警提示1.应该提前减速、保持车距：驾车通过ETC通道，要减速观察后通行，避免发生事故，碰到前车无法通过的时候应与其保持距离，方便其驶离该道。2.切勿随意变道、加塞：在进入收费广场后，为了少排队，建议进入收费站前要提前选好通过道口，尽量避免连续或随意变道、加塞。3.不能随意停车、上下车：有些驾驶员把收费站广场当成停车等候区，其实这是不允许的，为了避免发生事故，请不要选择在收费站停车等候或集中下站上下客。4.不做影响交通安全的行为：驾驶员通过收费站区，不要掉以轻心，要集中精力，保持安全车距，降低车速，杜绝分心驾驶或做一些影响安全驾驶的行为。供稿 | 信阳高速交警王方杰、杨晓丽返回搜狐，查看更多责任编辑：
