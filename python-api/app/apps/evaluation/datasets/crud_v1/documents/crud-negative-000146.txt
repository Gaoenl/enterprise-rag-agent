2023-08-16，正文：以往在人们的印象中，只要提起城管，大家的脑海中都会浮现一些城管与摊贩的不愉快过往，或者是暴力执法行为。所以，对于大多数的城管人员，民众也都是避之不及，可以说对城管人员十分的抵触和排斥！可是，就在8月14号在山东青岛，一女子在公园内卖东西，城管多次劝离未果后上前要将女子商品带走做进一步处理，而女子则一遍遍地重复喊话“你别抢我东西啊”！这个视频被曝光在网上后，迅速引发了广大网友的一个关注和热议！然而这次，让人感到意外的是，此事件在网上持续发酵后，人们纷纷对青岛城管的做法表示支持和赞成，认为任何事情都应该换位思考，你不容易，我也不容易啊！从网传视频中可以看到，在山东青岛，一名女子在公园内卖荧光棒之类的物品。一位城管正在公园里巡逻工作，看到女子在公园不允许的地方叫卖荧光棒，于是城管便上前告知女子：“你已经这样好多次了，我不可能这次就让你这样了。你在我的眼皮底下，我怎么交代，你在这我是要被扣钱的，你帮我补钱吗？你不容易我也不容易啊。”然而这位女子则看似一脸哭腔的说，“你别抢我东西啊，你别抢我东西啊！一直嘴子重复着这一句话。”这时候，这位城管说“我不是要抢你东西，我是让你去车上处理，我转了好几圈了，也告诉你三四次了，可是你却一直不理睬，这次我也不怕出这个名。”并且还说这件事情行车记录仪都有记录到，这次我不怕录，也不怕别人说。”这个事件被曝光在网络上之后，许多网友议论纷纷，并且表达出了对此件事情的不同看法！有网友表示，这位城管已经几次提醒你了，干嘛不暂时离开呢？被没收了，你就显得多么可怜的样子。这年头你不容易，难道城管容易吗？为什么要道德绑架呢？为什么不能相互理解一下呢？也有网友表示，这个女的真的是演员，人家城管不让摆，肯定那个地方确实是不能摆摊的，而这个女的却一直在那里说，别抢我东西，明显就是想带节奏。而且人家城管还是在提醒了三四次才上前去说不让摆的。并不是蛮横执法，直接赶你走的，所以说凡事要讲道理！
