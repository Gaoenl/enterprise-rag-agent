“八一”建军节将至 保定北市区开展慰问军人活动河北新闻网http://www.hebnews.cn2010-07-29 16:41来源:中新网中新河北网保定7月29日电(顾凤娟) 保定市北市区委宣传部29日透露,八一前夕,该区开展了走访慰问部队、退伍军人、伤残军人、军烈属、老复员军人活动,为他们送去慰问品和节日的祝福,使其切身感受到党组织的温暖。北市区四大班子主要领导先后对驻辖区6家部队进行了走访慰问,为部队官兵送去了价值4万余元的啤酒、牛奶等慰问品。并承诺要进一步加大对国防和军队现代化建设的支持力度,巩固和发展军政、军民团结和社会稳定的大好局面。同时,驻地官兵对该区在军属就业、子女就学、军转安置等方面给予的大力帮助表示感谢。此外,全区各部门也开展了走访慰问活动,通过走访重点户、集中开展座谈会、发放慰问品、慰问信等多种形式,大力开展宣传政策、倾听呼声、解决困难,确保切实把党和政府的关怀和温暖送到每一位军烈属的心中。据悉,军学社区还在休干二所广场上举办了“军民鱼水情深共谱和谐乐章”为主题的迎八一慰问联欢会,为驻辖区部队官兵送去居民的慰问。【责任编辑:孙婷】
