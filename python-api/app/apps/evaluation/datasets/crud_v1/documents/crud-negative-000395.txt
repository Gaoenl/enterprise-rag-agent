8月7日晚，如墨般的夜色笼罩在大清河长长的河堤上。宽阔的河水流速很快。“看看这里的水位。”听到声音，几把手电筒不约而同伸了过来。小心翼翼地走到岸边，扒开水草，仔细查看后，天津市静海区台头镇民生村党总支书记、村委会主任郝桂文放下心来，“目前还好。”眼下，天津行洪工作仍在持续，永定河、大清河河水已先后进入永定河泛区和东淀蓄滞洪区。作为海河流域重要的泄洪通道，大清河水位持续上涨，郝桂文带着村干部和村民日夜巡查着大堤。借着郝桂文的灯光，我们一路巡，一路寻，亲历着洪区一个个暖心的瞬间。河堤加固一刻也不能耽误“看堤的那一边！”顺着郝桂文的手电筒向远处望去，点点灯光闪烁，“那是大型机械设备在加固河堤，加固是一刻也不能耽误。”大清河围埝是天津市静海区台头镇的守护堤，要是洪水来临，这里是台头镇的第一道“关口”，也是“清北四村”胜利村、和平村、民生村、建设村的守护堤。郝桂文带我们踏上了刚刚加固的大堤，工程车辆来回穿梭，白色沙袋和沙石土料用来加固堤坝。沿着加固的堤坝一路走，一栋蓝色的临时帐篷内灯光明亮。刚走过去，记者就碰到了马上要去巡查的龚子博。作为中国安能武汉救援基地的一员，他刚从河北抢险回来，就立即奔赴天津抗洪一线。从北京、河北再到天津，今年28岁的他排查了不少风险，解了不少难题。不只是在大清河，日前，天津组织巡查队24小时不间断巡查大清河、子牙河、东淀蓄滞洪区围堤，及时消除行洪安全隐患。夜晚，灯光中，人在，堤在。民生村村干部和留守人员正在巡查。新华社记者 孙凡越 摄深夜的电话，放不下的牵挂沿着大清河南堤向南走近百米，有一条仅容一辆车通过的小巷，加筑堤坝、运送物资的渣土车不断经过，这是台头镇政府通往民生村的“主干道”。穿过小巷向西，巷尾一幢白色二层小楼内灯火通明，这里正是民生村党群服务中心所在地。“您现在在哪住？”“生活怎么样？”“有什么困难？”……党群服务中心内，民生村党总支委员张劲正在给村民挨个打电话进行回访。郝桂文也在一旁认真地听，不时做着记录。放下电话，张劲说：“不少人没有到政府的安置点，都是自己找地方住，村里选派了几名干部和村民留守，主要工作就是对转移安置的村民进行电话回访，及时了解他们的需求，并不时在村里进行巡查，以防出现紧急情况。”他介绍，村民转移安置后，经常打电话询问村里的情况。“有时一个还没打完，另一个就又打了进来。”晚上10点多，郝桂文带着张劲和几位干部一起到村里巡查。一根长木棒、一把大功率手电筒，这是他们巡查的“标配”。“村民不在家，我们要帮他们把村子守好。”郝桂文说。除了要时刻关注洪水情况，还要防止在洪水过境时持续降雨造成村里内涝。“大家分工协作，分批巡逻，有状况随时上报。”从8月4日洪水水头抵达台头镇，郝桂文和坚守在村内的村民就几乎没睡过整觉。巡查一圈后，时间已接近零点。村内留守人员在村党群服务中心活动室的地上铺上薄垫子和衣而卧，郝桂文搬了把椅子，坐在村党群服务中心门前。“放心不下这些村民，等一会儿他们都睡下，我也就去睡了。”郝桂文说。8月7日晚，村干部及留守人员在天津市静海区台头镇民生村村委会门外交谈。新华社记者 孙凡越 摄车灯交汇处，亦有“守夜人”夜色已深，天津市静海区台头镇的一处交通卡口依旧忙碌，一辆辆运送沙石土料的车辆排成长队，连点成线的车灯点亮了静谧的夜晚。每日，有许多车辆会经过静台路与梁台路交口处这个繁忙的十字路口。路口的东西方向连接着周边乡镇通往河北省的要道，南北方向则直通大清河堤坝。核验车证、指挥车辆、疏通拥堵……光线交汇处，天津市公安局静海分局交通警察支队副大队长赵阳紧张地忙碌着。赵阳（左）与同事在卡口值守。新华社记者 刘惟真 摄赵阳说，自己和同事们不仅要及时放行防汛工程车辆，以免延误堤坝加固施工的进度，也要时时留意社会车辆，劝离部分返乡的百姓。在无需值守的日子，赵阳还要在辖区8个乡镇开展执法办案、机动巡查等日常工作。“大概有七八天没回过家了。”防汛“号角”吹响后，支队30余名干警全员到岗，采取4人一组、“两班倒”的工作方式，在岗位上一守就是24小时。忙碌的时候，队员们常常寻机在路边匆匆扒上几口饭；长时间站立小腿酸痛，干警们就互相轮换着到车内休息片刻。到了夜间，人更容易困倦，大家更是靠着坚强的意志并肩奋战。“就怕打盹的功夫漏掉哪辆车。”赵阳说，自己一刻不敢松懈。天津市公安局静海分局副局长吕涛说，8月1日以来，该局每日出动警力556人、警车96辆，全力配合开展人员摸排、转移安置及治安秩序维护等工作。同时，开展大密度街面巡控，通过电子围栏、无人机巡查等形式，及时发现劝离回流人员，确保群众生命财产安全。行洪仍在继续，这一夜，大清河畔，不少人又是一夜无眠。
