2023-07-21 18:37，正文：当地时间20日，美国官员披露，五角大楼将向中东地区增派一个由三艘军舰和一支海军陆战队远征队组成的两栖战备群，以便在霍尔木兹海峡及附近水域对伊朗加以威慑。不愿公开姓名的美国官员告诉美联社记者，美国国防部长劳埃德·奥斯汀20日批准这一军事部署。增派的战备群包括“巴丹岛”号两栖攻击舰、“弗德台地”号船坞运输舰和“卡特·霍尔”号船坞登陆舰，这三艘军舰已于本月早些时候离开弗吉尼亚州诺福克海军基地。海军陆战队第26远征队将随舰派驻中东。按照美联社的说法，一支远征队的编制通常为2500人左右。美国国防部和中央司令部当天发表声明，确认向海湾地区增兵，称目的是“威慑伊朗”。最近几周，五角大楼批准向海湾派出“托马斯·哈德纳”号导弹驱逐舰和多架F-35型、F-16型战斗机。美军还多次出动A-10型攻击机，称其任务是为经过霍尔木兹海峡的商船提供空中掩护，并增强美军在海湾地区的存在感。据美联社报道，伊朗本月早些时候在霍尔木兹海峡试图拦截两艘油轮，并向其中一艘开火。伊朗方面没有证实相关消息。据伊朗伊斯兰共和国通讯社报道，伊朗伊斯兰革命卫队今年5月在霍尔木兹海峡扣押一艘外国油轮，称其违规，但没有详细说明具体原因。
