2023-08-01 07:29:44，正文：近日，有美国媒体探访了一处乌克兰军事基地，并曝光了乌克兰军队一款据称是以前从未向公众展示的无人艇。俄罗斯媒体“今日俄罗斯”对美媒的披露进行了报道，并称这款无人艇制造了7月早些时候对克里米亚大桥的袭击事件。美国有线电视新闻网报道称，这款乌军最新的无人艇由乌克兰自行设计制造，可用于在水面或水下执行攻击、监视和侦察等任务。这种型号的无人艇长5米，重约1吨，最高时速约80公里，可以携带300公斤炸药，对距离800公里外的目标发起攻击。据美媒介绍，这款无人艇设计的初衷就是为了在黑海及克里米亚地区实施攻击。2022年10月29日，俄罗斯国防部称，乌军当天使用无人机和无人舰艇在黑海港口塞瓦斯托波尔，对俄黑海舰队及停泊在那里的民用船只进行了袭击。乌克兰媒体同一天发布了袭击视频。 2023年7月17日，俄罗斯国家反恐委员会发布消息称，克里米亚大桥当天凌晨遭到两艘乌克兰水面无人艇袭击。俄方谴责乌方实施恐怖袭击。乌克兰国家安全局则称，乌方密切关注事态发展。乌克兰国家通讯社还援引消息人士的话报道称，乌克兰国家安全局和乌克兰海军可能在夜间对克里米亚大桥展开了特别行动，并使用水面无人舰艇攻击了大桥。美资深调查记者：美在克里米亚大桥遭袭中扮演“关键角色” 这不是克里米亚大桥自俄乌冲突开始以来第一次遭袭。2022年10月8日，克里米亚大桥公路桥上一辆卡车发生爆炸，导致与公路桥并行的铁路桥上一货运列车上7个油罐被点燃，公路桥部分路段受损坍塌。近期，多名乌克兰官员承认那次袭击是乌方所为。2023年7月27日，美国资深调查记者西摩·赫什在其个人网站上发文指出，美国政府在针对克里米亚大桥的两次袭击事件中都扮演了“关键的角色”。赫什在文章中援引一位没有透露姓名的美国官员的话说，袭击克里米亚大桥所使用的无人艇采用的是“美国提供的技术”，而且美国还告知乌方“可以做任何想做的事”，并且“无需美国的监督”。
