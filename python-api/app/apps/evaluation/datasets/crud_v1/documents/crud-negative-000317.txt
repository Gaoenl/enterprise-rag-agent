2023-08-12 17:34，正文：原标题：云南泸水：鲁掌边境派出所多措并举强化矛盾纠纷隐患排查化解工作自夏季治安打击整治行动开展以来，鲁掌边境派出所针对辖区实际，采取广泛宣传，深入排查，协同配合，跟踪问效等多项措施，强化各类矛盾纠纷隐患排查化解工作，确保辖区安全稳定。一是广泛宣传，提高群众法治意识和自身化解能力。该所压实社区民警责任，将矛盾纠纷隐患宣传作为法治宣传的一项重要工作来抓，具体结合辖区矛盾纠纷隐患种类，产生原因，解决途径等重要内容，采取以案释法，情理法相结合的方式向群众宣传，同时加强群防群治骨干力量的宣传培训，有效利用村组会议，驻村工作队走访入户等有利时机，适时强化宣传，做到宣传全民参与，不留盲区死角，通过宣传向群众灌输法治思维，同时有机结合道德规范，村规民约，提升群众自身化解问题的能力水平。二是深入排查，力争将问题隐患处置在萌芽状态。该所严密组织，部署各社区民警分组深入辖区各村寨，工矿企业，重点行业场所及在建施工工地，对各类矛盾纠纷隐患展开“拉网式”集中排查，并针对所排查发现的问题分析研判，制定措施及时整改，做到矛盾纠纷早发现，早预防，早处置，坚决力求将一切矛盾纠纷隐患处置在萌芽状态。三是协调配合，建立完善矛盾纠纷隐患处置队伍及协作机制。该所党支部高度重视，由所领导牵头协调建立“山城心连心固边服务队”及“主官矛盾纠纷调解队”，两支“服务队”围绕“枫桥式派出所”建设目标，有效总结提炼“枫桥经验”，分别对辖区普通类矛盾纠纷及疑难杂症类纠纷精准识别，有效突击，同时该所加强与地方党委政府，司法部门的沟通协作，建立完善了“所，村组，镇，司法”协调配合的“四级”联调机制，做到了“小事不出村，大事不出镇”。四是跟踪问效，切实提高群众的安全感和满意度。该所建立矛盾纠纷隐患排查化解回访机制，对已排查化解的矛盾纠纷隐患逐一进行回访，广泛听取民意，征求群众意见建议，防止群众事后反悔，事件反转，事态反复等情况发生，做到矛盾彻底化解，隐患坚决根除，群众安全感和满意度持续提升。本次矛盾纠纷排查化解工作，该所共派出警力12组36人次，开展宣传6场次，走访摸排行政村6个，村小组98个，发现各类纠纷隐患6起，现场排查化解2起，有效加强了辖区和谐稳定。来源：怒江边境管理支队鲁掌边境派出所通 讯 员：张何杰返回搜狐，查看更多责任编辑：
