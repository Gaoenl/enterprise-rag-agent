2023-08-07 02:56，正文：原标题：返乡大学生：“大学生文化管家”等你上任为充分激发城市书房、农村文化礼堂等基层公共文化空间活力，丰富基层群众精神文化生活，结合暑期大批大学生返龙实际，市委宣传部、市文化和广电旅游体育局、共青团龙泉市委联合向龙泉市公开招募2023年暑期基层公共文化空间“大学生文化管家”，以期通过青年人的思想、方法、路径，更好地激活基层公共文化空间内生动力，加快龙泉青年发展型城市和人文品质城市建设。一、招募对象在校大学生或2023年应届毕业生。二、文化管家工作职责1.城市书房：图书排架整理、图书借阅、读者阅读引导、读者咨询，根据大学生特长，开展绘本故事会、亲子阅读分享会、经典图书推荐等阅读推广活动。2.农村文化礼堂：暑期学业辅导、文艺演出活动策划、书法绘画等兴趣活动策划、红色历史文化科普、农业研学讲解。三、服务地点红豆公园城市书房、城东花园城市书房、西街城市书房、瓯江花园城市书房、新华书店城市书房、剑池街道吴岭村文化礼堂、西街街道周村文化礼堂、兰巨乡大巨村文化礼堂、安仁镇张畈村文化礼堂、住龙镇住溪村文化礼堂、八都镇溪坪村文化礼堂。四、服务时间志愿服务共分三期第一期：2023年7月20日—8月1日；第二期：2023年8月2日—8月14日；第三期：2023年8月15日—8月27日。五、志愿服务岗位需求六、报名时间7月12日至7月18日。七、报名方式八、评选表彰1.服务时长达60小时以上的志愿者颁发志愿者服务证书，并给予暑期实习服务证明。2.根据志愿者表现情况，评选若干优秀志愿者，并颁发荣誉证书。来源：龙泉市委宣传部返回搜狐，查看更多责任编辑：
