2023-08-07 22:35，正文：原标题：上月去外省考察，返苏后被免职，南京市委原统战部长华静被查即将年满60岁的华静，今年7月刚刚被免去南京市委常委、统战部部长职务，今日官宣被查。8月7日18时，江苏省纪委监委发布消息，南京市委原常委、统战部部长华静涉嫌严重违纪违法，目前正接受江苏省纪委监委纪律审查和监察调查。今年将满60岁的华静，是江苏扬州人，求学和仕途一直在南京，曾任南京市下关区委书记，南京副市长，2018年8月出任南京市委常委、统战部部长，今年7月被免职。华静。资料图据公开履历，华静，女，汉族，1963年11月生，江苏扬州人，1989年1月入党，1985年7月参加工作，在职研究生学历，硕士学位，工程师。华静毕业于南京工学院自动控制系工业自动化专业，毕业后入职国营720厂，在这家工厂工作了13年，历任厂团委副书记、厂团委书记，厂外经处处长兼进出口公司副经理、经理等职。国营720厂是南京长江机器集团有限公司的前身，是我国电子工业的骨干企业。1998年，华静调任南京市对外经济贸易委员会主任助理，自此走上仕途。2003年12月，华静出任江苏省妇联副主席、党组成员；2005年8月出任南京市浦口区委副书记、代区长、区长，南京高新技术产业开发区管委会主任，2008年6月出任下关区委书记，直至2011年底，她主政下关区3年多。2011年10月，华静出任南京副市长，2018年7月跻身南京市委常委，次月出任南京市委常委、统战部部长。据江苏省纪委监委公布的华静简历，今年7月，任职南京市委常委、统战部部长整5年的华静被免职，今日官宣被查。华静今年7月还出现在公务活动报道中。
