，正文：HMD Global宣布在美国市场推出诺基亚G310 5G手机，作为G42 5G手机的改进版本。该手机采用了耐用的Nordic设计，进一步增强了耐用性，并承诺在满电情况下可以续航3天时间。诺基亚G310手机采用铝合金中框和康宁大猩猩3玻璃保护，最大的亮点是采用了QuickFix设计。用户遇到故障时，可以轻松拆卸并更换问题零件，只需按照官方提供的支持手册操作。该手机配备6.56英寸屏幕，分辨率为720 x 1612，长宽比为20:9，刷新率为90Hz。搭载高通骁龙8nm 480+八核处理器和Adreno 619 GPU。内存容量为4GB，存储空间为128GB，并支持最高可扩展至1TB的microSD存储扩展。摄影方面，诺基亚G310拥有5000万像素主摄像头、200万像素景深镜头和200万像素微距摄像头，配备LED闪光灯、散景、视频EIS、OZO音频环绕和风噪消除技术。前置摄像头为800万像素。该手机运行安卓13系统，侧面配备指纹传感器，具有IP52级别防水性能。支持5G SA/NSA、双4G VoLTE、Wi-Fi 802.11 ac（2.4GHz + 5GHz）、蓝牙5.1、GPS/GLONASS/Beidou和USB 2.0等功能。诺基亚G310手机尺寸为165.0 x 75.8 x 8.55mm，重量为193.8克。内置5000mAh电池，支持20W快速充电。该手机将于8月24日开始发售，售价为186美元（约1358元人民币）。本文属于原创文章，如若转载，请注明来源：诺基亚G310 5G手机发布：满电续航3天https://mobile.zol.com.cn/828/8288614.html
