2023-08-02 14:43，正文：原标题：磨子潭镇：赓续双拥优良传统 多种活动庆祝“八一” 近日，霍山县磨子潭镇持续开展“八一”双拥系列活动，先后向县人武部官兵、辖区义务兵家庭、优抚对象、困难退役军人等送上节日的问候和祝福，共叙军民鱼水深情。 在县人武部，该镇党委书记高武一行走访慰问了部队官兵，代表镇党委、政府向广大官兵致以节日的问候，并送上节日慰问品。2023年，该镇一如既往地支持国防建设，做好征兵和民兵等工作，始终保持和发扬拥军优属的光荣传统，着力推进国防动员和后备力量高质量发展。 在辖区现役和退役军人家，慰问组详细询问他们的生活近况及生活中遇到的困难，同时宣传讲解国家相关政策，感谢他们为党和国家做出的贡献。此次八一期间共计慰问了8户现役军人家庭和24户优抚对象、困难退役军人家庭。 在庆祝建军96周年“八一”座谈会上，机关退役军人畅所欲言，现场气氛热烈。他们分别交流了军旅生涯、工作心得和生活经验。高武向各位退役军人致以诚挚问候和节日祝福，充分肯定了他们所做的积极贡献，同时勉励他们坚持发扬优良作风，在本职岗位上创先争优，勇当标杆，为磨子潭高质量发展聚力赋能。 下一步，该镇将以务实的工作作风为退役军人提供精细化服务，推动各项政策待遇落实落细，营造军政军民团结的浓厚氛围，凝心聚力推动双拥工作迈上新台阶。 信息来源：磨子潭镇(王庆)返回搜狐，查看更多责任编辑：
