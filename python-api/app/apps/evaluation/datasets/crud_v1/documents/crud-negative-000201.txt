，正文：8月16日，钉钉个人版正式开启内测，用户可通过官网申请测试资格。一旦申请通过，用户将可以免费使用钉钉个人版的一系列服务，包括文生文、文生图、角色化对话以及AI文本创作等。  钉钉个人版目前拥有两个AI助手：“贾维斯”和“缪斯”。贾维斯能够根据用户口语化的描述生成对应文本，或对内容进行总结。而缪斯则能够根据用户的需求，生成包括水彩、素描、油画等风格的绘画内容。这些功能在实测中都展现出了较高的质量。  在个人版中，钉钉还整合了我来wolai的文档协作、阿里云盘的存储和钉钉会议的能力。用户可以随时发起会议，进行沟通协作。此外，钉钉个人版还提供了一个空间，用于个人和团队知识的沉淀，采用信息块设定，将信息的最小单位从“文件”缩小到“信息块”。用户可以简易编辑、移动信息块，经实时呈现后组成页面，建立个人的知识库、搭建个人网站、管理工作流、存储管理资料。  需要注意的是，虽然目前内测阶段用户可以自由使用钉钉个人版的AI功能，但在正式版本中，用户使用AI问答等功能都将消耗“算粒”。当算粒消耗完后，用户将只能使用免费的限额次数，或者选择购买更多的算粒。本文属于原创文章，如若转载，请注明来源：钉钉个人版开启内测，免费用AI功能https://news.zol.com.cn/828/8289859.html
