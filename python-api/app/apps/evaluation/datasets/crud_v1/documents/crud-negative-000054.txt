2023-07-21 14:21:29，正文：为了更好地关心关爱残疾人士，杨浦区残联为新一批残疾人士组织开展免费体检，7月20日，90名残疾人士来到上海市第一康复医院，享受免费健康体检服务。“上面收缩压139，下面舒张压70，心率也是70，还比较好，比较正常。”早上7点半，新一轮杨浦区残疾人免费健康体检活动在上海市第一康复医院开展。量血压、抽血验血、B超心电图等体检项目前有序排起队。老陈是当天第一个完成所有体检项目的，他说这是他第一次享受区残联提供的免费健康体检服务，早在几天前，居委会工作人员就提醒他，做好准备来体检。“刚刚体检查出来有脂肪肝和高血压，今后的生活要注意饮食健康，油腻的食物要少吃。”为了让残疾人士有更好的体检服务体验，上海市第一康复医院专门配备了16名志愿者，全程服务残疾人士体检，特别针对视力残疾的老人，志愿者会直接一对一服务。上海市第一康复医院门诊办公室主任张静表示，能为残疾人士提供健康体检服务，是医院的责任和荣幸，必须做好后勤保障服务。考虑到最近天气炎热，医院还为参加体检的残疾人士特别准备了清凉解暑的绿豆汤。“喝完绿豆汤，心里也感觉更清凉，这是区残联对我们的关爱，也是医院对我的关爱，非常感谢。”参加体检的赵铭泽说道。据悉，一直以来，上海市第一康复医院积极为杨浦辖区内区的残疾人士开展免费的健康体检工作。通过健康体检，帮助大家更好地了解自己的身体健康状况，为他们在疾病预防、治疗和康复提供了指导和参考，切实提高残疾人士的获得感和满意度，同时也充分体现了党和政府对他们的关心，以及社会各界对他们的关爱。
