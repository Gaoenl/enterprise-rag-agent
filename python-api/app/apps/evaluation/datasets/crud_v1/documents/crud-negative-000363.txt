2023-08-15 11:04，正文：极目新闻记者 陈俊据福建电视台、厦门卫视等媒体报道，以所谓“过境”之名窜访美国的台湾地区副领导人赖清德，14日在纽约哈德逊河边的玻璃屋酒店出席宴会时，遭场外近千名华侨华人抗议。陈恒（左三）与华侨华人高喊口号（图源：视频截图）其中，挥舞五星红旗唱着“我的中国心”的一支队伍在人群中尤其引人注目。据了解，他们是由美国福建同乡会组织的爱国华侨华人。该会会长陈恒等人在现场与台湾媒体记者对话时表示，我们必须要团结，台湾永远是中国的，这个跑不掉。据了解，现场近千名爱国华侨华人手挥五星红旗，举着“台湾是中国不可分割的领土”等标语，《中国人》《我的中国心》《歌唱祖国》等歌曲响彻天空。爱国华侨华人（图源：视频截图）陈恒表示：如果“台独”，百分之百（会发生）战争。纽约中国和平统一促进会秘书长耿行也表示：因为我们爱好和平，不喜欢战争，反对战争。所以我们参加这种活动，是为了表达我们中国人，我们珍爱和平，反对台独，拒绝外来势力来干扰我们中国内政。现场，爱国华侨华人还高喊“赖清德，滚回去”“台湾永远是中国的，台湾不可能分割出去”等口号。当日，在美侨胞还在当地中文报纸《世界日报》上刊登全版广告，强烈抗议赖清德窜访美国。爱国华侨（图源：视频截图）8月13日，中国驻纽约总领馆发言人就赖清德“过境”窜美表示，广大在美华侨华人通过发表公开信、举行抗议等形式，反对赖清德“过境”窜美的行为再次证明，“台独”势力不得人心。个别“台独”分子媚美卖台、祸害民众的恶劣行径绝不可能得逞，也必将遭到全体中华儿女的唾弃和历史正义的审判。阿根廷侨界、比利时中国和平统一促进会也分别发表声明，坚决反对并强烈谴责赖清德“过境”窜美谋“独”。
