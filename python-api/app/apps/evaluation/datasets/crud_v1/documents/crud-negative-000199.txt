西安景区泼水节女子被泼后与游客起冲突,景区回应2023-07-23 15:08来源:澎湃新闻·澎湃号·媒体字号7月23日,有网友爆料称,陕西西安白鹿仓景区泼水节活动现场,一女子被游客泼水后产生冲突,大打出手。网传视频显示,穿黑衣的女子浑身湿透,指着对面男子大声呵斥:“我让你泼了吗?我让你泼了吗?”愤怒之下,该女网红还一脚向对方踹去。根据该女子描述,她当时是绕道走,没有走进场地,手上也没有拿水枪,并不准备加入泼水活动。据悉,该女子是一名网红。图源:视频截图22日晚间,当事女网红在网络上公开道歉,表示不找任何借口,确实动手了,因个人行为带来了不好的影响,给所有的粉丝们道歉。对此事件,景区工作人员表示,泼水节是景区举办,冲突发生后有人报警,警方已介入。另据九派新闻报道,当天该景区还有另一起因泼水而产生的互殴事件,当事人为两名未成年人。据网传视频显示,一名身穿蓝色上衣的男孩和一名黄色上衣男孩发生了言语和肢体冲突,其间有一名成年人试图将二人拉开。周围游客将二人隔开以后,两名男孩情绪仍然非常激动。图源:视频截图7月23日,记者致电白鹿仓景区,白鹿仓景区的工作人员回复记者说:“平常没有那么多人,22日游客人数较多导致乱泼水打架。目前还没有限定专门泼水的区域,泼水一般都是在民国街和水街。23日都有保安在活动现场巡查。”该工作人员还表示,事发之后,景区领导当晚10点半到12点一直在开会讨论这件事。原标题:《西安景区泼水节女子被泼后与游客起冲突,景区回应》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布,仅代表该作者或机构观点,不代表澎湃新闻的观点或立场,澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
