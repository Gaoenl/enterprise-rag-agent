，正文：近日，小米旗下手机品牌POCO在印度市场推出了一款新的M系列手机，名为POCO M6 Pro 5G。这款手机是去年M4 Pro 5G的继任者，本质上与此前在中国上市的Redmi Note 12R相同。POCO M6 Pro 5G的主要特点是搭载了高通骁龙4 Gen 2芯片，这是一款基于4纳米工艺的处理器，性能强劲，功耗低。 POCO M6 Pro 5G的外观设计独特，采用了双色调的后盖，中间有一个黑色的长条形摄像头模块。手机正面有一个6.79英寸的居中挖孔屏幕，分辨率为FHD+，亮度最高可达550尼特，刷新率为90Hz，手机侧面的电源键集成了指纹识别功能。 在拍照方面，POCO M6 Pro 5G后置有两颗摄像头，主摄像头为5000万像素，副摄像头为200万像素。前置自拍摄像头为800万像素。在系统方面，POCO M6 Pro 5G预装了Android 13操作系统，并且支持虚拟内存技术，最高可增加6GB的内存。 POCO M6 Pro 5G内置了5000毫安时的电池，并且支持18W快充。在连接方面，POCO M6 Pro 5G支持WiFi 5、3.5毫米耳机孔、红外遥控、蓝牙和5G网络。POCO M6 Pro 5G有森林绿和力量黑两种颜色可选。 POCO M6 Pro 5G在印度的售价为10999卢比起，最高配置的价格为12999卢比，将于8月9日开始销售。作为对比，Redmi Note 12R在中国的售价为1099元起。本文属于原创文章，如若转载，请注明来源：小米POCO M6 Pro 5G手机在印度推出，搭载骁龙4 Gen 2处理器https://news.zol.com.cn/827/8278761.html
