2023-08-09 19:23:19，正文：为了不断满足人民群众对教育高质量发展的需求，丰富区内青少年的校外学习生活，进一步培养青少年环保意识和社会责任感，作为普陀区政府开放月活动专场之一，区教育局组织开展了以“蓝色星球——如何捡回人们扔进海洋里的垃圾？”为主题的海洋保护科普体验亲子活动。8月4日上午，参加活动的10组家庭来到区青少年教育活动中心长风校区，在参观、体验科技感十足的创想实验室后，本次以环保为主题的项目化学习正式开始。同学们通过体验课程“蓝色星球——如何捡回人们扔进海洋里的垃圾？”，在老师的引导下、家长的陪伴中，学会观察现象、发现问题、探索原理、解决问题，针对海洋污染问题，利用旋转、捕捞和潮汐等技术，结合海洋垃圾的聚集场景，提出创造性的解决方案并展示了作品。家长们在参与活动的过程中，深切感受到了普陀校外教育的内涵与创新，表示将来会更积极地鼓励和陪伴孩子参与各类校外活动，在加强亲子交流、推进家庭教育的同时，进一步培养孩子的创新思维和创造能力。此次政府开放月活动搭建起了与家长的沟通桥梁，让家长更加了解和支持普陀教育发展。后续，区教育局将持续扩大公众参与，不断提升市民百姓对教育的知晓度、感受度和满意度，进一步推动普陀教育高质量发展，努力办好人民满意的教育。
