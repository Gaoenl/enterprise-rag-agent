2023-08-15 14:01，正文：原标题：印媒鼓吹：印度要造8艘13000吨级驱逐舰，垂发单元数量超中国055【环球网报道 见习记者 黄泽佳】印度军事资讯网站“印度国防研究”（IRDW）当地时间14日刊文称，印度海军正在推动一项雄心勃勃的计划，通过打造排水量高达13000吨级的“项目18”（Project-18，简称P-18）型下一代驱逐舰提升印度海军实力。印媒称，P-18驱逐舰最突出的特点是拥有强大的火力。报道提到，目前印度海军现役的“加尔各答”级驱逐舰以及“维沙卡帕特南”级驱逐舰的设计虽然“可圈可点”，但其最大缺陷是搭载的武器装备数量少于其他国家的先进驱逐舰。这两型驱逐舰只能搭载32枚垂直发射的“闪电-8”舰空导弹及16枚“布拉莫斯”反舰导弹。根据“印度国防研究”网站的说法，为解决火力不足的问题，P-18型驱逐舰将配备多达144个垂直发射系统单元，以前后各72单元的形式布置。除了垂直发射系统之外，P-18驱逐舰还将在舰桥后部布置8枚倾斜发射的“布拉莫斯-2”高超音速导弹。印媒称，P-18型驱逐舰将成为“印度海上霸权”的象征。报道还提到，与P-18驱逐舰相比，中国055型驱逐舰拥有112个垂直发射单元，美国“提康德罗加”级巡洋舰则拥有122个，印度的下一代驱逐舰将比肩中美。不过，“印度国防研究”也表示，可与中美战舰比肩的P-18型驱逐舰目前仍然处于纸面阶段，设计工作将于2024年完成。印度方面计划由西孟加拉邦加登里奇造船与工程有限公司（GRSE）以及位于孟买的马扎冈造船有限公司各建造4艘P-18型驱逐舰。根据印度的设想，这种万吨级驱逐舰最快将于2031年前服役。在印媒将新型驱逐舰与美军“提康德罗加”级巡洋舰对标之际，根据美国《星条旗报》等媒体报道，美国海军“莫比尔湾”号导弹巡洋舰于8月10日正式退役。“莫比尔湾”号是美国海军退役的第11艘“提康德罗加”级巡洋舰，1987年2月21日服役，已服役36年之久。返回搜狐，查看更多责任编辑：
