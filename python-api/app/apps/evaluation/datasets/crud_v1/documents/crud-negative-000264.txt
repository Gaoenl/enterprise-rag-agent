23-08-11 05:47，正文：浑南区五三社区卫生服务中心始终将“近距离为百姓服务，打造百姓家门口的健康驿站”作为工作重点，所属各卫生服务站都开展了“流动+阵地”的服务模式，延伸服务触角，方便社区群众，“为行动不便的居民提供上门服务，是中心家庭医生团队一直以来都在坚持做的事情。只要居民有困难，家庭医生团队成员都会走进居民家中，让家庭医生真正成为居民健康的‘守门人’。”浑南区五三社区卫生服务中心相关负责人称。近日，沈阳市浑南区五三社区卫生服务中心所属名流社区卫生服务站的工作人员正在为正式开诊紧张筹备，社区居民吴女士走进站内咨询，表示家中有位卧床的老人，刚手术出院无法下地，创面需要换药，附近又没有诊所，正犯愁，刚好看到这个服务站点，就想请医护人员到家里为老人换药。站长尹明听到吴女士的请求，立刻放弃了午休时间，带着站里的医生护士赶到吴女士家。“刚做完手术的老人看我们来到家中为他换药，喜悦之情溢于言表，连声表示感谢，激动地说‘社区卫生服务站能办在家门口，真是太方便了，你们的到来可真是解决了我的大难题’，并当场与服务站签订了家庭医生服务协议。”尹明称，浑南区名流社区卫生服务站走进居民家中，为社区居民排忧解难是医护人员的职责，他们将继续秉承为人民群众健康服务的理念，将上门服务、流动服务做得更好，提供优质、安全、贴心的服务，更好地为社区群众的健康保驾护航。沈阳日报、沈报全媒体高级记者 樊华
