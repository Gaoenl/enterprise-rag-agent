2023-08-15 14:15，正文：深圳新闻网2023年8月15日讯（记者 谢燕丽 通讯员 方莹 李烨）近日，玉塘街道开展创建“深圳市学习型街道”宣传培训讲座，进一步推动街道干部职工提能力、改作风、促发展，为谱写高质量发展、高效能治理新篇章“充电蓄能”。街道各部门各社区工作人员和专、兼职教师67人参加学习。 本次活动邀请广东省继续教育专家、广东省社区教育名师工作室主持人陈兆刚老师作“如何打造终身学习品牌项目和撰写工作案例”报告。报告指出，社区教育的具体目的是成为青少年的“第二课堂”、职场人的“充电站”、新市民的“心灵家园”、老年生活的“新舞台”以及社区治理的“助推器”。终身学习品牌培育和创建，是社区教育走向规范、提升办学辐射力和影响力的必然选择。陈老师表示，玉塘街道各部门、各社区在开展社区教育、推进学习型组织建设过程中，做了大量卓有成效的工作，如辖区深圳湾实验室科普教育、长圳社区建设儿童友好型公园等做法都可圈可点，特色鲜明。广大社区教育工作者要及时总结经验、深化成果和形成案例，切实让玉塘街道的终身学习品牌项目“做得出来、拿得出手、说得出口、传得出去”。讲座结束后，参训人员纷纷表示，此次讲座鼓舞了大家创建学习型街道的信心、决心和真心，定会继续努力，将理念付诸实践，期待全街道全民终身学习、共同全面发展，迎接幸福美好的生活。
