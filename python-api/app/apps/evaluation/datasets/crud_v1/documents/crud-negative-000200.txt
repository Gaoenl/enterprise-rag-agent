2023年07月28日 14:57:36 来自上海，正文：7月27-28日，俄非峰会在俄罗斯圣彼得堡举行。俄非峰会首日，海外社交平台上出现了普里戈任与非洲官员握手的照片，据称为普里戈任在参与俄非峰会期间与中非共和国代表团成员的合影。据美国有线电视新闻网（CNN）、美国政治新闻网站politico等多家外媒 7月27日报道，一个与瓦格纳集团有关联的Telegram账号当日发布了一张照片，并称照片内容为普里戈任在参加圣彼得堡俄非峰会期间与来访的中非共和国代表团成员握手。此前，该账号曾发文称，瓦格纳将继续加强在非洲的地位和影响力，“尼日尔发生的政变就是证明”，但CNN称目前无法对这一声明的内容进行确认。CNN报道称，这是普里戈任自“叛乱”以来首次在俄罗斯境内公开露面。此前，普里戈任在“叛乱”后仅出现在7月19日的一则视频中，该视频内容据称展现了普里戈任欢迎已抵达白俄罗斯的瓦格纳士兵的画面。据英国《金融时报》报道，一家专门追踪瓦格纳集团动态的机构称，在此次流传于社交平台的照片中，与普里戈任握手的非洲官员是中非共和国总统的礼宾主管。这张照片还被俄罗斯外交部下属文化中心网络“俄罗斯之家”在中非共和国分支机构的负责人德米特里·西蒂（Dmitry Syty）发布在其Facebook账号上，并配文称：“大使先生与我分享了俄非峰会的首批照片，我们看到了熟悉的面孔。”CNN、politico等外媒分析称，普里戈任“在俄罗斯的持续存在”说明，普里戈任“仍是克里姆林宫的重要组成部分”，并希望借此次峰会“展示实力”。在俄非峰会的前一天，尼日尔于7月26日突发政变，尼日尔总统卫队部分军人宣布扣押总统巴祖姆，军方随后于27日通过社交媒体宣布支持政变军人。此外，有多家外媒报道称，数百名“有经验的”瓦格纳集团战士已到达中非共和国，将为该国7月30日举行的公投提供安保服务。
