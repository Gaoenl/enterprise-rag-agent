2023-08-04 20:01，正文：原标题：云南泸水：洛本卓边境派出所开展2023年护边员培训为进一步提高护边员队伍素质，强化护边员法治意识、责任意识、使命意识，增强护边群防力量，近日，洛本卓边境派出所组织开展2023年护边员培训。会上，民警首先组织全体护边员共同学习了《云南省边境管理条例》《中华人民共和国出入境管理法》《中华人民共和国护边员工作制度》和奖励举报违法犯罪线索的公告。深入总结年初以来护边员队伍的整体工作情况，充分肯定了护边员在维护辖区稳定作出的贡献和努力,认真分析了当前辖区管控工作的短板弱项,并就下一步工作提出三点要求：一要提高思想认识。要充分认清维护边境安全稳定的重要性，以“守土有责、守土负责、守土尽责”的责任感、使命感，全力做好防风险、护稳定、保安全各项工作。二要扎实管边护边。要发挥“人熟、地熟、情况熟”的优势，对边境辖区周边重点区域、部位进行严密巡查巡护，积极协助派出所开展边境及治安管控各项工作，切实凝聚管边控边工作合力。三要提升业务能力。要积极参加教育培训，熟练掌握岗位业务技能，强化边境动态、案件线索、治安信息的收集，及时掌控辖区动态，增强护边意识，提升履职能力。 会后，民警通过示范演练等形式讲解了在处置突发情况中常用到的盾牌、钢叉、警棍等器械和防护装备的使用方法，并组织受训护边员开展实操演练，现场气氛活跃，训练效果良好。护边员纷纷表示，将会进一步发挥自身职能作用，不断增强工作责任心，切实提高守边、护边、固边的意识，积极协助派出所开展好边境治安巡逻防控等工作，切实与民警一道，维护好边境辖区的安全稳定。来源：泸水边境管理大队通讯员：王会文返回搜狐，查看更多责任编辑：
