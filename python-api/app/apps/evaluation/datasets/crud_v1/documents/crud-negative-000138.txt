2023-08-01 21:19，正文：原标题：大型旅游客车逾期未检验、逾期未报废？曝光！ | 夏季行动为进一步消除道路交通安全管理源头隐患，从严执行甘肃省公安厅道路交通安全“严管十条”要求，全面落实重点车辆逾期未检验和逾期未报废“清零”工作，甘肃公安交警 对全省逾期未检验、逾期未报废的大型旅游客车进行曝光（截至2023年7月31日），请车辆所属企业相关负责人、管理人、驾驶员尽快年检车辆。逾期未报废旅游客车名单逾期未检验旅游客车名单法律链接驾驶已达报废标准的车辆上道路行驶的，罚款2000元，吊销驾驶证。出售已达到报废标准的机动车的，没收违法所得，处销售金额等额罚款。驾驶未按规定定期进行安全技术检验的公路客运汽车、旅游客运汽车、危险物品运输车辆上道路行驶的， 驾驶证记3分，罚款200元；驾驶上述车辆以外的机动车上道路行驶的， 驾驶证记1分，罚款200元。 在检验有效期届满后连续3个机动车检验周期内未取得机动车检验合格标志的，机动车将 强制报废。 交警提醒车辆逾期未检验逾期未报废不仅违法还存在安全隐患请各位驾驶员及时关注车辆检验日期提前办理车辆检验安全文明出行来源 | 甘肃公安交警责任编辑：
