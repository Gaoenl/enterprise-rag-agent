2023-07-26 14:40，正文：原标题：湖南岳阳:17岁少年在射击俱乐部打工时中枪身亡？警方通报湖南岳阳:17岁少年在射击俱乐部打工时中枪身亡？警方通报 7月26日，湖南岳阳警方发布通报：一俱乐部内发生一起枪支走火伤人事件，杜某靖因抢救无效死亡。此前报道：17岁少年射击俱乐部打工中枪身亡，家属：目前已协商好近日，有网友称湖南岳阳一男性遭枪击身亡。26日，死者的表姐告诉记者，死者今年17岁，事发时在射击俱乐部打暑期工。图源：视频截图网传视频显示，在岳阳市一家医院大楼前，许多人痛哭。拍摄者称，该视频摄于7月24日，其到医院看病时，听工作人员说一男子被鸟枪击中身亡。据死者表姐介绍，中枪的男孩是她姨妈的儿子，今年17岁，再过一段时间就要成年。他就读于一所职业高中，暑假期间在一家射击俱乐部打工，因鸟枪走火被击中头部，经抢救无效身亡。岳阳殡仪馆工作人员透露，24日下午，确有一名因受枪伤后身亡的男性遗体送到殡仪馆，并确认少年17岁。死者表姐称，她的姨妈育有一儿一女，儿子平时性格很好。26日早上，他的遗体已被埋到山上，家人的情绪很不好，痛哭不停。其还称，目前已经协商好。（来源：九派新闻）LLY返回搜狐，查看更多责任编辑：
