2023-08-14 18:50，正文：原标题：暑期实践下乡去，修电器、科普知识一个都少不了极目新闻记者 张裕原本是暑期下乡调研，结果变成了师生们学以致用的维修大会，学生们不仅没有觉得累，反而认为这是学以致用将书本和实践结合的大好机会。8月14日，极目新闻记者从长江工程职业技术学院获悉，该校师生11人在两天时间里给罗田县河铺镇林家咀、许家宕等村的村民们维修了100余件电器，村民对师生们的善举赞不绝口。指导老师伍艳丽告诉记者：“ 从8月7日开始，师生们开展‘德技共育展青春，创新助农践初心’暑期‘三下乡’社会实践活动。原本计划利用两天完成行程，结果受到村民们的邀请，接到了家电修理等新任务。”林家咀村5组村民龚春香将用过多年准备报废的电扇试着请该校伍艳丽、李祥等一行的电气专业组师生帮忙修理。师生们一看就发现电扇是电动机绕丝坏了。“这个电扇修起来难度大，市场上修理的成本跟买一个新电扇差不多。”龚春香夫妇说，“8日晚上，学生们加班两个多小时拆开电机内部，一根根检查保险丝，最后将坏掉的两根保险丝修好，电机重新工作，将电风扇修好并将其保洁如新。”为了不耽误村民的时间，师生们白天入户修理家电外，到了晚上还委托村干部将各家各户要修的电视机、电饭煲、电扇等家电集中到村部和组里公共场所统一修理。从8日晚到10日早上，他们加班两天两夜，帮助两村村民修理家电100余件，大部分已修好能使用，小部分需要换特殊配件才能用的电器，他们都找到了病因，指出了问题，并将需要换的配件告诉村民，告知买回配件怎么安装上去。不仅如此，师生们还为两村公厕电灯定制了语音控制开关，解决过去公厕易出现长明灯的问题。在暑假实践活动中，该校师生还参加了林家咀村8月份支部主题党日活动。学校马克思主义学院副院长邱丽明为大家上了一节题为“将中国式现代化全面推进”的党课。村支书程其林代表基层党员说：“邱院长这节党课更加坚定了我们基层党员不忘初心、牢记使命的信心和决心。”（来源：极目新闻）返回搜狐，查看更多责任编辑：
