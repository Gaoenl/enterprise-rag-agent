北京时间6月11日法网女双决赛中国选手王欣瑜搭档中国台北选手谢淑薇逆转对手成功捧杯2019年,王欣瑜踏入了上海财经大学的校门,成为我校商学院的一名本科生。她和所有同龄人都一样,有着映出整个世界阳光的笑容和对未来满怀的憧憬。当然,她也与大多数同龄人不同,作为目前中国网球小花军团的代表人物之一,这位2001年出生的小花,16岁时在澳网亚太区外卡赛女单决赛中一鸣惊人,问鼎冠军,成为入围大满贯成年组正赛最年轻的中国球员。2018年1月27日,澳网青少年女双决赛,夺得冠军。时隔六个月,又在温网青少年女双决赛和搭档王曦雨以6-2/6-1横扫奥斯维圭/麦克纳利,成为温网史上第一对夺得青少年女双冠军的中国组合。此役是王欣瑜职业生涯第三次出战大满贯女双她成为第二位夺得法网女双冠军第五位夺得大满贯女双冠军的中国大陆选手祝贺王欣瑜!【责任编辑:曹竞】
