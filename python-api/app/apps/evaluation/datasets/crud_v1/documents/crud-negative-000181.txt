2023-08-16 11:16:19，正文：阅读童话，就像是一场梦中的旅行。意大利作家卡尔维诺说：“童话包含了对这个世界的全面阐释，丑陋的，美好的，都在里头。而即便是面对那些最可怕的魔力，我们也总能找到办法来摆脱它们。”为了将童话的“魔法棒”交到孩子们手中，近日，在杨浦区图书馆少儿分馆，YOUNG书房品牌读书活动“悦读圆桌会”举办了一场精彩的读书会，特邀沪上知名阅读推广人赵小华作为主讲，与孩子们共读著名童话故事《那一年，叶子没有落下来》，探讨并思考这本书所传达的深刻寓意。“秋天来了，小镇上发生了一件怪事：所有叶子都没有从树上落下来。原来，是叶子莉娜和叶子伊皮相爱了，不愿分开，便联合其他树叶一起对抗自然法则。谁想，这又成了树林居民红松鼠斯奎莉的烦恼……”读书会上，赵小华首先向大家介绍了《那一年，叶子没有落下来》这本书的作者和内容概要，并梳理了整体的情节脉络。两片树叶的爱情、红松鼠对小狐狸的爱慕，以及角色们面对人生选择的取舍，都在她的娓娓道来中呈现在小读者眼前。此外，赵小华还分享了书中多个精彩片段，并与台下的亲子家庭热烈互动。不少小读者自由发表观点、提问或分享自己阅读此书的感受，一起探讨什么是真正的“爱”，还结合自己的生活引发了对人性、亲情和友情的思考，充分体现出圆桌会活动“人人能参与，人人愿表达”的宗旨。这些互动，不仅让小读者们更好地理解了书中的主题，也促使他们像故事中的人物那样思考成长与叛逆，鼓励胆小的孩子们克服心理障碍，勇敢地表达自己。阅读是孩子们拥抱世界的窗口。杨浦区图书馆通过悦读圆桌会活动，为更多小读者提供了一个共同阅读和交流的机会，共同感受书籍所带来的魅力。本次活动旨在带着孩子们深入地导读，使他们能更加沉浸在书中，对阅读更有感悟，进一步丰富少儿读者的暑期生活，提升亲子阅读品质，培养少儿读者自主阅读能力。
