8-6 23:42，正文：                                                                                                                                                                                                                                                                         中新网北京8月6日电(记者 杜燕)北京市门头沟区消息：受台风“杜苏芮”影响，门头沟区遭遇历史罕见的连续强降雨天气，致使全区涉及57个村179条约392公里的乡村公路严重受损，道路阻断。门头沟公路分局统筹中交养护、中交一公局、北京建工等央企国企抢险力量，会同属地政府对受损村庄道路进行研判，全力打通乡村公路生命通道。  截至8月6日22时，门头沟全区9个镇乡村公路“生命线”已全部抢通，目前所有乡村公路仅允许抢险特种车辆及物资运送车辆通行，建议社会车辆不要进入。  【编辑:李岩】                                                                                                                              更多精彩内容请进入国内新闻
