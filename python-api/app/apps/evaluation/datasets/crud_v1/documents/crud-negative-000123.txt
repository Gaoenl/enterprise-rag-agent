2023-08-06 11:44:46，正文：红网时刻新闻8月6日讯（团结报全媒体记者 李再兴 付丹）日前，第八届美丽中国·深呼吸小城（壶关）夏季旅游文化节暨首届太行山山地旅游大会在山西省壶关县开幕。开幕式上发布了《2023深呼吸生态旅游魅力指数》暨2023“深呼吸生态旅游魅力名县”名单，湖南省10个县市区入选。其中，湘西州凤凰县、保靖县榜上有名。深呼吸——精准诠释了健康与环境的关系，是优质生态环境和健康生活方式的标志。《2023深呼吸生态旅游魅力指数》由中国国土经济学会深呼吸小城专家委员会主持，北京全域旅游规划设计院、中国文化和旅游产业研究院、亚太国际休闲文化（北京）中心联合编写。其中，依据美丽中国·深呼吸小城团体标准及生态旅游指数评价体系，评选出了2023“深呼吸生态旅游魅力名县”，湖南省上榜的有凤凰县、保靖县、武陵源区、桂东县、江华瑶族自治县、通道侗族自治县、新宁县、桃源县、沅江市、岳阳县。近年来，凤凰县、保靖县坚持以习近平生态文明思想为指导，全面践行“绿水青山就是金山银山”理念，坚持生态优先、绿色发展，把植树造林、扩大森林覆盖率、改善生态环境与旅游产业发展深度融合，以举办旅游发展大会为契机，精心打造热点景区、网红打卡地，培育乡村旅游品牌，持续丰富观光、休闲、度假、康养、研学等各类特色旅游产品，推进全域生态旅游高质量发展。到过凤凰、保靖的人都说，这两地山好水好空气好，均是可以深呼吸的地方。2022年，凤凰县完成造林绿化2.1万亩，建设森林绿化乡村16个，林地保有量166万亩，森林覆盖率达64%，空气质量优良率达100%，饮用水源水质达标率100%。保靖县完成森林质量精准提升1万亩、封山育林3.18万亩，森林活立木蓄积量约506万立方米，森林覆盖率达70.27%，湿地保护率达68.69%，空气质量优良天数比率达96.7%，国省考核断面水质和城市集中式饮用水水源地水质达标率100%。
