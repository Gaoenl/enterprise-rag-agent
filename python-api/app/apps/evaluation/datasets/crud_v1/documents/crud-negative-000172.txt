智通财经APP获悉,国信证券发布研究报告称,维持小鹏汽车-W(09868)“买入”评级,盈利预测不变,预计2023-25年销售收入分别为382/505/698亿元,净利润为-67/-56/-31亿元。公司首款搭载“扶摇”架构的全新战略车型超智驾轿跑SUV小鹏G6于2023年4月18号在上海车展正式亮相。“扶摇”架构汇聚了小鹏汽车在动力补能、智能体系、整车智造等领域的核心技术,使整车智能化技术达到新水平。该行认为,“扶摇”架构的发布,标志着小鹏汽车的智能化技术上升到了新高度,这也是小鹏汽车走向成熟化、体系化、加速发展的新起点。在过去几年中,小鹏汽车凭借智能驾驶系统Xpilot与XNGP的优秀表现,树立起了智能化的品牌形象,并以爆款车型小鹏P7获得了市场的关注与消费者的青睐。展望2023年,在管理层面,公司引入了长城汽车前任高管王凤英女士担任总裁职务,对公司的组织架构、产品定义与终端渠道进行了全面调整与升级;品牌层面,新车型全面落地800V高压平台技术,丰富品牌形象,电动化与智能化两条腿走路;产品层面,2023年P7改款,后续新车不断上升有望强化小鹏的产品矩阵,助力销量回升;财务层面,基于E、F、H三大平台造车,落地一体化压铸、标准化电池包等技术,有望控制成本,改善业绩。该行看好小鹏汽车在后续的市场竞争中全面调整、表现回升。
