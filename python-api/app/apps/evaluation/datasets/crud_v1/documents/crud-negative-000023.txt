2023-08-06 17:05:49，正文：红网时刻新闻8月6日讯（记者 吴公然）7月下旬以来，受台风“杜苏芮”北上影响，北京、河北等地出现强降雨天气，多个地区发生洪涝和地质灾害，造成人员及财产损失。8月4日，湖南省青少年发展基金会发出公告，决定开展2023年湖南希望工程救灾特别行动，接受社会捐资捐物，用于防汛救灾。公告发出后，正在长沙市委党校学习的长沙市教育系统复合型干部能力提升培训班（以下简称长沙市教育系统复合班）学员第一时间响应，该班党支部、班委会于8月5日向同学们发出爱心倡议，号召大家携起手来，积极参与2023湖南希望工程救灾特别行动，一起伸出援助之手，帮助受灾群众渡过难关，重建家园。在爱心倡议下，长沙市教育系统复合班全体成员纷纷慷慨解囊，奉献爱心，用诚挚爱心铸成抵御灾害的铜墙铁壁。复合班微信群中一句句“全力支持，已献爱心”汇聚成帮助灾区群众的大爱，共同谱写守望相助的动人篇章，用实际行动彰显党员的担当作为。据悉，本次筹集善款16120元，均来自60位学员及长沙市委党校班主任老师等。复合班班长严莹说：“对党员干部而言，越是重要关口越见精神品质，越是关键时刻越看担当作为。灾害发生时，就是群众需要党员站出来的时候，更是检验广大党员底色之时。”
