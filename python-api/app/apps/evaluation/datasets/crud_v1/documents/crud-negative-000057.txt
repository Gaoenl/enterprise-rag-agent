2023-08-13 11:51，正文：原标题：今年前7月宁波口岸进出口1.36万亿元中新网宁波8月13日电(方堃 夏丽玮 时明阳)受2022年高基数及全球贸易放缓影响，全球对中国产品需求波动以及国内需求疲软。港口是物流、信息流、资金流等交流、处理、交易的重要场所，数据显示，2023年1月至7月宁波口岸进出口、出口、进口3项指标均同比回落。据宁波海关统计，今年1月至7月宁波口岸进出口1.36万亿元，与去年同期相比(下同)下降11.6%；出口9980.3亿元，下降11.3%；进口3606.9亿元，下降12.5%。虽然3项总体指标走弱，但不乏结构性亮点。宁波舟山港穿山港区。吴梦凯摄 数据显示，1月至7月，宁波口岸对阿联酋、土耳其、南非、墨西哥等新兴市场进出口值逆势实现两位数增长，增幅由10.2%到32.9%不等；欧盟、美国、东盟依然为宁波口岸前三大贸易伙伴，分别进出口2461.8亿元、2218.5亿元、1330.4亿元，合计占同期宁波口岸进出口总值的44.2%。机电产品为宁波口岸第一大出口商品，1月至7月出口值达5204.2亿元，其中汽车及“清凉家电”出口增势喜人。汽车(包括底盘)出口值增长33.3%，其中电动载人汽车增长108.5%；“清凉家电”代表性商品空调、冰箱出口值分别增长20.1%、20.1%。金属矿及矿砂、消费品成为宁波口岸进口亮点。1月至7月，进口金属矿及矿砂219亿元，增长38.7%，其中，铜矿砂、铝矿砂、铁矿砂分别增长5.9倍、49.5%、36.9%。伴随着国内经济动能逐步修复，食饮类商品消费需求回升，1月至7月进口消费品217.4亿元，增长5.7%，其中文化娱乐类、食品烟酒类消费品进口值增势强劲，分别增长1.2倍、17.3%。(完)返回搜狐，查看更多责任编辑：
