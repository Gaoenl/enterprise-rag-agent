2023-08-11，正文：夏威夷野火蔓延民众避难：被迫跳海！据美国哥伦比亚广播公司（CBS）9日报道，受飓风“多拉”带来的强风影响，夏威夷日前爆发的野火迅速蔓延，城镇建筑被火舌吞没，当地民众被迫跳到海里，躲避大火和烟雾。面对野火的威胁，一些居民不得不跳入海中以躲避大火和浓烟。这一惊心动魄的场面反映了火灾对当地居民生命安全的威胁。夏威夷野火蔓延民众避难，夏威夷的消防部门和救援人员正全力投入抢救工作，试图遏制火势蔓延，保护居民的生命和财产安全。这次野火危机再次提醒人们自然灾害的不可预测性和严重性。强飓风、干旱等自然因素都可能成为火灾发生的催化剂，导致火势迅速蔓延，给居民和社区带来巨大威胁。美媒称，夏威夷多地野火8日迅速蔓延，现场视频截图。夏威夷野火蔓延民众避难！美媒称，夏威夷多地野火8日迅速蔓延，现场视频截图报道称，目击者向媒体描述了一个“末日般的景象”，毛伊岛拉海纳镇的部分街区被野火覆盖。当地业主艾伦·迪卡告诉媒体，“道路两边的建筑物都被吞没了。当时没有消防车。我认为消防部门已经不堪重负”。他还说道，“毛伊岛无法处理这个问题……很多人失去工作，因为很多企业被烧毁。很多人失去家园……对毛伊岛来说这将是毁灭性的”。CBS称，美国海岸警卫队官员伊莱恩·西蒙告诉该媒体，拉海纳镇的人们将水域作为避难所，但风正将浓浓的烟雾吹向水面。海岸警卫队证实已救出十余人，救援工作仍在进行中，目前尚不清楚还有多少人仍在水中。毛伊岛政府发言人马希纳·马丁当地时间9日晚接受电话采访时表示，目前尚不清楚有多少建筑物被烧毁，由于风力，直升机无法从空中灭火，也无法更精确观测火势大小。他说，“对于我们岛来说，这绝对是最具挑战性的日子之一”。夏威夷野火蔓延民众避难！(责任编辑：卢其龙 CN070)
