2023-08-08 20:23，正文：8月10日，云南省京剧院一级演员辛苑将携尚派名剧《梁红玉》亮相上海天蟾逸夫舞台，参加第32届上海白玉兰戏剧表演艺术奖评选。辛苑工青衣、刀马，先后师承李喜鸿、王志怡、滕莉、韩福香、邢美珠、张艳玲、尚慧敏等。作为京剧表演艺术家尚（小云）派亲传弟子孙明珠入室弟子，辛苑曾获云南省青年演员大赛一等奖、全国青年京剧演员电视大赛铜奖、全国青年京剧演员擂台赛新星奖等。这次辛苑带来上海的京剧《梁红玉》由尚（小云）派亲传弟子李喜鸿、孙明珠亲授。早在2020年，云南省京剧院就准备用《梁红玉》申报上海白玉兰戏剧表演艺术奖，一直未能成行，但院团和辛苑不放弃目标，沉下心来用三年时间精心打磨，力求该剧舞台艺术呈现在原有基础上进一步提高。尚派名剧《梁红玉》对演员要求非常全面。前半场唱腔设计起伏跌宕，人物情感表达细腻传神。后半出侧重于武，“战金山”一折是刀马旦戏，可以与大武生戏比美。辛苑饰演的梁红玉工架沉稳，气度饱满，嗓音洪亮高亢，举手投足带着英姿飒爽女元帅的风范，特别是击鼓一段，强化“战金山”艺术感染力。近年来云南省京剧院在青年后备人才培养上加大力度，聘请京津沪等地名家进行一对一教学，通过定剧目、请名师，以人带戏、以戏带功的教学方式，使演员们逐渐成熟起来。这次参加《梁红玉》的刘鹏飞、张世杰、闫丽霞等都在院团培养下跟随名师学习，上海演出也是云南省京剧院培养青年艺术人才成果的集中展示。
