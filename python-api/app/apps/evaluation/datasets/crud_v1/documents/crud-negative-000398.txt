北京排水集团消息，7月29日11时45分，北京排水集团启动防汛特级响应。响应启动后，集团防汛指挥部各级人员到岗指挥，各分指相关人员到岗，所有水厂及泵站人员全部在岗值守。共计出动大中小防汛单元 252组、防汛人员 2605人。集团运营范围内128座高低差大于1.5米的高风险桥区，集团盯守人员均已到位值守。截至7月31日19:00集团 73座雨水泵站启动运行，累计排蓄雨水61.4万立方米。集团各再生水厂7月28日14:00开始加大水量抽升处理，集团各再生水厂处理水量1182.2万立方米。截至目前，集团共处置积水事件49件，完成39件处置。其中，33积水断路事件完成25件处置、4件滞水事件全部完成处置、12件支援抢险事件处置完成10件。文/北京青年报记者  解丽举报/反馈
