2023-07-29 22:07，正文：原标题：（成都大运会）日本队斩获4金 成柔道比赛首日最大赢家新华社成都7月29日电（记者刘彤、魏婧宇）29日，成都大运会柔道比赛展开首日争夺，在当日产生的5枚金牌中，日本队赢得4枚，韩国队获得1枚。当日中国队有5名选手参加比赛，除了颜思外，其余选手都未能进入奖牌争夺战。在女子48公斤级铜牌战中，颜思遗憾负于韩国选手，最终名列第五。在男子60公斤级比赛中，日本选手中村太树战胜东京奥运会银牌得主、中国台北选手杨勇纬，获得该项目的金牌。杨勇纬在赛后表示，赛前针对对手做了大量“功课”，比赛中也看到了一些机会，但很遗憾没有把握住。“大运会是对我这段时间训练和学习的一个检视，发现不足的地方及时修正，才能以更好的状态备战巴黎奥运会。”他说。在男子66公斤级比赛中，日本选手服部辰成开场仅一秒钟就凭借一个快准狠的“一本”，战胜摩尔多瓦选手拉杜·伊兹沃雷亚努，获得该项目的金牌。在女子项目中，日本小将吉冈光战胜荷兰选手安贝尔·格瑞斯，获得48公斤级的冠军。女子52公斤级和女子57公斤级的决赛都是“日韩之战”，日本选手白石响战胜韩国选手，获得女子52公斤级的金牌，韩国选手许美美则在女子57公斤级比赛中力压日本选手大森朱莉夺冠。（完）返回搜狐，查看更多责任编辑：
