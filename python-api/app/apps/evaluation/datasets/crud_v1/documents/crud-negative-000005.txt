中央气象台：全国大部大气扩散条件较好 西北地区有沙尘天气2023-12-14 17:52中央气象台14日夜间至16日，受冷空气和降水影响，全国大部地区大气扩散和湿清除条件较好，无大范围霾天气。但未来三天，西北地区多扬沙和浮尘天气。具体预报如下：京津冀及周边区域14日夜间至16日，受降水和冷空气影响，区域大部无明显霾天气。17日至18日，区域中南部大气扩散条件一般，部分地区有轻度霾天气。19日至20日，区域再次受冷空气影响，大气扩散条件较好。长三角区域未来一周，受冷空气和降水影响，区域大部大气扩散和湿清除条件总体较好，无明显霾天气。汾渭平原区域未来一周，受冷空气和降水影响，区域大部大气扩散和湿清除条件总体较好，无明显霾天气。仅17日至18日，区域局地有短时霾天气。珠三角区域未来一周，区域大部大气扩散和湿清除条件较好，无明显霾天气。华中区域未来一周，区域大部大气扩散和湿清除条件较好，无明显霾天气。西南区域未来一周，受降水天气影响，区域大部地区大气扩散和湿清除条件较好。东北区域未来一周，区域大部大气扩散和湿清除条件较好，无明显霾天气，仅区域中部局地有短时霾天气。西北区域15日，受冷空气影响，内蒙西部、甘肃东部、宁夏等地的部分地区有扬沙或浮尘天气。16日，受冷空气大风影响，甘肃北部有扬沙或浮尘天气。此外，未来三天，新疆东部和南疆盆地多扬沙或浮尘天气。责编：赵钰阳阅读数(1）不感兴趣不感兴趣广告软文重复、旧闻文章质量差文字、图片、视频等展示问题标题夸张、文不对题与事实不符低俗色情欺诈或恶意营销疑似抄袭其他问题，我要吐槽确定*请填写原因感谢您的反馈，我们将会减少此类文章的推荐投诉
