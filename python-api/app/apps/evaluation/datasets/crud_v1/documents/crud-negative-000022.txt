2023-08-04 19:58，正文：                原标题：川妹子联手摘下女子双人3米板金牌，混双10米台冠军也有一位是四川小伙                            川妹子联手摘下女子双人3米板金牌，混双10米台冠军也有一位是四川小伙      8月4日，成都大运会跳水比赛继续在简阳文体中心游泳馆举行。在女子双人3米板决赛中，中国队组合陈佳、杨睿琳夺得冠军，马来西亚队组合、意大利队组合分获第二、三名。   在随后进行的混合双人10米台中，中国队组合王彬翰、王伟莹获得金牌，银牌、铜牌分别由日本队组合和韩国队组合获得。      ↑中国组合陈佳/杨睿琳（左）在女子双人3米跳板决赛中。图据新华社  4日的简阳，天气炎热，而比天气更加热烈的是简阳文体中心游泳馆的观众。每一位运动员入场，每一组运动员完成动作，都会收获现场热烈的掌声。  在女子双人3米板决赛中，中国队组合陈佳、杨睿琳第一跳难度系数仅为2.0，但两人配合默契，动作整齐划一，入水后水花压得很好。此后，中国队两位姑娘延续了第一跳的良好状态。在第四跳时，她们选择了全场难度系数最高（3.1）的动作，并凭借出色发挥拿下全场最高分，两人得分也一路领先。  值得注意的是，马来西亚队组合稳定发挥，前三跳取得较好的成绩。意大利队两位选手则在最后三跳选出了难度系数3.0的动作，这给比赛带来了一定的不确定性。    ↑陈佳（右）/杨睿琳女子双人3米跳板决赛中。图据新华社  据了解，参加女子双人3米板决赛的中国队选手是两位四川姑娘，其中陈佳来自自贡，是成都体育学院的大一学生，她此前已经在8月1日举行的女子1米板决赛中获得金牌，今日再次斩获金牌，显得格外高兴。8月5日，陈佳还将参加女子单人3米板的比赛。  来自成都的杨睿琳曾在2019年举行的全国跳水锦标赛中获得女子1米板冠军，在今年举行的全国青年跳水冠军赛、全国跳水冠军赛也拿到了金牌。对于杨睿琳来说，她延续了自己的好状态。  而在混合双人10米跳台夺冠后，中国队选手王伟莹已经在成都大运会取得第三枚金牌，此前她获得了女子单人10米台、混合双人3米板金牌。该项目另一位中国队选手王彬翰则是来自成都体育学院的川籍选手，他在比赛中发挥稳定，首次亮相就有金牌入账。  红星新闻记者 闫宇恒  责编 任志江 编辑 张寻返回搜狐，查看更多                        责任编辑：
