据中国新闻网综合外媒报道，当地时间20日晚，新加坡总理李显龙在2023年国庆群众大会全国电视演说中称，自己移交权力的计划现在已重回正轨，越来越多的决策权已经下放给第四代领导团队。同时，他否认近期“争议事件”会耽误此进程。据新加坡亚洲新闻台(CAN)报道，当天，李显龙在演讲中表示，他最初的计划是在2022年自己70岁生日之前移交权力，卸任总理职务。但新冠疫情打乱了这一计划，他当时向新加坡人民承诺，将与现任和第四代领导团队一起，带领国家“渡过难关”。但现在新冠疫情已过去，他的交接计划也重回正轨。李显龙 图片来源：视觉中国李显龙1952年2月10日出生于新加坡，祖籍中国广东省梅州市大埔县。李显龙是新加坡国父李光耀的长子，在2004年接任吴作栋成为第三代领导人。1992年，李显龙曾被诊断患上中期淋巴癌，接受化疗后痊愈。2015年，在接受手术后，他又成功治愈了前列腺癌。李显龙曾于2015年9月12日连任总理。2020年7月，李显龙再次连任总理。李显龙：我将移交权力新加坡第四代领导团队曾经的领军人物王瑞杰一度被视为李显龙的接班人，但2021年，他因“年龄和健康”因素辞职，在新加坡政坛投下“重磅炸弹”。7月，新加坡政坛频现政治丑闻。一度被认为是潜在接班人的交通部长易华仁7月11日因涉嫌贪腐和利益冲突被逮捕。他是新加坡近40年来首个涉嫌贪污的内阁成员。紧随其后，7月17日，国会议长陈川仁和人民行动党议员钟丽慧因婚外情退党和辞去议席。据澎湃新闻报道，陈川仁和钟丽慧辞职后，李显龙强调两人退党是“必要的”，这样才能保持该党“多年来一直坚守的高标准品格和个人操守”。陈川仁一度被外界视为人民行动党第四代核心领导班底（“4G”团队）的一员，是新加坡政坛的“明日之星”。李显龙在20日当天的讲话中提到，“最近发生了几个涉及政治人物的事件，让国人感到不安”。新加坡政府正在“全面且透明地处理这些问题”，强调“它们不会影响接班的时间线”。“我向大家保证：这些事件不会耽误我的权力移交时间表。我们正在重回正轨。”李显龙说道。据新加坡宪法相关条例，下一次大选最迟将在2025年11月举行。新加坡下一任领导人是他？李显龙的继任者是50岁的黄循财 (Lawrence Wong)。黄循财也将是这个城邦国家建国近60年来，第二位李氏家族之外的领导人。自1965年成为独立国家以来，新加坡开国总理李光耀领导的人民行动党一直掌权。黄循财 图片来源：视觉中国黄循财1972年12月出生于新加坡，祖籍中国海南，现任副总理兼财政部长。2022年4月14日，黄循财正式获推举成为第四代领导层团队的领军人物。李显龙当时就已明确表示，无论自己是在大选前还是大选后交棒，黄循财都是下一任总理人选。同年6月6日，黄循财正式升任为副总理，被认为接班人地位更加巩固。在最新的讲话中，李显龙没有明确给出交棒的具体时间。新加坡管理大学法律学教授Eugene Tan对法国国际广播电台表示，李显龙不愿意透露具体交接时间表“并不奇怪”，这样所有的牌都掌控在他的手中。因为一旦他给出时间表，他就会变成“跛脚鸭”。新一任领导层上任后，新加坡能否坚持目前的外交政策引发关注。8月11日，中国外交部长王毅访问新加坡时会见了李显龙及黄循财。新加坡外交部声明称，中新双方承诺将扩大合作，并确认共同建设开放、和平、包容的区域。中国外交部声明也表示，新加坡支持东盟与中国深化合作，共同维护地区和平稳定发展。对于中美关系，黄循财最新表态是在8月14日。他在纪念李光耀百岁诞辰的活动上表示，西方对中国的各种科技限制，可能会减缓中国获取高端能力的速度，但是不太可能压制中国。他表示，美国的对华政策将成为“世界的大问题”，中美紧张关系或对全球经济造成灾难性影响。
