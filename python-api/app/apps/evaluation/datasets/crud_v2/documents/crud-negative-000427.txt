2023-08-11，正文：新加坡外长宴请中国外长：两人亲切拥抱！外交部长王毅于10日正式开启对新马柬三国的访问。新加坡外长维文在新加坡植物园的餐厅为王毅一行设宴款待。王毅下车后，维文首先为自己没有打领带道歉，两人亲切拥抱，王毅随即也拿掉了自己的领带赴宴。王毅于10日至11日访问新加坡。在访问期间，王毅将分别与新加坡总理李显龙和副总理兼财政部长黄循财会晤。维文将设晚宴招待王毅。新加坡外长宴请中国外长，据悉，王毅上次到访新加坡是在2021年。访新期间，王毅外长分别与新加坡总理李显龙和副总理兼财长黄循财举行会晤，维文则设晚宴招待了王毅外长。在官宣王毅外长访问东南亚3国行程时，我外交部发言人指出，中新关系保持了良好的发展势头，双方建立了全方位高质量的前瞻性伙伴关系，中方期待通过此次访问，同新方加强战略沟通，落实好中新关系新定位。看得出来，中方对此次王毅外长的东南亚之行期望很高，将新加坡作为出访第一站，更是彰显了中方对双边关系的重视。当然，新加坡政府同样重视王毅外长此次来访，王毅外长抵达新加坡的当晚，新加坡外长维文特意在环境清幽的植物园宴请款待王毅外长。会谈后维文第一时间在社交媒体发文，向外界透露情况。他写道：“很高兴欢迎我的好朋友王毅来新加坡，我们在植物园很好地共进晚餐，并就多个战略课题进行了广泛交谈。”维文指出，他与王毅外长就两国旅游和商业往来、航空互联互通等问题进行了讨论，寻找两国合作的共同利益点，同时两人也在地区和国际形势议题上交换了意见，同意共同推动东盟与中国的合作。新加坡外长宴请中国外长！(责任编辑：卢其龙 CN070)
