新华网北京7月25日电 “强教必先强师”，教师是教育强国的第一人力资源，是在教育“双减”中做好科学教育加法的关键。为提高科学教师队伍素质，提升科学教育质量，逐步建立系统性、长效化培训工作机制，加快提升教师科学素养与科学教育水平，教育部、中国科学院、中国科学技术协会共同开展全国中小学教师科学素质提升培训工作。其中，由中国科协青少年科技中心、中国青少年科技教育工作者协会牵头承办的2023年度中小学教师科学素质提升暑期联合行动启动暨开班第一课于7月25日在北京大学举办。教育部教师工作司副司长韩劲红，北京大学党委常委、副校长孙庆伟，中国科协科普部副部长庞晓东，中国科协青少年科技中心主任辛兵，中国青少年科技教育工作者协会副理事长兼秘书长林利琴等参加活动。会上，2023年度中小学教师科学素质提升暑期联合行动正式启动。源头助力 彰显高校教师人才培养功能孙庆伟在致辞中说，基础教育是国民教育体系的根基，凝结了国家对未来的期望，事关国家发展和民族未来。北京大学高度重视本次活动，安排来自北大数学科学学院、继续教育学院、附属中学等的专家学者，精心设计课程并参与讲授。近年来，教育部启动“高质量教师队伍建设战略工程”，推动高水平综合大学培养高素质中小学教师。作为基础研究的主力军和重大科技突破的生力军，北大不仅培养了众多基础扎实、潜质突出的科技人才，也始终致力于建设培育高素质教师队伍，推动基础教育高质量发展。孙庆伟表示，希望以此次培训为契机，充分发挥北京大学在人才培养、教育创新等方面的资源优势，为加快建设教育强国作出新的更大贡献。整合资源 发挥科协组织和系统优势全社会科学教育资源的深度整合是促进科学教育高质量开展的有效途径。5月，教育部等十八部门联合印发了《关于加强新时代中小学科学教育工作的意见》（以下简称《意见》）。《意见》不仅要求加强青少年科学教育，也强调了有机整合社会各方资源。辛兵在致辞中说，中国科协青少年科技中心和中国青少年科技教育工作者协会在中国科协的领导下，积极配合教育部门，加强中小学教师科学素质提升工作。中国科协积极发挥其组织和系统优势，统筹社会优质科教资源，通过开发汇聚优质培训课程、组织科技教师线上线下培训，指导教师提升科学教育水平，并带动全国学会、地方科协等“两翼”助力中小学教师科学素质提升。本次由中国科协青少年科技中心、中国青少年科技教育工作者协会牵头承办的2023年度中小学教师科学素质提升暑期联合行动，以“基础学科”“海洋科学”“生态科学”等领域为重点，精心策划主题式系列研修活动、重点科普活动骨干教师交流活动、“送培到基层”科技辅导员交流活动以及线上学习等一系列示范性活动。“希望通过我们搭建的联合行动大平台，最大限度凝聚广大科技工作者的力量，统筹协调高等院校、科研院所、科普场馆、科技企业、科普教育基地等多方资源，为教师提供优质科教资源和服务，共同助力教师科学素质提升。”辛兵说。牵头抓总 教育部赋能“大科学教育”共建科学教育覆盖领域广泛，涵盖中小学校、科教场馆、实践基地、网络平台等校内外资源，这些资源分散在各部门、领域和行业中。如何有效整合各类教育资源，发挥其最大效用成为当前亟须解决的问题。因此，建立由教育部主导相关部门共同参与的协同科学教育工作机制，方能全面系统地推进科学教育落地见效。在推进教育强国建设、实施科教兴国战略、强化现代化建设人才支撑过程中，需要培养一支高素质、专业化、创新型中小学科学教育教师队伍，这也需要教育界和科技界紧密协作、协同发力。教育部一直致力于联合多方力量推进科学教师素养提升。今年7月，教育部办公厅、中国科学院办公厅和中国科协办公厅联合印发《关于做好2023年下半年全国中小学教师科学素质提升培训工作的通知》，整合三部门相关资源和项目开展工作，中小学教师科学素质提升暑期联合行动，是其中的重要内容。韩劲红表示，帮助广大中小学教师提升科学教育专业素养和能力水平，有助于推动建强校内科学教育主阵地，在系统化的课程教学中持续激发青少年的科学热情，让科学的种子在青少年心中不断生长。从一定意义上讲，针对中小学教师的科普会对一批又一批的青少年产生更为长久和广泛的影响。中国科学院数学与系统科学研究院研究员闫桂英为现场参会的100名中小学科学教师作《浅谈数学素质》报告，开启了本次培训的第一课。新华网、科普中国等就该报告进行直播，累计观看数360万人次。据了解，未来数月，2023年度中小学教师科学素质提升暑期联合行动还将邀请知名科普、教育专家等，充分利用高校和科研机构的科学教育资源，带领参训老师们深入科研工作现场和科普场馆，通过专题讲座、现场教学、探究实践、经验分享、交流研讨等多种方式，帮助老师们拓宽科学视野，了解国内外科技前沿发展动态，掌握科学研究方法，感受科学家精神，提升其科学素养和科学教育教学能力。来源：新华网客户端举报/反馈
