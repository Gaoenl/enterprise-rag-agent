2023-08-14 19:03，正文：原标题：广东发布环境资源审判十大典型案例央广网广州8月14日消息（见习记者 晁海娟）在首个全国生态日来临之际，8月14日，广东省高级人民法院召开环境资源审判新闻发布会，通报2018年至今年上半年全省环境资源审判工作情况，并发布十大典型案例。发布会现场（央广网发 图片来源于广东省高级人民法院官方微博）据介绍，2018年至2023年6月，广东省法院共审结各类环境资源案件62186件，其中刑事13977件、民事28745件、行政19464件。数据显示，2020年以来，全省法院环境资源一审案件受理数呈逐年下降态势，其中2022年一审刑事案件受理数同比下降35%，今年上半年继续呈下降趋势。这十大典型案例分别是：卓某走私珍贵动物案、非法出售收购穿山甲鳞片案、南岭国家森林公园公益诉讼案、北江非法采矿案、噪声扰民诉前禁止令案、百年荔枝古树保护案、碳配额行政处罚案、碳排放权交易合同纠纷案、检测机构提供虚假证明文件案、海洋生态保护案。其中，卓某走私珍贵动物案入选联合国环境规划署案例；北江非法采矿案一案判赔金额达29.6亿元，是全国判决赔偿数额最高的环境公益诉讼案件；噪声扰民诉前禁止令案是全国首份“噪声扰民”诉前禁止令案，获选“新时代推动法治进程2022年度十大案件”；海洋生态保护案作出海域使用金16倍罚款的决定……这些司法案例对于教育警示社会公众树立法律意识，自觉保护生态环境起到了较好的示范作用。据悉，目前广东建立了40余个跨区域、跨部门、跨层级的生态环境司法保护协作机制。今年以来，广东法院还先后与桂、滇、黔、赣、闽等省（区）建立了东江、韩江、西江流域生态环境司法保护协作机制。发布会上，广东省高级人民法院副院长林碧艳表示，广东法院将不断创新审判执行方式，持续强化规则引领，做到惩戒与修复并重、纠正违法与源头治理并举，切实保障人民群众环境权益，以高质量司法护航绿美广东生态建设和海洋强省建设。返回搜狐，查看更多责任编辑：
