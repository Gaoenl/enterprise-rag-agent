近年来，一些诈骗分子针对老年人普遍存在的养老需求，精心设计诈骗套路，侵害老年人的合法权益。近日，浦发银行北京分行以全国打击整治养老诈骗专项行动为契机，积极开展防范养老诈骗宣传活动，帮助老年人增强风险防范意识和识别能力，守好“钱袋子”，远离养老诈骗。主动宣讲 打好诈骗“预防针”据悉，浦发银行北京分行将老年人的金融知识普及作为“适老化服务”的重要举措，结合多样化的主题与特殊时点，持续对老年客户开展常态化宣传。针对防范养老诈骗，浦发银行北京分行以线上线下相结合的形式，设计制作电子宣传材料，并通过一系列养老骗局典型案例，揭露与养老有关的诈骗手法和骗局，加强对老年人的宣传引导。网点工作人员将宣传活动融入日常工作，遇到老年客户前来办理业务，在业务间隙主动向他们讲解养老骗局的诈骗手段，并根据老人的基本生活情况，分析他们有可能遭遇的诈骗方式，帮助老人打好“预防针”。警惕常见骗局辨识套路特征养老骗局往往“紧跟热点”，依据养老产业、养老政策精心设计，打着“服务老人”的旗号实施诈骗。目前最常见的有以下三种套路：1、“养老服务”骗局，以投资养老社区、预售养老床位等为名，虚构 “养老服务”相关项目，通过同时满足老年人理财与养老的需求，诱导老人以“投资”、“预购床位”等名义缴纳高额费用。对这类骗局来说，眼见并非为实，即便进行了实地考察，其实也是虚假的项目，且总是承诺可同时获得高额回报与优质养老服务。2、“以房养老”骗局，随着“以房养老”的兴起，犯罪分子也以此为名，诱骗老年人办理房产抵押，并把抵押房子的钱款用来购买他们推荐的“理财产品”。最后骗子会拿走老人的抵押贷款，而老人也因无法偿还贷款，失去房屋的所有权。在这类骗局中，老人会签下借款合同、房屋买卖合同、理财合同等本不应在正规的“以房养老”中出现的一系列合同。抵押手续完成后，不法分子总会以理财、投资等名义，再骗取老人的资金。3、“养老保险”骗局，不法分子会以代办社保、帮老人早日享受养老金为由，谎称认识人社局、社保局等部门的工作人员，欺骗老年人向其一次性补缴社保费用，或者冒充银行、保险机构的工作人员以代办社保为由，向老年人收取所谓的材料费、好处费等。上当的老人都是在领取养老金的驱使下轻信他人，而未通过官方渠道了解社保政策以及业务办理。养老骗局利用了老人期待收益回报、渴望安度晚年的心理，且套路设计越来越具迷惑性。后续，浦发银行北京分行还将强化防范养老诈骗常态化宣传，并切实保障老年人的财产安全，为广大老年朋友安享幸福晚年筑牢安全防线。此文内容为企业供稿，仅供参考
