2023-08-03 08:50，正文：荆楚网（湖北日报网）讯（记者 黄铮 通讯员 卢志广）8月2日下午，德国Carbonauten公司负碳材料中国总部基地项目签约仪式在湖北咸宁举行，这也意味着计划总投资15亿欧元的负碳材料项目将落地咸宁赤壁。 德国Carbonauten公司是一家致力于碳中和的环保技术及新材料创新公司，主要研发以竹子为主要原料的各类负碳材料，可实现“全竹利用”，产品市场前景广阔。咸宁市是全国知名的“楠竹之乡”，湖北楠竹主产区，具备竹产业基础。签约现场。黄铮 摄据介绍，该公司选择投资咸宁，不仅考虑到了咸宁丰富的竹资源与优秀的区位条件，还感受到了当地优良的营商环境。 预计项目一期建成后，最高年产各类生物基代塑负碳复合材料20万吨，生物基植物生长刺激素1600万升，可再生能源（热能、电能及氢能）不低于160Gwh，形成碳信用不低于10万吨。据悉，赤壁市已在赤壁高新区中伙光谷产业园规划用地100亩，用于一期精深加工项目建设。在官塘驿镇规划两块总面积185亩地块，用于原料初加工项目。咸宁市将全面落实《中华人民共和国外商投资法》及其实施条例，对标国际标准，打造市场化、法治化、国际化的一流营商环境，推动项目早开工、早投产、早达效，实现生态环境保护和经济发展双赢。
