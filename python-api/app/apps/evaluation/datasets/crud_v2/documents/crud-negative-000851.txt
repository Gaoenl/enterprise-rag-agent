2023-07-27 17:22，正文：原标题：甘州区西街街道北关社区开展“缤纷夏日 青春同行”未成年暑期读书活动甘州区西街街道北关社区开展“缤纷夏日 青春同行”未成年暑期读书活动 甘州融媒讯 为了让辖区未成年人度过一个快乐、充实、有意义的暑假，7月24日，甘州区西街街道北关社区组织辖区内未成年人开展以“缤纷夏日 青春同行”为主题的读书活动。活动当天，孩子们在社区志愿者的带领下来到社区社会化管理服务中心图书角开始阅读自己喜欢的书籍。静静地阅读了近两个小时后，大家开始交流读书心得，并相互推荐、介绍自己喜欢的书籍，一起分享知识大餐。现场气氛十分活跃，营造了浓厚的读书氛围。“读书活动太好啦，让孩子们的假期更有意义，希望社区以后多开展这样的活动，我们绝对支持！”李新宇妈妈开心地说。此次读书活动，不仅使孩子们开阔了眼界，了解了更多的知识，同时也激发了学生的阅读兴趣，引导孩子们愿意读书、读好书、好读书，受到孩子家长的一致好评。西街街道北关社区还将继续在暑假期间向孩子们开放图书角，供孩子们假期阅读学习，不仅能够分担家长对子女暑期生活安排的困难，还为孩子们度过一个充实而有意义的暑假打下了良好的基础。（罗小芳）返回搜狐，查看更多责任编辑：
