2023-07-26 14:45，正文：原标题：安徽省大学生社会实践采风创意艺术大赛在淮北举办7月18日—7月20日，在团省委和省学联指导下，团淮北市委和团烈山区委联合承办的2023年“夏日同行 青采有你”安徽省大学生社会实践采风创意艺术大赛(二期、三期)成功举办，此次活动分为视频宣传创作大赛、非遗创意设计大赛2项活动。来自安徽中医药大学、淮北师范大学、滁州学院、合肥城市学院、芜湖职业技术学院、淮北职业技术学院6所高校的35名青年学子参加。组织参赛省内高校青年学子拍摄全域旅游自然风景。杜磊摄参赛省内高校参赛学子走进“一群三链”重点企业参观宣传企业发展。杜磊摄在视频宣传创作大赛阶段，分文旅产业、“一群三链”重点产业、红色文化等3个主题，选取皖北川藏线、明清石榴园、青年公园为文旅产业缩影，选取国安电力、国晟新能源、和晶科技为企业发展代表，选取四眼井纪念馆、军王村后方医院为红色文化品牌，参赛学子通过实地参观，分主题开展宣传视频创作。在抖音平台创建“青采有你 记忆烈山”话题，截至目前，已上传创作高质量的自媒体宣传视频20余个。省内高校青年学子现场体验部分烈山非遗的制作过程。杜磊摄省内高校青年学子参观中国石榴博物馆。杜磊摄参赛省内高校青年学子实地参观非遗的制作过程。杜磊摄在非遗创意设计大赛阶段，组织高校学子参加非遗文化推介会，参观了中国石榴博物馆非遗展厅，互动体验了淮北花馍、孙氏面塑的制作过程，实地参观了李氏布鞋、洪庄编织、榴园地锅鸡的制作过程，在丰富省内大学生来淮实践活动的同时，加入烈山非遗文化的发展阵营，围绕非遗logo设计、非遗包装礼盒设计、非遗新体验等3个方面进行创意设计，构建非遗与创意的连接，超越空间和时间，让非遗以创新的形式存在。组织开展省内高校青年人才交流活动。杜磊摄此外，活动期间，在四季榴园景区露营地，举办“汇聚青才智 携手振兴路”省内高校青年人才交流活动，采取音乐会的形式，邀请和晶科技总经理马阳春、隐庐酒店负责人邵景卫高校青年学子一起共赴人才盛会、共话青春理想，在轻松愉悦的氛围中宣讲人才政策，并诚邀青年学子来淮就业创业。(杜磊 吴朝曦)返回搜狐，查看更多责任编辑：
