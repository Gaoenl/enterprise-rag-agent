2023-07-28 00:33，正文：原标题：赛富时曾投诉 微软Teams面临欧盟反垄断调查欧盟委员会周四表示，已针对微软将其通信应用Teams与其广受欢迎的办公应用Office套件捆绑销售的行为展开反垄断调查。欧盟反垄断监管机构表示，微软的这一行为可能使Teams较竞争对手更具优势。此次调查旨在了解微软是否通过这种做法“滥用和捍卫其市场地位”。对此，微软发言人表示：“我们尊重欧盟委员会在此案中的工作，并非常认真地对待我们自己的责任。”“我们将继续与欧盟委员会合作，并继续致力于寻找解决方案，以解决其关切。”据悉，早在2020年，赛富时旗下的Slack应用程序就已提出投诉，称微软滥用其市场主导地位，通过将Teams与Office相捆绑消除了Teams面临的竞争。批评人士表示，微软利用其在电脑软件方面的影响力，使Teams成为已经在使用Office软件的远程工作者最可行的选择。多年来，微软一直面临来自美国和欧洲的反垄断机构的压力，该公司被指控不公平地捆绑销售产品，并阻止竞争对手使用桌面版Windows软件。不过，自2013年因未遵守提供浏览器选择的承诺而被罚款以来，微软在过去十年内没有面临过欧盟主导的审查。来源：智通财经返回搜狐，查看更多责任编辑：
