2023年08月14日 07:21:39，正文：“今天体验了‘即买即退’的退税服务，能够在大运通APP上操作，非常明了易懂，谢谢你们。”日前，来成都观看大运会的日本游客桥本纱良在春熙路百盛购物中心四川时代店购物后现场办理了离境退税即买即退业务，即刻收到了108.57元的退税，并在其中国朋友的协助下向店员表示了感谢。 2023年夏天，伴随着大运会的举办，越来越多境外旅客来到成都，共享青春盛会。近日，记者从国家税务总局成都市税务局获悉，从7月22日大运村开村截至8月8日，成都已为来自55个国家或地区的338名客人开具414份离境退税申请单，商品销售额407万元，同时办理离境退税24万余元。大运会辐射带动着相关入境消费场景热度直线攀升，商家们有着最直观的感受。在荷花池，一拨又一拨的境外旅客寻找而来，让人眼花缭乱又实用的小商品让外国朋友流连忘返。荷花池商家成胜商贸部负责人陈西燕介绍道：“虽然语言不通，但是靠着软件翻译，我向阿塞拜疆的小伙子介绍了我们成都的火锅，当然还有荷花池商圈的各类小商品。”今年以来，截至8月8日，成都境外旅客购物离境退税迎来爆发式增长，离境退税申请达到471笔，累计退税销售额1843万元，退税147万元。全市退税商店总数已达320家，其中“即买即退”商店达到22家，全市离境退税“地图”持续点亮。（记者 李艳玲）（来源：成都日报）
