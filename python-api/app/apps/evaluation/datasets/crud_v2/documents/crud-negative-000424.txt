2023-08-14 11:24，正文：原标题：宝丰县检察院开展企业合规审查普法宣讲活动河南日报客户端记者 张海涛 王冰珂8月10日，平顶山市宝丰县检察院组织法治宣讲团队，深入平煤神马京宝化工科技股份有限公司（京宝化工），开展企业合规普法宣讲活动，组织干警向企业职工发放法律宣传手册，深入推进企业合规改革工作，增强企业职工的安全意识和法治观念，严防涉企案件发生，持续优化法治营商环境，为企业提供更加优质高效的司法服务，助力企业健康发展。据了解，活动中宝丰县检察院第二检察部主任韩莉芳紧紧围绕企业九大刑事法律风险，详细讲解涉案企业刑事合规改革制度，列举法条罪名，阐述预防犯罪和诉源治理，强调从源头遏制企业刑事犯罪、职务犯罪。对企业在经营中可能遇到的法律风险进行提示，并提出合规经营建议，引导企业职工牢固树立法律意识，增强法治观念。宝丰县检察院第一检察部副主任李辉结合企业实际，融入自身办案经历，通过污染环境罪，从生态文明保护的重要意义、表现、原因、措施四个方面入手，结合典型案例剖析，帮助企业职工增强法律意识、合规意识，宣讲采用的案例生动实用，通过以案释法，为企业敲响依法守法经营的警钟。市律师协会副会长陈鹏阁宣讲民法典的前世今生，强调民法典的重要性和现实意义，通过讲解公司规章制度能否成为裁判依据，自然人和公民的区别，胎儿的民事权利能力等，以一当万，让大家真正学到东西。在互动环节，企业职工代表畅所欲言并提出问题，涉及外包监测业务，企业合规经营，固体废料处理等各方面，检察官通过剖析犯罪构成要件、犯罪根源及预防措施、经营许可证等客体要件、《安全生产法》等相关法律法规，为企业讲授了一堂生动的普法课。“这次宣讲课极具理念深度和政治高度，也有针对性，帮助企业职工增长认识、开拓眼界。我们将建立健全内部机制，通过培训、学习、考试等方式，使各项措施落实、落细、落地，不断提升企业职工守法力度，推动企业健康良性高质量发展。同时，期待检察官们能经常开展法治宣讲，帮助企业防范法律风险，为企业发展保驾护航。”该企业党委书记、董事长王兴生说。返回搜狐，查看更多责任编辑：
