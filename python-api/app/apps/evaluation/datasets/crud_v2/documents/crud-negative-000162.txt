2023-08-14 17:53，正文：#时事热点头条说#首先根据中国外交部官网的消息，2023年8月10日，外交部副部长马朝旭会见了来华参加中越外交磋商的越南常务副外长阮明羽，此次会谈也是直奔主题！马朝旭开门见山的表示，中越是社会主义友好邻邦，是具有战略意义的命运共同体，中方愿同越方一道，落实好两党两国领导人重要共识推动构建中越命运共同体。而阮明羽则表示，发展越中关系，是越南对外政策的战略选择和头等优先，越方愿同中方共同落实好高层共识，加强交往，深化合作，推动越中全面战略合作伙伴关系取得更大发展。其中值得注意的一点是，此次双方会谈是建立在美国总统拜登访问越南的前提下进行的。大家可想而知其中的微妙之处，然而人还没到，拜登已经开始向越南释放了一大重要信号，则是希望越南提升与美国的关系，成为美国的主要合作伙伴，然而阮明羽的一句愿同中方共同落实好高层共识，加强交往，深化合作直接让拜登啪啪打脸！2023年对于美国与越南之间来说关系比较特殊，毕竟今年是两国建立全面伙伴关系第十年，早在今年4月份时，拜登就曾派国务卿布林肯出访越南，并重点讨论到了安全问题，称是美越关系的“重要组成部分”。除此之外，早在今年7月下旬，美国财政部长耶伦也访问越南，表示希望进一步深化两国经贸投资关系，尽快实现两国关系升级，不过，对于拜登单方面勾勒的美越关系，越方从未正面回应此类消息，由此看来，拜登突然放风将访问越南。可谓是尴尬之际，早前，越南外长随越南总理访华时早已明确表态，与中国发展关系是越南的头等优先，不言而喻，在中美之间的立场问题上，越南的态度可以说是非常明确，其实越南能够主动向中国靠拢，其实也不以为然，从经济层面来说，东盟是中国的第一大贸易伙伴，为此，连在中美之间“摇摆不定”的菲律宾，也舍不得中国的经济红利。就越南而言，该国是2022年与中方所达成贸易额最高的东盟国家，超过两千亿美元，是美越去年贸易额的快两倍，从政治层面来看，中国与越南发展关系。不针对第三方，也不受制于第三方，但美国却不一样，与越南交好，更多只是想要利用越南在南海给中国制造麻烦。
