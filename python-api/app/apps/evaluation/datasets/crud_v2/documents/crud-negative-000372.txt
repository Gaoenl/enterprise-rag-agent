12月6日，区委副书记、区长周海鹰主持召开区政府第67次常务会议，邀请专家学者作专题讲座，三位公众代表列席参与审议相关议题。区领导尼冰、吴雷、于洋、李奇楠、祁克萍参加。上海交通大学设计学院建筑学系王林教授围绕“城市更新”的主题，从人民城市理念与城市更新发展、城市更新类型模式及实践探索、对城市更新发展与未来的思考三方面，为大家讲授了人民城市理念下的城市更新模式，王林教授的讲座视野开阔、案例详实、借鉴性强，既有国际经验，也有上海实践，为大家了解城市更新的前沿思想、拓展工作思路提供了有力指导。周海鹰指出，当前，杨浦的城市更新正逐步迈入全新阶段，从大规模的增量建设转向存量更新，从外延扩张转向内涵提升，从大拆大建走向精细治理。要在城市更新工作中进一步融入专业力量，不断优化“社区规划师”机制、壮大规划师队伍，指导老旧小区改造和更新等各项社区规划工作，更大程度地发挥专业所长和杨浦的独特优势，共建更加靓丽的人民城市形象。要进一步回应群众需求，从人民群众最关心的问题出发，统筹吃住行娱、商旅文体、为老亲子、卫生教育等多元供给，顺应群众期盼，解决群众需求，把城市更新作为践行全过程人民民主的生动实践。要进一步结合创新发展，推进区域空间焕新、新旧动能转换，让历史建筑魅力重塑、低效用地转型升级，积极探索可持续的城市更新新模式、新路径、新机制，打造城市更新转型示范样本。会议还邀请了公众代表参与《杨浦区关于促进生命健康产业高质量发展的若干意见（试行）》制定情况的议题审议。杨浦区新联会副会长、上海同化益生纤生物技术有限公司创始人、董事长张楠，杨浦区新联会理事、上海优宁维生物科技股份有限公司董事长冷兆武，微医集团高级副总裁、上海微医数智健共体医疗管理有限公司董事长邱凯三位公众代表结合专业背景对杨浦生命健康产业高质量发展建言献策。周海鹰感谢三位公众代表对《意见》提出富有价值、具有前瞻性的意见建议，丰富了政府的视野，提高了政府审议能力。相关部门认真吸收研究，转化为工作举措。他表示，要抓紧建立产业链工作机制。在前期底数排摸的基础上，按照已基本成型的产业链链长制工作方案，做好产业链图谱分析，统筹企业、平台、智库等资源，加快建立产业链工作机制。要加快打造活跃创新生态。充分发挥高校科研优势，搭建好产学研用融合平台，更好支持区内企业创新迭代，支持医疗器械、先进医药就地转化，为生命健康产业规模壮大提供不竭动力。要持续开展政策评估优化。在广泛宣传推介政策、推动落地见效的基础上，深入分析产业发展和企业经营中遇到的新问题新挑战，评估政策的成效，及时优化政策举措，更好助力产业发展。文字：封辰霏图片：王修远原标题：《专家学者公众代表汇智聚力谋发展丨区政府第67次常务会议召开》阅读原文
