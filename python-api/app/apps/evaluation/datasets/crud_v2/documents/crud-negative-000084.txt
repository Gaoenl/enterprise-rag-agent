2023-08-09 12:20，正文：原标题：媒体关注中国前7个月出口同比增长1.5%参考消息网8月9日报道据美国《华尔街日报》网站8月8日报道，中国海关总署8日公布的数据显示，以人民币计，中国今年1-7月出口同比增长1.5%，进口同比下降1.1%，实现贸易顺差3.39万亿元，扩大10.3%。以人民币计，2022年中国出口同比增长10.5%，进口同比增长4.3%，贸易顺差约5.86万亿元。另据法新社8月8日报道，在世界第二大经济体面临全球需求疲软和国内经济放缓的挑战之际，8日公布的以美元计数据显示，7月中国出口总值同比下降14.5%。近几个月来，美国和欧洲陷入衰退的可能性以及通胀高企导致国际上对中国产品的需求持续减弱。与此同时，7月份的进口总值同比下降12.4%。中国领导层此前警告经济运行面临新的困难挑战，重点领域风险隐患较多。有关部门前不久发布了关于恢复和扩大消费的20条措施，涉及住房、旅游、汽车以及绿色消费等领域。近几周来，央行也多次降息，以提振经济。此外，据香港《南华早报》网站8月8日报道，8日公布的数据显示，7月中国出口下降，这加剧了人们对经济放缓的担忧。凯投国际宏观经济咨询公司的分析师们说：“最近的下降主要反映了价格下降，而不是数量下降。”他们认为，国内需求最近也有所走软，但政策支持应该有助于在未来数月内一定程度上扭转这种情况。2023年7月11日，在江苏省太仓港国际集装箱码头，一批新能源汽车即将通过专用框架运输方式出口（无人机全景照片）。（新华社）返回搜狐，查看更多责任编辑：
