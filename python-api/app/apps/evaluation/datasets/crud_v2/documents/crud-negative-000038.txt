2023-07-26 09:12，正文：原标题：《财富》中国500强榜揭晓 四川9家总部企业上榜7月25日，2023年《财富》中国500强排行榜揭晓，国家电网有限公司、中国石油天然气集团有限公司、中国石油化工集团有限公司分别位于此次发布的榜单前三。榜单显示，四川有9家总部企业上榜，其中包括新希望控股集团有限公司、蜀道投资集团有限责任公司、通威集团有限公司、成都兴城投资集团有限公司等。据了解，今年500家上榜的中国公司在2022年的总营业收入达到15万亿美元，净利润达到7171亿美元。国家电网有限公司以5300亿美元的营收位居榜首，中国石油和中国石化分列榜单第二位和第三位，位列第四位的是中国建筑集团。榜单显示，新能源领域的两家头部公司，营收相较上年增长巨大——宁德时代营收达到488亿美元，较上年增长141%；比亚迪营收增长92%，达到630亿美元。另外，金属产品行业共有56家公司上榜，是今年上榜公司数量最多的行业，上榜公司收入总额达1.4万亿美元。在盈利能力方面，最赚钱的10家上榜公司中，除5家商业银行和中石油、中海油、中移动外，两家私营企业也进入了前十位，其中腾讯的净利润比上年下降了19%，但仍以超过279亿美元的净利润排在利润榜第6位。这十家公司去年的总利润约为3087亿美元，约占上榜公司利润总和的43%。（成都日报锦观新闻记者 杨富 刘泰山）原标题：《财富》中国500强榜揭晓 四川9家总部企业上榜编辑：张烁 责编：董乐 返回搜狐，查看更多责任编辑：
