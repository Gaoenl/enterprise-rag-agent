2023-08-08 15:18，正文：原标题：泰兴济川街道：文明实践不打烊 七彩夏日夜来俏今年夏天，泰兴市济川街道将文明实践融入夏季夜市生活，精准对接群众需求，创新文明实践夜间场景，推动文明实践“活”起来、“热”起来。接地气、有活力的文化活动和志愿服务，让居民群众感受幸福济川新魅力，带来了最“嗨”的消暑方式。举办星空书会，用阅读点亮灿烂夏夜。8月4日傍晚，在张陈社区滨河家园小广场，一场趣味魔术秀正在开展，罗圈现彩、魔袋对联、绳环逃脱等精彩节目，引得现场观众齐齐叫好。在广场另一角，文明家庭代表顾红老师以家庭阅读计划如何养成为主题，开展互动分享，邀请现场青少年踊跃参与故事朗诵。情景剧《你睡不着吗》为现场观众演绎了当下家庭教育的故事，让大家了解到阅读作为家庭教育的重要方式有着不可替代的作用，孩子和父母能够在阅读中共享情感，体悟人生。好书推荐《婷婷的树》《神笔马良》，从不同角度切入，畅谈心得体会，并邀请大家写下阅读感言贴到社区阅读树上。活动尾声，文明城市创建问答泡泡秀的到来让现场高潮再现，小礼品泡泡水和飞碟，让夜空更添色彩。解锁公益夜市，用服务助燃城市烟火。跃进社区依托商业广场等群众聚集的夜间活动场所，不断丰富夜间实践活动菜单，为新时代文明实践“充电续航”。在夏日集市上，志愿者秀摆摊，展服务，为群众送上了丰富的“惠民礼包”，吸引了大量居民群众前来“赶夜集”。全民阅读摊位上以书易物，“换”醒沉睡旧书，分享阅读的快乐；理论小摊上，开展“学习强国”宣传推广工作，引导广大群众利用学习平台在线学理论、学知识；文明城市创建摊位上，居民们扫码参加创建应知应会闯关，赢得精美的创建文创奖品......文明实践活动丰富城市烟火气，加码群众幸福生活。开展赋能夜学，用知识蓄能精彩生活。“人无礼不立，事无礼不成。”为进一步引导辖区青少年从小践礼修德，知礼明德，济川街道南殷村组织了以“八礼四仪”为主要内容的文明礼仪夜学课堂，通过宣讲介绍，为孩子们提供知识普活动，促进少年儿童养成讲文明、懂礼貌、有道德的良好品质和行为习惯。“文明实践接地气、聚人气、有活力，在这个夏夜，我们将继续加强资源整合，拧成一股绳，持续打造精彩纷呈、引人入胜的文明实践夜生活，巩固与居民群众之间的文明链接，更好满足群众对夜生活的精神文化需求。”济川街道党工委副书记李鹏表示。（朱洁 张国暖 卞美艳 殷立峰）返回搜狐，查看更多责任编辑：
