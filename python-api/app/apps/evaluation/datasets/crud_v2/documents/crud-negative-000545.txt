今年以来，市人社部门积极贯彻落实国家和省、市关于稳就业的决策部署，多方发力，创优环境，各类重点群体就业工作稳步推进，城乡就业形势总体稳定，全市就业工作取得积极成效。截至10月底，全市实现新增就业40589人，完成年度目标任务的98.28%。今年以来，马鞍山市积极开展“千企万岗进校园”系列活动，线上联合智联招聘搭建“百校千企　才聚诗城”云招聘平台，同时在市内6所、市外20所高校建立人才工作站，广泛招引高校毕业生来马就业创业，共开展各类线上、线下招聘活动71场，登记岗位4.4万个，达成就业意向1.62万人次。加强就业培训，提升求职能力。市人社部门积极推进求职能力实训营项目，针对未就业青年开展求职能力实训营活动，通过求职能力实训与就业帮扶相结合，全力打造就业服务新模式。截至目前，实训营已举办11期，330余名青年群体参加求职能力实训。加强校企对接交流，吸引更多大学毕业生在马就业创业。马鞍山市组织重点企业与在马高校共同举办2023年留马就业校企合作座谈会，建立校企合作工作机制和平台。开展“马上就业”高校直通车活动，邀请江苏科技大学、安徽师范大学等省内外高校来马鞍山市走访相关企业，开展对接交流。2023年，全市6所高校应届毕业生2.12万人，毕业去向落实率达89.94%；留马就业4352人，留马就业率达28.28%，较去年同期增加2.42个百分点。为精准保障企业招工用工，马鞍山市健全服务机制，建立企业用工“白名单”制度，各级人社部门成立包保工作组，帮助企业解决用工4246人。推行“用工管家”制度，选派286名业务骨干担任企业“用工管家”，为企业提供用工指导等“一对一”跟踪服务。针对农民工、残疾人、妇女、退役军人等群体，常态化开展“2+N”招聘活动，组织线上线下招聘会1739场，参加企业2.1万家次，提供岗位36.55万个，达成就业意向3.33万人次。积极实施“聚马行动”计划，组织马鞍山市重点企业赴省外开展跨区域劳务对接，吸引1000余名务工人员来马鞍山市就业。马鞍山市还积极落实各项惠企政策，充分发挥失业保险助企扩岗作用，鼓励企业积极吸纳大学生就业。1至10月，失业保险经办机构采取“免申即享”“自主申报”等模式，主动向92家符合条件的企业发放一次性扩岗补助45.5万元。抓紧梳理失业保险参保缴费数据，持续加大失业保险稳岗返还力度，已向1.19万户企业返还失业保险稳岗资金6680万元。积极落实企业职工岗位技能提升补贴政策，引导企业、个人申报技能提升补贴，简化办理流程，共受理并审核7000多名参保职工提升技能补贴申请，支付补贴资金1100多万元。全面落实各项社保补贴政策，用好就业补助资金，精简优化业务办理流程，为企业和群众提供更加优质便捷高效的服务。1至10月，累计兑现单位社保补贴535.19万元，灵活就业人员社保补贴312.86万元，一次性就业补贴17.1万元。
