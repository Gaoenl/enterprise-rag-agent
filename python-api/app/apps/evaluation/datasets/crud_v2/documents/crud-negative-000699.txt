2023年08月10日 14:49:00 来自湖北，正文：极目新闻记者 刘琴8月10日凌晨，陕西一网友发布视频称，自己守店时被一名前来扫码租用共享充电宝的男子殴打，不过他没有还手。有网友评论称“这么大体格白长了”“怂”。10日上午，极目新闻记者从处理此事的派出所了解到，案件正在调查。280斤男子守店被人殴打（视频截图）视频显示，一名身穿黑色T恤、肩上披着一条蓝色毛巾的男子站在店门口的共享充电宝的机柜旁，用手机扫描机柜上的二维码后，他用脚踢了一下机柜，之后转身与坐在店门口台阶上身穿黄色上衣的男子交流，其间黄衣男子起身后又坐下，黑衣男子继续用手机扫描机柜的二维码，可是没有成功。之后黑衣男子走到黄衣男子面前，俯身说话，还用手托起黄衣男子的下巴，之后突然用拳头打向黄衣男子的脸部。“280斤的我无故被人打了。”网友发布视频时配文写道。有不少网友评论称“这么大体格白长了”“怂”，不过也有网友称“不还手是对的，还手就会被认定为互殴”。8月10日上午，被打男子李先生告诉极目新闻记者，他是西安市未央区启航佳苑小区一家24小时便利店的店员，9日当天他上夜班，从晚8点开始上班。由于不能在店内抽烟，当晚9时10分许，他到店外台阶上坐着抽烟，黑衣男子因扫描租用共享充电宝失败，于是用脚踢了踢机柜，坐在一旁的他说“你踢它也出不来”，黑衣男子反问“跟你有什么关系”。之后黑衣男子依然没能成功租用共享充电宝，手机还因没电关机了。“他没扫上充电宝，开始怪我，之后还骂我甚至动手，说我打也不敢还手，骂也不还口。”李先生说，他在忍无可忍的情况下骂了对方，对方就打了他，“三拳打在脸上，一拳打在胳膊上。”李先生称，事后他联系了便利店的老板，老板要带他去医院检查，但考虑到店面无人看管，身体也无大碍，因此没有去医院。当晚，李先生报了警，但警察到场后未找到打人的黑衣男子，李先生说：“当晚到隔壁理发店找他，但他洗完头就离开了，周边也没看见他。”10日早上8点，李先生下班回家休息，睁开眼发现不少网友在自己的社交账号上评论或留言，“有网友说我不还手是怂，可是我要是还手了，这件事就麻烦了，不仅给自己找麻烦，给我老板也会带来麻烦。”8月10日上午，极目新闻记者从处理此事的派出所工作人员了解到，案件正在调查中，但工作人员表示具体情况不便透露。
