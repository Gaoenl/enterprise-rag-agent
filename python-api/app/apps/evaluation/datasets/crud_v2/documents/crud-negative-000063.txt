2023-08-08 16:34:14，正文：今年是中国人民解放军建军96周年，也是纪念延安双拥运动80周年。为深入贯彻落实党中央、国务院、中央军委关于加强军政军民团结的决策部署，巩固和发展新形势下军政、军民关系，营造尊崇军人、崇尚英雄的良好氛围，8月1日，普陀区教育局机关党支部赴武警上海市总队某部开展了“共筑双拥家国梦，深化军民鱼水情”主题党日暨建军节双拥活动。普陀区教育工作党委副书记、教育局局长赵平，武警上海市总队某部上校政治委员、党委书记白文，以及区教育局领导班子、机关干部，武警上海市总队某部官兵参加活动。赵平代表普陀区教育工作党委、区教育局向武警上海市总队某部全体官兵致以节日问候并赠送了防暑慰问品。局机关干部观看了武警战士会操，参观了武器装备库、指挥中心、荣誉室、武警内务等。嘹亮的呼号、铿锵的步伐、挺拔的身姿、如炬的目光，展现了新时代中国军人斗志昂扬的精神风貌。局机关干部还参观了造币博物馆的造币工艺厅和当代造币厅，了解了近代造币工艺的设备和流程，学习了中国造币事业的发展沿革。当代造币厅里陈列着新中国各个时期生产的具有代表性的钱币产品，在显微镜下能清晰看到硬币上的微缩图案，记录着近代中国史上发生的重大事件。造币博物馆讲解员向局机关干部详细讲解了一枚硬币由原料称重、熔化浇铸、轧片、冲制坯饼、光变、压印、雕刻的完整工序，以及近现代造币发展历史和钱币知识，大家感受到了“为国造币”的庄严与神圣，也认识到了钱币在稳定全国币制乃至金融秩序方面所起的历史性作用。普陀区教育局将全面落实拥军优属政策，进一步巩固发展和谐的军民关系，全力做好新时代双拥工作，用心用情解决实际问题，积极支持国防和军队建设，持续巩固坚如磐石的军政军民团结，携手谱写军民鱼水情深时代新篇。
