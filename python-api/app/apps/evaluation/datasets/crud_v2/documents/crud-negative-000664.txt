2023-08-09 15:53，正文：原标题：九龙坡区：玩转暑假 垃圾分类实践活动趣味浓九龙坡区：玩转暑假 垃圾分类实践活动趣味浓 来源：人民网－重庆频道 原创稿小朋友们描绘垃圾分类主题环保袋。主办方供图人民网重庆8月9日电 (记者胡虹)为丰富辖区小朋友们的暑期生活，呼吁更多志愿者参与垃圾分类，8日上午，九龙坡区生活垃圾分类工作领导小组办公室组织开展“垃圾分类我践行·争当环保小卫士”暑期实践活动，希望通过以小手拉大手的形式，实现“教育一个学生、带动一个家庭、辐射整个社会”的宣传效果，营造全民参与垃圾分类的良好氛围，弘扬垃圾分类的文明新风。活动现场，区分类办工作人员通过开展垃圾分类大讲堂和发放垃圾分类宣传资料，向小朋友们讲解垃圾分类的意义以及如何正确分类垃圾等，使其对垃圾分类的理解更加深入。同时，寓教于乐，让小朋友们拿起画笔描绘垃圾分类主题环保袋，鼓励他们认真学习垃圾分类知识，并把现场学到的知识带给家人、朋友，为环境保护贡献自己的一份力量。小朋友给居民宣传垃圾分类知识。主办方供图学以致用的他们立即投入到“小小督导员”的队伍中，一批可爱又勤劳的小小志愿者们上线了，他们手里拿垃圾分类宣传单，一边向居民发放讲解垃圾分类知识，一边引导过往群众正确进行垃圾分类。通过“看桶”“守桶”，有效劝导居民树立垃圾分类意识。为了表彰小小志愿者们的辛勤付出和积极参与，活动最后，区分类办向参加活动的25名小朋友颁发了“垃圾分类环保小卫士”聘书。希望他们今后能积极参与垃圾分类宣传、引导、巡查工作，助推全区垃圾分类工作。小朋友获得了“垃圾分类环保小卫士”聘书。主办方供图此次垃圾分类活动增强了青少年的环保意识和责任感，使小朋友们对垃圾分类有更多的了解和认识。下一步，九龙坡区将持续推进垃圾分类宣传教育工作，通过丰富多彩的活动形式，让垃圾分类环保理念走进社区，走进千家万户，营造全民参与垃圾分类的浓厚氛围。返回搜狐，查看更多责任编辑：
