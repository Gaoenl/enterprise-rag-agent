文/羊城晚报全媒体记者 黄宙辉 实习生 谢珂婧 通讯员 穗文广旅宣图/羊城晚报全媒体记者 贺全胜8月15日-17日，首届穗港澳影视产业项目对接会在广州举办。来自香港、澳门、广州三地共52家影视机构、行业协会及重点网络平台的相关负责人齐聚一堂，推动穗港澳影视项目深度合作，探讨交流影视产业协同发展。活动共同发布了《加强穗港澳影视产业协作倡议书》，进行了影视剧目、协拍服务、影视产业园区等专场推介，达成了《饮早茶》等影视项目合作。本次活动由中央政府驻港联络办宣传文体部、中央政府驻澳联络办宣传文化部、广东省广播电视局、中共广州市委宣传部指导，广州市文化广电旅游局主办，香港特区政府文化体育及旅游局、澳门特区政府文化局协办，旨在发挥穗港澳三地影视全链条产业优势，携手共创大湾区影视文化名片，助推影视行业高水平开放发展。三地将签约一批影视产业项目在为期三天的首届穗港澳影视产业项目对接会上，主办方将推出主题分享会、专场推介、作品展映、项目签约等一系列活动，促进穗港澳影视企业进一步开展深度合作、共谋发展。在8月15日的开幕式上，广州市广播电视台党委书记、台长崔颂东，香港电影发展局主席及文化委员会副主席王英伟博士，澳门澳涞坞电影集团主席、澳涞坞电影工作者总会会长、世界电影产业大会主席王海歌先生进行了主旨演讲，并联合发布《加强穗港澳影视产业协作倡议书》。在穗港澳影视产业项目推介环节，包括电视剧《我在湾区等你来》《江海情》以及湾区题材纪录片重点项目进行推介。当晚，主办方还推出以“映见广州”为主题的穗港澳影视作品展映，共有16家影视机构的36部作品参与展映，其中电影《暗杀风暴》将于8月18日全国上映，进军暑期档。此外，在8月16日举办的穗港澳影视产业推介大会上，港澳影视专场推介、广州影视专场推介将陆续登场；8月17日闭幕日当天，主办方还将推出穗港澳影视产业项目签约仪式，届时将有一系列对接成果。穗港澳影视产业合作大有可为主办方表示，穗港澳文脉相亲，文明相连，历史文化一脉相承。近年来，国家对影视产业的扶持力度空前之大，影视行业迎来了发展“黄金期”。同时，“影视文化出海”形式更多元、渠道更开放，“出海”又“出圈”的文化产品加速走向全球，影视文化贸易焕发勃勃生机。在共同的基础上，穗港澳三地影视产业合作前景广阔、大有可为。近年来，广州市文化广电旅游局努力探索港澳传播和国际传播的有效途径，指导各播出单位和网络视听机构充分发挥粤语的情感认同与方言优势，以广州广播电视台驻香港记者站为支点、《湾区全媒睇》等优势栏目为主要抓手，与澳门广播电视股份有限公司达成战略合作，建立良好的常态化合作机制。同时，广州连续成功举办中国（广州）国际儿童电影展、中国（广州）国际纪录片节等国际国内电影节展、电影合作论坛，影视产业整体环境不断优化提升，呈现出较强的内生动力和可持续性。未来，穗港澳三地将促进影视产业高效协同发展，构建产业链条完善、结构布局合理、技术水平先进、经济效益显著的影视产业良好格局，实现三地影视产业可持续、一体化发展。【延伸阅读】广州影视产业发展生机勃勃广州文化产业基础扎实，与香港和澳门的影视产业合作前景美好。2023年上半年，广州文化产业各项政策显效发力，文化产业提速恢复发展，文化新业态引领作用明显，文化娱乐休闲服务领域呈现强劲复苏势头。数据显示，全市共有规模以上文化及相关产业法人单位3313个，实现营业收入2571.79亿元，同比增长15.7%，增速高于全国平均增速8.4个百分点。此外，广州拥有深厚的历史底蕴和独特的城市魅力，吸引了全国影视剧导演们争相到广州取景拍摄。被誉为“南国红豆，璀璨明珠”的粤剧也为广州影视产业注入了源源不断的动力，如粤剧《碉楼》《搜书院》、粤剧电影《南越宫词》等，都是精耕传统广州文化，挖掘广州本地特色创作而成。《粤港澳大湾区发展规划纲要》实施以来，一大批影视剧目在广州立项，一大批影视创作生产骨干企业在广州做大做强，绘就了一幅生机勃勃的影视产业发展画卷。博纳影业集团、英皇娱乐大湾区总部、寰亚娱乐大湾区总部、上海联瑞等头部企业相继落户。咏声动漫、易动文化创立了“猪猪侠”“百变校巴”“雄狮少年”等一系列知名原创动漫IP。广州市文化广电旅游局相关负责人介绍，在现有《广州市文化和旅游产业发展专项资金管理办法》的激励促进基础上，广州还将研究拟制《广州市促进电视和网络剧片创作生产实施办法》，力求形成产业相对完善、结构布局合理、整体技术水平先进、经济效益显著的影视产业发展格局。未来，广州还将继续积极吸引更多影视企业投资落户，做大做强影视产业主体，促成更多影视产业项目，发展影视良好衍生生态，并推进产业结构优化升级，推动影视产业高质量发展。来源 | 羊城晚报·羊城派责编 | 周欣怡校对 | 彭继业举报/反馈
