2023-08-05 19:17，正文：原标题：“杀人预告”！无差别攻击！韩国多地发生持凶器伤人事件！警方首次宣布启动特别治安行动本文转自【央视财经】；近期，韩国多地发生持凶器伤人的恶性事件。4日下午，韩国警察厅宣布启动特别治安行动，集中部署警力和装备，严打犯罪，消除民众的不安恐慌情绪。据韩联社报道，这是韩国警方史上首次宣布启动特别治安行动。韩国警察厅长尹熙根当天表示，近期发生的多起恶性犯罪事件，已经严重威胁到国民安全。根据特别治安行动计划，韩国警方将最大限度投入警力，强化治安巡查，搜查疑似持凶器者和异常行为者。一旦出现持凶器伤人犯罪行为，警方将毫不迟疑使用枪支、电击枪等手段进行压制。此外，警方还将严厉打击在网上散布恶性犯罪预告及传播各类虚假消息的行为。 就在4日当天，韩国中部大田市一所高中发生持刀伤人事件，导致一名教师受伤，一名20多岁的男性犯罪嫌疑人被逮捕。警方称，嫌疑人和受伤教师相识。而在此前一天，也就是3日，城南市也发生一起持刀行凶事件，一名男子先是驾车冲向行人，又持刀进入商场对普通民众进行无差别攻击，导致14人受伤，其中12人重伤。犯罪嫌疑人被逮捕，警方称这名嫌疑人是一名快递员，存在心理健康问题。行凶犯罪事件频发引发了韩国民众的恐慌。 据韩国警方4日通报，自当地时间8月3日18时以后，网上总计出现了15篇预告行凶地点实施无差别袭击犯罪的帖文。韩国警方3日成立了专案小组，表示将严惩发布“杀人预告”的人员，同时在预告的地点部署大批警力预防凶案发生。返回搜狐，查看更多责任编辑：
