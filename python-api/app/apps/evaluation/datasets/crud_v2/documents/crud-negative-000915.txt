对于一家出版社而言，无论时间如何流逝，社会如何变迁，总有一些经典书籍屹立于岁月长河，凝结成常读常新的经典，构筑了出版机构的品牌形象，成为一代代读者难以磨灭的珍贵记忆。比如“古典四大名著”“茅盾文学奖获奖作品全集”之于人民文学出版社、《新华字典》《现代汉语词典》之于商务印书馆……它们都可称得上是“镇社之宝”了。徜徉位于上海长宁区的中版书房，一整面墙的“镇社之宝”和醒目的专架C位，给优质图书最好的礼遇。今年恰逢新中国成立70周年，“奋进70年 中版好书迎大庆——上海中版书房主题图书展”活动在中版书房揭开序幕，将持续至10月底。“中版家族”精选出的6000余种图书陈列展销，分5大主题展区——“中版家族”“镇社之宝”“主题图书”“社科精品”“走出去最佳案例”。“中版书房自成立以来，就是中国出版集团在上海的桥头堡，负责发行集团所有出版社的所有图书，包括中国历史最悠久的商务印书馆、中华书局、三联，也包括大众出版机构如人民文学出版社、人民音乐出版社、中国大百科出版社、东方出版中心等；服务上百个图书零售机构以及政企单位。”上海中版图书有限公司董事长刘佩英谈到，“挑真正好书以嘉学术、做优质活动以惠读者、创中版渠道以强品牌”是中版书房理念，本次图书展既是服务广大读者的文化盛宴，对出版人而言也是“中版家族”的完整亮相。光是“镇社之宝”，就凝聚了无数作者和出版人的情怀智慧，彰显了中华文化精神。谈及选书策展思路，中版书房店长刘厶瑀说，本次主题书展所选书籍大多选择了“中版家族”各大出版机构中具有历史意义的重点出版物。比如“镇社之宝”主题系列的34种图书中，人民文学出版社《四大名著》首次出版时间为1953年11月，最新出版时间为2017年12月；商务印书馆《辞源》首次出版时间为1915年，最新出版时间为2015年10月……展区里每本图书都有展签展示出版时间及内容简介，并附上二维码，读者扫一扫就能直观了解一本书的来龙去脉。由中国出版集团东方出版中心打造的中版书房，自今年上海书展开幕日落地成为最年轻的分会场，如今已汇入沪上醒目的书香风景。书房占地约400余平方米，整体设计风格素雅简洁，为“出版国家队”旗下38家出版单位设置了专有书架，计划举办“中版新书 上海发布”等持续性活动，摸索中版书房连锁建设之路。一进门，书房左侧上方一字排开“中版家族”旗下主打出版机构介绍及展区，每年中版集团出版图书和音像、电子、网络等出版物2万余种，期刊报纸57种，在全国零售市场占有率为7%左右，持续多年位居全国第一。“中版集团拥有丰富的作者与名家资源，开业一个多月，就广邀历史学家樊树志、祝勇，经济学家梁小民、李信忠，出版人于殿利、贺圣遂等名家线下见面活动多场，吸引读者千余人。”在刘佩英看来，立足中版集团文化积淀，中版书房将长期举办文化活动，促进全民阅读。书房集图书、茶咖、文创与演讲空间为一体，“无亦无”茶文化以及专属文创设计产品线，都为这一新型文化阅读空间增添跨界魅力。据悉，活动期间书房全场图书9折优惠，购书读者还可获85折图书优惠券。目前中版书房正布局全国连锁，力求打造具有全国影响力的文化传播灯塔、人文精神新家园。作者：许旸编辑：许旸责任编辑：李婷*文汇独家稿件，转载请注明出处。|主办方供图
