红网综合讯 据湖南省安监局消息，7月25至27日，湖南省安监局在长沙举办冶金等工贸行业国有及重点企业主要负责人专题研讨班。25日上午，湖南省安监局党组成员、副局长杨国庆出席开班仪式并讲话，国家安监总局四司司长马锐应邀作题为《建设自主管理安全管理体系，实现企业可持续发展》专题辅导。杨国庆指出，这次研讨班是在关键时期举办的，一是下半年党的十九大即将召开，为党的十九大胜利召开营造良好的安全生产环境是下半年压倒一切的政治任务;二是今年全省安全生产形势依然严峻复杂，特别是上半年工贸行业发生了湘江纸业“3.28”中毒事故和澳泉食品有限公司“4.3”较大中毒窒息事故，虽然全省开展了以有限空间作业为重点的安全大检查，但也暴露出部分企业安全生产主体责任不落实，安全制度不健全、安全培训不到位，以及监管部门在检查中仍然存在走过场、执法不严等问题;三是目前正值高温季节，安全生产风险因素增加，而且即将迎来全国性的安全生产大检查，此时举办研讨班意义重大。杨国庆要求，要理清并落实监管部门责任和企业主体责任。针对企业安全生产主体责任得不到落实的问题，他分析指出：假设安全生产是一百分，如果监管部门做到了一百分，企业没有做到一百分，甚至是不及格，安全生产工作依然是不合格的；如果监管部门的工作没有做到位，但是企业把主体责任落实到位了，企业安全生产工作得了一百分，那么安全生产工作仍然还是一百分。杨国庆强调，监管部门要牢记“尽职照单免责，失职照单追责”，要摸清楚辖区内工贸行业底数，按照工贸行业分类标准，分情况管理重点企业、风险程度高和风险程度一般的企业;要从科学性、针对性和指导性等方面，重新审视今年制定的执法计划;要高高举起法律的武器，运用好行政处罚利剑，在执法过程中端正思想。企业要落实主体责任，主要负责人要重视安全生产，对于企业风险做到心中有数，履行好规定的企业主要负责人七项职责;要理清企业分管各部门的负责人、安全机构、其他部门以及从业人员的职责，从业人员要通过参加培训和自觉学习提高对本岗位应知应会的能力。马锐在授课中讲到，安全管理体系关系到人的生命财产基本权利和根本利益，是企业持续运营发展的基本前提、企业综合管理的重要组成部分，不仅提升企业安全业绩，更是提升综合业绩的强大驱动力，能推动部门合作、企业文化的形成。针对企业存在的人员、设备和管理问题，马锐强调，企业要根据安全生产发展规律，把控住自身安全生产，自主创建安全生产标准，自愿参与评审工作。通过领导以身作则，一把手亲自抓安全，调动员工的积极性，让员工充分参与到安全工作当中，创建自下而上全员参与安全工作的氛围。加强风险管控和文化建设并重的安全管理体系建设，建立隐患排查治理机制。加强风险管理，形成自身安全文化，建立自主的安全管理体系，实现企业可持续发展。国家安全监管总局四司相关负责人，省安监局工贸处、人事处相关负责人和湖南有色冶金劳动保护研究院院领导出席了开班仪式。全省冶金等工贸行业国有及重点企业86名主要负责人和14个市州安监局分管领导参加了研讨班。培训期间，省安监局还邀请其他专家和领导从工贸企业风险辨识与管控、工贸企业职业健康管理与监督、工贸企业有限空间安全管理与监督、工贸企业安全生产标准化等方面进行系统讲解。为严肃纪律，省安监局将对无故旷课、结业考核不合格或不遵守纪律情节严重的予以通报。
