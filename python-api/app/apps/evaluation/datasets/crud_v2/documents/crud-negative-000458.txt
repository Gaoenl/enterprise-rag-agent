2023-08-11 12:42，正文：原标题：俄罗斯修改中学历史教科书，增加了这些内容——参考消息网8月11日报道 据俄罗斯连塔网8月7日报道，俄罗斯教育部长谢尔盖·克拉夫佐夫在塔斯社举行的新闻发布会上，介绍了11年级的新历史教科书。他透露，1970年代至2000年代的部分已进行彻底修改，并且出现了关于2014年至2023年事态的章节，包括在乌克兰的特别军事行动。报道称，《俄罗斯商业咨询日报》记者公布了这些章节的内容。该书在特别军事行动章节前引用了俄总统普京今年2月9日向航空业代表发表的讲话，即俄罗斯并未发起，而是致力于结束军事行动。此外，对乌行动的目的是“先发制人地确保俄罗斯的安全”。根据新课本，乌克兰是一个极端民族主义国家。今天在乌克兰，任何异见思想都受到严厉打压，反对派被禁止，一切与俄罗斯有关的事物都被宣布为敌对的，一切以这样或那样的方式证明兄弟人民共同历史文化的东西都遭到毁坏。教科书作者指出，在特别军事行动中，俄罗斯面对的是整个北约。书中写道：“与我军对抗的是一支被灌输意识形态、配备北约武器、按照他们的标准训练、并由外国雇佣兵和教官补充的乌军。”报道称，课本起草者表示，莫斯科对西方采取了友好之举：努力改善俄罗斯和美国情报部门之间的关系，向遭受恐怖主义袭击的美国受害者表示慰问，修建供应西方天然气的管道。但正如课本所言，美国后来决定防止欧洲在俄罗斯保障下实现能源独立，阻挠俄对外供气。书中还写道：“西方向乌克兰政权注入大量金钱和武器，并对俄罗斯实施前所未有的制裁。”此外，教科书编写者揭露了西方国家篡改历史的行径，包括拆除将欧洲从纳粹主义蹂躏下解放出来的苏联官兵的纪念碑等。俄罗斯新历史教科书涵盖从1945年到21世纪初发生的事件，将于今年9月1日提供给俄罗斯学校。到2024年9月1日时，5至9年级学生也将使用新教材。返回搜狐，查看更多责任编辑：
