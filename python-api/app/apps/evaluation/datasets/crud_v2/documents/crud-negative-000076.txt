2023-08-14 20:49:13，正文：四川在线记者 陈碧红8月14日，记者从成都海关获悉，今年前7个月，四川货物贸易进出口总值5321亿元，规模位列全国第8。其中，出口3419.2亿元，同比增长1.6%。四川民营企业进出口活力不断释放。成都海关发布的数据显示，今年前7个月四川民营企业进出口额为2480亿元，同比增长36.5%，占同期四川进出口总值的（下同）46.6%，比重较去年同期提升14.4个百分点。同期，四川一般贸易方式进出口2203.4亿元，同比增长22.7%，占41.4%，比重较去年同期提升9. 5个百分点。四川外贸“朋友圈”更趋多元。前7个月，成都高新综合保税区进出口2197.5亿元，规模继续位居全国综合保税区第1位，占四川外贸进出口总值的41.3%。同期，成都国际铁路港综保区、宜宾综保区、泸州综保区、绵阳综保区进出口分别同比增长92.1%、42.1%、33%和59.4%，开放平台功能进一步发挥。与此同时，今年以来四川各类贸易主体充分利用中欧班列、西部陆海新通道等平台，加强西向、南向贸易合作，拓展“一带一路”沿线朋友圈。前7个月，四川对“一带一路”沿线国家进出口1837.9亿元，同比增长5.1%，多元稳定经贸关系不断拓展。近年来，随着四川加快培育和发展绿色产业、特色农业，相关产品出口稳步得以增长。数据显示，今年前7月四川电动载人汽车、太阳能电池、锂离子蓄电池等“新三样”产品出口98.7亿元，同比增长73.4%。“新三样”产业的迅猛发展，带动四川锂矿石进口257.8亿元，同比增长194.3%，列全国第一。同时，以“德阳造”鱼油、“雅安产”鱼子酱、安岳柠檬为代表的特色农产品，也受到国际市场欢迎。前7个月，我省鱼油出口3.9亿元，同比增长8.8%，列全国第一；鱼子酱出口3380万元，同比增长23.2%，列全国第二；柠檬及酸橙出口6463万元，同比增长48.5%，列全国第一。在上述产业带动下，前7个月，四川18个市（州）货物贸易保持增长，其中15个市（州）增幅达两位数以上。
