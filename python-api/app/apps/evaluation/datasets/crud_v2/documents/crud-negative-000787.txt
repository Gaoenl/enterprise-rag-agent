2023-08-18，正文：警察酒后侮辱客栈前台：向前台索要“特殊服务”近日，李女士发布视频实名举报称，山西晋中平遥古城派出所警察梁某文酒后在一客栈前台索要“特殊服务”并对客栈工作人员进行辱骂、吐口水。该女子从7月28日开始一共发布了近20条视频，内容都是举报山西平遥古城民警梁某文的朋友酒后在客栈前台索要特殊服务并耍酒疯，得知客栈员工报警后，醉酒的梁某文也来到客栈开始侮辱、辱骂前台，之后梁某文还动手打了该客栈两人。警察酒后侮辱客栈前台！8月17日，平遥警事微信公众号发布相关警情通报：2023年7月27日18时30分，平遥县公安局接群众报警称，平遥古城内某客栈有人醉酒闹事。接警后，公安机关高度重视，立即受案调查。经查，7月27日18时20分许,平遥县古城旅游警察大队工作人员梁某文酒后与平遥古城某客栈工作人员李某发生争执，后梁某文以辱骂、吐口水等方式对李某进行侮辱。鉴于案件涉及公安机关内部人员，平遥公安主动提请上级公安督察部门介入监督。警察酒后侮辱客栈前台！8月10日，平遥县公安局根据《中华人民共和国治安管理处罚法》第四十二条第二款之规定，对违法行为人梁某文依法行政拘留5日，并依据相关规定将其辞退。平遥县古城旅游警察大队相关责任人员因队伍管理不到位已进行问责处理。平遥县公安局将引以为戒，从严加强队伍管理，严防此类问题发生，诚恳接受并欢迎大家监督。婷告诉顶端新闻记者，事发当日，起先是梁某文的朋友先来到客栈前台，“他到了前台之后，就是一直在那笑，后来叫老板娘，消费消费，我的同事就过去了，问他说你怎么了，他就说要特殊服务。”李婷说，先出来接待的是她的同事，当时梁某文的朋友电话外放正在和梁某文通着电话，视频监控也证实了李婷的说法。
