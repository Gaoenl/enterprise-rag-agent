2023-08-15 15:52，正文：深圳新闻网2023年8月15日讯（记者 李慧 通讯员 陈兵）近日，罗湖区莲塘街道党工委组织莲塘街道商会企业代表深入广西隆林各族自治县沙梨乡和岩茶乡的8个村开展乡村振兴调研，了解乡村振兴情况，共谋发展良策、共话乡村振兴。调研过程中，工作组先后与沙梨乡和岩茶乡政府开展座谈，了解辖区主导产业发展、乡村振兴发展规划等工作，重点了解岩茶乡今年旱情治理及后续生产情况。并实地走访沙梨乡和岩茶乡的8个村，与村两委干部进行深入交流，详细了解当地集体经济发展、人居环境整治、村民就业及当前工作中存在的困难，重点了解各村产业发展现状及发展空间，并提出相关工作意见和建议。工作组鼓励村两委要充分发挥自身资源优势，发展乡村特色产业，拓宽农产品销售渠道，推动乡村产业融合发展，进一步提高村民收入，不断壮大发展村级集体经济实力，推动乡村振兴工作走深走实。调研中，工作组还实地走访了部分联系帮扶的村民家庭，并送上慰问金，详细询问他们的身体状况和家庭需求等，鼓励他们不断提升自我发展的内生动力，用勤劳的双手创造美好生活。据了解，自莲塘街道与隆林各族自治县沙梨乡和岩茶乡的8个村建立了乡村振兴结对帮扶关系以来，始终牵挂着当地村民，积极帮助村民开拓农产品销售市场，完善乡村基础设施。今年上半年，在隆林县岩茶乡遭遇旱情后，街道第一时间发动辖区党员干部、爱心企业为岩茶乡抗旱救灾捐款，彰显了两地间的深情厚谊。近年来，经过多方的努力，对口村寨的道路硬化、通电通水等问题不断完善，村容村貌稳步提升，群众干劲十足，帮扶成效不断提升。下一步，莲塘街道将严格按照帮扶方案抓好各项工作的落实，继续拓展延伸帮扶内容，多为乡村群众办好事、办实事、解难事，通过精准对接与合作，在基础设施提升、产业发展、人居环境整治提质等重点工作上持续发力。
