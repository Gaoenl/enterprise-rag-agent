2023-08-14 17:03，正文：原标题：反诈宣传频亮相 筑牢全民“安全墙”——黑龙江省同江公安开展暑期“防诈反诈”专题宣讲中新网黑龙江新闻8月14日电(鲁旭佳)为确保夏季治安打击整治专项行动有序有效开展，进一步提高辖区群众对电信诈骗的防范意识和鉴别能力，近日，同江市公安局反诈中心民警来到兴旺社区，开展“暑期儿童关爱服务暨家庭教育”为主题的普法宣传活动，让孩子和家长们对电信诈骗“记得住、会辨别、能预防”。活动现场，民警以播放PPT，围绕“什么是电信网络诈骗”“电信网络诈骗的常见类型”“如何识别防范电信网络诈骗”等方面的知识，面对面地向家长和学生进行了细致的讲解。重点围绕刷单返利类诈骗、冒充电商物流类诈骗及学生群体中高发的网络产品虚假交易类等诈骗案件，结合典型的真实诈骗案件，让观众更加清晰、直观地了解到诈骗犯的惯用手段，提高防范意识。同时还详细地介绍了相对应的预防措施，提醒观众不要被假象迷惑、不要有占小便宜的心理，在日常生活中要提高警惕。宣讲开始前，还在现场给家长和学生发放了反诈宣传单、印有反诈宣传标语的扇子，做到了有效的辐射宣传。本次活动参与人数100余人，发放宣传页80余份，发放扇子50余个。此次暑期反诈宣讲，民警用通俗易懂的讲解提高了家长和学生防范电信网络诈骗的意识，从思想上筑起了一道反电信网络诈骗的“防护墙”，努力实现“全民反诈”的目标。(完)返回搜狐，查看更多责任编辑：
