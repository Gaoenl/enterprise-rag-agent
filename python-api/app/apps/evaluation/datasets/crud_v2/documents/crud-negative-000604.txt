2023-08-15 10:48，正文：央视网消息：广东省汕头市南澳县风力资源丰富，作为广东省首批“近零碳”排放区城镇试点，这里依托风力优势，建成了亚洲最大的“近零碳”风电岛屿。岛上每年清洁能源的发电量不仅能够满足岛上居民生产生活需求，还能输送给内陆使用。南澳岛因其得天独厚的地理环境，每年冬春季来临时冷空气南下，岛上风力机可以达到满负荷运行，年风能资源的可用性达90%。广告 他只是个小司机，伺候的却是一个富太太，小人物一步步平步青云扶摇直上！ ×风是一种不稳定的能源，它具有季节性和时段性。如果入网的电量忽高忽低，会给电网的安全运行和用户带来严重影响。就如何更好地解决这个问题，记者前往了位于岛内的金牛换流站了解相关情况。广告 家道中落的男子从底层爬起，一步一个脚印，踏上巅峰，过上众美环绕的逍遥人生！ ×南澳岛发出的风能只需要三成就可以满足整个海岛的居民用电需求，多余的风能可以反哺内陆。依靠柔直系统，构建起绿岛与内陆的电流传输通道，每年有超1.5亿千瓦时的电量通过输电线路送到汕头主网。截至目前，南澳柔直系统已向内陆累计输送清洁能源电量约为16亿千瓦时，相当于减少二氧化碳排放134万吨。在未来，广东电网还会打造多个生态示范区，通过绿色低碳的方式，促进能源电网高质量发展。
