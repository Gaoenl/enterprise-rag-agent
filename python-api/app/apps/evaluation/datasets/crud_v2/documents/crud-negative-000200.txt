当青春与梦想相遇,当体育与古城相融,拥有2300多年建城史的成都,散发出活力四射的光芒。7月28日晚,成都,中国文化遗产标志“太阳神鸟”穿越时空翩飞而至,四只神鸟围绕旋转的太阳飞翔,12道金芒渐次点亮,璀璨的焰火在空中打出倒计时数字,结束时又绽放出成都市市花“芙蓉花”的模样。成都第31届世界大学生夏季运动会开幕式,以“阳光”的姿态开启,并贯穿始终——这样的创意,是开幕式主创团队无数次思想碰撞的结晶。他们认为,成都是一座向往太阳、崇尚光明的城市,阳光应该成为成都大运会开幕式最生动的核心表达。“国旗国旗真美丽,金星金星照大地。我愿变朵小红云,飞上蓝天亲亲你。”来自四川大凉山的孩子们演唱歌曲《国旗国旗真美丽》,用清澈而又空灵的歌声唱出了对祖国最真挚的爱。中国56个民族的青年合唱《歌唱祖国》,迎接国旗入场。台上的观众纷纷站起身来,给予热烈的掌声。升国旗,奏国歌。最庄严的时刻,全场一起合唱国歌。随后,古老的蜀锦织机编织蜀锦,为入场的世界大学生织出寓意多彩青春和美好未来的梦想之路。来自世界113个国家和地区的大学生运动员,伴随着大学生乐队现场演奏的亚洲、欧洲、非洲、美洲和大洋洲经典音乐,在这条梦想之路上接受“前程似锦”的美好祝福。伴随着《茉莉花》的音乐伴奏,中国大学生体育代表团压轴出场,全场观众起立欢呼,开幕式气氛达到高潮。这是一场阳光的盛会。从倒计时“礼赞阳光”,到运动员入场式“锦绣之路”、国际大学生体育联合会会旗入场“荣耀历程”、文体表演“青春追梦”、点火仪式“青春圆梦”,直至尾声“阳光下的欢聚”,都能让人们感受到“阳光”带来的热情与光明。这是一场逐梦的盛会。来自113个国家和地区的6500名运动员,在这里以拼搏的姿态去突破自我,为世界奉献一场又一场精彩的表演。中国大学生体育代表团田径运动员吴艳妮说,永远不会忘记自己的梦想,“我们年轻人只要继续坚持奋斗,做好自己的工作,而其他的就交给我们的时代和我们的国家。在这片土地上,青春终将绽放,梦想终将实现”。这是一场友谊的盛会。国际大体联代理主席雷诺·艾德把成都大运会看作一个舞台,他希望来自世界各地的运动员齐聚一堂,可以在舞台上发亮发光。来到成都的这几天,德国大学生体育代表团游泳运动员赫宁·本内特·穆莱特纳已经爱上了这里的文化多样性,而且非常期待能有更深的体验和感受。这是一场文化的盛会。以成都大熊猫繁育研究基地大熊猫“芝麻”为原型创作的大运会吉祥物“蓉宝”,是场上最忙碌的角色,既要陪大运健儿出场,又要陪演员们跳舞;“小辣椒”引导员服装,形象地展示出成都火热的城市个性;一边是青年大学生活力四射的运动表演,一边是古典优雅的川剧变脸展示......在开幕式上,古老与现代交相辉映。当31名火炬手奔跑而来,全场的气氛再度点燃。领跑的叶光富,是神舟十三号载人飞行任务乘组航天员。在叶光富的带领下,31名火炬手共同点燃的太阳神鸟点火盘光芒四射,盘旋上升,引燃象征太阳神鸟12道金芒的空中焰火,焰火传递,神鸟展翼,最终点燃场外的火炬塔。在熊熊圣火的照耀下,来自世界各地的运动员将围绕18个大项、269个小项展开角逐,成就梦想。在成都大运会赛场上,来自世界各地的运动员有着共同的向往,就像成都大运会主题曲《成就梦想》里唱的那样:“成就梦想,青春是我们。成就梦想,未来是我们。”记者蒲晓磊 马利民[ 编辑: 彭忠粤 ]
