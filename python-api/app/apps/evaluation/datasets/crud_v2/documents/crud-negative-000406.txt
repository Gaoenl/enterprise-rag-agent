2023-08-18 09:53，正文：原标题：天长市举办第十二届大学生暑期社会实践汇报演出天长市举办第十二届大学生暑期社会实践汇报演出 天聚英才，青春振兴。8月11日下午，天长市举办第十二届大学生暑期社会实践汇报演出暨大学生兼任团组织副书记工作启动仪式，副市长麻丽敏同志出席此次活动。市政府副市长麻丽敏出席活动并深情寄语青年学子活动的第一阶段，团市委相关负责人首先介绍了“天聚英才•青春振兴”工程暨天长籍大学生兼任团组织副书记的工作情况，来自武汉大学的学生陈澈作为兼职副书记大学生代表发言，她勉励在座的青年学子不仅要胸怀宽广，“树立远大理想、热爱伟大祖国、担当时代责任”，也要不忘故乡，“为新阶段现代化美好天长建设贡献自己的青春力量”。随后，副市长麻丽敏为兼任团组织副书记代表崇玉兴授团旗，全体起立奏唱团歌。第二阶段的开始，在座的大学生们观看了《菁菁学子 与团十二年》第十二届暑期社会实践活动的剪影视频，从“乡村振兴青年说”主题演讲，到“青春实践行”活动，再到“青年学子民族团结”主题座谈会，青年学子们的身影不仅活跃在自身的岗职上，更是融进了故乡发展的每一处细节中。接着，活泼可爱的少先队员为在场的观众带来了舞蹈《炎黄子孙》，元气满满的表演将新时代少年们的意气风发展现得淋漓尽致。随后，冯晓骞同学的一曲古筝独奏《香山射鼓》将台下观众带入了高远空旷、泓峥萧瑟的意境中。胡婧同学用歌曲《如愿》鼓舞在座的青年勇于奋斗才能实现梦想。最后，由林慧彦、李辰雨等同学出演的情景剧《风雨三十年 我与家乡共成长》表达了天长撤县建市的三十年中，青年人为故乡发展贡献出的青春与热血。本次的活动在《新时代的我们》的朗诵与《天耀中华》的合唱声中落下帷幕。团市委的相关负责人表示，将继续为青年学子们创造更多社会实践机会，持续推进“我为青年做件事”，进一步加深大学生对天长发展的认知，从而吸引更多的高校学子回到家乡就业创业。（通讯员 王简）返回搜狐，查看更多责任编辑：
