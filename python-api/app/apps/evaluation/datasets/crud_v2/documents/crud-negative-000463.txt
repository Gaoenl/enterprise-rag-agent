云南网讯（记者张琦敏娄新月杨苑牟燕红李熙临）8月16日，第7届中国—南亚博览会暨第27届中国昆明进出口商品交易会（以下简称“南博会”）在昆明滇池国际会展中心开幕。由云南省农业农村厅牵头、云南省省商务厅配合组展的高原特色现代农业馆“盛装”亮相。高原特色现代农业馆。张琦敏 摄　　高原特色现代农业馆位于12号馆，以“寻味绿色云品，悦享云南生活”为主题，集展示展销于一体，共设置省级综合形象展区、云南农垦展区及各州（市）展区等18个展区。全馆参展企业数量达433家，参展产品1500余种，涵盖高原特色现代农业茶叶、花卉、蔬菜、水果、中药材、咖啡、坚果、粮食、生猪、肉牛等重点产业。其中，历年“10大名品”获奖企业37家，国家级农业产业化龙头企业13家，参展产品取得绿色食品认证的企业104家，取得有机食品认证的企业149家。“昭阳红”苹果。张琦敏 摄　　“品种多样、天然生长、自然早熟、风味独特是‘昭阳红’苹果的核心优势。”昭通超越农业有限公司工作人员曾正告诉记者，获得“云南省十大名果”荣誉称号的“昭阳红”苹果很受消费者欢迎。这次带到南博会的嘎啦、华硕、黑卡、红露等都属于早熟品种，基本都是七月底八月初成熟采摘。昭阳红基地位于云南省昭通市，居山临水，高海拔、低纬度、光照强，昼夜温差大、雨水充沛，土壤富硒比例高，产出的苹果果肉细腻、脆甜多汁、香气浓郁。高原软香米。张琦敏 摄市民品尝咖啡。张琦敏 摄　　在云南农垦集团展区，一片金黄的“稻田”引人注目，不少市民争相购买高原软香米。“这款高原软香米为洱海保护而生，米粒圆润、口感软糯、清香回甜。”云南农垦集团工作人员陶俊鹏介绍，集团在洱海流域以“水稻+”模式打造万亩绿色、有机优质水稻种植基地，充分发挥水稻环境友好型半湿地功能对洱海保护的重要作用，为消费者提供“放心、贴心、养心”的高原特色优质绿色农产品。消费者还可以参加“洱海留香稻田认养”活动，选择认养面积，水稻成熟后，大米可以直接快递到家。云果展示。张琦敏 摄市民选购猕猴桃。张琦敏 摄　　记者了解到，展会期间，馆内将开展丰富多彩的宣传推介活动，综合形象展区持续推出“寻味绿色云品”系列活动，包括茶艺展示及品鉴、特色云果推介品鉴、特色饮品推介品鉴、中药材养生小课堂等。展区主入口设有鲜花美陈打卡点，消费者拍照分享社交媒体集赞后，即可领取“超值消费券”用于现场消费抵扣。高原特色现代农业馆。张琦敏 摄中药材展示。张琦敏 摄　　近年来，全省各级农业农村部门充分发挥资源优势，聚焦粮食、茶叶、花卉、蔬菜、水果、坚果、咖啡、中药材、牛羊、生猪、乡村旅游、烟草、蔗糖、天然橡胶“1+10+3”重点特色产业，加快推动高原特色现代农业发展。2022年，全省农林牧渔业实现总产值6635.80亿元，同比增长5.5%。茶叶、鲜切花、坚果、咖啡、中药材、烟草、天然橡胶等特色产业种植规模和产量稳居全国第1位，蔬菜、水果、肉牛、生猪、蔗糖等产业规模居全国前列，“土特产”已成为推动云南省经济发展的重要支撑和助力农民持续稳定增收的重要源泉。举报/反馈
