上证报中国证券网讯 近日,万兴科技旗下亿图脑图、亿图图示、亿图项目管理三款绘图创意产品全线焕新,致力提供多场景绘图创意服务,助力用户高效绘图、智绘办公。其中,亿图脑图于业内率先实现脑图文件桌面端协同编辑,打造多端协同一体化能力;亿图图示对UI界面进行深度优化,实现易用性和生产力升级;亿图项目管理全面提升单元格和条形图编辑功能,实现甘特图等核心图形的重大升级。据介绍,此次重磅焕新的亿图脑图V11,是目前市场上首款实现在线协同编辑的桌面端思维导图软件,支持用户在PC端创建多人协作的脑图文件,或通过“分享”功能将本地文件一键转换为协作文件,实现在PC端多人多地多设备在线同步编辑,不同终端都能畅享高效办公绘图,让团队协作更简单高效。新一代亿图图示则通过交互体验革新、操作逻辑优化、资源素材、格式兼容等方面的升级,为用户提供更易用、更具生产力的图示创作体验。亿图项目管理全新版本对编辑页顶部菜单栏进行了布局优化,任务、项目、设计、报表四大常用功能分类更清晰,用户可在各类项目管理文档间自如切换。在全球加速进入数字化时代的背景下,数字化办公需求愈发高涨,成为促进业务精细化运营的有效抓手。作为万兴科技旗下绘图创意明星产品,亿图脑图、亿图图示、亿图项目管理等致力于提供多场景、多品类的绘图创意高效协作体验,同时加速AI功能升级,赋能全球绘图创意用户释放数字办公生产力。亿图脑图及其海外版Wondershare EdrawMind已上线AI生成思维导图、AI对话、AI生成PPT、AI绘图、AI写作、AI文件解析、音视频导出等创新功能;亿图图示及其海外版Wondershare EdrawMax集成AI问答、AI生成流程图/表格/列表、AI生成用户故事等功能,移动端实现语音交互。万兴科技正加快深化AIGC布局,已推出万兴爱画、万兴播爆、万兴智演、Wondershare Kwicut、Wondershare VirtuLook、Wondershare Trumate等AIGC创意新品;旗下万兴喵影、Wondershare Filmora、Wondershare PDFelement、万兴PDF、墨刀海外版Mockitt等产品均已集成AIGC能力,并持续优化上新。(田立民)
