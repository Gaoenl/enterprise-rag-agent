"一场意外的事故,让年过九旬的老人痛失儿子,让其乐融融的家人痛失至亲,祖孙二人又因死亡赔偿金分配不均对簿公堂。8月10日,竹山法院得胜法庭法官通过多次上门耐心调解,妥善化解了该起纠纷,作为被告的孙儿主动将10万元赔偿款交到爷爷手中,并表示将继续承担赡养义务,至此祖孙握手言和、孝道延续,濒临破碎的亲情也得以挽救。今年7月得胜法庭受理了91岁高龄的爷爷诉孙子死亡赔偿款分割纠纷案件, 2020年5月,老人的儿子在外务工期间不幸死亡,事后获得的赔偿款由其儿媳和孙儿保管,被告考虑到原告在一起共同生活,便未将赔偿款同原告进行分割,而原告认为被告侵害了自己应有的权益,便一纸诉状将被告诉至法庭。案件受理后,承办法官通过阅卷和调查了解,认识到双方争议的焦点不仅仅是赔偿金如何分配这一件事,更涉及到原告今后的赡养问题,如果仅就赔偿款分配问题依法判决,但爷孙之间的亲情关系可能会走向对立。承办法官从老人今后的生活保障考虑,坚持从情理法和当地风俗角度着手,开庭前多次给双方当事人做工作,一方面向原告反复宣讲法条,告知抚恤金分割相关法律规定,消除其错误认知;另一方面又多次做被告及家人的工作,引导双方放下怨恨和不理解,最终促使双方互谅互让,达成分割协议,树立起了“金钱诚可贵,孝道价更高”的正确社会导向,也实现了法律效果和社会效果的有机统一。文/图:袁伟栋、孙荣能原标题:《祖孙对簿公堂分割赔偿款 ,法官上门调处修复破裂亲情》",
