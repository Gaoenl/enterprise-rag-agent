2023-08-09 10:26:31，正文：金融界8月9日消息，据小米公司，2023雷军年度演讲定档8月14日（周一）晚7点，主题为“成长”。雷军在微博称，这是其第4次年度演讲，想和大家聊聊，过去30多年几次关键成长的经历和感悟。2020年8月11日，雷军在小米北京总部举行主题为“相信自己，一往无前”的小米十周年演讲。2021年和2022年，雷军年度演讲继续举办，主题分别为“我的梦想，我的选择”和“穿越人生低谷的感悟”。在去年的年度演讲中，小米同时举办了新品发布会，小米 MIX Fold2 和 Redmi K50 至尊版两款旗舰机登场。今年的年度演讲上，两款旗舰新机小米 MIX Fold3 和 Redmi K60 Ultra 也有望如约而至。近日，2023年《财富》世界500强排行榜发布，雷军发文称，小米连续5年上榜。感谢每一位用户的支持与信任，未来小米将继续努力，坚持以技术为本，不断创新，为全球每一位用户带来更好的智能科技体验。7月19日，《中共中央 国务院关于促进民营经济发展壮大的意见》（下称《意见》）全文公布。《意见》指出，民营经济是推进中国式现代化的生力军，是高质量发展的重要基础，并明确提出支持提升科技创新能力、开展关键核心技术攻关、培育一批关键行业民营科技领军企业、专精特新中小企业和创新能力强的中小企业特色产业集群等31条政策措施。小米集团创始人、董事长兼CEO雷军表示，《意见》释放出引导民营企业践行新发展理念的明确政策信号，让企业更加坚定了坚守主业、做强实业的决心，增强了自觉走高质量发展之路和为科技现代化作贡献的动力。
