近日万兴科技旗下亿图脑图、亿图图示、亿图项目管理三款绘图创意产品全线焕新,致力提供多场景绘图创意服务,助力用户高效绘图、智绘办公。其中,亿图脑图于业内率先实现脑图文件桌面端协同编辑,打造多端协同一体化能力;亿图图示对UI界面进行深度优化,实现易用性和生产力升级;亿图项目管理全面提升单元格和条形图编辑功能,实现甘特图等核心图形的重大升级。亿图脑图及其海外版Wondershare EdrawMind已上线AI生成思维导图、AI对话、AI生成PPT、AI绘图、AI写作、AI文件解析、音视频导出等创新功能;亿图图示及其海外版Wondershare EdrawMax集成AI问答、AI生成流程图/表格/列表、AI生成用户故事等功能,移动端实现语音交互。万兴科技是中国数字创意软件领域产品覆盖面广、营收体量大、全球化程度高的A股上市公司,也是国内最大的数字创意软件出海企业,业务覆盖多个国家和地区,全球累计用户近15亿,月活近1亿。当前,万兴科技正深化AIGC布局,已推出万兴爱画、万兴播爆、万兴智演、Wondershare Kwicut、Wondershare VirtuLook、Wondershare Trumate等AIGC创意新品;旗下万兴喵影、Wondershare Filmora、Wondershare PDFelement、万兴PDF、墨刀海外版Mockitt等产品均已集成AIGC能力,并持续优化上新。(文章来源:中国证券报·中证网)
