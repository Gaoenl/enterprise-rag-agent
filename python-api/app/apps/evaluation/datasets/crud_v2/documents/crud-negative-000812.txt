2023-08-15 20:12，正文：原标题：专机故障再现 德外长取消对澳大利亚等国访问中新社柏林8月15日电 综合德媒15日报道，因专机故障后再度起飞失败，德国外交部长贝尔伯克取消了对澳大利亚等国家的访问计划。“我们已经尝试了一切方法。”她当日在社交媒体上表示，“但不幸的是，没有这架专机，就后勤而言继续印太之旅是不可行的。”当地时间14日，贝尔伯克在乘专机前往澳大利亚途中，飞机在阿联酋首都阿布扎比经停加油后起飞时因着陆襟翼机械故障飞回阿布扎比备降。当地时间15日凌晨，专机在阿布扎比再度尝试起飞，然而又因相同原因失败。报道称，专机于当地时间15日凌晨1时起飞，虽然飞机最初在爬升，但没有加速。起飞15分钟后，飞机再次偏离航线。第二次故障后，飞行员做出了不太乐观的预测：“对我们来说，今天的飞行又结束了。我们可能不会再飞往澳大利亚，甚至明天也不会。”他们目前正在想办法，如何让飞机返回德国。报道称，贝尔伯克原计划对澳大利亚、新西兰和斐济进行为期一周的访问。这是贝尔伯克出任德国外交部长后首次出访澳大利亚。德国空军的政府专机此前也曾发生机械故障。今年5月，贝尔伯克曾因专机轮胎故障被迫在卡塔尔首都多哈滞留。(完)返回搜狐，查看更多责任编辑：
