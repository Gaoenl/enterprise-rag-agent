，正文：受“卡努”台风外围环流带来旺盛西南气流影响，南投县仁爱乡因连日暴雨导致不少地方陆续出现土石崩塌、掩埋等灾情，使交通遭阻断、居民受困。对此，前高雄市长韩国瑜感叹，“安居乐业”此刻离无助的他们是多么遥远，身为典亮慈善基金会董事长的他决定为灾区尽一份心力，目前已备妥物资，后续将协助灾民采购所需的生活用品，南投县长许淑华也回复，“南投乡亲感恩您！”韩国瑜昨日在脸书上提到，典亮慈善基金会已与许淑华取得联系，且经许淑华实际走访仁爱乡部落了解，现阶段民生物资尚且充足，但家电、家具多已损坏，造成灾民生活上的不便，呼吁热心民众可视实际需求传递爱心。他也期盼民进党当局除协助救灾，更能在全台易致灾山区的重建工作上给予更多支持，让住在山区的朋友能真正安居乐业。韩国瑜这个举动令许多人相当感动，不仅吸引逾1.4万人点赞，许淑华更是亲自留言，“谢谢韩总连日来的主动关心，了解实际需求提供灾民物资协助，南投乡亲感恩您！”岛内许多网友也表示，“谢谢韩总关心我们族人”、“仁民爱物的韩总”、“你的心一直都在人民的身上，我们也没离开你”、“亲力亲为，胜过那些只出一张嘴的政治人物”、“感谢您抛砖引玉关心偏乡人民”、“在这条挺韩的道路上，不管多久，我们都会一直的等下去....因为这个人值得我们这样做”、“刚才也去捐了一点物资，看到大家的爱心，好感动！”海峡导报驻台记者 薛洋 整理报道
