在稳增长、扩内需的经济形势下，新一轮城中村改造备受关注。而在深圳，一些超大型城中村城市更新项目也传来进展。一直以来，白石洲城市更新项目具有深圳“城市更新航母”之称。近日，绿景白石洲全球发布会在深圳举办，备受瞩目的白石洲城市更新项目有了新进展。作为深圳乃至中国最具规模的城市更新体，绿景集团十以对标全球一线都市的超高标准，汇聚全球顶级资源共创全新白石洲。据悉，未来的全新白石洲是约500万平方米无界之城，集旗舰商业群、塔尖办公群、星级酒店群、高端居住群、大型公共配套群等丰盛业态于一体。与此同时，绿景白石洲·璟庭产品组团预计在8月底首发，住宅户型为建面约110至187平方米。公司相关负责人表示，绿景在与全球顶尖机构共创白石洲的过程中，思考的不再是一个项目，而是如何为深圳未来塑造一个样本城区、一种城市模式。据悉，深圳首个移民博物馆也将在白石洲落地，以深圳和白石洲的移民文化为主题，打造城市文化事件策源地、城市公共艺术发生地。去年公布的《深圳市城市更新和土地整备“十四五”规划》显示，规划期内完成城市更新和土地整备固定资产投资总额不少于1万亿元。在这万亿规模的投资下，城市更新也成为多数房企进军和立足深圳的重要法宝。记者梳理发现，除了白石洲项目、罗湖湖贝、蔡屋围等深圳城中村更新的“巨无霸”项目都已经动工。举报/反馈
