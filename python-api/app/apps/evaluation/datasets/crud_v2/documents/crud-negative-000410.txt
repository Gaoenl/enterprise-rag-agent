中国证券网讯（记者 浦泓毅）近日，两大国际权威评级机构，标准普尔公司（S&P）和穆迪投资服务公司（Moody’s），分别向国泰君安证券股份有限公司（601211SH）授予BBB和Baa1的长期发行人评级，评级展望均为稳定。其中，标普还授予国泰君安A-2的短期发行人信用评级，以及cnA的大中华区信用评级体系长期评级和cnA-2的短期评级；穆迪则授予国泰君安P-2的短期发行人评级。　　标普、穆迪两家机构均有百年历史，与惠誉并称为全球三大评级机构，长期为国际资本市场投资人提供专业的信用评级服务，为金融市场的透明性和整体性做出了积极贡献。此次获两家机构评级，国泰君安证券成为继中信、海通之后第三家接受国际评级的国内券商。　　据悉，获取国际评级是国内企业真正走向国际资本市场的一项重要条件，为相关公司今后的业务发展及国际战略布局提供了有力的支持，这一评级结果将有助于其拓展境外融资渠道、有效降低境外融资成本，同时为开展跨境及海外资本中介交易业务奠定良好基础。　　2014年以来，上海市启动了新一轮金融国资改革，国泰君安成为成为上海国际集团旗下专注资本市场、以券商业务为主的金控平台，作为一家国资金控集团，获取国际评级，积极参与国际资本市场，有利于国有资本在公开、透明、规范的市场环境中实现高效配置，符合国企改革创新的要求以及上海国际金融中心建设的国家战略。　　上海国际集团相关人士表示，本次按照国际标准进行的评价，结果跟集团的预期是相符的，也证明了国泰君安本身的市场竞争力和影响力。国际集团将持续通过国资运作平台，利用自身的金融资源为国泰君安“做大、做强、做新”提供支持，协同力量、全力配合国泰君安海外业务的布局与拓展，树立本土券商的国际知名度和影响力。　　据了解，由于本次评级历经市场大幅波动，因此评级过程更为严苛，两大机构分析师对国泰君安的财务状况、经营能力及股东背景均进行更为详尽的考察。标普报告认为，国泰君安先于市场加强保证金贷款和证券自营的风险管理，并设立明确的风险限额，显示了其审慎、“优于同业”的风控能力；穆迪认为，国泰君安与政府（截至2015年9月30日，上海国际集团持36.4%公司股份）的良好关系将为公司提供良好的市场缓冲。　　此次国泰君安同时获得两家国际评级，将有助于促使国际投资人进一步认识并关注中国证券行业的发展，提升行业整体在国际资本市场中的估值水平，也是国际评级机构对国内投行资本实力、财务状况、风控管理、业务结构的充分肯定。
