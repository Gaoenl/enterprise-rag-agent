看外交部网站的照片，7月26日，土耳其总统埃尔多安会见了来访的王毅，有一张照片，埃尔多安居中，王毅和土耳其外长费丹分居两侧，埃尔多安确实也不简单。但看内容，我最感兴趣的，是埃尔多安对王毅说的这句话：土方不支持北约在亚太地区加强活动，愿就乌克兰等国际和地区问题同中方保持沟通协调。别忘了，土耳其是北约的重要国家，对于北约向亚太伸手，土耳其明确表达不支持。加上土耳其，那就至少有两个国家对北约这一动向说不了。在不久前的北约峰会上，就因为法国的强烈反对，北约没能在日本设立办事处。法国总统马克龙的理由很简单。北约不应扩大到北大西洋以外，他警告：“如果我们推动北约扩大光谱和地理范围，我们将犯一个大错误。”对于一些国家矛头对准中国，土耳其也明确表达了同样的反对。而且，要在乌克兰等问题上，和中国保持沟通协调。当然，双方也有一些客套话。比如，埃尔多安说，土中是有全球影响的国家，两国合作的重要性超越双边范畴。土方恪守一个中国原则，认为中国的发展不是威胁，欢迎中国企业扩大对土投资。王毅则告诉埃尔多安，中方祝贺总统先生连选连任，支持土耳其坚持独立自主，中土都是新兴市场国家的代表和发展中大国，没有根本利害冲突。中方愿同土方一道，在各自民族振兴道路上相互支持，在彼此核心利益问题上相互照顾。土耳其外长费丹也向王毅承诺，土方高度重视发展对华关系，不认同中国经济、科技“威胁论”，反对抹黑、遏制中国发展，不允许在土从事破坏中国领土完整的活动。不允许谁，你应该懂的。以前中国被西方污蔑为“东亚病夫”，土耳其则是“西亚病夫”。两个国家都遭受了巨大的侮辱和损失。现在又是世界百年未有之大变局，中土确实可以多相互支持，相互照顾。国中土耳其，是不是这样啊？
