2023-07-31 21:42:21，正文：新华社北京7月31日电（贾启龙、王凌硕）围绕预编征用的军民通用装备、抢险救灾装备组织战技术性能、操作使用方法培训，采取集中笔试、网上答题、实装操作全面检验成效……7月上旬，军委国防动员部按照装备仓库管理“标准化建设、精确化储供、立体化安防、专业化警卫”的“四化”新模式，分期分批对所属军分区民兵管理骨干强化集训，立起了新时代省军区系统装备管理工作的标准规范。省军区系统现役装备和民兵装备分布点多面广、谱系纷繁复杂，装备仓库管理是有效履行新时代应急应战使命任务的重要内容。近年来，军委国防动员部主动适应改革新情况新变化，建立健全与全军装备管理体制相衔接、与省军区系统实际相符合的装备管、修、供、保管理新模式，推动民兵装备保障纳入全军武器装备保障体系，确保了新体制下省军区系统装备工作有序运行。“为了开创民兵装备仓库建设新局面，我们积极创新装备管理手段、转变装备保障模式，运用网络化、数字化、智能化管装方式，建立区域化、社会化、市场化保障方法，探索形成了‘标准化建设、精确化储供、立体化安防、专业化警卫’等民兵装备仓库‘四化’管理新模式。”军委国防动员部某业务局分管领导说。记者在山东某民兵仓库看到，武器、弹药等装备被分门别类地存储在技术区内。仓库保管员手持终端机，逐件对入库装备生成二维码、粘贴射频标签，可对所有装备品种型号、数量批次、质量等级及出入库信息实现自动采集、实时更新。“运用物联网、云存储、人工智能等技术升级仓库管理信息系统，装备出入库等业务均可依网运行。”山东省某军分区领导说，“如今，坐在办公室内点击鼠标，就可实时调阅装备动态信息。”此外，他们坚持信息赋能、科技增效，在严格落实传统人防、物防、技防要求上，发展智能手段，拓展防卫区域，健全防控机制，通过引入周界防护系统，对周边安全态势进行全维全时感知，并搭建起智能“防控屏”，一屏显示人员活动、装备分布等态势，以此打造内控外防一体、地面空中一体的立体化安防，切实把民兵装备仓库建成让各级放心的“安全屋”。分享让更多人看到
