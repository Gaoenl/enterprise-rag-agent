2023-08-10 23:11，正文：原标题：状告发帖股民被驳回！中科云网受投资者索赔案预计影响净利润2600多万元据上海市高级人民法院官网公布的案号（2022）沪02民终9097号的上海市第二中级人民法院民事判决书，中科云网科技集团股份有限公司（下称“中科云网”）诉东方财富信息股份有限公司及几名股民网络侵权责任纠纷一案已审理终结，判决结果为原告诉讼请求被驳回。官网资料显示，中科云网成立于1999年，前身为北京湘鄂情集团股份有限公司，是中国第一家在国内A股上市的民营餐饮企业集团。2009年，中科云网在深交所挂牌上市，注册资本8.4亿元，旗下曾拥有“湘鄂情”、“菁英会”、“湘鄂情·源”、“晶殿”大宴会厅等多个餐饮品牌，并逐渐形成了“餐饮团膳+互联网游戏推广及运营”双主业协同发展的格局。2018年7月，中科云网控股股东变更为上海臻禧企业管理咨询合伙企业（有限合伙），实际控制人由孟凯变更为陈继。九派财经注意到，今年以来，中科云网多次发布关于收到《民事裁决书》的公告。4月19日的公告显示，关于多名投资者以“证券虚假陈述责任纠纷”为案由起诉中科云网、以及有部分投资者要求前控股股东孟凯承担连带赔偿责任的索赔一案，中科云网被判决需向526名投资者赔偿投资损失3176.05万元，并承担54.60万元的诉讼费，合计3230.65万元。公告显示，中科云网在以前年度报告中就该投资者索赔案累计计提预计负债545.07万元，此次补充计提预计负债2685.58万元，预计对公司2023年度净利润的影响金额为-2685.58万元。业绩预告显示，今年上半年，中科云网预计实现营业收入1.10亿元至1.20亿元，较上年同期大幅增长，主要系2022年新拓展的餐饮团膳项目持续运营，以及新引入游戏产品陆续上线发行；净亏损8000万元至1亿元，主要系新引入游戏产品前期市场培育推广成本较高，报告期摊销股份支付费用合计影响金额5400多万元，以及根据投资者索赔诉讼案件一审判决结果补充计提预计负债2600多万元。九派财经记者王芊蔚编辑李宛珊【来源：九派财经】版权归原作者所有，向原创致敬返回搜狐，查看更多责任编辑：
