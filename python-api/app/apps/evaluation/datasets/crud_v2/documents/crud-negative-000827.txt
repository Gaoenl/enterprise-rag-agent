2023-07-24 14:19，正文：原标题：首场“鲁渝有约·山东支医千村行”活动在巫溪举行活动现场。巫溪县白鹿镇供图近日，重庆市巫溪县卫生健康委组织山东支医专家、巫溪县人民医院、巫溪县中医院、巫溪县白鹿镇卫生院在白鹿镇中坝村开展“鲁渝有约·山东支医千村行”义诊活动，此次活动，邀请了消化内科、肾病内科、眼科、重症医学、中医康复科等相关科室共计10余名专家。活动现场，前来咨询问诊的居民络绎不绝，专家们耐心地为每一位居民量血压、听诊号脉、指导用药、普及健康知识、免费发放健康宣传资料，并根据每位患者的患病情况提出个性化治疗方案，得到了群众的交口称赞。“知道今天有义诊，我一大早就来排队了。”接到村办公室义诊通知的李正义早起便赶到中坝村办公室等候。他表示自己有高血压，常年头晕，特意前来问诊。老年病科支医专家冯倩细心询问病症，测血压、听诊心脏，并告诉李正义不用过度担心头晕的问题，平时要注意清淡饮食，规律服用高血压药即可缓解。对于李正义胆固醇高的问题，冯倩医生提醒李正义要注意保护心脏，配合服用降血脂药物。“医生讲的很清楚，很有耐心。”咨询完以后，李正义说，这样的义诊活动为很多行动不便的老年人提供了很大便利，真心感谢医生们的辛苦付出。测量血压、血糖、体验神奇针灸理疗、免费进行白内障筛查，专业疾病问诊……现场义诊活动受到了群众的热捧，他们从一个义诊台转到其他义诊台，坐诊专家也都细致地解答居民的健康咨询，为群众检查身体，告知相关注意事项。据悉，此次义诊活动前来问诊群众共计300余人次，后期“鲁渝有约·山东支医千村行”还将深入巫溪县32个镇街。支医队长李建刚表示，扎实执行泰安市—巫溪县关于东西部协作的决策部署，以“鲁渝有约·山东支医千村行”活动为载体，尽支医团队一份力量，将更多的健康知识、惠民服务送到群众身边，打通群众看病就医“最后一公里”，让群众“少跑路”“少花钱”，让人民群众共享鲁渝卫生健康帮扶成果。(谭俊、谭传国)返回搜狐，查看更多责任编辑：
