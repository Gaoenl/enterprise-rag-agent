"中国经济网上海6月6日讯（记者沈则瑾）2017上海国际信息消费节将于6月28日-7月4日举行，消费节将以“数字经济，无限未来”为主题，打造信息消费领域面向市民和企业的嘉年华。据组委会介绍，消费节将重点打造“3个有”，“一项有影响力的评选，一场有获得感的展览，一个有高品质的开幕论坛”，展现迈向以数字经济为代表的未来生活新模式。消费节将举办第二届上海市民信息消费推荐APP评选（简称申·APP），计划在首届评选活动基础上，进一步汇集“互联网+”各领域的优秀APP应用，作为向上海市民推荐的信息消费优秀应用集合。为此，组委会和腾讯、华为等机构进行了全面合作，由腾讯应用宝、华为终端根据上海用户使用情况提供APP数据，并经安全测评中心检测，按照市场规模、公共服务、创新突破三个维度，根据下载量、用户活跃度、用户满意度等数据进行评估，评选出受市民认可喜爱的“申·APP”，并通过2017年上海市政府实事工程——市民云平台，统一向市场宣传推广。作为消费节同名主题展览，今年的2017上海国际信息消费博览会将继续与“世界移动大会·上海”配套举行，今年的主题选定为“智在必得”，将于6月28日至6月30日在上海新国际博览中心E3馆举办，展出面积约为11500平方米。博览会将聚焦“互联网+”在各个方面的应用，包括“衣、食、住、行、学、娱、信、金、体、医”等生活要素，让市民“一站式”体验数字经济时代的生活新方式。博览会还将聚焦热点领域，如邀请上海美术电影制片厂作为特约合作伙伴，现场展出60年来国漫风采，并整合社会服务机构及行业平台联合参展，展现国产动漫产业走进互联网科创时代的创新态度，与“互联网+”产业共同寻找跨界融合新机遇。博览会还将聚焦科技创新前沿领域，设置人工智能、新一代电商、云计算等新兴热点展区，市民将可以近距离体验娱乐机器人、VR/AR、跨境电商等最前沿的信息产品。此外，本届还将在现场设置申·APP展示区，让市民近距离体验“申·APP”的魅力。6月28日消费节开幕当天，将举办“数字经济，未来经济新引擎”暨上海国际信息消费节主题论坛，论坛主旨“让数字经济更好服务传统产业”。为此，今年将邀请如高通、华为、腾讯、上海交通大学、GSMA等全球知名的行业协会、智能终端生产商、信息服务提供商、产业界、学术界顶尖专家、代表，围绕人工智能、智能网联汽车、智能终端应用、城市智能服务等发展热点，共同探讨数字经济时代的未来发展趋势。论坛上还将发布《上海互联网+生活指数》研究报告。消费节期间还将举办聚焦VR/AR产业发展的“第二届全球虚拟·现实大会(GVRC)”、聚焦最前沿造客产品的上海夏季造客汇、聚焦信息消费创新应用的电视节目《创新启示录》消费节专场、向市民推荐“申·APP”应用的“申·APP社区行”系列活动、聚焦关注科技助老产业发展的“互联网+”银发论坛等各类主题活动。",
