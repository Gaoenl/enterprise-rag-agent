2023-08-16 11:52，正文：原标题：中山建行: 成功堵截电信诈骗案 为客户挽回经济损失20万余元近年来，通过邮件、短信、微信等方式实施诈骗的事件层出不穷，让人防不胜防，而且手段越来越先进，要提高服务意识和专业水平，及时发现客户异常情况，避免客户发生财产损失。近日，建设银行中山市分行成功堵截了一起邮件诈骗案，为客户挽回经济损失20万余元。下午约16时30分，一位女客户神色匆匆地来到大堂智慧柜员机前，说需要在5点前进行大额转账，说自己的老板通过邮件要求她立刻给客户公司进行打款，否则会影响公司资金链运转。因为数额太大，引起了大堂经理萍姐的注意。深入了解情况后萍姐询问客户是否已与老板进行确认确实需要转这笔账。客户反映老板并未及时回复微信，但是时间限制很紧急，联系不上老板的情况下只能匆匆来到最近的建设银行中山市分行进行转账。在多次联系客户的老板无果之后，大堂经理联系附近公安进行协助，在公安的协助下确认了这是一起邮件诈骗案。客户庆幸大堂经理多询问了几句她的情况，立即当面表扬了大堂经理 “如果您没有注意到我的异常，我肯定会给公司造成巨大损失，会失去这份工作甚至背上巨额负债，谢谢您!”银行柜面是客户资金流出的最后一道关口，成为堵截电信诈骗的关键环节。建设银行中山市分行通过细化柜面流程规范与执行，确保客户资金安全。按照“三问二看一核对”标准流程，向每位个人汇款的客户提示防范电信诈骗;指引客户认真阅读《防范电信诈骗告知书》。对新开通网银、手机银行业务的客户，核实绑定的手机号码是否为客户本人所有，防止被不法分子利用;利用老年人存、取款的机会，重点加强对老年人防范电信诈骗常识的宣传;对边打电话边办理业务、神色慌张、对汇款用途、收款人信息含糊其辞的客户进行重点防范。返回搜狐，查看更多责任编辑：
