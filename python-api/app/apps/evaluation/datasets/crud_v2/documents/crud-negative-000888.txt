第三届中国-非洲经贸博览会在长沙举行安哥拉工业和贸易部长维克多·费尔南德斯国际在线报道(记者李菁 韩硕 杨刚 钮璇 朱婧):正在长沙参加第三届中国-非洲经贸博览会的安哥拉工业和贸易部长维克多·费尔南德斯在接受记者独家专访时表示,安哥拉和中国两国在经贸方面有着很强的互补性,合作潜力巨大。他欢迎更多的中国企业家前往安哥拉投资。费尔南德斯说,中国-非洲经贸博览会对中非经贸合作起到了重要的促进作用。随着非洲大陆自由贸易区的成立,非洲形成了一个巨大的市场,人口总量接近中国的人口总量。中国与非洲的合作已经不仅仅局限于某一个国家,而是和整个非洲大陆的合作。他认为,中国和非洲的合作取得了良好的效益,未来将更加深入和广泛。费尔南德斯表示,从2017年起,安哥拉寻求国家发展的多元化,希望把国家从原材料的提供者转变为成品的制造者。中国和安哥拉是长期的伙伴,他欢迎中国有更多的企业家能够到非洲,到安哥拉投资,尤其是在工业、农业领域。他希望中国的投资能够帮助非洲提高工业生产能力,把原材料转化为成品,销往世界各国。费尔南德斯还指出,如今我们处在一个全球化的世界,应当关注气候变化、碳排放等全球性问题。他认为,发展经济不应以破坏环境为代价。而面对这些共同的问题,各国应继续加强联系和合作,更加团结。
