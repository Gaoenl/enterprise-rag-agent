2023-08-06 17:42，正文：原标题：日媒爆料：美日图谋“统一调动部队”参考消息网8月6日报道据《日本经济新闻》8月6日报道，美国政府和国会已开始讨论修改驻日美军的调动运用体制。有方案建议，就部队运用和行动计划，在日本设置负责与日本自卫队磨合的协调机构，建立起“战事发生之际”统一调动日美部队的体制。报道称，美国国会参议院7月底通过的2024财政年度国防授权法案，提到了修改驻日美军体制事宜，要求国防部研究在日本统一负责陆海空军和海军陆战队的调动运用并深化与自卫队合作的体制。共和党人、众议院军事委员会副主席惠特曼在接受《日本经济新闻》采访时，针对“台湾有事”情态指出，“在极其严峻的环境下，(日美部队合作所需)时间将决定胜负”。他明确表示，众议院也将讨论参议院明文规定的有关驻日美军条款。美国参议院和众议院将于秋天开始把各自通过的国防授权法案进行统一，届时驻日美军体制将成为焦点之一。据多名相关人士透露，拜登政府也已开始讨论调整驻日美军的调动运用。报道称，美方主张设立协调机构的理由有两个。首先是因为日本拥有了反击能力。美军作为实施攻击之“矛”、自卫队作为防守之“盾”的明确分工已淡化。自卫队提高了陆海空、太空、网络等全部领域的能力，与美军的作用容易发生重叠。日美角色调整的重要性增大。其次，在日本还没有掌管整个驻日美军调动应用的机构。驻日美军司令部处理美军基地等问题，原则上不参与陆海空军和海军陆战队的一体化运用。目前是在夏威夷设立司令部的印太部队负责一体化运用，与自卫队进行协调。（编译/刘洁秋）返回搜狐，查看更多责任编辑：
