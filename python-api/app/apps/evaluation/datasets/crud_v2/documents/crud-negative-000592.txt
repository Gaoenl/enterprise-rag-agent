2023-08-06 21:51，正文：                原标题：俄国防部：击落袭击莫斯科的乌克兰无人机                            中新社莫斯科8月6日电 俄罗斯国防部6日表示，一架乌克兰无人机在莫斯科州南部被俄防空系统击落，没有造成人员伤亡和其他损失。同一天，俄军对乌克兰空军基地实施了导弹打击。  俄国防部在社交媒体平台通报称，当日11时27分，乌克兰方面试图利用无人机对莫斯科地区目标进行恐怖袭击。无人机在莫斯科州南部的波多利斯克区被俄防空系统摧毁。事件没有造成人员伤亡或其他损失。  莫斯科市长索比亚宁在社交媒体平台发文表示，当日11时左右，一架无人机试图闯入莫斯科，但在接近时被俄防空部队摧毁。  另据俄媒报道，出于安全考虑，位于莫斯科西南部的伏努科沃机场对飞机的起降实行临时限制，自10时26分起部分航班改降莫斯科其他机场。目前伏努科沃机场恢复正常工作。  此外，俄国防部通报表示，5日夜间至6日凌晨，俄军使用空基和海基远程高精度武器对位于乌克兰赫梅利尼茨基州斯塔罗康斯坦丁诺夫地区和罗夫诺州杜布诺地区的乌空军基地实施打击，所有指定目标均遭重创。(完)返回搜狐，查看更多                        责任编辑：
