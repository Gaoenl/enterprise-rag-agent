封面新闻记者 代睿8月1日，封面新闻记者从水利部了解到，由于海河流域发生流域性较大洪水，从7月31日开始，多个蓄滞洪区相继启用。受台风“杜苏芮”减弱低压环流和冷空气共同影响，海河流域永定河干支流、大清河北支拒马河、滹沱河和滏阳河支流等13条河流发生超警以上洪水。其中，拒马河等4条河流发生超保证洪水。海河流域子牙河、永定河、大清河相继发生编号洪水，海河流域发生流域性较大洪水。7月29日起，京津冀等地出现强降雨，北京凉水河涨水明显。封面新闻记者代睿摄影河北多个蓄滞洪区启用要求提前做好人员转移安置7月31日，子牙河系大陆泽、宁晋泊蓄滞洪区、大清河系小清河分洪区相继启用。此后，根据北拒马河、琉璃河、白沟河当前水情，综合考虑上游来水情况，河北决定当日23时30分启用兰沟洼蓄滞洪区分滞洪水。兰沟洼蓄滞洪区地处大清河水系北支中游，面积228平方公里，滞洪量3.23亿立方米，为大清河系北支超标准洪水滞洪洼淀，承担分滞白沟河、南拒马河洪水，减轻雄安新区防洪压力的任务。8月1日凌晨2点，东淀蓄滞洪区启用。东淀蓄滞洪区位于河北与天津交界处大清河南北两岸，总面积379平方公里。按蓄滞洪区启用预案，东淀蓄滞洪区大清河以北部分启用。大清河洪水进入东淀蓄滞洪区河北部分后，经分洪减速，预计8月9日前后到达天津。根据子牙河水系滹沱河来水情况，河北决定8月1日11时启用献县泛区。该泛区位于滹沱河下游，总面积331.5平方公里，涉及衡水、沧州2市3县，蓄洪容积约5.4亿立方米。通过上游岗南、黄壁庄等水库拦蓄和献县泛区运用，可有效保证滹沱河大堤安全，保障石家庄等滹沱河沿线地区及下游天津市等广大地区防洪安全。封面新闻记者注意到，在蓄滞洪区启用前，水利部均提前发出通知，要求提前做好人员转移安置等工作。在滹沱河献县泛区启用前，水利部发出通知，要求河北省水利厅督促地方提前做好人员转移安置、围堤隔堤巡查防守等蓄滞洪区运用准备。截至7月31日晚已转移约2.9万人，剩余人员将根据洪水演进情况及时组织全部转移。蓄滞洪区、行洪区、分洪区分别指什么？什么是蓄滞洪区？水利部有关负责人介绍，蓄滞洪区主要指河堤外洪水临时贮存的低洼地区及湖泊等。包括行洪区、分洪区、蓄洪区和滞洪区。行洪区指天然河道及其两侧或河岸大堤之间，在大洪水时用以宣泄洪水的区域。分洪区是利用平原区湖泊、洼地、淀泊修筑围堤，或利用原有低洼圩垸分泄河段超额洪水的区域。蓄洪区是分洪区发挥调洪性能的一种，它是指用于暂时蓄存河段分泄的超额洪水，待防洪情况许可时，再向区外排泄的区域。滞洪区也是分洪区起调洪性能的一种，这种区域具有“上吞下吐”的能力，其容量只能对河段分泄的洪水起到削减洪峰，或短期阻滞洪水作用。加强蓄滞洪区的管理，确保国家和人民生命财产安全，根据《中华人民共和国水法》和《防汛条例》等有关法律法规，各省市结合实际，制定管理办法或管理条例。《河北省蓄滞洪区管理办法》于2021年2月1日起施行，该省列入国家蓄滞洪区名录的包括永定河泛区、小清河分洪区、白洋淀、东淀、文安洼、贾口洼、献县泛区、宁晋泊、大陆泽、盛庄洼、兰沟洼、永年洼、大名泛区等十三处蓄滞洪区。8月1日京津冀降雨减弱部分地区仍有暴雨据中央气象台消息，7月31日以来，北京、河北中部和南部、天津北部、河南北部及四川南部、云南西北部等地部分地区出现暴雨或大暴雨，北京怀柔、延庆、昌平、门头沟及河北保定局地特大暴雨（250～300毫米），北京昌平王家园水库391毫米；上述地区最大小时降雨量40～90毫米，局地超过100毫米。预计1日白天到夜间，京津冀等地强降雨明显减弱，但河北中西部和北部沿山地区、北京、天津北部及河南北部和西部、四川东部和南部、贵州、云南等地部分地区有中到大雨，河北北部、北京西部沿山地区及吉林北部、四川东南部、云南西北部等地有分散性暴雨（50～70毫米）；上述部分地区伴有短时强降水（最大小时降雨量30～50毫米，局地可超过60毫米），黑龙江西北部等地的局地将有雷暴大风或冰雹天气。中央气象台8月1日早晨维持暴雨红色预警和强对流天气黄色预警。专家提醒，华北、黄淮等地受持续降雨叠加影响，致灾风险很高，请公众提高警惕，不要前往山区等地质灾害易发区，远离河道并及时关注最新预警预报、安全提示信息。举报/反馈
