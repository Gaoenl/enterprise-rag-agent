湖北超额完成农户无害化厕所建改造任务完成340.6万座,农户满意率98%日前从省发改委获悉,我省建改造300万座农户无害化厕所任务超额完成,完成量达340.6万座。最新调查问卷显示,全省“厕所革命”农户满意率达98%。作为农村人居环境整治的重要内容,我省将“厕所革命”作为一项重大生态工程来实施。根据“厕所革命”三年攻坚行动计划,2018年至2020年,全省将完成六大类厕所新建和改造任务,包括330万座农户无害化厕所、25063座农村公共厕所、3837座城市公共厕所、3270座乡镇公共厕所、260座交通沿线厕所和2883座旅游公共厕所。为保质保量完成新建和改造任务,省政府每年统筹10亿元财政资金,3年共安排30亿元,对农户无害化厕所建设改造、污水处理和农村公共厕所建设予以奖励。同时,鼓励县市区政府在此基础上,对本地农户予以一定额度的补助。省发改委农经处二级调研员邓锋介绍,在三年攻坚行动中,省发改委等部门制定了《湖北省农村无害化厕所施工安装手册》和《农村无害化厕所建造技术指南》,确保建造质量优良。2018年,我省在钟祥、宜都等20个县市区先行开展“厕所革命”,摸索经验,再逐步推广。当年底的调查显示,20个试点地区农户满意率达96.3%,起到了良好的示范作用。此间,省厕改办加强检查督办,及时发现问题并整改。今年6月至7月,省厕改办参与省政府督查室组织的工作组,分别对黄石、襄阳、宜昌等11个市的36个问题进行了挂牌督办,逐项销号。截至目前,我省“厕所革命”三年攻坚已完成95%的目标任务。其中,农户无害化厕所建改造完成340.6万座,农村公共厕所完成29700座,城市公共厕所完成3935座,乡镇公共厕所完成3340座,交通沿线厕所完成225座,旅游公共厕所完成2673座,全部建改造任务将在今年底完成。记者:胡弦编辑:孙望龙来源:湖北日报原标题:《湖北超额完成农户无害化厕所建改造任务》阅读原文
