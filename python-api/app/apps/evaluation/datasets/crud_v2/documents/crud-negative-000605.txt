中国青年报客户端北京11月23日电（中青报·中青网记者 蒋肖斌）今天上午，第五届海上丝绸之路国际艺术节新闻发布会在北京举行，宣布艺术节将于12月8日至13日在福建泉州举办。本届海艺节包括“共情之美”“天籁之美”“匠心之美”“和合之美”“炫光之美”等5个主题板块与12项活动，融合美艺、美音、美展、美舞、美作等，努力呈现中外文明交流、多元文化汇聚、多国民众联欢的生动图景。新闻发布会现场 主办方供图这也是一次人民的节日，践行“全民、全龄、全域、全时”办节理念，一切从惠民利民出发，全域联动、线上参与、线下体验。海艺节通过组织南音会唱、木偶表演、街头文化艺术展演等活动，深入街区、进入社区，与群众互动、与市民联欢，打造“没有围墙的剧院”，营造全城参与、人人共享的艺术氛围，将艺术盛会与市民群众生活紧密衔接，使文化魂和烟火气在世遗之城融合展现。海上丝绸之路国际艺术节是贯彻落实共建“一带一路”倡议的重要举措，是以“海上丝绸之路”为主题的国家级综合性国际艺术节。海艺节由文化和旅游部、福建省人民政府联合主办，每两年举办一届，永久落户泉州，2014年迄今已成功举办四届，先后有60多个国家和地区、众多国际组织参与。来源：中国青年报客户端举报/反馈
