2023-08-19 11:32，正文：原标题：英国冷血护士谋杀7名婴儿后被判有罪 通过注射空气等多手段杀人海外网8月19日电据英国广播公司等多家媒体报道，当地时间8月18日，英国护士露西·莱比因在其工作的医院内谋杀7名婴儿并试图杀害另外6名婴儿而被判有罪。英媒称，莱比在2015年6月至2016年6月期间谋杀了7名婴儿，包括故意给他们注射空气和胰岛素、过度喂奶以及殴打等方式。而在2015年6月前，莱比所在的新生儿病房每年婴儿死亡人数不到3例。检方称，莱比“精于算计且狡猾”，通过反复改变伤害婴儿的方式，尽最大努力隐瞒自己的罪行。她还试图欺骗同事，并将她造成的伤害伪装成是婴儿本身的脆弱。警方在调查过程中搜查了莱比的房子，发现了大量手写便条，其中一张纸条上写着“我很邪恶，我做了这件事”，还有纸条写着“我不配活下去。我故意杀了他们，因为我不够好，无法照顾他们。”媒体称，莱比是英国近年来“情况最严重的婴儿连环杀手”，她拒绝出庭接受最新判决。受害者家属在18日发布的一份联合声明中表示：“正义得到了伸张，本应照顾我们婴儿的护士被判有罪。但这种正义并不能消除我们所经历的极度愤怒和痛苦。”莱比将于8月21日在曼彻斯特刑事法庭被判刑。（海外网张霓）（来源：海外网）返回搜狐，查看更多责任编辑：
