2023-08-16 16:32，正文：原标题：国网泰和县供电公司：开展首个“全国生态日”环保公益宣传活动“我们要爱护自己的家园，共创绿色生活，共享绿色家园，做生态环境保护的宣传者、实践者、推动者……”8月15日，国网泰和县供电公司在文田营业厅门口组织开展首个“全国生态日”环保公益宣传活动，牢固树立和践行“绿水青山就是金山银山”理念，增强全民生态环境保护的思想自觉和行动自觉。该公司在营业大厅门口，摆放主题宣传展板，积极向前来缴费的电力客户、过往的市民群众讲解宣传生态环境保护内容，发放电网环境保护宣传手册，宣传电网环保、电能替代、安全用电等知识，进一步提高群众的生态文明意识。同时，还组织共产党员服务队人员在现场悉心解答群众关于如何做到节能减排、如何使用“网上国网”APP等问题，让更多市民群众了解电网的生态优先、绿色发展理念，倡导大家树立低碳环保意识，养成生态文明、节能环保习惯，积极参与生态文明建设，共同建设美丽家园。“这个宣传活动真的很有意义，之前都不知道全国生态日，今天了解了很多，还知道了电网实施的候鸟生命线、生命鸟巢等公益项目，是为了推动电网与鸟类和谐共处。”家住文田市场的袁女士感慨道。下一步，国网泰和县供电公司青年志愿者将通过“线上＋线下”的形式开展环保公益宣传教育活动，组织青年志愿者积极践行首个全国生态日“绿水青山就是金山银山”主题行动，秉承绿色发展理念，结合地域特点，从自身做起、从小事做起，全面推进生态环境质量提升，建设幸福美丽新泰和。(康信彬、周丹）返回搜狐，查看更多责任编辑：
