人民网海口1月11日电 (李学山)美国太平洋时间1月9日，第41届摩根大通医疗健康大会(J.P. Morgan Healthcare Conference)在美国加利福尼亚州旧金山盛大开幕。大会期间，海南博鳌乐城国际医疗旅游先行区(以下简称“博鳌乐城先行区”)管理局联合先声药业，于北京时间1月10日举办“一条进入中国的快速通道：海南乐城先行政策专项推介会”(以下简称乐城先行区政策推介会)。这是2023年博鳌乐城先行区首场境外推介会，也是海南自贸港园区首个在美专场推介会。尽管当天天气微凉，但推介会现场却热度“爆棚”，这场横跨太平洋的政策推介会吸引了143家药械企业参与，包括CTI BioPharma、Agios、Marinus、Phathom等10余家上市制药企业，85家拥有创新药械产品但未在国内上市的美国药械企业，以及30余家创新药械中小企业。美国旧金山第41届摩根大通医疗健康大会(J.P. Morgan Healthcare Conference)迎来“乐城时刻”。本次政策推介会采取线上线下相结合的方式，旨在搭建博鳌乐城先行区与国际药械从业者的沟通交流渠道，强化先行区与国际药械企业之间的沟通交流，激发市场主体活力，进一步提升海南省及乐城先行区在国际创新药械领域的知名度和影响力，推动国际优质资源汇集，赋能海南自由贸易港高质量发展。海南省长冯飞在视频致辞中说，建设海南自由贸易港，是中国重大国家战略。海南正瞄准世界最高水平的开放形态，加快建设具有世界影响力的中国特色自由贸易港，将实行“一线放开、二线管住”和“境内关外”的特殊制度安排，并逐步形成以“零关税、低税率、简税制”和贸易、投资、跨境资金流动、人员进出、运输来往自由便利以及数据安全有序流动为主要特征的自贸港政策制度体系。博鳌乐城国际医疗旅游先行区是海南自贸港重点园区之一，也是中国医疗医药改革创新发展先行先试区，至今累计引进国际创新药械超290种，成为国际创新药械进入中国内地的最主要通道。海南是个宜游宜居宜业的活力宝岛，建设自贸港为全世界投资者带来巨大发展机遇。热情欢迎全世界投资者和各类人才到海南自贸港投资兴业，共享海南对外开放的丰硕成果。博鳌乐城先行区管理局常务副局长吕小蕾在会上分享了海南省及博鳌乐城先行区政策、产业化发展优势，多角度展现海南自由贸易港和博鳌乐城先行区的投资机遇。她表示：“博鳌乐城先行区是链接中国与全球先进药械市场的全球窗口，是全球创新药械在华提前使用的‘医疗特区’。博鳌乐城先行区在全国率先开展的临床真实世界数据应用试点，为国际创新药械加速进入中国市场提供‘绿色通道’。我们真诚希望世界各地更多创新药械产品在乐城的帮助下快速进入中国，更多制药公司参与中国医疗卫生领域的改革开放，分享中国健康消费的大市场。”先声药业首席投资官、乐城产业招商大使周高波分享了先声药业的创新发展以及合作情况。先声药业是一家创新与研发驱动的制药公司，重点聚焦肿瘤、神经系统及自身免疫三大领域，同时积极前瞻性布局未来有重大临床需求的疾病领域，致力于让患者早日用上更有效药物。先声药业的创新药品科赛拉(注射用盐酸曲拉西利)通过使用乐城真实世界证据支持产品临床评价，于2022年7月13日获国家药监局批准进口注册上市。“真实世界数据研究试点的适用范围是什么？”“真实世界数据研究试点推动产品在中国的注册上市，与常规临床研究(RCT)有何不同？”“真实世界数据研究试点项目申报流程是怎样的？”……在随后的问答发言环节中，与会药械企业代表踊跃提问，现场交流氛围热烈。对于美方企业代表普遍关心的问题，乐城管理局代表一一进行了详细解答。此次推介会吸引了更多美方药械企业将目光投向博鳌乐城先行区，为先行区进一步开展国际化招商奠定了基础。现场参会的美方药械企业代表纷纷表示，本次推介会让他们对海南自贸港和博鳌乐城先行区有了更直观的认识，非常期待能与海南自贸港和乐城先行区有更多领域的合作机会，参与到海南自贸港的发展新浪潮，共享发展新机遇。举报/反馈
