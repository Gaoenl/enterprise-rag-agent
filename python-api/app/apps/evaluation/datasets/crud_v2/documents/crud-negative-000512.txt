2023-08-07 23:29，正文：                原标题：川渝特高压工程开展铁塔组立首基试点                              8月6日，位于重庆市潼南区新胜镇的川渝1000千伏交流特高压线路工程101号塔，国网重庆市电力公司员工正在进行组塔施工作业。刘洪君摄  8月6日下午2点，在重庆市潼南区新胜镇，川渝特高压交流工程开展全线首基铁塔组立试点，标志着该工程全面进入铁塔组立阶段。  据介绍，川渝特高压交流工程起于四川省康定市呷巴乡，止于重庆市铜梁区少云镇，工程新建线路全长1316公里，铁塔1937基，其中单塔最重达751吨，最高达194.8米。    8月6日，位于重庆市潼南区新胜镇的川渝1000千伏交流特高压线路工程101号塔，国网重庆市电力公司员工正在进行组塔施工作业。刘洪君摄  据了解，该工程是第一个落点重庆市的特高压工程，也是重庆首个机械化施工率达100%的特高压输电线路工程。全域、全过程机械化施工有效缩短了铁塔组立等工序作业时间，仅需18天即可完成1基百米级铁塔的组立，作业效率将提升30%-50%，大幅降低了现场安全风险。  川渝特高压交流工程是国家《“十四五”电力发展规划》明确的“十四五”期间开工建设的重点输电工程，建成后可满足雅砻江、大渡河新增水电可靠送出，保障成渝负荷中心用电需要，提升西南电网整体供电能力和运行可靠性，为成渝地区双城经济圈建设提供更加坚强的电力保障。(王燕、杨涛、张力)返回搜狐，查看更多                        责任编辑：
