展示中国艺术！新版杂技芭蕾剧《天鹅湖》亮相新加坡2023-07-28 22:14来源：澎湃新闻·澎湃号·媒体字号7月27日，由西安战士战旗杂技团创排的新版杂技芭蕾剧《天鹅湖》在新加坡滨海艺术中心圆满完成首场演出，受到了到场观看的新加坡总统和市民观众的高度赞誉。伴随着《天鹅湖》经典音乐在新加坡滨海艺术中心剧场奏响国籍不同、肤色不同的现场观众在这一刻感受到了同样直抵心灵的中国杂技艺术魅力您了解新版杂技芭蕾剧《天鹅湖》吗？新版《天鹅湖》是西安战士战旗杂技团根据西方名著、舞剧《天鹅湖》改编并加入杂技元素的芭蕾舞剧。创新版的作品先后在中国多个省区市以及国家庆典上演出，深受各界人士好评。据了解，此次赴新加坡演出是该团在新冠疫情后首次走向国外演出，给新加坡观众带来了一份文化厚礼。新版《天鹅湖》节目在保留传统芭蕾舞演艺风格的基础上推陈出新，巧妙地将芭蕾舞剧与杂技技巧融为一体，演出强化了节目观赏性和趣味性，扣人心弦。肩上芭蕾、斜杠、抖杠、钻圈、柔术、流星球、高空吊环、空竹、单手顶等30多个杂技节目，在展示高难度技巧的同时，注重剧目的审美和文化表达的方式，令观众们印象深刻。此次演出作为助力新加坡“总统挑战”慈善募捐义演首场演出，首场演出的所有收益将作为慈善基金，用于帮助当地生活的弱势群体。西演·西安战士战旗杂技团新版杂技芭蕾剧《天鹅湖》精彩纷呈的表演受到新加坡各界人士的热烈欢迎和高度评价。新加坡总统哈莉玛·雅各布到场观看演出，并为团队颁发了义演纪念杯。据了解，此次演出不仅可以让新加坡的观众欣赏到中国多元化的杂技艺术，还可以品鉴到来自中国西安的特色文创，为中新建交33周年，共建“一带一路”的合作，弘扬中华传统杂技艺术、展示中华文化自信起到良好推动作用。另外7月28日、30日还有三场演出奉献给新加坡观众今年十月新版杂技芭蕾剧《天鹅湖》还将奔赴阿曼苏丹国再次助力世界文化交流明年还将前往日本、英国等国家进行演出将中国文化推向世界展露中国杂技的“国际范”原标题：《展示中国艺术！新版杂技芭蕾剧《天鹅湖》亮相新加坡》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
