记者从中国医药物资协会获悉，6月28日，该协会第六届第一次常务理事会议在重庆召开，会议既总结回顾了2019全年及2020年上半年的工作，也对协会2020年工作要点和设想进行了部署。值得关注度的是，会上，中国医药物资协会对外发布《2019年度中国医药知识产权行业发展状况报告》（下称报告），对协会常务理事以上会员单位的知识产权数据（商标）进行了汇总分析，受到业界关注。报告指出，2019年，我国医药工业发展整体形势向好，主要指标均有不同程度的提高。“一带一路”战略全面推进，健康中国2030战略全面实施，国际市场需求回暖，国内健康消费升级加快，医药工业呈现企业创新更加活跃，行业洗牌持续加剧等趋势。我国医药行业参与国际竞争的方式，由过去大宗原料药出口、欧美代工逐步向仿制药国际注册、创新药国际注册转型，产品出口附加值逐年提高。值得关注的是，报告从商标品牌、专利技术、版权保护、法律纠纷等多个维度对节选的74家会员单位进行知识产权综合评分，尤其对这74家会员单位的商标布局情况进行了较为详细的梳理。数据显示，2019年，74家会员单位共申请商标1.0889万件，其中无效状态的商标总数达到1562件，商标申请无效状态占比达到14.34%；从第35类商标的申请注册情况来看，节选的74家会员单位中，未申请注册第35类商标的达到19家，占比高达26.03%。报告认为，国内企业知识产权整体评分偏低，无论是从对商标品牌的布局、保护及风险防控，还是对第35类商标的重视程度来看，都有较大的提升空间。比如，针对1562件无效商标所潜藏的商标品牌布局漏洞和品牌发展风险，后续该如何争取权利和防控风险，将会对74家会员单位带来不同的发展前景。此外，第35类是商标抢注的重灾区，同时也是企业未来发展连锁经营商业、电子销售的核心类别，药企在第35类商标申请上的布局，将对企业未来的发展和壮大有着重要的意义，然而，现有数据表明相关从业者并未充分认识这一点。报告提出，我国医药工业要提高行业竞争力，除从业者在人才培养、技术创新、知识产权培育等方面下功夫外，也需要多渠道加强政策和资金扶持力度，多途径鼓励药品医疗器械创新与转化，多措施完善药品供应保障机制，多举措提升产业集中度和国际化水平等。正如中国医药物资协会负责人所言，大健康产业作为战略新兴产业的代表，知识产权是其发展的重要资源和竞争力的核心要素，对院校科技创新、人才培养有着重要的基础性作用。同时，医疗大健康专利技术的跨界融合、大数据与医疗大健康的成功融合以及国际化全链条，为医疗大健康发展送来机遇。（本报记者 姜旭）(责编：林露、李昉)分享让更多人看到
