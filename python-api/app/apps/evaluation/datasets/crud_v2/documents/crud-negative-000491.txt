2023-08-16，正文：因未让座大妈公交上打患癌症小伙 一巴掌打晕在地，家属索要100万赔偿暴力大妈一上公交车就要求一名身患胃癌晚期的小伙赶紧让座，小伙明确的告诉了大妈自己的身体状况无法长时间站立，可大妈依旧不依不饶的说不相信，并且还嘲讽的说‘年纪轻轻的不想让座编什么理由啊？我还一身病不能站呢。于是小伙说了一句‘阿姨你看起来壮实的很不像生病的’，可能就是这句话惹怒了大妈，大妈二话不说抬手就是狠狠的一巴掌打在了小伙的脸上，小伙当场就被打晕在地，大家看这个大妈红润壮实的很，一般人还不一定打的过她呢！看着被打晕在地的小伙大家都慌张了起来，赶紧打了急救电话，大妈也被带到了派出所调查，据医院检查结果身患癌症的小伙被打出了脑震荡，小伙家属要求大妈赔偿100万，大妈当场就拒绝并狡辩说他晕倒是因为他自己身体原因，并不是她打成这样的。尽管我们倡导尊老爱幼的价值观，但年轻人也有自己不舒服的时候。小伙子已经说明了自己的身体状况，但大妈却不相信，认为小伙子故意不给她让座。即使不让座，车也会开到站下车，大妈也没有到站下车的困难。为什么非要用一巴掌打小伙子呢？这明显是道德偏差的表现。从个人角度来看，我认为大妈的行为确实过分，应该赔偿小伙子。作为一个病人，小伙子本来就身体不适，这一巴掌无疑会使他心理上感到不舒服，甚至可能影响他的病情。毕竟相对于健康人，病人的心理承受能力要较弱一些。因此，大妈应该为自己的行为负责并赔偿小伙子。(责任编辑：黄昱植)
