2023-08-04 16:13，正文：                原标题：印度医院一儿童用挖洞纸杯当氧气面罩 当地卫生部长事后回应                              视频画面截图  海外网8月4日电据《今日印度》8月4日报道，近日，印度一名儿童在医院中使用纸杯当氧气面罩的视频在网上疯传，引发了印度网友对该邦医疗设备可用性的质疑。当地卫生部长随后也不得不做出回应。  印媒称，这段视频摄于泰米尔纳德邦一家政府医院。一位父亲因年幼的儿子呼吸困难而将他送到医院里。视频画面显示，这位父亲将一个戳了洞的纸杯连接到氧气瓶上，用它作为儿子的临时面罩。  对此，不少印度网友对该邦医疗设备的可用性提出质疑，并批评为何院内的医生会允许这种做法。随后，泰米尔纳德邦卫生部长苏勃拉马尼安表示，他在询问后发现该医院备有氧气面罩。画面中孩子的父亲拒绝使用这些面罩，是担心多名患者可能使用相同面罩，给他的儿子带来感染其它疾病的风险。这位部长还怀疑，男孩的父亲“看起来是有目的的在进行拍摄”，但他也表示，无论出于什么原因，医院工作人员不应该允许孩子“戴纸杯面罩”。（张霓）返回搜狐，查看更多                        责任编辑：
