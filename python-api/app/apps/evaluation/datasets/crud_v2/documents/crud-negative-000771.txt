2023-07-26 10:21，正文：原标题：贝壳公益“我来教您用手机”项目服务老年人超54万人次贝壳公益“我来教您用手机”项目服务老年人超54万人次 三秦都市报讯（记者 王媚）近年来，随着我国社会数字化的飞速发展，老年人对智能手机的使用需求越来越大。近日，记者从贝壳公益获悉，自2018年在北京率先推出“我来教您用手机”项目，至今已走过第五个年头。截至2023年3月底，“我来教您用手机”项目已走进全国55个城市，开展6777次手机公益课堂，服务老年人超54万人次。据悉，贝壳公益通过发动数万门店经纪人组织开展定期公益授课，为“银发族”提供满足老龄需求、符合老龄特质、适于老龄学习的实用性手机教学课程，务实有效帮助他们与数字新时代接轨。贝壳公益通过不断完善课程内容、更新优化课件课本，丰富学习环节，帮助每一个参与项目的老年人都能学得轻松、学得快乐，享受便捷快乐的社区养老生活。西安一位参加手机课堂的李叔叔说，通过手机课堂他学会如何利用美图秀秀修图、微信发红包、支付宝乘坐公交地铁等，这些都是最日常最实用的，学会后只要带着手机出门，非常便捷，收获还是蛮多的。除社区日常课程，贝壳公益还围绕“我来教您用手机”项目展开丰富多样的创新活动，例如为老人们举行“银发毕业典礼”，把社区课堂带进养老院，为老人们的闲暇时光增添一抹数字光彩，向社区老人宣传下载国家反诈中心APP等。在“我来教您用手机”公益项目中，收到鼓舞的不仅仅是老年学员，讲堂的“老师们”也是主角。西安公益讲师志愿者金万瑞说，老人们日常生活中需要使用的手机功能还是挺多的，但是子女们都要上班，没时间教他们，但来到贝壳公益课堂，这些问题都可以解决，老年朋友们一起相互交流，也让大家开心许多。返回搜狐，查看更多责任编辑：
