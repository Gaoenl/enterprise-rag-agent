人民网迪拜7月28日电 (记者张志文)7月26日，中国驻科威特使馆举办庆祝中国人民解放军建军96周年招待会。驻科威特大使张建卫、国防武官薛传来，科副首相兼国防大臣艾哈迈德亲王，总参谋长代表、后勤供应事务总长助理哈立德少将等近500人出席。科王储米沙勒等赠送花篮。薛传来致辞表示，党的十八大以来，在党中央、中央军委和习近平主席坚强领导下，人民军队开创了中国特色强军事业新局面。习近平主席提出全球安全倡议，为应对当前纷繁复杂的国际安全挑战贡献了中国方案。中方愿与科方积极落实两国领导人达成的重要共识，推动双边军事交流合作取得更多成果。艾哈迈德转达科埃米尔、王储、首相以及科政府的热烈祝贺，表示在两国领导人的亲自引领和推动下，科中将不断深化包括国防在内的各领域合作。举报/反馈
