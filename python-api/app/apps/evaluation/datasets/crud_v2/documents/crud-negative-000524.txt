2023-08-08 16:15，正文：近日，鞍山钢铁完成全部51家单位、14000多台终端的网络终端准入工作，实现全覆盖，比计划工期提前半个月。鞍山钢铁网络终端准入工作是2023年鞍钢集团推进的一项重点工作，列入数字鞍钢建设重点任务清单，旨在对接入网络的终端设备进行实时监察和管理，保证网络安全和信息安全。今年以来，鞍山钢铁不断夯实网信安全基础管理，深化安全防护技术应用，加大自主可控改造力度，先后完成网络终端准入、互联网出口统一收敛等重点、难点工作，全面打造“管理技术 自主可控”三位一体的网信安全防护体系，为数字鞍钢建设保驾护航。面对下属单位较多、网络层级不规范、交换机与要求不符等困难，鞍山钢铁发动各单位迎难而上，明确分工，落实责任，全力推进网络终端准入工作。针对各单位网络改造牵涉面广、技术复杂、问题排查难度高等不利因素，鞍山钢铁组织鞍钢信息产业公司分别建立网络和准入专班团队，协同各单位全面梳理整改历史遗留问题，累计更换不合要求的网络交换机328台，并借助准入平台验证功能对整改结果进行全网络合规性验收。为确保各职能中心和基层单位工作业务不受影响，相关部门和各单位累计献工80多个工作日，充分利用节假日休息时间加班加点，尽力做到无感切换、提前完工。作者：姜帅
