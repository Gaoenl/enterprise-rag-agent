2023-07-31 11:01:04，正文：东方网通讯员姚均7月31日报道：近日，闵行华漕镇一男子将女友的贵重首饰变卖，为了蒙混过关，还购买了同款高仿品以假换真。谁知发觉首饰异常的女友到黄金回收店进行鉴定，而该店正是男友销赃地点，于是东窗事发。7月14日，该男子因涉嫌盗窃罪被闵行警方依法刑事拘留。近日，家住闵行华漕镇的刘女士发现自己的一个黄金手镯重量明显变轻，觉得蹊跷的刘女士委托家附近的黄金回收店进行鉴定，谁知店主说刘女士的手镯是假的，而店主前不久刚回收了一个同款手镯。大感意外的刘女士回家后检查其余首饰，发现另有两条项链和一块手表疑似被掉包，怀疑是自己的同居男友曹某某所为，于是到华漕派出所报案。随后，派出所民警传唤曹某某接受调查，曹某某对盗窃的行为供认不讳。曹某某称，其觉得与刘女士交往花销太大无法负担，近期正准备与女友分手后离开上海，为了“挽回损失”，遂分别于7月1日和7日从女友处窃取一个手镯和一条项链进行变卖，并将事先购买的假冒同款手镯和项链放回原处。而去年11月，他曾用相同手法将女友的一块名牌手表和另一条项链以假换真后变卖。经初步估算，4件被盗物品共计价值13万余元。目前，犯罪嫌疑人曹某某因涉嫌盗窃罪被闵行警方依法刑事拘留，案件正在进一步审理中。
