2023-08-05 20:00，正文：原标题：“抑”路阳光，守护少年的你极目新闻记者 常怡通讯员 汪海燕 程雪菲 汪志强8月3日，武汉市慈善总会“抑”路阳光心灵驿站服务点揭牌仪式在新洲区邾城街道章林社区和祥燕社区依次举行。至此，新洲区两家社区青少年儿童心灵驿站正式成立，可为全区青少年提供心理健康服务。在启动仪式上，市慈善总会、区民政局、邾城街道办事处、予爱青少年发展服务中心相关负责人共同为“抑”路阳光心灵驿站服务点揭牌。新洲区民政局相关负责人致辞，表示青少年是家庭的希望、祖国的未来。将以此活动为契机，联动街道和社区将驿站打造成为长期开展健康讲座、心理咨询、问题指导、心理疏导、助教助学的心灵释放场所，让孩子们在温暖的环境中快乐成长，树立正确的世界观、人生观、价值观。予爱青少年发展服务中心向大家介绍了项目发起、宗旨、覆盖范围和预期成效。当天还在章林社区开展了一堂心理美术沙龙，45名孩子在专业老师的引导下，感受了别样的心灵疏导快乐课堂。据了解，“抑”路阳光慈善项目是武汉市慈善总会发起，予爱青少年发展服务中心执行，意在全市各区建立“阳光驿站”服务点，为青少年抑郁症心理健康提供康复服务平台。打造心情树洞、陪伴者训练营、开办成长课堂、抑郁症心理咨询、康复指导、疗愈工作坊、幸福家大型公益课宣讲等，下一步，将以点带面，覆盖全区，继续探索关心关爱青少年心理健康新路径，切实把关心关爱青少年身心健康落到实处。（图片由通讯员提供）（来源：极目新闻）返回搜狐，查看更多责任编辑：
