2023-07-24，正文：近日，一起商标纠纷案引发了网友的关注。一家名为“理想汽车贴膜工厂”的店铺，被理想汽车以“侵害商标权及不正当竞争纠纷”为由，起诉索赔120余万元。店铺老板朱裕昊却表示，“理想”是他的小名，从2012年开始开店就叫“理想汽车装饰”，当时理想汽车还没出来。据悉，该店铺位于山东临沂，主要从事汽车贴膜业务。店铺成立时店名为“理想汽车装饰”，店铺营业执照为“临沂市朱裕昊汽车用品销售部”；2022年店铺成规模后登记注册为“临沂理想汽车服务有限公司”，一个月后更名为“临沂新理想汽车服务有限公司”；2023年3月，在对店面装修时，更名为“理想汽车贴膜工厂”。这是朱裕昊的“理想汽车贴膜工厂”。而理想汽车是一家新能源汽车企业，创立于2015年7月。国家知识产权局商标公告显示，理想汽车在2018年5月申请第30727125号“理想”注册商标，分类为12-运输工具，专用权期自2020年5月28日至2030年5月27日。这是理想汽车的注册商标。理想汽车认为，贴膜店使用与其相同或近似的企业标识，容易让消费者误以为贴膜店与理想汽车有关联或合作关系，从而损害了理想汽车的商标权和商誉。因此，理想汽车向法院提出以下诉讼请求：判令被告停止在店面门头、店内装潢及短视频平台上继续使用与原告第30727125号“理想”注册商标相同或近似的企业标识；判令被告更改企业名称，且更改后的企业名称不得含有“理想”文字；判令被告在当地媒体登报道歉30天；判令被告赔偿原告经济损失人民币100万元、为制止侵权而支出的费用20万元（暂计）。这是理想汽车提出的诉讼请求。朱裕昊则认为，自己使用“理想”二字是出于个人姓名和情感的考虑，并没有故意模仿或借用理想汽车的商标和知名度，也没有给理想汽车造成任何实际损失。他表示，自己的小名就叫理想，叫了30多年，“从我2012年开始开店，店名就叫‘理想汽车装饰’，那时候理想汽车还没出来呢。”
