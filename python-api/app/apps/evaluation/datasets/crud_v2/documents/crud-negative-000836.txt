端午假期宁夏交警持续开展统一行动，全区道路交通安全畅通有序2020-06-29 16:45来源：澎湃新闻·澎湃号·政务字号端午节假期，宁夏公安交管部门提前分析研判，精心部署组织，结合上级工作部署，连续三天组织开展全区统一行动，全力做好道路交通安全管理工作，全区未发生死亡3人以上道路交通事故,未发生长时间、大范围交通拥堵，全区道路交通安全畅通有序。认真分析研判 精心组织部署公安厅交通管理局精心分析全区交通安全形势，利用科技大数据编制《2020年端午节假期出行预测报告》。结合节日期间交通出行特点制发专门通知，要求各地针对重点路段和区域加强分析研判，制定有针对性的工作方案，细化工作措施，明确工作任务，切实做好端午节期间道路交通安全管理工作。加强源头管理 切实消除隐患假期前，各地交管部门积极会同交通运输、安全监管、应急管理等部门对辖区客货运及危化品运输企业开展突击检查，加大对旅游包车、七座以上等“营转非”车辆路面监管力度，督促企业落实主体责任。按照“四必进、七必查”工作要求，对辖区危化品运输企业开展拉网式隐患排查，通报典型事故案例强化警示提醒，加大对危化品运输车辆的路面检查力度，切实消除安全隐患。强化路面管控 严防交通事故端午节期间，各地交管部门最大限度地将警力、执法装备投入到高速公路、国省道等重点路段和午后、傍晚等重点时段，加强对自驾车流、公路客流集中的高速公路、国省道以及通往旅游景区道路的交通疏导和巡逻管控力度。认真开展“逢五”“逢十”及周末酒驾醉驾夜查集中统一行动，通过联勤执法、接力整治、错时勤务、交叉检查、随机抽查、机动巡查等方式，不间断、无盲区、全管控、无缝隙，全力治理酒驾醉驾违法犯罪行为。统一行动期间，各级领导带队深入一线执法岗点，每日通报工作战果，督促落实工作措施，推动酒驾查处取得实效。据统计，端午假期全区交警共出动警力3202 人次、警车489辆次，查处各类交通违法6791起，其中：饮酒驾驶50起、醉酒驾驶34起、无证驾驶37起。原标题：《端午假期宁夏交警持续开展统一行动，全区道路交通安全畅通有序》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
