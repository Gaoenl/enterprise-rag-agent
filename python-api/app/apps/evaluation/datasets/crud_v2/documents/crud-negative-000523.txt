2023-08-18 18:33，正文：原标题：索诺瓦携手清华大学公益助力推动无障碍聆听环境建设8月18日，全球领先的听力解决方案供应商索诺瓦与清华大学就合作助力校园无障碍环境提升、促进中国残疾人事业发展进行了亲切会谈，启动了“无障碍聆听”公益合作。会议期间，索诺瓦就捐赠索诺瓦旗下峰力络+无线聆听设备和云塔稳态声场系统与清华大学达成意向合作。双方期待通过此项合作提升清华大学校园无障碍聆听环境的建设水平，推动中国无障碍融合教育的发展，保障听障人士平等、充分享有受教育的机会，便捷地参与和融入社会生活等方面，做出表率和示范。清华大学党委副书记向波涛，索诺瓦集团首席执行官Arnd Kaldowski，索诺瓦全球副总裁、中国区总经理方芳，清华大学教育基金会副秘书长孙大鹏、学生代表江梦南等人出席了启动仪式并发言。清华大学无障碍发展研究院邵磊院长主持了会谈。向波涛表示，“清华大学在建设中国特色世界一流大学的过程中，积极推动无障碍交叉学科的建设与发展，与中国残联合作设立了智库科研平台清华大学无障碍发展研究院，清华大学也在持续开展更加无障碍的包容性校园环境建设工作，为国家无障碍环境建设和残疾人事业发展发挥了重要的推动和示范作用。”他还表示，“中国无障碍环境建设法将于9月1日正式实施，需要充分发挥政府、社会等多方力量共同构建。清华大学愿与索诺瓦集团一道，加强交流与合作，构建更广泛、更紧密的合作关系，为人类的健康福祉提升和包容友好的社会环境建设做出更多的努力和贡献。”索诺瓦是全球领先的听力解决方案供应商，致力于为人们提供全面的听力解决方案，从个人音频设备到听力保健服务，助听器和人工耳蜗。通过创新的技术和方法，让所有关注听力健康的人们享受聆听的美好，从而创造无限的人生。“索诺瓦作为行业的创新领导者，希望与清华大学一道，为保障中国听障人士的权益，提高听障人士的生活品质，促进社会的进步和可持续发展而不懈努力。”索诺瓦集团首席执行官Arnd Kaldowski表示。“峰力的无线传输技术在业内可谓独树一帜的。该技术能够使放大的言语信号自动根据周围环境或噪声音量的变化而变化，无论在语言康复机构和特殊教育学校、普通的中小学、高等院校、还是特定的公共场所等，帮助各个年龄阶层的听障人士从容面对各种复杂和挑战的聆听环境。”返回搜狐，查看更多责任编辑：
