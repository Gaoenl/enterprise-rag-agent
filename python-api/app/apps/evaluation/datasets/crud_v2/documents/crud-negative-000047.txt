2023-07-31 10:56:00，正文：中新社香港7月31日电 中国人民解放军驻香港部队(驻香港部队)31日发布消息称，驻香港部队30日晚在昂船洲军营举行庆祝中国人民解放军建军96周年招待会，感谢香港各界长期以来对驻军工作的关心与支持。香港特别行政区行政长官李家超、中央人民政府驻香港特别行政区联络办公室主任郑雁雄、中央人民政府驻香港特别行政区维护国家安全公署署长董经纬、外交部驻香港特别行政区特派员公署署理特派员潘云东，驻香港部队司令员彭京堂和政治委员赖如鑫担任主礼嘉宾。招待会在雄壮的中国人民解放军军歌声中开始。现场播放了反映驻香港部队建设发展成就的主题短片《守护》。解放军驻港部队司令员彭京堂在致辞中回顾了96年来人民军队在中国共产党领导下为党和人民建立的伟大历史功勋，回顾了驻军进驻香港26年来坚决听党指挥、忠实履行防务、真诚爱港亲民的奋斗历程，对香港特别行政区政府和社会各界长期以来对驻军的关心支持表达了衷心感谢。彭京堂表示，党的二十大擘画了“一国两制”事业发展的宏伟蓝图，香港进入了从由乱到治走向由治及兴的新阶段，驻香港部队全体官兵将高举习近平新时代中国特色社会主义思想伟大旗帜，深入学习贯彻习近平强军思想，坚决听从党中央、中央军委和习主席指挥，严格遵守香港基本法、驻军法，加强部队全面建设，不断提高履行使命能力，坚定支持行政长官和特区政府依法施政，与香港社会各界一道携手同心、齐力奋进，为维护国家安全和香港长期繁荣稳定，为推进“一国两制”实践在香港行稳致远作出新的更大贡献。香港特别行政区政府主要官员、中央驻港机构有关负责人、驻港中资机构代表、部分港区全国人大代表和政协委员、爱国爱港社团代表以及驻军官兵代表等200余人出席招待会。(完)
