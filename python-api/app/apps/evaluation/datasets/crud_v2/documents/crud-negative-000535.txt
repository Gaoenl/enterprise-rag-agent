2023-08-09 10:15，正文：本报讯（全媒体首席记者 沈璐佳）一边是公安的校园周边“见警察、见警灯、见警车”，一边是教育部门的“见值班领导、见教师、见家长”，还有志愿者的不间断守护……昨日记者了解到，为了加强学校、幼儿园的第一道安全屏障，日前，我市各方联手开会部署秋季开学安全工作，为“护校安园”吹起冲锋号。市公安局相关负责人表示，要把“护学岗”工作作为一项政治任务和民生工程抓细抓实，在上放学等重点时段，学校周边做到“三见”，即见警察、见警灯、见警车，全力克服警力短缺问题，确保完成“护学岗”任务。除公安部门视频点调、实地抽查外，希望教育行政部门和中小学、幼儿园要及时将公安干警出警执勤情况反馈给市公安局，杜绝“护学岗”期间存在警察空岗现象。市教育局学校安全管理科副科长倪栋表示，教育行政部门和各级各类学校、幼儿园要配合公安部门做好“护学岗”工作，在上放学等重点时段，同样做到“三见”，即见值班领导、见教师、见家长及志愿者，全面加强人防、物防、技防建设，不断强化校园安保管理。对于“护学岗”，不得不提的重要力量便是不辞辛苦的志愿者们，他们传递温暖，用心撑起保护伞，用爱筑起安全墙。孙宝江公益团队负责人孙宝江介绍，团队成立“护学岗”已经有3年了，目前为46所学校站岗服务，总计有7万多人参与。一直以来，志愿者们风雨无阻用爱心坚守，大家觉得穿上红马甲的那一刻便责任重大，愿意通过付出换来孩子们的“一路平安”。据了解，市教育局和市公安局还将建立信息共享和通报机制，对全市1018所学校（幼儿园）实施常态化检查，排查校园周边安全隐患，联手呵护师生和校园平安。
