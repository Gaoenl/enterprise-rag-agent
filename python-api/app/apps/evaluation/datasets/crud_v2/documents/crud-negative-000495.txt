正在青岛集训备战世界杯的中国女足即将迎来热身赛的实战考验。据来自俄罗斯足协官网的消息称，俄罗斯队已于26日抵达青岛，并将在7月1日和4日与中国女足进行两场非公开的热身赛。据了解，俄罗斯队由莫斯科直飞青岛。抵达青岛后，她们立即在酒店进行简单的热身训练，并进行战术讲解课。昨天，俄罗斯队进行了抵达青岛后的首次正式训练。在最新一期的国际足联女足国家队排名榜上，俄罗斯队位列第24位，比中国队低10位。值得一提的是，俄罗斯足协官网公布了球队此次访华的23人大名单，其中大部分队员来自泽尼特队、莫斯科火车头队、莫斯科迪纳摩队等俄罗斯女超联赛劲旅。俄罗斯队主教练克拉斯诺然透露，俄罗斯队在本月早些时候收到中国女足的热身邀请，“中国队多次获得亚洲杯冠军，并在世界杯和奥运会上取得过好名次。与这样一个高水平对手比赛，过程肯定很精彩。”克拉斯诺然表示，由于中国队正在备战世界杯，考虑到阵容和战术需要保密，因此本次比赛将以非公开的方式进行。中国女足目前正在青岛进行最后一个阶段的集训。有消息称，全队将于7月6日前后启程前往澳大利亚，提前适应当地的气候和环境。另据国际足联规定，在首场比赛开始5天前，参赛球队仍然有机会在当地进行热身赛。中国女足在本届世界杯的首场小组赛将于7月22日晚在珀斯的矩形体育场进行，对手是欧洲劲旅丹麦队。来源：北京日报　记者 赵晓松流程编辑：U031版权声明：文本版权归京报集团所有，未经许可，不得转载或改编。举报/反馈
