央视网消息:北京时间7月27日,第31届世界大学生夏季运动会男子水球比赛在成都现代五项赛事中心游泳击剑馆拉开战幕,中国队在小组赛中以7:13不敌格鲁吉亚队。当日比赛中国队开场与对手展开对攻,首节以2:3落后;第二节被对手连续得分,半场过后格鲁吉亚队将领先优势扩大到8:3。尽管后两节中国队奋起直追,但依然没能逆转,最终落败。中国队主教练王敏辉赛后表示,比赛开始阶段中国队防守战术比较好,但之后对方改变了进攻方式,导致中国队防守空间被压缩,分差被拉大。当日其他比赛中,匈牙利队以27:2轻松战胜新加坡队,德国队以14:8战胜日本队,韩国队以9:11不敌斯洛伐克队,意大利队以13:11击败美国队。水球比赛将持续到8月8日,男子比赛共有11支队伍参加,女子比赛有6支队伍参加,女子比赛将于7月30日开始。
