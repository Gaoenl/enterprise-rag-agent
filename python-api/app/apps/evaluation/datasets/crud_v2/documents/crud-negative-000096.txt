2023-08-19 16:44，正文：原标题：外媒：英特尔将在美国加州裁员140人8月18日消息，据外媒报道，英特尔将在加州裁员140人，其中该公司的福尔瑟姆园区将裁员89人，而圣何塞将裁员51人。外媒称，继今年1月、3月和5月裁员后，此次裁员标志着今年福尔索姆研发园区裁员近500人。去年10月，外媒曾报道称，英特尔正着手裁员，并计划在2023年削减30亿美元的成本。该公司努力削减成本之际，正值其面临芯片需求放缓和竞争激烈的压力。为了降低成本，该公司今年1月份在美国加州裁员数百人，高于该公司此前宣布的裁员数量。该公司还增加了在加州佛森市研发园区的裁员数量，在从1月31日起裁撤111个岗位的基础上，从3月15日起再裁167人。今年5月，该公司还在其客户端计算业务部门（CCG）和数据中心部门（DCG）启动了另一轮裁员。英特尔的裁员计划正值PC需求骤降导致营收大幅下滑以及该公司试图重回芯片制造前沿之际。由于PC和智能手机所需的半导体或芯片需求大幅下降，该公司2023年第一季度的营收同比下降36%，这是该公司营收连续第五个季度下滑。2023年第二季度，该公司的营收为129亿美元，与去年同期的153.21亿美元相比，同比下降15%，这是该公司营收连续第六个季度下滑。该公司预计，2023年第三季度的营收约在129亿至139亿美元之间。本周三，英特尔宣布终止收购以色列半导体代工厂高塔半导体（Tower Semiconductor），原因是无法及时获得合并协议所要求的监管批准。根据合并协议的条款，英特尔将向高塔半导体支付3.53亿美元的终止费，这完全抵消了英特尔代工服务（简称IFS）部门在2023年第二季度获得的2.32亿美元营收。来源: TechWeb返回搜狐，查看更多责任编辑：
