上市公司在行动丨北京文化:《封神第一部》分享研讨会举行 探索中华优秀传统文化创新性发展之道中国上市公司协会2023-12-11 16:36:4511月24日,由中国文联网络文艺传播中心、中国文联电影艺术中心、中国外文局文化传播中心主办,中国文艺网、北京京西文化旅游股份有限公司(股票简称:北京文化证券代码:SZ000802)、世纪长生天影业(北京)有限公司共同承办的《封神第一部》分享研讨会在京举行。此次研讨会围绕充分发挥电影的传播与组织优势,助力建设文化强国、坚定文化自信等重要主题,以及《封神第一部》的故事创作、美学系统、宣传推广等各方面主题进行讨论交流。中国文艺评论家协会主席夏潮表示,中华文明几千年传承下来的优秀的思想观念、道德规范、价值追求,要与当代文化相适应、与现代社会相协调,要与当代审美理念和追求相结合,并由今天生活在高科技、数字化、快节奏、多元文化时代的年轻人传承、弘扬和传播。《封神第一部》的创作,是对新时代中华优秀传统文化的创造性转化和创新性发展进行的一次有益探索。中国电影家协会分党组副书记、秘书长闫少非表示,从今年暑期档《封神第一部》《长安三万里》的票房成绩,可以看出当下观众对于传统文化题材影片的关注和喜爱。这说明立足传统文化的土壤、挖掘传统文化的宝藏,是电影创作的守正之路。电影创作需要更多更好地承担起对优秀传统文化深层次表达的历史使命,把中华优秀传统文化中的世界观、价值观、审美观融入电影的文本创作和影像创作中去。制片人罗珊珊表示,我们努力让电影《封神第一部》成为一部能带给年轻观众震撼和感动的中国神话大片,更希望通过电影《封神第一部》能给观众送上一份中国古典之美,展示我们的文化自信。“坚定文化自信,是当代中国电影人责无旁贷的使命。”《封神第一部》导演乌尔善这样说。他表示,秉持开放包容,是推动电影工业化的必经之路;坚持守正创新,是电影人打造文艺精品的创作标准。将中华传统文化瑰宝转化成符合当代观众喜闻乐见的电影作品,将中华优秀传统文化传播出去,是当代电影创作者应当持续追求奋斗的目标与使命。编剧冉平表示,今天的年轻人正从传统经典去汲取营养,寻找和解决自己现实处境中的位置和问题。我们的创作面对的是年轻人,因此在古典艺术形象的重塑、叙事策略的重置上,要以他们为焦点,围绕当下为年轻人提供有益的价值观借鉴。北京文化电影事业部总经理张焱表示,《封神第一部》将中华优秀传统文化作为影视开发的基石,电影传播主流价值观,弘扬中华优秀传统文化,受到广大中国观众的喜爱,我们也希望让全世界观众通过《封神第一部》更好地了解中国历史和文化。北京文化深耕影视文艺领域多年,坚持弘扬主旋律,坚持将主流价值观和中国优秀传统文化用当下大众所喜爱的方式传播给全世界,《封神第一部》正是公司这一理念的生动实践,未来,北京文化还将推出更多弘扬中华文化的精品力作。文化是一个国家、一个民族的灵魂。文化自信是一个国家、一个民族发展中更基本、更深沉、更持久的力量。中华优秀传统文化既是构成国产影视剧作品优质内容和形成独特美学风格的主要元素,也是引起广大观众共情共鸣的重要因素。北京文化一直以来扎根于深厚的中华文明脉络,用“强刺激、强共鸣、强共情”的影片,将属于国人的文化瑰宝与主流价值观以大众喜闻乐见的方式进行弘扬与传播。由北京文化出品的主旋律影片《战狼2》《我和我的家乡》、现实题材影片《我不是药神》、科幻题材影片《流浪地球》、喜剧题材影片《你好,李焕英》等影视作品,始终坚持以人为本、守正创新,让电影成为文化产业中的引领性力量,成为最受人民群众欢迎的文艺形式,成为中华文化“走出去”的亮丽名片。而《封神三部曲》的创作,可以说是为中国神话史诗题材类型电影“打开了一扇窗”,让全世界的观众看到了中国在此类型电影上的突破,为提高中国文化在世界的影响力与传播力贡献一份力量。在《封神三部曲》的创作过程中,北京文化充分发挥自身全产业链服务型平台的优势,在统一类型化创作标准、建立科学化管理系统、完善科技与艺术的结合上为主创团队提供大量帮助。《封神三部曲》是中国人自己的神话史诗电影,不但拥有充满想象力和史诗感的故事情节,还有高难度的战争场面,需要大批专业人员的共同努力和付出,才能最终高质量地呈现在观众眼前。由包括中国在内的21个国家专业人士组成的《封神三部曲》主创团队,通过共同分享电影工业化制作、特效制作、人员管理方面的经验和智慧,使得属于中国人的神话故事呈现给全世界观众。未来,北京文化将不辜负广大影迷的期待,将《封神三部曲》后两部在全世界观众面前完美呈现。同时,北京文化还将推出更多影视精品,为弘扬中华优秀传统文化贡献力量。
