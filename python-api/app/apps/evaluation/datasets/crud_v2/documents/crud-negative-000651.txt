山西省气象台2023年07月21日14时15分发布雷暴大风蓝色预警，预警区域：太原市、大同市、阳泉市、长治市、朔州市、晋中市、忻州市、吕梁市、晋城市、运城市。预计未来6小时，预警区域中的部分地区将出现雷暴大风天气，阵风风力达7级以上或有较强雷电，局部地区将有短时强降水。请有关单位和人员做好防范准备。防御指南：1.政府及相关部门按照职责做好防风防雷工作；2.注意有关媒体报道的雷雨大风最新消息和有关防风通知，学生停留在安全地方；3.关好门窗，加固围板、棚架、广告牌等易被风吹动的搭建物，妥善安置易受大风影响的室外物品，遮盖建筑物资；4.户外人员应当躲入有防雷设施的建筑物或者汽车内；不要在树下、电杆下、塔吊下避雨；在空旷场地不要打伞，不要把农具等扛在肩上。再来看一下全国的天气情况↓↓↓华北东部和东北地区等地有较强降雨新疆高温天气持续摘要：今天白天，北京、河北、山东、重庆等地部分地区出现强降雨。预计未来三天，辽宁、吉林、黑龙江等地有暴雨灾害中风险，关注可能发生的山洪、地质灾害和城乡积涝及强对流危害；新疆大范围高温天气持续，关注对人体健康、能源供应、农业生产等的影响。一、天气实况1.北京河北山东重庆等地出现强降雨今天白天，北京中西部、河北南部、天津中南部、山东西部、河南东北部和东南部、安徽中部、浙江东部、重庆等地部分地区出现大到暴雨，北京、河北衡水和沧州、山东德州和聊城、重庆等局地大暴雨（100～191毫米）；上述部分地区最大小时降雨量40～100毫米。二、重点天气预报1.华北东部和东北地区等地有较强降雨22日至23日，江汉、苏皖及华北东部、黄淮东部、东北地区等地有中到大雨，其中湖北东部、河北东北部、辽宁大部、吉林西南部和内蒙古东北部等地部分地区有暴雨，局地大暴雨。预计，7月21日20时至22日20时，内蒙古东部、辽宁、吉林西部、河北东北部、天津东部、山东北部、湖北东部、贵州北部等地部分地区有大到暴雨，其中，辽宁中西部、河北东北部等地部分地区有大暴雨（100～220毫米）。上述部分地区伴有短时强降水（最大小时降雨量30～60毫米，局地可超过70毫米），局地有雷暴大风等强对流天气。中央气象台7月21日18时继续发布暴雨蓝色预警。图1 全国强降雨落区预报图（7月21日20时-22日20时）2. 新疆高温天气持续未来10天，新疆盆地地区、甘肃西部、内蒙古西部高温天气持续，最高气温一般有35～38℃，局地可达40℃以上。三、未来三天具体预报7月21日20时至22日20时，内蒙古东部、辽宁、吉林西部、河北东北部、天津东部、山东北部、湖北东部、贵州北部等地部分地区有大到暴雨，其中，辽宁中西部、河北东北部等地部分地区有大暴雨（100～220毫米）。辽东半岛、山东半岛等地部分地区有4～6级风（见图2）。图2 全国降水量预报图（7月21日20时-22日20时）7月22日20时至23日20时，内蒙古东部、黑龙江中西部、吉林大部、辽宁北部、浙江大部、江西北部等地部分地区有中到大雨，其中，黑龙江西南部、吉林西部等地局地有暴雨（50～80毫米）。新疆南疆盆地、内蒙古东部、东北地区北部等地部分地区有4～6级风（见图3）。图3 全国降水量预报图（7月22日20时-23日20时）7月23日20时至24日20时，黑龙江大部、吉林东部、辽宁东部、内蒙古东部、河北西部、西北地区东南部、青海南部、西藏、江汉南部、江南北部和东部、江淮东部、西南地区等地部分地区有小到中雨，局地有大雨（25～40毫米）。新疆南疆盆地有4～6级风（见图4）。图4 全国降水量预报图（7月23日20时-24日20时）综合来源：山西省气象台 中央气象台图文制作：山西广电融媒体catalogs:115814;contentid:11621652;publishdate:2023-07-21;author:王焕君;file:1689936823183-38dbfc84-f7a7-42a0-a80a-beb52489b6a0;source:29;from:山西广播电视台;timestamp:2023-07-2118:53:41;[责任编辑: ]
