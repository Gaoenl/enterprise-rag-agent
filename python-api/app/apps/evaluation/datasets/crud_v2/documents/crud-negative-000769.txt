据美联社3月21日报道,本月初,美国弗吉尼亚州一非裔男子遭多名警察跪压后死亡,21日公开的监控录像显示,男子遭虐待长达20分钟。这名男子的家人已对涉事警察提起二级谋杀罪指控。男子在地上挣扎,多名警察将其压住(美国国家广播公司视频截图)这名非裔男子是一位患有精神疾病的在押犯人。在办理入住精神病院手续过程中,7名警察和3名医院工作人员将其强行带到一个房间内。监控录像显示,男子一开始被按在椅子上,然后跌落下来,身体在地板上扭动。随后,越来越多的警察和医院工作人员束缚住他,使他全身“从辫子到脚趾”都遭到重压。这名男子一开始有所挣扎,但被虐待大约20分钟后不再动弹。男子最终一动不动(美国国家广播公司视频截图)最终尸检结果尚未公布,但负责此案的检察官反复表示,受害者的死因确为窒息。他表示:“显然,他原本不该被勒窒息身亡,但这真的发生了。”受害者家人发出强烈抗议(美国国家广播公司视频截图)这名非裔男子的家人称,他在医院期间和几天前的执法拘留中都受到了残酷虐待。男子的母亲控诉:“我的儿子被当作狗对待,甚至连狗都不如。”(原标题:现场曝光!“长达20分钟”)来源:海外网流程编辑:TF016如遇作品内容、版权等问题,请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话:010-85202353下载“北京日报”客户端 阅读体验更佳哦扫描二维码下载手机客户端扫描二维码下载手机客户端
