2023-07-26 22:18，正文：原标题：七旬老人欲转账投资，民警及时劝阻止损极目新闻记者 吴昌华通讯员 孙逊 李鑫得7月25日15时许，武汉市公安局武昌区分局梅苑警务站接某银行工作人员报警，称七旬的李婆婆疑似遭遇电信诈骗，正欲汇款，需要民警帮忙核实。民警熊健忠、辅警胡波接警后，在赶往现场的同时电话联系银行工作人员，让其先稳住婆婆。到达现场后，看到李婆婆正坐在大厅通过微信与人聊天，熊健忠赶紧上前询问相关情况。经与李婆婆沟通后得知：24日，李婆婆在某网站看到一个投资信息后，添加其客服微信，随后客服人员将李婆婆拉入微信群，李婆婆按照对方指导下载了某款APP，尝试投入了250元后获利50元，看到投资这么快就获利，李婆婆便对此深信不疑。25日上午，李婆婆按照对方指导，来到某银行转账4000元，回家后李婆婆联系客服人员问能否退还，客服人员却称可以退还，但需要再转16000元用来做保证金。当日下午，李婆婆再次来到某银行准备转账，幸好细心的银行工作人员发现其中端倪。“对方是骗子，这钱不能转！”熊健忠结合真实案例，耐心向李婆婆讲解了冒充客服工作人员诈骗的常见手法，同时向李婆婆普及了相关反诈知识。期间，李婆婆还不愿完全相信眼前的民警，拿起手机将投资理财群给民警看。“这些都是骗子，你难道不相信警察吗？”经过耐心劝说，李婆婆这才恍然大悟，随后在民警的指导下，将自称某平台客服的微信拉黑删除，退出相关投资理财群，并卸载了某款投资理财APP。民警及时赶到银行阻止老人转账（通讯员供图）“真的太感谢了，如果不是你们我这1.6万元就保不住了”，李婆婆不断对民警表示感谢。警方提醒：在投资理财的过程中，要选择正规、有资质的平台，千万不要随意给他人转账，以免上当受骗。子女要多关心老人日常生活，多讲些防诈知识，提高老人的防诈意识。（来源：极目新闻）返回搜狐，查看更多责任编辑：
