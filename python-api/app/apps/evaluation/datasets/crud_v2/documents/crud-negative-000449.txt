"发生轮胎故障的德国政府专机“康拉德·阿登纳”号(图源:《法兰克福汇报》)海外网4月2日消息,最近,一向“守时”的德国人又迟到了。德国外长马斯(Heiko Maas)因飞机故障,错过了于1日举行的联合国安理会非正式会议的启动仪式。巧合的是,此次发生故障的政府专机正是几个月前导致默克尔缺席G20峰会首日的“康拉德·阿登纳”(Konrad Adenauer)号,而这也是该专机完成故障修理后的“复出首秀”。据德国《法兰克福汇报》报道,纽约当地时间4月1日,德国外长马斯在乘坐空客A340型号政府专机“康纳德·阿登纳”号飞行9小时后到达纽约当地机场,但由于飞机轮胎发生故障而无法独立停靠在指定位置,需要借助其他手段拖动停机,导致马斯在机上等待1个多小时,错过了联合国安理会非正式会议启动仪式。《世界周刊》援引法新社描述称,飞机是在着陆时发生轮胎爆裂,因而不得不停下来等待拖车将飞机拖动到停机坪。2018年G20峰会前夕,默克尔搭乘的专机因通信系统故障紧急折回后迫降科隆-波恩机场(图源:《联合早报》)据了解, 此次飞行是“康拉德·阿登纳”号专机完成故障修理后的首飞。2018年11月29日,在德国总理默克尔前往阿根廷首都布宜诺斯艾利斯参加G20峰会途中,所搭乘的“康拉德·阿登纳”号政府专机因通信系统故障紧急迫降,默克尔只能改乘民航飞机出行而错过了G20峰会开幕首日的相关活动。德国《商报》评论该事件称“这是一次毁灭性的形象损害”,但更多媒体则质疑专机是不是太老、该换了。德国《图片报》此前报道显示,自默克尔上任后,远程专机就发生了大大小小10起事故。此前德国总统施泰因迈尔乘坐“康拉德·阿登纳”号赴南非访问途中,曾发生引擎遭雷击失灵事故。德国副总理兼财政部长肖尔茨在赴印尼参加国际货币基金组织会议时,因专机电缆被老鼠咬坏,不得不搭乘其他飞机回国。政府专机“特奥多尔·豪斯”号(图源:德新社)资料显示,“康拉德·阿登纳”号隶属于德国联邦政府飞行执勤队。该机队还有一架远程专机“特奥多尔·豪斯”(Theodor Heuss)号,两架专机均为空客340-300型,分别以联邦德国首任总理阿登纳和首任总统豪斯命名。“康拉德·阿登纳”号与“特奥多尔·豪斯”号此前曾作为客机为汉莎航空(Lufthansa)分别服务9年和10年,2009年由德国空军购下,编入联邦政府飞行执勤队。默克尔乘坐较多的“康拉德·阿登纳”号可以搭乘143名乘客,内部设有一间卧室、以及办公室和会议室等。专机还装有导弹防御系统和防窃听设备。不过,与美国的“空军一号”和俄罗斯总统普京的4架专机相比,德国政府专机还是显得有些“寒酸”。德国媒体认为,德国政府在专机的购买和维护上就不该省钱,这也是“德国制造”的质量体现。故障频发也引起了德国政府的注意。据《明镜周刊》报道,今年3月起,德国部长一级出差一般要乘坐商业航班,政府专机将只在小范围内使用。可以使用专机的人员包括联邦总统、联邦总理、副总理、外交部长和内政部长。报道还称,总统施泰因迈尔和总理默克尔出行时还会配备备用飞机,以便在故障发生时可以随时救急。原标题:坑完总理坑外长?德政府专机"复出首秀"又出故障【免责声明】上游新闻客户端未标有“来源:上游新闻-重庆晨报”或“上游新闻LOGO、水印的文字、图片、音频视频等稿件均为转载稿。如转载稿涉及版权等问题,请与上游新闻联系。",
