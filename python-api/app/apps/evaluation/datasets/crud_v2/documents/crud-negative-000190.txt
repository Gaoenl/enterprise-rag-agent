据《环球时报》16日报道,土耳其外交事务委员会推迟了对瑞典加入北约的审议投票,具体时间另行确定。经过“漫长而热烈的辩论”后,土耳其给出的官方解释是,这个问题“还不成熟”,无法做出决定,土方还需要从瑞典了解更多关于其向土耳其所作承诺的执行情况等信息。土耳其外交事务委员会主席奥克塔伊表示,将举行进一步会谈,并可能在下周将审议投票重新提上议程,但他没有给出明确时间。从提交加入北约的申请至今,瑞典已等待了18个月。2022年5月,瑞典和芬兰同时申请加入北约,同年7月北约30个成员国的代表签署瑞典和芬兰加入条约的议定书。目前,芬兰已于今年4月4日正式获准加入北约,成为第31个成员国。但瑞典的入约议定书尚未获得土耳其和匈牙利的正式批准。按照规程,新成员的加入需要北约所有成员国的一致同意。此前由匈牙利总理欧尔班领导的青民盟批评瑞典对匈牙利的民主状况“公然撒谎”,因此一直拖延批准该国加入北约的申请。但据知情人士透露,匈牙利政府表示自己“不会是批准瑞典申请的最后一个国家”,并对瑞典入约充满信心。有分析认为,相比匈牙利,土耳其或将成为瑞典加入北约的主要障碍。虽然土耳其总统埃尔多安在今年7月的北约峰会期间曾表示不再反对瑞典加入,但土方仍有几方面的顾虑。首先,土耳其一直指责瑞典对被土耳其视为恐怖组织的库尔德工人党过于宽容。土方对库尔德工人党支持者在瑞典进行的一系列示威感到愤怒,并要求瑞典采取更多措施控制该党在当地的成员。为顺利加入北约,瑞典承诺深化同土耳其在反恐问题上的合作并支持土耳其再度申请成为欧盟成员。此外,斯德哥尔摩还推出了一项新的反恐法案,同时取消了对土耳其的武器出口限制。尽管如此,埃尔多安一方面承诺他将努力推动瑞典的入约进程,一方面又称瑞典没有对库尔德工人党采取足够的行动。“我重视北约扩员,但我们必须消除心中存在的一些争议,当前的瑞典已经成为一些恐怖组织的避风港和天堂,”土耳其执政党正义与发展党议员阿里·萨欣说,“瑞典迄今采取了一些有价值的措施,但还不够。”另外,有分析表明,土耳其的决定可能与其希望从美国购买F-16战斗机相关。埃尔多安曾在9月将批准瑞典入约当作“筹码”,表示土耳其是否批准瑞典入约取决于美国是否按承诺向土方出售F-16战机。虽然美国坚称,此类协议不会与瑞典会否成为北约成员国挂钩,但已有美国国会议员表示,在土耳其批准瑞典加入北约之前,他们不太可能批准对土耳其的F-16军售合同。虽然瑞典入约进程受阻,但有分析人士认为,土耳其议会可能会在11月末举行的北约外长会议前走完批准瑞典入约的全部流程。(编辑邮箱:ylq@jfdaily.com)栏目主编:杨立群文字编辑:杨立群本文作者:徐晓语题图来源:视觉中国图片编辑:苏唯
