大众网青岛1月12日讯为响应中央精准扶贫号召,为贫困儿童提供优质的保险保障,中国儿童少年基金会、上海浦东发展银行、上海保险交易所,三方共同发起“无忧计划-儿童保险礼物公益项目”。该项目通过为贫困儿童、留守儿童等需要帮助的社会群体设计专属保险产品,采用资金透明运作模式,实施公开透明的保险招标采购,形成一套针对儿童的公益新模式,实现精准扶贫、长效扶贫、从根上扶贫。据介绍,儿童保险礼物公益项目积极响应了我国关于精准扶贫、精准脱贫、创新扶贫工作机制和模式的号召,为贫困儿童提供优质的保险保障。浦发银行是“无忧计划”第一家捐赠机构,项目首批将为云南省文山州文山市、昭通市镇雄县、大理州剑川县、昭通市巧家县、保山市总计99641名建档立卡的贫困儿童(0-14周岁)提供重大疾病和住院医疗费用报销的保险保障。同时开通腾讯乐捐平台接受公众捐款。每份保险礼物仅需19元,即可为1名贫困家庭0-14周岁的儿童送上一份给付型重大疾病和报销型住院医疗费用保险保障,让持有保单的儿童在不幸遭遇重大疾病时最高可获人民币50000元的赔付;如住院医疗费用报销包括意外伤害住院和疾病住院,赔偿可达15000元(含既往症),对扣除新农合、大病保险等社会保险后,被保险人现金支付的部分按100%赔付,无免赔。在该项目中,捐赠方以及公益慈善组织利用上海保险交易所招投标平台的公开、透明、便捷、全程可控的优势,可使帮扶对象获得保障程度高、服务质量好、成本相对较低的保险产品,从而有效撬动保险放大保障的功能,促进扶贫的规范化、精准性和制度化。自2008年1月,浦发银行在中国银行业率先开展全行志愿者日活动并建立志愿服务长效化机制,该活动至今已连续成功举办10年。每年1月9日行庆日前后,浦发银行都会在全国范围内统一策划、组织全行志愿者日活动,开展各类公益志愿服务,至今已累计约8万人次参与其中,受到社会各界的广泛关注与认可。今年,浦发银行志愿者日活动采取网络和现场相结合的方式,通过腾讯乐捐平台,为“无忧计划――儿童保险礼物”公益项目开展募捐。浦发银行将借助此次志愿者日活动,在全行近5万名员工中发出倡议,向“无忧计划――儿童保险礼物”公益项目开展网络募捐,并争取带动更多的客户和利益相关方参与项目捐赠。同时,浦发银行承诺将根据志愿者的募捐总金额进行等额配捐。浦发银行青岛分行积极响应总行号召,1月5日至9日,在青岛、烟台、威海三地同步开展公益募捐活动,一方面在网点现场发起募捐活动,呼吁员工和客户为贫困地区儿童捐款,一方面该行志愿者走上街头、走进社区、影院,积极向三地市民介绍公益募捐活动。该行志愿者日活动受到市民的广泛关注,纷纷加入爱心队伍,为贫困地区儿童捐款购买“保险礼物”。
