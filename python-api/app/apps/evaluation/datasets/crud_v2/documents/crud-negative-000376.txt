2023-08-02 18:22，正文：原标题：外媒：李显龙首次就执政党丑闻向国会讲话，称人民行动党“受到打击”【环球网报道 实习记者 王馨仪】路透社8月2日报道，新加坡总理李显龙当天首次就近来执政党内部一系列丑闻向国会发表讲话，称人民行动党因此“受到打击”，但他们将做正确的事情，以重拾民众信任。报道称，李显龙在讲话中表示，涉嫌贪污并正在接受调查的新加坡交通部部长易华仁目前已被停职，同时每月减薪8500新币直至另行通知。李显龙表示，这种涉及到部长级别的贪污事件在新加坡很罕见，执政的人民行动党将对腐败“零容忍”。“......人民行动党受到了打击，但我们将向新加坡人表明，我们将坚持原则并做正确的事情，以维持信任，”他说。另据新加坡《联合早报》8月2日报道，李显龙当天在用中文发言时还表示，“人民行动党一直以来致力于维持清廉政治。一个廉洁的政府、良好的治理体系对我们的民主制度至关重要，因此我们制定严厉的法律制度，以遏制违规行为。在价值观或是个人操守方面，部长和议员的个人行为也必须符合社会规范。”新加坡政坛最近连爆丑闻，涉及来自执政党人民行动党的国会议长、交通部部长，还有来自反对党工人党的重量级人物。7月14日，新加坡贪污调查局（CPIB）证实，交通部部长易华仁和地产大亨王明星近日被逮捕，随后保释在外，协助该局调查。同月17日，同属新加坡执政党人民行动党的国会议长陈川仁和女议员钟丽慧同时请辞并退党。据新加坡《今日报》等媒体报道，两人的婚外情被曝光后，陈川仁向所在党及选区民众致歉。7月26日，新加坡副总理兼财政部部长黄循财在接受英国广播公司（BBC）采访时表示，这些政治丑闻对执政党来说是一次“挫折”，新加坡政府将“加倍努力重新赢得公众信任”。他还表示：“我相信新加坡人信任贪污调查局的工作。数十年来的政绩反映了我国廉洁的体制，我们对贪腐持着零容忍态度。”返回搜狐，查看更多责任编辑：
