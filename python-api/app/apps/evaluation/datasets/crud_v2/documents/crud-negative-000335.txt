2023-08-14 16:23，正文：原标题：泰州姜堰：警企携手 向投资理财诈骗说“不”为进一步提高辖区企业员工的反诈意识，预防和打击电信网络诈骗，构建反诈防火墙，8月11日下午，泰州市公安局姜堰分局三水派出所组织反诈宣讲团队走进江苏太平洋精密锻造有限公司，开展反投资理财诈骗宣讲活动，提醒企业员工保持警惕、防范网络诈骗套路。民警现场宣讲投资理财诈骗套路（缪海舟 摄）活动中，宣讲民警用通俗易懂的语言，结合生动的案例和真实的数据，向企业职工详细介绍了投资理财诈骗的常见手段和特点，如虚假高回报投资、网络借贷等，揭露了一些看似诱人实则是诈骗的投资陷阱，深入剖析了投资理财诈骗的运作方式和欺诈手法，并通过情景模拟带领企业职工分析受害人心理，了解诈骗分子话术，传授预防技巧。民警接受企业职工的反诈咨询（缪海舟 摄）活动现场，民警还邀请企业职工分享对于防范电信网络诈骗的认知和收获。职工们反响热烈，纷纷表达自己的看法，与民警一起探讨如何更好地防范电信网络诈骗。民警也对企业职工进行了相关法律法规的补充宣传和教育，为积极参与的现场人员送出了反诈大礼包，并鼓励大家积极向公安机关举报诈骗行为，共同维护社会安全和稳定。民警向企业财会人员开展一对一反诈宣讲（缪海舟 摄）最后，针对企业财会人员这一特殊群体，民警专门走进财务室，开展一对一宣讲。提醒财会人员要时刻保持警惕，对于任何转账请求都要认真核实，尤其是在转账前一定要多方核实领导身份，切勿轻信对方，更不能泄露个人信息。一旦发现可能被骗，及时拨打110报警。此次反投资理财诈骗宣讲活动取得了显著效果，不仅提高了企业员工的反诈意识，还增强了他们对电信网络诈骗的防范能力。员工们纷纷表示将提高警惕，自觉培养反诈意识，在工作和生活中谨慎识别诈骗行为，同时提醒身边的亲友同事避免上当受骗。（张玉成 缪海舟）返回搜狐，查看更多责任编辑：
