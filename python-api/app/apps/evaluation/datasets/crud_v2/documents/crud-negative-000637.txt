2023-08-13，正文：8月11日，有媒体报道河北邢台市平乡县与广宗县交界处附近，突然出现大面积黄色烟雾，此事引发社会关注。8月11日晚，平乡县应急管理局就此发布一则情况通报。通报全文如下：针对网上反映我县东庙村上空出现黄色烟雾的情况，经调查：8月11日11时31分，该村迈浪儿童用品有限公司一库房内酸性物质泄漏向外散发大量黄色烟雾。经消防、应急、环保等部门紧急处置，13时10分左右不再向外散发烟雾，13时40分左右基本处置完毕，没有人员被困，没有人员伤亡。据业主估算，造成经济损失约15000元。事件现场处置完毕后，环保部门对事发地及周边环境持续监测，没有发现空气质量异常。事件相关情况正在进一步调查处理。感谢广大网民对平乡的关注。平乡县应急管理局2023年8月11日此前报道：8月11日，据百姓关注报道，当日11时许，河北邢台平乡县河古庙镇天空中出现黄烟。画面显示，烟雾从低处腾升后，逐渐弥漫整个天空。行人和车辆在烟雾中穿行。附近商户表示，曾听到消防车和救护车经过。当天下午，周边有居民告诉极目新闻记者，黄色烟雾持续的时间约10分钟左右，味道有些刺鼻。图源：视频截图17时许，平乡县应急管理局回复称，黄烟系一企业化学品存放不当发生泄漏，与外界物质产生反应后导致。“事发后消防、环保等部门到场处置，防止气体挥发出来对居民造成伤害。目前没有人受伤，也没有人员死亡。”来源：九派新闻综合(责任编辑：路子康 CN078)
