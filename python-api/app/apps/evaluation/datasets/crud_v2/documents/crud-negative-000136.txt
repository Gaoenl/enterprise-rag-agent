来源：海外网7月28日，第31届世界大学生夏季运动会开幕式在成都东安湖体育公园主体育场举行。这是中国大学生体育代表团在开幕式上入场。（图源：新华社）满场“蓉宝”欢乐起舞、运动员踩着七彩蜀绣入场、“太阳神鸟”穿越时空翩飞而至……7月28日，成都第31届世界大学生夏季运动会向世界奉献了一场“阳光灿烂”的开幕式。“每一秒都不浪费，每一分钟都精彩”，这场盛会让世界领略“巴蜀明珠”的夺目光彩，也展现出全世界青年健儿在成都成就梦想的青春力量。大运会是属于大学生的盛会，青年是开幕式上绝对的主角。在全场的“雄起”声中，中国大学生体育代表团的入场格外引人注目。中国代表团在本届大运会实现“满项报名”的目标，来自25个省(自治区、直辖市)百余所高校的411名运动员将参加全部18个大项的角逐，平均年龄为22.9岁，青春力量从四面八方汇聚成都。在大运会的舞台上，中国队创造了一个又一个高光时刻。这项素有“小奥运”之称的赛事自1959年诞生起，中国就与它结下不解之缘。在意大利都灵举办的首届大运会上，中国就派代表团参加了部分田径项目比赛。从1977年第9届起，中国派团参加了迄今为止的历届大运会。在深圳大运会上，中国队勇夺75枚金牌、145枚奖牌达到新高度。此后，从俄罗斯喀山，到韩国光州，再到意大利那不勒斯，中国代表团金牌和奖牌数稳居三甲。郎平、李宁、姚明、刘翔、李娜、苏炳添、郭晶晶……许多耀眼的中国体坛明星都曾在这个赛场成就辉煌。在成都大运会赛场上，相信更多中国青年运动员的梦想将振翅高飞。这场盛会让世界感受到成都这座“来了就不想走的城市”的独特魅力，也让“雪山下的公园城市、烟火里的幸福成都”更有活力、更有内涵。2022年底，成都已有体育场地设施6.41万个，建成5000多公里天府绿道，植入体育设施1700多处，全年举办了全民健身活动6000余场次。篮球、网球、滑板、骑行、飞盘、街舞……随着健身场地不断增多，健身热潮在成都的街头巷尾涌动。这是落实全民健身国家战略、推进健康中国建设的生动写照，同时传递出全民参与大运会、支持大运会、助力大运会的精神与力量，向世界展示充满青春活力的中国城市形象。这场精彩的开幕式让世界有理由相信，成都大运会定将成为一届具有中国特色、时代气息、青春风采的国际体育盛会，为大运会树立“新标杆”。成都大运会博物馆日前隆重开馆，成为世界大运历史上首家在大运会开幕前向公众开放的大运主题博物馆，大运体育精神在此熠熠生辉。国际大体联官员曾专程赴博物馆参观，并称赞其为“杰出的大运遗产”，奠定了成都大运会在世界大运历史上的重要地位。大运会志愿者、科创人员……蓬勃的青春力量在赛场外涌动，为出彩成都大运会保驾护航。“黑科技”满满的大运场馆也将在赛后打开“惠民之门”，成为宝贵的大运遗产。阿根廷大学生体育联合会主席埃米利亚诺·奥赫亚说，中国是世界上办赛水平最高的国家之一，拥有高品质的体育场馆等基础设施以及热情专业的赛事志愿者。成都大运会将为世界带来新的惊喜。从倒计时的“礼赞阳光”到尾声“阳光下的欢聚”，贯穿整个开幕式的“阳光”这一核心元素，映照着每一位大运人的灿烂笑脸。正如成都大运会开幕式官方主题曲《成就梦想》所唱：“向着光的方向，每个心愿都可以生长，每个微笑都可以分享，向着太阳飞翔。”（栾雨石）海外网版权作品，未经授权不得转载。举报/反馈
