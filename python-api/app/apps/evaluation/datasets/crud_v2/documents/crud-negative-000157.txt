2023年07月28日 15:29:00 来自北京市，正文：【环球网报道】据台湾“中央社”28日报道，美国国会参议院当地时间27日晚通过2024财政年国防授权法案，呼吁美国和台湾进行军事合作，为台湾军队制定全面的培训、咨询与机构能力建设计划，并进行军事网络安全合作。对此，有岛内网友表示，美国整天想骗钱，想引起其他地区战争，满口仁义道德，私下尽干坏事。据“中央社”报道，美国参议院27日晚以86票赞成、11票反对，通过2024财政年国防授权法案，给国防部提供总额达8860亿美元预算。报道称，美参议院军事委员会随后发声明称，上述法案包括授权“太平洋威慑倡议”与“欧洲威慑倡议”的全部预算编列、建立印太作战倡议，同时为台湾军队制定全面的培训、咨询与机构性能力建设计划。此外，法案呼吁美台进行军事网络安全合作，还要求美国国防部长、美军参谋长联席会议主席与国家情报总监，递交一份全面分析中国大陆对台湾“持续军事封锁的风险与影响”报告。台湾“中央社”称，美国众议院于15日通过众院版国防授权法案，由于参众两院版本不同，需通过协商取得最后版本，再交由两院重新各自表决通过，才会递交美国总统签署生效。对于美国参议院通过的国防授权法案，有岛内网友表示，都还是以美国的利益最大化为考量，目前台湾就是个任人使唤冲锋的“棋子”，等美国目的达到了，台湾就是可抛弃的弃子。↓
