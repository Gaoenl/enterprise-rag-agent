【相约2019北京世园会】一抬头,徽州石雕牌坊上的“徽风皖韵”字样,俨然是徽文化最醒目的标签,牌坊前花鼓灯《夫妻观灯》表演俏皮活泼。戏台上,黄梅戏折子戏《女驸马》和徽剧唱段《贵妃醉酒》等经典剧目轮番登场,引来无数喝彩......根据北京世园会组委会安排,6月9日至11日为世园会“安徽日”。安徽主题日期间,不仅将上演徽剧、黄梅戏、花鼓灯等精彩戏剧演出,还有明德折扇制作技艺等安徽非遗精品展演。“安徽馆的设计和建设充分体现了世园会的宗旨,‘让园艺融入自然,让自然感动心灵。’”安徽省副省长周喜安介绍,安徽馆的设计和建设呈现三个鲜明特点,“第一,我们整个的布展都是按照天人合一、物我共生的这个理念来进行布置的,充分体现了自然的流畅和自然的展现。第二,突出了安徽独有的徽派建筑。这不仅是安徽的特色,在全世界也是具有标志性的建筑和园艺。第三,体现了跟群众生活的有机融合。安徽馆就是一个平民院落,这是老百姓生活的真实体现。所以,安徽馆呈现的就是我们生活的一部分,而不仅仅是一个建筑的摆设,在安徽版图上,这些都是活态呈现。”戏曲和非遗各展风采徽剧、黄梅戏是备受全国人民喜爱的地方剧种。世园会“安徽日”期间,共有六场“徽黄佳话”和“花鼓天下”文艺演出,表演具有代表性的徽剧、黄梅戏及花鼓灯。其中,“花鼓天下”在安徽园正门口演出,共有包括经典剧目《千里长淮一条线》在内的14个节目,“徽黄佳话”在世园会妫汭剧场内演出,共表演15个节目,包括徽剧唱段《贵妃醉酒》和黄梅戏小戏折子戏《女驸马》等经典剧目。在世园会安徽园正门口,记者看到,徽匠神韵——安徽非物质文化遗产精品展正在举行,现场模拟千年古井贡酒酿造工艺,省级非遗项目痘姆陶器现场轮制拉坯等吸引了众多游客的眼球。非遗展示之外,园内的书法展示,也呈现了中国的文房四宝——宣笔、徽墨、宣纸、歙砚,古韵典雅。安徽省文旅厅副厅长周明洁介绍,非遗展示“安徽日”重点展出的项目,共有精选出的7项省级以上非遗代表性项目进行活态展演和精品展示,现场辅以互动、体验等环节,普及非遗保护知识,宣传安徽优秀传统文化。“各显神通”推介安徽旅游穿过高耸的“徽风皖韵”牌坊,就进入了北京世园会安徽园。青山绿水环绕村落,粉墙黛瓦点缀其间,安徽园以徽派建筑艺术和徽派园林风格,呈现出物我共生、天人合一的至臻格局。“我们特意在青山绿水和亭台楼阁间安装了雾化设备,只要打开,标志鲜明的徽派古民居立刻云雾缭绕,仿佛仙境一般。”安徽园设计师王引说,3000平方米的展园分为水口园林区、村落文化及生活园艺展示区、田野园艺区三部分,不论是白墙黛瓦的徽派建筑,还是到处可见的精美雕刻,都传递着徽州特有的诗意与浪漫。斯里兰卡驻华大使卡鲁纳塞纳·科迪图瓦库对安徽园赞不绝口:“在这里可以看到安徽人古老的生活方式,也能感受到安徽对传统文化保护所作的努力,有一种返璞归真的感觉。”开幕式后,安徽旅游推介也在世园会园区同行广场多功能厅举行。省文化和旅游厅在此推介安徽旅游,亳州、六安、滁州、黄山、池州、宣城、安庆等7个市也将进行旅游推介。绿水青山带笑颜走进安徽园,田野园艺区带给游人闲云野趣,云雾茶园、药园、果园、文房四宝、奇草异卉园、竹林六个景观小品分列两旁,一个原汁原味的古村落呈现眼前。安徽园入口处的牌坊,原料是一块上千吨的整石,由二十多位非遗传承人手工雕刻而成。展园入口处,是徽派的水口园林,水口园林是徽州古村落的特有形式,因古民居常在水流出村口处,因此人们便在此修建园林。这里有拱桥、休息亭、跌水、大树、条石驳岸,为夏日带来一抹清凉。近年来,安徽省大力实施乡村振兴战略,在保护古村落之外,通过森林抚育、人工造林等绿色提升行动,提高了森林覆盖率;同时深入实施新安江和太平湖流域综合治理项目,保护水环境,让徽州古村落、古民居与大自然紧密相融,形成了“绿树村边合,青山郭外斜”的意境。目前,安徽正在推深做实河(湖)长制、林长制和新安江生态补偿机制,擦亮自然生态“底色”,提升高质量发展“成色”,努力打造生态文明建设安徽样板,为美丽中国作出贡献。(本报记者 常河)
