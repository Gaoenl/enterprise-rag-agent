最新的《财富》世界500强排行榜于8月2日发布。中国共有142家公司上榜（包括港澳台），大公司数量继续位居各国之首。粤港澳大湾区共有25家企业榜上有名，相比去年增加了1家。其中深圳10家、广州6家、香港6家、佛山2家、东莞1家，涵盖金融、科技、汽车、医药、家电、房地产等行业。在中国7家新上榜和重新上榜公司中，就有3席来自大湾区，包括广州工业投资控股集团有限公司、广东省广新控股集团有限公司和立讯精密工业股份有限公司。世界500强首次出现了东莞身影以及广东省省属国企。粤港澳大湾区共有25家企业榜上有名制图：界面大湾区分区域来看，各地上榜的企业有着鲜明特征：深圳以高科技闻名，榜单中的5家高技术中国企业，就有3家出自深圳——华为、腾讯以及中国电子信息。新上榜的“果链一哥”立讯精密是5家高技术企业之一，也和深圳紧密关联。被称为“小富士康”的立讯精密经历了从代工到自主研发的进阶历程。从2010年上市以来，公司市值一度创下4405亿元的最高纪录。在苹果产业链之外，立讯精密也切入了汽车电子、通信业务，正在尝试减轻“苹果依赖症”。此次榜单中，立讯精密成为中国公司中的ROE十强。广州主打国有企业，不管是老选手广汽集团、广州建筑、广药集团，亦或是新上榜的广州工投和广新集团，都是国有企业。广新集团成为《财富》500强中广东省首家上榜的省属国企。2021年，广新集团成功并购生物发酵细分行业排名全球前三的伊品生物，实现业务重组上市。广州工控则是最年轻的企业，由广钢集团、万宝集团、万力集团于2019年联合重组形成，以营业收入365.885亿美元的成绩首次上榜。广州工控目前控股5家上市公司，拥有万宝、五羊、万力、广日等多个品牌。广州市属国企中入选世界500强的数量也从3家增至4家。除了新晋选手，最出风头的莫过于比亚迪。连续第二年上榜的比亚迪，今年是排名上升幅度第二大的公司，上升224位排212名。上半年，比亚迪出口8.1万辆，同比增长10.6倍。同样专注汽车业务的广汽集团也实现了21位的上升，排名165名。可以说，新能源汽车已成为大湾区高质量制造业的代表作。值得留意的是，2023年《财富》世界500强净利润门槛出现负增长，不少企业也未能躲过排名下滑。榜单显示，尽管上榜企业营业收入总和约为41万亿美元，比上年上涨8.4%，但是净利润总和同比减少6.5%，约为2.9万亿美元。在135家中国大陆（包括香港）企业中，有89家位次下降。大湾区25家上榜企业中，亦有15家名次出现下滑。下滑幅度较大的包括碧桂园（下滑68位至206名）、长江和记实业（下滑60位至453名）、中国太平保险集团（下滑51位至385名）、正威国际（下滑48位至124名）。“宇宙第一房企”碧桂园是大湾区选手中唯一亏损的公司。继2022年亏损60.52亿之后，公司预计今年上半年可能录得净亏损。这将是碧桂园自2007年上市以来首份亏损的中报。而2022年也是碧桂园首次年报亏损。另一湾区房企万科的盈利也未达到平均水平。上榜中国大陆（包括香港）企业的平均利润约为273亿元，而万科2022年盈利为226.2亿元，可见房地产行业面临增长的困境。今年《财富》世界500强也将房地产公司纳入金融领域。即使是华为、腾讯等巨头，排名也有小幅下滑。华为今年的排名下降了15位，跌出前100名；营收和利润均有下滑，其中利润跌幅达70%。腾讯下滑了26位，其2022年营收和净利润分别有1%和16%的负增长。当然，这没有阻碍腾讯成为中国上榜企业的利润率前十和ROE前十。跟去年相比，今年大湾区有2家企业落榜。自2019年入选500强的格力电器首次落榜。2019年，格力在榜单中排名414位，但到2022年，排名已下滑至487位。受困于多元化战略进展不顺，以及对线下依赖度高，格力电器营收已连续3年徘徊在2000亿元以下，2022年增长仅0.26%，远低于外界预期。在去年12月发布的《2022胡润世界500强》中，格力电器同样没有进入名单。另一个落榜的公司是2022年排名288位的友邦保险。素有“最强代理人”之称的友邦保险，受疫情黑天鹅冲击以及投资市场震荡影响，2022年收益大幅下滑，营收和纯利分别下降59.79%和95.72%，其总投资收益率更是降为负数，为-6.6%。（文章来源：界面新闻）
