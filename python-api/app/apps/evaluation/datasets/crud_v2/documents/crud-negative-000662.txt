"人民网南京6月8日电 （马晓波）6月21日，南京创新周大幕再启。作为创新名城中心区，主城玄武紧扣“新发展格局下的城市创新”这一大主题，筹划了18场科技成果展示、学术交流探讨、创新项目合作活动，36个优质产业项目将签约落地。5月8日，南京城市硅巷现场会暨南师大玄武科技园开园仪式的举行，标志着玄武创新周系列活动正式开启。从“麒麟杯”东大校友双创大赛到“凤栖玄梧・才聚紫金”2021中国・玄武高层次人才创新创业大赛，从“遇见・千年”南京-佛罗伦萨文化周到第17届公众科学日活动，一个月内，玄武端上丰盛的“前菜”，为创新周做足“热身运动”。在南京创新周开幕当天，“苏南自主创新示范区首届高峰论坛”将在玄武区举办，该场论坛由苏南国家自主创新示范区理事会、江苏省科技厅指导，示范区内五座城市的科技工作者将以长三角区域一体化国家战略的视角，深入探讨前沿科技协同创新，产业发展融合共赢。届时，玄武区还将邀请多位产学研界嘉宾，聚焦生物医药主导产业，分享真知灼见，共商疫情防控常态化下的行业趋势和未来风口，为示范区内生物医药企业提供智力支持。产业是发展的动力源，也是创新的落脚点。创新周期间，玄武将有36个科技创新项目签约落地，其中，由玄武区政府、东大、南医大三方共建的南京医工交叉创新研究院，以高端医疗器械研发和智慧医疗服务为主导方向，孵化一批具备源头创新能力的研发头部企业，聚集一批行业龙头和产业链关键节点企业，打造一批专业科技服务类企业。依托德国H&A银行搭建的中欧科创中心，计划投资1.2亿元，为玄武产业升级输送来自欧洲的创新资源。围绕“十四五”规划明确的“1+2+2”产业体系，玄武贯彻落实“产业质效提升年”要求，千方百计招引投资体量大、带动能力强、市场前景好的优质项目，不断夯实产业基础，延展产业链条，优化产业生态。据了解，为营造“全民感知创新”的浓厚氛围，玄武还结合市级关于展览展示有关要求，有序推进黑科技、八大产业链、创新产品及应用场景等招展布展工作。届时，珠江路金鹰天地广场设置创新周网红打卡点，依托糖果车站海量人流，在城市中心打造全新体验场景。同时，创新周元素还将走进园区、社区，通过调动群众参与热情，打造一个永不落幕的“超级派对”。(责编：唐璐璐、吴纪攀)",
