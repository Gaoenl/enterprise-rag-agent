2023-08-14，正文：碧桂园杨氏家族辉煌传奇的发家史 31年完成新老交棒，杨惠研实控近600家企业近日，处于风波中的头部民营房企碧桂园控股有限公司（以下简称碧桂园）再因债务兑付受到市场关注。天眼查App显示，2007年4月于香港上市的碧桂园成立于2007年2月，目前，其主席、执行董事为碧桂园创始人杨国强女儿杨惠妍。8月10日，碧桂园发布公告，成立杨惠妍领导的专项小组统筹协调努力渡过难关。8月11日，重庆一券商投资顾问赵先生告诉上游新闻（报料邮箱baoliaosy@163.com）记者：“碧桂园是一家典型的家族企业，实控人为杨国强、杨惠妍父女，碧桂园目前的应对办法能否渡过难关还有待继续观察。”碧桂园，这个如今在中国乃至全球房地产业中享有盛名的品牌，背后蕴含着一段中南地产界的辉煌传奇。而这段传奇的缔造者，正是杨氏家族。杨国强，碧桂园的创始人，出生在一个农民家庭，生活贫困。然而，他凭借自己的努力和智慧，一步步从一名普通的泥瓦匠成长为一位杰出的房地产商人。31年的创业历程，杨国强以他的坚韧和远见，塑造了碧桂园这个中南地产界的巨头。杨国强的成功并非一蹴而就。他始终坚持创新，不断探索新的发展机遇。在房地产市场蓬勃发展的时期，他准确把握市场趋势，发挥自己的泥瓦匠技艺，将工程质量提升到新的水平。同时，他积极学习现代企业管理知识，不断提升自己的领导能力，为碧桂园的快速发展奠定了坚实的基础。随着碧桂园的不断发展，杨国强的家族影响力也逐渐扩大。家族成员在企业的各个岗位上发挥重要作用，共同推动碧桂园的成长。在这个过程中，家族成员间的合作与默契起到了至关重要的作用。他们共同秉承家族传统，致力于企业发展和家族荣誉的维护。
