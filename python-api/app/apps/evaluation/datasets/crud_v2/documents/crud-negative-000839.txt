2023-08-02 08:48，正文：                原标题：日本谋求重启“中日韩会议”                              参考消息网8月2日报道据日本《每日新闻》8月1日报道，日本、中国、韩国轮流主办的“日中韩领导人会议”大概率将于今年年内在韩国举行。由于日韩关系恶化，日中韩领导人会议自2019年12月以来中断至今，日韩两国关系的迅速改善为重启会议迎来契机。  日本外相林芳正在7月25日的记者会上强调：“日中韩三国领导人肩负着维护地区和平与繁荣的重大责任，齐聚一堂展开磋商具有极为重要的意义，希望三国在事务层级认真研究。”  报道说，眼下围绕福岛第一核电站处理水排海计划，中方表达了强烈不满。  按照惯例，日中韩机制的运作都是从事务级别会谈开始，之后是外长会谈，最后是领导人会议，因而事务级别磋商何时启动备受关注。  报道还说，日中韩领导人会议始于2008年。日本将这一安排视为深化同中韩合作的重要机制。  但是2018年文在寅担任韩国总统期间，韩最高法院判决日本企业需对前劳工进行赔偿，从那时起日韩关系跌入低谷。虽然2019年在中国该会议得以举行，但在2020年交接棒传到韩国之后，协调工作陷入僵局。返回搜狐，查看更多                        责任编辑：
