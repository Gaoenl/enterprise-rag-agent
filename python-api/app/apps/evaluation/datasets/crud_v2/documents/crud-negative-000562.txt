8-13 08:58，正文：                                                                                                                                                                                                                                                                         中新网8月13日电 据俄新社报道，当地时间12日，俄罗斯外交部就乌克兰企图对克里米亚大桥发动“恐怖袭击”进行谴责，称此举将无辜平民的生命置于危险之中，并誓言采取报复措施。  俄外交部发言人扎哈罗娃发表评论称，俄方“强烈谴责这些恐怖事件”。她表示，“这种野蛮行径毫无道理可言，势必将得到回应。”  据此前报道，俄罗斯国防部12日通报称，俄军当天两次发现并拦截试图袭击克里米亚大桥的乌军S-200导弹，事件未造成人员伤亡和财产损失。此外，俄国防部称，乌军当天试图出动20架无人机袭击克里米亚，其中14架被防空系统摧毁，6架被电子战系统压制。  【编辑:张乃月】                                                                                                                              更多精彩内容请进入国际频道
