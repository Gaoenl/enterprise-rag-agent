原标题：独脚戏《石库门的笑声》演到第5年，毛猛达的秘诀是什么？“本来只想做20场，没想到一做就是5年。”9月15日、16日独脚戏《石库门的笑声》迎来首演5周年，将重回首演地兰心大剧院。8月14日，演员毛猛达透露，《石库门的笑声》一直在升级更新，“现在版本70%是新的，只保留30%首演内容。”2018年9月首演至今，独脚戏《石库门的笑声》演出近140场，成为上海演艺大世界票房成绩最亮眼的驻演品牌之一。9月15日、16日兰心大戏院5周年纪念演出出票已到7成。《石库门的笑声》聚焦改革开放以来上海文化、上海制造、上海服务、上海购物变化与发展，在兰心大戏院首轮演出短暂试水后，2018年深扎当时刚修缮启用的中国大戏院进行驻场演出。2021年6月20日，《石库门的笑声》百场纪念演出亮相上海文化广场，三枪集团、老凤祥、老大昌、杏花楼、邵万生、大富贵、豫园股份等十余家历史悠久的申城老字号前来助阵。今年年初，《石库门的笑声》中国大戏院驻演，毛猛达、沈荣海走出剧场已近晚上10点半，遇到复旦大学哲学系学生拿着节目册求签名，“天气很冷，这位观众都快流鼻涕了。”年轻人对传统曲艺的喜爱让毛猛达和沈荣海惊喜。2024年，毛猛达、沈荣海将迎来合作40周年，“《石库门的笑声》百场纪念演出时，我们说这是舞台生涯的逗号，到5周年纪念演出、合作40周年，我们还将继续写‘逗号’，没有句号。”5年来，《石库门的笑声》不断打磨，扬弃老段子，加入新话题，既有表现石库门邻里关系的“借醋”等有趣桥段，也提醒观众沪语传承要从娃娃抓起。一百多位上海及长三角文化名家登台成为《石库门的笑声》嘉宾。毛猛达、沈荣海最难忘的是一位小嘉宾——2020年主办方邀请勇救老人的格致中学学生盛晓涵来看《石库门的笑声》，盛晓涵说，“小时候家里人爱看《老娘舅》，我也在旁边看。今天能现场看戏，特别开心。”2021年，《石库门的笑声》两次登陆东方卫视，分别围绕上海生活的“衣食住行”“吃喝玩乐”推出两期节日特别节目，收视率名列前茅。去年国庆，东方卫视创意海派实景喜剧《石库门的笑声》重阳特辑邀请表演艺术家郑毓芝参与，分享退休养老日常。在网络平台，《石库门的笑声》同样笑得响亮。毛猛达抖音粉丝已近67万，不断有来自加拿大、美国、英国、日本观众进入直播间，聆听上海故事。“不美颜，不用滤镜，不开大灯，只用日常光。”毛猛达笑言，自己“触网”主打质朴本色，“我做直播不预告不带货，只想和观众聊天，拿起手机就上，有网友还在评论区说要给我送话筒。连拍小视频也是一条过，内容为王。吃蟹小视频浏览量超过900万。”在这个讲上海话的直播间，平常有五六千观众，最高达到1.2万人。直播没有脚本，围绕上海人的衣食住行，“比如聊上海点心，我和网友回忆小时候吃牛肉煎包、冷面，全家四口人分两份冷面，味道真好，再说到百年老店的工匠精神。”台上一分钟，台下十年功，看似主题自由的直播背后，毛猛达时刻琢磨节奏、说上海话的语感“和舞台演出一样，要静下心，投入当下火热生活，把握最新时事、热点话题，比如淄博烧烤火了，不到一个星期，它就出现在我们的作品中。”他不喜欢走捷径赚取廉价笑声，“只有主业做好，说出的话才能掷地有声。问问观众你是哪里人、我是哪里人，把独脚戏搞得像演唱会，没有艺术含量。”7月《石库门的笑声》，毛猛达问起现场观众谁看过他的直播，不少人举起手。“我在直播间不表演，也不唱歌，坚持聊天主播定位，不是才艺主播，想看独脚戏，必须来剧场。”毛猛达笑言，因直播来看独脚戏的年轻观众越来越多，年轻观众反应快、笑声尖，而且他们常常下午就出门，在餐馆吃完饭再来看演出。”5年来，《石库门的笑声》带旺中国大戏院周边业态，原来的五金街，餐饮店渐渐多了，这一两年又出现网红下午茶店。每逢演出，毛猛达下午4点前吃完饭，5点到后台，他和沈荣海都强调要保持演员好奇心、敏感与演出逻辑性，“基本功扎实、有功夫的语言、和上海人心连心，让独脚戏有别于相声、脱口秀。”《石库门的笑声》从剧场讲到学校、养老院，“生于斯，长于斯的我们有着自己独特的语言和幽默，我们用一种传统与现代相结合的新喜剧模式，诙谐却又不失礼貌地表达对这座城市的热爱。”返回搜狐，查看更多责任编辑：
