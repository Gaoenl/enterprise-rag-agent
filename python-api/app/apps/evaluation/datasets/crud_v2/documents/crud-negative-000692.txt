2023-08-17 10:49，正文：原标题：湖北仙桃警方破获一起25年命案积案中新网湖北新闻8月16日电 (付水平) 湖北仙桃警方8月15日将命案犯罪嫌疑人李某义押解至仙桃市剅河镇一村湾，进行公开指认现场。1998年9月27日，村民李某某在家门口因琐事与犯罪嫌疑人李某义、金某群发生争执，被对方持刀刺中心脏致死。案发后，犯罪嫌疑人李某义、金某群潜逃至今。“我是2016年从刑侦前辈手中接过‘接力棒’，一直跟踪此案7年。”仙桃市公安局刑警支队民警梁少军说，为侦破命案积案，一方面快速立案侦查，完善证据，将两名犯罪嫌疑人上网追逃；一方面根据刑事技术的发展，千方百计搜集到两人90年代初的关键图像信息。今年8月，在全国公安机关夏季治安打击整治行动中，仙桃市公安局将此案犯罪嫌疑人的抓捕作为重点目标，依托打击整治一体化作战中心持续研判追踪，利用现代刑事技术科技手段进行追捕。同时，积极争取公安部、省公安厅刑侦专家的支持和跨省合作，组织专门力量开展破案攻坚。8月10日晚，在公安部指挥下，鄂晋警方协同作战，将潜逃25年的命案逃犯李某义、金某群在山西忻州一出租屋抓获归案。两人对1998年9月27日持刀刺死同村村民李某某的犯罪事实供认不讳。目前，该案正在进一步办理中。(完)返回搜狐，查看更多责任编辑：
