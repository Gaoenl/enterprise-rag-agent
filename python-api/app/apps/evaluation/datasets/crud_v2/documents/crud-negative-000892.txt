2023-07-28 15:03，正文：原标题：普京：朝鲜对特别军事行动的支持彰显抵制西方政策的决心【克里姆林宫新闻处表示，俄罗斯总统弗拉基米尔•普京在祝贺朝鲜祖国解放战争胜利70周年的贺电中表示，朝鲜对特别军事行动的支持以及在主要国际问题上与俄罗斯的团结一致彰显抵制西方政策的共同决心。】通稿中表示：“朝鲜对特别军事行动的坚定支持以及在主要国际问题上与俄罗斯的团结一致彰显了我们抵制集体西方阻碍确定真正的基于国际法优先、安全不可分割、尊重主权和各国国家利益的多极公正世界秩序的共同意愿和决心。”普京总统在贺信中指出，历史上曾并肩作战的这一经历并未失去其价值，这也是俄罗斯与朝鲜之间进一步发展政治、经济和安全关系的牢固基础。面对现代威胁和挑战，维护和弘扬睦邻友好、互帮互助的光荣传统尤为重要。普京总统表示，在1950年至1953年艰苦卓绝的解放战争时期，朝鲜人民军在最高司令金日成的领导下，克服万重考验，发扬英勇精神，捍卫了祖国的自由和独立。苏军飞行员驾机执行战斗任务数万架次，与朝鲜爱国志士并肩作战，为战胜敌人做出了重大贡献。俄罗斯领导人祝愿金正恩先生身体健康，并在造福朝鲜人民的责任重大的工作中取得更大成就。同时祝愿本次纪念大会与会者祥宁幸福。1953年7月27日，朝鲜停战协议正式签订，结束了历时三年的朝鲜半岛的战争。中国和苏联支持朝鲜，美国及其盟国支持韩国。根据停战协议，朝鲜和韩国确定了一个非军事区，但双方从未签署过和平条约。返回搜狐，查看更多责任编辑：
