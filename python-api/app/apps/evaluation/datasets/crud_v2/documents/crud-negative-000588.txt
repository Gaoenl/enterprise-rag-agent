，正文：苹果公司的生成式人工智能技术的发展明显滞后于其竞争对手，且没有迹象显示该公司计划在明年推出其AI服务，这是苹果分析师郭明錤最近的观点。他解释说，由于该领域的进展缓慢，苹果可能不会在财报电话会议上过多讨论人工智能相关问题。 据悉，目前没有迹象表明苹果计划在2024年推出或集成AI计算或硬件产品，这意味着AI在短期内不太可能对提振该公司的股价或供应链做出贡献。 上个月，有报道称苹果正在开发名为“Apple GPT”的人工智能项目，该项目可以与OpenAI的ChatGPT相媲美，但目前仍处于内部测试阶段。据称，苹果尚未制定为消费者打造AI产品的“明确战略”，尽管它可能会在2024年发布“重大”人工智能更新，但目前还没有看到具体计划。 在今年五月份的财报电话会议上，苹果CEO蒂姆·库克表示，人工智能有“许多问题需要解决”，并强调在开发过程中“深思熟虑”很重要。他还表示，苹果认为人工智能是“伟大的”，并计划“继续以深思熟虑的方式将其融入产品中”。本文属于原创文章，如若转载，请注明来源：苹果AI滞后竞争对手 没有计划推出AI服务https://news.zol.com.cn/827/8275093.html
