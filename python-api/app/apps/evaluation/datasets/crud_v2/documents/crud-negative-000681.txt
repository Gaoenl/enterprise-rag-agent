2023-07-25 11:10，正文：原标题：3分钟1042次！郑州一大学生打破跳绳世界纪录7月24日，从郑州科技学院再次传来喜讯。该校体育学院大学生杜婷婷在美国科罗拉多，当地时间7月23日，参加2023年世界跳绳锦标赛决赛中，打破自己初赛3分钟单摇跳1028次的世界纪录，最终以1042次刷新了自己的初赛纪录，再次打破世界纪录并荣获冠军。在美国当地时间7月20日的初赛中，杜婷婷以1028次的成绩打破了赵书平2019年挪威WJR跳绳世界杯赛中创造1022次的纪录，向世界展现了中国跳绳的强大实力。在美国当地时间7月23日的决赛中，杜婷婷展现了惊人的稳定性和强大的耐力，每一次跳跃都毫不犹豫地演绎出了完美的动作。这场锦标赛吸引了来自世界各国的顶级跳绳选手，竞争异常激烈。在紧张的3分钟中，她顽强拼搏，出色表现让她的得分一路攀升，当大屏幕显示杜婷婷以1042次的成绩夺得3分钟单摇项目的冠军时，现场爆发出巨大的欢呼声与掌声。杜婷婷成功地将鲜艳的五星红旗在赛场升起，为祖国赢得了荣耀。“杜婷婷成功的背后凝结了她辛勤训练和不懈的努力。作为中国跳绳运动的杰出代表，她的出色表现激励着青年学子追求梦想并展现自己的实力。这次夺冠不仅是对杜婷婷个人成就的肯定，同时也为中国跳绳运动增添了新的辉煌篇章，我们相信，杜婷婷将继续努力训练，不断挑战自我，在未来的比赛中创造更加辉煌的成绩。”郑州科技学院校长孙金锋说。转自：正观新闻来源：郑州人民广播电台返回搜狐，查看更多责任编辑：
