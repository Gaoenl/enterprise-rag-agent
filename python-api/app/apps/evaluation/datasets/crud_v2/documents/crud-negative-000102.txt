中证网讯(记者康曦)近日,万兴科技旗下万兴播爆(直播版)全新升级,上线智能互动、AI智能脚本和智能翻译等功能,进一步提升数字人直播体验。同时,全新版本实现AI数字人形象数量翻倍,已拥有100+超逼真多国家数字人形象,并升级会员体系,推出限时版会员,开放用户试用权限,进一步满足企业直播、个人IP直播、直播电商、跨境电商等场景下的数字人需求,持续推动直播行业进入AI数字人时代。智能互动功能打造了数字人互动新模式,可满足电商直播场景下的数字人互动需求,用户只需预先设定回复内容、名片等信息,数字人即可自动完成从观众入场时自动发名片、自动打招呼,到观众提出问题时解答问题等实时互动。目前,这一功能已率先支持阿里国际站。万兴科技是中国数字创意软件领域产品覆盖面广、营收体量大、全球化程度高的A股上市公司,也是国内AIGC行业龙头企业。当前,万兴科技已推出万兴爱画、万兴播爆、万兴智演、Wondershare Trumate、Wondershare Kwicut、Wondershare VirtuLook等AIGC创意新品;旗下万兴喵影、Wondershare PDFelement、万兴PDF、亿图图示、亿图脑图、墨刀海外版Mockitt等产品均已集成AIGC能力。(文章来源:中国证券报·中证网)
