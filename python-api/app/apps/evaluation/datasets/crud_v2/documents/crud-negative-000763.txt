2023-08-06 15:38，正文：原标题：书香伴暑假，安全你我他！张家港经开区（杨舍镇）开展防溺水主题科普阅读活动暑假来临，随着气温的逐渐升高，未成年人溺水事故进入高发期。为进一步强化未成年人防溺水工作，提高安全防范意识，近期，张家港经开区（杨舍镇）蒋桥村党委联合张家港市河道管理处组织开展“书香伴暑假 安全你我他”防溺水主题科普阅读活动。知识讲座，谨防溺水活动开始，河道处志愿者首先为参与活动的少年儿童带来了一场“防溺水”安全知识小课堂，向大家普及防溺水“六不一会四知”，以及如何预防溺水、如何掌握溺水自救互救技能等知识。小课堂上节奏明快的安全知识儿歌，和提问互动式的安全警示教育，不仅带来了满满的知识干货，同时也提高青了少年儿童对防溺水的重视，筑牢了安全防线。七彩夏日，快乐阅读防溺水主题绘本故事会环节，教师志愿者为现场小朋友领读爱河小书童系列——防溺水教育启蒙绘本。在《好好拥抱这个夏天》和《如果不安全玩水》故事中，小朋友们聚精会神地聆听老师讲述淘气包“明一”湖中“冒险”的故事，在老师绘声绘色地描述下，大家牢牢记住要了“远离危险环境，谨防溺水事故”的提醒。童心防溺， “画”说安全阅读环节后，现场进行了亲子防溺水帆布袋涂鸦手绘DIY活动，小朋友们在分发的帆布袋上自由涂色，既锻炼了动手能力，又让少年儿童在轻松的氛围中识别安全隐患，树立不独自到水边玩耍，预防溺水的安全意识。蒋桥村通过开展形式多样的防溺水安全教育主题科普活动，以知识讲座、绘本领读、手绘实践等方式帮助少年儿童提高安全防范意识，有利于发动小朋友们主动思考，增强对溺水事故危害的认知，防止意外事故的发生。活动结束后，小朋友们都表示今后不会单独玩水，而是在家长的陪伴下，前往游泳馆游泳。扬子晚报/紫牛新闻记者 黄玉琴校对 盛媛媛返回搜狐，查看更多责任编辑：
