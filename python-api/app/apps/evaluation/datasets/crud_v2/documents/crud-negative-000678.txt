舜网讯 为扎实开展“不忘初心、牢记使命”主题教育，切实落实主题教育“守初心、担使命，找差距、抓落实”的总要求，7月18日，济南市退役军人事务局到市中区和历城区进行调研，深入了解退役军人服务体系建设情况，并现场解答退役军人工作中的难题。市退役军人事务局党组书记、局长潘传利先后来到市中区退役军人服务中心、七里山街道退役军人服务站、七里山街道蓝天社区退役军人服务站、历城区王舍人街道退役军人服务站、历城区王舍人街道大辛庄退役军人服务站，实地察看了退役军人服务中心和服务站建设情况，办公设施以及人员配备情况，了解了服务站工作的运行情况，并在七里山街道办事处和王舍人街道办事处召开了两次座谈会。座谈会上，潘传利听取了大家对街道和社区两级退役军人服务站建设情况的汇报，肯定了市中区和历城区在落实“有机构、有编制、有人员、有经费、有保障”五有标准、加快退役军人服务保障体系建设、落实退役军人服务保障工作方面取得的进展和成绩，对大家反映的工作中的困难和问题也作了解答：关于服务保障体系机构建设方面的问题，街道和社区退役军人服务站要按照中央的相关要求，单独挂牌，具备独立的办公场所和专门的工作人员，切实保障为退役军人服务的质量和水平；关于部分退役士兵的保险接续工作，目前已经展开工作，各区保险续接工作专班要按照中央政策规定和《全市部分退役士兵社会保险接续工作实施办法》，围绕“确保稳定、确保精准、确保顺畅、确保满意”四个目标，稳妥有序推进；关于退役军人服务站办公经费问题，市局也将积极协调相关部门进行顶层设计，积极探索推进解决。潘传利指出，市退役军人事务局挂牌成立以来，全局上下凝心聚力、团结奋进，边组建机构、边推进工作，边谋划发展、边解决问题，退役军人工作没有现成的经验可以借鉴，基层同志们进行了很多有益的探索，取得了很好的成效，为下一步的工作提供了宝贵的经验。作为专门为退役军人服务的部门，我们必须提高政治站位，牢固树立起以退役军人为中心的理念，用心用情全面做好退役军人服务保障工作，把退役军人当成自己的家人，提升他们的幸福感、荣誉感、获得感和尊崇感。潘传利鼓励大家要继续勇于探索，勇于创新，把实践上升为理论成果，开创退役军人事业的新局面。
