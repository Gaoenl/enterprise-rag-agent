8月12日，据央视新闻报道，美国夏威夷州政府称，夏威夷州毛伊岛大火导致的死亡人数已达67人。夏威夷州州长表示，毛伊岛山火造成的破坏将需要数十亿美元才能修复和重建，根据美国的消防数据，这场大火已成为美国过去100年来第二致命的大火。夏威夷大火有多凶猛？又是缘何而起？△图/央视新闻建筑成灰、汽车烤化80%的土地被山火摧毁据央视新闻报道，当地时间8日，夏威夷州毛伊岛燃起大火，火势凶猛。△图/央视新闻截至目前，大火过火面积超过2000英亩，对毛伊岛上超过3.5万人造成威胁。至少1.1万名游客从毛伊岛疏散，数以千计居民逃离家园。毛伊岛市长理查德·比森表示，受灾地区几乎面目全非，现场如同“战区”。“最贴近现状的描述是，这里如同战区或者刚遭遇炸弹爆炸。街上的汽车被烤化，大多数连原本的结构都不复存在。”其中，位于毛伊岛西端的历史名镇——拉海纳镇，是这场大火的重灾区，该镇80%的土地已被摧毁，约有1700处建筑被烧毁，部分建筑已经化为灰烬。△图/央视新闻夏威夷州州长警告返回家园的居民，拉海纳已是一个满目疮痍的地区，“人们将看到他们一生中从未见过的破坏。大家回去时请做好准备。”截至发稿时间，毛伊岛上仍有多处明火，由于大范围的通信中断等原因，当局尚未确定全岛共有多少人失踪。死亡人数可能进一步上升。山火来袭警报失效？游客信号断联、跳海逃生山火发生后，数以千计游客试图逃离毛伊岛，但仍然有大量游客被困在当地，来不及离开夏威夷州。有游客表示，他们直到最后一刻才收到撤离通知，也无法与外界联系，差点被大火吞噬。△图/央视新闻据央视新闻报道，来自加州洛杉矶的游客布莱恩表示，他们当时住在拉海纳镇的宾馆，什么也不知道，没有手机信号，没有电视，没有网络，只看到有浓烟冒起。直到火灾发生第二天， 9日，才突然接到通知要撤离。“真的是最后一分钟，没有提前警告，让我们赶紧收拾，赶紧走。”来自美国加州的游客维塞克，带着妻子和5个孩子来夏威夷拉海纳镇度假，他在遭遇大火时，无人救援，为了躲避大火和烟尘，只能跳海逃生。△图/央视新闻据美国媒体报道，夏威夷毛伊岛的很多居民表示，此次毛伊岛大火发生时，他们没有听到任何警报声，直至看到附近的火焰或是听到爆炸才意识到危险来临。美国夏威夷州紧急事务管理局表示，该部门的记录显示，8日大火发生时，毛伊岛的警报系统并未被触发。而当地消防局方面则称，大火蔓延速度过快，消防部门无法与负责发出警报的紧急事务管理部门取得联系。目前，夏威夷州州长称已下令对毛伊岛山火应急响应进行全面审查，并进一步调查在山火发生后毛伊岛公共安全警报器没有启动的原因。夏威夷史上最大自然灾害极端天气又要背锅？大火发生后，夏威夷州州长乔希·格林将这场大火描述为“夏威夷州历史上最大的自然灾害”，究竟是哪些因素导致此次大火如此严重，使夏威夷陷入了前所未有的危机？△图/央视新闻据美国有线电视新闻网10日报道，当天发布的美国干旱监测周报显示，夏威夷的干旱在过去一周加剧，这导致火灾蔓延。毛伊县的严重干旱面积从上周的5%上升到了16%，而整个夏威夷州中度干旱面积则从6%上升到了14%。与此同时，本周经过夏威夷岛南部的飓风“多拉”带来了极强的大风，强风助燃，大火迅速向社区蔓延，造成致命的后果。美国国家气象局表示，截至8月10日晚，4级的飓风“多拉”已经持续了122个小时，是有记录以来太平洋飓风持续时间最长的一次。强大的风力也是最初起火、导致电力中断和消防直升机停飞的部分原因。英属哥伦比亚大学森林与保护科学系研究员科普斯-格尔比茨表示，“这些与气候变化相关的灾难已经超出了我们过去习惯应对的范围，正是这些相互关联的多重挑战导致了一场巨大的灾难。”catalogs:13000400;contentid:11709142;publishdate:2023-08-13;author:崔珍妮;file:1691884463160-7d1080a0-547d-4d96-8641-3cc1f927058c;source:29;from:潇湘晨报;timestamp:2023-08-1307:54:23;[责任编辑: ]
