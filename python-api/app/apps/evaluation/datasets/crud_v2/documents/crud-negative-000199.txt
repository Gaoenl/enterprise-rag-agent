2023-08-09 14:27，正文：原标题：拜登透露：我将很快访问越南【文/观察者网 张菁娟】据路透社报道，当地时间8月8日，美国总统拜登在新墨西哥州的一场政治筹款活动上透露，他将很快访问越南，并称越南希望提升与美国的关系，成为美国的主要合作伙伴。 当被问及拜登的访越行程时，一白宫发言人表示，“目前没有进一步的消息可提供”。 拜登（资料图）7月28日，拜登在缅因州出席2024年连任竞选活动时曾称，“我接到越南领导人的电话，他非常希望在二十国集团（G20）峰会与我会面，希望将美国提升为与俄罗斯及中国一样的重要合作伙伴”。9月9日至10日，G20峰会将在印度新德里举行。 报道称，虽然官员们没有解释更紧密的关系可能意味着什么，但专家分析认为，这可能包括增加军事合作和美国的武器供应。 今年4月，美国国务卿布林肯出访越南时便透露，安全问题是美越关系的“重要组成部分”，美国已敲定向越南移交第三艘巡逻艇的事宜，以增强越南海岸警卫队的能力。 布林肯当时还称，美越关系是美国拥有的“最重要且最具活力的外交关系之一”，“在过去几十年里，美越关系有着非凡的发展轨迹，我们相信这一关系可以变得更加强大”。 他称，希望在“未来几周或者几个月内”，将两国关系提高到更高水平。 今年是美国与越南建立全面伙伴关系第十年，两国互动频频。7月下旬，美国财政部长耶伦也访问越南，表示希望进一步深化两国经贸投资关系，尽快实现两国关系升级。 除此之外，美国的核动力航母编队停靠越南岘港市仙沙港、大规模商务代表团考察河内。 2023年6月25日，越南岘港，美国海军尼米兹级核动力航空母舰里根号驶入港口。图源：视觉中国尽管美国是越南最大的出口市场，但美国目前仅被越南列为“第三级外交伙伴”。路透社指出，尽管美国一直致力于将美越关系升格为战略伙伴关系，但正奉行“多重结盟”战略的越南却一直保持谨慎态度。 返回搜狐，查看更多责任编辑：
