2023-08-14，正文：医院女副院长被抓哭诉：我坐十几年牢后怎么养老！从7月中旬开始，监管部门先后3次表达了医疗反腐行动与决心，中国医药反腐风暴又一次升级。从今年8月份开始，医疗系统干部倒台的新闻就天天不断地传出。公开消息称，这轮医药反腐不只是对医药代表进行严格检查，各医院都开始对科室和医生进行检查。据媒体报道，到8月12日前，我国今年至少有176家医院的院长和书记被查处。监管部门连续三次表达对医疗反腐的行动和决心，我国医药反腐风暴再次升级。8月以来，每天都有医疗系统干部落马的消息被通报。公开信息显示，本轮医药反腐不仅要严查医药代表，医院也开始查科室、查医生。媒体统计发现，截至8月12日，今年全国至少已有176位医院院长、书记被查。8月12日，医院副院长被抓痛哭自己没法养老，登上热搜。医院原正副院长同日被通报双开痛哭忏悔：一二十年的牢坐了出来怎么养老7月6日，四川省宜宾市纪律检查委员会官方微信“廉洁宜宾”发布两条通报：宜宾市第一人民医院原党委书记、院长谢明均严重违纪违法被开除党籍；宜宾市第一人民医院原党委委员、副院长杨利严重违纪违法被开除党籍和公职。医院女副院长被抓哭诉！经查，谢明均理想信念丧失，纪法意识淡薄，背弃初心使命，在党内搞团团伙伙，对党不忠诚不老实，台上讲廉台下收钱，做“两面人”；违反中央八项规定精神，收受可能影响公正执行公务的礼金；违背组织原则，在组织多次函询时均不如实说明问题，长期隐瞒不报个人有关事项，在干部选拔任用中为他人谋取利益；违规向管理和服务对象放贷并收息，违规拥有非上市公司股份；生活腐化堕落，道德败坏；利用职务上的便利，为他人在工程项目、医疗设备及耗材采购等方面谋取利益并收受财物，数额特别巨大。
