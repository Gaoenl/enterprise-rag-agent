2023-07-25 17:53，正文：原标题：北京市海淀交通支队深入辖区“两客一危一货”企业开展交通安全宣教活动为认真贯彻“守护海淀”事故预防百日行动部署要求，大力推进“违规电动三四轮车综合治理”、“五不一戴”交通安全宣传实践、“严禁酒后驾驶”等宣传教育活动深入开展，依托交通安全“七进”宣传平台，7月24日，北京市海淀交通支队中关村交通大队民警深入辖区“两客一危一货”重点单位北京中通信诚快递服务有限公司，组织开展交通安全宣教活动。活动开始前，驻街民警首先结合北京市发布的《关于加强违规电动三四轮车管理的通告》及市交管局关于开展电动三四轮车综合治理的相关精神，与单位负责人及交通安全骨干进行深入交流，动员企业积极发挥行业示范引领作用，配合交管部门推进违规电动三四轮车于2023年底有序退出。随后向在场的快递员代表开展宣传，强调：违规电动三四轮车过渡期截至2023年12月31日；过渡期内，须自觉遵守交通安全法律法规，守法、文明出行；过渡期后，违规电动三四轮车一律不得上路行驶，不得在道路、广场、停车场等公共场所停放。违规上道路行驶或停放，执法部门将依法采取扣车、罚款措施。活动中，民警结合今年以来涉及电动自行车、电动三轮车亡人事故，向参加活动的单位交通安全负责人及快递员代表介绍我市开展守法安全文明骑行——电动自行车“五不一戴”的重要意义。随后，组织现场快递员签署“守法出行交通承诺书”，承诺做到：驾驶电动自行车出行时不闯灯、不逆行、不违法进入机动车道、不“醉酒”骑行、不违规骑行带人、骑乘电动自行车正确佩戴安全头盔。在之后的宣教活动中，民警针对“两客一危一货”行业特点，就“超员超速、客货混装、货车违法载客、疲劳驾驶”等专业运输驾驶员易发违法行为进行重点提示，告诫单位交通安全负责人做好内部宣教工作，针对以上违法行为要经常性提示教育。随后，民警通过讲解真实事故案例，全面阐述了规范使用安全带是减少道路交通事故致人伤亡的有效手段。结合“严禁酒后驾驶”主题宣教工作，民警分析近期酒后事故案例，重点提示单位驾驶员牢记“酒后不驾车、驾车不饮酒”，坚决杜绝酒后驾车这一严重违法行为。来源：北京市海淀交通支队返回搜狐，查看更多责任编辑：
