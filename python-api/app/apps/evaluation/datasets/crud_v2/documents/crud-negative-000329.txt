“秋天的第一杯奶茶”又一次在朋友圈掀起一阵狂欢。“秋奶”仿佛已经成为奶茶行业的“双11”。位于徐汇区天钥桥路上的蜜雪冰城店8月8日订单量激增，到了晚上十点，店员还在忙着制作不停新来的外卖订单。记者了解到，为了把秋天的第一杯奶茶顺利送到消费者手中，蜜雪冰城和美团外卖从7月份就开始筹备。“除了在配送端的紧密合作外，美团外卖的往年数据积累对我们在供应链能力储备、门店选址和实战推演等多方面都提供了有效的支撑。此外，今年我们还加入了美团外卖新推出的‘神抢手’直播活动，用一起过立秋的沉浸式直播场景，进一步释放需求，打造品牌。”蜜雪冰城相关负责人表示。据美团外卖数据显示，共有15万奶茶门店参与到今年的立秋奶茶狂欢节，当日累计卖出超4000万杯，继去年立秋后参与商家数和订单量再创历史峰值。其中，销量突破百万杯的奶茶品牌有8家，分别是蜜雪冰城、茶百道、古茗、沪上阿姨、喜茶、coco都可、书亦烧仙草和益禾堂。而在口味选择上，杨枝甘露成为今年奶茶口味的“人气王”，芒果以鲜亮的颜值和接地气的价格受到商家和消费者的喜爱。柠檬水和珍珠奶茶位列其后，成为下单量最多的奶茶外卖单品。在徐汇上班的徐女士表示，“秋天的第一杯奶茶”已成为每年立秋的一种仪式感，“等不到下班，中午就买了一杯！”茶饮行业近年来的蓬勃发展，除了其产品和服务满足了年轻消费者的需求之外，外卖属性强也是中国奶茶品类在全球消费市场，尤其是年轻人消费市场中独树一帜的重要原因。如果说“秋天的第一杯奶茶”带来的消费浪潮只是短时效应，但这种短时效应折射出的供给侧变化，则会长期推动需求侧增长。这个立秋，你喝到的第一杯奶茶是什么？记者：曹香玉编辑：叶芳芳校对：耿洁玉审校：韦丽转载请注明来自上海徐汇官方账号上观号作者：徐汇通
