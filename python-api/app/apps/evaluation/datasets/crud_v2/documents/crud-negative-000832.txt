2023-07-26，正文：近日，山西沁源发生一起未成年人遭霸凌事件。事发后，沁源县不少群众于7月25日凌晨前后，前往清河镇派出所希望公开处置结果。7月25日0时，沁源县公安局《通报》称，警方已成立专班进行处置，案件正在调查处理，相关人员已全部到案。7月25日上午，华商报大风新闻记者从有关部门获悉，此前家属未报案，7月24日警方发现网传视频，遂成立专班介入调查。网传视频——女孩遭多人围堵，视频录下其遭掌掴、脚踹等过程网友称事发地点位于山西省沁源县根据网传视频显示，一名女孩被多名女孩围堵，并遭遇掌掴。女孩在遭到多次掌掴后，低头躲避，但被踹倒在地，多人上前对其踢踹。现场，女孩双手护头，但再次被对方踹倒在地……华商报大风新闻记者注意到，视频中，女孩至少3次脚踹、拉扯倒地，倒地后仍有多人对其进行踢踹、撕扯头发……视频在网络传播后，7月25日有网友称，该段视频事发地位山西省沁源县，他是昨天才看到的，具体事发时间不清楚，“有人说事发时间是7月10日，不知道真假。我们作为家长都有孩子，肯定不希望这种事发生在自己孩子身上。”事件发酵——不少市民希望公示处置结果警方连夜公告“已成立专班处置，相关人员全部到案”
