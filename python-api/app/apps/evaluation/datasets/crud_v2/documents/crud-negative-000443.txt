2023-08-03 12:43，正文：原标题：欧元区失业率稳定在历史最低水平 年轻人就业形势欠佳海外网8月3日电根据欧盟统计局（Eurostat）的数据，2023年6月，欧元区的失业率稳定在6.4%，与4月和5月一样处于历史最低水平。据法新社报道，欧盟统计局8月1日公布的数据显示，2023年6月，欧元区的失业率为6.4%，与2022年同期相比下降了0.3个百分点，是该机构自1998年编制该数据以来的最低水平。对整个欧盟来说，6月的失业率为5.9%，与4月和5月相比保持稳定。6月份，欧盟27个成员国的失业人口约有1280万，欧元区20个国家的失业人口约有1081万。其中，法国失业率为7.1%，与5月持平；德国失业率为3%，与前几个月持平；意大利失业率为7.4%。失业率最低的几个国家是捷克（2.7%）、马耳他（2.6%）、波兰（2.7%），失业率最高的是西班牙（11.7%）、希腊（11.1%）。按年龄来说，25岁以下年轻人的失业率远高于整体水平，6月份欧盟该年龄组的失业率为14.1%，欧元区该年龄组的失业率为13.8%。欧盟统计局的数据是基于国际劳工组织对失业的定义，即在过去四个星期内积极寻找工作，并可在未来两个星期内开始工作的失业人士。（海外网-巴黎-鲁佳）责编：张霓、刘强返回搜狐，查看更多责任编辑：
