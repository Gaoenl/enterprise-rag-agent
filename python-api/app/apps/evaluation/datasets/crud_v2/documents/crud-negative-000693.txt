2023-07-26 18:33，正文：原标题：日开行列车20.5对！郑焦城际列车8月4日起施行公交化开行新方案央广网郑州7月26日消息（记者 夏莎 通讯员 李晶晶）7月26日，记者从中国铁路郑州局集团有限公司（以下简称：“国铁集团郑州局”）获悉，为服务旅客便捷化出行需求，自8月4日起，国铁集团郑州局对管内郑焦城际公交化列车开行方案及部分旅客列车停站、停时进行优化调整，精准投放运力，助力旅客美好乘车体验。郑焦城际列车8月4日起施行公交化开行新方案（央广网发 宋京 摄）新的郑焦城际公交化列车开行方案将开行郑州至焦作间列车20.5对，其中，城际列车13对，焦作～南阳寨间11.5对，焦作西～南阳寨间1.5对；动车组列车7.5对，焦作～郑州间3对，焦作西～郑州间2对，焦作西～郑州东间1对，焦作～郑州东间1.5对。郑焦城际列车8月4日起施行公交化开行新方案（央广网发 宋京 摄）为满足沿线旅客出行需求，郑焦城际部分旅客列车将增加停靠站或调整开行时间，其中，郑州-焦作D7852次增加黄河景区站，郑州-长治东D7854次、长治东-南阳东G7903次分别增加武陟站。新的郑焦城际公交化开行方案，具有列车间隔时间短、开行密度大的特点，更好地满足旅客随到随走的需求。郑焦城际列车8月4日起施行公交化开行新方案（央广网发 宋京 摄）铁路部门提示，郑焦城际多趟旅客列车开行时间微调，具体情况，可通过铁路12306网站（含手机客户端）等进行查询，合理安排出行计划。返回搜狐，查看更多责任编辑：
