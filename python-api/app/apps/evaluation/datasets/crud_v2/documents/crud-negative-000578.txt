2023-08-02，正文：央广网长春8月2日消息（记者舒震）据气象部门预测，由于第5号台风“杜苏芮”的残存水汽与副高后切变层的联合作用，长春市将于8月1-3日出现一次显著的降水过程，该过程累积降水80-120mm，局部地区可达到160-210mm，这是一次持续性强、累积降水多、强度大的暴雨。针对积水路段工作人员设置路牌提示市民绕行（央广网发长春市城防办供图）7月31日晚，长春市召开防御第5号台风“杜苏芮”防汛工作部署会议。长春市城乡建设委员会相关部门、各区市政维护单位主要负责人参加，针对即将到来强降雨天气，按照防汛四级响应，开展相关工作。会上传达了省、市防御第5号台风“杜苏芮”部署会议精神，并对下一步城区排水防汛工作进行了周密部署，要求各维护单位提高思想认识，坚持人民至上、生命至上，绷紧“防大汛、抢大险、抗大灾”这根弦，以“时时放心不下”的责任感，迅速进入临战状态，全力以赴抓紧抓实城区防汛各项准备工作，切实保障人民群众生命财产安全。一要强化责任落实，各单位主要领导要靠前指挥、果断处置，各级责任人要加强值班值守、坚持在岗在位，确保各项防汛工作落到实处。二要全面周密部署，加强会商研判，加密预报预警，做到准确预判、传达到位；针对城市低洼隐患点位置重点布放，及时消除在建工地、市政设施、地铁运营等安全隐患，确保做到万无一失。三要加强科学调度，严格按照应急预案，有序有效落实各阶段防御措施，加强排水管网清掏维护工作，及时督促维护单位对易堵及低洼地段排水管渠进行彻底地排查和清掏。分类精准做好河道闸门、吐口等看守工作，牢牢掌握防汛工作主动权。
