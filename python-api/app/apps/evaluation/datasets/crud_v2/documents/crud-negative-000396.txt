2023-08-17 22:14，正文：原标题：朋克式养生走红，1/3年轻人转变，唯品会保健品销量亮了在大众眼里，养生向来是中老年“专属”，但如今却开始趋于年轻化。最近有媒体就发现一个新现象，近两年市面上出现了“中药咖啡、中药奶茶”，并一度在年轻人中大火，尤其是上海、广州和成都等潮流城市。业内人士分析，咖啡与中药结合，并非商家招揽顾客的营销手段，反映出的是年轻人对养生的关注度增加。他们既想养生又管不住嘴巴，在种草平台上搜索相关词，“咖啡和中药冲突吗”、“吃中药能喝咖啡吗”，受到大量年轻人关注。类似的现象非常多，年轻人还赋予了一个新鲜词：朋克式养生。有人半夜和朋友撸串，却在扎啤里面放枸杞；有人凌晨4点睡觉，早上9点起床，睡前还要敷大牌面膜，醒来要吃各种保健品……还有很多年轻人，最近天气炎热，却热衷晒背泡脚，但同样又冰淇淋不离手。一位小姐姐自述她的朋克式养生法则，一边熬夜追剧，一边喝冰奶茶，少冰少糖是最后的倔强。《中国美好生活大调查》数据发现，今年18-35岁年轻人的消费榜单前三位，分别是旅游、数码产品和保健养生，其中超过30%的年轻人愿意为养生买单。在年轻人爱用的种草平台上搜索养生，相关笔记达到好几百万。从电商平台公布的具体销售数据看，年轻人养生的趋势更加直观。例如唯品会7月以来，鱼油DHA、奶蓟草等保健品销量翻倍，膳食营养品销量增长57%，还有维生素、益生菌销量同比增长均超过20%，其中90后Z世代的订单占比猛增。重庆的00后女大学生琴琴，就自嘲是朋克式养生中的一员，在吃上从来都不忌口，火锅冒菜和麻辣烫都是最爱，晚上还要熬夜看综艺。但同样，琴琴也要健身吃保健品，前几天趁着唯品会做活动买了益生菌，每天早上都在吃。在社交平台上，#为什么越来越多年轻人爱在养生上花钱#，还一度冲上热搜，吸引大量网友围观。有人表示，因为不想退休后立马进医院，想留个健康的身体去享受生活。这的确是很多年轻人热衷养生的关键，他们往往面临着较大的生活和工作压力，身体已经出现一些警报，但是又很少能够有自律的生活习惯，于是抱着适当运动、吃保健品的想法，希望抵消一些对身体的不良影响，朋克式养生就火了。返回搜狐，查看更多责任编辑：
