2023-08-07，正文：据央视新闻，当地时间8月3日17时55分左右，在京畿道城南市盆唐区地铁书岘站附近，一名男子驾车冲向人行道上的行人，造成5名行人受伤；之后该男子又持刀进入附近的百货商场进行无差别袭击，造成9人受伤。警方在当天18时05分左右将这名男子紧急逮捕，据了解，嫌疑人没有对自己的犯罪动机进行特别的陈述，警方还在进行详细调查。 据韩国京畿道警方3日通报，截至当地时间当天21时，在京畿道城南市盆唐区发生的无差别持刀伤人事件已造成1人死亡、13人受伤。韩国总统尹锡悦4日就盆唐区发生的无差别行凶案下达指示称，政府应动员全部警力予以超强硬应对，避免让民众恐惧不安。环球网称，尹锡悦表示，城南“无差别行凶案”是针对无辜市民的恐怖袭击。据海外网8月7日援引韩国《朝鲜日报》报道，韩国警方7日公布了嫌犯的个人信息，包括照片、姓名和年龄等。韩国无差别行凶事件嫌犯照片据报道，嫌犯名为崔元宗（音译），现年22岁。8月3日，他驾车冲向人行道上的行人，造成5名行人受伤。之后又持刀进入附近的百货商场，进行无差别袭击，造成9人受伤。其中一名被撞的女性于6日凌晨不幸身亡。图为崔某作案时的场景崔元宗因涉嫌杀人未遂等被批捕。由于一名伤者死亡，警方将崔某的犯罪嫌疑从“杀人未遂”变更为“杀人”等。据报道，韩国近期发生多起持凶器伤人案件，网络上也频现宣称要在人员密集场所发动类似袭击的帖子，引发民众担忧。54人被调查，有人持刀在公交车站徘徊韩国警方6日表示，已对54名涉嫌发布这类消息者发起调查，涉嫌发帖者中包括多名未成年人。此外，首尔中央地方法院当天以谋杀未遂罪名对一名20多岁男子发出逮捕令。这名男子4日在首尔一处公交车总站持刀徘徊。此前，他曾在网络上宣称将实施暴力犯罪。另据中新网援引韩国国际广播电台7日报道，仅在5日一天，京畿道南部便有8人因发布“杀人预告帖”被捕，其中6人不满20岁。发布的内容大多涉及在开学后进行校园内杀人、在游泳池和繁华商圈等人群密集处杀人等。
