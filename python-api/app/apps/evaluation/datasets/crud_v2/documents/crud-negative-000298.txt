2023-08-15 09:03，正文：原标题：新疆洛浦公安：青春不停步 反诈最先行中新网新疆新闻8月14日电（姚亚龙 陈 暾）为进一步推进县域法治建设，不断提升暑期返乡大学生法治意识素养，远离电信诈骗，保护人身财产安全，连日来，新疆和田地区洛浦县公安局在全县范围内广泛开展开展“返乡大学生防电信诈骗、防溺水、道路交通安全暨法治宣传”活动。活动中，民警结合近期新发高发电信网络诈骗案例和自身防范电信网络诈骗工作的实践经验，采用以案说教的方式，向大学生们介绍了电信网络诈骗特点规律、常见形式和识别防范方法。特别针对目前常见的冒充电商、熟人、公检法工作人员和校园套路贷、刷单返利、“杀猪盘”诱导等类型电信诈骗进行了详细解说和剖析解读，提醒广大学子在日常生活中时刻绷紧防范弦，并积极向家人朋友进行宣传。活动同时围绕树立正确安全观、法纪观，对防溺水知识和交通安全法规进行了大力宣传。此次培训共发放宣传资料700余份，现场解答法律咨询100余件，全面提升返乡大学生人群防范网络电信诈骗能力意识，他们纷纷表示要提高警惕、积极行动，共筑全县防电诈坚固防线。下一步，洛浦公安将持续优化反电诈工作思路，“线上+线下”齐发力，守护群众“钱袋子”，全力营造“全民反诈”浓厚氛围。返回搜狐，查看更多责任编辑：
