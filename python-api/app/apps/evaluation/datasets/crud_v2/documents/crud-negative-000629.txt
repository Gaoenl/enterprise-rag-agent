，正文：网易近日宣布在美国德克萨斯州设立新的游戏工作室T-Minus Zero Entertainment，由资深MMO游戏人士Rich Vogel领导。目前，该工作室正在研发一款以科幻宇宙为背景的原创第三人称多人动作游戏。  Vogel表示：“我们工作室的使命是创造史诗般的沉浸式世界，让全球的玩家可以一起游玩，形成一个充满活力和热情的社区。网易团队与我们有着共同的愿景，即创造难忘且有意义的体验，他们优先考虑提供支持和创作自由，让我们能够实现梦想。”Vogel是一位资深游戏开发者，曾领导开发了《星球大战：旧共和国》等多款MMO游戏。  此外，该工作室的其他资深开发者包括游戏总监Mark Tucker，他有22年的从业经验，曾参与开发《辐射76》和《毁灭战士4》等游戏；美术总监Jeff Dobson，他有26年的从业经验，曾参与开发《星球大战：旧共和国》、《龙腾世纪：审判》、《质量效应：仙女座》和《圣歌》等游戏；以及运营和产品副总裁Scott Malone，他有10年的产品经验，曾参与开发《辐射76》、《毁灭战士4》和《上古卷轴OL》等游戏。本文属于原创文章，如若转载，请注明来源：网易美国新游戏工作室成立 开发科幻宇宙游戏https://news.zol.com.cn/829/8293381.html
