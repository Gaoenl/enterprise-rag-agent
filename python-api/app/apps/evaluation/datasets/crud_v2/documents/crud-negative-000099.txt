2023-08-15 18:16:20，正文：中国经济周刊-经济网讯（记者 孙晓萌）8月10日，国家能源集团长源电力股份有限公司发布《关于公司董事及高级管理人员辞职的公告》。公告称，因正常工作调动，袁光福先生申请辞去公司董事、总经理职务。袁光福先生辞去上述职务后将不在公司及其控股子公司任职。今年，国家能源集团旗下已有多次人事调整。4月，多家媒体报道，国家能源投资集团原副总经理、党组成员王树民到龄退休。5月12日，国家能源投资集团有限责任公司召开党组会议，宣布了关于国家能源投资集团有限责任公司副总经理任职的决定：徐新福任国家能源投资集团有限责任公司副总经理、党组成员。作为国家能源投资集团控股的上市公司，长源电力今年还有两位主要领导辞职。3月24日，长源电力发布公告称，因年龄原因，赵虎辞去公司董事长、董事职务，任德军辞去公司副总经理职务。不同于近期的人事变更，赵虎、任德军辞任后，仍在公司担任其他职务。另外一家由国家能源投资集团控股的国电电力，7月14日发布公告称，因工作原因，杨富锁辞去公司副总经理、总会计师职务，并且其离职后，将不在公司担任任何职务。公司董事会聘任刘春峰为公司副总经理、总会计师。国电电力是核心电力上市公司和常规能源发电业务的整合平台，主要经营业务为电力、热力生产及销售，截至2022年底，公司资产总额4128.52亿元，公司总股本178.36亿股。据天眼查，国家能源投资集团共持90.39亿股，占总股本比例50.68%。国家能源投资集团旗下的重要新能源企业，4月26日，龙源电力发布公告称，经董事会提名委员会审核后，公司董事会同意聘任宫宇飞为公司总经理，同意聘任李星运为公司副总经理，任期都是自董事会审议通过之日起生效，直至第五届董事会任期届满为止。天眼查APP显示，龙源电力成立于1993年，是一家以从事电力、热力生产和供应业为主的企业。国家能源投资集团持有龙源电力46.02亿股，占总股本比例54.91%。一审：郑扬波 二审：王新景 三审：周琦
