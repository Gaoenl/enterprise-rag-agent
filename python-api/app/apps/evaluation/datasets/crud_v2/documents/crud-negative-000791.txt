2023-08-03 15:28，正文：原标题：通报！合肥两公司被罚为深刻汲取违规动火作业事故教训，进一步规范动火作业安全管理，强化警示教育，防范事故发生，8月1日，合肥市应急管理局公布2起违规动火作业执法案例，两家涉事公司分别被行政罚款2万元和4万元。01焊接与热切割工人无证上岗4月，合肥市应急管理局接到合肥某机械科技有限公司的举报，派出执法人员对其进行核查。执法人员发现，该公司人员胡某、吴某2人未按规定经专门的安全作业培训，并取得相应资格进行特种作业（焊接与热切割）。执法人员针对以上问题，现场下达了《责令限期整改指令书》，并依法依规立案查处。该公司使用未取得有效特种作业操作证的特种作业人员上岗作业的行为，已经涉嫌违法。合肥市应急管理局依据有关法律规定，经自由裁量决定给予该公司罚款人民币2万元的行政处罚。02加油站内进行违规动火6月，肥西县应急管理局接到暗查暗访线索，工作人员对合肥某商贸有限公司加油加气站进行执法检查。工作人员发现，该公司雇佣的张某、黄某、朱某等员工在该加油站车辆入口处（非固定动火区域）从事动火作业。同时，该公司还存在使用未取得焊接与热切割特种作业操作证的员工上岗作业、未履行动火作业审批手续、未安排专门人员进行现场安全管理等多项问题。执法人员对该公司负责人王某、安全员黄某进行了询问，现场下达了《责令整改指令书》《现场处理措施决定书》。经查明，该公司使用未经专门的安全作业培训取得相应资格的特种作业人员上岗作业的行为，以及非固定动火区域的动火作业未履行动火作业审批手续、未安排专门人员进行现场安全管理的行为，违反了《安全生产法》有关规定。肥西县应急管理局依法决定，给予该公司罚款人民币4万元的行政处罚。【此文系转载，来源于合肥晚报，版权归属原作者】编辑：汪雨婷返回搜狐，查看更多责任编辑：
