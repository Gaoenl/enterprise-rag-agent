2023-07-29 21:43，正文：原标题：大运会射击开赛 印度冠军直呼“十分想见大熊猫”新华社成都7月29日电（记者王沁鸥、黄耀漫、李春宇、田光雨）成都大运会射击项目29日开赛，四枚金牌各归其主。女子10米气步枪冠军、印度选手瓦拉里万赛后直言：“十分想见大熊猫！”女子10米气步枪资格赛当天率先进行，资格赛各队三名选手的总成绩之和将直接决定该项目团体名次。最终，韩国队在团体排名中拔得头筹，这也是本届大运会射击项目的首金。匈牙利队和中国队分列二、三位。决赛有8名选手参加，冠、亚军分别归属瓦拉里万和东京奥运会10米气步枪混合团体亚军、美国选手塔克。中国选手邢航在前两枪排名垫底的情况下逆势搏得一枚铜牌。瓦拉里万分享了来到中国后的快乐：“这是我第三次来中国，但却是第一次来成都。想做的事，那肯定是见熊猫！”赛后新闻发布会上，瓦拉里万只要提到熊猫就很兴奋：“我听说了很多关于它们的事，我盼望着比赛结束，这样就能有机会去见它们了！”塔克则很喜欢中国的交通系统，她在美国西弗吉尼亚大学上学。她说：“我来到大运村就看到了那些公交车，还有大家都可以骑的自行车，这真的很棒，在美国我住的地方就不怎么能看到这些。”参加过奥运会、世锦赛、世界杯等多项国际大赛的塔克说，大运会的氛围很像奥运会：“当我走在大运村里，一切都让我想起奥运会，各代表团不同项目的运动员可以彼此交流，成为朋友。”瓦拉里万同样经历过多项世界大赛，她认为，大运会射击项目的竞技水平很高，像印度队这次就派出了多位曾在世界杯分站赛等世界赛事上拿到过金牌的选手。印度队当天还收获女子10米气手枪团体冠军，队员巴克尔摘得该项目个人金牌。中国队当天还收获女子10米气手枪团体银牌。（完）返回搜狐，查看更多责任编辑：
