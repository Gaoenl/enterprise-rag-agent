连日来亚洲和北美多地经历高温肆虐美国多地高温破历史纪录韩国持续高温致23人遇难伊朗部分地区气温超过51℃......这些国家所经历的高温有多极端？目前情况如何？未来高温是否还将持续？一起来关注一下↓↓↓美国美国今夏出现持续高温，北部的波士顿、费城和华盛顿特区一度陷入高温紧急状态，西南部的加利福尼亚州、亚利桑那州、得克萨斯州多地出现创纪录高温。高温给民生、经济、农业等都造成了一系列直接和间接的影响。亚利桑那州首府菲尼克斯（又称凤凰城）近期连续31天日最高气温超过110华氏度（约43.3℃），创下历史纪录。在美国东南部佛罗里达州，迈阿密附近海水温度达到100华氏度（约37.8℃），以致美国总统拜登说：“（下海）更像是跳进热水浴缸，而不是在大海中乘风破浪。”在以炎热著称的得克萨斯州第一大城市休斯敦，由于热浪持续，市政府8月4日发表声明，把公共卫生高温应急计划延长至8月6日，同时开放一些设施作为降温中心供人们避暑。无家可归者可拨打热线电话并免费乘车前往降温中心。休斯敦卫生部门也与一些慈善机构、商场和公共图书馆合作，在这些场所营业时间内，市民均可前往避暑。受持续热浪影响，当地居民户外活动大幅减少。休斯敦居民苏尼加说持续高温已导致她血压异常，如今外出只去有空调的场所。美国有线电视新闻网报道说，酷暑天气已成为美国的新现实，而相关公共政策尚未跟上。由于能源援助计划资金不足等原因，低收入者、老年人和其他弱势群体在热浪中遭遇的健康风险最大。拜登近日宣布采取一系列措施应对极端高温，包括发布高温危险警报以提供联邦高温相关保护，加强对建筑和农业等高风险行业的检查，美国林务局提供资金帮助城镇种植树木，增加天气预报投入，扩大因热浪而干旱加剧的西部各州的蓄水能力等。拜登在白宫记者会上称，美国“与天气相关的头号杀手”是炎热，并承认极端高温天气对美国老年人、无家可归者等弱势群体打击最为严重。另有专家表示，今年美国与高温相关的死亡人数可能会再创纪录。韩国韩国消防部门8月2日发布的数据显示，韩国今年夏天的高温天气已经导致23人死亡。韩国行政安全部1日将该国高温预警上调至最高级别，这是近四年来头一次。8月3日，市民顶着烈日走在韩国釜山街头。图/新华社数据显示，从今年5月20日政府启动酷暑应急响应至7月底，高温天气已致21人死亡；截至当地时间7月30日16时，全国范围内共报告73例热射病等中暑病例，仅7月29日就有6人疑似死于热射病；8月1日，庆尚北道永川市和全罗北道井邑各有1人因中暑死亡，至此累计23人死亡。8月3日，市民在韩国釜山的海滩消暑。图/新华社据韩联社报道，死者多为高龄老人，多数死亡病例在农村，其中大部分人是在田间务农时死亡，被发现时体温很高。韩国最近连日出现高温天气，受影响的主要地区包括庆尚道、忠清道、京畿道、全罗北道等。韩国中央灾难安全对策本部要求相关部门和地方政府针对高龄农民、户外劳动者和弱势群体制定高温应对措施。8月3日，市民在韩国釜山一处建筑物下避暑。图/新华社据行政安全部通报，连日来，韩国多地最高温度超过38℃，首都首尔以南的骊州市1日测得最高温度达38.4℃。高温叠加潮湿，使得体感温度更高。行政安全部1日18时启动中央灾难安全对策本部一级应急响应，时隔四年再次将高温预警上调至最高的“严重”级别。按照韩联社说法，高温预警“严重”级别意味着韩国至少40%地区的体感温度连续3天以上超过35℃，或至少10%地区的体感温度连续3天以上超过38℃。伊朗据《纽约时报》报道，当地时间8月1日，由于遭受“前所未有”的高温天气，伊朗宣布全国政府机关、银行和学校放假两天。报道称，伊朗南部多个城市连日遭受异常高温天气。伊朗首都德黑兰2日气温达39℃。伊朗南部城市阿瓦士的气温曾超过51℃。图片来源:《纽约时报》报道截图当天，伊朗政府发言人贾赫罗米在社交媒体上表示，“鉴于前所未有的热浪将席卷全国，内阁同意卫生部的提案，宣布2日、3日两天全国放假，以保护公众健康。”伊朗卫生部还表示，医院将处于高度戒备状态。该部还警告，过度曝晒于阳光下可能有中暑的风险，建议老年人、儿童和有潜在健康问题的人留在室内。伊朗足球联赛也取消了未来几天的所有比赛。报道称，近年来中东地区水源不断减少，沙漠面积扩大，人们面临缺水和间接性断电的情况。此前6月，伊朗曾提前政府员工的夏季办公时间，以节省能源。以上地区高温还会持续吗？全球还有哪些地区会经历高温？中央气象台预计受异常偏强的副热带高压带持续影响未来三天美国中南部墨西哥中北部、非洲北部、西亚中亚中南部、南亚西北部等地高温天气仍将持续日最高气温普遍在37℃以上局地最高气温可达45℃以上伊比利亚半岛南部、亚平宁半岛南部等地也有35℃以上的高温天气广告中国气象报社  出品来源：新华社 中国新闻网 央视新闻编辑：郭曼如审核：崔国辉 叶海英举报/反馈
