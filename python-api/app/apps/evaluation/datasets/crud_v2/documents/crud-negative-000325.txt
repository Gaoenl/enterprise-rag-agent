沈阳市“青年英才‘留沈阳，好住房’”活动走进长春吉大博士想来沈阳创业安居“沈阳这些年发展得特别好。”“沈阳是个包容的城市，无论是从历史文化传承，还是城市建设，都走在东北的前沿。”“期待毕业后能去沈阳创业安居。”6月26日，沈阳市“青年英才‘留沈阳，好住房’”活动东北行第三站走进长春，在吉林农业大学和吉林大学，本次活动均受到广大学子们的高度关注，叠加的购房安居优惠政策更是吸引了博士们的目光。吉林农大学子争先恐后提问在吉林农业大学就业培训中心，高校学子们对沈阳的购房安居优惠政策充满期待。在沈阳市房产局市场监管处副处长周国伟介绍完优惠政策后，学生们争先恐后举手提问。“沈阳是一座美丽的城市，也是东北地区的中心城市，住房的确是我们毕业生即将面临的一个现实问题，今天听了沈阳市房产局的各种购房补贴政策，让我感到非常心动，也燃起了我去沈阳这座城市工作生活和发展的决心。”吉林农业大学大四学生王一婷说。“作为一名应届毕业的硕士，我们找工作首先想知道各地的购房政策，以及我们作为外地人去沈阳工作能享受到怎样的租房政策。这场宣讲会对我来说吸引力还是比较大的，沈阳市15天的免费住房政策，对我去沈阳择业和就业的过渡期提供了很好的保障。沈阳有着深厚的文化底蕴，我很喜欢这座城市，也会考虑去沈阳就业和发展。”这位名叫赵梦非的女生对记者说。吉大俩女博士看好沈阳“这个是我们的宣传手册，所有的政策都在里边。您如果到沈阳就业或创业，比如说刚开始没地方住，我们可以提供短期免费公寓。如果前三年没有地方住，我们还给租房补贴，博士最高是给到一个月2500元，连续给三年。像您二位都是博士，这是属于高学历的人才，我们是怀着满满的诚意邀请你们到沈阳去，我们这个购房的政策，比如博士买房一次补贴7万元，你们随时都可以享受。而且我们是一次性把7万元钱都给你，还有全额的契税减免，契税补贴也是一次性都给你们。”在吉林大学，周国伟先是热情洋溢地介绍了沈阳带来的各种购房安居政策，并给学生们送去了可爱的小熊玩偶。两位物理系的女博士张同学和孙同学表示，她们念本科的时候去过沈阳，对沈阳的印象特别好。“感觉沈阳是个包容的城市，无论是从历史文化传承，还是城市建设，都走在东北的前头，就业机会也很多，我很期待能在沈阳找到好的工作机会，到沈阳创业安居。”张同学和孙同学还现场加了沈阳市房产局的公众号，希望对沈阳的购房安居政策有更深的了解。房企助力外地英才来沈发展当天下午，沈阳一行人来到了建筑面积450万平方米、总投资400亿元的东北亚第一超级产城大盘——中铁长春博览城。在现场，周国伟向嘉宾介绍了沈阳市的购房安居政策，得到与会者的热烈掌声。沈阳市房地产业协会驻会会长、联祥地产（中国）董事总经理杜宏鹏表示，“沈阳是一座活力城市、魅力之都、青年友好型城市，对于青年人很有吸引力，尤其这次活动，我们针对青年人出台了很多针对性的政策，给青年人一个来到沈阳、留在沈阳的理由。”杜宏鹏说，“希望长春的人民能够来到沈阳安居乐业，同时我也隆重推荐一下，沈阳的沈北新区也是活力之区，这里的中铁逸都项目也推出了一些针对青年英才的政策。万亿央企买房助就业，希望青年英才们能在中铁项目安居乐业。”（沈阳日报、沈报全媒体记者 张晓宁）举报/反馈
