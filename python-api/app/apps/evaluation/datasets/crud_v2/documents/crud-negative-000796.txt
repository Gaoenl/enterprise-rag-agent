2023-08-02，正文：河北多地遇山洪 中部战区组织官兵和民兵紧急救援 据保定日报消息，受台风“杜苏芮”影响，河北保定市自7月29日至8月1日出现大暴雨和特大暴雨，总降水时长超过了80个小时。全市平均降水量350毫米，最大雨强82.2毫米/小时。250毫米（特大暴雨）以上降水面积占比辖区面积的90%。而保定历史上的“63.8”“96.8”“12.7”“16.7”等特大暴雨过程，影响区域均不到40%。此次降水极端性强，主要有累计雨量大、覆盖范围广、持续时间长、降水强度强、大值中心多等特点。降雨量超过600毫米有5个，最大极值为易县紫荆关736.6毫米，依次分别是阜平辽道背698.2毫米、涞源杨家庄镇626.3毫米、竞秀江城616毫米、徐水大王店604毫米。本次过程最大日降水量为491.7毫米，超过了此前的历史记录400.8毫米。自入汛以来全市平均降水量544毫米，比去年同期偏多84.7%，比常年同期偏多141.6%。保定区位特殊，是首都南大门，雄安新区腹地，确保防汛安全责任重大。气候特殊，全市年降雨量70%集中在“七下八上”的主汛期，暴雨强度大，持续时间长。地形特殊，地势自西北向东南倾斜，东西间距200公里，高差2200余米，地形坡度陡，河流源短流急，山洪暴发，急剧下泻，极易成灾。任务特殊，山洪灾害防治区面积7845平方公里，涉及99个乡镇，1342个行政村，132万人口；地质灾害点639处，涉及84个乡镇，363个村，0.7万人口；河道178条，总长4386公里，堤防总长1046公里。
