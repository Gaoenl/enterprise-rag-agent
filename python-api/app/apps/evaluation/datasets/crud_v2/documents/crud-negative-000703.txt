【中国食品报】讯(刘婧婧 张鑫铭 记者高伟)寒地虾宴,醉美宾县。9月15日晚,由宾县委、县政府主办,宾县水产技术推广总站承办,宾县旅游事业发展中心、县融媒体中心协办的黑龙江·宾县首届寒地小龙虾美食节盛大开幕。省、市水产技术推广总站相关负责人、县领导出席开幕式。暮色四合,华灯初上。夜幕下的宾县体育场流光溢彩,人头涌动。开幕式上,黑龙江省水产技术推广总站站长张旭斌为基地授牌,授予宾县水产总站试验基地为“黑龙江省寒地小龙虾扩繁基地”;江苏盱眙龙虾创业学院原院长为基地授牌,授予宾县水产总站试验基地为“黑龙江省寒地小龙虾养殖产学研试验基地”。宾县委常委、副县长何洪千在致辞中指出,在这里隆重举办黑龙江·宾县首届寒地小龙虾美食节,既是对龙江渔业振兴事业的丰富延伸,又是全面宣传展示宾县美食美景、丰富百姓餐桌的积极探索,更是推进渔业转型升级、助力乡村振兴的大胆尝试,必将为宾县渔业发展注入新的活力。随后,宾县委副书记马平宣布黑龙江·宾县首届寒地小龙虾美食节盛大开幕。宾县将以此次盛会为契机,继续挖掘寒地小龙虾发展潜力,打造集“美食餐饮、休闲观光、农事体验、科普教育”于一体的地域特色品牌,让广大市民游客体会美食中的意趣,爱上舌尖上的宾县。
