网易科技讯 10月28日消息，据路透社报道，亚马逊今天发布了2016财年第三季度财报。财报显示，亚马逊对第四季度的业绩预测令人失望,而第三季度的业绩不及华尔街分析师的预期，原因是该公司对货运、视频内容及其它项目进行了巨额投资。受这一消息影响，在纳斯达克周四盘后交易中，截止发稿时，亚马逊股价下跌了6.15%，至每股768美元。投资者和分析师正在试图评估亚马逊计划在各种投资项目上继续投入多少，而且令人感到不安的是，亚马逊在其业绩展望中提供的数据变动范围较大。市场研究公司Jackdaw Research首席分析师简·道森(Jan Dawson)指出，投资者不赞成该公司业绩展望中的“不确定性”。他说：“亚马逊自己确实不知道这季度会发生什么。”亚马逊预计第四季度净销售额为420亿美元到455亿美元之间，同比增长17%到27%之间。第四季度包括了美国所有重要的节日购物季。根据汤森路透I/B/E/S的数据，亚马逊第四季度业绩展望的中间值437.5亿美元，不及分析师平均预测的445.8亿美元。亚马逊还预测，第四季度的运营利润为零到12.5亿美元。美国证券公司Wedbush分析师迈克尔·帕克特(Michael Pachter)表示：“亚马逊第四季度运营利润区间的最高值，仍然与分析师平均预期相差2.5亿美元。”亚马逊首席财务官布莱恩·奥尔萨夫斯基（Brian Olsavsky）告诉记者，亚马逊对新仓库和视频内容的投资，推高了第三季度的成本。他说：“为了支持我们正在投资的项目，我们进行了大量招聘。”亚马逊第三季度的总运营开支为109.4亿美元，比去年同期上升了31.5％，其中包括对云服务“AWS”(Amazon Web Services)和全球范围内开展Prime会员服务的投资。在截至9月30日的这一财季，亚马逊的净利润为2.52亿美元，摊薄后每股收益0.52美元，这一业绩远好于去年同期。2015财年第三季度，亚马逊的净利润为7900万美元，摊薄后每股收益0.17美元。这是该公司连续第六个实现盈利的季度。但根据汤森路透I/B/E/S的数据，亚马逊第三季度的每股收益远低于分析师平均预期的0.78美元。亚马逊本月早些时候表示，在节日购物旺季，将在美国雇佣超过12万名季节性员工，比去年同期增长20％，突显了该公司对传统零售商不断增长的威胁。该公司报告称，第三季度的营收同比增长29％，符合分析师此前预期，主要受益于其Prime Day年度促销日销售大幅增长、强劲的学生返校购物热潮及其市场领先的云服务业务。这家全球最大的在线零售商表示，第三季度净销售额为327.1亿美元，比去年同期的253.6亿美元增长29%。亚马逊今年7月份表示，在其第二届Prime Day促销日，全球订单数同比增长60%。该公司当时没有提供具体销售数据。第三季度，亚马逊云服务“AWS”的营收达到32.3亿美元，同比增长了55％。根据市场调查公司FactSet StreetAccount的数据，分析师此前平均预期为31.9亿美元。长期以来，亚马逊云服务“AWS”以投资巨大和亏损严重而著称，但该公司已在这项业务中实现持续盈利。亚马逊和微软等市场领先的云服务供应商营收迅速增长，反映了全球范围内各家公司正转向由它们为其托管数据，让传统软件和硬件供应商望尘莫及。第三季度，亚马逊最大市场——北美地区（美国、加拿大）的净销售额为188.7亿美元，比去年同期的150亿美元增长26%美国时间周四，亚马逊股价收盘于818.36美元，今年以来已累计上涨21.1％。在过去52周，该公司股价最高为847.21美元，最低为474.00美元。
