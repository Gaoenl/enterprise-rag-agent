中新网山东海阳4月23日电 (王娇妮侯俊南)东方航天港产业发展大会、地球空间信息技术协同创新中心工作会议、东方航天港产融合作大会……4月22日，在第八个中国航天日即将到来之际，山东省海阳市举办系列会议，助力航空航天事业发展。据悉，自东方航天港项目在山东海阳建设以来，当地以发射带动制造应用，正崛起中国首个百亿级商业航天产业集群。会议期间，烟台国丰申万航天投资基金正式启动，将加快组建总规模20亿元的航天产业基金，撬动更多社会资本投入，精准投资产业链上下游，以资本赋能航空航天产业发展。与此同时，地球空间信息技术协同创新中心智能遥感卫星烟台基地揭牌，将开启“东方慧眼”智能遥感星座项目建设新征程，带动海阳卫星制造及相关配套产业突破发展。会议期间还邀请院士专家围绕空天信息应用、天地往返运输、海上商业发射等领域进行主旨演讲，献策航空航天产业创新发展。值得一提的是，沿着山东海阳航天大道一路向南，一座航天科普教育大型综合体拔地而起。这里将建成集“发射观礼+航天科普教育研学”为一体的沉浸式游览体验中心，非发射期间作为航天科普教育基地向社会公众开放。2019年6月，长征十一号固体运载火箭以海阳港作为出海母港，成功实施中国首次海上发射。截至目前，东方航天港累计成功保障中国海上发射任务5次，发射卫星37颗。当地已签约航空航天产业项目15个，涵盖星箭研发制造、空天信息应用、航天文旅产业等领域。(完)（文章来源：中国新闻网）
