总建筑面积超3万平方米！宝山区档案馆新建工程预计2025年1月建成2023-07-20 18:34来源：澎湃新闻·澎湃号·政务字号以硬件设施提升为基础，宝山区档案馆的综合面貌将全面升级。在杨行镇，宝山区档案馆新建工程正在如火如荼进行。目前这个项目的主体结构已经建到了地上3层，整个工程预计在2025年1月按计划完成。点击观看视频建设中的宝山区档案馆位于区卫健委的西侧，它东起月明路、西至规划五路、南至松傲路，与新建成的杨行体育中心相隔一片绿化带。该工程于2022年12月中旬正式开工，项目总投资约36147.26万元，用地面积为13150.2平方米，总建筑面积为30594.8平方米。其中地上建筑面积25458.4平方米，地上建筑为8层；地下建筑面积5136.4平方米，地下为1层。绿地面积3950.2平方米，绿地率30%。宝山区档案馆项目主要是一个单体，地下1层、地上8层。建筑高度40米，单体最大跨度16.8米。项目建设内容包括地下停车库、非机动车库及设备用房、档案库房、城建档案用房、对外服务用房、档案业务及技术用房、办公室用房等。项目于今年5月17日完成了地下室结构施工，目前正在进行主体结构施工。宝建集团项目相关负责人表示：“目前，二层钢结构的顶板在铺设钢筋，将在近日完成。钢柱安装也在同步进行，本周末，钢柱的安装将完成到五层。框架结构现在是顶板二层铺设完成，目前在搭设排架。”据了解，宝山区档案馆项目预计在今年11月完成主体工程施工，2024年1月完成二次结构施工，2025年1月完成所有实物工作量并验收。记者：段小龙 仲昱峰原标题：《总建筑面积超3万平方米！宝山区档案馆新建工程预计2025年1月建成》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
