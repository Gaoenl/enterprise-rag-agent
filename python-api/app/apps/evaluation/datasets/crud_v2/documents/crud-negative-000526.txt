“国家的长期护理保险政策,给我们家庭提供了保障。”家住山东省德州市临邑县恒源街道李家胡同村王老太向《农村金融时报》记者说道。据了解,王老太的老伴马某因病长期卧床,她不得不长年累月照顾老伴。前不久听了临邑县医保局和中国人寿财险宣传的居民长期护理保险政策后,她第一时间提出投保申请。目前,马某一个月内已经享受了4次居家护理服务,王老太对护理人员的护理水平和态度赞不绝口。据山东省德州市临邑县医保局局长王殿峰介绍,去年7月份,国家卫生健康委、国家发展改革委等11个部门联合发布《关于进一步推进医养结合发展的指导意见》,明确提出稳步推进长期护理保险制度试点,适应失能人员基本护理保障需求。作为试点县,临邑县委、县政府将推进长护保险政策作为今年18件民生实事之一,从县医保资金中调拨1400余万元作为专项投保资金。今年初,中国人寿财险德州市中心支公司凭借品牌和服务实力,成功获得临邑县长期护理险的独家承办资格。该项目承保期限为三个年度,保费由职工基本医保统筹、参保个人、财政按比例承担,涉及职工29.5万人、居民42万人。为将这一惠及民生、覆盖全民的事办好,临邑县医保局、中国人寿财险德州市中心支公司、部分医疗机构代表专门赴外地学习取经,全面掌握了参保人申办流程、失能人员评定、档案管理、护理服务机构管理及对失能人员失能状态核查等重点环节事项,以便在确保医保基金使用合规合理的前提下,让失能人员享受到最优质服务。为让人民群众真正了解这一政策的意义,临邑县医保局、中国人寿财险及各医疗经办机构工作人员协同联动,采用广播电视、赶大集、进社区、宣传栏等多种形式宣传。在失能人员等级评定环节,参与评定的专家从德州市医疗专家库中随机抽取。县医保局对各评定专家严格管理,制定评定工作流程,确保评定科学、规范。失能人员家属向医疗机构或经办机构递交评定申请后,由中国人寿财险与县医保局组织专家严格按照评定标准进行评定,保证失能人员身份的真实、有效性。目前,全县第一批187名被认定为长期护理失能等级三级及以上的重度失能人员,已经按规定享受长期护理保险待遇。为规范高效地为失能人员提供优质上门护理服务,临邑县医保局、中国人寿财险联合召开长期护理保险上门服务操作实训培训会,邀请市县福利服务中心专家对长期护理服务定点机构护理员进行理论及实操培训;中国人寿财险工作人员对信息登记、理赔服务记录、服务打卡等内容进行了详细讲解。临邑县医疗保险事业中心主任宫庆才介绍,临邑县长期护理保险分为职工类和居民类两种类型,保障形式为医疗专护、机构护理和居家护理三种。医疗专护和机构护理可为参保人员提供长期24小时连续护理服务,居家护理可按病情需要享受护理人员上门提供护理服务,实行基本生活照料服务+基础护理项目上门服务模式。保险待遇不设起付标准,实行限额管理,根据保障形式和失能等级不同,确定不同待遇水平。失能人员为特困人员、低保对象等医保帮扶对象的,保险基金支付比例还可提高至90%。中国人寿财险德州市中心支公司总经理韩立霞表示,公司将充分发挥专业优势和技术优势,按照医保部门的要求和群众的需求,加大政策宣传力度,加强护理人员巡查监督,科学规范运用医保基金,采取“线上+线下”相结合的服务形式,让这一民心工程办到群众的心坎上,实现群众、社会、政府三方满意。(文章来源:证券日报)
