据中央纪委国家监委7月25日消息，经北京市委批准，北京市纪委监委决定给予北京知识产权法院原党组书记、院长宿迟（正局级）开除党籍处分。通报称，经查，宿迟纪法意识淡漠，搞钱色交易；执法犯法，利用职务上的便利，为他人谋取利益，或利用职权、地位形成的便利条件，通过其他国家工作人员职务上的行为，为他人谋取不正当利益，非法收受他人财物。通报称，宿迟严重违反党的纪律，构成严重职务违法并涉嫌受贿犯罪，且在党的十八大后不收敛、不收手，性质严重，影响恶劣，应予严肃处理。公开简历显示，宿迟，男，1957年1月生，汉族，北京市人，1986年5月入党，1976年3月参加工作，北京大学法律系法律专业大学毕业，在职研究生（中国政法大学诉讼法学专业），法学博士。宿迟（资料图）公开资料显示，宿迟曾任北京市高级人民法院民庭副庭长、副处级审判员，民庭副庭长、正处级审判员，北京市中级人民法院知识产权庭庭长、审委会委员，北京市第一中级人民法院党组成员、副院长，北京政法职业学院副院长。其中，北京市中级人民法院知识产权庭是全国首家知识产权审判庭。2013年7月，宿迟任北京市第二中级人民法院党组副书记、副院长。2014年8月31日，十二届全国人大常委会第十次会议通过关于在北京、上海、广州设立知识产权法院的决定。北京知识产权法院是全国首家知识产权法院。2014年11月，宿迟出任首任北京知识产权法院院长、审判委员会委员、审判员，成为全国首个知识产权法院的院长。2015年2月，北京知识产权法院召开建院后第一次全院大会，宿迟以“党风廉政建设”为主题讲了廉政党课。当时，宿迟表示，“做好党风廉政建设和反腐败工作，保证知识产权审判队伍的廉洁性，是当前全院工作的重中之重，也是将建院第一次全体大会主题确定为廉政党课的用意所在。”宿迟2018年初退休。2018年11月，宿迟接受采访时还表示：“退休了，咱也不能闲着。早有出版社约了稿，我准备出本书，就讲讲中国知识产权司法审判25年。”不料4年后，2022年8月，北京市纪委监委通报其涉嫌严重违纪违法，正接受纪律审查和监察调查。（极目新闻综合中央纪委国家监委，人民网，北京青年报）（来源：极目新闻）更多精彩资讯请在应用市场下载“极目新闻”客户端，未经授权请勿转载，欢迎提供新闻线索，一经采纳即付报酬。举报/反馈
