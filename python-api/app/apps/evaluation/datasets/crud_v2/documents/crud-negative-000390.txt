参考消息网11月20日报道 据美国《纽约时报》网站11月18日报道,面对美国越来越不愿向乌克兰提供更多军事援助的局面,欧洲国家领导人正在着手填补这一缺口,并承诺会给予基辅新的支持。包括德国、英国和挪威在内的一些欧洲国家正在扩大武器生产,尤其是乌克兰迫切需要的炮弹。德国此前宣布,计划在2024年把对乌克兰的援助规模增加一倍,达到85亿美元。此外,欧盟国家还加紧额外训练1万名乌克兰军人,让目前受过训练的军人总数达到4万人。荷兰国防大臣卡伊莎·奥隆格伦本月在一个论坛上表示:“我们真的必须加大行动力度。”但是这对乌克兰来说或许起不到多大安慰作用,随着冬季日益临近,乌克兰对俄罗斯军队的反攻已陷入停滞。欧洲无力兑现援助承诺目前出现的一个令人担忧的迹象是,欧盟看来很可能无力保持对乌克兰的支持力度。欧洲此前曾大张旗鼓地承诺在一年内向乌克兰捐赠100万发155毫米口径炮弹,不过外界普遍预计最终提供给乌克兰的炮弹达不到这个数量。德国国防部长鲍里斯·皮斯托里乌斯说:“达不到100万这个数字——我们必须作出这样的假定。”他承认欧盟无法在明年3月的最后期限到来时兑现承诺。欧洲官员长期以来一直担心,由于共和党人越来越反对美国向乌克兰提供军事支持,一旦拜登总统不能赢得连任,美国在资助乌克兰继续作战上发挥的主导作用会遭到削弱。欧盟外交与安全政策高级代表何塞普·博雷利·丰特列斯最近表示:“我们欧洲人必须在政治和物质上愿意去帮助乌克兰并且持续这样做,甚至要在美国的支持减弱——现在看来这种可能性很大——的情况下,从它手中接过这项工作。”俄罗斯2022年2月对乌克兰的入侵震动了欧洲领导人,他们意识到面对在自己后院发生的战争,他们的军队和国防工业准备不足。瑞典国防大臣波尔·荣松称这次事件“粗暴唤醒”了欧洲,不过也让大多数欧洲国家团结起来支持乌克兰——在许多欧洲国家看来,乌克兰类似于俄罗斯和北约之间的缓冲区。爱沙尼亚高级外交官约纳坦·弗谢维约夫在接受乌克兰媒体采访时说:“如果西方停止支持乌克兰,乌克兰将不复存在,欧洲的安全架构也将不复存在。”尽管目前欧洲还没有在支持乌克兰的问题上达成一致,比如斯洛伐克已表示将停止对基辅的军事援助,不过仅在17日这天,荷兰、芬兰和立陶宛都宣布了对乌克兰提供新的防务援助。最大一笔援助来自荷兰政府,它承诺明年将向乌克兰提供超过21亿美元的援助。俄乌战事转向工业战争据西班牙皇家埃尔卡诺研究所网站11月15日报道,乌克兰战争对西方军事工业的能力提出了考验。冷战结束后,对欧洲国家武装部队的投入大幅减少,而美国则重质不重量。然而,高强度战争重回欧洲土地,导致北约盟国不得不改变其军事战略范式,以便能够支撑其乌克兰伙伴对抗俄罗斯的战争努力。苏联解体后,欧洲国家纷纷决定大幅减少对其武装部队的投入,于是其军火库和军用物资生产能力几十年来大幅减损。在这个问题上,值得一提的是,几乎所有欧洲国家都没有遵守北约规定的国防开支最低占比(GDP的2%),许多欧洲国家政府已承诺修正这一问题。自诩为“世界警察”的头号大国美国则承担不起大幅削减国防预算的代价。然而,这并不意味着其武装部队和工业基础已经为一场像乌克兰战争这样的战争做好了准备。根据战略决策,华盛顿转向以技术、精度和质量为导向,而非以数量为导向的军队。乌克兰转向了一场工业战争,在军事物资生产方面拥有更多资源和能力的一方将在其战场上拥有巨大优势。数量在这场战争中相当重要。北约军工产能面临挑战几个月前,北约秘书长延斯·斯托尔滕贝格宣称,乌克兰的弹药消耗速度高于北约能够生产的速度。西方援助及其库存的数据显示北约、特别是欧洲国家军火库处于岌岌可危的境地。截至7月,华盛顿已向乌克兰提供了430亿美元的军事援助,其中许多来自美国自己的储备,而不是新生产的武器装备。可能没有任何一个欧洲国家有能力长期维持常规战争。鉴于欧洲各国武装力量及其工业基础的特点,即使欧盟27个成员国团结起来,可能也不能确保将冲突维持下去。面对乌克兰弹药短缺的局面,意识到有必要长期维持对基辅援助的欧盟委员会制订了三阶段的计划。第一阶段,欧洲各国政府要向乌克兰交付价值10亿欧元的库存弹药;第二阶段,欧盟准备联合为乌克兰购买10亿欧元的弹药;第三阶段,制订了在一年时间内生产100万枚155毫米口径炮弹的联合计划。缺乏高素质劳动者和关键原材料的欧洲军工面临着巨大的挑战。与其他行业的情况一样,防务企业在获取必要的原材料方面存在问题。此外,增加军火生产的战略也造成了供应链的瓶颈,因为许多公司都寻求生产同样的产品。(编译/李凤芹)
