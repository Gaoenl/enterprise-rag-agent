7-23 03:46，正文：                                                                                                                                                                                                                                                                                                    扬子晚报讯(记者 汤敏)球王驾到！7月22日上午，球王梅西迎来在新东家迈阿密国际的首秀，他利用直接任意球攻入绝杀进球。在北美联赛杯小组赛迈阿密国际主场迎战墨西哥蓝十字队的比赛中，梅西第54分钟替补出场，带领球队以2：1险胜。 主帅马蒂诺把梅西和布斯克茨放进本场比赛的替补名单，两位前巴塞罗那队长尤其是球王梅西的一举一动都格外引人注目。到了第54分钟，梅西终于替补出场，身披10号战袍，戴着队长袖标，和他一起替补出场的是布斯克茨。梅西在运动战方面还需要与队友磨合，到了伤停补时最后时刻，梅西左脚主罚任意球越过人墙飞入球网，门将古蒂诺鞭长莫及。迈阿密国际在美职联已经连续11场不胜，10场不胜时已经创下队史最差纪录，梅西带领球队重返胜利轨道。蓝十字队在墨西哥联赛以三连败开局，在积分榜排名垫底。 【编辑:付子豪】                                                                                                                              更多精彩内容请进入体育频道
