今年上海国际电影节首次特别设立“科幻电影周”单元。6月11日上午，上海国际电影节“科幻电影周”主旨论坛暨上海科技影都发布会在上海松江区举行，集聚国内外科幻电影主创、科学顾问、行业代表，共同探讨中国科幻电影的发展路径。本届科幻电影周系列活动由主题论坛、主题展映和户外放映等活动组成。主题论坛共3场，分别是“科幻电影周主旨论坛”“科影融合论坛”和“电影科技论坛”。郭帆、王红卫、陆川等中国科幻电影的核心创作者，国际知名视效艺术家彼得·贝布，以及诸多优秀科幻电影的概念设计者等幕后主创及科学顾问围绕“科幻电影的国际视野与时代语境”“科幻电影：想象力与科学精神”以及“科幻电影驱动电影工业升级”等话题展开探讨。主题展映则由三个专题“火星纪事”“全球新作”和“经典回顾”共计11部展映影片组成，不仅关注世界科幻电影发展，也着力呈现中国早期电影人对科幻电影创作的探索轨迹。此外，今年科幻电影周也在辰山汽车影院对“经典回顾”主题中的三部影片《珊瑚岛上的死光》《错位》以及《霹雳贝贝》进行户外展映，满足科幻影迷和大众影迷的观影需求。11日活动现场，上海科技影都影视协拍产业联盟宣布成立，并举行了上海科技影都元宇宙创制基地启动仪式、影视产业知识产权应用与保护（松江）基地揭牌仪式、长三角国际影视中心启用暨仓城国家文化出口基地进驻启动仪式等。当天也发布了《松江区关于促进上海科技影都影视产业高质量发展的若干规定》，包括支持影视企业上市、支持影视新兴业态、鼓励影视人才引进和培养等影视产业重点环节的具体扶持措施。本届上海国际电影节科幻电影周还将推出“未来引擎· 科幻电影年度展望”，发布未来几年内值得关注的中国科幻电影项⽬信息。（总台记者 胡祎玮 罗安敏）来源：央视新闻举报/反馈
