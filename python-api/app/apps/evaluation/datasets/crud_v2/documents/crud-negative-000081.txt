"8月3日下午，韩国京畿道城南市盆唐区发生一起“无差别行凶案”，事件已致1死13伤。凶案发生后，韩国网络上出现了10多篇威胁将进行模仿犯罪的“杀人预告”。8月4日，韩国又发生多起持刀伤人事件。韩国总统尹锡悦下达指示，要求动员全部警力予以超强硬应对。男子百货商店内持刀行凶当地时间8月3日17时55分左右，韩国京畿道城南市盆唐区地铁书岘站附近，一名23岁的崔（Choi）姓男子驾驶一辆车冲向人行道，造成5名行人受伤。随后，该男子又在地铁站附近的一家百货商店内持刀行凶，造成9人受伤。当地媒体称，男子行凶时“不分对象，无差别行凶”。当天18时5分左右，警方将这名男子紧急逮捕，据了解，嫌疑人没有对自己的犯罪动机进行特别的陈述，警方还在进行详细调查。8月4日，中国驻韩国大使馆方面向记者表示，该案目前仍在调查中，暂时没有收到中国公民伤亡报告。案发次日又发生多起持刀伤人事件就在这起“无差别行凶”案发生的第二天，8月4日，韩国又发生多起持刀伤人事件。4日上午，韩国大田市的一所高中发生一起袭击事件，一名男子持刀闯入校园，刺伤一名高中教师，嫌疑人已被捕。同一天，首尔江南高速巴士客运站出现一名20多岁的持刀男子，韩国警方接警6分钟后，将其紧急抓捕，没收了其随身携带的两件凶器。据警方透露，事件造成一名保安受伤，该男子的动机正在调查中。网上出现十多篇“杀人预告”帖“今晚7时将在江南站杀死100人”……韩媒称，在一系列的持刀伤人案件发生后，网络上还出现了一系列类似于“要在人群密集区域发动类似袭击”的匿名威胁。据韩国警方8月4日通报，自当地时间3日18时以后，网上总计出现了15篇预告行凶地点，威胁将实施无差别袭击的帖文，其中12篇“杀人预告”把首尔市区定为行凶地点，甚至还有人把行凶地点定在8月3日发生案件的城南市盆唐区。韩国警方3日成立了专案小组，表示将严惩发布“杀人预告”的人员，同时在预告的地点部署大批警力预防凶案发生。警方开展特别治安行动当地时间8月4日下午，韩国警察厅厅长尹熙根表示，为应对恶性犯罪的发生，将展开特别治安行动，将对疑似持凶器者和异常行为者进行筛选检查。特别治安行动是指，在日常治安行动很难维持治安的情况下，警方集中投入警力和装备的措施。这是韩国首次发布特别治安行动命令。韩国警察厅厅长尹熙根 资料图尹熙根指出，一旦发生持凶器伤人事件，一线警员要积极利用枪支或设备维持治安，对于为了压制犯罪而使用枪支的警察，将积极适用免责规定。警方计划将247个人流密集的广场、地铁站、百货商店等设定为重点场所，安排超过1.2万名警力进行巡逻。此外，警方还将在韩国13个市、道警察厅部署全副武装的反恐特警，一旦发生持凶器伤人事件，将迅速出动到现场。尹熙根同时强调，警方将集中全部调查力量，迅速确认、检举发帖人员，严厉惩罚那些发布威胁性消息或在网上传播假新闻的人。综合央视新闻  红星新闻（ID：cdsbnc）  南方都市报（ID：nddaily）  新闻坊（ID：stvxwf）举报/反馈",
