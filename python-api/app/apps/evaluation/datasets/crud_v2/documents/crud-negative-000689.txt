根据交通运输部办公厅《2022年度国家公路网技术状况监测实施方案》文件要求，6月15日至21日，交通运输部检测组在我省开展国家公路网技术状况监测工作。6月16日，交通运输部2022年国家公路网技术状况监测项目（江西站）首次会议在南昌举行，省交通运输厅党委委员、副厅长王昭春主持会议并作公路养护管理重点工作情况汇报。部监测工作组负责人简述了监测工作内容和流程。厅机关有关处室、省综合交通中心、省交通执法局、省交通投资集团相关负责人参会。部监测工作组负责人指出，开展国家公路网技术状况监测工作是落实党中央、国务院、交通运输部部署的一项重大举措，是服务交通强国建设的需要，是提升行业治理能力和治理体系现代化管理的需要，有利于充分了解掌握我国公路网、桥梁隧道长期性能变化规律，为交通运输部出台更加科学专业的养护管理政策提供智慧。同时要求，受检单位要做好配合工作，并按照各地疫情防控工作要求，落实好相应防控措施，共同完成好此次监测工作。据悉，此次监测主要内容为养护管理检查、路况抽检、重点桥梁监测、重点隧道监测、公路交通安全设施评估等五个方面。通过现场抽签，国家公路网技术状况监测工作组于6月16日-20日赴实地开展监测检查工作。预计将在6月21日召开2022年度国家公路网技术状况监测项目（江西站）末次反馈会。（温静）【来源：江西省交通运输厅】声明：转载此文是出于传递更多信息之目的。若有来源标注错误或侵犯了您的合法权益，请作者持权属证明与本网联系，我们将及时更正、删除，谢谢。 邮箱地址：newmedia@xxcb.cn举报/反馈
