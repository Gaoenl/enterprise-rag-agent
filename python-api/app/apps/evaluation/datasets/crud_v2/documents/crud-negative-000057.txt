，正文：7月25日晚，一款名为财富Plus的APP公布了2023年中国500强企业排行榜，世界500强企业排行榜将于8月2日发布，两个榜单的评选标准相同。今年上榜的500家中国企业在2022年的总营业收入达到15万亿美元，净利润达到7171亿美元。 国家电网有限公司以5300亿美元的营收位列榜首，中国石油和中国石化分别排名第二和第三，中国建筑集团位列第四。苹果最大代工企业鸿海精密位列第五，是排名最高的台湾公司。中国平安保险（集团）股份有限公司是前十名中唯一的大陆民营企业，排名第九。 新能源领域的两家头部公司，宁德时代和比亚迪，营收增长显著。宁德时代营收达到488亿美元，同比增长141%。比亚迪营收增长92%，达到630亿美元，归母净利润同比增长超过四倍，达到24亿美元。 在盈利能力方面，最赚钱的10家上榜公司中，除五家商业银行和中石油、中海油、中移动之外，台积公司和腾讯也进入了前十位。台积公司以333亿美元净利润排在利润榜第五位，腾讯的净利润虽然比去年下降了19%，但仍以超过279亿美元的净利润排在利润榜第六位。 净利润率方面，排名最高的五家公司中，有三家是锂电池相关行业的企业，分别是天齐锂业、青海盐湖工业和江西赣锋锂业集团，其中天齐锂业的净利润率高达59%，位列利润率榜第二位。利润率榜榜首是九安医疗，凭借核酸检测试剂在去年的强劲销量，该公司的利润率超过60%。 在中国500强中，共有64家公司未能盈利。亏损榜前十家公司中，有三家航空公司，四家房地产公司。值得一提的是，中国的三家互联网代表企业，除京东的营收有约5%的增长外，阿里巴巴和腾讯的营收与去年相比均有所下降。而拼多多营收同比增长约39%，净利润增长近三倍，盈利超过46亿美元。 在上榜的车企中，新势力“蔚小理”均登上了榜单。同时，比亚迪营收增幅最大，同比增长92.4%。上榜的15家车企中，有7家未能实现营收增长。本文属于原创文章，如若转载，请注明来源：2023《财富》中国500强排行榜发布https://news.zol.com.cn/826/8266646.html
