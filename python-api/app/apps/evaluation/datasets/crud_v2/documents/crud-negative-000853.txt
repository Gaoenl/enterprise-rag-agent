2023-08-05，正文： 光明日报河北涿州8月4日电（记者耿建扩、陈元秋 通讯员张岩）8月4日上午10时，在河北省涿州市翡翠滨江小区院内，8台应急电源车“嗡嗡”作响，该小区电力已基本得到保障。“我们昨天中午到达涿州集合点，晚上10点领到任务，来翡翠滨江小区保障供电。”国网山东电力应急发电组负责人侯乃乾介绍，经过5个多小时的抢修，8月4日凌晨4时左右小区基本用电恢复正常。 “能来电太好了，整整两天没有电，手机也没法用。这么热的天，大老远跑过来支援，真是太感谢了。”居民肖季凤说，来电后赶紧联系了亲戚、朋友报个平安。 现场，侯乃乾和队友们紧盯供电设备，随时检修。“我们这次的27台应急电源车从山东各地向涿州集结，只要水位下降我们便能进入小区供电。”侯乃乾介绍，应急电源车受限于积水问题，待小区水位下降后，随时进入小区为居民恢复基本用电。 天气炎热，工作人员身着厚厚的工装，守在应急电源车前。“我们会等到小区供电全部正常了才撤离。”侯乃乾表示，一定完成好这次供电保障任务。 据了解，目前，国家电网公司调集90余台应急电源车抵达涿州，保障当地受灾群众用电。 《光明日报》（2023年08月05日 02版） 					                                                                                    	[                      	责编：田媛 ]
