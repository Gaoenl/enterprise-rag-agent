新华社澳门8月1日电(刘刚 李松)解放军驻澳门部队1日在氹仔军营举行招待会,庆祝中国人民解放军建军96周年,感谢澳门特区政府、中央驻澳机构和澳门社会各界长期以来对驻军工作的关心支持。全国政协副主席何厚铧,澳门特区行政长官贺一诚,澳门中联办主任郑新聪,外交部驻澳门特派员公署特派员刘显法,解放军驻澳门部队司令员于长江,澳门特区立法会主席高开贤、终审法院院长岑浩辉担任主礼嘉宾。上午11时,招待会正式开始,各界来宾共同观看驻澳门部队近年来全面建设和履行防务纪实片。于长江和贺一诚分别致辞。于长江在致辞中回顾了中国人民解放军96年的光辉历程。他表示,解放军驻澳门部队进驻以来特别是党的十八大以来,坚决贯彻党中央和中央军委决策部署,坚决贯彻习近平主席两次视察重要指示精神,认真落实“一国两制”方针和澳门特别行政区基本法、驻军法,出色完成以履行防务为中心的各项任务,展示了我军威武文明之师良好形象。驻澳门部队将牢记习近平主席嘱托,始终与澳门同胞同呼吸、共命运、心连心,始终坚定支持特区政府依法施政,始终坚定支持澳门经济社会发展,当好党和人民放心、澳门同胞信赖的忠诚卫士,为推进“一国两制”在澳门的成功实践作出新的更大贡献。贺一诚致辞表示,驻澳部队是“一国两制”事业的建设者和捍卫者,为维护澳门繁荣稳定发挥定海神针的作用。二十多年来,驻澳部队始终坚决贯彻“一国两制”方针,严格遵守澳门基本法、驻军法,坚定支持特区政府依法施政,积极参加社会公益事业,出色完成各项任务,用自己的行动塑造了文明之师、威武之师的良好形象,赢得了广大澳门居民的衷心爱戴。特区政府将一如既往加强与驻澳部队的紧密联系和交流合作,坚定支持驻澳部队各项建设,积极为驻澳部队完成各项任务创造更好条件。澳门特区政府主要官员,中央驻澳机构和驻澳中资机构负责人,澳区全国人大代表、政协委员,澳门爱国爱澳社团等约200名各界人士应邀出席招待会。
