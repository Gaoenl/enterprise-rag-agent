8-15 18:23，正文：                                                                                                                                                                                                                                                                         中新社东京8月15日电 (记者 朱晨曦)今年8月15日是日本战败78周年纪念日，日本首相岸田文雄当日通过代理人以“自民党总裁”名义向靖国神社供奉“玉串料”(祭祀费)。  当日，日本经济安全保障担当大臣高市早苗参拜了靖国神社。此外，日本自民党政调会长萩生田光一、前环境大臣小泉进次郎、前防卫大臣稻田朋美以及70多名“大家一起参拜靖国神社”跨党派国会议员联盟成员当天也参拜了靖国神社。  靖国神社位于东京千代田区，供奉有包括东条英机在内的14名二战甲级战犯。长期以来，日本部分政客坚持参拜靖国神社，遭到日本国内爱好和平人士和国际社会的强烈反对，也导致日本与中韩等亚洲国家关系紧张。(完)  【编辑:甘甜】                                                                                                                              更多精彩内容请进入国际频道
