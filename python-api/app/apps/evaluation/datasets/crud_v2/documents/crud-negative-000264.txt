2023-08-07 18:04，正文：原标题：大米禁令后，印度会把手伸向食糖吗？印度的降雨不足也影响到了糖的产量，市场开始担心印度政府颁布针对部分大米出口的禁令后，将轮到食糖了？8月2日，据印度制糖企业协会(ISMA发布的消息，由于主要产糖邦的降雨量减少可能会影响单产，即将于10月1日开始的2023/24产季年度印度糖产量预计下降3.3%，预计产糖仅为3170万吨。这也意味着，新产季的糖产量或将连续第二年下降。8月7日，彭博社报道称，产量的下降可能会限制印度的食糖出口。现在，印度政府已经限制小麦和部分大米的出口，来保证国内供应并降低价格。彭博社粉丝指出，印度此前就限制过糖的出口。在2022/23产季，印度的食糖出口量被限制在610万吨，而前一榨季为1100万吨。分析师预计，根据目前的产量推测，很可能下一产季只会允许出口200万至300万吨食糖，还不及这一产季的一半，或者印度政府将禁止食糖出口，这都两种情况会进一步推高全球糖价：热带研究服务公司糖和乙醇部门主管Henrique Akamine表示，大米出口禁令是一个明确的信号，这意味着印度政府担心粮食安全和通货膨胀。现在担心的是，“政府可能会效仿大米禁令，对糖采取类似的措施”。印度制糖企业协会主席Aditya Jhunjhunwala表示，尽管如此2023/2024榨季的糖产量将下滑，但仍可以满足印度供国内对糖的需求。与此同时，印度或将更多的糖用于生物燃料。该协会预计约有450万吨糖将用于生产乙醇，同比增长9.8%。StoneX 糖和乙醇主管 Bruno Lima 表示，按照目前的产量水平，印度可能不会释放任何出口。“我们必须密切关注将有多少糖被用于乙醇生产。”印度政府需要对明年榨季产量有确切了解，才会决定是否允许下一季的糖出口。预计要到2024年上半年才能决定印度是否允许下一季的糖出口。今年的季风表现以及接下来两个季节（2023/2024榨季和2024/2025榨季）的甘蔗产量将是关键。返回搜狐，查看更多责任编辑：
