2023-07-30 20:33，正文：原标题：南县青树嘴镇组织返乡大学生开展志愿服务活动返乡大学生志愿者开展防溺水知识宣讲。志愿者开展禁毒知识宣传。红网时刻益阳7月30日讯（通讯员 汤玉成）7月28日，南县青树嘴镇乡村振兴人才服务站组织返乡大学生代表开展“智汇潇湘，鸿雁之约”人才服务活动，让大学生志愿者在社会实践中开阔视野和眼界、练就过硬本领、贡献青春力量。活动现场，20余名返乡大学生、青年志愿者、蓝天救援队、巾帼志愿者禁毒工作者等为青少年儿童开展防溺水知识宣讲、妇女儿童权益保护宣传、交通安全、禁毒宣讲、公益小课堂等一系列社会实践活动。工作人员为参与活动的小朋友们发放防溺水安全知识手册，普及救生设备使用知识，防溺水急救培训知识等，进一步树牢防溺水未成年人防溺水安全意识。志愿者们还通过案例讲解、交流互动、观看教育片等方式，进一步加深小朋友们对道路交通安全知识，毒品预防知识的了解，切实提高小朋友们安全意识和自我保护能力。在实践活动中，返乡大学生志愿者们各司其职，以实际行动充实暑期生活，用青春力量为家乡建设添砖加瓦。在服务家乡、奉献社会的过程中增强责任感和使命感。“作为一名青年大学生，我很荣幸能参加此次社会实践活动，积极投入家乡的发展和建设中是时代赋予青年的责任和使命，也是青年人精彩人生的开始，我会立足岗位，用青春的热血和汗水奉献自己的力量。”下一步，青树嘴镇将继续以乡村振兴人才服务站为阵地，推动农村青年人才资源返乡创业，促进各类青年人才投身到家乡建设，着力打造一支懂农业、爱农村、爱农民的青年人才队伍。来源：时刻新闻作者：汤玉成 编辑：岳敬然 本文链接：https://yiyang.rednet.cn/content/646741/74/12912330.html返回搜狐，查看更多责任编辑：
