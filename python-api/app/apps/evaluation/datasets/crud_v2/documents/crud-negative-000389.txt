来源：澎湃新闻，正文：                                                                 宁波工程学院设立“毕业生之家”，在毕业第一年为应届毕业生提供低价宿舍，帮助他们度过适应期。澎湃新闻（www.thepaper.cn）8月4日从学院了解到，“毕业生之家”2020年起设立，是该校翠柏校区的2栋学生公寓，到目前已接待四届毕业生，累计入住500余人。   据介绍，该校将空闲宿舍归整为2幢公寓作为“毕业生之家”，有单人间、双人间共170余间，房租最高每间350元/月，配有公共厨房和洗衣间。每年5月起，落实就业或自主创业的毕业生可以提前看房，确认意向后在手机上签约入住，并可通过办理校友卡，继续使用学校食堂、运动场地等。“出校门步行3分钟就是超市、菜场、商铺，步行5分钟是地铁口，工作生活十分方便。”学院工作人员表示，应届毕业生的租房预算有限，找工作也不易，这一举措也是为帮助他们顺利度过第一年的适应期。                                   【责任编辑：胡庆章】
