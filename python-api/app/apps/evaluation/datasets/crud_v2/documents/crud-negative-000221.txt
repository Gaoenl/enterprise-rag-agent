為吸引青年人留京就業創業創造有力的服務保障，北京自去年起面向應屆畢業大學生推出保租房青年公寓試點。今年，北京共籌集3000余套(間)青年公寓，截至目前所有房源已裝修完畢並配備必要的家具家電以及寬帶網絡，畢業生可以拎包入住。今天，記者從北京市住房城鄉建設委了解到，為更好解決新市民、青年人特別是新畢業大學生的住房問題，北京市連續五年開展“畢業季租房服務進校園”活動，為畢業生群體提供減免押金、租金月付、法律咨詢等服務。去年，北京面向應屆畢業大學生推出保租房青年公寓試點，為吸引青年人留京就業創業創造有力的服務保障。今年，北京進一步加大保租房青年公寓房源供應，用心用情解決新畢業大學生走出校園走向社會的階段性住房困難問題。考慮到中心城區、平原新城既有眾多高校，畢業生數量多，又有大量重點功能區，就業聚集等因素，在這些區域開展保租房青年公寓項目有助於實現產城融合、職住平衡。各區和北京保障房中心有限公司積極籌備項目，結合本區實際編制工作方案，共籌集3000余套(間)青年公寓。截至目前，所有房源已裝修完畢，並配備必要的家具家電以及寬帶網絡，畢業生可以拎包入住。5月8日，豐台區率先發布2023年保租房青年公寓面向畢業大學生專項配租公告，萬科泊寓草橋項目300間房源面向在豐台區行政區域內就業且無房的近三年畢業生租賃，6月3日已辦理選房入住。6月底，大興區、朝陽區也先后發布配租公告。7-8月，預計經開區、昌平、房山、通州、順義將陸續啟動配租。和去年首次試點大多面向當年應屆畢業大學生相比，今年所有配租房源全部或優先面向近三年畢業的大學生，北京保障房中心有限公司持有的燕保·平樂園家園項目還實現了常態化配租，北京市行政區域內就業或創業、在京無房、學歷為全日制本科及以上、年齡不超過35周歲的青年均可申請，每月16日至19日登記。以上項目專項配租公告將在相關區政府和北京保障房中心有限公司官方網站發布，有需求的畢業生可及時關注並提交申請。目前朝陽區仍在登記期間內，7月10日17:00截止。經開區7月10日-7月16日申請登記。有登記意向的畢業生可自行登錄北京保障房中心有限公司網站或APP，進入保障性租賃住房登記界面了解房源情況，下載及操作方式可查詢相關公告。(責編：李依環、熊旭)分享讓更多人看到
