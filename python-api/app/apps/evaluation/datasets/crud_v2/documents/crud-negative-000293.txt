近期,驻阿德莱德总领馆领区连续发生中国留学生遭遇“虚拟绑架”类电信诈骗的案件,受害人经济损失巨大,精神受到创伤。诈骗团伙冒充驻澳大利亚使馆、国内公检法人员称当事人涉嫌违法,诱导当事人在其网络平台上查询“真伪”,随后要求当事人下载指定的Whatsapp后,多人配合轮换使用该APP进行语音、视频笔录等所谓“案件”审理工作,获得当事人证照、家庭关系、视频、音频等信息,并签署“保密协议”、“欠赌还款协议”。在当事人无法足额提交“保证金”、“欠赌还款协议”款项后,威胁当事人配合办案,尽快离家与外界断绝联系。确认当事人离家后,不法分子通过当事人微信、电话,向当事人亲属发送事先要求当事人撰写的“欠赌还款协议”、拍摄的当事人被绑架视频,索要“巨额赎金”。驻阿德莱德总领馆再次提醒领区中国公民对“虚拟绑架”等类型电信诈骗提高警惕。切记驻外使领馆工作人员、公检法人员不会通过电话或邮件等方式办案,凡是自称驻外使领馆或国内公检法人员,以涉嫌相关违法犯罪为由,要求将资金打入“安全账户”或“取保候审保证金账户”的,都是诈骗!凡是要求必须离家、不告诉任何人、遵守保密协议并且在网上接受调查的,都是诈骗!如遇相关情况,请立即向当地警方报案,并联系学校及总领馆求助。如款项系通过国内银行账户转账,可同时向本人户籍所在地公安机关报案。联系电话当地报警电话:非紧急情况拨打131444(可提供翻译服务),紧急情况拨打000外交部全球领事保护与服务应急热线(24小时):+86-10-12308+86-10-65612308驻阿德莱德总领馆领事保护与协助电话:0882688806catalogs:115955;contentid:11755180;publishdate:2023-08-24;author:季爽;file:1692875093462-15245a38-245f-4c75-be6c-b64150793715;source:29;from:领事直通车;timestamp:2023-08-2419:04:48;[责任编辑: ]
