据《山西新闻联播》报道，11月18日，山西省委常委会扩大会议暨全省持续深入开展安全隐患排查整治工作会议召开。山西省委书记唐登杰主持会议并讲话，省委副书记、省长金湘军作部署讲话。省委常委、常务副省长吴伟通报有关情况。会议以视频形式开到市一级。据报道，与会同志还观看了全省安全生产和代县精诚矿业瞒报事件警示教育片。会议指出，切实把安全生产作为做好山西工作、推动高质量发展的根本前提，坚持一手抓经济发展、一手抓安全生产，牢牢守住发展决不能以牺牲安全为代价这条红线。会议对下一步工作作出具体部署，指出要认真践行“人民至上、生命至上”理念，深入细致做好吕梁永聚煤业“11·16”重大火灾事故的伤员救治和善后工作，彻查事故原因，严肃追责问责。要痛定思痛，高度警醒起来，迅速行动起来，坚决扛牢安全生产政治责任，立即开展全省冬春火灾防范专项整治行动，持续深入开展重大事故隐患专项排查整治2023行动，全面开展安全意识大教育、安全隐患大排查、安全问题大整治、安全责任大落实专项行动，强化督查检查，消除盲区死角，全面摸清并动态掌握重大事故隐患底数，推动重大事故隐患得到系统治理，重大风险防控取得明显成效。要发扬斗争精神，敢于动真碰硬，真正把各项举措严起来、硬起来、落到位，让各项制度规定“长牙带电”，更好统筹发展和安全，坚决防范和遏制重特大事故发生。公开报道显示，11月16日7时许，山西省吕梁市离石区永聚煤业办公楼发生重大火灾事故。事故造成26人不幸遇难、38人受伤。会议强调，要加强组织领导，压实扣紧责任链条，着力构建全方位的安全生产责任体系，推动安全生产形势持续稳定向好。要严格落实党政领导责任，认真落实“党政同责、一岗双责、齐抓共管、失职追责”要求，部署发动各方面力量全力抓好安全防范工作，特别是县级党政“一把手”要在抓好安全生产工作上投入更大精力，在深入一线检查指导上扑下身子、亲力亲为。要严格落实部门监管责任，按照“三管三必须”和“谁主管谁负责”原则，坚决把本行业领域安全生产责任落实到位。要严格落实企业主体责任，压实企业法人、实际控制人、实际负责人的第一责任人责任，切实做到安全投入到位、安全培训到位、基础管理到位、应急救援到位，切实维护人民群众生命财产安全和社会大局稳定，为扎实推进中国式现代化山西实践营造安全稳定的良好环境。与会同志观看了全省安全生产和代县精诚矿业瞒报事件警示教育片。大家一致表示，要深刻领会坚决贯彻习近平总书记重要指示精神，深刻汲取事故背后血的教训，从思想深处深刻认识事故之危害、瞒报之危害，切实以案为鉴、举一反三、警钟长鸣，加快补齐工作短板，不断夯实安全基础，全力抓好安全生产各项工作。公开报道显示，今年7月30日，山西省联合调查组通报，精诚矿业自2003年8月成立到2022年发生“9·1”滑塌事故前，先后瞒报生产安全事故40起、死亡矿工43人。会议以视频形式开到市一级。省委常委，省人大常委会、省政府、省政协负责同志，省法检两长出席会议。省安委会成员单位、省直各单位和驻并省管本科院校、省管国有企业、中央驻晋有关单位主要负责同志在省主会场参加会议。来源：观察者网原标题：《致26人遇难火灾2天后，山西省委集体观看教育片》阅读原文
