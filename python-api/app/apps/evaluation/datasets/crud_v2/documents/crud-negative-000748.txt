2023-08-11，正文： 没有前台服务的无人酒店，刷脸就可入场的无人球馆……得益于科技的不断进步，“无人经济”模式正在多个行业扩展，南宁街头也涌现出不少“无人店”。那么，这些“无人店”到底有多火？消费者在其中获得怎样的消费体验？“无人店”真的赚钱吗？近日，记者对南宁市多家“无人店”一探究竟。“无人酒店”客人可以全程自助办理入住没有前台、无人值守、只需点击二维码自己就可以全程办理入住，退房也是全程自助。近期，南宁市区出现了无人值守酒店，开创了南宁“无人酒店”的先河。近日，记者前往南宁市良庆区五象大道天誉城该公寓，对这家“无人酒店”一探究竟。与传统酒店不同的是，上到酒店楼层出了电梯后并没有看到前台，也没有店员接待，在公寓入口放置有一张办理入住指引图，附有联系电话，另有入住要求提示等。提示入住大概流程为：微信扫码进入小程序，第一步点击查找第三方平台订单，第二步输入姓名并点击确认，第三步点击办理入住就成功了。此外，有公安机关提供的网上入住实名登记功能二维码。“无人酒店”门口有办理入住指引图记者注意到，该楼层均为公寓客房，为高楼层观景酒店。麻雀虽小五脏俱全，客房为双层复式Loft房型，即下层为客厅，配有厨房、卫生间等设施；上层为睡房，步行楼梯可往来上下层。客厅的桌子上有一本物品使用记录本，如牙刷、矿泉水等均有记录，并放置有付款二维码。“无人酒店”为双层复式房型桌子上有物品使用登记本
