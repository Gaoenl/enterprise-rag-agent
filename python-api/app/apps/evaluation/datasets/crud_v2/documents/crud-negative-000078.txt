2023-08-04 16:07，正文：原标题：乌克兰：开始与美国谈判！当地时间3日晚，乌克兰总统办公室主任叶尔马克表示，乌克兰当天开始与美国就安全保障双边协议进行谈判。另一方面，乌克兰问题“和平会议”将于明日（5日）在沙特港口城市吉达召开，俄罗斯媒体称，一些国家已拒绝在没有俄罗斯参加的情况下讨论解决俄乌冲突问题，所谓的“和平会议”注定失败。叶尔马克在社交媒体上发文称，美国作为第一个和乌克兰启动安全保障双边协议谈判进程的国家，为乌克兰的其他伙伴国创造一个成功的模式。他强调，这些安全保障将加快乌克兰未来加入欧盟和北约的进程，加入欧盟和北约是乌克兰的最终目标，也是最可靠的安全保障。叶尔马克没有提到谈判的举行地点，也没有提及有哪些人参与。路透社称，七国集团在7月份举行的北约峰会上承诺，将制定和履行对乌克兰的安全保障，乌美此次谈判是北约峰会的后续行动。另一方面，据美媒此前报道，沙特主办的乌克兰问题“和平会议”将于5日召开，会议焦点将是乌克兰总统泽连斯基提出的“和平计划”。沙特和乌克兰已向约30个国家发出邀请，包括印尼、埃及、墨西哥、智利和赞比亚等，但作为冲突一方的俄罗斯却被排除在外。目前暂不确定有多少国家决定参加此次会议。俄罗斯《消息报》3日发表题为《为何沙特举办的乌克兰和平会议注定失败》的文章，称此次会议的主办方希望除西方国家外，全球南方国家能参加会议，以改变其中立立场，支持基辅的“和平计划”。但一些国家已拒绝在没有俄参加的情况下讨论解决俄乌冲突问题。墨西哥总统洛佩斯上月底已表示拒绝参加会议。他说，只有冲突双方都参加，会议才有意义。巴西总统卢拉2日也表示，乌克兰冲突必须在联合国安理会层面解决。俄外交部发言人扎哈罗娃2日称，基辅和西方国家根据泽连斯基的“和平计划”在沙特举行会议是一场骗局，实际上是为了加强反俄联盟，以展示世界在反俄行动上的伪团结。俄一再重申这一“和平计划”是不可接受的，也不可能实现。转自：CCTV4《中国新闻》中央广播电视总台华语环球节目中心新媒体来源：CCTV4返回搜狐，查看更多责任编辑：
