2023-07-26 16:00，正文：原标题：科技赋能！无人机助交警快速勘查处置道路交通事故大众网记者 李彦涵 东营报道7月21日早间，东营区域内突发一起交通肇事致人重伤事故，时逢早上班高峰期，出行人多、道路拥挤，情况紧急。东营交警二大队主要领导现场调度，事故处理中队迅速启动预案调集人员，明确分工、及时跟进，快速处置该起交通肇事致人重伤案件。21日7时许，东营交警二大队事故中队民警接指挥中心转警：在黄河路与西二路南黄河口家具城，一辆吊车鲁E773**与一辆电动车相撞，人受伤，已拨打120。警情就是命令，执勤民警迅速组织队员赶赴事故现场，同时经联系，120急救已将伤者送至胜利油田中心医院实施紧急救治，执勤民警立即封锁现场细化分工展开勘验。此时正值上班高峰期，路面车流量较大，易造成交通拥堵，且存在发生二次事故隐患，为了解决此问题，事故中队出动了一位特殊的“警员”——无人机。民警利用警用无人机拍摄现场实时视频和监控图像，快速勘察、绘制事故现场图纸，同时利用无人机喊话快速疏导周边车辆，人机分离，避免发生二次事故。经详细勘查后，及时处置并恢复道路交通。目前，肇事司机已被及时控制，该起案件正在进一步调查处理中。为有效掌握道路交通周围态势，迅速、准确处置突发事件，东营交警支队二大队在支队统一领导下，配备无人机勘查系统，在日常道路事故处理平面视角的基础上，探索启用无人机并提升其在巡逻勘查、侦查取证、立体寻防等工作领域的应用水平。利用无人机大大降低了事故现场警力部署要求，小事故可以远程取证，通过喊话快速恢复交通。随着当下公安大脑、智慧警务的发展，当前警用无人机已广泛应用于日常巡逻、勘查救援、应急处突等工作中，尤其是在道路交通事故处理方面，从三维立体的角度，助力办案民警多角度、新思维的接处警情和处置案件，为道路交通事故的处理工作助力添翼。来源：大众网返回搜狐，查看更多责任编辑：
