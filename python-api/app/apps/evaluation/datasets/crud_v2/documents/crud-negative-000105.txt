2023-08-19 08:10，正文：原标题：日媒称中俄军舰首度同时穿越宫古海峡，我军事专家解读【环球时报驻日本特约记者 林雪原 环球时报记者 丁雅栀】日本防卫省统合幕僚监部17日发布一则“中国及俄罗斯海军舰艇动向”通报，称中俄两国共11艘海军舰艇当天经冲绳本岛和宫古岛之间的宫古海峡北上，从太平洋驶向东海。据日本共同社17日报道，这是日本首次发现中俄舰艇同时通过冲绳本岛和宫古岛之间。通报称，这11艘舰艇包括中国海军6艘舰艇以及俄罗斯海军5艘舰艇。据新加坡亚洲新闻台18日报道，俄罗斯国防部当天发表声明称，俄罗斯海军和中国海军的一支分遣队目前正在东海水域演习。自演习开始以来，联合分遣队已航行6400多海里。声明写道，演习内容包括反击空袭、舰艇燃料补给和货物传送等。演习期间，两国海军进行了反潜演习，击退了模拟敌对空袭，开展了海上救援训练，并提高了在军舰甲板上起降直升机的技能等。18日，在中国外交部例行发布会上，法新社记者提问：俄罗斯国防部今天称，俄罗斯与中国军舰在东海开展了联合海上巡航。发言人能否提供更多细节？巡航已经结束还是正在进行？中国外交部发言人汪文斌表示，中俄舰船正常过航符合国际法和国际惯例。日本共同社报道称，这是日本首次发现中俄舰艇同时通过冲绳本岛和宫古岛之间。日本防卫省认为，中俄两国在日本周边反复进行联合行动，对日本“采取示威行动的意图明确”，日方“从安保角度严重关切”。对此，军事专家宋忠平在接受《环球时报》记者采访时表示，中俄之间的联合巡逻不针对第三方，目的是维护地区和平与稳定。位于日本海的宫古海峡、对马海峡、津轻海峡等海峡事关中俄的国家战略安全，中俄要维护本国国家安全必须打通海上战略安全通道，也必须要在相关海域进行演练，这符合中俄两国的实际利益，也符合各自的国家安全利益。日本认为中俄联合巡逻针对日本，是以己度人。返回搜狐，查看更多责任编辑：
