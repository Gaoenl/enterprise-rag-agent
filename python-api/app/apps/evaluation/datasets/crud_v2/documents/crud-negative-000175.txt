中证网讯(记者 康曦)近日,万兴科技在日本东京举办产品焕新发布会,旗下AI视频创作软件Wondershare Filmora 13亮相,新产品实现了从交互方式到内容生成、音视频剪辑上多元AI化升级。全新Wondershare Filmora 13内置创作助手Copilot,Copilot可根据用户输入的自然语言描述,提供相关创作建议和指导,让用户专注于更重要、更有创造性的工作。此外,Wondershare Filmora 13还上线了AI文本成片/AI音乐生成器等AI生成功能,以及AI文字快剪/智能人声分离/AI智能遮罩等AI智能编辑功能,赋能创作者进一步降低视频创作门槛、提升视频创作效率。全新推出的AI生成功能,覆盖文本、音频、视频等多媒体格式,用户无需辗转多个平台,可通过AI实现多样化的可商用、无版权内容素材生成;AI智能编辑功能,覆盖剪辑、音频、调色、特效等视频创作流程,让视频创作更简单;同时,Wondershare Filmora 13深化云服务,支持用户在手机端、平板端、PC端间轻松共享文件、逐帧审阅视频和自动同步编辑元素,进一步提升创作协同效率。业内人士预测,到2030年,90%的数字内容都将是AI生成,预计到2032年,全球AI视频生成软件的市场规模将达到21.72亿美元。作为万兴科技旗下明星视频创意软件,Wondershare Filmora在全球拥有过亿用户,跻身世界主流视频剪辑软件行列。万兴科技是中国数字创意软件领域产品覆盖面广、营收体量大、全球化程度高的A股上市公司。公司自2011年在东京设立运营中心以来,已深耕日本市场长达12年。
