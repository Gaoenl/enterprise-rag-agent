去年11月，当俄罗斯等同意延长黑海港口农产品外运协议时，联合国秘书长表示“非常感动”！近日，俄罗斯叫停了黑海港口农产品外运协议，马克龙称这是一个“巨大错误”。黑海港口农产品外运协议有多重要？俄罗斯叫停黑海港口农产品外运协议将意味着什么？黑海港口农产品外运协议是什么？2022年7月，俄罗斯和乌克兰分别与联合国和土耳其签署协议，同意设立联合协调中心，对乌克兰谷物等农产品经黑海出口运输提供安全保障，也保障俄罗斯粮食与化肥进入国际市场。俄乌双方同意任何一方都不攻击运送农产品的船只，协议有效期为120天，应于11月19日到期，如无任何一方反对将自动延期。该协议于去年11月延长生效120天。在今年3月商谈续签事宜时，俄方强调其粮食和化肥出口依然受阻，只同意延长协议60天。该协议于7月17日到期。黑海港口农产品外运协议效力为何中止？黑海港口农产品外运协议一部分保证乌克兰粮食通过黑海安全出口，另一部分保证取消对俄农产品和化肥进入国际市场的限制。俄罗斯总统新闻秘书佩斯科夫表示，由于黑海港口农产品外运协议涉及俄罗斯的部分迄今没有执行，因此俄方终止协议效力。上海外国语大学教授、上海全球治理与区域国别研究院执行院长杨成表示，就在俄方宣布不再续约几个小时前，克里米亚大桥于7月17日凌晨再次遭袭，造成2人死亡。有人认为，这一事件可能是压垮协议的“最后一根稻草”。黑海港口农产品外运协议有多重要？对全球粮食安全意义重大据悉，乌克兰素有“欧洲粮仓”、“世界面包篮”之称，是葵花籽油、玉米和小麦出口大国，通常每年向全球市场供应约4500万吨粮食。俄罗斯也是粮食和化肥出口大国，去年7月至今年6月的粮食出口量达到创纪录的5800-5900万吨。乌克兰危机升级后，由于船只一度无法安全进出乌克兰港口，大量粮食在仓库中堆积，导致全球主要粮食价格上涨。这让一些发展中国家的民众面临饥饿风险。在黑海港口农产品外运协议达成后，全球粮食安全危机得到一定缓解。该协议也因此被联合国秘书长古特雷斯誉为“希望灯塔”。国际救援委员会也将该协议称为处于粮食不安全前线的79个国家和3.49亿人民的“生命线”。据联合国网站介绍，协议实施近一年来，超过3200万吨粮食商品已从乌克兰的三个黑海港口出口到遍布三个大洲的45个国家，解决了重要粮食商品的供应问题，扭转了全球食品价格创纪录的增长趋势。俄罗斯停止执行协议会造成哪些影响？一、国际主要粮食价格应声上涨从短期来看，俄罗斯停止执行协议将对乌克兰农产品出口造成很大影响，甚至乌粮食出口可能因此停摆，导致国际粮价的波动。在俄罗斯外交部17日就黑海港口农产品外运协议发表的声明称该协议将在18日失效后，全球主要粮食小麦、玉米和大豆价格出现不同程度上涨。二、部分国家或引发饥荒协议停止生效后，乌克兰的粮食外运成本要增加15%至20%，对全球粮食价格来说将是巨大的冲击因素，甚至将影响部分国家的粮食安全，引发饥荒。各方反应如何？乌克兰：愿意继续执行乌克兰总统泽连斯基17日在接受非洲媒体采访时表示，乌克兰愿意在没有俄罗斯参与的情况下继续执行黑海港口农产品外运协议。泽连斯基指出，乌克兰外交部将与联合国和土耳其进行交涉，以获得关于继续实施黑海港口农产品外运协议的答复。如果乌克兰和土耳其确保这些船只通过，拥有这些船只的公司将可以继续运输谷物。土耳其：继续斡旋、推动相关协议能够重新获得延期土耳其总统埃尔多安明确表示，希望能尽快与俄罗斯总统普京进行面对面的会谈，讨论协议的相关情况。但对于乌克兰方面关于在没有俄罗斯参与的情况下继续执行黑海港口农产品外运协议的提议并未做出明确回应。联合国：深感遗憾联合国秘书长古特雷斯17日在纽约联合国总部表示，对俄罗斯决定中止黑海港口农产品外运协议深感遗憾，联合国将继续致力于寻找解决方案。中方：希望有关方通过对话协商解决国际粮食安全问题在中国外交部7月18日举行的例行记者会上，发言人毛宁对此表示，中方希望有关方通过对话协商妥善解决国际粮食安全问题。中方愿同各方加强沟通合作，促进形成更多的国际共识，为确保世界粮食安全作出积极贡献。资料来源：央视新闻、央广网、中国新闻网、上观新闻、中国青年报编辑：黄灵责编：吴忠兰审核：冯飞【免责声明】上游新闻客户端未标有“来源：上游新闻”或“上游新闻LOGO、水印的文字、图片、音频、视频”等稿件均为转载稿。如转载稿涉及版权等问题，请联系上游。举报
