教育部、财政部近日联合印发《关于做好2023年银龄讲学计划有关实施工作的通知》，提出2023年义务教育阶段计划招募6000名讲学教师，明确讲学教师服务时间原则上不少于一学年，鼓励考核合格的连续讲学。这是“银龄讲学计划”启动实施以来的第六个年头，一个明显的趋势就是计划名额总体上连年增加，另一个显著特征就是经费保障权责分明、标准清晰、用途明确。为了帮助农村学校提升教学水平和管理能力，缓解农村学校优质师资总量不足、结构不合理等矛盾，促进城乡义务教育均衡发展，2018年国家启动“银龄讲学计划”。该计划既让优秀退休教师群体老有所为，又提升了农村地区受援校（地）义务教育发展水平，形成了多赢的良好局面。如何进一步加强农村教师队伍建设，加快推进义务教育优质均衡发展，值得深入探讨。“银龄讲学计划”旨在助力提升中西部地区农村的教师队伍质量，当时实施的战略背景是打赢脱贫攻坚战，是教育精准扶贫的重要内容。所以，计划最初的部署在时间上明确从2018年开始到2020年，招募10000名教师。随着脱贫攻坚的全面胜利，面对强国建设和高质量教育体系建设的新形势、新要求，“银龄讲学计划”需要重新定位功能，进行顶层设计。过去，“银龄讲学计划”在学校实际运行层面也产生了一些矛盾。例如，由于身体条件限制，一些银龄教师在参与学生课外活动等方面存在困难；随着“互联网+教育”改革实践的深入，新技术、新设备的使用给银龄教师带来了一定的挑战。此外，有的地区系统性支撑不够，对优秀的银龄教师还不足以形成有效激励。一些欠发达地区生活条件和医疗水平相对落后，存在就医不便等问题。我国已经进入老龄化社会，老龄事业已明确纳入经济社会发展总体规划和可持续发展战略。“银龄讲学计划”应顺应这一趋势，搭建教育领域老有所为的广阔平台，发挥优秀退休教师持续参与农村教育改革、乡村教师队伍建设的积极作用。当下，按照建设高质量教育体系和教育强国的目标任务要求，结合党的二十大对乡村振兴全面推进的部署，需要对“银龄讲学计划”进行制度化提升，系统推进计划走深走实，着重解决好银龄教师的交通、住宿、医疗等实际问题，形成有效的政策合力。一是继续强化政策顶层设计，在国家层面推动实施“银龄讲学计划”的升级改版。二是开展经费保障分析评估，强化省级统筹和经费保障主体责任，引导和鼓励地市级财政加大经费投入，确保不形成对县级财政的压力。三是坚持需求导向，推进讲学教师岗位和评价管理的权限向区县级教育行政部门和学校层面的下沉。四是着重在生活便利、医疗便捷、工作适应、薪酬科学上提升岗位吸引力。进一步细化明确地方各级政府以及学校在讲学教师工作环境、生活条件、待遇保障方面的职责。五是加强对计划基本理念、目标定位、政策举措的解读和实施效果的宣传。各级教育行政部门应以多种渠道组织开展对时代背景和政策本身的解读与宣讲，避免一些偏颇甚至是错误的认识，形成政策实施的无形阻力。（作者：杨小敏系北京师范大学中国教育政策研究院副教授）举报/反馈
