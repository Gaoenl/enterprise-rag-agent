2023-08-08，正文：村庄河道出现巨大漩涡喷涌3米高水柱 水利局：系灌溉水管阀门损坏开阔的沧河河道内，两股高达3米多的水柱喷涌而出，这一现象在河南新乡卫辉市安都乡口头村持续数日，引来当地不少居民围观打卡。8月7日，当地水利局副局长回应称，上游水库涨水，该处灌溉水管的水阀因压力过大损坏从而喷出水柱，待河道水位下降后，会对阀门进行修复。两股水柱相隔百余米（视频截图）近日，多名河南卫辉市的网友发布视频称，当地安都乡口头村的沧河河道内喷出两股水柱，很是壮观，还有人专门过来拍照打卡。视频中，在开阔的河道内，两股水柱喷涌而出就像巨型的喷泉，两股水柱相隔百余米，有不少人在旁边拍照、戏水。有人称，这是大雨之后河道形成的天然喷泉，还有人猜测，这是不是地下水饱和了。有网友称，此前现场曾拉了警戒线，不让大家靠近这两处水柱。水柱旁有人围观（视频截图）8月7日，极目新闻（报料邮箱：jimu1701@163.com）记者联系上口头村一超市老板。她介绍，大约在一周之前，当地下大雨后河道涨水，就有两处水柱喷出来，目前还在不断喷涌。当地另一村民李先生告诉极目新闻记者，水柱喷涌处离口头村的战备桥约200米，这并非天然喷泉，而是埋在河道内的灌溉水管阀门损坏，管内水压太大，所以才喷了出来。灌溉水管的源头是上游的水库。
