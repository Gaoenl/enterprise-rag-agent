2023-07-31 15:24，正文：                原标题：上半年客运量43.2亿人次，高速路小客车出行规模超疫情前                            南都讯记者陈秋圆 发自北京 7月31日，交通运输部召开例行新闻发布会，交通运输部综合规划司副司长李传光介绍了上半年交通运输经济运行情况，今年以来呈现出“持续恢复、整体好转”的特点，为推动经济回升向好提供了有力保障。    交通运输部综合规划司副司长李传光。  具体来看：一是货运量持续增长。上半年，完成营业性货运量259.3亿吨，同比增长6.8%，其中，铁路、公路、水路、民航分别完成货运量25亿吨、190.1亿吨、44.2亿吨和328万吨，同比分别增长0.6%、7.5%、7.7%和6.4%。  二是出行量加快恢复。上半年，完成营业性客运量43.2亿人次，同比增长56.3%。全国完成城市客运量454.2亿人次，同比增长15%。完成高速公路小客车出行量117.8亿人次，同比增长39%，规模已明显超过疫情前同期水平。  三是港口货物吞吐量较快增长。上半年，完成港口货物吞吐量81.9亿吨，同比增长8%，其中，内、外贸吞吐量同比分别增长7.6%和8.9%。集装箱吞吐量保持增长、完成1.5亿标箱，同比增长4.8%。  四是交通投资高位运行。上半年，完成交通固定资产投资1.83万亿元，同比增长9.1%。分方式看，铁路完成投资3049亿元，同比增长6.9%；公路完成投资13830亿元，同比增长8.9%，其中，高速公路、普通国省道、农村公路同比分别增长7.5%、13.6%和9.8%；水路完成投资936亿元，同比增长26.7%；民航完成投资462亿元，同比增长0.2%。返回搜狐，查看更多                        责任编辑：
