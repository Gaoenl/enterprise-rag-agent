中国网财经7月18日讯(记者 张增艳)格力地产昨日晚间公告称，因前期会计差错需对2018-2022年财报进行追溯调整。日前，格力地产对存货项目前期计提减值情况进行梳理和调查，发现下属全资子公司上海海控保联置业有限公司、上海海控太联置业有限公司及重庆两江新区格力地产有限公司2018-2021年未能准确估算存货的预期未来售价。通过采用追溯重述法补提2018-2021年存货跌价准备，并由此导致2022年年初存货、未分配利润和2022年度资产减值损失需做相应调减。综上，公司对2018-2022年度财务报表进行追溯调整。需要指出的是，经过追溯调整，将导致格力地产2018-2021年归属于母公司所有者的净利润分别变动-4.42亿元、-303.81万元、-1.63亿元和-1886.13万元，分别占更正前公司2018-2021年归属于母公司所有者的净利润的-86.21%、-0.58%、-29.10%和-4.10%；并由此导致2022年年归属于母公司所有者的净利润调增6.26亿元，占更正前2022年归属于母公司所有者的净利润的23.34%。格力地产表示，此次前期会计差错更正仅影响公司合并资产负债表和合并利润表，主要涉及存货和资产减值损失科目，不影响合并现金流量表以及母公司财务报表的列报和披露，上述调整不会导致公司已披露的相关年报出现盈亏性质的改变。举报/反馈
