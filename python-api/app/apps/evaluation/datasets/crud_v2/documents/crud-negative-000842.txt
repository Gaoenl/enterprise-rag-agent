，正文：7月29日，房山区财政局派驻史家营乡史家营村“第一书记”张乘山收到汛情讯息后，同村“两委”开始了紧张忙碌的防汛工作，直至今日他们依然奋斗在抢险救灾第一线。惊心动魄的48小时7月30日至31日，村内暴雨连续、河水暴涨、水漫多处，山洪、塌方、泥石流各种灾害接踵而至。史家营村书记董永忠、驻村第一书记张乘山和村“两委”干部迅速行动，立即启动应急预案，冒着倾盆大雨和随时发生二次塌方的情况组织机械疏通泄洪，迅速转移受灾群众41户87人统一安置到安全地点避险，4位瘫痪老人直接肩扛身背到村委会进行安置。经过奋战两天两夜，史家营村内虽多处塌方，但百姓无一伤亡。大雨无情人有情傍晚时分，村内统一组织烧起大锅饭，保障百姓温饱。村里淳朴的大妈拿出了家里的被褥，农家院的大嫂主动承担了大锅饭的任务，将家中存粮烧火做饭，村内八十多人温饱得以解决。张乘山及村“两委”干部熬夜奋战，凌晨一点仍在搬运沙袋。积极组织自救雨停后，一位尿毒病人多日没有透析，生命危在旦夕，因村内断水、断电、断路、断联，村内也十分缺少物资，张乘山和村书记立即商议村内自救方案。经向乡镇府请示后，张乘山徒步从史家营村步行18公里至贾峪口出山，沿途与元阳水、柳林水村传递乡内救灾情况，途径湍急的河流、茂密的山林、破损的河滩，并攀越防护网，最终寻找到了信号，及时向上级报告了乡内受灾严重、各项物资紧缺等情况，请求上级部门紧急支援。 目前，卫健委消防救援等部门已知悉相关情况，派遣消防救援抢险队转送患者下山，救护车和医护人员在山下随时待命。同时，紧急安排了柴油、药品等应急物资，保障群众生命安全。灾难来临张乘山作为“第一书记”勇于向前与村“两委”干部用实际行动带领大家共克时艰虽然18公里的残壁断路磨破他们的脚掌但他们毫无畏惧依旧把人民扛在肩上把灾难踩在脚下趟出了一条“生命通道”来源：北京房山流程编辑：TF060                             如遇作品内容、版权等问题，请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话：010-85202353
