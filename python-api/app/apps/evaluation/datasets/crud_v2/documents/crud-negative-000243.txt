沈阳正通过一些政策让青年人“向往沈阳、扎根沈阳、圆梦沈阳”。随着一系列保障性租赁住房政策落地,沈阳有越来越多为青年人打造的“专属项目”出现,在沈阳不仅有适宜的工作,也是宜居之地。根据沈阳市房产局最新消息,截至2023年4月底,沈阳市通过新建、改建、转化等多种方式,累计筹集保障性租赁住房6.85万套,已投入运营2.5万套。通过筑巢固巢,把青年人引得来,住得下。“十四五”期间,沈阳市计划筹集保障性租赁住房13.5万套,其中2022年底前筹集6万套,2023~2025年每年2.5万套。目前,沈阳市已通过落实土地、财政、税收等优惠政策、搭建资源平台、金融机构提供金融支持,鼓励和引导各类市场主体参与保障性租赁住房建设,形成了政府统筹、社会房源转化以及企业自建等多主体参与、多渠道保障的房源筹集模式。“采取人才安居与住房保障双轨并行,将解决青年人住房问题纳入整个住房保障体系中统筹推进,以加快推进保障性租赁住房建设为重点,让沈阳成为青年人宜居乐居、拼搏创业的圆梦逐梦之家。”沈阳市房产局相关负责人介绍。保障性租赁住房都在哪儿?2022年2月,沈阳市政府印发实施《关于加快发展保障性租赁住房的实施意见》,遵循优化布局、以需定建的工作原则。从现阶段筹集的房源项目看,多位于主城区,或围绕轨道交通枢纽,或产业园区、科研院所周边等,地理位置优越,交通较为便利。例如,万科、龙湖、房发、建信等品牌住房租赁企业,其运营项目均位于市内主城区;以市属国有住房租赁企业沈阳市房产事业发展集团建设的逸居中德青年人才社区为代表的一批项目也落地沈城。另外,企业自建房源(职工宿舍类)已达1.81万套,重点解决了产业园区及企业职工居住问题,有效解决了职住平衡,引导实现产城人融合。什么样的年轻人可以申请?据了解,保障性租赁住房的对象主要是新市民、青年人以及从事基本公共服务人员等群体,不设收入门槛限制;租金要略低于同地段、同品质市场租赁住房,适应保障对象的承受能力。根据市场调查,目前市场上运营的品牌项目,月租金多在1000元-1300元/月,价格适中,配套齐全,受到青年群体的青睐。现代年轻人追求品质化,既要安全感又要社交圈,在居住方面要求“关上门就是自己,打开门就是世界”。根据目前已运营的项目看,保障性租赁住房力求打造“丰富功能性”与“精神属性”并存的园区生活,像社交大堂、健身房、公共厨房等配套设施一应俱全,年轻人“足不出户”就能享受丰富的社区生活。选聘年轻人为“公寓运营官”,消除与年轻业主的“代沟”,实现24小时服务。此类项目出租率基本稳定在95%以上,租客以单身青年为主,满意率在90%以上。鼓励购房置业 首套贷款利率近五年最低在沈阳住得这么舒服,什么时候可以有个真正属于自己的小家?针对一部分青年人的购房置业需求,沈阳市房产局配套出台了多条优惠政策,例如根据个人住房贷款利率政策动态调整机制,现首套个人住房贷款利率为3.8%,为近5年来最低。对非限购区域首套住房商业贷款首付比例降为20%执行。此外,按照吸引人才的政策,政府给予购房补贴、租房补贴等。在购房补贴方面,对获得高精尖优才奖励的,A类人才实行“一人一议”解决首套购房问题,B类、C类人才分别给予150万元、100万元首套购房补贴。对在沈就业创业的博士、硕士和本科毕业生(含技工)分别给予一次性7万元、4万元和2万元首次购房补贴。自2018年政策执行以来,已累计发放购房补贴11.2亿元,涉及享受补贴政策人才5.26万人。同时,对驻沈高校在校大学生及毕业5年内大学生购买新建商品住房,其缴纳契税由市财政全额补贴,其中在校大学生还按照建筑面积每平方米200元额外予以补贴。2018-2022年,累计发放补贴89377件,补贴资金10.9亿元。租房补贴方面,对符合条件的高层次人才(A、B、C类)提供三年内免租人才公寓住房,免租补贴上限为A类人才5000元/月、B类和C类人才3000元/月。在申请人才公寓无房源的情况下可申请补贴,补贴标准为A类人才3000元/人/月、B类和C类人才1500元/人/月。同时,按照沈阳市“人才新政3.0”规定,对在沈就业创业的应届大学本科以上高校毕业生发放3年生活补贴(包含租房补贴),博士每月2500元、硕士1200元、本科毕业生600元。自2018年政策执行以来,累计发放生活补贴近亿元,享受补贴政策人才1.55万人。让“城市对青年更友好、青年在城市更有为”,解决好“住”的问题,是让青年人扎根城市最直接的需求。下一步,相关部门将在筹集渠道上下功夫,重点挖掘盘活存量,辅以适度新建;结合“85后”、“90后”新生代租客的不同需求,提供更多、更好满足市场需求、多元化、多层次的租赁住房项目,真正让青年“留得下、住得好”,沈阳用实际行动欢迎更多的青年人。
