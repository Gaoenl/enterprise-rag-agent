2023-07-25 09:52，正文：原标题：美国一大学周边连发枪击暴力案件 外籍学生称太不安全想回家教师艾默生在美国天主教大学内遭枪杀（美国天主教大学）海外网7月25日电据美国福克斯新闻网24日报道，位于华盛顿哥伦比亚特区的美国天主教大学在新学年开始前，校园内和周边地区接连发生枪击暴力案件，学生对安全问题极其担忧。今年7月，美国天主教大学校园内和校园附近分别发生两起致命枪击事件，以及一起针对刚毕业学生的袭击事件。人们对学校的安全忧心忡忡。一名在该大学就读的外籍学生称，“我不知道自己应该换个地方读书，还是应该回土耳其。虽然学业重要，但我太害怕。”第一起枪击事件发生在7月5日，25岁的教师艾默生在参加会议后，返回学校途中，遭犯罪分子抢劫后开枪射杀。第二起枪击事件发生在7月17日，警方在校园附近发现一名男子遭枪击死亡，事件仍在调查中。而7月13日，一名刚毕业的该校研究生从地铁站步行回家时遭一群人袭击。大学领导层已和华盛顿哥伦比亚特区警方举行会议，并要求警方提供更多安全保障。校方称，将加强校园内的武装警员配备，并推动相关培训、认证工作，允许警员携带枪支。（海外网 王珊宁）责编：王珊宁、李萌返回搜狐，查看更多责任编辑：
