首页>济宁频道>济宁区县> 正文“感知圣城 优选济宁”2022青年人才聚“济”行暨大学生社会实践交流会成功举办2022-08-11 14:57:21 来源:鲁网大字体小字体扫码带走打印鲁网8月11日讯(记者赵丽娟 通讯员 胡思谋)为深入贯彻落实济宁市委人才工作会议精神,全力创建青年发展友好型城市,促进青年人才和大学生感知济宁、选择济宁,8月10日,由济宁市委人才办、团市委、市人力资源社会保障局、市教育局、济宁城投控股集团等联合主办的“感知圣城 优选济宁”2022青年人才聚“济”行暨大学生社会实践交流会在太白湖畔的济宁市图书馆举办。市委组织部副部长、市公务员局局长秦明出席会议并作重要讲话,团市委书记田卫锋致辞。各县(市、区)团委书记,市县大学生联合会负责人,青年人才加速器负责人,省属和市属高校团委、学生会负责人,青鸟驿站站长代表,实习实践大学生代表等参加活动。秦明表示,济宁市委、市政府历来高度重视青年人才工作,围绕集聚青年人才,持续不断调整优化各项政策,从生活补贴、安家补助、子女入学等方面给予大力支持。“感知圣城 优选济宁”大学生实习实践活动是服务青年学生社会实践的重要措施,通过建设“青鸟驿站”、青年人才加速器、打造实习实践项目等措施,为广大青年学子感知济宁、实践提升提供了广阔舞台。希望青年学子们把这次实习锻炼作为初涉社会、了解基层的窗口和宣传济宁、推介济宁的平台,积极展示在济宁暑期实践的美好感触和见闻,大力宣传济宁经济社会发展的优越环境。田卫锋指出,引领广大青年学子感知济宁、实习实践,是济宁共青团服务青年成长成才的重要举措。今年来,团市委聚焦青年所需所盼,全力创建青年发展友好型城市,实施促进青年发展“十大行动”,成功争取列入全省首批创建城市,山东青年报专版刊发了济宁市创建经验,山东新闻联播专门报道了团市委“青鸟计划”工作。下一步,团市委将会同有关部门不断推出惠及全市青年的支持保障政策,持续打造富有“青年活力、青创动力、青才引力、青春魅力”,青年聚“济”、乐业安“宁”的青年发展友好型城市。今年,团市委积极拓展“青鸟驿站”建设路径,创新打造了美国、俄罗斯、韩国等海外“青鸟驿站”,实现了青年人才招引渠道的新突破。会上展示了今年新聘任的部分“青鸟驿站”站长的风采,现场为“青鸟驿站”站长代表颁发了聘书。任城区、泗水县、梁山县团委负责同志介绍了本地大学生实习实践特色项目,泗水阅湖尚儒研学实践教育基地、邹城市钢山街道介绍了实习实践基地建设情况。近年来,团市委联合市委人才办,在全省创新打造“青年人才加速器”实体运作空间,链接重点企业、产业园区和青年人才需求供给,为青年人才提供成果转化、技能提升、创业孵化等全链条服务。会议现场为新认定的A、B、C三个等级的“青年人才加速器”举行了授牌仪式。济宁中科先进院、山东省智能机器人应用技术研究院、山东北工大产业园管理有限公司等3家A级加速器负责人展示了人才服务项目。优秀实习实践学生代表进行了精彩的发言,分享了自己的实习实践感受。同学们表示,将积极响应济宁市委、市政府号召,以共青团为纽带,以实干为诺言,不论走到哪里都将宣传济宁、服务济宁、成就济宁,为新时代济宁的美好未来贡献青春力量。第二阶段,实习实践大学生代表参观了济宁市博物馆、济宁市城市展示馆,同学们在畅游中进一步感知了济宁的辉煌历史与繁荣发展,厚植了未来宣传济宁、服务济宁、建设济宁的情感维系。今年来,全市各级共青团积极招募全国各大重点高校大学生来济开展实习实践,截至目前,共发动1000余家机关企事业单位和基层组织、发布高质量实习实践岗位5030余个,招引7200余名大中专学生和80余支重点团队,下沉到各地各单位开展志愿服务、疫情防控、乡村振兴、调查研究、政策宣讲、支教支医等工作,在不同领域、不同行业、不同条件的岗位上践行着自己的青春梦想。下一步,各县(市、区)团委还将持续开展青年人才县区行活动。全市共青团将进一步总结实践成果、开展跟踪问效,加快创建青年发展友好型城市,促进广大学子从“实习实践在济宁”向“就业创业在济宁”提档加速,服务青年人才在“孔孟之乡、运河之都”的沃土上实现个人价值与城市发展的双向驱动、同频融合。责任编辑:王利平新闻关键词:青年人才感知济宁实践大学生社会
