"中新网北京8月14日电 (记者 高凯)由电影频道节目中心、中国电影家协会儿童电影工作委员会主办的“邀老师看电影——《雪豹和她的朋友们》教师夏日专场放映活动”日前在京举行，吸引了众多中小学教师与小朋友参与。《雪豹和她的朋友们》教师夏日专场放映活动举办。主办方供图映后，影片联合监制、1905电影网董事长李玮与观众见面、交流，中国电影家协会儿童电影工作委员会副会长阎宇主持了映后交流环节。《雪豹和她的朋友们》教师夏日专场放映活动举办。主办方供图《雪豹和她的朋友们》由著名野生动物摄影师奚志农执导，与包括三位牧民摄影师在内的摄影团队耗时六年拍摄完成，著名演员朱亚文献声旁白，是我国第一部完全由本土团队自主拍摄完成的雪豹题材野生动物纪录电影。雪豹之外，牦牛、藏狐、鼠兔、岩羊、兀鹫、斑头雁等自然精灵亦纷纷闯入摄影师的镜头之中。兢兢业业的牧民摄影师与呆萌可爱的野生动物在故土相遇，记录并保护着它们。天寒地冻的雪山之巅，一幅人与自然和谐相处的绝美画卷，缓缓展开。这部属于中国人自己拍摄的雪豹电影，不仅是高原动物生活点滴的光影见证，更被认为凝结了摄影团队排除万难，超越极限的高燃时刻。作为一部院线电影，《雪豹和她的朋友们》打破了传统叙事逻辑，展现的不再是雪豹捕猎本能与牧民驱赶之间的矛盾，而是从牧民不伤害、不打扰地记录雪豹生活的全新视角，让环境保护教育和理念从对人类的约束转变为融入自然、感受自然、保护自然的人文情感，让观众真正认识到人与自然和谐共处的美好。该片豆瓣开分8.3分，获得第20届电影频道最受传媒关注纪录电影，被认为为中国野生动物纪录电影打开了一扇新的大门。(完)举报/反馈",
