教育部简报〔2022〕第33期四川省认真学习贯彻习近平总书记关于做好高校毕业生就业工作的重要指示批示精神，深入落实党中央、国务院“稳就业”“保就业”决策部署，着力打好强化统筹联动、积极稳企拓岗、优化就业服务、聚力精准帮扶、深化责任落实的就业工作“组合拳”，持续提升就业工作质量和效率，努力促进高校毕业生更加充分更高质量就业。强组织，统筹联动抓就业。省委省政府高度重视高校毕业生就业工作，省领导带队开展专题调研，多次召开专题会议，出台系列政策措施，着力推动高校毕业生就业工作扎实深入开展。教育、人社、卫健、民政、财政等相关部门密切配合，先后出台《进一步促进高校毕业生等青年就业创业十三条政策措施》《2022年公共卫生特别服务岗项目实施方案》《大学生就业创业扶持政策清单》《关于做好2022届离校未就业高校毕业生不断线服务的通知》等文件，进一步织密就业政策保障网。压紧压实各地党委政府责任，充分发挥各市(州)党委教育工作领导小组作用，着力构建齐抓共管、上下联动、统筹推进的高校毕业生就业工作格局。扩增量，拓展岗位稳就业。省政府出台《进一步稳定和扩大就业十五条政策措施》，明确提出“重点解决高校毕业生就业”要求，并细化扩大机关事业单位招录(聘)、国有企业招工、应届毕业生应征入伍、科研助理岗位聘用的规模等具体举措，积极拓展政策性岗位空间。面向高校毕业生举办国有企业系列招聘活动，320余家国有企业提供4000余个优质岗位。扎实开展“书记、校长联系百家企业”活动，2022年指导全省高校党委书记、校长走访企业5300余家，新开拓就业岗位8.5万余个。抢抓成渝地区双城经济圈发展机遇，组织两地高校毕业生就业大型网络招聘活动，累计提供就业岗位11.4万余个。积极与广东、江苏等省联合举办校企合作线上洽谈会，大力拓展长三角、珠三角等地区就业市场，努力为毕业生提供更多优质就业岗位。搭平台，优化服务助就业。积极利用信息技术手段，打造一体化就业服务平台，向毕业生精准推送就业信息，完善高校毕业生网上签约系统，提供“一站式”就业服务。建立健全“学校领导联系二级院系、院系领导联系班级、辅导员联系毕业生”的服务指导制度，打造就业指导“名师金课”“青春就业大讲堂”等，推动就业指导“进支部、进宿舍、进家庭、进课堂、进企业、进云端”，引导毕业生树立正确的职业观、就业观和择业观。持续开展政策宣传、就业指导、创业服务、职业培训、困难帮扶进校园活动，组织就业创业“双百”导师团深入高校提供就业指导，积极服务学生的不同职业发展需求，2022年以来共举办讲座70余场，相关就业指导项目累计服务毕业生3万余人次。注重线上线下同向发力，组织开展“智汇天府”公共招聘进校园、“就业有您 职等您来”专场招聘、民营企业招聘月等专场活动，努力实现常态化招聘活动不断档、不掉线。严格落实高校毕业生创新创业政策，从资金补贴、贷款贴息以及场地、项目等方面鼓励支持高校毕业生就业创业。盯重点，精准帮扶保就业。完善重点群体“一人一档”“一人一策”精准服务机制，把脱贫家庭、低保家庭、零就业家庭以及有残疾的、较长时间未就业的高校毕业生作为重点帮扶对象，全面摸清底数，建立基本信息和就业帮扶两本台账，为有就业意愿的毕业生至少提供1次职业指导、3次岗位推荐、1次职业培训或就业见习机会;按照人均600元标准，为3万余名困难群体毕业生发放帮扶补贴。依托“宏志助航计划”，对5200余名就业困难高校毕业生开展线下集中培训，着力提升毕业生就业能力。组织教育、人社、民政、乡村振兴、残联等部门召开重点群体毕业生就业推进会，开展为残疾毕业生“送岗上门”活动，进一步分解任务、明确举措，共同推进重点群体毕业生就业。严考核，压实责任促就业。压紧压实高校就业工作主体责任，严格落实就业工作“一把手”工程，将毕业生就业情况纳入高校学科专业建设评估、领导班子年度考核等，并将就业工作情况与招生计划、绩效考核等相挂钩，着力确保人员、经费、场地和机构“四到位”，对就业工作不力高校进行约谈。加强就业数据核查，成立工作专班，召开就业数据统计核查专题会、情况反馈会等，以“学校两次查、全面覆盖查、动态跟踪查、突出重点改”相结合的方式，深入开展核查工作，推动高校毕业生更加充分更高质量就业，助力全省经济社会持续健康发展。
