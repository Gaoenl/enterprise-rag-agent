7月19日上午，财政部举行新闻发布会，介绍延续和优化新能源汽车车辆购置税减免政策的具体内容，明确新能源汽车车辆购置税减免政策延长至2027年底，减免力度分年度阶梯性退坡。具体减免政策如下：对在2024年1月1日至2025年12月31日期间购置的新能源汽车免征车辆购置税，每辆汽车免税额不超过3万元；对在2026年1月1日至2027年12月31日期间购置的新能源汽车减半征收车辆购置税，每辆汽车减税额不超过1.5万元。财政部税政司副司长魏岩表示，为支持新能源汽车产业发展、促进汽车消费，相关部门延续和优化了新能源汽车车辆购置税减免政策。下一步将在落实好今年已出台的多项政策基础上，针对形势变化，加强政策储备，积极谋划针对性强、务实管用的税费优惠政策，着力为经营主体纾困解难，不断增强发展动能，优化经济结构，推动经济持续回升向好。以税收政策激励新能源汽车产业高质量发展近年来，国家出台了一系列针对新能源汽车产业发展的财税政策。财政部副部长许宏才介绍，经国务院批准，自2014年9月1日起，对购置新能源汽车免征车辆购置税；2017年、2020年、2022年先后三次延续该政策。截至2022年底，上述政策累计免税规模超过2000亿元，预计2023年免税规模将超过1150亿元。据初步估算，此次延长政策实行后，2024年至2027年减免车辆购置税规模总额将达到5200亿元。此外，国家还对新能源汽车免征车船税，对纯电动汽车不征消费税，相关财税政策有力支持了新能源汽车产业的高质量发展。工业和信息化部还将根据新能源汽车技术进步、标准体系发展和车型变化等情况，优化享受车辆购置税减免政策的技术要求，引导企业加快新能源汽车技术研发和升级。财政部副部长许宏才认为：“通过动态提高享受车辆购置税减免政策技术门槛，并相应改进目录管理措施，更好发挥税收的激励作用，支持新能源汽车高质量发展。”新能源汽车相关利好政策频出7月21日，国家发展改革委等部门制定的《关于促进汽车消费的若干措施》公布，进一步提出要稳定和扩大汽车消费，优化汽车购买使用管理制度和市场环境，更大力度促进新能源汽车持续健康发展。在降低新能源汽车购置使用成本方面，若干措施明确，推动居民小区内的公共充换电设施用电实行居民电价，推动对执行工商业电价的充换电设施用电实行峰谷分时电价政策。到2030年前，对实行两部制电价的集中式充换电设施用电免收需量（容量）电费。此外，推动提供充电桩单独装表立户服务，以解决居民广泛存在的“安桩”难问题。在推动新能源汽车智能网联化落地方面，据工业和信息化部透露，将在今后一段时期发布新版的智能网联汽车标准体系指南，推进功能安全、网络安全、操作系统等标准的制修订，并启动智能网联汽车准入和上路通行试点。这将提升智能网联汽车的科技水平，为人们的驾驶出行提供便利和安全保障。汽车消费潜力有望进一步释放当前，我国汽车消费复苏态势稳中向好，密集推出的政策支持与自主品牌的竞争优势相互促进，为中国汽车产业的可持续发展注入了强大动力。上半年，我国汽车产销量分别完成1324.8万辆和1323.9万辆，同比分别增长9.3％和9.8％，在一季度汽车产销同比下滑的情况下，二季度明显恢复。在各项促消费政策、汽车营销活动等共同拉动下，上半年汽车类商品零售额达到22409亿元，同比增长6.8％。（资料图片）据目前的情况显示，汽车消费仍有挖潜提质空间。因此针对调研发现的问题，《关于促进汽车消费的若干措施》提出务实的优化限购管理政策和车辆更新机制。包括积极协调有关限购地区，鼓励因地制宜增加年度购车指标投放，实施城区、郊区指标的差异化政策，尽早下达全年购车指标，加快投放进度；鼓励各地综合运用经济、技术等手段推动老旧车辆退出，并对取消二手车限迁、便利二手车交易登记等已出台政策进一步加强督促落实等。7月24日召开的中共中央政治局会议提出，要提振汽车、电子产品、家居等大宗消费，推动体育休闲、文化旅游等服务消费。有专家表示，相关政策和措施将有效促进消费扩容提质，带动居民消费增长和经济恢复。汽车产业是稳工业、稳经济的重要力量。面对压力与挑战，以汽车为抓手稳定消费、畅通供需循环，对激发市场需求、保持工业持续复苏具有重要意义。（文／王梦冉）责任编辑：格桑卓玛
