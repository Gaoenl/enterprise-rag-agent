中新社郑州8月16日电 (记者 刘鹏)中国农业大省河南官方近日发布《关于做好新型职业农民职称评定工作的通知》(以下简称通知)提及，将持续推进“农民评职称”。职称评定是反映专业技术人员的技术水平、工作能力以及学术成就的主要标志。近年来，随着中国农业生产的进步及不少有知识、有技术、有能力的“新农人”投身农村，农民正从一种身份悄然转变为一种职业。2018年，中央一号文件提到，要大力培育新型职业农民，鼓励各地开展职业农民职称评定试点。此后，吉林、山东、浙江多地纷纷试水职业农民职称评定工作。人口大省、农业大省河南也不例外，早在2007年，河南就曾出台《河南省农民技术人员职称评定实施意见》；2020年又出台了《河南省农业系列职称申报评审条件(试行)》；2021年，河南省漯河市成了该省唯一一个新型职业农民职称评审试点城市。同年，有44人获得新型职业农民中级职称。年近六旬的陈付枝是漯河市一家种植专业合作社的负责人，作为“田秀才”的她于2022年申报了农民职称评审。当崭新的证书捧到手里时，只有高中文化的陈付枝不敢相信种红薯也能“种”出中级职称。有了新身份后，陈付枝开讲座、搞培训，把新政策、新知识带给周边更多的村民。数据显示，近年来，河南省每年参评农业系列和农业科研系列职称的人数均呈上升趋势。截至2022年11月，该省已有逾百名新型职业农民获得农业系列副高级职称。上述通知称，为创新乡村人才评价机制，激励农村优秀人才更好发挥示范带头作用，助力农业强省建设，河南省政府决定在全省开展新型职业农民职称评定工作。评定范围和对象包括以农业生产经营为职业，从事种植业、养殖业、农产品生产加工或农业生产服务的家庭农场、农民专业合作社、农业企业中的农业专业技术人员，以及返乡创业农民工、返乡创业大学生、退役军人等具有相应农业生产经营管理能力的专业技术人员。通常情况下，专业技术职称参评者往往需要满足学历、论文、研究成果等“硬杠杠”。记者注意到，该通知不仅降低了农民参与职称评审的门槛限制，打破学历、身份、层级、年限等条件限制，还畅通了职业农民职称评审的渠道，评审范围也更广、更明晰。河南省社会科学院人口与社会发展研究所所长陈东辉16日接受中新社记者采访时表示，该通知要求推进农民职称评定工作，不看学历看资历，不看论文看田地，有助于为职业农民创造发展空间，进一步激发农业人才扎根农村、发展农业的内生动力，助力乡村振兴。(完)举报/反馈
