国以农为本，农以种为先。9月8日，国家玉米新品种核心展示示范暨品种试验培训班在公主岭举办，旨在展示玉米品种创新最新成果，加大优良品种推进力度，服务农民选种和种业企业发展。本次活动是我国玉米品种最新创新成果的一次大检阅、大比武，是玉米种业人踔厉奋斗与种业振兴行动的具体实践。中国农业大学院士戴景瑞，全国农技中心副主任刘信，农业农村部种业管理司处长陶伟国，省农业农村厅副厅长刘文国，公主岭市委副书记、市长赵师骐出席。赵师骐在致辞中表示，公主岭处于世界三大黄金玉米带之一的核心区，玉米产量稳居全国县域第三位，单产连续多年全国首位，被赋予“中国玉米之乡”的黄金名片，是全国首批重点商品粮基地、东华北区域唯一的部省县三级共建的国家玉米新品种区域性集中展示评价基地。2021年，公主岭市获批国家现代种业产业园；2022年，国务院批复吉林长春国家农高区，开创了公主岭现代农业以及种业研发的崭新局面。公主岭深入落实习近平总书记提出的“立志打一场种业翻身仗”“种业振兴”重要指示精神，依托国家农高区平台，强化企业创新主体地位，推动政府、种业企业、科研院校在科技资源整合方面深度合作，力争未来公主岭实现玉米种业百亿产值的目标，争当吉林省现代农业发展排头兵中的排头兵。刘文国对本次活动和系列会议的召开表示诚挚祝贺。他说，吉林省始终牢记习近平总书记嘱托，坚决扛稳保障国家粮食安全的政治责任，坚持藏粮于地藏粮于技战略，全方位夯实粮食安全根基，成为保障国家粮食安全的重要压舱石，为保障国家粮食安全作出了应有贡献。国家玉米新品种核心展示示范活动在吉林省召开，这是农业农村部和全国农技中心对吉林省粮食生产的最大支持和厚爱，也是对吉林省品种展示示范工作的充分肯定。吉林省将以此为契机，认真学习借鉴兄弟省份的先进经验和做法，进一步加快优良品种选育和推广应用，为实现吉林省千亿斤粮食产能提升发挥更大作用。陶伟国在讲话中表示，2021年7月，习近平总书记主持审议种业振兴行动部署，要求把种源安全提升到关系国家安全的战略高度，实现种业科技自立自强，种源自主可控。开展新品种展示评价是遴选推荐优良品种的有效手段，是指导服务农民科学选种的重要平台，是实施品种全生命周期管理的重要一环，也是提高粮食和重要农产品单产水平的重要举措。吉林省委省政府高度重视粮食生产和玉米种业发展，为全国玉米生产和单产提升作出了积极贡献。公主岭市连续6年承担国家玉米新品种区域性集中展示评价工作，连续3年承办国家东华北区玉米新品种展示示范观摩活动，展示了东华北区玉米品种最新创新成果。农业农村部种业管理司将继续大力支持吉林主业，抓住新机遇，打造新优势，创出新经验新模式，在推动东华北乃至全国种业振兴中贡献更多力量。开幕式后，与会领导、专家及参会代表参观了展示田。农业农村部农村经济研究中心研究员吴天龙、吉林省农业科学院玉米研究所副所长路明、中国农业大学副教授赵海铭分别围绕《当前玉米供求形势及市场行情分析》《我国玉米育种研究与发展思考》《加强转育品种综合农艺性状评价 推动生物育种产业高质量发展》作主题培训。今年基地内共展示玉米新品种305个，均是各企业和科研单位即将重点推广的优良品种，设置五个区：一是核心展示区，展示突破性玉米新品种25个；二是区域性集中展示区，集中展示玉米新品种156个；三是种植密度对比展示区，展示不同密度品种65个；四是高产竞赛品种展示区，参加竞赛品种46个；五是重大品种推广后补助展示区，展示目前市场推广面积较大的优势品种13个。近年来，公主岭市委市政府高度重视现代种业发展，深入实施“1126”发展战略，全力加快农高区建设，以创建国家级现代种业产业园为契机，不断发挥优势，持续借势发力，努力打造“北繁硅谷”。目前，全市持证的种子生产企业55家，占全省的三分之一，育繁推一体化种业4家，占全省的57%。国家玉米产业技术体系东北区重点任务一县一业落在公主岭市，先正达、隆平高科、大北农、山东登海等国内种业龙头及科研院所在公主岭市建立了育种站。同时公主岭市出台了招商引资、人才引进、知识产权保护等配套措施，在种质资源、生物育种、品种推广、技术集成、生产加工、种业交易、人才引进和企业集聚等方面给予最有力支持、最优质服务、最高效保障。国内有关专家、学者，全国农技中心，国家农作物品种审定委员会，各省、自治区、直辖市种业管理机构和品种试验组织管理部门有关同志；国内各大玉米种业企业相关负责人参加本次活动。撰 稿：马俊超编 辑：彭海瑞编 审：迟英梅 张仁侠总编审：高智慧原标题：《国家玉米新品种核心展示示范暨品种试验培训班在岭举办》阅读原文
