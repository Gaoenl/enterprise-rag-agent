2023-08-07 16:53，正文：原标题：“司法救助+妇联帮扶” ！乌当开展多元化救助发放4.5万司法救助金近日，在人民监督员的见证下，贵阳市乌当区检察院联合乌当区妇联向生活困难的4名刑事案涉妇女发放司法救助金4.5万元。赵某某等4人国家司法救助案中，1人为被拐卖妇女，1人为交通肇事案死者家属，2人为放火案被害人。交通肇事案死者是家中唯一劳动力，被救助对象赵某某已怀孕9个月，案发后让本不富裕的家庭更是雪上加霜，孩子一出生就将面临更加窘迫的生活。为此，乌当区人民检察院及时伸出援助之手，对4名困难妇女给予司法救助帮助她们渡过难关。考虑到经济补助仅能解决家庭的一时之需，该院根据和区妇联共同签订的《关于全面加强困难妇女群体国家司法救助工作协作机制实施意见（试行）》，及时将该线索移送区妇联，商请妇联联合救助。乌当区妇联工作人员为4名妇女送慰问品、进行心理安抚和疏导，帮助她们调整心态走出阴影，还积极协调当地政府部门为她们提供国家政策性岗位，最大限度地帮助她们走出困境。受助者们向区检察院和妇联表达了深深的感激之情，危困之时施以援手，不仅解决了燃眉之急，更让她们重拾克服困难的勇气，重燃美好生活的希望。参会的人民监督员说，乌当区检察院立足检察职能，主动作为、积极履职，以困难妇女权益保护为重心，及时为需要救助关爱的人送去了司法温暖，为群众排忧济困办实事的严谨工作作风值得肯定。据悉，此前，乌当区检察院与乌当区妇联建立困难妇女群体司法救助协作机制，这是机制建立后第一次向涉案困难妇女集中发放国家司法救助金。乌当区检察院相关负责人表示，该院将严格把握司法救助程序和标准，对涉困难妇女群体司法救助“应救尽救”，也将充分发挥与妇联的协作机制积极构建多元救助工作格局。以“检察+妇联”为新起点，不断拓展“检察+ ”救助模式，推动司法救助融入社会救助之中，为更多困难群体提供保障，为社会治理现代化提供新探索、新实践。贵州日报天眼新闻记者 罗华编辑 方勇二审 熊瑛三审 李中迪返回搜狐，查看更多责任编辑：
