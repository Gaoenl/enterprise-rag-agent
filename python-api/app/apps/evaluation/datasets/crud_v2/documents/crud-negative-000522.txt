综合外媒报道，近日，美国前总统特朗普在得州举行的竞选集会上再次表示，若当选2024年美国总统，将在24小时内解决乌克兰危机。据报道，当地时间25日，特朗普在得州瓦科(Waco)举行竞选集会，这也是他宣布将角逐2024总统大选以来，首次举行大规模竞选集会。特朗普在竞选集会上说，“我认识两边的人，你可以非常、非常快地达成它(和解)……我将在24小时内达成和解。”他还称，他会阻止第三次世界大战的发生。资料图：特朗普。此前报道据美媒报道，当地时间2月20日，特朗普在佛罗里达州对支持者发表讲话时称，如果自己再次当选总统，在胜选的当晚就会致电俄罗斯总统普京和乌克兰总统泽连斯基，以结束乌克兰危机。据美国“佛罗里达之声”新闻网消息，当被问到将如何结束乌克兰危机时，特朗普称，“我会说，‘我们会见面的’，我保证我能解决这个问题，我保证。我非常清楚自己在说什么。我告诉(他们中的)一个人这个，告诉另一个人那个，然后告诉他们‘你们最好达成协议’，我们将会在24小时内达成协议。”另据美国《国会山报》报道，继今年1月正式开启总统竞选活动后，特朗普于20日宣布了自己2024年总统大选的竞选团队。（原标题：特朗普承诺：若当选，24小时内解决乌克兰危机）来源：中国新闻网流程编辑：TF099举报/反馈
