举世瞩目的第31届世界大学生夏季运动会,7月28日在成都开幕。开幕式以“成就梦想”为主题,向世界呈现出一场具有中国特色、时代气息、青春风采的活力盛会。江苏台记者黎明:相约大运,青春当“燃”!第31届世界大学生夏季运动会在成都盛大开幕,成都东安湖体育公园主体育场已经变身成为了一个世界青年的主场,来自世界各地的170个国家和地区的上万名大学生运动员欢聚成都,成就梦想。各国的运动员正在依次入场,他们脚下的大屏呈现的是中国的国家级非物质遗产蜀锦。青年健儿们踏着这条锦绣之路,奔向他们的锦绣前程。成都大运会共有18个大项269个小项的比赛,赛事期间还将举行各种丰富多彩的文化交流活动,促进世界青年的交流。在激动人心的圣火点燃仪式环节,31名火炬手奔向会场中央,其中领跑的是四川成都籍航天员叶光富。当31名火炬手共同完成点火后,太阳神鸟点火盘光芒四射,盘旋上升,焰火传递,神鸟展翼,最终点燃场外的火炬塔。成都大运会开幕式演出以“成就梦想”为主题,中国风格、四川特色、青春风采依次精彩呈现。从千年三星堆到非遗川剧,从蜀锦蜀绣到国宝大熊猫……开幕式上的这些巴蜀元素,让成都散发出历史与现实交融的独特韵味。从北京冬奥会的“一起向未来”,到成都大运会的“成都成就梦想”,这是向世界发出的诚挚邀约。成都已为来自全球的大学生运动员搭建好舞台,等待选手们在奉献精彩比赛的同时,共同编织友谊、理解、和平的美好故事。哈萨克斯坦运动员Duisenov shamsat说,这是一个棒的夜晚,成都是一个非常友好的城市,在这里我们都成了好朋友。葡萄牙运动员Machado mariana说,太神奇了,太棒了,一切都很好!我们真的很享受中国的文化和氛围,他们真的很善良。我们很自豪能来到这里,也很高兴能来到这里。中国香港运动员李孟宪说,这是全世界大学生选手都来的交流比赛,所以是一个很好的机会,尽力比赛,赢输没关系,做好自己最重要。(江苏广电总台·融媒体新闻中心记者/黎明 周颖 张允熙 编辑/胡超)(本条新闻版权归江苏省广播电视总台所有,转载请注明出处)
