2023-08-01 15:12，正文：原标题：杭城暑托班今年“亚运味”格外浓杭城暑托班今年“亚运味”格外浓 上城区暑期托管澎博小学服务点护航亚运活动。“你们了解亚运会吗？”“我知道杭州亚运会马上要召开了，学校在校门口设立了亚运会倒计时牌”“学校组织我们去做志愿者，清洁人行道，扮靓城市环境” ……7月24日，在杭州市澎博小学的教室里，穿着不同校服的学生坐在一起，和老师畅聊“亚运”。7月初，杭州多地启动暑托服务。顺利结束为期10天的第一期暑托班后，目前，不少学校的第二期暑托班陆续开班。记者从上城区教育局获悉，今年的暑托服务面临一个新情况：随着杭州亚运会的临近，不少从事亚运保障工作的家长这段时间都比较忙。在这类家长比较集中的暑托服务点，老师们在课程里加入了很多“亚运”相关的内容。“我们向家长传达的是‘你们安心保障亚运，我们贴心带娃’。”澎博小学老师金佳妮笑着说，学生们的爸妈有的在亚运场馆工作，有的从事电力、环卫、医疗工作，还有的是社区志愿者，所以这次暑托服务“亚运味”很浓。她拿出一份主题课程清单，每一天的安排都与“亚运”有关，“比如7月26日，主题是亚运场馆设计师，让学生画他们心中的场馆；如何种花、养花，营造‘花香迎亚运’的绿色氛围？我们安排了专门的园艺课程；最后一天还会办一个小型运动会。”学生小朱参加了澎博小学的两期暑托班，经过第一期的体验，他说自己对杭州亚运会的“参与感”更强了，“作为小小东道主，我将用实际行动助力亚运，用自己的活力和感染力带动身边的人参与到迎亚运的行列中来 。”在课程中加入“亚运”元素，也让不少学生对父母的职业有了更深的认同。参加了第一期暑托班的学生小陈，特意写了一篇作文，主题是爸爸。他的爸爸是一名建筑工人，参与了杭州亚运会场馆的建设工作，他写道：“‘扶风豪士天下奇，意气相倾山可移’……为了亚运会，齐心协力，我爸爸也算是李白口中的‘豪士’吧。”在另一个暑托服务点杭州采荷中学，学生父母参与亚运保障工作的情况也比较多。现场，学生在老师的指导下制模、覆盖、上色，按家庭合照亲手制作了拓印作品，还在背后写上“老爸，这段时间您辛苦了”“妈妈，我和弟弟在家都很乖，您放心”“爸爸，请放心工作，我们一家人永远支持你”……“同学们以拓印家庭照的方式，表达心中特别的爱与自豪。”学校副校长李永成说。返回搜狐，查看更多责任编辑：
