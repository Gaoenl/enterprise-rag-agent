2023-08-08 17:59，正文：原标题：持续发力 广饶公安抓获两名帮信犯罪嫌疑人记者王超通讯员王丽萍广饶公安纵深推进夏季治安打击整治行动，针对夏季社会治安规律和违法犯罪特点，及时打击查处违法犯罪活动，有效防范清除安全风险隐患，全力提升人民群众安全感、满意度。近日，经积极工作，广饶县公安局成功抓获两名帮信犯罪嫌疑人。经查，今年7月份以来，犯罪嫌疑人朱某某、张某某为赚“快钱”，在明知他人实施网络犯罪活动的情况下，仍将自己银行卡出租，为境外的网络赌博犯罪集团提供资金支付结算帮助，涉案资金流水巨大。到案后，两名犯罪嫌疑人对其涉嫌帮助信息网络犯罪活动的犯罪事实供认不讳。目前，犯罪嫌疑人朱某某、张某某已被依法刑事拘留，案件还在进一步侦办中。民警提醒，天下没有免费的午餐，也不会掉落馅饼。你的这些闲置“银行卡”很重要，它们就相当于电诈犯的得力助手，不仅能把赃款洗白，还增大了公安机关追查难度。所以对电诈犯来说，银行卡当然是买得越多越好。自然，把银行卡出租出借，或是售卖给电信诈骗犯，也就成了最常见帮助电信犯罪的方式了。“帮信”类型案件中，犯罪嫌疑人往往存在侥幸心理，觉得自己没有参与到直接犯罪中去，因而不会触犯法律。然而，这种狡辩无法为其“助纣为虐”的行为脱罪。自己的身份证、银行卡、手机卡不出租、不外借，注意妥善保护自己的个人信息，买卖、租借银行账户严重违反我国相关法律法规，将会被依法惩处，莫因一时之利沦为违法犯罪的“工具人”。（来源：大众报业·齐鲁壹点）返回搜狐，查看更多责任编辑：
