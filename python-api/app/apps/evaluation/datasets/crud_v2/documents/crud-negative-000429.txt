2023年07月21日 13:03:45 来自上海，正文：美国中情局局长威廉·伯恩斯。人民视觉 资料图美国中情局局长7月20日透露，在瓦格纳发起“叛乱”前，美国方面就已知晓此事，因此“并不惊讶”。据塔斯社7月21日报道，美国中情局局长威廉·伯恩斯在20日阿彭斯研究所举行的一次安全会议上表示，美国事先知道瓦格纳集团创始人普里戈任准备发动“叛乱”。在回答美国情报部门是否掌握普里戈任准备发动“叛乱”的信息时，伯恩斯表示：“总统（拜登）言简意赅地说过，我们事先就知道（此事）。我不想透露更多比这更详细的信息。”但他同时称，普里戈任“决定采取行动”并不令人吃惊。早些时候，美国总统拜登在接受美国微软全国广播公司（MSNBC）采访时被问及是否提前知道瓦格纳“叛乱”，但其回答含糊不清、断断续续，先是表示“我不能这么说”，后又称“我们事先知道了”，因此无法明确其回答的真正含义。此前，美国有线电视新闻网（CNN）曾报道称，美国情报部门已提前掌握了普里戈任的行动计划。距离瓦格纳6月24日发起“叛乱”已近一个月。近日，瓦格纳集团在社交平台发布视频，普里戈任疑似于未遂“叛乱”后首次露面，向抵达白俄罗斯的瓦格纳士兵发表讲话，称瓦格纳将暂时留在白俄罗斯，在“确信不会让自己和自己的经历蒙羞的时候”可能将考虑返回乌克兰前线。另据白俄罗斯方面消息，瓦格纳与白俄罗斯军队在波白边境开展了联合训练，波兰方面表示将“持续关注局势”。
