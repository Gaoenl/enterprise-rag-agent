卖的时候开发商说是一套大房子，被人为分割成“两套”，房产证也是两张。原本以为这样一来可以省点税，孰料“限购令”后就不能再购房，生出了一大堆麻烦。最近，这样的事情发生在了饶先生身上。大房子其实是两套饶先生是一名新杭州人，2009年初，饶先生和他的女友决定果断出手，为爱情筑窝。“当时手头上的购房资金很有限，只能挑那些价格低的楼盘。一个偶然的机会得知新西湖小镇价格很低，就决定去看看。”饶先生说，新西湖小镇在那段时间降价促销力度很大，于是他跟女友就一块前往新西湖小镇售楼处看房。饶先生回忆说，当时在售的是13号楼，售楼小姐告诉他都是大户型，150平方米以上。见价格还便宜，饶先生最终挑中了18楼的一套157平方米户型。不过事后售楼小姐告诉他，这其实是两套房子，到时候要办两张房产证。其中一套60多平方米，一室一厅；另一套90多平方米，两室一厅。初次购房的饶先生没搞明白，一套大房子为什么要拆成两套房？既然是两套房子，为什么要捆绑在一起出售呢？饶先生记得当时售楼小姐是这样对他说的：“虽然是两套房子，但原本就是一套房子，中间只隔了一堵墙，到时候打通就是了。”售楼小姐还说，这幢楼的房子都必须是两套一起买，单独买一套的话还真不好操办。为省税购房者下单售楼小姐的这一解释，饶先生并未完全理解。不过，售楼小姐最终还是说服了他，因为分成两套房可以少交一半税，这可是好事。“售楼小姐随后跟我讲了分成两套房的好处，可以少交税。按照当时的规定，140平方米以上的房子要交3%的契税，而140平方米以下的房子只需交1.5%。”饶先生说，售楼小姐的这一番话倒是打动了他。既然分成两套房没什么坏处，而且还可以少交点税，何乐而不为呢？饶先生顿时心存感激，对于像他这样的刚需来说，能省一点是一点。于是，饶先生决定买下这套房子——从法律上说是两套房子。拼接房带来限购烦恼如今饶先生和女友已经成婚，当初买下的房子开始给这个家庭带来烦恼。因为根据限购令，饶先生就不能再买房了。“房子原本去年底就该交付，一直延期到上个月，不过我还没去收房。按理说现在总算交房了心里高兴才对，可我心里怎么也高兴不起来。”饶先生说，由于新西湖小镇地处余杭中泰乡，离市区实在太远。虽说靠近高速，走高速进城很快，但交通成本太高。思前想后，饶先生打算卖掉那边的房子，到市区重新买一套。可问题来了。由于饶先生和他妻子名下共有两套房产，按规定必须卖掉一套才能再买进一套。是卖90多平方米的那套，还是卖60多平方米的那套？要是把90多平方米的那套卖了，那么60多平方米的那套以后就会成为烫手山芋，自己是不可能跑那么远去住只有一室一厅的房子，要卖的话估计也不会有人接手。想来想去，饶先生决定将两套房一同转手。但这个决定从操作层面上说非常棘手。限购令下，只有无房户才能一次性买进两套房。即便有人符合购买资格，也会考虑买下之后的后遗症——不能再购买其他房产了。退一步讲，即便有人愿意买下，饶先生的换房计划还会碰到一个障碍。由于之前买下的这两套房子都贷过款，根据银行认房又认贷的规定，饶先生再购房的话，就必须全款付清。[1][2]下一页尾页
