2023-08-01 16:30，正文：原标题：拜登政府想让尼日尔总统重新掌权，上千美军暂被“限制”！据美国有线电视新闻网网站7月31日报道，在拜登政府努力让尼日尔总统穆罕默德·巴祖姆重新掌权之际，驻尼日尔美军被限制在位于该国阿加德兹的美军基地。报道称，一名美军官员表示，大约1000名士兵上周“退回”了上述基地，而这就发生在7月26日巴祖姆被总统卫队成员扣押后不久。报道称，美国尚未正式就尼日尔发生的事件是否构成政变作出决定。如果认定发生政变，美国将停止对尼日尔政府在军事等方面的援助，而这可能对该地区的反恐斗争和稳定造成严重后果。美国国务院一名高级官员7月31日表示：“我们正在非常非常努力地工作，看看能否扭转局面。由于局面尚未尘埃落定，我们认为应该尝试抓住这个机会。”▲7月30日，尼日尔安全部队发射催泪瓦斯驱散尼亚美法国大使馆外的抗议人员。（路透社）7月27日，美国参谋长联席会议主席马克·米利同尼日尔军方领导人通了电话。美方发表的一份声明称：“两位领导人讨论了美国人员的安全和尼日尔的局势发展。”报道指出，美国在尼日尔的总体军力态势没有改变，因为这需要单独的政策决定。一位美军官员表示，五角大楼正在“保持战略耐心，观察局势变化”。美国在尼日尔驻军已有大约十年时间，主要是为尼日尔军队提供反恐方面的建议和培训。上述美国国务院高级官员表示，仍然没有迹象表明像瓦格纳集团这样的团体在军事接管或随后的抗议活动中发挥了任何作用，但是“当然，这是我们的预期——你已经听到（瓦格纳集团创始人）普里戈任的讲话——他们会尝试并利用它”。（来源：参考消息）返回搜狐，查看更多责任编辑：
