2023-08-18 15:37，正文：原标题：乐高集团乐乐箱玩乐嘉年华在长沙启动，助力困境儿童学习发展(知消2023年8月18日讯)乐高集团乐乐箱玩乐嘉年华在长沙正式启动，以更丰富的玩乐体验助力困境儿童的学习和发展。这也是“乐乐箱困境儿童关爱计划”自2019年成立以来的一次重要创新发展。乐高集团乐乐箱玩乐嘉年华在长沙正式启动 本次玩乐嘉年华邀请到近200名来自长沙市长沙县的困境儿童前来参与活动，这些孩子都是居住在当地社区的流动儿童和留守儿童。这也是玩乐嘉年华的首次亮相。该项目为孩子们提供十多项以“乐乐箱”为核心工具的玩乐活动，其中包括平衡高塔、火星上的家、明日的愿望、拆书部落、破解数独、穿越火线和暗影侦探等，在充满趣味性和互动性的活动中，让孩子们尽情发挥自己的想象力和创造力。同时，孩子们还能在玩乐中学习如何解决问题、结交新的朋友、与他人合作与沟通、表达自我的想法等等重要的能力。和以往的乐乐箱玩乐活动相比，玩乐嘉年华的活动规模更大，参与者的数量也更多，可容纳上百名儿童参与活动。其提供的玩乐活动也更加丰富多元，覆盖从创造能力、社交能力、认知能力、情绪能力到运动能力等全方位的能力培养和发展，是“乐乐箱计划”发展过程中一次重要的创新。“‘乐乐箱计划’从2019年成立以来，携手众多中国本地的公益机构，致力于将高品质玩乐体验带给身处不同困境的儿童，守护他们玩乐的权利。“乐乐箱计划”是乐高集团在中国开展的主要社会责任项目之一，通过其自主开发的公益工具“乐乐箱”及相关玩乐培训，赋能本地公益机构合作伙伴，以充满创意的玩乐体验支持流动儿童、留守儿童、病患儿童等身处不同困境同时缺乏玩乐机会的儿童群体，为他们提供在玩乐中学习和发展的机会，为孩子们的未来种下无限的可能。返回搜狐，查看更多责任编辑：
