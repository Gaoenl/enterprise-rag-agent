"来源：海外网8月8日晚，第31届世界大学生夏季运动会闭幕式在成都露天音乐公园举行。图为参赛代表团旗帜入场。（图源：新华社）8月8日晚，成都第31届世界大学生夏季运动会闭幕式在成都露天音乐公园举行。闭幕式舞台以“手机”为设计元素，手机视窗高低错落，并创造性增设一名“大运拍客”，完成一场全球联动的青春“直播”。12天的精彩赛事见证青春绽放，引燃无数激情梦想，奏响团结友爱的青春之歌。这是一场中国味十足的盛会。成都大运会闭幕式恰逢中国立秋，告别夏日迎接金秋之际，“中国红”再次闪耀世界。“蓉宝”大玩混搭风，与流行女团、说唱、川剧、清音、木偶变脸等碰撞出火花，中华文化在一次次灵动、鲜活的表演中得以诠释。赛场内外，成都大运会用中国元素不断刷新世界审美。比赛场馆内，奖牌的太阳神鸟、会徽的传统色、绶带的芙蓉花、熊猫体育图标的中国书画……诸多细节之处中国风拉满，向世界展现独特巴蜀风韵；大运村里，非遗体验活动等丰富多彩的“文化饕餮盛宴”让各国青年沉浸式感受中国文化之美。这是一场青春绽放的盛会。中国青年运动健儿在成都大运会上斩获103枚金牌，中国代表团金牌数、奖牌数均列第一，这也是中国队参加历届大运会以来单届金牌数最高纪录，中国也因此成为大运会历史上第二个在一届大运会上金牌总数破百的国家。每一枚奖牌背后，是青年运动员们数年如一日的艰辛训练，汗水和泪水浇灌的青春之花在这个盛夏恣意绽放。田径女子10000米比赛中，来自清华大学的夏雨雨在最后一圈发起挑战，超越领先于她的对手夺得冠军；跆拳道女子团体品势决赛中，来自重庆经贸职业学院的李婉和队友直面强劲对手，在上场前30分钟决定挑战“踺子后空多腿”这一高难度动作；女排决赛之夜，在全场观众的助威声中，中国队以3:0战胜日本队……怀揣梦想勇往直前，他们树立的青春榜样将激励更多人努力奔跑。一同挥洒汗水的，还有来自中国不同高校的共计2万名志愿者。被亲切称为“小青椒”的他们以热情、细致、周到的服务成为一道靓丽风景线，展现自信阳光的中国青年风貌。这是一场团结合作的盛会。闭幕式上，当川剧青衣与说唱歌手对歌、流行女团与说唱俑造型打击乐手和鸣，一次次中西、古今的融合充分展现“美美与共”。大运会不仅是体育盛事，更是一次人类团结和平友谊的盛会。各国运动员相聚蓉城，在追梦圆梦过程中共同进步，在“成都成就梦想”的守望中跨越隔阂，书写了一个个团结友爱的故事，为世界带来温暖和希望，让大运精神更加熠熠生辉。在羽毛球男单比赛中，乌干达选手球拍断线，中国选手王正行把自己的另一副球拍借给了对手；跆拳道女子73公斤以上级半决赛上,伊朗选手与铜土耳其选手赛后紧紧拥抱鼓励，完全忘却赛场上的激烈竞争；中国羽毛球选手谭强看到对手巴西运动员的鞋子有些破旧，赠送他一双新鞋……来自全球113个国家和地区的6500多名运动员在成都大运会舞台上追逐梦想、结下友谊，演绎团结的力量。一棵枝叶繁茂寓意生命茁壮的巨型珙桐树“生长”于舞台之上，朵朵象征和平的鸽子花绽放其中……被国际大学生体育联合会代理主席雷诺·艾德评价为“精彩绝伦”的成都大运会，在这个夏天为世界留下难忘的成都记忆。成都大运会再见，青春之歌未央！（栾雨石）海外网版权作品，未经授权不得转载。举报/反馈",
