新型冠状病毒感染的肺炎疫情快报最近，黑龙江全省上下全力应对疫情，努力确保疫情不扩、复工不迟、春耕不误。常态化防控确保疫情不扩经过不懈奋战，黑龙江省近期出现新冠肺炎疫情的哈尔滨等地已连续多日保持社会面清零。近日，随着疫情形势逐步好转，哈尔滨市逐步有序解除主城六区社会静态化管理措施，科学设置了多处免费核酸采样点，常态化防控下，进入商场、超市等公共场所仍需测温、扫码、出示48小时核酸检测阴性证明，对无疫社区村屯等每间隔一日进行一次核酸检测，重点人群每日进行一次核酸检测。市民在哈尔滨市荣市社区一处核酸采样点进行核酸检测。新华社记者 闫睿 摄“虽然社会面清零了，但并不意味着风险清零。”哈尔滨市文景社区工作人员李君说，快递送来后要统一消毒，再由居民取走。在哈尔滨市荣市社区的一处核酸采样点，医护人员、社区工作者各司其职，依旧忙碌着。哈尔滨新区近八成项目开复工机器轰鸣中，哈电集团汽轮机公司动装分厂钳工杜磊一直在忙碌，“这次任务比较紧，我们安排好班次，24小时连班装配，确保不耽误交货。”哈电集团是我国重要的发电设备制造和研发基地。“我们制定了健康筛查、闭环管理和应急保障等一整套疫情防控方案，员工出勤率目前保持在95%以上。”哈电集团电机公司生产部经理王洪锦说。哈电集团电机公司生产车间。新华社记者 强勇 摄4月，中铝集团东北轻合金有限责任公司高端合金产量同比提升了24.7%，公司1200多名职工为保障国家重大工程项目用材，实行驻厂生产。在公司锻压3000吨水压机工作现场，锻压乙班区域技师侯文峰正在锻造某重点型号模锻件，“今年订单多，我们要抓紧时间往前赶。”他说。目前，在国家级新区哈尔滨新区，近八成项目已开复工。旱田播种面积已超9600万亩9日，在北大荒集团鸭绿河农场有限公司开阔平整的水稻田里，一台台安装了北斗导航系统的插秧机，满载水稻秧苗缓缓前行。“有了高科技助力，作业效率提高了，水稻秧苗全部插在高产期。”鸭绿河农场有限公司第二管理区水稻种植户段希秋说。这是北大荒集团鸭绿河农场有限公司的插秧现场。（受访单位供图）在黑龙江省富锦市，农业部门引导种植户抢抓晴好天气，全面开展玉米大田播种作业，一台台农机在田间穿梭不停。在哈尔滨市巴彦县丰裕现代农业农机专业合作社，2400余亩玉米播种作业已全面结束。黑龙江省委组织部动员全省各级党组织和广大党员深入田间地头，组建备耕春耕服务队，为农户提供有力服务和保障，黑龙江省各级农业农村部门加强与气象部门沟通，全力做好信息传递、技术指导。记者从黑龙江省农业农村厅获悉，截至5月9日，黑龙江全省旱田已播种超9600万亩，水稻插秧超260万亩，大豆已播种1600万亩以上。原标题:黑龙江：防疫不松懈，生产加把劲
