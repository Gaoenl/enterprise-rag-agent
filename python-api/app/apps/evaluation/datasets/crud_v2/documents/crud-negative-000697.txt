“小朋友们，欢迎大家！今天我们暑期托管班正式开营啦！”7月18日，在南京玄武区儿童“关爱之家”，“爱心托管，同心筑梦”暑期托管班正式开班。科学实验、学业辅导、心理疏导……孩子们将在这里度过一个充实的暑假。暑期来临，江苏各地民政部门充分利用关爱之家阵地，急农村留守儿童、困境儿童所需，开设儿童身边的“爱心暑托班”、夏令营，由专业社会组织筛选培训优秀的大学生志愿者、公益爱心人士，开发特色微项目引入优质资源，为农村留守儿童、困境儿童及有需求的儿童提供党史教育、劳动实践、角色体验、艺术修养、法治教育、安全急救、素质拓展等关爱服务。孩子们不但暑期有了专业照护，同时还能提升沟通交往、协作共享能力。监护有专人 授课有特色今年暑假，泰州市民政局联合团市委、市教育局、市文明办、市关工委等部门，在全市开办“青仔公益暑托班”，为孩子们提供公益暑托“套餐”服务。依托儿童“关爱之家”场所，泰州科学设置办班点131个，确保每个乡镇（街道）至少开办一个公益暑托班。据了解，“青仔公益暑托班”为期4周，各办班点不收取任何费用。各办班点以在读小学的困境儿童、留守儿童为重点服务对象，兼顾快递小哥、网约车司机等新兴青年群体子女，积极动员和帮助有困难的服务对象入班，共提供4641个名额。对于距离较远、家长接送有困难的困境儿童，鼓励采用“送课上门+线上助学+集中实践”相结合的方式开展服务。在常州溧阳市民政局主办的“小树之家”暑期公益课堂，国家二级心理咨询师正在为孩子们开展“心理角色转换”“构建自我认知”等主题辅导课。昆山市依托落地在各区镇儿童关爱之家里的12个“点亮希望·伴你成长”社工服务项目，将重点服务对象由困境留守儿童延展至新市民子女等，采取线上+线下的方式，集中在暑期组织开展安全教育、抗逆力情绪管理、伴学成长、正面管教、职业体验、人际交往、社区融入等特色服务。截至7月19日，江苏全省749个未保工作站（关爱之家）共开设公益“爱心暑托班”2400多个班次，服务困境留守儿童及外来务工人员子女约3.1万人，投入经费达1000万元。8月陆续还将有新的暑托班和夏令营开班、开营。江苏省民政厅儿童福利处相关负责人表示，“暑托班”既要照料好孩子们的生活，又要兼顾成长发展需求，责任重大。各地民政部门严密组织、制定预案、加强培训、责任到人，确保暑托班活动全程安全，为全省困境儿童、农村留守儿童打造暑期第二个温馨之家。今后，暑托班还要标准化、常态化开展下去，把“暑期公益课堂”“搬进”更多镇村、社区和家庭，让孩子们度过一个快乐而充实的假期。（来源：江苏广电融媒体新闻中心/王敏 编辑/国正）
