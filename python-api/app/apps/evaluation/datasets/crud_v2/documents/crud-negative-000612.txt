7-24 07:23，正文：                                                                                                                                                                                                                                                                         记者从齐齐哈尔市搜救现场指挥部了解到，截至24日3时，齐齐哈尔市第34中学体育馆屋顶坍塌事故已造成9人死亡。  事故发生时，馆内共有19人，其中4人自行脱险，15人被困。截至24日3时，被困人员中9人已死亡，4人无生命危险，仍有2人被困，救援还在紧张进行中。  经现场初步调查，与体育馆毗邻的教学综合楼施工过程中，施工单位违规将珍珠岩堆置体育馆屋顶。受降雨影响，珍珠岩浸水增重，导致屋顶荷载增大引发坍塌。深入调查仍在进行中。  目前，教学综合楼施工单位责任人已被公安机关控制。(央视新闻客户端)  【编辑:房家梁】                                                                                                                              更多精彩内容请进入社会新闻
