2023-07-24 23:00:56，正文：湖南天心种业临澧育种基地。天心种业荆州基地。红网时刻新闻7月24日讯（记者 陈雪骅 通讯员 谭吕佳）近日，农业农村部办公厅发布《关于公布2022年国家畜禽核心育种场等遴选核验结果和信息变更的通知》，湖南天心种业有限公司延续国家生猪核心育种场资质，这也是本次通过核验的省内唯一一家国家级生猪核心育种场。自2012年首次被农业农村部遴选为国家生猪核心育种场后，天心种业已连续11年保持该项国家级资质。天心种业是国家生猪核心育种场，国家畜禽养殖标准化示范场，农业农村部动物疫病净化示范场，农业农村部非洲猪瘟无疫小区，国家生猪产业体系长沙综合试验站站长单位。作为高新技术企业，公司“天心”牌种猪荣获中国畜牧业协会“中国品牌猪”称号。主要生产新美系杜洛克、长白、大约克原种种猪以及长大二元母猪，种猪场采用自繁自养模式开展生猪的培育及销售，经过多年的选种、选育和技术攻关，“天心”牌种猪具有生长性能好、抗应激能力强、产仔数高、泌乳力强、肢体强健、料肉比底、瘦肉率高等特点。随着我国生猪养殖全产业链转型升级，天心种业公司将继续聚焦主责主业，强化产业有效协同，提高产业链韧性和安全水平，加快夯实生猪产业链“链主”基础，坚持把关键核心技术掌握在自己手里，打造生猪育种策源地，扛稳兴农强省使命。
