2023-08-15 16:37，正文：原标题：智飞生物向河北省洪涝灾区捐赠1000万元智飞生物向河北省洪涝灾区捐赠1000万元。智飞生物供图近日，受台风“杜苏芮”影响，河北省遭遇了罕见的暴雨洪涝灾害。一方有难，八方支援。8月15日，智飞生物通过重庆市慈善总会向河北省洪涝灾区捐赠1000万元，用于购买当地基层医疗卫生机构急需的救护车、心电图机等物资，支援当地的应急医疗服务保障和灾后重建工作。“此次灾情牵动着全国人民的心，也牵动着全体智飞人的心。”智飞生物副董事长、副总裁蒋凌峰表示，公司在第一时间启动了捐赠程序，希望本次捐赠能够为保障人民群众健康、帮助灾区人民重建家园贡献一份力量。据悉，智飞生物自成立以来，始终秉承“社会效益第一，企业效益第二”的宗旨，时刻关注社会需求，积极投身公益事业，履行企业社会责任，近年来累计捐资捐物超过4亿元。公司入选全国工商联2021中国民营企业社会责任优秀案例，并在全国22家优秀案例中位列第一；获得全国慈善会系统“2021年度爱心企业”；获得“2022中国企业慈善公益500强”等多项荣誉。未来，智飞生物将继续以高度的责任感和使命感，践行企业的责任与担当，为公益慈善事业发展贡献更多力量。(陈卓)返回搜狐，查看更多责任编辑：
