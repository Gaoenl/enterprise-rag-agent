（观察者网讯）“胜选当晚，我要给普京和泽连斯基打电话，我们将在24小时内达成协议。”据美国“佛罗里达之声”新闻网当地时间2月20日消息，美国前总统特朗普当天在一场活动上大放豪言，称自己如果再次当选总统，将立即给俄罗斯总统普京和乌克兰总统泽连斯基打电话，促成三方会谈，并且在24小时内达成协议，解决冲突。特朗普 资料图特朗普当天出席一场在佛州西棕榈滩举行的活动，被问及如何结束乌克兰冲突，他对台下支持者们说道：“胜选当晚，我要打电话给普京和泽连斯基，我会说，‘我们得碰个面’，我保证我能解决这个问题。我们将在24小时内达成协议。”美国《滚石》杂志报道称，特朗普还在当晚的集会上吹嘘了自己和普京的私人关系，称如果自己还在位执政，俄罗斯永远不会对乌克兰发起军事行动。“佛罗里达之声”官方推特截图这并非特朗普首次在俄乌问题上如此表态。上个月，特朗普在其自创社交媒体“Truth social”上发文，称自己有能力24小时内结束俄乌冲突。“如果我是总统，俄乌战争永远不会发生；但即便到如今，如果总统位上的是我，我也能在24小时内通过谈判结束这场可怕的、迅速升级的战争。这么多生命白白被浪费，太悲惨了！！！”特朗普当时写道。他还批评拜登政府不断给乌克兰提供军事援助，运送主战坦克，很可能会将局势升级为“核战争”。对于特朗普的言论，克里姆林宫发言人佩斯科夫1月27日回应称，他部分同意特朗普关于西方向乌克兰提供坦克或加剧危机的言论。他说，“人们可以同意这一说法”，因为紧张局势正在升级。佩斯科夫还表示，在许多方面，基辅政权的命运掌握在华盛顿手中。“如果美国总统希望结束这场冲突，他可以很快做到。”佩斯科夫说道，但美国总统拜登似乎不愿意接受这样的政策，而是选择“进一步向乌克兰提供武器”。特朗普上月发文称“24小时解决俄乌冲突”就在特朗普20日放言“24小时解决俄乌冲突”之际，拜登突然访问乌克兰首都基辅，会见乌克兰总统泽连斯基。拜登在会谈中向乌克兰重申美国和其盟友的支持，并且承诺美国将向乌克兰提供约5亿美元的军事援助。泽连斯基则对美国的支持表示感谢，并宣称“会晤中的广泛讨论使我们更接近胜利”。拜登此次基辅之行共持续了5个小时左右。美国哥伦比亚广播公司（CBS）称，拜登已在当地时间20日晚些时候抵达波兰，预计将在21日会见波兰总统杜达，讨论美国与波兰的合作以及支持乌克兰的问题。当地时间2月20日，美国总统拜登与乌克兰总统泽连斯基在基辅举行会谈在突访乌克兰的几个小时后，美国五角大楼宣布将向乌克兰提供4.6亿的新一揽子军事援助，包括“海马斯”火箭弹、反坦克系统、对空监视雷达等装备。美国全国广播公司（NBC）指出，如今美国向乌克兰提供的军事援助已接近300亿美元。本文系观察者网独家稿件，未经授权，不得转载。举报/反馈
