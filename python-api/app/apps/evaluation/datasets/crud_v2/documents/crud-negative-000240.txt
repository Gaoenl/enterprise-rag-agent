2023-08-11 10:39，正文：原标题：外媒：成都大运会“令人激动和感动”参考消息网8月11日报道 据德国奥林匹克体育同盟网站8月9日报道，8月8日，在中国成都露天音乐公园举行的大运会闭幕式上，国际大学生体育联合会会旗被移交给下届主办方德国。德国联邦内政与国土部议会国务秘书马哈茂德·厄茨德米尔和国际大学生体育联合会执行委员会首席执委贝雷娜·布尔克代表德国接过了会旗。厄茨德米尔表示，他对此次大运会感到兴奋，并期待着两年后欢迎运动员们到访德国。另据拉美社8月9日报道，各国运动员9日启程回国。对于在刚刚闭幕的成都大运会上的经历，他们纷纷表示受益匪浅、感触颇深。美国代表团成员戴维·安东尼说，这是一次精彩、安全且达到最高标准的盛会。他对媒体说：“我的特别记忆是这里的人，我遇到了许多出色的志愿者和工作人员，他们态度热情、笑容满面。”匈牙利击剑运动员本亚明·弗鲁霍夫认为，这是一个很好的机会，得以构建一个这项运动的国际网络，结识学习类似技能的人。德国代表团成员斯韦娅·塔姆森认为，大运会的经历“确实令人激动和感动”。她说：“来自世界各地的运动员相聚于此，有一种团队合作的感觉，我们同台竞争，也相互鼓励，营造出一种和谐团结的氛围。”此外，马来西亚《新海峡时报》网站8月7日的报道称，成都世界大学生运动会激发了青春活力。报道称，夜幕初降，成都大运村里的文化市集流光溢彩，投壶、蹴鞠……来自世界各地的大学生运动员饶有兴致地交流互动，交换徽章、分享快乐。自成都大运会开幕以来，大运村里住满了不同国籍、不同语言的大学生运动员。国际大学生体育联合会代理主席雷诺·艾德对中国秉持简约、安全、精彩的办赛理念，认真兑现庄严承诺，确保成都大运会顺利举办表示感谢。报道还说，在中国与国际大学生体育联合会和各国各地区代表团共同努力下，成都大运会成为一届具有中国特色、时代气息、青春风采的国际体育盛会。8月8日，演员在闭幕式上表演。当晚，第31届世界大学生夏季运动会闭幕式在成都露天音乐公园举行。（新华社）返回搜狐，查看更多责任编辑：
