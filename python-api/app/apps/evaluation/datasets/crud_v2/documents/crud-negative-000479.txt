8-7 13:42，正文：                                                                                                                                                                                                                                                                         中新网宁波8月7日电(林波 方舟)8月7日，记者从浙江省宁波市江北区农业农村局获悉，该市一艘鱿鱼钓船获农业农村部批准，入渔阿根廷专属经济区海域作业。这是该市渔船首次进入阿根廷200海里海域。    甬发8号渔船靠泊码头。中新社发 方舟摄  近几年来，西南大西洋公海作业渔船不断增加，鱿鱼产量持续低迷。阿根廷200海里专属经济区内渔业资源丰富，与公海生产相比，在该区内进行鱿钓渔业生产的产量具有明显优势。  基于此，众多国家渔船竞相入渔。  据了解，该船系宁波甬发远洋渔业股份有限公司的甬发8号渔船。    甬发8号渔船一景。中新社发 方舟摄  据宁波甬发远洋渔业股份有限公司总经理吴梦男介绍，该公司于今年上半年购置这艘大型鱿鱼钓船，并与阿根廷方达成合作协议，获得鱿鱼配额，“目前该项目已完成国内手续，预计最快能在明年阿根廷渔季入海作业。”  据悉，该项目投产后，预计年捕捞鱿鱼2000吨，产值4000万元，90%的渔获全部运回国内销售。(完)  【编辑:黄钰涵】                                                                                                                              更多精彩内容请进入财经频道
