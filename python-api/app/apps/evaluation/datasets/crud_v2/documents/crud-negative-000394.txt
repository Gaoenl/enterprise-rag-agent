据德国《法兰克福汇报》网站6月23日报道，印度当局正在调查极端高温导致的上百人死亡情况。据《印度时报》报道，在印度人口最多的两个邦北方邦和比哈尔邦受影响地区，目前死亡人数约为170人。过去几天，这些地方的最高气温已达46摄氏度。围绕实际死亡原因爆发了一场政治争吵。北方邦伯利亚区一家公立医院的院长在将一些患者的死亡归因于中暑后，因发表“不负责任的言论”被解职。当地官员指出，这些死者均年事已高，并且此前已患有其他疾病。批评者指责地方和国家政府没有采取足够的措施预防死亡病例。他们认为，大量高温死亡病例反映了卫生系统的不堪重负和准备不足。例如，反对派政治家、北方邦前首席部长阿基莱什·亚达夫认为这是“地方政府的疏忽”所致。他说，死者都是贫穷的农民，他们因得不到食物、药品和及时治疗而死亡。那里缺少公立医院和预警系统。根据政府间气候变化专门委员会的说法，印度是受气候变化影响最严重的国家之一。在4月份出现极端气温之后，科学家在一项研究中指出，由于气候变化，印度和孟加拉国发生热浪的可能性已增至原来的30倍。鉴于全球变暖，热浪的温度比从前平均高两度，而且可能大约每两年重复出现一次。季风延迟到来也增加了电力消耗，导致频繁停电。因此，科学家认为准备好高温行动计划非常重要。印度是该地区拥有此类计划的少数国家之一，然而在较低行政层级上实施不力。印度卫生部长现已指示7个受影响邦的代表审查各自的预备措施。地方政府显然不希望将死亡与高温联系起来。然而，在受影响地区医院就诊的患者之多恰恰表明了这种联系。目前医院的情况已经堪比新冠大流行的高峰期。据美联社6月23日报道，印度一家政府救援机构23日说，季风暴雨本周袭击了印度东北部村庄，有一人在洪水中死亡，数万人在政府管理的救灾营地避难。阿萨姆邦已经进入红色警戒状态，将生活在低洼地区的民众撤离，准备应对本周末更多的暴雨。该邦受季风洪水影响的人口已接近50万人。亚洲最大河流之一布拉马普特拉河每年都会发生洪水。这条河流在阿萨姆邦境内有1280公里，然后流入孟加拉国。来源：参考消息网举报/反馈
