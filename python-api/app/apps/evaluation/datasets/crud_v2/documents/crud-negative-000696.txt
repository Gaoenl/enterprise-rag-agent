2023年08月15日 14:44:14 来自湖北，正文：极目新闻记者 陈俊作为台湾军方的导弹试验场，位于屏东县的九鹏基地本月来第二次出现意外事故。综合台湾“中时新闻”、中天新闻网报道，本月初刚刚发生余药销毁燃烧意外造成4人受伤的台湾“中山科学研究院”九鹏基地8月15日早又出意外，一枚“爱国者”导弹近距离自爆。目前“中山科学研究院”及军方正在了解原因，这是爱国者二型导弹在岛内射击首度发生意外。空中爆炸（图源：中天新闻网）报道称，15日清晨6点30左右，九鹏基地发射两枚“爱国者”导弹，但第一枚导弹射向高空，发出一声巨响之后，在空中炸出火花，不明原因近距离自爆。不过，意外没有影响第二次发射，相隔一个小时，基地又发射一枚“雄三”导弹。根据台军消息，这是针对台湾岛东南部海域，从8月1日到25日的重要操演，有空对空和空对海导弹，还有反舰和防空导弹的实弹射击。发射现场（图源：中时新闻网）据此前8月3日报道，九鹏基地当日进行剩余火药销毁作业时，发生不明原因的燃烧，导致四人受伤，其中一人全身达90%的二到三度烧烫伤，四个人全部转送医院救治。军方人士说明，推进剂是制造导弹等设备的火药之一，目的是让弹药往前推进，但在制作推进剂的过程中，不可能全数用完，一定会有剩余，相关人员在销毁这些剩余火药的过程中发生意外。台军九鹏基地位于屏东，隶属于台“中山科学研究院”下属第二所，实际上是台军各式导弹和火箭武器系统的综合性试验、组装及研制基地，是岛内唯一的导弹、火箭等武器的发射试验场，是“台湾秘密研制具备战略攻击能力的战术性地对地导弹的唯一地点”，台军曾称该基地是“亚洲最大的导弹基地”。“爱国者”导弹（图源：中时新闻网）“爱国者”导弹是美国雷神公司制造的中程地对空导弹系统，在伊拉克战争中声名大噪。
