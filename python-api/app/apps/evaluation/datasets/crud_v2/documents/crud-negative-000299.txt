央广网北京6月30日消息（记者王晶）今年7月11日是我国第19个航海日，2023年中国航海日论坛暨全国航海日活动周启动仪式将于当天上午在河北省沧州市举办。届时，船舶挂满旗并统一鸣笛1分钟，2023年中国航海日公告也将同时发布。6月30日举行的国新办新闻发布会介绍了上述情况，并公布今年航海日的主题为“扬帆新丝路，奋楫新格局”。今年是中国提出共建“一带一路”倡议十周年，也是中国恢复国际海事组织合法席位50周年。交通运输部总工程师、水运局局长李天碧表示，今年的主题明确倡导要充分发挥航运在“21世纪海上丝绸之路”建设中的优势作用，进一步加强国际航运交流合作共赢，推动国际航运更高质量发展。国新办举行上半年水运高质量发展及2023年中国航海日发布会（央广网记者 王晶 摄）船舶将挂满旗并鸣笛1分钟李天碧介绍，今年航海日将有三项权威发布，包括2022年中国航运发展报告、2023年全国五一劳动奖和全国工人先锋号航海领域表彰名单、中国航海科技奖获奖名单，系统、全面展示一年来航运发展的成就和亮点。7月10日至15日期间将举办9个专题论坛，涉及航海技术与安全、国际海员、港航企业发展、疏浚、航海文化等多个方面。今年还新增了船长轮机长沙龙，为一线航海工作者提供交流互鉴平台。此外，今年是中国恢复国际海事组织合法席位50周年，因此组织了“中国与国际海事组织五十周年”专题论坛。今年将通过线上线下方式举办航海科普、群众性纪念活动等。同时，各地航海博物馆、展览馆和航海科普教育基地也将向社会公众开放。6月28日，南京，船舶航行在长江航道南京长江大桥附近水域我国190万余名注册船员如何分布？就当前船员队伍发展情况，交通运输部副部长付绪银在回答记者提问时介绍，截至2022年底，我国注册船员总数190万余人，其中海船船员90万人、内河船员100万人。付绪银介绍，2022年，我国外派到世界各地的船舶任职的船员达到12.7万人次，为国际水上物流供应链稳定，特别是疫情期间，确保国内国际双循环提供了有力支撑。“交通运输部一直高度重视船员工作，近年来出台了一系列措施，推动高素质船员队伍的建设。”付绪银表示，一是深化船员管理改革。不断强化船员培训考试管理，严把船员培训考试关。深入推进航海教育培训质量评估工作，深化“用、学、考”一体化改革。同时大力惩戒伪造船员资历和船员考试作弊等行为，编制发布《海船船员考试大纲（2022版）》，提升船员管理法治水平。二是不断优化船员发展环境。强化多部门协同联动，全面推进海事劳工履约，构建和谐海上劳动关系。大力宣传船员价值和贡献，提高船员职业社会关注度和认可度。三是强化船员合法权益保障。疫情期间，积极采取措施做好国际航行船舶船员疫情防控工作，保障了53.7万人次的船员换班。交通运输部开通“全国船员业务咨询热线（4008566180）”，编制发布《船员从业及维权指南》《船员职业百问百答》等小册子，通过这些基础工作保障船员合法权益。付绪银表示，下一步，交通运输部将继续做好船员培训考试发证工作，保证船员质量，推动优化船员发展环境，强化船员职业保障工作，促进高素质船员队伍建设，为我国水上物流供应链稳定畅通继续提供坚实支撑。6月26日上午，浙江舟山，来自全国各地的50名运动员分驾5艘小艇，参加第六届中国海员技能大比武水上操艇（预赛）如何培养航海人才？中国航海学会连续多年参加航海日活动，是国家发展航海科技事业的重要社会力量，中国航海学会常务副理事长张宝晨介绍，对于好的成果予以奖励，通过奖励、通过评价发现优质人才和优秀团队，这是基础性工作。“与此同时，把创新链、产业链、人才链、资本链融合到一起，有需求的企业不了解成果，有科研成果的机构不知道需求在哪里，我们学会可以进行对接。”张宝晨说，在这个方面，组织实施科技服务团的项目，围绕新技术、新成果组织院士、专家到有需求的地区或企业服务。近三年来，中国航海学会推荐的候选人都获得了国家创新争先奖。推出“青年科技奖”“青年人才托举工程”，发现值得培养的航海领域青年人才，进行指导、辅导，找大师传帮带。张宝晨称，目前看，中国航海科技奖的含金量越来越高，大家的认可度也越来越高，我们推荐的人才和项目，获得了国家科技特等奖、国家科技进步一等奖、科技发明奖等。据介绍，航海学会作为全国性的科技社团，同时作为水路交通运输全产业链的科技社团组织，服务于航运、海洋、造船、渔业，包括国防等各个领域。学术交流、智库、科普、科技服务是四大职能，航海科技服务、促进人才发展是学会非常重要的工作。
