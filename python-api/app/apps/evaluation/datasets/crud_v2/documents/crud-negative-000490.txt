2023-08-16 17:21:54，正文： 	中国山东网-感知山东8月16日讯 8月16日，以“千年古崖州 和美新渔港”为主题的2023中国（南海）三亚开渔节暨崖州中心渔港水产品交易中心开业活动在三亚崖州中心渔港举行。 	中午12时，随着一声开船令下，嘹亮鸣笛声响起，停靠在三亚崖州中心渔港码头的近百艘渔船浩浩荡荡朝着南海的方向破浪而行，开启了新一轮耕海牧渔的作业生活。这标志着历时3个半月的南海伏季休渔期结束，南海迎来新渔季。 	当天，“奋进自贸港 谱写新篇章”2023年全国重点媒体海南行暨交流推介活动采访团走进渔港，与渔民共同体验渔家生活、渔家文化，共享这场极富崖州特色的“渔业+旅游”文化盛宴。 	 	与往届开渔节不同，今年开渔节以全新开业的崖州中心渔港水产品交易中心为主题活动举办地，从8月16日至18日为期三天的活动全面升级，精心策划了渔业展销会暨休闲渔业发展论坛、和美渔村运动会暨崖州区首届排球村VA、“渔见崖州”美食市集等一系列活动，多角度生动展现崖州渔家文化，既融合了行业论坛的专业性和公众活动的参与性，同时致力打造高质量的三亚海洋文化旅游节庆品牌，助推开渔节系列活动成为三亚渔旅融合及文化推广的年度盛事。 	中国山东网记者 焦竞赛 报道
