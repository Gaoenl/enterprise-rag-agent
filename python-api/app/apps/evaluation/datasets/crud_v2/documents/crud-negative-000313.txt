2023-08-13 17:45，正文：原标题：兴化戴南文明实践夜市活动丰富群众夜生活，还宣传了文明扬子晚报网8月13日讯 （通讯员 袁开建 王晓荣 记者 王国柱）8月11日晚，兴化戴南镇“活力多巴胺，仲夏夜游会”文明实践夜市活动在裴马村远教广场举行，千余名村民参加活动。百姓大舞台上，各艺术团体表演了《梅花赋》《万里长城永不倒》《这里也是你的家》《十八相送》等舞蹈，小朋友们也带来了舞蹈《焦糖玛奇朵》《芊芊》，歌曲《最炫民族风》等，国家非物质文化遗产《茅山号子》更是将现场气氛推向高潮。一个个精彩纷呈的文艺节目轮番上演，赢得现场观众掌声不断，让群众在家门口感受文明和谐、欢乐喜庆的夜生活。另一边，志愿者们在现场摆起了志愿服务“夜市地摊”。“树立新型婚俗观，可以举办以下哪种类型的婚事？”“移风易俗‘六提倡六反对’有哪些内容？”……现场，戴南镇新时代文明实践所的志愿者们用有奖问答的形式开展移风易俗文明宣传。志愿者们特别为小朋友们精心准备了知识竞答小卡片：“我国历史上第一个王朝是哪个？”“被誉为‘中国导弹之父’的人是谁？”“电器起火，首先要做的是什么？”……内容涵盖了文学历史，数学百科，天文地理，生活安全等各类知识点，小朋友们也积极地参与进来，一个个争先恐后地抢答着。现场还进行了微电影展演，文明城市创建问答等环节，设置了“投壶”游戏区，供小朋友们一展身手；志愿者们还开展了“扫黄打非”、“绿书签”、“书香兴化”、“全民阅读”等系列宣传活动，发放各类宣传资料300多份。本次活动以百姓喜闻乐见的文艺表演+微宣讲+夜市活动的方式，倡导文明生活，有效带动志愿服务实践活动融入群众，营造了睦邻友好和谐幸福的村居文化氛围。校对 李海慧返回搜狐，查看更多责任编辑：
