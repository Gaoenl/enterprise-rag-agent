临近年底，一些重要的部门都对我国当前和未来的经济形势做出了研判和展望。国家发改委6日表示，中国经济韧性强、潜力足、回旋余地广。今年经济运行“总体回升向好，长期向好”的基本面没有变。7日，海关总署也对外公布了11月份及今年前11个月的外贸数据，数据显示，眼下我国外贸发展的积极因素不断增多，进出口连续两个月同比增长，可以说“稳中向好”的发展态势在延续。在韧性强、潜力足、回旋余地广的背景下，中国经济运行是如何实现总体回升向好的？前11月外贸进口与出口呈现出怎样的特点？从数据来看，虽然前11个月的进口和出口总额互有增减，但到了11月份，当月无论是进出口总额，还是进出口分项数据，都迎来了全面增长的好势头：进出口3.7万亿元，同比增长1.2%；出口2.1万亿元，增长1.7%；进口1.6万亿元，增长0.6%。前11月外贸进口与出口呈现出怎样的特点？海关总署统计分析司司长 吕大良：进入四季度，我国外贸发展的积极因素不断增多，进出口连续2个月同比增长，稳中向好的发展态势持续巩固。根据中国海关贸易景气统计调查，反应出口、进口订单增加的企业占比均有提升，实现全年外贸促稳提质目标的基础更加坚实。当前，国内经济持续恢复向好、市场需求持续改善，带动进口回升向好。海关总署统计分析司司长 吕大良：我国持续扩大进口，让中国大市场成为世界共享的大市场。11月当月，我们自拉美、非洲进口继续保持10%以上的较快增长。今年以来，我国出口顶住了外需走弱等多重压力，展现出较强韧性。近期部分商品出口表现亮眼，11月份手机出口值同比增长56.2%，延续了10月份两位数增长态势，这既反映了相关行业外部需求回暖，也充分体现了我国制造业的综合竞争优势。前11个月，长三角区域出口同比增长1%，拉动同期我国出口增长0.4个百分点，有效发挥了外贸增长极功能。从行业看，长三角的乘用车、船舶出口全国占比均在五成以上，引领示范、辐射带动作用突出。结束连续6个月下降中美贸易同比增长2.7%从外贸数据还能看出，我国在全球市场布局中出现了一些积极的变化，共建“一带一路”国家、中亚五国等新兴市场都继续保持了良好势头。除此之外，对部分传统市场贸易也出现了积极变化。其中值得关注的是对美国的贸易变化。11月，中美货物贸易同比增长2.7%，结束了连续6个月的同比下降，环比增长4.3%。新兴市场持续开拓 传统市场积极向好海关统计数据显示，今年11月份，我国对前3大贸易伙伴东盟、欧盟、美国分别进出口5843.9亿元、4416.6亿元、4149亿元，合计占我国进出口总值的38.9%；对共建“一带一路”国家进出口1.72万亿元。同期，我国与拉美、非洲、中亚五国进出口延续良好态势，分别增长9.3%、8.4%、43%。海关总署统计分析司司长 吕大良：近期，我国对新兴市场进出口继续保持良好发展态势，同时对部分传统市场贸易也出现积极变化。11月，中美货物贸易同比增长2.7%，结束连续6个月的同比下降，环比增长4.3%。民营企业进出口规模不断壮大海关统计数据显示，今年前11个月，我国民营企业进出口20.24万亿元，同比增长6.1%，占我国进出口总值的53.3%，提升3.1个百分点。海关总署统计分析司司长 吕大良：今年以来，我国民营企业进出口持续活跃，同比增速表现持续好于整体，占比进一步提升。最近几个月民营企业进出口规模连续保持同比增长，有力支撑我国外贸稳规模、优结构。如何继续发力实现全年经济目标？还有二十多天就将迎来新的一年，面对2023全年目标，我们该如何利用自己的长项，展开最后冲刺？国家发改委相关负责人在答记者问时指出，中国经济今年对全球经济增长的贡献将达到三分之一，仍然是全球增长最大引擎。在展望下一步时他指出，中国经济发展仍然具备较多有利条件和支撑因素。其中就包括：一是拥有中国特色社会主义制度优势。二是拥有超大规模市场的需求优势。三是拥有产业体系配套完整的供给优势。四是拥有持续深化改革开放带来的动力优势。五是拥有较大的宏观调控政策空间。从国家发改委提到的这些优势可以看出，应对各种经济挑战，只要运用好工具箱中的各种工具，实现全年经济目标是有信心的。来源：央视新闻客户端编辑：李拓流程编辑：郭丹举报/反馈
