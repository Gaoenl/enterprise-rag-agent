一张老照片、一份报纸、一枚纪念章……市民手中的这些珍藏，有可能成为历史进程中的印证。2021年将迎来中国共产党成立100周年。南京市档案馆联合南京报业传媒集团，发出“庆祝中国共产党成立100周年”红色档案“征集令”，向全社会征集1921年-2021年期间与南京相关的各类红色档案资料。南京市档案馆一级调研员张军介绍，“红色百年南京印记”主题档案有很多，既保存在各级各类档案馆和企事业单位，也可能保管在社会各界人士手中。在此背景下，推出“百年华诞·百件珍档——红色百年南京印记”红色档案征集活动，旨在用档案讲好党的故事，传播红色文化。活动即日起启动并贯穿全年，主要征集自1921年以来，记录中国共产党在南京取得辉煌成就的重要档案、资料，包括新民主主义革命时期、社会主义革命和建设时期、改革开放和社会主义现代化建设时期等重大历史阶段，中国共产党带领人民群众在南京进行革命、建设、奋斗、创新等重要节点和重大事件中的珍贵档案、资料，包括但不限于纸质、声像、实物等载体，具体如日记、手稿、题词、任命书、证件、地图、票据、勋章、奖牌以及照片和录音录像等。捐赠者可将档案资料以图片或数字文档形式，并附500字以内文字介绍+联系人姓名、电话等，发至活动专项征集邮箱：1378596401@qq.com，或邮寄至南京市档案馆宣传教育处（南京市梦都大街168号，联系人：徐海凤，电话：025-68781947）。本次征集活动属于无偿捐赠，凡经审核征集入馆的档案资料，南京市档案馆将进行整理、保管，并按规定向社会提供利用。对捐赠档案资料者，主办方将视具体情况颁发感谢函或者捐赠证书。此外，捐赠档案将有机会在新落成的南京新媒体大厦永久展陈，捐赠人也有机会作为“荣誉策展人”出席相关主题展览的线下、线上活动。除了发布“征集令”，主办方介绍，“百年华诞·百件珍档——红色百年南京印记”党报档案大型展陈暨全媒体行动还包括：一个陈列展，通过不同时期的珍贵档案和党报资料，举办礼赞百年的主题展陈活动；一次揭秘“百年珍档”的全媒体行动，讲述红色百年的南京印记；一个抖音号，通过系列短视频带领读者、网民穿越时空对话珍档；一系列读档读报活动，征集全市基层党组织一同参与寻访“百年珍档”活动；一场拉歌会，传唱“百年珍档”中的“红色曲谱”。同期，南京市委网信办还启动征集“礼赞百年 声声有宁”红色经典歌曲，包括但不限于1921年-2021年间红色经典歌曲的名称、年份、视频、手稿、故事等。只要你知道歌名，只要你会唱一段，就在微博、抖音、美篇平台搜索“礼赞百年 声声有宁”，发布演唱视频并带话题#礼赞百年 声声有宁#，即可参加活动。
