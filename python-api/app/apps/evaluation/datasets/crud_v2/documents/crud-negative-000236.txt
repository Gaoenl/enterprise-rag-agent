2023-07-28 19:31，正文：原标题：退赃50余万元 被盗车辆8辆 平邑警方召开退赃大会为进一步提升群众安全感、满意度，展示夏季治安打击整治行动成果，7月26日，平邑县公安局仲村派出所召开退赃大会，将近期在夏季治安专项行动中追缴的财物公开返还受害群众。平邑县委政法委副书记李昌伟、仲村镇党委副书记王涛、平邑县公安局刑侦大队、反诈中心及仲村派出所全体民警辅警及辖区部分群众参加活动。夏季治安打击整治行动开展以来，仲村派出所严厉打击各类侵财类犯罪，坚持开展即案即侦，快办快处，针对严重危害人民群众利益的盗抢骗案件从严从重打击，先后破获了能某诈骗案、吴某诈骗案、郭某等团伙诈骗案以及王某、唐某盗窃案等一批刑事案件,犯罪嫌疑人均已被采取刑事强制措施，追缴了一批涉案赃款赃物。退赃仪式上，被盗骗赃款、赃物已全部追回并退还被害人，受害群众领回失而复得的财物，向办案民警送上致谢锦旗，以表达对民警的感激之情。以打开路，打防结合，以打促防。2023年上半年，仲村镇辖区总发案数136起，同比下降6.2%，其中行政案件发案数97起，同比下降7.6%，刑事案件发案数39起，同比下降2.5%。行政拘留35人，刑事拘留43人，移送起诉27人，逮捕4人，解决各类矛盾纠纷320余起。追回被诈骗现金50余万元，被盗摩托车、电动车8辆。行动的开展，全面净化了辖区社会治安环境，进一步提升了辖区群众安全感满意度，取得良好社会治安效果。来源：平邑公安返回搜狐，查看更多责任编辑：
