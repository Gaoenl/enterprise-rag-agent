2023-08-17，正文：人民网北京8月17日电 （记者杜燕飞）近日，受台风影响，我国多地出现极端降雨过程，引发洪涝和地质灾害，造成人员伤亡和财产损失。人民银行决定增加河北、北京、黑龙江、吉林、福建、重庆6省（市）支农支小再贷款额度350亿元，支持这些受灾严重地区抗灾救灾及灾后重建金融服务工作，加强对受灾地区的经营主体特别是小微企业、个体工商户，以及农业、养殖企业和农户的信贷支持。业内人士认为，支农支小再贷款、再贴现，属于长期性的结构性货币政策工具。人民银行增加河北等6省（市）支农支小再贷款额度350亿元，一方面可以为金融机构提供更多资金支持，另一方面将降低金融机构资本成本，激励金融机构进一步加大对受灾严重地区经营主体的支持力度。通过加大对受灾农业、养殖及中小企业金融支持力度，有助于稳定经营主体信心，加快恢复生产，在保障市场供应，稳定就业，促进内需恢复方面将发挥积极作用。助力灾后重建，金融支持是重要一环。此前，国家金融监督管理总局印发的《关于做好防汛救灾和灾后重建金融服务工作的通知》要求，银行机构要强化对小微企业、个体工商户、“三农”、与民生密切相关的灾区交通、通讯、燃气电力、农田水利、排洪防涝等基础设施修复重建和改造升级等重点领域的信贷支持，做好个人客户金融服务。鼓励银行机构针对受灾地区的小微企业、个体工商户以及农业、养殖企业和农户、新型农业经营主体等，开发专项救灾信贷产品。8月11日，国家金融监督管理总局北京监管局联合人民银行营业管理部、北京市地方金融监管局共同印发《关于帮扶市场主体支持灾后重建的通知》，明确将加强货币政策工具保障，单列100亿元支农、支小再贷款额度和50亿元再贴现额度用于支持相关金融机构做好灾后金融服务工作。记者了解到，今年7月，人民银行已决定增加支农支小再贷款、再贴现额度2000亿元，进一步加大对“三农”、小微和民营企业金融支持力度。其中，支农再贷款、支小再贷款、再贴现分别增加额度400亿元、1200亿元、400亿元。该举措将发挥精准滴灌作用，降低社会融资成本，促进扩大就业，支持经济内生动力恢复。分享让更多人看到
