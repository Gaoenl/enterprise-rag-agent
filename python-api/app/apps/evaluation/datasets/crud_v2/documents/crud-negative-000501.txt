省农业农村厅统筹灾后恢复重建和乡村振兴全力保障粮食安全 加快建设和美乡村河北日报讯（记者郝东伟）河北省委十届五次全会指出，要统筹灾后恢复重建和乡村振兴，持续提升人居环境，全力保障粮食安全，坚决防止因灾返贫，加快建设宜居宜业和美乡村。11月24日，河北省农业农村厅召开党组会，深入学习领会省委十届五次全会精神，研究部署贯彻落实意见。省农业农村厅党组书记、厅长刘宝岐表示，全省农业农村系统将深入学习贯彻习近平总书记视察河北重要讲话精神，坚决贯彻落实省委十届五次全会安排部署，更加坚定自觉地坚持以人民为中心，更加坚定自觉地抓好灾后恢复重建，更加坚定自觉地统筹发展和安全，更加坚定自觉地为受灾群众办实事解难题，坚决扛起肩负的使命职责，全面完成农业农村灾后恢复重建各项任务。粮食安全是“国之大者”。如何夯实粮食安全根基，牢牢扛稳粮食主产省政治责任？刘宝岐表示，他们将牢记“国之大者”，毫不放松抓好今冬明春粮食生产，以17个水淹县（市、区）为重点，持续开展个性化包联指导服务。以12个首批小麦单产提升示范县为抓手，编制高产全程化综合性解决方案。藏粮于地、藏粮于技战略是保障粮食安全的关键举措。省农业农村厅将落实藏粮于地，加大高标准农田建设力度，加快推进灾毁农田恢复，保质保量完成国家下达的高标准农田建设任务。全力推进盐碱地改造提升和综合利用，用好盐碱地调查成果和试点经验，把盐碱地综合利用作为挖掘粮食增产潜力的战略举措。落实藏粮于技，大力实施种业振兴，加快培育一批突破性粮食作物新品种。充分发挥技术体系专家作用，组织各级农业技术人员，推行全程精细精准科学管理行动，确保明年夏粮丰产丰收，为完成明年粮食生产目标任务打下坚实基础。提升农业防灾减灾救灾能力，加快农业设施修复重建。强化与气象、水利、应急等部门沟通对接，健全农业气象灾害风险预警机制。扎实推进冬春农业生产，落实好病虫害防控措施，防范低温雨雪等不利天气影响。加强农田水利建设，建设农田灌排网络体系，提高防洪排涝能力。实施保费补助，增强农户投保意愿、提升保险机构承保积极性，充分发挥政策性农业保险兜底作用。发挥财政资金撬动作用，引导金融和社会资金投向现代设施农业，重点支持受灾地区设施农业重建修复。加快推进衡沧高品质蔬菜产业示范区创建，重点支持13个种植受灾重点县（市、区）棚室升级换代，打造一批现代设施农业示范区。加大脱贫地区防返贫动态监测力度，对因灾有返贫风险的脱贫户，及时落实产业帮扶政策，确保脱贫农户持续稳定增收。深入学习运用浙江“千万工程”经验，加快建设宜居宜业和美乡村。省农业农村厅将统筹灾后恢复重建和乡村振兴，把灾后恢复重建与学习运用“千万工程”经验结合起来，将灾后恢复重建的过程变为建设和美乡村的过程，布局建设一批和美乡村示范区、和美乡村，特别是打好村庄清洁行动攻坚战，确保全省乡村面貌干净整洁有序。产业振兴是乡村振兴的重中之重。省农业农村厅将推动乡村特色产业发展，积极培育绿色农业、设施农业、高效农业，做好“土特产”文章，发展壮大农业产业新业态，推进一二三产融合发展。巩固提升“河北净菜”品牌，深化产销衔接，抓好京津冀共建蔬菜生产基地建设，高质量打造一批农业区域公用品牌、企业品牌、产品品牌。在全力推进京津冀农业农村领域协同发展方面，省农业农村厅将坚持问题导向，建立健全协调协同、执行合作机制，大力抓好行政壁垒和体制机制障碍等问题的解决，推动京津冀农业农村领域统一标准、统一政策的落地落实。建立京津冀农产品质量安全协同追溯体系，确保农产品质量安全。全力推动雄安新区高质量发展。扎实推动农业绿色发展，持续优化白洋淀生态环境，建设国家级水产质量资源保护区，强化白洋淀上游流域粪污防治。认真打造雄安智慧农业场景，吸引更多农业优势企业和科研机构入驻雄安，充分发挥雄安新区在智慧农业建设中的创新示范作用。
