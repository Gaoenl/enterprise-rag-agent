记者昨日从市发展改革委了解到,为全面落实国家及省统一部署,推动解决妨碍建设全国统一大市场突出问题,我市发布《关于征集妨碍建设全国统一大市场问题线索的公告》,面向社会征集七个方面的问题线索和意见建议。分别是:有关地方和单位出台或实际实施含有地方保护、市场分割、指定交易等妨碍统一市场和公平竞争政策方面的问题。有关地方和单位利用数据、算法、技术手段等方式排除、限制竞争等方面的问题。有关地方和单位违规设置地方保护和区域壁垒问题。如,违规设置区域壁垒限制外地企业承接工程项目,实施补贴等优惠政策限制外地企业参与,国企垄断市场资源妨碍其他经营主体公平参与市场竞争等。有关地方和单位妨碍经营主体依法平等准入和退出问题。如,变相设定外地企业准入障碍,设定不合理或歧视性条件提高企业准入门槛,采取将企业列入经营异常名录、暂停办理流程、故意拖延等手段为企业跨区域经营或迁移设置障碍等。有关地方和单位妨碍公平公正招标投标和政府采购问题。如,招投标条件设置不利于外地企业,限定或指定特定的专利、商标、品牌、零部件、原产地、供应商等。其他不落实《中共中央 国务院关于加快建设全国统一大市场的意见》的问题。关于加快建设全国统一大市场的意见建议。我市对收集的问题线索和意见建议进行梳理汇总,督促有关地方和部门研究处理。对企业和群众反映强烈、带有普遍性和典型性的重要问题线索,将直接派员进行督查。经查证属实的,将依法依规严肃处理。联系电话:0558-2285989;电子邮箱:fyfgwtgk@163.com(请在邮箱主题栏注明“问题线索”);寄送地址:安徽省阜阳市清河东路539号阜阳市发展和改革委员会体改外资科。
