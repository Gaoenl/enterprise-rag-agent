为贯彻落实全国危险化学品安全生产会议工作部署,精准防范化解危险化学品重大危险源安全风险,根据《广东省应急管理厅 广东省消防救援总队关于印发<广东省危险化学品重大危险源企业2023年第一次专项检查督导工作方案>的通知》(粤应急函〔2023〕143号)要求,6月26日至27日,省消防救援总队洪声隆总工程师带领联合执法检查组到湛江开展危险化学品重大危险源企业2023年第一次安全专项联合执法检查。湛江市消防救援支队、湛江市应急管理局有关同志参加检查。省联合执法检查组对我市中国石化销售股份有限公司华南分公司、中科(广东)炼化有限公司湛江东兴石油化工有限公司进行了实地督导检查。在企业现场,检查组听取了企业负责人关于重大危险源安全风险隐患自查自改的情况汇报,详细了解了企业自查自改的质量、重大危险源安全包保责任制落实、《重大危险源安全评估报告》措施建议的落实、线上录入问题隐患情况以及企业消防安全管理、专职消防队建设、消防设施维护保养、消防控制中心值班值守、预案制定演练等工作情况。广东省危险化学品重大危险源企业2023年第一次专项检查督导工作方案>检查组还对市级交叉检查全覆盖、检查发现隐患质量、被检查地市依法实施行政处罚、落实“消地协作”机制、宣传曝光等情况进行了实地核查。针对检查过程中发现的隐患问题,检查组向属地政府、相关部门和企业逐一进行反馈,并提出改进意见,要求限期落实整改。此次检查,充分发挥了联合执法的效能和效力,进一步厘清了我市重大危险源危化企业的安全隐患和薄弱环节。通过现场发现问题,倒查问题的根源,倒逼企业落实消防安全主体责任,全市危险化学品重大危险源企业安全管理工作水平得到全面提升。下一步,市安委办、市消安委办将按照联合执法检查组反馈的问题隐患,以全新的监管视角,全面查摆我市重大危险源危化企业的安全隐患和薄弱环节,督促企业逐项分析研判、整改落实,实施整改闭环管理。指导属地相关部门落实行政执法和隐患的整改验收核查工作,推动我市重大危险源企业不断健全完善安全生产风险分级管控和隐患排查治理双重预防机制,提升重大安全风险防控水平。原标题:《省联合执法检查组到我市开展危险化学品重大危险源企业2023年第一次安全专项联合执法检查工作》阅读原文
