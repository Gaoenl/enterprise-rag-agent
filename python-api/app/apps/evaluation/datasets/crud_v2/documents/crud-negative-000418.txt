2023-08-15 09:03，正文：原标题：广东2018年至今年上半年受理环境资源案件超6万件中新网广东新闻8月14日电 (方伟彬 吴捷燃 吁青 王依琪)广东省高级人民法院14日召开环境资源审判新闻发布会通报，2018年1月至2023年6月，该省法院共受理各类一审生态环境资源案件64004件，审结62186件。其中，一审环境资源刑事案件收案14255件，审结13977件；一审民事案件收案29533件，审结28745件；一审行政案件收案20216件，审结19464件。近年来，广东法院先后建立了40余个跨区域、跨部门、跨层级的生态环境司法保护协作机制。今年以来，广东法院先后与桂、滇、黔、赣、闽等省(区)建立了东江、韩江、西江流域生态环境司法保护协作机制。广东法院紧盯大气污染、水污染、土壤污染等重点领域，通过判处实刑、高额赔偿等司法判例，巩固蓝天、碧水、净土保卫战成果。在林某泉刑事附带环境民事公益诉讼案中判赔29.6亿元高额赔偿，在某养殖基地擅自占海造地案中并处海域使用金16倍罚款，在某垃圾处理厂固体废物污染案中判赔1.3亿元生态环境修复等费用。另外，广东法院还主动延伸环境司法职能，通过司法建议参与生态领域社会管理创新。五年来，广东法院共发出生态环境资源类司法建议175份。(完)返回搜狐，查看更多责任编辑：
