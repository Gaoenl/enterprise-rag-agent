国际能源网/氢能汇获悉,当地时间7月8日,欧盟委员会正式对外发布了《欧盟氢能战略》和《欧盟能源系统集成战略》两项战略计划。这两项安全环保、自动再生的能源战略将成为“欧盟经济复苏计划”的支柱。此次战略计划预示着欧盟将在未来10年累计向氢能产业投入约5750亿欧元,相当于4.56万亿人民币的资金,以此发展氢能产业,保证欧盟国家可以在2050年实现碳中和。欧盟委员会预计到2050年,氢能可以满足全欧盟24%的能源需求,创造出至少540万个就业岗位。在此基础上,欧盟提出了氢能开发需要经历三个过渡段:从2020年到2024年,支持欧盟安装至少6吉瓦的可再生氢能电解槽,生产多达100万吨可再生氢能;从2025年到2030年,欧盟至少要有40吉瓦的电解槽装机容量,生产多达1000万吨的可再生氢能;从2030年到2050年,可再生氢能技术应该达到成熟水平,并在所有难以去碳化的领域大规模部署。欧盟执行官周三称,到2050年,欧洲可再生氢能源可能需要1800亿欧元至4700亿欧元的投资。鉴于私人投资者的兴趣,该委员会对融资持乐观态度。在《欧盟能源系统集成战略》中,欧盟指出能源系统集成将为绿色能源转型提供框架。据欧盟委员介绍,欧盟能源系统一体化战略是要让不同的能源生产载体、基础设施及消费行业联系起来,实现统一规划和运营。这一战略有三个主要支线:第一,以能源效率为核心且更加注重“循环”的能源系统;第二,扩大终端部门的直接电气化,如构建一个100万辆电动汽车充电站组成的网络;第三,对难以电气化的部门,促进清洁燃料的发展。
