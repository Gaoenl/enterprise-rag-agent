2023-08-09 06:03，正文：原标题：外贸形势复杂多变 保持韧性要有强力措施证券时报记者 秦燕玲海关总署公布的进出口数据显示，今年前7个月，我国进出口总值23.55万亿元人民币，同比增长0.4%，其中，7月进出口总值为3.46万亿元，下降8.3%。在国际市场，尤其是发达经济体市场需求持续不振的背景下，外贸进出口持续承压。商务部有关负责人研判下半年外贸形势时就曾明确指出，经济因素和非经济因素相互交织，形势极为严峻。对于外贸的增长压力，不必过于悲观。一方面，国内疫情控制更好、生产制造匹配国外需求等原因交织，助力我国外贸出口实现过去三年的超预期表现，基数明显抬升，当前事实上正逐步由非常态的增长向常态化增长回归。另一方面，贸易不振的压力是全球范围内的。新近发布7月出口数据的韩国、越南分别遭遇了3年来的最大出口跌幅和14年来的最长跌幅。韧性何来？“一带一路”及东盟、拉美、非洲等新兴及发展中经济体市场增量支撑规模企稳，随着近期《区域全面经济伙伴关系协定》（RCEP）全面生效，全球人口最多、经贸规模最大、最具发展潜力的自由贸易区已正式进入新阶段，红利显现等利好因素将进一步发挥重要作用。同时，制造业转型升级助推外贸提质。以“新三样”为代表的出口产品俨然已经成为外贸出口的新名片。在电动载人汽车领域，据中汽协统计，今年上半年我国新能源汽车出口53.4万辆，同比增长1.6倍。新能源汽车的迅猛发展为汽车整车的出口蓄力，上半年我国已经超越日本，成为全球汽车出口第一的国家。这些出口结构的新变化，正是过去十几年制造业持续开拓创新的集中体现。此外，在调研采访中企业家的表现更乐观、积极，中国贸促会的最新调研数据表明，75.1%的中国外贸企业对今年三季度发展“信心稳定不变”及“较有信心”。关关难过关关过，在复杂严峻的形势面前，企业需要尽可能地解决问题才能生存下来，他们本身的韧性也为外贸稳定提供了更多确定性。当前，民营企业已成为外贸主力军，要有强力措施，持续为他们扫清创新技术、拓展市场的障碍，推动制造业持续转型升级，从而让中国在严峻的外部形势下保持出口优势与韧性。 返回搜狐，查看更多责任编辑：
