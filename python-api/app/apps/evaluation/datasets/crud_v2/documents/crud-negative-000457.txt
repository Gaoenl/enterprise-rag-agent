据华盛顿知情人士透露,美国司法部准备起诉维基解密(WikiLeaks)创始人朱利安.阿桑奇(Julian Assange),而且越来越相信可以将他送上美国法庭。知情人士称,美国检察官在过去一年里讨论了可能对阿桑奇提出的几种指控。自从2012年获得厄瓜多尔的政治庇护后,阿桑奇一直住在厄瓜多尔驻伦敦的大使馆。熟悉此案的知情人士不愿透露美国方面是否已开始与英国或厄瓜多尔讨论阿桑奇的问题,只说最近的事态发展让他们感到鼓舞。自去年莱宁.莫雷诺(Lenin Moreno)当选总统以来,厄瓜多尔与阿桑奇的关系急剧恶化。莫雷诺称阿桑奇是“鞋子里的石头”,并表示不可能一直让他留在大使馆。美国特别顾问Robert Mueller提交的起诉书显示,俄罗斯情报机构利用维基解密在2016年大选期间发布了数千封被黑客 露的民主党电子邮件,这让阿桑奇更难以记者身份进行辩护。美国公众对阿桑奇的看法自大选以来有所下降。知情人士透露,检察官已考虑公开起诉阿桑奇,藉此机会让他离开大使馆,因为围绕阿桑奇案件的证据细节可能会让厄瓜多尔当局有理由将他移交。司法部具体会提出何种指控仍不清楚,但有可能涉及间谍法,该法将披露国防相关信息定为刑事犯罪。阿桑奇的律师Barry Pollack表示,他没有听说起诉的消息。Pollack表示∶“我们没有听到当局即将对阿桑奇发起刑事诉讼的暗示。如果发布真实信息反被起诉,将开创一个可怕而又危险的先例。”
