近日，北京市首批非应届毕业生正式入住保障房项目。本次配租的范围由先前的应届毕业生扩大至毕业三年内的大学生。针对高校毕业生租房难的问题，北京市在今年4月份启动了首批保障性租赁住房青年公寓试点项目，为毕业大学生步入社会保驾护航。本次大学生保障房毕业三年内的大学生均可登记配租，项目启动至今，配租登记人员共832人，通过资格审核人员782人，最终共选出房源235间。保障房内配备基础生活设施，同时配备智能门锁和宽带网络，可满足青年群体的基本住房需求。北京首批4个试点项目分别位于海淀、朝阳、昌平、房山，均为全装修交付新房，配备家具家电，大学生可拎包入住。户型既有26—35平方米的单间公寓，也有两居室、三居室分租房屋。申请方式采取线上登记、线下审核、先到先得的形式。房屋租金严格控制在2600—4800元。刚刚搬入“新家”的毕业生张恩泽说道：“我已经毕业一年多了，之前租的房子地理位置不如这个好。这个房子离合生汇、离地铁口都非常近，离我单位也很近。整个这个社区里住的都是刚刚毕业的大学生，整体氛围非常年轻，我非常喜欢这里。”为精准服务青年群体，北京市朝阳区平乐园项目还增加了部分个性化服务，首层配备共享休闲区，配备运动健身区、书吧阅读区、共享会客区、休闲娱乐区四大功能区，可以满足青年人才“吃住行娱学”等需求。相关部门提示，有登记意向的毕业生可自行登录北京保障房中心网站（www.bphc.com.cn）或下载北京保障房App，进入大学生公寓配租登记界面了解房源情况，进行线上登记，下载及操作方式可查询配租公告及附件。（原标题：正式拎包入住！在这个一线城市，毕业三年内可申请保租房！租金严格控制...）来源：央视新闻客户端流程编辑：TF029如遇作品内容、版权等问题，请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话：010-85202353下载“北京日报”客户端 阅读体验更佳哦扫描二维码下载手机客户端扫描二维码下载手机客户端
