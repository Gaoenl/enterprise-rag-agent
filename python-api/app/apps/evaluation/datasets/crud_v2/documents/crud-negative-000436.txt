"东北网9月27日讯(赵宇 记者 庄园)9月27日下午,中俄高校(部分)教育合作与特色发展论坛在黑河学院举行。来自俄罗斯远东国立农业大学、阿穆尔国立大学、共青城国立人文师范大学、哈巴罗夫斯克国立文化学院、布拉戈维申斯克国立师范大学、南乌拉尔国立大学及中国厦门大学、上海师范大学、东北农业大学、齐齐哈尔大学、哈尔滨学院、绥化学院、贺州学院、大庆师范学院及黑河学院15所中俄高校负责人齐聚黑河,共商中俄教育合作大计。中俄高校教育合作与特色发展论坛现场。 程旺 摄与会人员围绕“深化中俄高等教育合作厚植本科特色发展新内涵”、“搭建中俄人文交流、民心相通之桥”“构建教育的大目标大体系”、“携手开创中俄高校文化艺术交流新篇章”、“基于人才培养模式渊源的中俄高等教育理念的回顾与反思”、“俄罗斯高校与中国合作的经验与前景”等方面展开讨论。中俄校长互通有无、深度交流,进一步挖掘中俄两国高等教育互补优势,共同勾勒出了两国教育文化交流合作的美好未来,推动本地区人民共享合作机遇和发展成果。据了解,本次论坛是黑河学院60周年校庆系列活动之一。黑河学院将同其他高校一道,抓住中俄地方合作历史机遇,顺应时代潮流,不断增强开放合作意识,进一步解放思想,树立世界眼光,共同在掌握对外开放本领、用好对外开放政策、营造对外开放环境上寻找突破,解决影响和束缚中俄高校教育文化合作的突出问题,不断提高国际化水平,共同培养具有较强的创新能力、国际合作意识,熟悉国际惯例,具有参与国际竞争能力的复合型创新人才。责任编辑:王傲高校|教育合作相关新闻第216期全国高校思想政治工作骨干示范培训班在黑河市举办对俄教育合作“渐入佳境”黑河市2015年高校毕业生就业服务周拉开帷幕",
