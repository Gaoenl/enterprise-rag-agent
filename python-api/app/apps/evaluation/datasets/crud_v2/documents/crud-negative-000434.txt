青年早餐丨第三届“中国数字冰雪运动会”启动〔2023.08.03〕2023-08-03 07:30来源：澎湃新闻·澎湃号·政务字号2023年08月03日最及时01要闻速递◆ 第三届“中国数字冰雪运动会”启动。近日，第三届“中国数字冰雪运动会”在国家速滑馆“冰丝带”启动。活动现场不仅为广大冰雪爱好者提供近距离体验冰雪运动、冰雪文化的机会，还特设“惊喜环节”、打卡拍照区、互动区和展示区等内容，丰富多彩的项目吸引了不少观众参与。自由式滑雪世界冠军郭丹丹在现场与嘉宾互动，号召大家参与冰雪运动，享受冰雪竞技的乐趣。◆ “吉林一号”宽幅02A星亮相。近日，由长光卫星技术股份有限公司自主研发的“吉林一号”宽幅02A星在吉林省航天信息产业园亮相。该星是由长光卫星研发的新一代覆盖型卫星的首发星，具备高分辨、大幅宽、高速数传、低成本的特点，将于近期在中国酒泉卫星发射中心择期发射。目前，该卫星星座已在农林、水利、环保、交通、自然资源、城市建设等14个领域开展各类服务，客户来自全球10余个国家和地区。◆ 两部门：因灾返贫风险农户可先落实帮扶措施。近日，农业农村部、国家乡村振兴局印发通知，对各地有因灾返贫风险的农户，符合政策规定的，可通过设立绿色通道，先落实帮扶措施再及时完善手续，切实防止因灾返贫。最感动02青春榜样◆张家齐：为国争光的信念从未改变。在成都大运会跳水项目的首个比赛日，来自北京体育大学的奥运冠军张家齐和来自上海体育大学的世界冠军掌敏洁密切配合，为中国队拿下成都大运会跳水项目的第二枚金牌。2016年，当时年仅12岁的张家齐在全国跳水冠军赛上一鸣惊人，夺得冠军。如今19岁的张家齐已经褪去了稚气，但她对为国争光、追求梦想的理解也更加深刻。张家齐表示，不会觉得今天的比赛更轻松，因为为国争光就要跳到最好，无论什么比赛，对自己的这种要求都是不变的。最聚焦03各地动态◆ 团天津市委助力党建引领基层治理。近日，团天津市委在宝坻区调研助力党建引领基层治理“社区青春行动”工作情况，并召开推进会议。座谈会上，团天津市委相关部门、各团区委、中央驻津团工委直属团组织结合工作实际进行交流发言，围绕在党建引领基层治理行动中汇聚青年智慧、贡献青春力量进行了充分的讨论。会议促进落实天津市委、市政府“十项行动”部署要求和调查研究工作要求，推动社区青春行动各项重点任务落实落地。◆ “流动少年宫”牵线，四川甘孜少年暑假赴成都研学。近日，由团四川省委、四川省青少年社会教育服务中心牵头组织的“流动少年宫”少年军校主题研学活动圆满结束。来自四川省甘孜藏族自治州“流动少年宫”结对学校的40名青少年来到成都，参加了为期4天的少年军校主题研学活动，青少年们围绕军事、科技和红色教育等主题，进行了队列、战术等训练，还体验了火箭筒、迫击炮、真人cs、丛林穿越等课程。活动增强了青少年的爱国意识，帮助青少年收获实践本领。来源：微信公众号“团中央权益部”原创，转载请注明来源。往期推荐原标题：《青年早餐丨第三届“中国数字冰雪运动会”启动〔2023.08.03〕》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
