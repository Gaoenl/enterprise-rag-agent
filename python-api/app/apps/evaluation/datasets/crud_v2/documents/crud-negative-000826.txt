2023-07-28 19:37，正文：原标题：街头售卖私油，“油贩子”被群众举报后落网极目新闻记者 张理晶通讯员 尹晓婧实习生 何星豫7月16日，武汉市公安局东湖新技术开发区分局豹澥派出所查获一起非法贩卖成品汽油案，嫌疑人周某将7座的面包车加装储备油桶和加油机，向客户兜售低价汽油，被抓获时，车内载有约260升的92号汽油。“喂，是周老板吗？李总推荐我来你这买油。”7月16日，豹澥派出所民警侯喆栋接到群众举报线索，在神墩五路交叉口有辆面包车贩卖“私油”，侯喆栋随即假扮客户，获取周某的信任，约定在某路口见面交易。挂完电话，侯喆栋带领辅警陈家润立即驾驶警车前往约定地点，见到了在路边等候客户的周某。看到一辆警车驶来，周某神情慌张，对贩卖成品油一事百般抵赖，当警方拿出通话记录、交易截图等证据时，周某只好承认了自己的违法行为。据了解，周某在未取得相关经营执照的情况下使用储油罐、加油枪、电子油表计价等设备，拆掉面包车座椅，改装成移动加油车，以低于市场三分之一的价格售卖成品油，不仅扰乱市场秩序，还存在重大安全隐患。目前，成品油已由公安机关全数移交商务部门，案件正进一步侦办中。（来源：极目新闻）返回搜狐，查看更多责任编辑：
