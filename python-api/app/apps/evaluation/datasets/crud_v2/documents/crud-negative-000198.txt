昨天，全球外交活动中，有三件事特别引人注目。第一个，是在西方国家不断“提醒”的声音中，中央外事办主任王毅出访俄罗斯，让西方企图“孤立俄罗斯”的盘算彻底落空；第二个，是俄罗斯总统普京在俄乌冲突爆发后，首次发表国情咨文，对整个战事进行“大总结”；第三个，是美国总统拜登在战场旁边的波兰发表演讲，为乌克兰打气，为西方盟友们打气，要“一起追究俄罗斯的战争责任”。中美俄是世界大国，也同为联合国“五常”国家，这一天，同时与“俄乌冲突”出现关联，自然引来了全球的视线。值得关注的是，已经宣布参加2024年大选的美国前总统特朗普，不愧是商人出身，对机会的嗅觉非常灵敏，也在这个“关键日子”出来蹭热度，选择在这一天举行了一场竞选拉票活动。面对台下众多的支持者，特朗普非常聪明地将话题引到了与当天三大国外交活动相关的“俄乌冲突”上。他表示，如果我胜选，再次当选美国总统，那么当晚就会给普京和泽连斯基打电话，促成三方会谈，而且会在24小时之内达成协议，结束俄乌冲突。特朗普还大肆吹捧了自己和俄总统普京的私人关系，并进一步表示，如果去年我还在美国总统的位置上，俄罗斯根本就不会对乌克兰发起军事行动，“这么多生命被白白浪费，太悲惨了”。对于美国现任总统、并很有可能成为自己明年大选最后对手的拜登，特朗普也是毫不客气，称拜登政府不仅向乌克兰提供导弹和主战坦克，甚至还想提供F-16战斗机，这样做，“只会将美国推向核战争”。不得不说，特朗普很善于抓对方的“漏洞”，也知道自己的支持者和美国民众们，在这个时候最想听什么。对于拜登政府大把掏钱军援乌克兰，美国民众、媒体，甚至主导国会的共和党，早就感到不满了。美媒就曾嘲讽乌总统泽连斯基，称“那个穿绿色T恤的傲慢外国人，一直在向白宫勒索现金，拜托你能不能走开一点，美国现在也需要钱”。美国共和党重夺国会控制权后，不少党员曾对外喊话，称“一分钱也不会送给乌克兰”。昨天，拜登闪电出访乌克兰时，宣布将对基辅提供5亿美元的军事援助，这一“大单”，很有可能是民主党还在主导国会时，就已经确定的方案。美方此举，是希望继续升级局势，延长冲突时间，当然，最为主要的是借俄乌冲突，一方面削弱自己的对手俄罗斯，另一方面在经济上“收割”欧洲盟友。对于拜登亲自去乌克兰“打气”，并再次宣布大笔军援，普京在发表国情咨文时，也直接做出了回应，称“在战场上击败俄罗斯，是根本不可能出现的事情”。更为值得关注的是，普京还宣布了一个重磅消息——暂停参与《新削减战略武器条约》，这也是美俄之间最后一个军控条约。同时，也是两国互相监视对方核动态的关键条约，暂时停止意味着什么，美国应该最清楚。在最近举行的慕尼黑安全会议上，中方已经对外披露，有意对俄乌冲突推出一个“和谈方案”，并就此与美国、法国和德国、乌克兰进行了沟通，王毅主任出访俄罗斯，这也可能是议题之一。俄乌冲突一年了，除美国外，另外几方都已经露出“疲态”，若中国能主导和谈，各方也是时候坐到桌子边了。若真等到特朗普出来“解决问题”，则意味着冲突还要进行两年，因为他即便当选，也是2024年底的事。用他的话来说，两年中，又不知会有多少生命会“白白浪费”，国际社会当然不能坐视。举报/反馈
