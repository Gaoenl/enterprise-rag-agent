，正文：中国制造商“原相科技”在最新财务报告中表示，他们将为一家日本公司的全新游戏机制造组件。原相科技是为任天堂Switch JoyCon提供SoC以及其他任天堂家用游戏机部件的供应商。报告还提到，这家日本公司多年来一直没有推出新系统，而最新一代将于2024年初发布。 这是迄今为止最为确定的任天堂Switch 2发布日期之一，即2024年初。虽然原相科技的报告没有直接提到新款任天堂Switch，但考虑到任天堂是唯一一家多年没有发布新系统的日本公司，这完全排除了索尼的可能性。 值得注意的是，这并不是中国公司第一次暗示下一代任天堂Switch将于2024年初发布。本月早些时候，金属外壳制造商宏尊透露，由于任天堂计划在2024年第一季度发布一款新游戏机，他们预计今年下半年的销量将有所增长。 然而，任天堂方面并没有过多谈论新款Switch。今年5月，任天堂总裁古川俊太郎表示，在本财年(2024年3月31日结束)结束之前，不会发布新的硬件。本文属于原创文章，如若转载，请注明来源：原相科技暗示新款任天堂Switch将于2024年发布https://news.zol.com.cn/826/8269661.html
