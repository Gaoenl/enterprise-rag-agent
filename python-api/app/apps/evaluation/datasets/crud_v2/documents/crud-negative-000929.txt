新加坡厦门公会参访团到访厦门同安2023年07月17日 13:18   来源：中国侨网参与互动字号：小中大新加坡客人在厦门参观。　同安区侨联供图中国侨网厦门7月17日电 据厦门同安区侨联消息，日前，新加坡厦门公会会长汪家裕，新加坡原政务部长、新加坡厦门公会荣誉顾问曾士生，新加坡厦门公会副会长白毅柏，新加坡厦门公会永久荣誉顾问林璒利，新加坡华夏文化促进会副会长庄委勋，新加坡厦门公会秘书池姝娜等一行6人到访厦门同安区，受到同安区委常委、统战部部长颜志良，区侨联主席林一亭等的热情接待。颜志良向来宾们简要介绍了同安区近年来的发展和同安新城建设情况。他表示，同安历史悠久，文化底蕴浓厚，欢迎海外华侨华人多回来同安参观考察、联谊交流，加强双方的联络和信息互通，整合资源，寻求合作。希望在当前的发展机遇下，海外华侨华人多关注家乡同安，感受家乡的发展变化，共同助力同安区建设发展。汪家裕会长表示，同安区良好的投资和营商环境让人印象深刻，将努力推动在更高层面、更广领域的合作。汪会长还表示，今年底恰逢新加坡厦门公会成立85周年，诚挚邀请同安区政府组团参加活动，希望加强与同安区交流合作，增进乡情乡谊。新加坡厦门公会一行在同安区侨联主席林一亭、秘书长曾明辉、美林街道统战委员李德龙的陪同下，参观了环东海域滨海新城，实地感受同安的发展巨变。(完)【责任编辑:惠小东】
