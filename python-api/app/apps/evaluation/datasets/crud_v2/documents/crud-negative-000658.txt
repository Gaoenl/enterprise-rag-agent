中新网广西新闻8月4日电（黄艳梅 张晟川）广西南宁市农业农村局4日介绍，今年上半年，南宁市生猪产能充足，但价格持续低位运行，主要受阶段性供大于求影响。近一周，生猪价格出现回暖迹象，随着秋冬季节消费旺季到来，价格有望逐步回升，养殖收益将有所改善。今年以来，因市场供应较为充足、猪肉消费阶段性偏弱，中国生猪价格总体低位运行。作为中国农业大省区，广西生猪总产量稳居全国前列。记者从当日举行的南宁市2023年上半年农业农村经济运行情况通报新闻发布会获悉，今年上半年，南宁市生猪出栏264.65万头，同比增长4.1%；猪肉产量21.16万吨，同比增长4.8%。图为新闻发布会现场。张晟川 摄今年以来，南宁市大力发展规模养殖业，落实生猪产能调控政策，上半年新增申报20个国家级生猪产能调控基地。截至今年7月底，全市备案猪场数量达到1021家，其中万头猪场221家，10万头超大型猪场19家，生猪规模化率超过80%。据南宁市农业农村局党组成员、四级调研员蒋建议介绍，在生猪保供稳价方面，南宁主要采取了加强生猪产能调控、加快产业转型升级、持续抓好疫病防控等措施。南宁市落实以稳定能繁母猪为主的生猪产能调控政策，通过相关平台监测调度，加强分析预警，引导养殖场（户）合理安排生产，稳住生猪调出大县等主产区和大型猪场的基础产能。今年二季度末，全市能繁母猪存栏25.69万头，比正常保有量26.5万头少3.1%，处于正常波动的绿色区域，生产未出现大起大落。今年以来，南宁市统筹整合生猪调出大县奖励资金、良种补贴、全产业链提升项目等各级财政资金7516.9万元人民币，推进养殖标准化示范创建和万头智慧猪场建设，狠抓重大项目落地开工建设投产，支持18个万头智慧猪场、良种繁育基地和标准化屠宰厂建设，加快推进产业转型升级和高质量发展，拓展生猪行业监管服务功能，实现生猪生产降本增效。此外，南宁市紧盯重点区域和关键环节，落实监测排查、消毒灭源、调运监管等防控措施，完善应急制度，为生猪生产提供强有力保障。蒋建议称，目前生猪生产仍在惯性增长，短期内生猪价格缺乏大幅回升基础。下一步，南宁市将继续紧盯生猪产能调控，强化监测预警，抓好重大动物疫病常态化防控，推动规模猪场改造升级，持续推进粪污资源化利用，不断完善现代生猪生产流通体系，促进生猪产业高质量发展，确保猪肉市场稳定供应。蒋建议同时提醒广大养殖场户要科学安排生产，保持合理节奏，顺时顺势出栏，避免盲目压栏和二次育肥。（完）
