央广网天津7月21日消息（记者韩雨晨）7月21日，第十三届中国旅游产业博览会（以下简称“旅博会”）新闻发布会在北京国际饭店召开，本届旅博会将于9月1日至9月3日在国家会展中心（天津）举办，由文化和旅游部、天津市人民政府主办，天津市文化和旅游局、北京兴旅国际传媒有限公司承办，突出展现旅游产业、汇聚探讨前沿观点、聚焦促进洽谈交易、积极助力消费升级，努力将其打造成为推动国内国际双循环、带动旅游业转型升级的重要平台。据了解，中国旅游产业博览会已经在天津举办十二届，成功搭建起旅游产业展览展示和洽谈交易平台，有力促进了国内外旅游产业交流合作，本次旅博会首次选址国家会展中心（天津），展出面积为12万平方米，是迄今为止规模最大的一届，将举办展览展示、专题论坛、洽谈交易、场景体验等一系列活动。与往届旅博会相比，本届旅博会将突出四方面特色。本届旅博会突出旅游装备，结合天津市“一基地三区”特别是“全国先进制造研发基地”的城市定位，重点展示房车露营装备、景区装备、酒店装备、特种旅游装备等内容，特别是结合天津资源禀赋，呈现海洋旅游装备、邮轮游艇等内容；强调行业引领，本次主论坛为旅游产业高质量发展论坛，邀请国内顶尖旅游专家、知名旅游企业负责人展开研讨，为中国文化和旅游产业的融合发展及创新提供新的思路与方案，同时，举办全球旅行商大会、文商旅融合发展论坛、5G+智慧旅游协同创新发展推动大会等分论坛和活动，同期发布系列行业报告，力争将旅博会打造成旅游产业发展的前沿阵地。同时，本届旅博会还将凸显科技元素，突出科技+旅游，通过展示数字服务、旅游智能装备、旅游智慧管理等最新应用，全面勾勒智慧旅游发展的成果和最新技术，为旅游智慧化改造赋能，特别是天津展区将通过科技智慧元素展现天津旅游特色，模拟实际旅游场景，为观众提供沉浸式、互动式、智能式的现场观展体验；将强化采购交易，旅博会期间将组织2023京津冀旅游项目投融资洽谈会、旅游产品推介会、项目签约仪式等活动，整合主承办方资源，邀请上千名国内专业买家来津交易洽谈，安排“一对一”交易洽谈，探索解决文旅企业融资难、融资贵、融资慢的路径，提升展会实效，促成更多交易。此外，为充分展示天津特色，本次展会期间将开展精彩纷呈的文旅活动。展馆将特设“天津早点好  处处西北角”展区，展示天津大福来、耳朵眼、起士林等特色美食，让参会者感受到地道的天津味道。同时，展会期间还有哈雷摩托车巡游、王者荣耀争霸赛、文旅产品直播带货等场景活动，力求从多个角度呈现多样天津的文旅资源和城市底蕴。全市各区、各主要旅游企业还将围绕“天长地久，津秋常走走”主题，在金秋9月组织100余项文旅活动，为广大市民群众和各地游客提供丰富多彩的津韵旅游产品。更多精彩资讯请在应用市场下载“央广网”客户端。欢迎提供新闻线索，24小时报料热线400-800-0088；消费者也可通过央广网“啄木鸟消费者投诉平台”线上投诉。版权声明：本文章版权归属央广网所有，未经授权不得转载。转载请联系：cnrbanquan@cnr.cn，不尊重原创的行为我们将追究责任。举报/反馈
