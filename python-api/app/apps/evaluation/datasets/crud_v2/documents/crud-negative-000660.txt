，正文：8月17日凌晨，超跑品牌兰博基尼发布了首款纯电车型的预告视频。这段15秒的影片起初从城市的高楼大厦中取景，随后转场至一位女模特的眼睛，再到太空、彗星等元素依次出现，最后展示了这款神秘新车的轮廓。  虽然短片中仅出现了新车的车头轮廓，但还是能看到部分新车的明显特征。车头采用“=”字形前大灯，车身姿态较高，但车顶高度较低。结合此前兰博基尼放出的另一则预告，该车侧面看上去拥有四座轿跑的姿态，棱角分明的设计也很好地继承了兰博基尼以往的设计语言。  兰博基尼CEO Stephan Winkelmann透露，新车将是一款2+2“大型旅行车”（grand tourer），相比于Huracan或新款Revuelto来说，更适合日常使用。新车将在8月18日举行的蒙特雷汽车周上展示。  这辆车将采用由保时捷领导开发的新平台“SSP Sport”，并计划在2028年正式上市。兰博基尼设计总监Mitja Borkert表示，这款新车“将保留1000%的兰博基尼设计基因”，且兰博基尼旗下Aventador、Huracan和SUV车型Urus未来都将会完成电气化改造。本文属于原创文章，如若转载，请注明来源：超跑品牌兰博基尼发布首款纯电车型：2+2大型旅行车https://news.zol.com.cn/829/8290316.html
