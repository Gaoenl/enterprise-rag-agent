用深圳精神向世界讲述中国故事——写在深圳出品原创舞剧《咏春》即将开启海外首秀之际③在全国20余座城市收获无数掌声与赞誉之后，深圳出品原创舞剧《咏春》受邀将于9月27日至30日在新加坡滨海艺术中心连演4场，拉开海外演出的大幕。这部在中国演艺市场催生出“咏春热”文化新景观的现象级舞剧，将把新时代的深圳故事与中国故事传扬海外。双场景、双故事带来时代共振舞剧《咏春》由中共深圳市委宣传部、深圳市文化广电旅游体育局出品，深圳歌剧舞剧院创排演出，由2022年度国家艺术基金、广东省文艺精品（文艺人才）专项扶持资金与深圳市宣传文化基金共同资助，邀请了中国舞蹈家协会主席冯双白编剧，舞坛“双子星”韩真、周莉亚共同执导，并汇聚了一批国内顶级艺术家参与舞台创作。《咏春》讲述的是一个发生在电影拍摄片场的故事：戏外，深圳《咏春》剧组在拍摄叶问的故事；戏内，叶问赴香港打拼创业，弘扬咏春武学之道。舞剧中，戏内外两个故事并行展现、无缝切换，两个场景在舞台上旋转交替。虽然剧名为《咏春》，该剧讲的却不仅仅是英雄叶问的故事，而是同时在“戏外”塑造了以灯光师大春为代表的一群“追光”的平凡人。双场景、双故事的艺术架构带来了两个时代的同频共振，是该剧的亮点之一。导演韩真说：“这部舞剧当然是以叶问为精神核心，同时也讲述了这个电影片场的造梦人、平凡人，他们是如何追逐着光、靠近光，用光去雕刻、塑造英雄的身影，以及这帮电影人追溯着英雄的脚步，虽然希望自己站在光里，但是最终照亮别人的故事。”在《咏春》中，叶问的故事让观众看到了优秀传统文化中体现出的民族精神，而“追光者”的故事则让观众感受到了时代精神。观众杨女士表示：“虽然叶问、咏春拳、拍电影这些事情好像离我们很远，但我的内心却又感觉很近、很亲切，它讲的就像是我身边的甚至是我自己的故事，看完后回味无穷，让人产生情感共鸣。我们每个人都有过至暗时刻，叶师父为我们做了榜样，灯光师告诉我们追光的意义。”双非遗呈现中国传统文化内涵在双场景、双故事的艺术架构中，《咏春》创作者以令人惊艳的艺术巧思嵌入了双非遗——咏春拳、香云纱。“刚”的咏春拳与“柔”的香云纱，这两项来自岭南的国家级非物质文化遗产以刚柔并济的形式生动书写了新时代的深圳故事与中国故事，呈现出深圳出品文艺精品的特质。尚武精神是中华优秀传统文化的重要组成部分，而中国武术便是尚武精神的主要表现形式。在舞剧《咏春》中，五大功夫门派咏春拳、南螳螂拳、八卦掌、八极拳、太极拳悉数登场，高燃对决场面恰到好处、惟妙惟肖地精准表达了中国武术的人文内涵，咏春拳作为拥有200多年历史的传统文化大IP，也在剧中得到了完美而又创新地诠释。《咏春》中的另一项国家级非遗——有一千多年历史的香云纱，则通过“深圳设计”穿在不同角色身上。该剧的香云纱顾问由深圳本土品牌设计师邢莉莉担任，她用“深圳设计”在服装、道具、视觉等方面提供了诸多奇思妙想，让咏春拳、香云纱“双非遗”展现出新的生命色彩。该剧服装设计阳东霖也表示：“我觉得用这样一种传承的国家级非遗技艺，能够让舞台上身穿香云纱的演员带来的舞段，充满我们想要的岭南记忆。”剧中人物体现深圳精气神心怀梦想、拼搏进取是深圳最动人的精神体现。《咏春》中的那群“追光者”，正是深圳拼搏精神的真实写照，也是与这座城市的精神连接。正如叶问的饰演者、深圳歌剧舞剧院首席舞者常宏基所说，在这部舞剧中，叶问与“追光者”一样要去追求自己的理想。“剧里所有的人物，他们的拼搏、坚毅、果敢、奉献，体现的正是深圳这座‘梦想之城’‘青春之城’的精气神。”舞剧《咏春》编剧、中国舞蹈家协会主席冯双白则认为，深圳的舞者们也是“追光者”，追求着艺术作品的完美。“深圳这些可爱的年轻人是真正地把自己沉浸在传统文化的世界里，正是他们的表演让舞剧呈现出不同于以往的质感，这种质感也决定了舞剧《咏春》的独特审美，这一点是非常宝贵的。”拿下中国冬奥会历史上第一枚速度滑冰金牌的运动员张虹，在哈尔滨观看《咏春》后瞬间成为迷妹，她激动地说：“舞台上这几十个演员，代表了年轻有活力的深圳，我也希望他们能够代表中国的年轻人，给世界展示中华文化、中国精神。”如今，《咏春》即将扬帆启航，通过这部富有精神内涵、审美韵味与人文价值的深圳文艺精品，向世界讲述新时代的中国故事。编辑 郑蔚珩 审读 刘春生 二审 高原 三审 陈晨周斐斐（作者：深圳报业集团记者 祁琦/文 莫荣宝/视频 陈苑婷/文案 平安琪/设计)[责编：邢彬]
