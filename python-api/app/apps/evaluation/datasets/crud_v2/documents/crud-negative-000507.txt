原標題：傳達學習習近平總書記來川視察重要指示精神研究部署省政協貫徹落實舉措7月31日，省政協黨組召開（擴大）會議，傳達學習習近平總書記來川視察重要指示精神和省委常委會（擴大）會議、省委工作會議精神，研究部署省政協學習宣傳貫徹落實舉措。省政協主席、黨組書記田向利主持會議並講話。會議指出，在深入學習貫徹黨的二十大精神、奮力推進全面建設社會主義現代化國家開好局起好步的關鍵時期，習近平總書記親臨四川視察指導，充分體現了對四川人民的如山厚愛、似海深情，對四川工作的高度重視、殷切期望。這是四川發展歷程中具有裡程碑意義的大事。總書記的系列重要指示為四川發展精准把脈定向，對於我們深入貫徹黨的二十大精神，奮力譜寫中國式現代化四川新篇章﹔對於准確把握黨中央關於高水平對外開放的戰略部署，推動四川構筑向西開放戰略高地和參與國際競爭新基地﹔對於更好把握黨中央關於開展主題教育的決策部署，推動我省主題教育走深走實具有十分重要的意義，必將進一步增強巴蜀兒女擁護“兩個確立”、做到“兩個維護”，緊跟總書記、緊跟黨中央的堅定自覺，奮力推動新時代治蜀興川再上新台階。全省政協要把學習宣傳貫徹習近平總書記重要指示精神作為首要政治任務，與黨的十八大以來總書記對四川工作系列重要指示精神一體學習領會，深切感悟領袖關懷，充分認識重大意義，准確把握核心要義，扎實抓好貫徹落實，不斷提升政協服務治蜀興川再上新台階的貢獻率。會議強調，要堅決貫徹落實總書記重要指示精神，嚴格按照省委部署安排，結合政協實際，認真總結主題教育和上半年省政協工作，圍繞總書記提出的“三個牢牢把握”“四個發力”重要要求，以釘釘子精神做好下半年工作。要從全國大局把握四川的戰略地位和戰略使命，聚焦在推進科技創新和科技成果轉化上同時發力、在建設現代化產業體系上精准發力、在推進鄉村振興上全面發力、在筑牢長江黃河上游生態屏障上持續發力，精選小切口題目開展調研視察、民主監督、協商議政，扎實推進“同心共建現代化四川”專項行動，深入開展“我為高質量發展獻一策”活動，助力我省圓滿完成全年目標任務。要持續抓好主題教育，對標對表開展全面自查、系統評估、切實整改，建設讓黨放心、人民滿意的模范機關。會議審議通過了《中共政協四川省委員會黨組學習宣傳貫徹習近平總書記來川視察重要指示精神工作安排》。（四川日報全媒體記者陳婷）(責編：袁菡苓、羅昱)分享讓更多人看到
