23-08-16 06:55，正文：本报讯(沈阳日报、沈报全媒体记者 吕良德)8月11日，文明春风“五进”系列活动——“传播文明新风共建文明餐桌”文明餐桌进社区主题活动在沈河区风雨坛街道铝镁社区新时代文明实践站举行。这是沈阳市文明办、沈阳市饮食文化研究会共同开展的第30场“文明餐桌进社区”活动，旨在进一步提高市民文明意识，倡导文明、绿色的用餐理念，营造节俭光荣的良好氛围。活动中，铝镁社区志愿者向辖区居民讲解了“如何勤俭节约，珍惜粮食”的生活小妙招，现场宣讲文明餐桌公约、文明餐桌礼仪17条宣传资料，并倡导广大居民从自身做起，从现在做起，节约每一粒粮食，抵制和反对浪费粮食的行为，养成勤俭节约的良好风尚；同时积极与辖区内饭店、商铺代表沟通，提醒他们要发挥监督作用，提醒顾客树立点餐吃多少点多少、吃不完打包带走的用餐意识。大力宣传勤俭节约的良好习惯，号召广大居民行动起来，节约粮食，反对舌尖上的浪费，养成文明健康绿色环保生活理念。在有奖问答环节中，居民踊跃参与，就主持人提出的问题积极发言，将活动现场的气氛推向高潮。下一步，风雨坛街道铝镁社区将常态化开展文明餐桌礼仪活动，以实际行动践行勤俭节约理念，“一粥一饭，当思来处不易；半丝半缕，恒念物力维艰”，引导居民从珍惜每一粒粮食做起，让每一位居民都成为共建文明餐桌的宣传者、参与者。
