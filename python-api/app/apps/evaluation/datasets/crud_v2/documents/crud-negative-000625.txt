2023-08-07，正文：全城悲恸，只为一人！8月5日，在山东省济宁市汶上县，市民自发地手持鲜花，走上街头。他们惋惜、悲痛，心中秉持着一个信念：接烈士冯振，回家！7月31日，山东济宁籍消防员冯振在强降雨抢险救灾中壮烈牺牲，年仅30岁。8月2日，应急管理部批准冯振同志为烈士，并追记一等功。事情是这样的，一名打工小伙下夜班后，错过回家的末班公交车，舍不得花十几块钱打车，决定步行回家。小伙表示：对普通人来说，这里花十几块钱、那里花十几块钱，几千块钱的工资很快就没了。小伙表示：钱难赚，十几块钱都能吃三天的早餐了，还是走路回去吧。网友看到这一幕后，纷纷说出了自己的看法。有网友说：成年人的世界哪有容易二字，看得出来，这名小伙舍不得花钱，说话的时候都在颤抖，看出来不容易。还有网友说：小伙说话之际几次哽咽，引起我们的共鸣了，太能感同身受了，曾经我为了省下一块钱走了好几公里的路。也有网友说：加油，小伙子，你的未来还长着呢，不要轻言放弃。不得不说，这名小的处境是很多人的真实写照，有多少在大城市努力奋斗的人还在不断拼搏，愿他们都能被生活温柔以待。网友评论：这才是普通人的生活，少看那些毒鸡汤吧这里十几块，哪里十几块，一个月就那几千块工资，几下就没了，这句话说出了好多打工人的悲伤曾经为了省2块钱公交费，徒步走了5公里(责任编辑：黄昱植)
