2023-07-27 09:42，正文：原标题：成都大运会火炬传递最后一个传递日活动举行央广网北京7月27日消息（记者韩民权 黄鹂 陈凯）据中央广播电视总台中国之声《新闻和报纸摘要》报道，成都第31届世界大学生夏季运动会26日举行最后一个火炬传递日活动，“青春绽放——世界大学生运动员人文交流活动”也于26日晚在四川大学博物馆新馆举行。26日早上9点，成都大运会最后一个火炬传递日活动在西南交通大学（九里校区）举行。火炬随后在成都理工大学、成都大学进行传递，并在东安湖体育公园举行收火仪式。成都大运会火炬传递自6月10日启动后，已完成在北京、哈尔滨、深圳、重庆、宜宾5座城市高校的传递。火炬手们通过火炬传递，将“绿色、智慧、活力、共享”的办赛理念和“成都成就梦想”的大运会口号传遍每一个角落。参与本届大运会火炬传递的火炬手共有800名。成都大运会火炬手蒋文文：以前我们是运动员，然后转型成为教练员，第一次作为火炬手参加到综合运动会当中，真的非常自豪。28日晚，经过10站26个点位传递的成都大运会火炬将点燃开幕式举办地东安湖体育公园主火炬塔，正式拉开成都第31届世界大学生夏季运动会的帷幕。26日，主题为“青春绽放——世界大学生运动员人文交流活动”在四川大学博物馆新馆正式启动。其中，“青春 in Time”第31届世界大学生夏季运动会运动员联欢会将于7月29日在成都大运会运动员村举办。大运会火炬“蓉火”设计者许燎源：这次最不同的就是除了体育竞技，更重要的是一个人文交流，让全球的青年、学生都能看到的一个未来的中国，一个充满远见、充满文化和艺术感的新的中国。“国宝新韵"博物馆文创大集26日也同步在四川大学博物馆新馆举办，活动将持续至8月10日。来自故宫博物院、中国国家博物馆、三星堆博物馆等国内几十家知名博物馆的特色文创在这里展览展销。四川大学博物馆馆长霍巍：我们博物馆这次几乎没有一件复制品，都是我们的真品，让大家真实触摸到过去的历史。返回搜狐，查看更多责任编辑：
