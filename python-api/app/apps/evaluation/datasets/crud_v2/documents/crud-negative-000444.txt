首个国外航司入驻鄂州机场；一客机在空中“喷火” 航班紧急返航！2023-08-18 16:03来源：澎湃新闻·澎湃号·政务字号韩媒：韩国7个地方机场扩增中国航线 年内将增加4500个航班据韩国亚洲经济报道，韩国机场公社（以下简称“公社”）于16日召开紧急对策会议，旨在吸引更多的中国团体游客。会议决定增加金浦机场、济州机场等国内七个地方国际机场的4500个中国航班。公社方面表示，随着中国政府10日允许赴韩团体旅游，为吸引更多中国游客，制定上述紧急对策。今年上半年，通过7个韩国地方机场入境韩国的中国游客达到12.5万人次。与新冠疫情暴发之前的2019年同期相比，仅达到18.8%。然而，公社对未来充满期待，预计重启赴韩团体旅游后，下半年中国赴韩游客将达到72万人次。除了增开中国航班以外，会议当天还讨论一系列追加对策，包括开辟新航线、举办机场免税店打折活动，以及在机场内设立专门为中国团体旅客提供接送服务的区域。日航社长有意扩充地方航线将访日游客送往各地据共同社消息，日本航空社长赤坂祐二近日接受共同社采访，表示有意扩充在日本的国内地方航线。他称考虑开通连接交通不便的离岛等地方机场的航班，“希望打造能把访日外国游客吸引到各个角落的基础设施”。日航将主动创造需求，比如打造在北海道可体验大自然和不同文化的旅游商品，或支援鹿儿岛县奄美大岛的环保。通过增加与地方联系，到2025年度把国内休闲等目的的旅客数较2019年度提高一成。日航子公司北海道Air System最快2023年冬季开通札幌丘珠至根室中标津航线。赤坂考虑到连接地方的这类航线，介绍称“将铺开细致的网络”，“通过更多人到访，可以提升地方活力”。BAESL品牌标志正式发布8月18日，中国国际航空股份有限公司（简称国航）与罗尔斯-罗伊斯（简称罗罗）合资成立的北京航空发动机维修有限公司（简称BAESL）正式发布品牌标志，以崭新形象登场。按计划BAESL项目将于8月底正式破土动工，国航与罗罗在民用发动机售后维修领域的合作即将迈出坚实一步。BAESL将为罗罗遄达700、遄达XWB-84和遄达1000发动机提供MRO（维护、修理和大修）支持，BAESL的成立将丰富国航维修版块布局并扩大发动机大修能力范围，有力推动国航机务产业化发展，有效降低高推力发动机运营及保障风险，提升国航机队营运水平。首个国外航司入驻鄂州花湖机场8月18日5：34，花湖机场晨光熹微。比朝阳更早到的是一架阿提哈德航空的波音777-200全货机。这是一段航程的结束，却是另一段跨文化旅程的开启。因为这不仅意味着“阿布扎比-鄂州”全货运航线首航成功，也是花湖机场迎来首个国外航司入驻。越南航空业前7个月客运量同比增长41.8%越南航空局领导表示，2023年前7个月越南航空客运市场出现复苏迹象，各家航空公司运输乘客量比去年同期增长41.8%。其中，越南各家航空公司载客量增长20.1%。国内各家航空公司运输的国际旅客数量猛增至424.2%，而国内旅客数量较2022年同期小幅下降4.4%。近日，越南政府批准了新的签证政策，允许向所有国家和地区的公民发放电子签证；自8月15日起，将电子签证（e-visas）的有效期从30天延长至90天。同时，部分国家的游客可免签入境越南，居留时间从15天延长至45天。凭借这项新政策，国际游客更容易来到越南，也可以延长停留时间，增加旅游活动、体验和消费。预计这将进一步推动越南旅游业和航空业在今年最后几个月的发展。一客机在空中“喷火” 航班紧急返航！综合外媒报道，8月15日晚，美西南航空一架从休斯敦飞往墨西哥的307航班在飞行过程中突然起火，画面显示发动机冒出火焰。一名搭乘该航班的乘客回忆道，“一开始飞机左右晃动，我坐过很多次飞机，我知道这不同寻常，透过窗户，可以看到火焰窜出。”报道称，该航班原定从休斯顿飞往墨西哥，事发后该客机返航至休斯顿机场。根据FlightAware数据显示，该客机在空中共飞行27分钟。飞机降落机场后，机上乘客被安排搭乘另一航班前往目的地。美西南航空发言人劳拉·斯威夫特(Laura Swift)表示：“飞机已安全着陆，并已停止服务接受审查。”“已安排另一架飞机继续飞往坎昆，我们感谢乘客的耐心和支持。”美西南航空随后又在声明中表示，这架飞机检查出了“潜在的机械问题”，该航空公司没有对火灾事件进一步置评。原标题：《首个国外航司入驻鄂州机场；一客机在空中“喷火” 航班紧急返航！》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
