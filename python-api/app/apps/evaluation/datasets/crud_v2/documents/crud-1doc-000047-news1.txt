08-15 09:16，正文：日前，第十六届西普会——中国健康产业（国际）生态大会在海南博鳌开幕，本届大会以“二元协同重塑产业——开启个人健康主体责任新时代”为主题，汇聚众多行业精英人士，共同寻求健康产业新机遇。华润三九董事长邱华伟出席会议，并作了《大健康产业高质量发展的思考》主题演讲。邱华伟表示，宏观政策引领、供需两端发力，大健康作为我国重点发展的战略产业，迈入高质量发展的新阶段。“华润三九顺应产业发展趋势，持续开展创新升级实践，以创新引领‘高质量发展’。”邱华伟介绍，公司不断升级创新品牌传播方式，以消费者为中心，与故宫、温氏食品等开展跨界合作，满足年轻人个性化需求，打造健康公益日-三九健康日，传递品牌“暖心”调性，提高与消费者的沟通能力。公司利用大数据提升新品的引入效率，从包装、剂型、成分多维度提升用户体验，优化工业设计，通过产品创新升级，为更多人提供更优质的解决方案。除了深耕品牌及产品创新，华润三九还积极探索智能制造新模式。邱华伟介绍，公司通过自动化与信息化深度融合，打造数字化标杆工厂，将数字化技术与核心制造环节相结合，引领医药行业进入智能制造新时代。2022年，华润三九成为国内首家通过智能制造能力成熟度四级评估的医药行业标杆企业。邱华伟表示，华润集团致力于带动中药全产业链发展，强化责任担当。华润三九作为中药行业代表性企业，围绕中药产业链持续深耕。为更好地落实中药产业链高质量发展计划，发起成立中药产业链高质量发展联盟，广泛联合国内中医药行业各类资源，构建中医药新生态，充分发挥主体支撑与融通带动作用，推动落实国家中医药发展战略。“华润三九将以消费者为核心，以差异化的、优质的产品和服务，满足消费者更高层次健康需求，建设领导品牌。”邱华伟还表示：“未来，将继续秉持可持续发展理念，持续提升现代化公司治理水平，始终将广大股东的利益放在首位，与市场各方携手创造价值，共享发展成果，用实际行动和优良业绩助力‘健康中国’建设”。来源：中国证券报·中证网作者：陆静温馨提示：最新动态随时看，请关注金投网APP。
