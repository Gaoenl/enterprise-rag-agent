近日，《2023南京市民营经济发展报告》正式发布，报告显示，南京市上规模民营企业对全市经济增长的贡献率达43.1%。南京税务部门在9月发布《支持民营经济发展若干举措》，从落实税费政策、优化办税服务、维护企业权益、服务地方发展等四个方面推出服务措施，并推动各项举措落地见效，进一步提振民营经济发展信心，用“硬核”措施滋养民营企业“秧苗”，更大力度支持民营经济做大做优做强。税惠活水“滴灌”重大项目重大项目是拉动地方发展的重要引擎，税惠政策的精准释放为全市重大项目的早启动、稳落地、早建成提供了充足动能。“今年企业出货规模、销售收入持续增长，我们目前的生产设备均满负荷运转，订单已经排到了2024年。”在江苏国轩新能源智能制造项目生产基地，为提高生产效率，完成订单任务，今年4月刚刚建成投产的第三条生产线马力全开，经流水线合浆、涂布、辊压等十余道工序，一块块银白色的磷酸铁锂电池陆续“下线”。江苏国轩新能源科技有限公司总经理张峰坦言，如何获得充足的资金保障是重大项目顺利推进的关键。为确保重大项目顺利落地、建设、投产，六合区税务局结合新能源产业特点组建服务专家服务团队，从政策宣传、申报辅导、跟踪问效等方面为企业提供精准纳税服务。“今年，我们企业享受了包括研发费用加计扣除在内的多项优惠政策，这对我们扩大生产、增加投资帮助不小。良好的营商环境，贴心的服务保障，是我们选择在这里投资兴业的关键。”张峰说。南京伟思医疗科技股份有限公司是一家扎根于南京市雨花台区的国家级专精特新企业，公司的研发总部建设项目（南园项目）是南京市的“重点工程”，税务部门为公司顺利完成国外技术收购提供了精准的政策辅导。“我们通过加强数据分析对比，运用大数据工具为重大项目企业精准画像，通过‘税企直联’机制，及时指导企业适用税费优惠政策，同时与发改委、财政局、工信局等部门积极开展信息交换，助力重大项目又好又快发展。”雨花台区税务局相关负责人说道。优质服务助企轻装疾行在2023世界显示产业大会上，杉金光电（南京）有限公司带着可折叠系列等最新产品在展区亮相。“我们一直坚定走差异化创新之路，近几年公司享受研发费用加计扣除近4.5亿元，让我们更有底气壮大研发团队，不断交付出有差异化竞争优势的产品，如今公司已成为全球规模最大的偏光片生产基地。”公司办税人孙贻兴表示，企业的研发创新离不开税惠政策的持续激励。“改革”“创新”“研发”是民营企业蓬勃发展的活力基因，也同样成为税务部门赋能企业发展的关键词。近期，经开区税务局组建网格员及业务骨干先锋队，聚焦企业的创新研发需求，积极推送“红利账单”，让企业“秒懂”政策红利，在企业创新研发的关键时刻“扶一把”“帮一程”。“我们设有新疆研发中心，并计划成立南京、上海两地研发中心，近年来公司的研发投入达到了销售收入10%以上。”创新研发的信心和底气从何而来？在特丰制药有限公司财务负责人班波涛看来，税费优惠政策给予了最直接的支持。“高淳区税务局给我们送来了惠企‘政策锦囊’，先进制造业企业增值税加计抵减等税惠政策让我们能够在创新之路上大胆闯大胆试。”班波涛说。税企携手共建沟通桥梁在南京市六合区的“金秋真情送岗位就业帮扶暖人心”招聘会上，人才市场门口的税费政策咨询服务台热闹非凡，不少求职者和招聘企业正在向税务人员咨询各项税费优惠政策和便民办税缴费服务举措。“刚刚税务工作人员非常耐心和详细地向我介绍了关于招用应届大学生的税费优惠政策，让我有了系统性的了解和认识，这对于我们民营企业来说非常受益。”南京龙海土地开发有限公司的章先生对于税务部门的暖心服务频频点赞。南京税务部门结合“便民办税春风行动”“春雨润苗”专项行动，积极面向民营企业开展多种形式的特色活动，为民营企业提供个性化服务，营造支持民营企业发展的良好氛围。“您知道‘税银合作’的具体措施吗？”“我们公司是今年新设立的一般纳税人，还没有办理过汇算清缴，能申报享受‘六税两费’吗？”……一场别开生面的惠企政策沙龙在中国（南京）软件谷云密城顺利召开，30余家企业代表参与其中。该活动以税收圆桌会议的形式，让税务人员与企业代表共同探讨企业发展过程中遇到的涉税难题，并征集税务服务意见建议。“今天的活动让我真切感觉到税务‘管家’就在我们身边，税务部门把对接企业的实际需求和普及最新的税收优惠政策融入进轻松的对话交流中，让我们的疑难困惑都能及时得到解答。”江苏欧帝电子科技有限公司财务人员说道。(宁穗）
