2023-08-02 16:25，正文：原标题：公教预约|2023暑期少儿“美术馆之夏”艺术活动（第三期）为向公众提供多元化公共文化服务，丰富我市少儿暑期艺术生活，泰安市美术馆以培养少年儿童艺术兴趣、激发少儿艺术创造活力、发掘少年儿童多方面艺术才华和艺术智慧为目的，精心组织策划了一系列丰富多彩的少儿美育活动。这个夏天，让我们齐聚泰安市美术馆，通过“美术馆之夏——少儿艺术集结令”活动，让孩子们体会到水墨人物写生的妙趣，欢迎广大少儿朋友及家长积极参与，泰安市美术馆祝愿小朋友们暑假多彩并充实快乐！活动名称趣味水墨漫画——儿童创意思维表现之水墨人物写生活动内容8月4日，将开展美术馆之夏第三期——趣味水墨漫画·儿童创意思维表现之水墨人物写生少儿公教活动，主讲水墨人物漫像写生。课上的技法教学和现场写生各占一半，通过水墨加线条造型，直接写生身边熟知的物像，来引导孩子感知世界，形成观察世界、认知世界和表现世界的能力，进而培养孩子的主动创作和表现力，培养孩子们对形体的认知能力。利用水墨画的无限可能，发挥孩子们丰富宽广的想象力，让孩子们沉浸式体验水墨画的乐趣和获得感，在幼稚单纯的心灵里种植绘画最朴素的原始美。相信水墨人物漫像写生会创作出意想不到的精彩。主讲教师王天 中国青年美术家协会理事，中国国家画院张江舟工作室画家，中国艺术研究院杜滋龄工作室画家，中华诗词学会会员，泰安市美术馆（泰山画院）副馆长（副院长），泰安市青年美术家协会主席。擅长写意人物、花鸟画，兼顾写意山水画。活动地点泰安市美术馆一楼少年儿童公教体验区活动时间和人数8月4日（周五）下午3:00——5:00报名人数：20活动对象7—16岁未成年人（报名需填写未成年人信息）其他事项1、所有绘画工具均由美术馆提供。2、按照年龄要求报名，不能虚报、代报。3、当天活动开始前20分钟到场。4、请父母任何一人陪同参加。5、预约参加公教活动累计2次未到馆参与活动，将被列入黑名单，60日后才能重新获得预约权限。6、咨询电话：0538-6995267活动时间和人数请长按下图二维码，填写报名信息（请按要求填写活动参与者真实信息）来源：泰安市美术馆 返回搜狐，查看更多责任编辑：
