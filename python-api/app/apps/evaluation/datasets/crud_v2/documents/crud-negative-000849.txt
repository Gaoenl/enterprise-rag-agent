2023-07-27 23:18:41，正文：红网时刻新闻7月27日讯（记者 张金东 实习生 梁静 胡倪菲）昨日卸甲别军营，今朝地方再启航。7月27日，“2023·荣光行动”湖南退役军人暨军人军属（大湘西片区）专场招聘会在怀化市体育中心篮球馆举行。此次招聘会由湖南省退役军人事务厅、怀化市人民政府、怀化军分区主办，怀化市退役军人事务局、怀化市人力资源和社会保障局、怀化军分区政治工作处共同承办。招聘会现场，中国联通、湖南兴怀新材料、酒鬼酒等140多家企业集中揽才，岗位涵盖销售、技术、物业、教育、消防等不同领域，行业范围广，岗位类型多，可选择性强，可满足不同年龄、不同学历、不同专业退役军人的就业需求。“你先填个表，如果对销售感兴趣，我们也可以提供相应岗位。”在怀化市澳海物业服务有限公司招聘展台前，工作人员向求职者热情介绍。记者注意到，公司还“趁机”为楼盘打起广告，一块“首期1万 分期付”的招牌十分醒目。除了销售、安保人员等岗位，本次招聘会提供了为数不少的技能技术岗位，包括储备干部、策划、管理、新媒体运营、机械加工等，满足了退役军人及军属“多元化”求职需求，也让退役军人职业技能培训成果得到更好运用。翊程教育公司是一家从事体育赛事策划、健身休闲、文化交流的公司。负责人向德光介绍，他们专程从吉首赶来，将退伍军人作风引到学校里面去，国防教育和国防意识注入到学校里面去，这是一个刚兴起的一个行业，也是一个刚兴起的职业，而这对于退伍军人来说也算是专业对口。紧扣退役军人需求，招聘企业还提供了部分岗位供军人军属挑选。“我是中方人，中方离怀化很近，今天是陪着退伍的男朋友来的，顺便逛逛看有没有适合自己的岗位。”杨微说道，她觉得这个招聘会办的很好，招牌企业挺多，对于自己来说，选择的机会也更多，希望能找到一份离家近的工作。据初步统计，来自怀化市、邵阳市、张家界市、娄底市、湘西州的720名退役军人与随军家属参加了本次招聘，达成就业意向228个。怀化军分区相关负责人表示，怀化素有拥军优属、拥政爱民的优良传统，已八次荣获“全国双拥模范城”，接下来将进一步增强责任感和使命感，从大局出发，汇集力量，形成合力，全力做好退役军人与军属就业创业的各项工作。
