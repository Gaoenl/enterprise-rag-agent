2023-07-22 15:07，正文：本文转自【央视新闻客户端】；近日，美国多地遭遇恶劣天气，密歇根州、威斯康星州、科罗拉多州部分地区等遭冰雹袭击，在俄克拉何马州北部，风暴还导致一列火车脱轨。当地时间20日，在密歇根州的戴维森市，不少车辆的车窗被棒球大小的冰雹砸碎。当地居民：你可以看到当时这冰雹得有多大，车窗完全被砸碎。广告 可御可甜 有颜有料 惩罚整蛊任你选 >>进入直播间与主播亲密互动 ×当地居民：冰雹砸下来产生的那种压力，令人难以置信。同一天，威斯康星州的赖斯莱克市也遭遇冰雹袭击，对房屋和车辆造成破坏。当地居民拍摄的画面显示，冰雹从一家沃尔玛超市破损的天窗落到超市里，对商品造成损坏。科罗拉多州部分地区当天也遭冰雹袭击，当地居民拍摄的视频显示，院子的地板被冰雹覆盖，密密麻麻的冰雹砸在窗户上砰砰作响。据美国国家气象局报道，20日，雷暴天气还袭击了密苏里州西部、伊利诺伊州南部和肯塔基州北部，带来冰雹和强风。俄克拉何马州遭遇风暴 导致火车脱轨21日，在俄克拉何马州北部，一场最高风速每小时约130公里的风暴导致一列火车在费尔蒙特镇发生脱轨，共有29节车厢脱轨，维修工作已经展开，尚没有关于人员伤亡的报告。
