近日,中国科学院《互联网周刊》公布“2023年度中国数字化办公之选”名单,AIGC软件A股上市公司万兴科技(300624.SZ)入选“信创办公”榜单,旗下亿图脑图MindMaster入选“办公黑科技”榜单。此次一同上榜的还有金山办公、华为Metaline天线等知名企业和旗下产品。“2023中国数字化办公之选”名单由中国科学院《互联网周刊》、中国社会科学院信息化研究中心、德本咨询、eNet研究院等机构共同发布,聚焦技术实力、业内口碑、成长性、品牌力以及创新案例五大方向,遴选数字办公领域具有代表性、创新力及独特价值的企业。入选该名单,代表行业对万兴科技在数字化办公领域贡献的认可。万兴科技是中国数字创意软件领域产品覆盖面广、营收体量大、全球化程度高的A股上市公司,业务覆盖全球200多个国家和地区,累计用户近15亿,月活近1亿,被视为中国版Adobe。AIGC浪潮下,万兴科技正加速旗下亿图图示、亿图脑图等绘图创意软件,以及万兴PDF等文档创意软件的AI能力集成进程,赋能信创办公场景下的效率提升。绘图创意软件方面,万兴科技旗下一站式办公绘图利器亿图图示已上线智能助手亿图AI,支持AI写作、AI绘图、AI问答等AIGC能力,输入一句话即可生成流程图/思维导图/列表等。值得一提的是,此次入选“办公黑科技”榜单的亿图脑图MindMaster,为万兴科技旗下明星绘图创意产品,是国内首款实现AIGC“文生脑图”全端上线的脑图软件。依托AI技术,亿图脑图MindMaster集成了一键生成多层级思维导图、AI连续对话、AI绘画、预设场景、智能注释等功能,吸引全球新生代广泛使用。日前,在华为开发者大会上,万兴科技旗下亿图与华为签订鸿蒙生态深化合作协议,将通过亿图脑图MindMaster等集成AI能力的全场景一站式思维导图解决方案,助力鸿蒙用户在读书笔记、知识整理、商务办公、战略规划等场景中更高效使用思维导图等软件。文档创意软件方面,万兴科技旗下万兴PDF海外版Wondershare PDFelement已多端集成AIGC能力,支持AI聊天、智能总结、智能解释、内容重写、提问等功能。作为AIGC先行者,万兴科技通过聚焦行业用户核心需求,以视频创意、绘图创意、文档创意等创意软件为产品底座,加速数字化进程,驱动创意和效率升级,目前已服务全球100万中大型组织。当前,全球启动新一轮科技创新周期,生成式AI爆发宣告数字经济关键时点的来临。互联网周刊表示,数字办公已成为迎接变革的关键驱动力,AI加持下的办公软件有望迎来体系化的范式重构,国产办公软件智能化升级值得期待。
