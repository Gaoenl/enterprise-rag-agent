2023-08-09 15:32，正文：原标题：重庆警方侦破一起非法捕捞水产品案 抓获107名嫌疑人新华网重庆8月9日电 在8月15日首个全国生态日即将到来之际，重庆警方公布成功侦破一起跨省市重大非法捕捞水产品案件，抓获犯罪嫌疑人107人，现场查获渔获物600余公斤，涉案金额216.8万元。据了解，今年1至2月，重庆警方从市内部分餐馆有销售体态“活性”极佳、体表毫无损伤的野生鱼线索入手，以潜水电捕鱼必备作案工具“电鱼杆”“潜水服”为突破口开展分析，锁定51名潜水电捕鱼嫌疑人。经研判，落地查实并一举打掉以武隆陈某、北碚张某康为首的2个潜水电捕鱼团伙。经筛查比对，重点突破该51人共同上家——电捕鱼工具销售主要嫌疑人银某港。在此基础上，拓展研判、串并扩线，发现长江流域部分省市2400余人涉及潜水电捕鱼相关线索。对此公安部高度重视，将其列为公安部长江办重点专案，并成立专案组。在公安部统一调度指挥下，重庆警方会同贵州、广西、湖南等地公安机关，历时3个月、辗转36000多公里，于4月10日，在湖南通道县将销售电捕鱼工具的主要嫌疑人银某港抓获归案。6月2日，重庆、贵州、广西三地出动警力220余人开展集中收网行动，抓获犯罪嫌疑人79名，收缴电捕鱼工具13套、潜水装备1套，查扣涉案车辆4台、船舶4艘，一举打掉3个长期盘踞渝黔桂三地的非法捕捞全链条犯罪团伙。至此，重庆专案组共抓获嫌疑人107人（采取强制措施76人），现场查获渔获物600余公斤，查获涉案渔船14艘、车辆10台、电捕网捕渔具45副（套），涉案金额216.8万元，成功斩断跨渝黔桂三地的非法捕捞“捕运销”地下产业链。目前，该案正在进一步侦办中。来源：新华网返回搜狐，查看更多责任编辑：
