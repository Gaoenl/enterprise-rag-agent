2023-08-14 21:22，正文：原标题：红色小象儿童友好街区开街，把儿童福祉融入社区建设一个儿童友好街区应该是怎样的？日前，公益项目儿童友好街区在上海嘉定西云楼开街，从儿童的角度出发切实思考孩子的多元需求，为孩子们提供一个更加健康、安全、包容、绿色、繁荣的公共空间，助力上海市儿童友好型城市建设，让街区更有温度、更具活力、更加包容。活动当日也是世界大象日，上美股份旗下婴童护理国民品牌红色小象围绕“一切为了孩子，为了一切孩子，为了孩子一切”的主题，带领现场大、小朋友体验了一场别开生面、富有童趣的“红色小象冒险之旅”。在小象课堂环节，红色小象结合世界大象日，为孩子及家长们科普关于大象的趣味知识和儿童护肤的宝贵建议；在互动游戏环节，孩子们通过小象拼图、打卡闯关、小象寻宝大作战等一系列小游戏，成为本场活动焦点，让儿童友好街区真正成为孩子们的欢乐营地。此外，红色小象“小学系列”新品小学霜，也在活动中迎来首次线下亮相，成为当天另一大亮点，吸引了众多家庭前来体验。基于对市场需求的洞察及守护中国婴童肌肤的初衷，红色小象专为中国1.07亿小学生研制推出“小学系列”新品，涵盖小学霜、小学乳等多品类产品，一站式满足小学生从洗到护、多个场景的个性化护肤需求，与家长共同守护儿童成长期肌肤健康。作为国货化妆品行领先企业，上美股份始终将自身发展融入时代发展与社会需要，多年来公益之旅未曾间断。其中，依托红色小象、newpage一页等婴童品牌对于母婴行业的关注与洞察，关爱儿童成为上美股份践行社会责任的重要一环。红色小象曾携手中国公益基金会为“童伴妈妈项目”捐赠超100万元物资；上美股份曾向四川偏远地区女童、安徽省临泉县贫困学生捐赠护肤品；连续六年向贵州少数民族地区捐赠爱心书包、校服，以实际行动关心、关注、关爱儿童的健康成长。在公益之路上，上美股份也不断拓展其公益视角，从弱势儿童到社会各个层面，从小爱到大爱。旗下一叶子作为国内纯净美容代表品牌，始终保持着对绿色原料的探索与专研，践行绿色、可持续发展，推动产业绿色升级。近期，京津翼等地深陷洪涝灾害，上美股份联合旗下多个品牌捐赠100万元产品物资，为受灾地区成人、儿童肌肤提供专属守护。作者：徐晶卉编辑：商慧*文汇独家稿件，转载请注明出处。返回搜狐，查看更多责任编辑：
