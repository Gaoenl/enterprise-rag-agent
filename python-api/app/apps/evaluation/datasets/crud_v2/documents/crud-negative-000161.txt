2023-07-27 06:32，正文：综合美国福克斯新闻网、“今日俄罗斯”（RT）等外媒报道，美国总统拜登25日在白宫发表“令人惊奇的言论”，称他的政府已经有效“终结了我们所知道的癌症”。这一言论引发舆论关注，也引发了网友的吐槽。“我常被问到的一个问题是，为什么美国人在一段时间内对能够做大事失去了信心？如果你能做任何事情，乔，你会做什么？我说我会治愈癌症。他们看着我，好像在说，为什么是癌症？因为没有人认为我们能做到。这就是为什么，而且我们可以做到。我们已经终结了我们所知道的癌症，”拜登当天说。福克斯新闻网称，拜登是在进行关于心理健康保健服务讲话时发表的这一言论。他在讲话中称，将致力于解决美国的精神危机，这也是他“团结议程”的一部分。关注这一新闻的俄媒RT评论称，拜登宣布的这一消息让许多美国人感到意外。福克斯新闻网介绍，拜登言论很快引起批评者的注意，不少人开启吐槽模式。众议院保守团体“自由核心小组”成员格雷格·普莱斯评论称，“痴呆症太严重了，现在他认为自己治愈了癌症。”↓美国保守派人士罗根·奥汉德利称，“拜登刚刚宣布他治愈了癌症。是的，他真的做到了。我们是一个国际笑话。”↓美国保守派机构媒体研究中心则进行了“事实核查”，“拜登：我说我会治愈癌症，他们看着我，好像在说，为什么是癌症？因为我们可以做到。我们已经终结了我们所知的癌症。事实核查：乔·拜登尚未治愈癌症。”↓福克斯新闻网介绍，拜登在其儿子博·拜登于2015年因脑癌去世后将“治愈癌症”作为其施政重点，2020年竞选期间也曾承诺“治愈癌症”。2016年，拜登在奥巴马政府期间领导了一项关于治疗癌症计划。他于2022年重启了该计划，目标是在未来25年内将癌症死亡率降低至少50%，并承诺在未来使致命癌症变得可以治疗。但是，报道援引癌症研究人员和专家的话称，治愈癌症仍有很长路要走。来源：环球网流程编辑：TF060                             如遇作品内容、版权等问题，请在相关文章刊发之日起30日内与本网联系。版权侵权联系电话：010-85202353
