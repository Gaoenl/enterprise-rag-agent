2023-08-19 10:43，正文：原标题：中俄海军舰艇东海联合巡航参考消息网8月19日报道据俄罗斯卫星社网站8月18日报道，日本防卫省统合幕僚监部17日发布消息称，中俄两国共11艘海军舰艇当天经冲绳本岛和宫古岛之间北上，从太平洋驶向东海。通过的舰艇大部分于7月在日本海实施射击等联合训练后，穿过北海道与萨哈林之间的宗谷海峡，驶入鄂霍次克海。据分析，这11艘舰艇参加了两国此前宣布的第三次海上联合巡航。日本防卫省称已通过外交渠道对两国提出交涉，指出“从安保角度严重关切”。据称这是首次发现中俄舰艇同时通过冲绳本岛和宫古岛之间的水域。日本防卫省称，这11艘舰艇15日上午9时前后在日本最南端的冲之鸟礁东北约280公里处航行，16日在冲绳县冲大东岛以南约50公里处向西前进，17日向东海移动。据报道，此前，中国国防部发言人吴谦表示，根据中俄两军年度合作计划，两国海军舰艇编队在太平洋西部和北部相关海域举行海上联合巡航。此次行动不针对第三方，与当前国际和地区局势无关。巡航过程中，中俄双方舰艇严格遵守国际法，全程位公海航行。他表示，日方近距离跟踪监视是非常危险的，极易引发误解误判和海空意外事件，敦促日方停止这些毫无实际意义的干扰，停止影响中日双边关系健康发展，损害地区和平稳定的不负责任言行。吴谦指出，中俄两军合作公开透明，旨在共同捍卫国际公平正义、维护世界和地区安全稳定。与一些国家抱守冷战思维，大搞阵营对抗，处处霸权霸凌的做法完全不同。另据路透社8月18日报道，俄罗斯国防部18日在一则通告中说，俄罗斯与中国的海军舰艇一直在太平洋联合巡逻，并在东海举行海军训练演习。俄罗斯国防部在“电报”社交平台上的一则通告中说：“俄罗斯海军和中国人民解放军海军的舰艇分队目前正在东海海域活动，自巡逻开始以来已航行6400多海里。”返回搜狐，查看更多责任编辑：
