"原标题:黑河学院举办中俄高校教育合作与特色发展论坛来百度APP畅享高清图片程旺 摄影作为黑河学院60周年校庆系列活动之一,9月27日下午,中俄高校(部分)教育合作与特色发展论坛隆重举行,来自俄罗斯远东国立农业大学、阿穆尔国立大学、共青城国立人文师范大学、哈巴罗夫斯克国立文化学院、布拉戈维申斯克国立师范大学、南乌拉尔国立大学及中国厦门大学、上海师范大学、东北农业大学、齐齐哈尔大学、哈尔滨学院、绥化学院、贺州学院、大庆师范学院及我校15所中俄高校领导齐聚黑河,共商中俄教育合作大计。党委书记王刚在致辞中指出,当今,中俄两国都在各自复兴之路上阔步前行,两国高等教育肩负着培养人才的特殊历史使命。继共同主办“国家年”“语言年”“旅游年”“青年年”“媒体年”之后,中国与俄罗斯两国将从今年开始举办“地方合作交流年”,续写新一轮两国举办国家级“主题年”活动的友好传奇。黑河学院愿继续同其他高校一道,抓住中俄地方合作历史机遇,顺应时代潮流,不断增强开放合作意识,进一步解放思想,树立世界眼光,共同在掌握对外开放本领、用好对外开放政策、营造对外开放环境上寻找突破,在观念上、行动上、体制上解决影响和束缚中俄高校教育文化合作的突出问题,不断提高国际化水平,共同培养具有较强的创新能力、国际合作意识,熟悉国际惯例,具有参与国际竞争能力的复合型创新人才。与会领导围绕“深化中俄高等教育合作 厚植本科特色发展新内涵”“搭建中俄人文交流、民心相通之桥”“构建教育的大目标大体系”“携手开创中俄高校文化艺术交流新篇章”“基于人才培养模式渊源的中俄高等教育理念的回顾与反思”“俄罗斯高校与中国合作的经验与前景”等方面展开讨论。中俄校长互通有无、深度交流,进一步挖掘中俄两国高等教育互补优势,共同勾勒出了两国教育文化交流合作的美好未来,推动本地区人民共享合作机遇和发展成果。(中国日报黑龙江记者站)返回搜狐,查看更多责任编辑:",
