2023-07-21，正文：7月18日，有网友发视频称，广西桂林阳朔遇龙河景区筏工用船桨殴打游客，并将游客推下河，引发关注。小王告诉记者，7月18日16时左右，她与父亲、妹妹、朋友在遇龙河景区乘坐竹筏，被筏工告知不能在竹筏上玩水，以免打湿救生衣，“但我在途中发现其他竹筏上有游客在玩水”。筏工告诉小王，想玩水的话，“需要在船票的基础上再交50元”。之后小王父亲和妹妹乘坐的竹筏先到达岸边，妹妹拿着水枪朝河里滋水，遭到了筏工的训斥，筏工用撑船的竹竿拍打水面，水花溅到父亲和妹妹的身上。父亲上前质问筏工，其他筏工聚集过来，双方发生了口角。视频拍摄者表示：“我就从前面走，听到声音看了一下，看到他拧开一瓶水往老人头上倒，然后又拿出一瓶水往老人头上倒，然后用瓶子打他。被打的老人看着像是流浪汉，我不知道具体情况，我只是路过，今天早晨从那出来的时候他还在那躺着。”19日，长江派出所工作人员回应称，会将视频里情况向领导反映。这起街头暴力事件引发了人们对于社会弱势群体的关注和担忧。在现代社会中，社会的发展和进步也带来了各种问题和挑战。尤其是在大城市里，随着人口的增加和城市化的发展，流浪汉、乞讨者等弱势群体也逐渐增多。社会应该如何保障这些弱势群体的权益和尊严，是我们面临的一个重要问题。
