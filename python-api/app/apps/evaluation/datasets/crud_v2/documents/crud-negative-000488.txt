2023-07-27 22:31，正文：原标题：晋俄企业项目对接会“云端”举行 推动两地经贸合作中新网晋中7月27日电 (高雨晴)2023年晋俄企业项目对接会27日在山西晋中举行，会议以“现场+视频”的方式进行。本次对接会由山西省人民政府外事办公室、山西省人民对外友好协会和俄罗斯晋商总商会共同主办，旨在深化山西和俄罗斯的友好交流，推动晋俄两地企业之间的经贸合作。2023年晋俄企业项目对接会27日在山西晋中举行。图为俄中友协副主席谢尔盖·萨纳科耶夫致辞。高雨晴摄 俄中友好协会副主席谢尔盖·萨纳科耶夫表示，今年，俄中两国贸易增长明显加快。据俄罗斯相关部门预计，2023年，双边贸易额有望超过2400亿美元。“我已收到来自山西省对外友协的邀请，很乐意到山西考察访问，希望与山西开展互利共赢的合作。也欢迎山西的企业家、社会活动家等，到俄罗斯莫斯科及其他城市访问。”萨纳科耶夫说。2023年晋俄企业项目对接会27日在山西晋中举行。图为山西省人民对外友好协会会长李悦娥致辞。高雨晴摄 山西省人民对外友好协会会长李悦娥说，中俄两国是山水相连的友好邻邦，近年来，两国元首和高层互访频繁，中俄关系处于历史最好时期。山西与俄罗斯在经贸科教、文化旅游、国际友城、民间交往等多个领域都有着非常好的交流合作基础和前景。目前，山西与俄罗斯共有5对友好城市与8个合作伙伴。李悦娥表示，举办此次企业项目对接会，旨在推动中俄经济和贸易合作高质量发展，为全面推进双边合作注入新动力，保持两国货物和服务贸易快速发展势头，致力于2030年前将两国贸易额显著提升。“做好山西省晋中市与俄罗斯方面的对接，对晋俄企业都是一次良好的机遇。”晋中市副市长张王杰表示，希望双方以此次对接会为契机，加强交流合作，巩固传统友谊，多层面、多维度开展对接，助力晋俄企业合作再上一个新台阶。当天的对接会上，共有8家中俄企业进行线上交流发言、项目推介。本次活动吸引了两国政府、企业、社会机构等上百名代表参加。(完)返回搜狐，查看更多责任编辑：
