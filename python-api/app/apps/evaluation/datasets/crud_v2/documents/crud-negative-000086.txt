海关总署2月14日发布数据显示，今年1月我国货物贸易进出口总值2.73万亿元人民币，同比增长8.7%。其中，出口1.5万亿元，增长13.9%；进口1.23万亿元，增长2.9%；贸易顺差2711.6亿元，扩大1.2倍。开局良好！数据背后有哪些新亮点？稳中提质！促外贸转型升级，如何助力高质量发展？2月16日晚，商务部研究院对外贸易研究所所长梁明和央视财经评论员刘戈做客《央视财经评论》演播室，深度解析。一月外贸开局良好亮点在哪儿？我国对“一带一路”沿线国家进出口增长11.5%，较整体增速高2.8个百分点，占我国外贸总值的比重提升0.7个百分点至28.2%。梁明：外贸“开门红”成色十足亮点纷呈商务部研究院对外贸易研究所所长梁明：这个开门红不仅是简单的开门红，而是一个成色十足、亮点纷呈的开门红。一月份进出口总额达到了2.73万亿元人民币，这个额度在历年1月份是非常高的，另外，一月份出口额也是非常高的，放在去年全年12个月也可以排在第四位。进口由于多个因素增速下滑，比如今年春节比较早，还有一些大宗商品价格大幅下跌，总体上来看，1月份进出口成色确实是非常足，此外，外贸结构是持续优化，动能也是持续转化。刘戈：外贸“开门红”来自多点开花央视财经评论员刘戈：这个开门红可以表述为多点开花，对欧盟，以及新兴经济体的出口大幅度增长，另外，从产品来说，除了机电产品，原来很传统的产品，比如塑料制品、玩具、家具、服装增长也很快。稳外贸如何助力高质量发展？一月份贸易方式和外贸商品结构的变化也表现了我国外贸优化结构、高质量发展的趋势。出口商品中，机电产品对出口增长的贡献率超过一半，集成电路、汽车及其底盘、计算机及其部件等产品出口附加值进一步提高，出口金额分别增长30.3%、36.5%和14.3%，出口单价分别增长34.6%、17.2%和19.3%。进口方面，1月份我国对原油、天然气等商品进口量增加，铁矿砂、大豆进口量减少。梁明：中国外贸企业创新能力持续增长商务部研究院对外贸易研究所所长梁明：中国的外贸企业凭借完备的研发创新能力和强大的技术支撑，依赖自身的竞争力拿到了国际多家知名公司长期供货的订单，创造不少利润。民企的韧性是最强的，只要有市场就会去保市场、保份额、保渠道。现在民企跟原来的民企已经发生了天翻地覆的变化，第一个转变是从数量的优势到质量的优势，第二个转变是更加注重品牌化的竞争力。刘戈：世界对中国制造需求潜力依然巨大央视财经评论员刘戈：世界对于中国制造需求的潜力还是巨大的，现在像“一带一路”的相关国家，它们对于中国制造的产品的需求，在相当长的时间里面很难被其他国家替代。比如，生产一个塑料玩具，模具制造必须跑到江浙等地，这边有成熟配套的产业链，另外很多电子产品也非常有市场，现在更多是自有品牌，这样会有更高附加值。梁明：民营企业对外贸易支撑力增强中国有能力做好“稳外贸”工作商务部研究院对外贸易研究所所长梁明：从数量到质量，从价格到品牌都是在转化中，尤其是外贸企业包括民营企业强劲的竞争力，会支撑中国外贸实现非常好的增长，再配合稳外贸的相关政策，将可以支撑2019年外贸总体增长，我们的信心还是比较足的。刘戈：外贸出口既要转型升级也要稳住底盘央视财经评论员刘戈：外贸出口要转型升级，但同时也要稳住底盘，我们传统的出口强项不能丢，“一带一路”相关国家的需求非常旺盛，新兴经济体经济增长，当地百姓对美好生活的追求，需要有大量中国制造的产品。而随着中国扩大开放步伐，也会带给众多国家互利合作的新商机，未来外贸通过转型升级和稳住传统制造，助力中国经济。
