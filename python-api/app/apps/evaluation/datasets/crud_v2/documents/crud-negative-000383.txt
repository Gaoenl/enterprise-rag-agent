2023-08-16 11:38，正文：暑假期间，不少在校大学生选择回乡度假或实习。江苏东台、盱眙、句容等多个县市近期抓住时机，举办了各种形式的交流活动，或带回乡学子游览景区、参观标杆企业，或拿出工作岗位供学子挑选，在畅叙家乡情谊的同时，试图吸引正在大城市求学的本地籍学子回乡创业、就业，打出了与大城市错位竞争的“抢人”招数。7月下旬，盐城东台市举办首届东台学子家乡行活动，组织500余名东台籍大学生开展了“五看”家乡行活动，即看城市、看乡村、看景区、看企业、看项目，让回乡学子了解家乡的人文底蕴、产业优势等。据《东台日报》微信公号报道，东台市有关部门向学子介绍了当地的人才政策，并发出“未来以来，就在东台”的邀约：“这里不仅有最深刻的眷恋和牵挂，更有广阔的干事创业舞台和发展前景，回到东台，扎根东台，是每一个有眼光、有抱负青年的正确选择。”7月底，淮安盱眙县委人才办、团县委联合举办盱眙籍优秀大学生交流分享会，邀请了来自南京大学、山东大学、四川大学、苏州大学、南京航空航天大学等80所高校的113名盱眙籍青年学子参加活动。活动现场为20名学子颁发“菁彩盱眙推荐官”聘书。会后，当地还邀请学子参观了盱眙经济开发区展示馆、盱眙龙虾博物馆以及部分企业，提升学子对盱眙的认同感、归属感和自豪感。还有镇江句容市，于8月11日举行“学子归来”招引服务活动，来自南京大学、东南大学、中南大学等高校的300余名暑期在句容实习以及句容籍大学生参加。活动预发布了200余个2024年优选生、公务员事业岗位和优质企业人才需求信息，市级部门及企业有关负责人与学子现场对接岗位信息、洽谈就业意向。相比各大中心城市，县市高教资源相对缺乏，鼓励外出学子回到家乡工作不失为“抢人”的一大招数。澎湃新闻（www.thepaper.cn）注意到，有的城市甚至在学子外出上大学之前，也就是高中刚毕业时便组织召开座谈会，鼓励本地学子将来回乡工作。8月10日，常熟市召开高中毕业生代表座谈会，市委书记周勤第在会上表示，希望各位同学在搏击学海中习得真本领，同时也希望大家关注家乡、支持家乡，与常熟双向奔赴、携手同行、互相成就，返乡创业携手赢未来。
