2023-08-17 20:20，正文：为做好困境儿童群体的关心服务工作，培养孩子们的爱国主义情怀，8月17日，由杨浦区妇女联合会主办、交通运输部上海打捞局党群工作处协办的“爱·守护”杨浦区“8.18”自强少年暑期爱国主义教育活动在中国救捞陈列馆进行。少年们首先在救捞陈列馆进行了参观学习，逐一观摩了亲切关怀、兴业华章、铸就辉煌、实践跨越、传承与创新5个展区，切身感受我国救捞事业从无到有、从弱到强，中国救捞事业近70年走过的发展历程，传承了中国救捞核心文化，感受“使命、责任、舍己、创新”的展馆内涵和“把生的希望送给别人，把死的危险留给自己”的救捞精神。少年们还一起观看了纪录片《2021大寒潮》，感受了救捞工作的不易，钦佩救捞队员的无畏勇气与高尚担当。在接下来开展的818帮困助学活动仪式上，上海打捞局、杨浦区妇联和社会爱心力量为自强少年们发放了爱心物资，希望能以此更好激励少年们勤奋学习，坚定理想和信念。记者了解到，长期以来，杨浦区妇联都通过“8.18”帮困助学活动关心区内困境儿童，并通过“向日葵计划”爱心助学活动，每年为有需要的困境儿童提供600次以上的基础教育帮助。除了帮困助学，杨浦区还开展了“邻家妈妈”项目，聚焦区内监护缺失儿童，由社区招募来的爱心妈妈与他们进行结对，帮助各类困境儿童健康快乐成长，培养自立自强品质。杨浦区妇联表示，未来将汇聚更多社会力量，多措并举，扎实开展困境儿童关爱服务活动，营造困境儿童学习、生活、健康成长的良好氛围，守护他们的快乐童年。
