近段时间，云南多地正密集启动新一轮的反诈宣传。云南南华县8月21日，云南楚雄州南华县公安局发布《南华县公安局致全县广大人民群众防范电信网络诈骗一封信》，信中提醒：境外电诈、赌博团伙通过网络发送高薪招聘信息，诱骗国内公民偷渡出境参与电信诈骗和赌博，一旦偷渡出境，将会被当作商品随意买卖，被电诈、赌博团伙非法拘禁，遭受殴打、伤害，解救工作十分困难，并需要支付高额赎金，请不要相信任何边境高薪招聘广告、视频及朋友的邀约偷渡出境。网络赌博都是境外犯罪团伙布置的陷阱，不仅输钱，还违法犯罪，将受到法律制裁。全文如下：云南昆明8月17日，昆明反电信网络诈骗中心发布《昆明反电信网络诈骗中心给全市市民的一封信》，信中称：近年来境外实施的电信诈骗案件频发，使用境外电话为途径实施电信诈骗的情况较为突出，为有效遏制境外电话引起电诈案件的高发态势，切实提高人民群众防骗意识和能力，现号召统计全市市民在无海外业务的情况下，关闭境外电话功能。全文如下：云南玉溪此前，云南玉溪市公安局反诈中心也发布了《玉溪市公安局反诈中心致全市人民的一封公开信》，其中提示：境外并非“遍地有黄金”。希望广大市民朋友不要轻信境外高薪招聘的虚假宣传，也不要轻信境外人员的甜言诱惑，避免落入境外“电诈”团伙的圈套。全文如下：云南禄劝县云南昆明禄劝县公安局反诈中心此前发布《禄劝公安局反诈中心致全县人民的一封公开信》，信中提到：被安排到诈骗窝点后如果想要回国，则需缴纳巨额的“赔款”和“赎金”。如果不交钱又完不成工作任务，则会像“猪仔”被转卖、受尽折磨，甚至有生命危险。全文如下：云南保山市保山市公安局反诈中心在《保山市公安局反诈中心致全市人民的一封公开信》中表示：被送至诈骗窝点的人员，通常会被不法分子限制人身自由，在诈骗窝点头目的安排下，强制学习诈骗技能，从事诈骗活动，完成高额诈骗任务。在任务完不成的情况下，轻则被断食、重则被电击、殴打等。全文如下：严打！中泰缅老四国警方联合出手！据央视新闻客户端消息，8月15日至16日，中国公安部、泰国警察总署、缅甸警察总部、老挝公安部在泰国清迈联合举行针对本区域赌诈及衍生的人口贩运、绑架、非法拘禁等犯罪的专项合作打击行动启动会。各方决定，在泰国清迈共同建立专项行动综合协调中心，并针对赌诈猖獗的区域设立联合行动点，以更紧密的合作、更主动的攻势、更专业的行动，严厉打击本区域电信网络诈骗和网络赌博犯罪，坚决扭转人口贩运及绑架、拘禁等犯罪高发态势。各方表示，将用实际行动向那些仍不收手的赌诈犯罪集团发出严厉警告，向国内外展示中泰缅老四国警方团结合作、严打赌诈的坚定决心。4天内24人被押解回国据中国驻缅甸大使馆微信公众号26日消息，8月26日，又有5名电信诈骗犯罪嫌疑人在仰光国际机场由缅甸警方移交给中国警方工作组押解回国。至此，在四天时间内共24名电诈犯罪嫌疑人被押解回国。图源：8月26日中国驻缅甸大使馆微信公众号综合自：楚雄州南华县公安局、昆明反电信网络诈骗中心、玉溪市公安局反诈中心、昆明禄劝县公安局反诈中心、保山市公安局反诈中心、澎湃新闻、央视新闻客户端、中国驻缅甸大使馆微信公众号来源：中国新闻社举报/反馈
