，正文：奇瑞汽车官方消息，其中型SUV奇瑞瑞虎8冠军版和PHEV车型将于今晚正式上市，预计将与比亚迪宋Plus进行市场竞争。新车型主要在配置方面进行了调整，外观及内饰设计与现款车型基本保持一致。新车前脸采用大尺寸点阵式中网，前包围两侧配有多边形散热口，搭配横置LED日间行车灯，点亮效果十分出色。PHEV版车型的前脸加入了蓝色饰条进行点缀，这也是其与燃油版车型比较明显的区别。 新车前后侧翼子板略微突出车身，配合车门下方的镀铬装饰条，以及密条辐大尺寸轮圈，看起来运动感十足。尾部新增了一个尾翼，尾灯同样采用了贯穿式的设计。此外，新车还采用了双边共四出的排气设计，搭配下方的扩散器，让车辆的运动氛围进一步提升。车身尺寸方面，新车长宽高分别为4745/1860/1745mm，轴距为2710mm。 内饰方面，根据配置差异会搭载仿皮座椅、侧气囊、侧气帘、主驾电动6向座椅调节、双区自动空调、8扬声器品牌音响、全景天窗、多色氛围灯、540度全景影像、HUD抬头显示以及前排座椅加热等配置。瑞虎8 PRO冠军版车机还会采用高通骁龙8155芯片，操作流畅度也会有一定提升。 动力方面，瑞虎8 PRO冠军版预计会沿用现款1.6T和2.0T发动机。其中，1.6T涡轮增压发动机最大功率为197马力，最大扭矩为290牛·米。2.0T发动机最大功率为254马力，最大扭矩为390牛·米。插混版本或将搭载由1.5T发动机和电动机组成的插电式混动系统，其中发动机最大功率115kW，匹配双电机，系统综合功率240kW、综合扭矩545N·m。传动系统为奇瑞自研的3挡DTH变速箱，0-100km/h的加速为7.2秒。瑞虎8 PRO新能源自带对外放电功能，可化身为3.3kW大功率移动电站。奇瑞官方还暂未公布该车的其他信息，更多消息，我们将持续为您跟进。本文属于原创文章，如若转载，请注明来源：奇瑞瑞虎8冠军版今晚上市 配置升级https://news.zol.com.cn/828/8281272.html
