2023-07-25 17:00，正文：原标题：保康一女子被骗至宾馆洗脑51分钟，紧急时刻民警及时赶到极目新闻记者 周萍英通讯员 欧阳智慧 马锦秀“幸亏你们及时赶到，不然我卡里的3.34万元钱就转给骗子了！”7月25日，在湖北省保康县城关镇某宾馆客房，大梦初醒的葛女士对民警“闯”入房间果断拦截电信诈骗的行为表示感谢。民警在查看葛女士电话7月25日9时许，保康县公安局过渡湾派出所接到上级反诈中心预警指令，称所辖过渡湾镇梅花村1组居民葛女士，接到疑似冒充公检法诈骗分子的电话，系统预警其极有可能上当受骗，要求民警迅速找到事主并阻止其汇款。接到指令后，过渡湾派出所会同县局反诈中心民警快速对信息进行落地研判，得知葛女士已被诈骗分子骗进城关镇一宾馆。根据经验民警判断，葛女士电话一直处于通话中，极有可能被深度洗脑，并按骗子指令到宾馆开房，诱导其转账汇款。骗子指令葛女士操作情况紧急，民警丝毫不敢迟疑，立即驱车来到宾馆，及时敲门“闯”入房间。“我们是过渡湾派出所民警，你被骗了，电话给我……”“在给谁通话，打了51分钟。还好，还没来得及转账！”民警一边查看手机，一边再次表明身份，惊魂未定的葛女士这才回过神来。原来，一小时前葛女士接到一个自称某警官的电话，对方称其丈夫在外涉嫌洗钱已被公安机关逮捕，要求她到宾馆开房并保持通话，同时按要求下载某软件进行操作。就在准备进行下一步操作时，民警及时赶到，成功为葛女士止损3.34万元。（来源：极目新闻）返回搜狐，查看更多责任编辑：
