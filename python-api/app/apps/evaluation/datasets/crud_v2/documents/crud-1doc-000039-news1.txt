07-31 08:17，正文：7月7日，北京市住建委官方微信公众号“安居北京”发文称，北京市推3000余间保租房青年公寓助力大学生安居。考虑到中心城区、平原新城既有众多高校，毕业生数量多，又有大量重点功能区，就业聚集等因素，在这些区域开展保租房青年公寓项目有助于实现产城融合、职住平衡。各区和北京保障房中心有限公司积极筹备项目，结合本区实际编制工作方案，共筹集3000余套（间）青年公寓。截至目前，所有房源已装修完毕，并配备必要的家具家电以及宽带网络，毕业生可以拎包入住。为更好解决新市民、青年人特别是新毕业大学生的住房问题，北京市连续五年开展“毕业季租房服务进校园”活动，为毕业生群体提供减免押金、租金月付、法律咨询等服务；同时自去年起面向应届毕业大学生推出保租房青年公寓试点，为吸引青年人留京就业创业创造有力的服务保障。5月8日，丰台区率先发布2023年保租房青年公寓面向毕业大学生专项配租公告，万科泊寓草桥项目300间房源面向在丰台区行政区域内就业且无房的近三年毕业生租赁，6月3日已办理选房入住。6月底，大兴区、朝阳区也先后发布配租公告。7-8月，预计经开区、昌平、房山、通州、顺义将陆续启动配租。和去年首次试点的大多面向当年应届毕业大学生相比，今年所有配租房源全部或优先面向近三年毕业的大学生，北京保障房中心有限公司持有的燕保·平乐园家园项目还实现了常态化配租，北京市行政区域内就业或创业、在京无房、学历为全日制本科及以上、年龄不超过35周岁的青年均可申请，每月16日至19日登记。以上项目专项配租公告将在相关区政府和北京保障房中心有限公司官方网站发布，有需求的毕业生可及时关注并提交申请。目前朝阳区仍在登记期间内，7月10日17:00截止，经开区7月10日-7月16日申请登记。有登记意向的毕业生可自行登录北京保障房中心有限公司网站或APP，进入保障性租赁住房登记界面了解房源情况。来源：中国证券报·中证网 作者：徐杨温馨提示：最新动态随时看，请关注金投网APP。
