本报讯 近日，国网济南供电公司党员突击队队员来到石热入济长距离输送供热工程(济南段)3号中继泵站，开展上门走访，了解该项目送电后的用电情况，主动服务、问需献策。“我们项目能在这么短时间内送电，真是多亏了你们。石热入济项目贯通后，将为泉城人民提供充足的热源保障。”项目负责人杨浩琳说。石热入济长距离输送供热工程(济南段)是济南市今年的重点项目，项目管网长度183千米，跨越平阴县、长清区、市中区3个区县，沿途共设置中继泵站5座，供电容量13.48万千伏安，供电线路总长51.5千米。2月初，石热入济长距离输送供热工程(济南段)刚开工，济南供电公司便成立了由发展、营销、运检、调度等专业的党员骨干组成的党员突击队，为该项目提供收集办电资料、制订供电方案、推进业扩配套项目建设等全过程跟踪办电服务。3月，党员突击队队员在制订石热入济长距离输送供热工程(济南段)3号中继泵站供电接入方案时，发现距离该项目最近的110千伏长清变电站负荷过载，需要从距离该项目20千米远的220千伏文昌变电站接入。但因距离较远，且线路需跨越村庄、农田等，送电日期无法确定。对此，党员突击队队员多次研讨，最终决定将110千伏长清站接带的3条10千伏线路1.8万千瓦负荷调整至110千伏阜新变电站接带，为该项目3号中继泵站就近接入腾出负荷空间。“按照市委、市政府部署要求，我们这个项目需要在供暖季前全部完工，5座泵站的供电接入也要在10月底前完成送电，时间紧、任务重，还请你们多帮忙。”供电方案确定后，杨浩琳对党员突击队队员说。面对客户的紧急用电需求，党员突击队组建了工程推进微信工作群，倒排工期、挂图作战，制订了工程施工期间临时用电方案;组织召开12次协调推进会，解决通信通道受阻等问题16项。经过184天的连续奋战，最终于9月27日提前34天完成该项目5座泵站的送电工作。石热入济长距离输送供热工程(济南段)4号中继泵站是该项目的末端站，供电接入需跨越河道、高架桥、铁路等，施工难度较大。为确保工程顺利推进，党员突击队加强与济南热力集团、市自然资源和规划局、市住房城乡建设局等各方的沟通协调，及时解决供电项目施工过程中遇到的问题，细化驻点值守、风险防控等专项工作措施，为项目提前送电奠定了坚实基础。原标题：国网济南供电公司全过程服务保障供热项目用电值班主任：高原作者：戴升宝 通讯员 张治林 刘岚云责任编辑：鞠月芹
