2023-07-21 10:15，正文：                原标题：这事发生后，伊拉克驱逐瑞典大使并召回代办                            参考消息网7月21日报道据德国新闻电视频道网站7月20日报道，为了回应有人计划在瑞典焚烧《古兰经》，伊拉克驱逐了瑞典大使。伊拉克总理苏达尼要求瑞典驻该国大使“离开伊拉克领土”。与此同时，伊拉克外交部宣布，将召回本国驻瑞典大使馆临时代办。  法新社此前曾报道称，伊拉克总理办公室在推特上说：“伊拉克政府已通过外交渠道通知瑞典政府，任何再次发生在瑞典领土上的焚烧《古兰经》事件都可能导致两国断交。”伊拉克政府还表示，目前已暂停瑞典电信设备制造商爱立信在伊拉克的经营许可。  报道称，当地时间20日凌晨，在有人宣布要在瑞典焚烧《古兰经》而引发的紧张局势中——这并非首次——瑞典驻巴格达大使馆遭到了冲击。当天凌晨3点左右，数百名示威者聚集在瑞典驻巴格达大使馆前。抗议者翻越了使馆围墙，焚烧了部分建筑。瑞典谴责称，冲击大使馆的行为“完全不可接受”。  据报道，瑞典警方之前批准了于20日在伊拉克驻斯德哥尔摩大使馆前举行示威的申请。两名参与者计划焚烧一本《古兰经》和一面伊拉克国旗。其中一人是来自伊拉克的移民，6月就曾在斯德哥尔摩一座清真寺前焚烧《古兰经》。他说，自己之所以申请举行这场示威活动，是因为他想由此“表达对《古兰经》的看法”。  报道称，出于安全考虑，瑞典警方希望禁止这类示威活动，但迄今一直因法院反对而未果。法院认为，禁止这类示威是限制言论自由。多家新闻机构报道，20日在伊拉克驻斯德哥尔摩大使馆前举行的示威活动中，一本被示威者称为《古兰经》的书被踩踏，部分损毁，但没有被烧。（编译/王勍）返回搜狐，查看更多                        责任编辑：
