"原标题：2023广州艺术季开幕，54台、168场优秀剧目将上演南方网讯 记者获悉，2023年广州艺术季将于6月至10月惊艳亮相。活动共设置“红色经典”“锦绣华章”“名家名团”“湾区荟萃”四个主题板块，演出54余台优秀剧目共168场次，类型涵盖歌剧、话剧、舞剧、音乐会、杂技、粤剧、音乐剧等。本届艺术季以《“红色随想”交响管乐音乐会》开幕，杂技剧《天鹅》闭幕。本次活动由中共广州市委宣传部、广州市文化广电旅游局主办，中国对外文化集团有限公司协办，中演演出院线发展有限责任公司承办，广州大剧院执行，围绕“高歌逐梦，跃舞潮头”活动主题，展演一批国内外有筋骨、有道德、有温度的优秀文艺作品。近年来，广州市着眼持续推广普及传统艺术，每年举办一期艺术季活动，集中推出一大批涵盖所有戏剧种类的国内外优秀文艺作品。2023广州艺术季展演作品，用情讲好中国故事、彰显中国审美志趣、传播当代中国价值观念，为广大市民朋友上演一批反映时代新气象、讴歌人民新创造的精品力作。其中，有芭蕾舞剧《白蛇传》，“舞坛双子星”韩真、周莉亚共同编导的最新力作《咏春》，由毓钺编剧、杨立新导演并主演的话剧《钟馗嫁妹》，还有上海歌剧院舞剧团舞剧《嫦娥》、著名京剧表演艺术家于魁智和李胜素领衔主演的《龙凤呈祥》和《穆桂英挂帅》、著名越剧表演艺术家方亚芬和章瑞虹领衔主演的《梁山伯与祝英台》和《红楼梦》、杨丽萍亲自参演的舞剧《孔雀》、改编自梁晓声同名小说的话剧《人世间》、广州粤剧院最新作品《隆平稻香园》等弘扬中国精神、传播中国价值、凝聚中国力量的精品力作。尹袁版《红楼梦》剧照芭蕾舞剧《白蛇传》海报自今年一季度以来，中外舞台艺术交流再度活跃，本届艺术季也将引进一批国外优秀文艺成果，积极对话世界，展现人类文明多样之美。美国玛莎·葛兰姆舞团中国巡演将带来《阿巴拉契亚之春》《即时的悲剧》《无辜的喜剧演员的颂歌》；世界上唯一一个能在冰上演绎古典芭蕾舞全剧的演出团体——俄罗斯圣彼德堡国家冰上芭蕾舞剧团将带来《天鹅湖》；富有传奇色彩的塞尔维亚钢琴家伊沃·波格莱里奇也将带着多部肖邦名作让中国乐迷一饱耳福；俄罗斯“国宝级”指挥大师弗拉基米尔·费多谢耶夫携柴可夫斯基交响乐团再次来华巡演。除此之外，还有一批小而精的国外优秀舞台剧目，例如由墨西哥默剧艺术家加布瑞艾拉·穆尼奥斯自导自演的独角默剧《也许，也许，也许》、由西班牙b vocal奇妙人声组带来的阿卡贝拉音乐会、Chaiti印度传统音乐会、比利时今日巴洛克古乐团音乐会等。俄罗斯冰上芭蕾天鹅湖本届艺术季精选了一批内容形式丰富、风格手法多样、引领社会风尚的优秀作品。被誉为一生必看的“教科书”级音乐剧《剧院魅影》将迎来它的第18个语言版本——中文版，中外顶级制作团队为品质保驾护航，保障与世界版本齐平的作品呈现与视听体验；由上海话剧艺术中心出品、何念导演的悬疑舞台剧《心迷宫》延续了“姐妹篇”《深渊》的高人气和好口碑，以扎实剧本、震撼舞美、动人情感迅速在热爱戏剧的年轻人群中风靡；话剧《你好，疯子！》将排演十周年纪念版，饶晓志导演力邀到万茜加盟，她在同名电影中让人头皮发麻的炸裂表演将在舞台再现。还有由音乐剧《哈姆雷特》、东野圭吾同名小说改编的舞台剧《虚像的道化师》、沉浸式独幕喜歌剧《苹果之夜（Pomme d’Api）》等引发热议的新作。本届艺术季还将举办一系列线上、线下的讲座、工作坊、展览等艺术活动，为广州市民送上丰盛的艺术大餐。其中，“戏剧嘉年华”作为广州艺术季的亮点环节之一，将在广州永庆坊、粤剧艺术博物馆进行两天快闪演出活动，邀请国内十个演出团队，以街区为舞台，串连起东西方向的故事，进行非传统形式戏剧演出，探索空间，对话青年，让市民能在户外公共空间中感受体验到艺术和文化氛围。图片由广州大剧院提供返回搜狐，查看更多责任编辑：",
