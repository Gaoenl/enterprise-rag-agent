2023-08-09 09:58，正文：原标题：水发集团积极投身平原公司灾后抢修工作并向平原县政府捐赠救震物资上证报中国证券网讯 8月8日，水发集团党委委员、副总经理王东凯率水发派思燃气、水发燃气有关负责人奔赴平原县政府捐赠救震物资，助力该县抗震救灾，并督导平原新星燃气有限公司灾后抢修恢复和群众生活保障工作。王东凯一行到达平原县后，第一时间与县地震救援指挥部主要领导会面并向平原县政府捐赠物资。王东凯表示，水发集团作为省属国企，将继续加大对当地政府的配合力度，快速响应，全力以赴支持灾区尽快恢复生产生活秩序。随后，王东凯一行来到平原新星燃气有限公司实地查看了震后受损情况，对公司干部职工进行了亲切慰问，对公司生产设备设施、管道、燃气管理系统等进行了现场检查，展开了现场调研会。王东凯在会上强调，要做好余震应对措施，全面排查安全隐患，全面落实企业安全生产主体责任，加强现场安全管理；要全力配合当地政府开展震后各项处置工作，以“严真细快实”的工作作风进行深入排查整治工作，全面排除地震对设施设备造成的安全隐患，为当地安全形势稳定贡献国企担当。8月6日，平原县发生5.5级地震，全县多地均不同程度受灾。在灾情发生当天，平原新星燃气第一时间紧急联动各部门进行全方位抢险排险，在7日下午5点即恢复供气。作为平原县最早恢复供气的公司，平原新星燃气展现了过硬的设施水平以及国有企业管理规范、扎实的技术水准，保住了基础民生供应，扛起了国企担当，擦亮了水发品牌，赢得了全县上下各领域的一致好评。（陈志强）返回搜狐，查看更多责任编辑：
