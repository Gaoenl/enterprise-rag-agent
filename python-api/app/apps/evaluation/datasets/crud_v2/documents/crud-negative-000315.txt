11月26日至28日,应急管理部危险化学品重大危险源企业专项督导核查第九组在程柏松副组长带领下,到珠海进行督导检查,广东省应急管理厅危化处蔡汉悦副处长、珠海市应急管理局马桂民副局长及珠海消防救援支队等有关负责同志全程陪同检查。11月26日下午至27日,督查组一行先后来到万华化学(广东)有限公司、珠海宏昌电子材料有限公司、珠海裕珑石化有限公司等开展危险化学品重大危险源企业2021年第二次安全专项部级督导核查;11月28日上午到珠海万通化工有限公司开展化学品储罐区安全风险评估整治工作部级督导核查。督查组通过实地检查、查阅资料、听取企业汇报等形式,对企业安全基础管理、重大危险源管理、储罐区物质固有危险性、安全隐患排查整治、消防设备设施运行等进行了认真检查。本次督查适逢周末,金湾区应急管理局和被检企业的主要负责人等放弃周末休息时间,坚守岗位,认真做好迎检工作。督查组要求,要以极端负责的态度抓好安全生产,不断强化防范化解重大安全风险的政治责任,深入开展化工、危险化学品企业的安全整治,全面排查治理各类重大风险隐患,有效防范和坚决遏制重特大事故。市应急管理局马桂民副局长要求企业落实好企业主体责任,对检查中发现的问题,能立即整改的必须立即整改,不能立即整改到位的,要明确责任、明确时限,落实防范措施,进一步夯实危化企业重大危险源安全生产和消防安全责任;要深挖隐患问题根源,查深查透、举一反三,以认真负责的态度抓好安全生产,切实加强安全监管,提升企业安全管理水平,持续保持我市危险化学品安全监管形势稳定。编辑:珠海应急管理
