2023-07-27 23:20，正文：极目新闻记者 赵贝通讯员 仁宣7月25日至27日，湖北省十四届人大常委会第四次会议在武汉召开，会议期间，湖北省人民检察院报告了2023年上半年工作情况（以下简称报告）。报告显示，今年上半年，湖北省人民检察院共办理各类案件12.4万件，其中涉“流域综合治理”案件4390件。会议现场报告指出，湖北省人民检察院统筹发展和安全，以能动检察服务湖北先行区建设，积极服务流域综合治理，促进优化法治化营商环境，全力维护社会安全稳定。主动对接《湖北省流域综合治理和统筹发展规划纲要》，部署开展“助力流域综合治理”专项检察工作，共办理相关案件4390件；扎实开展长江流域非法捕捞和非法采砂等专项整治行动，受理审查起诉2266人；持续深化长江流域生态保护公益诉讼专项行动，立办公益诉讼案件2114件，督促清理被污染流域面积781.4亩、清理固废3.4万吨。优化法治化营商环境方面，湖北省人民检察院深化开展“促进优化营商环境”专项检察活动，共办理相关案件4935件。强化市场主体司法保护，受理审查合同诈骗、职务侵占等侵害市场主体合法权益犯罪案件1291件；办理涉市场主体民事执行活动监督案件369件，涉案金额3.7亿余元。办理涉案企业合规案件125件，办理涉知识产权案件137件。维护社会安全稳定方面，湖北省人民检察院坚持总体国家安全观，批捕各类刑事犯罪嫌疑人14293人、起诉24189人。常态化开展扫黑除恶，坚持“不拔高、不放过”，依法起诉涉黑恶犯罪99人，从严追诉严重暴力犯罪922人，依法起诉“黄赌毒”犯罪3531人。加强网络新型犯罪全链条打击，依法起诉电信网络诈骗、帮信、网络赌博等犯罪1774人。积极防范化解金融风险，依法起诉非法集资、非法吸收公众存款、洗钱等犯罪333人。（图片由通讯员提供）
