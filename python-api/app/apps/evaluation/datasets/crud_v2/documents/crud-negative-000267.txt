2023-07-25，正文： 新华社布宜诺斯艾利斯7月23日电（记者王钟毅）阿根廷大学生体育联合会主席埃米利亚诺·奥赫亚日前表示，期待即将举行的成都第31届世界大学生夏季运动会为世界带来惊喜。 奥赫亚接受新华社记者采访时表示，相信本届大运会将是令人难忘的一届，因为中国是世界上办赛水平最高的国家之一，拥有高品质的体育场馆和基础设施以及热情专业的赛事志愿者，此外赛事的开闭幕式也令人印象深刻。 奥赫亚说，期待阿根廷运动健儿在本届大运会上取得优异成绩，同时也希望他们能在大运会赛场上学习和体验不同的文化。 阿根廷大学生男子篮球队队长阿古斯丁·马雷罗告诉记者，他和队员们都很期待前往中国参加大运会比赛。“我们抵达后还有几天时间来训练和调整，我们希望能以最好的状态迎接比赛。” 当天，阿根廷大体联在布宜诺斯艾利斯埃塞萨国际机场举行成都大运会阿根廷代表团出征仪式，57名阿根廷大学生运动员启程前往成都，将参加篮球、排球、艺术体操、柔道等项目的比赛。 《光明日报》（2023年07月25日 11版） 					                                                                                    	[                      	责编：王宏泽 ]
