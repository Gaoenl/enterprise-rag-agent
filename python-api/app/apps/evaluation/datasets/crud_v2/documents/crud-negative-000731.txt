2023-07-30，正文：                         新华社成都7月29日电（记者周勉、曹奕博）成都大运会男子篮球预赛29日开打，位于A组的中国队出师不利，首战面对巴西队以79:89告负。中国队首发阵容由来自广东工业大学的陈国豪和来自清华大学的王岚嵚领衔。第一节刚开始，巴西队连得5分，中国队进入状态较晚，比赛前4分钟仅得2分。全场观众“雄起”的助威声显然感染了中国队队员，在经过反复交换球权，投入第二个两分球后，中国队又投进一记三分球。首节最后1秒，中国队投进一记压哨三分，将比分追至17:20。比赛在第二节一开始就进入高潮。先是陈国豪完成一记精彩的空中接力，随后黎伊扬连续两次带球突破后助攻，帮助中国队以29:28反超比分。第二节后半段，王岚嵚还连续投中两记三分球，帮助中国队以43:40领先结束上半场。第三节比赛开始后，中国队接连几次进攻受阻，巴西队则在加强防守的基础上提高了进攻效率，并在第三节结束时以62:59再次取得领先。第四节一上来，巴西队又打出一波小高潮，并利用中国队的急躁犯规多次罚球得分。失去节奏的中国队最终以79:89负于巴西队。“我们这批球员的国际比赛经验太少了，在一起打球的时间也短。”赛后，中国队主教练陈磊表示，巴西队今天的防守强度比较大，导致中国队队员很不适应，教练组将在赛后从细节开始总结。
