世界银行发布的《全球商品展望》指出，2023年全球大米价格较去年同期平均上涨28%，预计2024年将继续上涨6%，并且全球大米价格在2025年前不会大幅降温。联合国粮食及农业组织发布的数据显示，今年7月，国际米价升至近12年以来最高水平。 《全球商品展望》分析称，此次大米价格提高，主要原因包括极端天气厄尔尼诺的威胁，全球重要大米出口国的政策调整，以及大米生产、出口的地理与市场过于集中。自今年7月以来，受粮价影响，多国陆续宣布大米的出口禁令。当地时间7月20日，印度政府首先宣布将禁止除蒸谷米和香米外的大米出口，这项禁令预计覆盖印度大米出口的75%-80%。随后阿联酋政府宣布将暂停大米出口四个月。7月29日俄罗斯决定临时禁止大米出口至2023年底。中央财经大学经济学院教授于爱芝在接受农视网采访时分析表示，各个国家采取贸易限制措施，主要在于前几年疫情冲击导致供应链不稳定，以及俄乌冲突导致的粮食运输通道不畅等方面的影响。预期的不明朗为投机带来了空间，导致粮食价格的波动，进而导致一些国家考虑通过限制粮食出口来保障国内粮食安全。同时教授表示：“整体上讲，供求形势从供给端来说并没有出现很明显的总量下降。” 亚洲受此轮全球米价风暴影响严重。亚洲基准米价以过去两周内上涨57美元的速度，于11月30日攀升至640美元/吨的价格，逼近2008年10月以来的最高水平。在此轮大米暴涨的环境下，印度与泰国的表现值得关注。印度是全球大米第一出口国，今年受厄尔尼诺现象威胁出现减产，印度政府对大米出口表现得非常谨慎。今年8月，印度政府决定对蒸谷米征收20%的出口关税，10月又将其延长至明年3月。同时，已经实施了一段时间的大米出口限令，短时间内也没有迹象表明会立即取消。同为头部大米出口国的泰国，今年最高米价呈12000泰铢/吨，超过此前平均米价8000-9000泰铢/吨，同比增长超过50%。泰国大米出口商协会名誉主席Chookiat Ophaswongse表示，由于巴西、菲律宾等买家对泰国大米的购买意愿增强，泰国大米出口强劲，以及泰铢升值，导致泰国国内大米价格涨幅明显，创下17年来的最高水平。亚洲其他一些国家也出现了米价上涨的情况。例如上周越南破碎率为5%大米价格涨至655-665美元/吨，而前一周价格大约为650-655美元/吨。稻米作物产出良好且库存充足的孟加拉国在上周米价也呈上涨趋势。但国内市场而言，大米价格总体平稳。今年3月以来，国际米价持续走高，我国米价4月出现小幅下跌后，小幅上涨。据中商情报网数据，9月，早籼米批发价约1.99元/斤，环比上涨0.5%，同比上涨2.6%；晚籼米2.03元/斤，环比上涨0.5%，同比上涨0.5%；粳米每斤2.12元，环比上涨1.0%，同比上涨3.9%。较国际自3月开始的大幅度提升，我国米价涨势不明显。数据来源：中商情报网究其原因，我国大米进口总量不大且来源相对集中度不高。根据国家统计局官网信息数据显示，2023年我国大米总产量2833.7万吨（566.7亿斤），而海关数据显示，1-10月期间，我国稻米累计进口量225万吨，大米进口量和我国国内产量相比较小。界面新闻曾报道今年粮食生产克服局部灾害影响，产量有望再创历史新高，连续9年保持在1.3万亿斤以上，其中，中晚稻的质量好于常年，市场粮源供应充足。而国家统计局信息数据也显示，2023年我国大米总产量达2833.7万吨，同比增长0.8%，市场供应角度波动小。此外，我国大米进口来源相对分散，其中越南进口89.6万吨，占比39.9%；缅甸进口46万吨，占比20.5%；泰国进口32万吨，占比14.2%；印度进口24万吨，占比10.7%左右。我国受单一国家大米出口变化影响小。 但根据我的钢铁网分析，目前大米市场存在供强需弱的情况。今年稻谷新作总体质量较上一年明显提高，受此支撑，新作上市以来价格高企。但终端需求不畅，下游需求疲软，业者采购积极性放缓，短时供应压力或依旧较大。综合来看，市场供强需弱格局日益凸显，稻米市场后期供应压力难有缓解。举报/反馈
