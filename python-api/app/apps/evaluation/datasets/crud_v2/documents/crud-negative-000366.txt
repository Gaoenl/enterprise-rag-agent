2023-07-26 13:50，正文：原标题：折纸、手势舞等特色课程​！庆云县暑期托管 “托”起多彩假期齐鲁晚报·齐鲁壹点通讯员 邱文英 记者 孙文丽“青鸟计划”工作推进以来，共青团庆云县委积极对接省内外高校，畅通校地合作渠道，进一步凝聚青年力量，助力留守儿童关爱，带动志愿服务下基层。暑假期间，在中丁乡中丁村，前来支教的大学生志愿者正在辅导孩子们学习，丰富的课堂内容和绘声绘色的讲解让孩子们沉浸其中。中丁乡中丁村学生丁伟志说：“我最喜欢的是语文课，老师会给我们拓展一些课外的知识，开阔了我们的视野。老师们在下课的时候还会陪我们做游戏，既好玩又能学到知识。”大学生志愿者们在孩子们原有课程的基础上结合自身特长，开设了折纸、手势舞、传统文化、文字演变等特色课程，在激发孩子们兴趣的同时提升了他们的学习动力。山东政法学院微光公益组织微光引航队队长王子心说：“我个人非常喜欢小孩子，喜欢和孩子们相处，他们天真的眼神以及他们的纯真与善良都让我觉得十分幸福。我觉得跟孩子们相处是一种双向治愈的过程，我们在帮助孩子们的同时，孩子们也给我很多温暖、很多关心。”本次12名志愿者老师全部来自山东政法学院微光公益组织，他们将为这里的孩子们开展为期半个月的暑期托管服务，为他们提供内容丰富的教育实践课程和活动，培养孩子们良好的学习习惯，让孩子们度过一个安全、愉快的暑期。“为引导青年学生在社会实践中‘受教育、长才干、作贡献’，助力乡村振兴及乡村教育发展，共青团庆云县委点对点与高校团委建立密切联系，引导鼓励山东科技大学、山东政法学院、青岛农业大学等高校大学生到基层开展‘三下乡’社会实践活动。通过暑益课堂、暑期托管等活动形式，不仅改善基层教育短板问题，同时也让高校大学生们能够了解基层生活、参与社会实践、展现个人价值。团县委也将继续做好‘枢纽’工作，不断深化校地合作共建，为乡村振兴和经济社会发展提供坚强的人才保障。”共青团庆云县委副书记冯欣说道。返回搜狐，查看更多责任编辑：
