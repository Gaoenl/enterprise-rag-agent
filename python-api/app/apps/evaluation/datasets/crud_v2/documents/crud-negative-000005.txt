【环球时报-环球网报道 赴广州特派记者 郭媛丹】12日，工业和信息化部发布消息显示，2023年上半年我国造船业三大指标均位居世界第一，新接订单量的国际市场份额超过了70%，实现了我国造船业国际市场新接订单量的新纪录。《环球时报》记者在广船国际造船厂区内见证了中国造船业的蓬勃发展，在三到五年内广船国际的订单十分“饱满”。工业和信息化部发布消息显示，2023年上半年，我国造船业完工量2113.1万载重吨，同比增长14.2%；新接订单量3766.9万载重吨，同比增长67.7%；手持订单量12377万载重吨，同比增长20.5%，三大指标均位居世界第一。中国船舶工业行业协会秘书长李彦庆表示，中国是唯一一个三大指标实现全面增长的国家，实际上证明了我们中国船舶工业已经实现了一种良性的发展态势。权。李彦庆对此评价说，这在历史上是第一次，上半年的数据从侧面反映我们全面超越的一个形式，创造了历史上最好的成绩，是已经吹响了中国船舶工业全面提升、进入到领先的冲锋号。当天上午，《环球时报》记者在中国船舶集团旗下广船国际造船厂区内见证了中国造船业蓬勃发展的态势。厂区内船坞和码头呈现出一片繁忙的生产景象，“今年上半年实现了工业产值和利润‘双过半’，上半年经营接单同比增长90%，造船订单承接已经排至2026年。”广船国际党委副书记张庆环介绍说。中国造船业的良性发展态势不仅仅体现在“量”上，更体现在“质”上。比如广船国际始终把科技创新放在最重要位置，着重在高技术、高附加值船型发力，先后攻克了世界首艘极地重载甲板运输船、液化天然气（LNG）双燃料豪华客滚船等高技术、高附加值船舶的研制任务，多次填补相关领域技术空白，形成了国际领先优势。广船国际副总经理周旭辉介绍 “目前广船国际手持造船订单70余艘，价值超过500亿元，其中有近40艘、价值200亿元的船舶订单为高技术、高附加值的甲醇双燃料或LNG双燃料新型绿色船型。”此外，据介绍，广船国际上半年共承接生效了20艘船舶订单，高技术、高附加值产品占比约94%，其中以LNG双燃料汽车运输船、LNG双燃料和甲醇双燃料油轮船型为主。当天上午，在南沙邮轮母港，记者参观了广船国际为“一带一路”沿线国家意大利建造的全球最大豪华客滚船——2500客/3800米车道Moby豪华客滚船2号船。根据该型船项目经理曹继飞的介绍，这型船超过70000总吨，共建造2艘，其中1号船已经交付船东。“这艘船上层建筑面积约为2万平方米，其中供游客使用的各类餐厅和娱乐场所面积达到约10000平方米，内装媲美豪华邮轮，相当于一座漂浮在海上的‘五星级酒店’”曹继飞对《环球时报》记者表示，该型船也已经达到交付标准，同类型的豪华客滚船目前有6条在建，预计2023年、2024年、2025年各交付2艘。“我们这型船的建造速度极大提高，船舶建造的码头周期从12多个月压减到7个月，并且内装材料实现了100%国产化，也因此带动了一系列企业的发展，成为产业链的‘链长’”。周旭辉表示，上述豪华客滚船的1号船，已投入到地中海沿岸的意大利热那亚、奥尔比亚以及里窝那之间的航线运营。“船东在运营一段时间后向我们反馈，该型船航速更快，载客量更大，并且油耗大幅降低。”船东的评价是对中国造船业最好的宣传和推广。根据介绍，欧洲国家对豪华客滚船的需求量很大，最近国外超20年船龄有约200余艘客滚船，近10年会有持续的更新换代需求，“其中，中国可以占到70%-80%的市场份额。”曹继飞表示，“价格优势，建造周期快以及性能足够好，这些都是中国在该领域拔得头筹的因素。而且与此前话语权掌握在船东手中不同，比如在内部装修以前材料都需要国外进口，但随着我们设计能力的不断增强，在材料，色彩等选择上，我们话语权越来越强，掌握了话语权，也就实现了供应链的控制，带动产业链的发展。”周旭辉表示，从2020年开始，广船国际创造了豪华客滚船交付纪录和在手订单世界第一，半潜船交付数量世界第一，破冰船和冰区运输船交付数量中国第一，汽车运输船（PCTC）手持订单数量世界第一，MR、LR油轮交付数量中国第一的纪录。工信部的消息显示，今年上半年，我国新接订单量更是占国际市场份额的72.6%，这意味着中国造船业正逐渐在全球市场中掌握主动权。李彦庆对此评价说，这在历史上是第一次，上半年的数据从侧面反映我们全面超越的一个形式，创造了历史上最好的成绩，是已经吹响了中国船舶工业全面提升、进入到领先的冲锋号。举报/反馈
