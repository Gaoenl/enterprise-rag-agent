2023-07-30 17:31，正文：原标题：多个国家宣布禁止大米出口 最不发达国家面临粮食安全考验受粮食价格影响，近期全球多个国家宣布禁止大米出口。据俄罗斯媒体当地时间7月29日报道，俄罗斯政府决定临时禁止大米出口至2023年12月31日。“今日俄罗斯”电视台网站报道截图此前一天，阿联酋经济部宣布，即日起阿联酋将暂停大米出口4个月。据阿联酋当地媒体报道，此举旨在确保当地市场有充足的大米供应。当地时间20日，印度政府已经宣布，为保障国内市场供应，印度将禁止除蒸谷米和印度香米外的大米出口，即日生效。印度消费者事务、食品和公共分配部当天发布公告说，强季风降雨对农作物造成严重损害，在大米零售价格一个月内上涨3%后，政府决定实施限制大米出口的措施。印度是世界重要的大米出口国，2022年印度大米出口总量约2200万吨，占世界大米出口量40%以上，受本次出口禁令影响的大米出口量约1000万吨。受今年厄尔尼诺现象影响，联合国粮食及农业组织7月初发布的大米价格指数显示，全球大米价格一直维持在11年来高点附近。印度大米出口商协会主席克里希纳·拉奥指出，贝宁、塞内加尔、科特迪瓦等非洲国家受印度大米出口限制影响尤为严重。《巴伦周刊》报道截图中国社科院农村发展研究所研究员胡冰川在接受中央广播电视总台环球资讯广播记者采访时说，俄罗斯等国宣布大米禁止出口或者是限制出口的措施，主要是出于保障国内的需要。这种措施对全球大米市场和价格的影响，需要理性看待。胡冰川进一步分析称，大米出口量的减少推高了大米进口国的进口成本、增加了限制大米出口国的贸易伙伴国的贸易成本，这对发展中国家、尤其是最不发达国家的粮食安全是非常不利的。《经济学人》报道截图返回搜狐，查看更多责任编辑：
