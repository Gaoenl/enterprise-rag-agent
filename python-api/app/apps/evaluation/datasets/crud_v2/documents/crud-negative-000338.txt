"近日，国务院常务会议审议通过《关于在超大特大城市积极稳步推进城中村改造的指导意见》。其中提出，要加大对城中村改造的政策支持，积极创新改造模式，努力发展各种新业态，实现可持续运营。业内人士表示，在超大特大城市进行城中村改造，有利于增加优质租赁房源供给，改善城中村内居民居住条件，提升整体市容市貌。全国城中村改造市场有望重回万亿元规模。城中村改造市场规模将达万亿元会议明确要求，要对隐患较多的城中村进行改造，成熟一个推进一个；同时要加强组织实施，科学编制改造规划计划，坚持多个渠道筹措改造资金，高效综合利用土地资源，把城中村改造和保障性住房建设结合好。根据第七次全国人口普查数据显示，我国超大城市包括北京、上海、深圳等7个城市，特大城市包括东莞、杭州、南京等14个城市。国金证券在研报中指出，2019至2022年，全国城中村改造的市场规模分别为1.40万亿元、1.24万亿元、1.36万亿元、6559亿元。在一线城市中，广州今年计划推进127个城中村改造项目，力争完成2000亿元城市更新固定资产投资目标，同比增长60%。上海计划在2023年至2025年新启动30个城中村改造项目，每年10个，面积不少于400万平方米。民生证券表示，目前已有11个城市公布了“十四五”规划期间投资规模将达4.4万亿元。按照这个节奏来测算，预计2023年至2025年，21个特大超大城市每年城中村改造投资规模或在万亿元。政策持续加码，为房地产市场注入信心事实上，城中村改造的政策脉络，最早可以追溯到2020年。2020年，“十四五”规划首次提出城市更新行动；2023年4月，政治局会议提出在超大特大城市积极推进城中村改造；而近日召开的国常会则对超大特大城市的城中村改造工作进行了细化。与往年棚户区改造相比，此次城中村改造政策有三点不同之处。一是住建部此前曾提出，在城市更新行动中，要以保留利用提升为主，加强修缮改造，而不是拆除重建；二是当下政策涉及21座城市城中村改造，而不是撬动三四线新增地产需求；三是此次改造的资金来源是政府资金与民间资本共振，而之前棚改则主要依赖于政策性金融工具。需要说明的是，城中村改造并不意味着总量投资大规模扩张，当下时点的政策更多强调的是大中城市城中村改造，政策尝试给房地产市场注入信心。目前，超大特大城市都在斥资改善公共基础设施、改造城中村和老旧小区。在政策的支持下，城市硬件条件改善有望进一步吸引人口、资源和生产要素向其流入，未来各个城市之间的房地产发展分化或将进一步加剧。相关上市公司有望受益民生证券在研报中指出，在城中村改造项目持续推进的过程中，与旧城改造相关的规划设计、新型城镇化、装修建材等板块或将迎来投资机会。此外，部分拥有专业资质、技术实力过硬的上市公司有望受益。山水比德（300844.SZ）是一家集投资、研发、规划、设计、建设及运营为一体的全产业链式服务运营商，拥有风景园林甲级资质。公司通过灵活多变的合作模式，为全国各地政府及地产、商业、文旅开发商，在社区环境、城市设计、区域规划等领域，提供全过程的高品质系统服务。杭州园林（300649.SZ）是A股资本市场首家以园林设计为主营业务的上市公司，杭州园林(300649)设计院是全国首批甲级园林设计院，具有风景园林和建筑设计双甲级、城市规划甲级、市政行业专业乙级等多项资质。该公司的专业实力突出，在业内享有较高的行业地位和影响力。东方园林（002310.SZ）专注于生态修复与环境治理领域，深耕生态治理、环保业务及循环经济三大板块，依托景观绿化、河道治理、生态修复等业务，整合规划、设计、工程、运营等优势，提供领先的全产业链服务。从盘面上来看，截至7月24日中午收盘，新型城镇化板块涨幅居前。个股方面，山水比德收获20CM涨停，深圳瑞捷（300977.SZ）、宏景科技（301396.SZ）涨超10%，苏州规划（301505.SZ）涨8.36%，东方园林(002310)涨7.49%。（责任编辑：董萍萍 ）",
