[2023/08/13  10:02]，正文：         8月11日晚，第十六西普会——全称“健康产业（国际）生态大会”之“西普金奖”年度榜单在中国海南博鳌正式发布，太极藿香正气口服液、急支糖浆凭借出色表现荣膺2023年健康产业·品牌榜，获颁行业最高荣誉“西普金奖”。该奖项作为西普会重磅产业活动之一，因其较高的评选标准，成为备受行业瞩目的权威榜单，被业界誉为“产业奥斯卡奖”。  2023西普会活动丰富，开设有20多场卫星论坛会，权威发布了系列行业奖项，同时推出“2030中国健康产业全景预测”“中国药品零售业态升级与分化”等多份行业独家重磅报告，集结行业智慧、传递行业信息、总结行业发展、探寻行业方向，多维度剖析行业的机遇与挑战。 在本届西普会上，国药太极凭借优秀品牌影响力及产品实力，还荣获以下殊荣：  ▲国药太极党委书记、总经理俞敏先生荣膺本届“时代人物” 国药太极旗下重庆桐君阁大药房连锁有限责任公司、四川太极大药房连锁有限公司荣获“2023年药品零售城市群竞争力十强”称号。  ▲桐君阁大药房总经理聂志阳 近年来，国药太极在混改突围后，不断深化改革，推进战略转型，聚焦主业、聚焦主品。藿香正气口服液、急支糖浆等主要产品均实现超常规持续增长。未来国药太极将继续秉承战略引领、数据驱动，努力推进三年打造一个数字化太极的目标，为成为世界一流中药企业打下坚实基石。  ▲国药太极营管中心消化及代谢产品群副总经理苏中波先生 上游新闻记者 刘勇 实习生 张荣 编辑：周钰蝉 责编：彭光瑞 审核：罗军         （责任编辑：蔡情）
