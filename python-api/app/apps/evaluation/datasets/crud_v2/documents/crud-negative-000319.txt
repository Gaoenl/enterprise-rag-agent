2023-07-29 16:45，正文：原标题：日本紧盯中俄舰艇编队最新动向参考消息网7月29日报道据俄罗斯卫星社网站7月29日报道，日本防卫省统合幕僚监部7月29日发布消息称，中国和俄罗斯两国海军共10艘舰艇28日至29日穿过宗谷海峡，驶入鄂霍次克海。期间，日本自卫队派出两艘军舰和一架P-3C海上巡逻机进行警戒监视和情报收集。报道称，俄罗斯太平洋舰队信息保障处28日发布消息称，俄罗斯海军和中国海军舰艇已经开始在太平洋海域执行第三次海上联合巡航任务。在俄罗斯海军和中国海军舰艇离开符拉迪沃斯托克后，在彼得大帝湾海域组建了一支联合编队，该编队已开始沿着双方先前商定的路线前进。另据共同社7月29日报道，日本防卫省统合幕僚监部29日发布消息称，中国和俄罗斯两国共10艘海军舰艇28日至29日穿过北海道与萨哈林之间的宗谷海峡，从日本海驶入鄂霍次克海，其中9艘于18日至23日在日本海实施了射击等联合训练。报道称，中俄两国此前已发布海军舰艇编队将在太平洋实施海上联合巡航的消息。日本防卫省称此次航行或是相关行动，正在关注今后的动向。防卫省称，28日下午3点前后，10艘舰艇在距离北海道礼文岛西南约200公里的海域航行，此后北上并朝东穿过宗谷海峡。报道称，10艘舰艇为中俄各5艘，中国派出的是导弹驱逐舰、护卫舰及补给舰，俄罗斯派出的是驱逐舰、护卫舰及补给舰。实施联合训练的是其中的9艘，另一艘是俄罗斯的补给舰。返回搜狐，查看更多责任编辑：
