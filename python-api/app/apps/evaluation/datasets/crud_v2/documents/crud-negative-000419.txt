12月9日,广东省高级人民法院和世界知识产权组织仲裁与调解中心签署《加强知识产权领域替代性争议解决交流与合作协议》。世界知识产权组织总干事邓鸿森出席活动,最高人民法院副院长陶凯元,世界知识产权组织副总干事王彬颖,广东省委常委、政法委书记袁古洁出席活动并致辞。广东高院院长张海波和世界知识产权组织仲裁与调解中心主任伊格纳西奥·德·卡斯特罗签署协议。当天,广东高院移交了首批6件委托调解案件。据介绍,协议的签署将进一步加强双方在知识产权纠纷处理方面的交流与合作,包括双方委派或委托调解、加强人才培养、开展公共宣传等内容。陶凯元在致辞中指出,本次签约活动,是落实最高人民法院张军院长与世界知识产权组织邓鸿森总干事在今年4月签署的加强交流与合作谅解备忘录的重要举措之一。中国是世界知识产权组织第90个成员国,近年来,中国的知识产权司法保护工作发生了深刻变革,取得了长足进步。目前,中国已成为审理知识产权案件最多的国家,跨进审理周期最短的国家行列。广东,地处改革开放前沿,是中国知识产权案件量最大的省份,也是涉外涉港澳知识产权案件数量最多的省份。希望中国法院与世界知识产权组织进一步深化沟通互信、合作互利,共同推动全球知识产权治理体系向着更加公正合理方向发展。王彬颖表示,欢迎双方在替代性争议解决领域开展更深入的交流与合作。世界知识产权组织作为联合国负责知识产权发展和保护的专门机构,致力于引导发展一个兼顾各方利益的有效全球知识产权生态系统,以促进创新创造,使未来更加美好,更可持续。广东是中国最早实行对外开放的省份之一,也是中国创新产业的聚集地。协议的签署,标志着广东法院与世界知识产权组织进入了紧密合作、共谋发展的新阶段,为促进涉外涉港澳知识产权纠纷多途径化解,发挥司法与专业调解的叠加优势提供了新路径,相信并期待成为中国法院深度参与世界知识产权组织框架下全球知识产权治理的新典范。(来源:南方+)[ 编辑: 李若凡 ]
