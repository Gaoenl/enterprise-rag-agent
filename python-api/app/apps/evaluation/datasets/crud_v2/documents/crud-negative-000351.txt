12月10日，漯河市食品营养与健康产业高质量发展大会和河南省首届营养与健康论坛举行。国家、省相关领导和食品产业领域的知名专家学者齐聚一堂，共话食品产业转型升级大势，共商食品营养与健康产业发展大计，共谋食品产业高质量发展未来。国家卫生健康委食品安全标准与监测评估司司长刘金峰，中国工程院院士、中原食品实验室学术委员会主任庞国芳，国家食品安全风险评估中心党委书记王永挺，省卫生健康委主任黄红霞，河南省储备粮管理集团有限公司党委书记、董事长王玉田，河南省卫生健康委二级巡视员张学旺，河南省临床营养师协会理事长余薇，郑大二附院院长刘剑波出席会议。漯河市委书记秦保强讲话。漯河市委副书记、市长黄钫主持大会。漯河市领导贾宏宇、李思杰、乔彦强、周剑、宋琰琰等出席。秦保强代表中共漯河市委、市人大、市政府、市政协向出席大会的专家、来宾表示欢迎。他指出，近年来，漯河市深入贯彻“健康中国”战略，充分发挥首个中国食品名城食品产业生态完善、链群发展的集成优势，积极践行“大食物观”，始终把营养健康作为食品产业的“永恒主题”，把中原食品实验室作为食品营养健康产业发展的“强大引擎”，把农产品当作食品营养健康的“第一车间”，把食品安全当作食品营养健康的“红线底线”，着力构建科技创新与食品产业深度融合的现代化食品产业体系，以超常规大力度的创新之举引领食品营养健康产业加快发展，努力成为世界餐桌的供应者、营养健康食品的引领者、未来食品的探索者、美食文化的创造者，加快建设“优势再造、形神兼备”的现代化食品名城。成立国家食品安全风险评估中心食品安全风险监测（漯河）合作实验室，是开辟食品营养健康新赛道、助推食品产业品质提升的重大举措。漯河市将以合作实验室揭牌为契机，充分用好这次论坛的研究成果，吸收各位专家的真知灼见，对标“健康中国”战略，持续推进安全保障“数智化”、源头品控“绿色化”、科研创新“高端化”、产业孵化“多元化”、特色品牌“国际化”，实现“大食物观”与大健康观的全面精准有效对接，推动食品营养健康产业高质量发展。希望国家卫健委、国家食品安全风险评估中心、国家食品安全标准与营养研究联盟、省卫健委、省临床营养师协会等上级部门一如既往关心支持漯河食品营养与健康产业发展；希望各位院士、专家多来漯河开展学术研讨和交流，为食品安全营养与健康创新发展出力出智；希望与会企业家把更多优质资源、创新项目布局漯河，实现共赢发展。王永挺代表国家食品安全风险评估中心向合作实验室的落成表示祝贺。他指出，合作实验室的挂牌是各方加强合作的大事喜事，标志着国家专业机构与地方专业机构“喜结连理”，是我们共话未来、共同进步的开始。漯河作为首家中国食品名城，食品产业主导地位突出、名牌食品企业荟萃、科研创新实力雄厚。希望借助此次合作，实现与中原食品实验室资源共享、优势互补，协同创新、发展共赢，更好保证人民群众“舌尖上的安全”，更好助力漯河乃至河南食品产业健康转型和高质量发展。黄红霞表示，漯河食品产业体量大、名企多、链条长，发展势头强劲、产业集聚效应明显，高标准建设中原食品实验室，大幅增加营养健康食品研发投入，为产业转型升级提供了强大的技术支撑。希望漯河市抓住机遇、乘势而上，做食品安全的示范者、合理膳食的先行者、营养健康食品的引领者、新业态开发的探索者、“大食物观”的践行者，为推进中国式现代化建设河南实践作出新的重大贡献。大会上，国家食品安全风险评估中心、市政府和中原食品实验室签订《国家食品安全风险评估中心食品安全风险监测（漯河）合作实验室框架协议书》。刘金峰和秦保强共同为国家食品安全风险评估中心食品安全风险监测（漯河）合作实验室揭牌。秦保强为合作实验室特聘专家代表颁发聘任证书。河南双汇投资发展股份有限公司、河南中大恒源生物科技股份有限公司、中原食品实验室分别作交流发言。论坛上，刘金峰作了题为《将健康优先策略贯通食品安全与营养健康事业产业发展全过程》的主旨演讲；中国工程院院士、中原食品实验室学术委员会主任庞国芳，中国疾病预防控制中心研究员张继国，郑州大学教授余增丽分别作了题为《食品安全农药残留检测技术标准化研究30多年》《营养与健康》《合理膳食远离疾病》的专题讲座。出席本次大会的还有来自东北农业大学、南方医科大学、天津科技大学、华中农业大学、湖南农业大学、北京工商大学、上海理工大学、郑州大学等院校的专家教授，国家卫健委食品安全标准与监测评估司和国家食品安全风险评估中心的专家教授，各县区（功能区）、市直有关部门主要负责同志，中原食品实验室有关负责同志及河南双汇投资发展股份有限公司总裁马相杰等相关企业代表。责任编辑：李连凡
