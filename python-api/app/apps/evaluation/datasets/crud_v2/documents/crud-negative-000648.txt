2023-07-26 10:29，正文：原标题：儿童走失，家长急！民警救助，反应快！ 近期，前来北戴河游玩的旅客日渐增多，7月25日北戴河火车站先后发生两起儿童走失的事件，北戴河站派出所执勤队民警反应迅速，及时帮助他们找到家长，受到旅客的高度称赞。7月25日14时许，北戴河站派出所执勤三队队长解文辉与民警和弦在北戴河站候车室执勤时遇一旅客求助，该旅客称因自己疏忽与孩子走散，孩子向候车室西侧走去后就不知去向。民警和弦在记录走失儿童的特征后立刻在候车室内开展查找，经过排查候车区域、走访旅客，最终在一楼候车室出口旋转门附近发现了一名与走失儿童极为相似的男童，该男童此时已经通过出口旋转门出站，独自向广场走去。此时，正在候车室外巡逻的民警马笑雨也注意到了该男童，经电台联络，两民警将男童和家长带至进站口，经过相认，母子团聚，旅客对民警的帮助表示感谢。当日下午15点55分许，执勤民警孟祥帅在进站口开展查缉时，一名中年男子带着一名男童过来寻求帮助，该男子称孩子跟他的父母走散了，希望民警能够提供帮助。民警一边安慰男童不要害怕，一边民警带领他去北戴河车站服务台进行广播寻人。同时，询问男童是否知道自己坐几点的火车，男童说好像是坐下午四点多去北京的火车，民警经过查看列车停次表，推断他们乘坐下午4点25分T5698次列车的可能性比较大，便立刻领着男童在T5698次列车候车区进行寻找。大概在候车厅寻找了4、5分钟，民警就看到正在急迫寻找孩子的男童父母。经了解，男童是去找卫生间，但一不小心走出了车站，然后遇到了好心旅客领着他来到进站口求助民警。民警孟祥帅认真核对了男童父母的身份证件，然后叮嘱他们出门乘车一定照顾好小朋友和看管好随身财物，如有困难可第一时间寻找民警求助。来源：北戴河站派出所通讯员： 吴庆伟 苗壮返回搜狐，查看更多责任编辑：
