"快科技8月2日消息，今天国内最长的城市地铁环线——武汉轨道交通12号线首个盾构区间青菱站至罗家村站区间右线顺利贯通，标志着该工程建设全面进入快车道。据悉，武汉地铁12号环线线全长59.9公里，连通武汉三镇，串联了武汉7个行政区域。全线共需72台盾构施工，目前正在同步掘进的有15台盾构，此次“洞通”的青菱站至罗家村站区间右线全长874米。据悉，武汉地铁12号环线于2017年12月18日在园林路站开工土建预埋，预计于2024年底开通武昌段，2025年开通江北段并成环运营。这是武汉地铁的首条环线，串联了武汉三镇，两次穿湖（墨水湖、沙湖），三次过江（两次长江、一次汉江），连接了汉口火车站、二七滨江商务区、青山滨江商务区、华中金融城、武昌火车站、汉江两岸、王家墩中央商务区、园博园等客流集散点。武汉地铁12号线全线长度约为59.876km，共设站37座（全为地下站），平均站间距约为1618m，采用6节编组A型车。举报/反馈",
