2023-07-29 09:54，正文：荆楚网（湖北日报网）讯（记者黄铮 通讯员邹小山 姜杭德）7月28日，咸宁市召开安全防范工作视频调度会，传达有关批示和重要提示，安排部署近期安全防范相关工作。 咸宁市召开安全防范工作视频调度会。黄铮 摄咸宁市安委会28家有关成员单位出席本次会议，该市建设、城镇燃气、消防、综合交通、校园等专委会进行发言。 会议要求，要提升抓安全生产工作的政治站位和行动自觉，深刻汲取近期国内多起重大突发事件事故教训，安排部署本地区、本行业安全防范工作，坚决确保咸宁市平安稳定。要切实落实党委政府领导责任、部门监管责任和企业主体责任。要加强安全生产督导检查，对发现的安全生产领域不担当不作为情形，一律从严从重问责处理，保持安全监管高压态势。视频会现场。黄铮 摄同时，要针对汛期强降雨和暑期高温季节特点，结合正在开展的全市重大事故隐患专项排查整治2023行动，突出重点开展安全生产大检查。特别是做好台风“杜苏芮”灾害防御工作，防范由此引发的城镇内涝、山洪地质灾害。 会议指出，各地各部门一定要凝心聚力、担当尽责、攻坚克难，以“时时放心不下”的责任感、“事事落实到位”的执行力，落实各项安全防范措施，确保全市安全生产形势的持续平稳，营造安全稳定的良好环境。
