6月15日晚，在西安永宁门瓮城内，西安战士战旗杂技团进行网络直播，引来众多游客驻足观赏，其中不乏一些外国友人。直播中，演员孙艺娜表演了肩上芭蕾，足尖站肩、180度转体等高难度且极具观赏性的动作，让观众屏息欣赏，随即热烈鼓掌，直播间里的粉丝数也不断上涨。“我们希望通过直播向广大网友展示新时代的杂技艺术。”西安战士战旗杂技团团长张权介绍，“自直播以来，每天观看量约有230余万人次，最多一场达到500万人次。”西安战士战旗杂技团是由曲江新区管委会将原广州军区战士杂技团和原成都军区战旗杂技团的优秀演员吸纳引进至西安而组建的，成为西安演艺集团旗下专门从事杂技艺术表演的文艺团体。近年来，团队创排新版杂技芭蕾剧《天鹅湖》、杂技剧《如梦长安》《第三战队》，先后40余次登上央视和多家卫视平台，作品触达数十亿观众。今年，西安战士战旗杂技团获“中国杂协2022年度工作成绩突出的杂技院团”荣誉。张权介绍，2004版中国杂技芭蕾剧《天鹅湖》先后在法国、德国、丹麦、俄罗斯、英国等全球25个国家和地区演出超2万场。东方杂技与西方芭蕾的融合，得到外国观众的一致称赞，并收获了一系列海内外大奖。2019年，西安战士战旗杂技团成功创排新版杂技芭蕾剧《天鹅湖》。新版杂技芭蕾剧《天鹅湖》不仅将原作中蕴含的艺术精神完整地继承下来，还创新性地加入了“一带一路”沿线的国家风情、西域风貌以及对大唐文明、长安文化的展现，使故事更具东西方交流的人类文明史格局。西安战士战旗杂技团执行董事闻雅娜介绍，新版杂技芭蕾剧《天鹅湖》自首演以来，已完成国内38个城市的巡演，同时通过线上线下演出形式亮相第十三届中国国际青年艺术周活动、巴西戴尔艺术冬季艺术节、中国驻捷克共和国大使馆第八届“欢乐春节”活动等。2021年12月7日，作为第七届丝绸之路国际艺术节闭幕式演出剧目，新版杂技芭蕾剧《天鹅湖》在西安索菲特人民大剧院精彩上演。此次艺术节闭幕式活动通过线上线下相结合的方式进行全球直播，惠及俄罗斯、奥地利、波兰、意大利等20多个国家和地区约1300万名观众。2020年，西安战士战旗杂技团自主创排了“一带一路”主题杂技剧《如梦长安》。该剧讲述了罗马女孩经过丝路沿线国家东到长安的故事，再现大唐盛世的兼容并蓄。该剧将多个曾获国内外各类奖项的经典杂技节目巧妙融入剧情，营造出惊险、唯美的舞台艺术情境，生动刻画出跨越时空的真善美。该剧先后获得“陕西省大型舞台艺术创作资助项目”及“第三届陕西省戏剧奖·剧本奖”等荣誉。2022年，《如梦长安》在“相约北京”国际艺术节进行了线上云展播；2023年春节期间，西安战士战旗杂技团在曲江竞技中心进行了为期15天的驻场惠民演出，其中《如梦长安》连续展演14场，之后该剧作为南昌红谷滩大剧场装修改造后的首部开业大剧上演了三场，得到各地观众的好评和赞誉；今年年初，《如梦长安》作为“欢乐春节”中国文化月活动主推剧目，在墨西哥、哥伦比亚等国家进行了线上展演。2021年，西安战士战旗杂技团推出现代军旅题材杂技剧《第三战队》。该剧将话剧与杂技充分融合，不仅有着巅峰杂技技艺，还有引人入胜的紧张情节，让人不由得跟随剧情发展而心潮澎湃。在2022年丝路城市春晚上，《第三战队》经典片段精彩上演。闻雅娜说：“我们肩负着传播新时代杂技艺术的责任和使命。希望通过杂技演出让世界各国人民了解我们的优秀传统文化。”今年5月18日至19日，中国—中亚峰会在西安举行。西安战士战旗杂技团参与各国政要出席的大唐芙蓉园盛大迎宾仪式，同时在浐灞中国—中亚峰会新闻中心以快闪形式让中亚各国媒体朋友近距离感受杂技魅力。闻雅娜介绍：“今年7月27日至30日，新版杂技芭蕾剧《天鹅湖》将登陆新加坡滨海艺术中心。10月23日至29日，该剧将在阿曼苏丹国马斯喀特皇家歌剧院表演。今年是共建‘一带一路’倡议提出10周年，我们很荣幸能够通过杂技艺术为两国文化的互联互通合作贡献新的力量。”（记者 师念 实习生 李怡佳）
