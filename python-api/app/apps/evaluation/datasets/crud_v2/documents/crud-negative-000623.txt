大众网・海报新闻记者 王靖程 聊城报道“真没想到能办成,帮我解决了一大难题,非常感谢你们!”2023年3月20日,市民郝女士通过聊城市东昌府区行政审批服务局“府院联动绿色通道”顺利完成了公司股东变更业务,郝女士对该局为民解难、主动出击的服务态度赞不绝口!据了解,郝女士原是某购物中心有限公司员工,2020年,公司成立之初,她与该公司实际控股人签订了股份代持协议,成为该公司的股东。2022年,郝女士离职,多次要求公司变更股东,但公司一直不予回应,拒绝办理。根据《中华人民共和国公司法》规定,公司成立后,公司股东承担相应法律责任。当代持股东从公司离职后,公司若拒绝配合办理相应的登记变更手续,代持股东将继续承担公司经营中的法律风险,如果公司出现负债,甚至还会影响其正常的工作、生活。为尽快解决问题,恢复正常的生活秩序,郝女士来到了东昌府区行政审批服务局市场准入审批科,说明了自己的困扰,工作人员得知,郝女士已就此事向东昌府区人民法院提起诉讼,法院已依法判决划转股权,并出具生效判决书。但仅凭判决书并不能完成公司股东变更登记。了解情况后,工作人员安抚好郝女士的情绪,立即启动“府院联动”工作机制,与东昌府区人民法院主动联系、积极沟通,第一时间为其出具《协助执行通知书》;与此同时,该局工作人员主动出击、分派“专员”、协助执行,耐心帮助她在网上进行相关信息的填报,上传申报材料,即时审核办结,该公司变更股东业务顺利完成,整个过程只用了半个小时的时间,如此高效的审批服务,完全得益于部门间的协同联动、完美配合,形成了工作合力,最终解决了郝女士的“心头事”。“府院联动”工作机制是东昌府区行政审批服务局对破产企业顺利退出市场的一项创新服务举措,该局以群众需求为导向,拓展创新成果应用场景,将“府院联动”机制应用到依法裁判股权变更业务中,协助法院执行股东变更事宜,切实维护了企业群众的合法权益,解决了群众的急难愁盼,一定程度上帮助企业规避风险,正常运转。下一步,东昌府区将始终以群众需求为导向,坚持有解思维,敢于创新突破,探索出更多便民利企促发展、纾困解难暖人心的服务举措,持续擦亮“昌快办・畅快办”政务服务品牌,真正为市场主体开路、减负、加油,让群众办事省心、舒心、安心。(通讯员 苑永军 张晓阳)
