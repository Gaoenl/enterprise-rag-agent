进入移动版，省流量，体验好被堵塞的河道疏通了天长镇对辖区河道开展全面整治图为河道清理现场。记者赵元君 摄4月10日，本报以《河道内垃圾渣土成堆》为题，报道了井陉县天长镇大石桥附近的河道内堆积着大量垃圾和渣土的事情。报道见报后，天长镇有关部门对此事非常重视，当天便调集人员开始对辖区河道进行全面整治。当天中午，记者再次来到了天长镇，在大石桥周边的河道内，众多工作人员正在对堆积的垃圾和渣土进行清理。散落的垃圾经过清理后被集中到一起等待运走，大堆的渣土和淤泥则由推土机搬运填平。经过几个小时的清理，大石桥周边河道内的卫生状况有了明显的改善，之前一些淤塞的水道也恢复了通畅，河水重新从桥下流过。在现场，工作人员还对村民们在河道内私自开辟的菜地等违章建筑进行了清理，过程中，一些村民起初不同意工作人员对“自家”的东西进行清理，但是在工作人员耐心劝解下，他们最终认识到了此前行为的不合理，并表示愿意配合清理工作。除此之外，工作人员还拆除了设在桥洞周围的篱笆、石墙等设施。在清理的过程中，附近的村民也闻讯赶来观看。“这些东西长期占据河道，真是该好好清理一下了！”北关村的村民王先生表示，他非常支持这次清理工作，并希望今后有关部门也能加强监督管理，让清理的成果长期保持下去。“除了有关部门，居民们也应当约束自身的行为，自觉维护河道的卫生和畅通，毕竟这是和百姓生活和安全息息相关的东西！”村民马先生也说。天长镇党委委员刘恒告诉记者，不久前，县里就召开过关于农村人居环境综合整治的动员会，其中就包括对河道及周围区域环境卫生的整治，这段时间，天长镇也一直计划对绵蔓河全域进行综合治理，在4月10日一早，镇上也是专门召开了动员会，并立刻调集人员开始对河道进行全面的清理整治。刘恒表示，这次治理一是要对河道内存在的垃圾和违建进行彻底清运拆除，二是继续强化落实河长制，要求各村组织清扫队伍对辖区河道进行清理，并定期予以考核。为了保证治理效果能长期保持下去，他们还会加强监督管理，在容易倾倒垃圾的区域安装摄像头进行技术防范，并针对河道附近的居民和商户开展引导教育，通过发放宣传手册和明白纸等方式呼吁大家自觉维护河道及周边的环境。除此之外，未来他们还计划在河岸周边区域发展旅游业，推动经济发展的同时也保证周边环境稳步提升。（记者赵元君 实习生张坤征）
