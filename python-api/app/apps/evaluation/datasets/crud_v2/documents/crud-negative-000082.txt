2023-08-08 14:42，正文：                原标题：前7个月我国外贸进出口总值23.55万亿元 外贸结构持续优化                            央视网消息：海关总署今天（8月8日）公布，今年前7个月，我国货物贸易进出口总值23.55万亿元，外贸运行平稳、符合预期。  据海关统计，今年前7个月，我国货物贸易进出口总值23.55万亿元，同比增长0.4%，其中出口13.47万亿元，增长1.5%；进口10.08万亿元，下降1.1%。    海关总署统计分析司司长 吕大良：二季度以来，我国月度进出口规模稳定保持在3.4万亿元以上。7月当月，我国进出口3.46万亿元，处于历史同期较高水平。与2019年同期相比增长25.7%，较2020—2022年同期均值高4.5%。整体看，我国外贸进出口运行平稳、符合预期，长期向好的基本面没有改变。  海关统计显示，今年前7个月，我国外贸结构持续优化，一般贸易进出口15.41万亿元，同比增长2.1%。民营企业进出口12.46万亿元，同比增长6.7%，占进出口总值的比重提升至52.9%。机电产品出口占比提升，前7个月出口7.83万亿元，同比增长4.4%，占出口总值的58.1%。返回搜狐，查看更多                        责任编辑：
