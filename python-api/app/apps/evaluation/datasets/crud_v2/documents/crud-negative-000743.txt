2023-08-08 09:22，正文：原标题：省市公安部门联合开展反诈宣传进漫展活动省市公安部门联合开展反诈宣传进漫展活动 为进一步营造“全民防电诈 全社会反电诈”的浓厚氛围，特别面向青少年群体精准开展反诈宣传，8月5日，省公安厅政治部宣传处、省公安厅刑警总队联合兰州市公安局新闻宣传中心、兰州市公安局刑警支队走进“兰州·HIacg次元嘉年华”漫展活动现场，同步开展“夏季行动·平安守护——反诈联盟进行时”反诈防骗宣传，现场1200余名青少年参加本次活动。“我就经历过游戏皮肤类诈骗，现在回想起来真是一场噩梦，今天这个针对我们学生群体反电诈知识科普太有必要了，可以让更多的人了解、预防、远离电信诈骗。”一名高中生讲述自己被骗经历时说道。现场“反诈小课堂讲解”“这条路你要怎么选”等系列通关反诈防骗游戏，吸引了众多漫展观众驻足参与。“不仅拿到了精致的公安文创产品，还提升了自己防电信诈骗的意识，今天真是收获满满。”“出借、出租、出售自己的电话卡和银行卡竟然涉嫌违法犯罪，今后坚决不做电信网络诈骗的‘帮凶’。”反诈宣传与动漫的奇妙融合，让最具朝气、最有活力的年轻群体更有兴趣地学习掌握反诈知识，进一步提高了防骗意识。广大漫展观众纷纷表示，今后将积极参与到防范电信网络诈骗宣传的活动中，传递“识诈、防诈、反诈”法律知识，争做防范电信网络诈骗的“形象大使”，助力营造全民反诈的积极氛围和健康向上的网络生态。兰州日报社全媒体记者 伊晓明返回搜狐，查看更多责任编辑：
