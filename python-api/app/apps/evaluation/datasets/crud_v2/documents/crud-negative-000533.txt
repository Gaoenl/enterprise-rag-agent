2023年07月30日，正文：                                                                 中新网7月30日电 综合俄媒报道，俄罗斯莫斯科市长谢尔盖·索比亚宁称，乌克兰无人机当地时间30日凌晨发动袭击，莫斯科市的莫斯科国际商务中心两座办公大厦外立面轻微受损、1人受伤。图片来源：俄新社报道截图据俄罗斯卫星通讯社报道，俄罗斯国防部发布消息称，当地时间30日上午，俄方阻止了一次乌方无人机对莫斯科设施实施“恐怖袭击”的企图。俄国防部称，一架乌克兰无人机在莫斯科州奥金佐夫斯基区上空被防空系统所摧毁。此外，俄方已通过“电子战”制止另外两架乌克兰无人机，并使其失去控制，无人机坠毁在莫斯科非住宅建筑区域内。另据塔斯社30日消息，莫斯科伏努科沃国际机场于当地时间30日凌晨一度关闭，机场关闭了进出港航班。报道援引航空部门最新消息称，机场目前已恢复正常运行。法新社指出，莫斯科及其周边地区距离乌克兰边境约500公里，在乌克兰危机期间很少成为袭击目标，但今年以来已发生多起无人机袭击。本月早些时候，俄罗斯方面表示，击落了五架“扰乱莫斯科伏努科沃国际机场运作”的乌克兰无人机。                                  【责任编辑：唐红】
