11月6日，石家庄市政府新闻办召开扶持创建普惠性民办幼儿园新闻发布会。图为新闻发布会现场。 记者吴培源摄河北新闻网11月6日讯（记者吴培源）从石家庄市政府新闻办今天上午召开的扶持创建普惠性民办幼儿园新闻发布会上获悉，该市今年继续扩大普惠园覆盖面，已新扶持创建97所普惠园，提供普惠学位2.6万余个。为解决学前教育供给结构性不平衡的难题，补齐学前教育短板，加快构建公益普惠的学前教育公共服务体系，2016年3月，石家庄市制定出台了《石家庄市普惠性民办幼儿园认定及财政扶持管理实施办法（试行）》等“1+4”系列配套文件，从加大学前教育供给侧结构改革入手，通过“政府买服务、园所得扶持、幼儿得实惠”实施路径，调动社会力量的积极性，扩充优质普惠的学前教育资源。2016-2018年，全市市级普惠园达到124所，惠及3.4万名幼儿家庭，为市民提供更多优质普惠的学前教育服务。2019年，继续扩大普惠园覆盖面，新扶持创建97所普惠园，提供普惠学位2.6万余个。石家庄市还创新服务举措，积极扶持普惠性民办园，满足适龄幼儿有质量的入园要求。采取“优质办园有奖补、幼儿家庭分段补”的“双补”举措：奖补优质普惠园，采取升类奖励和优质园扶持等举措，激励优质民办园加入普惠行列，为市民提供更优质的服务；补贴幼儿保教费，采取分段补贴幼儿家庭保教费资金的方式，切实减轻了家庭负担，直接增强了百姓学前教育获得感，市内5区普惠园的幼儿家庭每月可获得保教费补贴250-300元，其他县市区50-100元。同时鼓励各地采取配置玩教具、改善办园条件、购买保安服务等多种举措加以扶持。在落实现有的国家学前教育资助制度基础上，创新增设了家庭经济困难幼儿、孤儿、残疾幼儿的普惠园资助经费制度，用于减免此类儿童的保教费、餐费，彰显了对特殊儿童的关爱，体现了教育公平。针对“入园难，入园贵”的问题，石家庄市实施了幼儿园增量工程、普惠工程、提优工程、以及安心工程，实现了“有园上”“上得起”“上得好”“安心上”。“有园上”。实施“幼儿园增量工程”，大力发展公办园。采取提速新园建设、扩容老园规模、盘活闲置资源转办幼儿园等方式综合施策，新增幼儿学位4.5万个。“上得起”。实施“幼儿园普惠工程”，积极创办普惠民办园。市委、市政府连续四年将普惠园创办列入利民惠民实事，以政府购买服务方式，将专项补贴直接发放到幼儿家庭，2016-2019年，全市新扶持创办普惠园221所，新增普惠学位6万个，进一步提升老百姓的教育幸福感和获得感。“上得好”。实施“幼儿园提优工程”，重点支持农村园建设。坚持推动老园创优质，名园带弱园，近年来全市新增省市优质百所幼儿园，特别是在改善农村办园条件和提升办园水平上，新增幼儿学位1.3万余个。“安心上”。实施“幼儿园安心工程”，规范小区配套园。积极推进教育资源配置地方立法，先后出台实施《石家庄市教育设施规划建设管理条例》《石家庄市居民住宅项目配建教育设施移交管理办法》，为配套幼儿园建设、移交工作提供政策保障，2019年开展城镇小区配套幼儿园专项治理，将接收后的配套园办成公办园获委托办成普惠性民办幼儿园，进一步扩充普惠性学前教育资源。目前，石家庄市内5区保教费在500元至1200元的民办园占67%。市教育局、市财政局联合印发的《石家庄市普惠性民办幼儿园认定及财政扶持管理实施办法》（石教〔2019〕45号）中规定，普惠园保教费保持相对稳定。对保教费实际收费标准为500元-1200元/生•月的普惠园进行政府购买服务，补贴幼儿家庭（财政补贴250—300元/生•月），做到受益人群最大化。（责任编辑：）
