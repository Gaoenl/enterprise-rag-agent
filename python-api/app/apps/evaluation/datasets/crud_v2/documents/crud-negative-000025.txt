2023-07-26 07:44:13，正文：北京时间7月25日晚上10时，2023年《财富》中国500强排行榜揭晓。国家电网有限公司、中国石油天然气集团有限公司、中国石油化工集团有限公司分别位于此次发布的榜单前三，其中国家电网有限公司以5300亿美元营业收入居榜首。榜单显示，四川有8家企业上榜，其中靠前的为新希望控股集团有限公司、蜀道投资集团有限责任公司、通威集团有限公司、成都兴城投资集团有限公司等。据了解，今年500家上榜的中国公司在2022年的总营业收入达到15万亿美元，净利润达到7171亿美元。国家电网有限公司以5300亿美元的营收位居榜首，中国石油和中国石化分列榜单第二位和第三位，位列第四位的是中国建筑集团。依据该榜单及其数据，可以了解中国最大企业的最新发展趋势。榜单显示，新能源领域的两家头部公司，营收相较上年增长巨大——宁德时代营收达到488亿美元，较上年增长141%；比亚迪营收增长92%，达到630亿美元。另外，金属产品行业共有56家公司上榜，是今年上榜公司数量最多的行业，上榜公司收入总额达1.4万亿美元。在盈利能力方面，最赚钱的10家上榜公司中，除五家商业银行和中石油、中海油、中移动之外，两家私营企业也进入了前十位，其中台积公司以333亿美元净利润排在利润榜第5位，腾讯的净利润比去年下降了19%，但仍以超过279亿美元的净利润排在利润榜第6位。这十家公司在去年的总利润约为3087亿美元，约占上榜公司利润总和的43%。此次发布的榜单，《财富》中国500强中共计有64家上榜公司未能盈利，亏损榜前十家公司中有3家航空公司、4家房地产公司。据悉，《财富》世界500强榜单将于8月2日发布。附：上榜的四川企业排名 公司名称 营业收入(百万美元)100 新希望控股集团有限公司 41,426.2108 蜀道投资集团有限责任公司 38,019.4136 通威集团有限公司 31,944.4140 成都兴城投资集团有限公司 31,304.1164 四川省宜宾五粮液集团有限公司23,117.1215 四川长虹电器股份有限公司 13,748.2346 天齐锂业股份有限公司 5,971.5474 泸州老窖股份有限公司 3,734.8
