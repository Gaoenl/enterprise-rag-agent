2023-08-12，正文：近日，广西来宾宣武县东渡码头，发生一起让人心痛的溺亡事件，救人者的身世，和被救孩子哭喊的话语，都让众人围观众人为之落泪，甚至医生都一度绷不住了。据目击者描述，事发时，一个孩子突然落入公园的湖中，在岸上结伴而行的一对男女中的黑衣男子，立即毫不犹豫地跳入水中，奋力将落水的孩子推到了岸边，而他自己却无法脱离危险水域，挣扎几下后不幸溺亡。消防人员和医护人员赶到现场后，将男子从水中捞出，并对他进行了人工呼吸和心肺复苏的紧急施救，然而已经无力回天。据知情者介绍，这名溺亡的男子正是落水孩子的父亲，当时他和姐姐带着孩子在公园游玩，孩子不慎落水后，虽然他不会游泳，但还是义无反顾地跳入水中去救孩子，最终不幸溺亡，可以说是用他自己的生命换回了孩子的生命，这种一命换一命的救人行为，让人十分感慨。而这名男子的身世则更让人心生怜悯，据了解，这名男子姓刘，今年36岁，他和妻子在前几年离婚了，他独自抚养两个孩子。他的两个孩子都在上小学，年龄小的那一个仅10岁。视频画面显示，这名男子被消防人员救上来后，他的姐姐和孩子一起跪地痛哭，孩子撕心裂肺地喊到：“爸爸，爸爸，你回来啊”，他的姐姐则不断地哭喊着哀求医护人员：“我求你们了，求求你们救救他”，场面让人十分动容，在场的医生都绷不住了，警察不得不出面维护秩序。
