2023-07-31 17:00，正文：原标题：推特更名“X”后总部架发光标志，夜晚狂闪引居民不满（观察者网讯）当地时间7月28日起，一座巨大的“X”形金属灯架出现在美国旧金山原推特（现名“X”）总部楼顶，开始不分昼夜发光，甚至在夜晚狂闪，“亮瞎”周围居民。 但马斯克本人深爱这刺破夜空的“X”光，并将相关视频设为置顶。 综合路透社和《纽约时报》报道，旧金山建筑检查部门工作人员正在调查该灯架是否违规搭建，但X公司代表两度拒绝他们上楼顶勘察，并称那只是“一个活动的临时亮灯标志”。 住在X公司对面的帕特里夏·沃林加告诉告诉美国哥伦比亚广播公司（CBS），这是一场“小丑表演”，自己原以为那是闪电或是警报，对此非常困惑。她称自己所在的大楼多是租户，而且有很多老年人，对他们来说这种强光绝对是“危险”的。 律师乔治·沃尔夫称，居民们有权批准或拒绝此类项目。 有人开玩笑地猜测这样的高频闪烁定是摩斯密码。北约前欧洲盟军最高司令、美国退役海军上将詹姆斯·斯塔夫里迪斯（其拒绝购买推特蓝色认证）转发并调侃称：“作为一名上海军将，我可以解码。意思是：‘埃隆不应该解雇推特的电工’。” 有用户表示，这简直可以起诉对方造成“光污染”了，并称这种闪光可能导致癫痫病发作，还会造成失眠、头痛等不适。 “这让人讨厌。” 还有用户直言，对这种公然不替任何人着想的行为感到震惊。 与此同时，旧金山建筑检查部门对这一X灯架展开了调查，称这一变更在没有得到批准的情况下发生，可能违反了相关规定。 一位该部门检查员在报告中称，他7月28日、29日连续两天奔赴大楼，想进入屋顶检查那个装置，但都被X公司代表拒绝。其中一名代表解释称，这一装置是“一个活动的临时亮灯标志”。 旧金山建筑检查部门发言人帕特里克·汉南7月30日表示，为了确保装置的结构稳固、安装安全，安装这一标志需要经过规划审查并得到批准。 当地时间7月31日晚，这座灯架一度熄灭，随后再次亮起。 返回搜狐，查看更多责任编辑：
