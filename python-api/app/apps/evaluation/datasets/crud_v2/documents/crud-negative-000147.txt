2023-08-04 07:06，正文：原标题：扎哈罗娃：乌和平会议“是骗局”，以展示在反俄行动上的伪团结【环球时报特约记者 柳玉鹏】“为什么沙特举办乌克兰和平会议注定失败？”俄罗斯《消息报》3日以此为题报道称，5日，一些国家的代表将聚集在沙特举行会议，讨论俄乌冲突解决方案，但没有邀请俄参加。报道称，此次会议关注的焦点将是乌克兰总统泽连斯基提出的所谓和平计划。另据报道，俄乌3日再次相互发起无人机攻击。俄《消息报》3日报道称，此次会议的主办方希望邀请约30个国家的代表参加，除了西方国家外，也希望全球南方国家能参加会议，以改变他们的中立立场，支持基辅的和平计划。但一些国家已拒绝在没有俄参加的情况下讨论解决俄乌冲突问题。墨西哥总统洛佩斯上月底已表示拒绝参加会议。他说，只有冲突双方都参加，会议才有意义。俄新社2日报道称，巴西总统卢拉当天表示，乌克兰冲突必须在联合国安理会层面解决。如果联合国更早讨论乌克兰问题，和平早就实现了。同一天，俄外交部发言人扎哈罗娃称，基辅和西方国家根据泽连斯基的和平计划在沙特举行会议是一个骗局，实际上是为了加强反俄联盟，以展示世界在反俄行动上的伪团结。俄一再重申这一和平计划是不可接受的，也不可能实现。3日，俄罗斯与乌克兰再次相互实施无人机攻击。今日俄罗斯电视台报道称，俄国防部3日称，在俄卡卢加州上空，基辅企图用无人机进行恐怖袭击。俄军防空系统摧毁了6架无人机，没有造成人员伤亡和损失。同一天凌晨，乌克兰多地发出空袭警报。乌克兰独立新闻社称，基辅军事管理部门负责人波普科当天表示，俄军连续第八次袭击基辅。在基辅方向，乌军防空部队发现并摧毁了近150个空中目标。这次对乌首都的空袭持续了3个小时。返回搜狐，查看更多责任编辑：
