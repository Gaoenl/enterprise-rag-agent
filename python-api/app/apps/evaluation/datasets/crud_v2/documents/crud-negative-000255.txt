2023-07-28 21:30，正文：原标题：扎哈罗娃称乌克兰人羡慕嫉妒恨：他们想要普京当自己总统（观察者网讯）“乌克兰人民的悲剧在于，他们非常希望拥有一位像普京这样的总统。”当地时间7月28日，俄罗斯外交部发言人扎哈罗娃接受“今日俄罗斯”（RT）采访时表示，对于乌克兰来说，事与愿违才是常态，“他们经常只能接受西方指定的人作总统”。 扎哈罗娃接受RT采访，视频截图扎哈罗娃告诉RT主持人，这就是正在乌克兰发生的事情，即“他们仇恨普京、对普京很有攻击性，是因为他们想要普京成为他们的总统”。 她进一步称，乌克兰人需要“一个开放、坚定、知识渊博且敢于独立发言的人；一个并非根据华盛顿发给他的一张纸来说话，而是知道自己在说什么的人“来成为他们的总统。 采访中，扎哈罗娃还提到了美国总统拜登，批评拜登“与世界脱节”，并称“当美国总统会看到一个已经死去的人并与之交谈时，这真的很可怕”。 扎哈罗娃此处似乎指的是拜登向去世女议员喊话事件。去年9月，拜登在一场关于消除饥饿的会议上发表讲话时，现场寻找起了印第安纳州共和党籍众议员杰基·沃罗斯基（Jackie Walorski），还呼喊着“杰基，你在吗？杰基你在哪儿？”。他好像忘记了这名女议员已经在上个月的一场车祸中身亡。 此外，扎哈罗娃还剑指欧洲，直指“欧洲国家成为了美国的殖民地”。 根据RT报道，扎哈罗娃是在俄罗斯圣彼得堡参加俄罗斯-非洲峰会期间，接受的上述采访。第二届俄罗斯-非洲峰会于7月27日至28日期间在俄罗斯圣彼得堡举行。 当地时间27日，俄罗斯总统普京出席开幕式，在讲话中宣布以无偿援助的形式向六个最需要援助的非洲国家提供粮食。普京还向非洲国家元首和代表们的到来表示了热烈欢迎，称非洲国家是俄罗斯“志同道合“的伙伴，同时表示，俄罗斯与非洲国家应加强在能源、货币结算、工业、教育等领域的合作。 返回搜狐，查看更多责任编辑：
