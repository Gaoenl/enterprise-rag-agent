2023-07-20 11:03:30，正文：东方网通信员杨帆报道7月20日：7月18日，上海一位年近7旬老人疑因中暑晕倒街边，在中国石化耀华加油站员工的热心救助下，老人中暑症状得到缓解，并在警方帮助下，找到其家人。当天15时许，耀华加油站员工王燕娟正在为车辆加油，工作间隙，只见人行道上一位白发老人走路时踉踉跄跄，就在她放下油枪的一会儿功夫，再次抬头时，不见了老人踪迹。她感到有些不对劲，连忙小跑到人行道上，只见老人已经仰面躺在路边，脸色苍白，意识不清。“师傅、师傅你还好吗？” 王燕娟赶紧蹲下来询问老人情况，老人只能微弱地应答两声。她赶紧呼叫同事们来帮忙，“一位老人晕倒了，快来帮忙。”站长王瑛见状，赶紧拨打警方电话反映情况。图片说明：中国石化上海石油供图​ 同时，员工们将晕倒老人搀扶到加油站营业室休息，还拿来盐汽水、人丹及风油精等，帮助老人缓解中暑症状。见老人情况好转，员工们便询问道，“老伯伯，你感觉怎么样啦？家住在哪里呀？”可老人还是沉默不语。不久，来到加油站的民警查看老人体貌特征后说，该老人与上午市民报警走失的家人信息比较吻合，民警便将老人带回派出所。临走前，民警对加油站员工竖起大拇指，说道：“老人从上午走失，估计到现在都没有进食，天气又这么热，谢谢你们及时救助，不然后果难料。”
