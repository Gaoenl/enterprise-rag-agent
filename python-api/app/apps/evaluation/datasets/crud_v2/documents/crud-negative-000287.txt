2023-08-07 18:07:21，正文：印度的降雨不足也影响到了糖的产量，市场开始担心印度政府颁布针对部分大米出口的禁令后，将轮到食糖了？彭博社粉丝指出，印度此前就限制过糖的出口。在2022/23产季，印度的食糖出口量被限制在610万吨，而前一榨季为1100万吨。分析师预计，根据目前的产量推测，很可能下一产季只会允许出口200万至300万吨食糖，还不及这一产季的一半，或者印度政府将禁止食糖出口，这都两种情况会进一步推高全球糖价：目前全球粮食市场已经因厄尔尼诺现象和俄乌冲突加剧而陷入困境，作为全球最大的食糖生产国，及全球第二大食糖出口国，如果印度政府也限制食糖出口，无疑会进一步加剧全球粮食市场供应的压力，让本就处在高位的糖价雪上加霜。热带研究服务公司糖和乙醇部门主管Henrique Akamine表示，大米出口禁令是一个明确的信号，这意味着印度政府担心粮食安全和通货膨胀。现在担心的是，“政府可能会效仿大米禁令，对糖采取类似的措施”。印度制糖企业协会主席Aditya Jhunjhunwala表示，尽管如此2023/2024榨季的糖产量将下滑，但仍可以满足印度供国内对糖的需求。与此同时，印度或将更多的糖用于生物燃料。该协会预计约有450万吨糖将用于生产乙醇，同比增长9.8%。StoneX 糖和乙醇主管 Bruno Lima 表示，按照目前的产量水平，印度可能不会释放任何出口。“我们必须密切关注将有多少糖被用于乙醇生产。”印度政府需要对明年榨季产量有确切了解，才会决定是否允许下一季的糖出口。预计要到2024年上半年才能决定印度是否允许下一季的糖出口。今年的季风表现以及接下来两个季节（2023/2024榨季和2024/2025榨季）的甘蔗产量将是关键。
