近日，驻新加坡使馆与新加坡警察部队反诈骗中心联合，一起进入新加坡管理学院（SIM），向学院中国留学生宣介防范电信网络诈骗知识。活动中，使馆领事保护干部详细分析介绍了近期发生的涉中国留学人员虚拟绑架等类型电信诈骗案件情况，及新近出现的引诱离境骗局，提醒在新留学生密切关注警方和使馆发布的通知提醒，了解诈骗套路，提高防范意识，保护个人安全和财产安全。新加坡警察部队反诈骗中心警官以案说法，就识别诈骗电话、避免卷入骗局和保护个人信息等进行生动讲解。当前海外电信网络诈骗犯罪形势十分严峻，此次联合宣讲体现了中新双方加强反诈合作、防范与打击危害群众行为的坚定立场，现场气氛热烈、互动频繁，受到了学校师生的普遍欢迎。
