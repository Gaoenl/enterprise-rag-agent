美众议长要求展开弹劾调查，拜登会被弹劾吗？特朗普何态度？中新网2023-09-13 10:36全球速报>字号综合外媒报道，当地时间12日，美国国会众议院议长、共和党人麦卡锡要求众议院相关委员会对民主党籍现任总统拜登展开正式弹劾调查，引发外界关注。白宫方面迅速谴责麦卡锡的决定，称发起弹劾调查是“最糟糕的极端政治”。正谋求竞选连任的拜登会因此被弹劾吗？曾两次被弹劾的前总统特朗普如何回应此事？弹劾调查！拜登家族有“腐败文化”？据美国《国会山报》12日报道，当天，麦卡锡在共和党人的鼓动下，要求对总统拜登进行弹劾调查。“今天，我指示众议院相关委员会对拜登总统展开正式弹劾调查，”麦卡锡12日在国会表示，众议院监督和问责委员会对拜登家庭成员调查发现，拜登家族有“腐败文化”，可能存在“滥用权力、妨碍司法、腐败”等。“我并非轻易做出这个决定。无论你属于哪个政党，或者你投票给谁，这些(拜登家族的)事实都应该引起所有美国人的关注。”麦卡锡说道。资料图：美国众议院议长麦卡锡。 中新社记者 沙晗汀 摄另据美联社报道，8月27日曾有媒体问麦卡锡是否准备在9月国会复会后，对拜登展开弹劾调查，他当时回应称，“如果了解到迄今为止我们收集到的所有信息，就会认识到弹劾调查是符合逻辑的下一步。”他表示，弹劾调查将“赋予国会最高法律权力来获取所需的所有信息”。据此前报道，对拜登家族的调查主要围绕拜登此前任美国副总统时期，其子亨特·拜登在乌克兰一家能源公司的商业行为。根据8月公布的一份记录，亨特的一名前商业伙伴8月在众议院监督与问责委员会的闭门听证会上供述，亨特制造了可以通过他接触拜登的假象，但据他所知，拜登没有任何不当行为。拜登会因此被弹劾吗？特朗普的态度意味深长据美联社介绍，弹劾调查是对美国联邦官员(例如美国总统、内阁官员或法官)可能存在的不当行为进行调查。这一程序被写入美国宪法，是美国国会对行政部门最有力的制衡。虽然众议院有权弹劾联邦官员，但只有参议院才有权对个人定罪或罢免。被弹劾调查，是否意味着拜登未来将被弹劾？美联社分析称，不一定。为了弹劾拜登，众议院必须至少批准一项对他的弹劾指控，这需要众议院多数票。此外，弹劾调查也可以在没有提出弹劾指控的情况下结束。美联社还分析称，即使拜登在众议院遭弹劾，由于参议院由民主党控制，弹劾案获得通过的可能性也不大。资料图：美国总统拜登。中新社记者 陈孟统 摄迄今为止，还没有哪位总统因弹劾而被迫离开白宫。但美国前共和党籍总统尼克松于1974年主动辞职，当时众议院正准备对针对他的弹劾条款进行投票。在2019年和2021年，当时由民主党控制的众议院两次弹劾共和党籍的时任总统特朗普，引起许多共和党人的愤怒抗议；不过，特朗普两次弹劾都在参议院被判无罪。据美媒报道，麦卡锡宣布对拜登展开弹劾调查，在一定程度上是为了满足众议院共和党中极右翼保守派的要求。共和党保守派议员盖茨12日表示，对拜登展开弹劾调查只是“微小一步”，“我们要加快行动步伐”。他还表示，如果麦卡锡行动缓慢，将可能采取措施让其“下台”。白宫方面迅速谴责了麦卡锡的决定。白宫发言人伊恩·萨姆斯12日发表声明称，众议院共和党人对拜登的调查已持续9个月，至今未能发现“不当行为的证据”，如今发起弹劾调查是“最糟糕的极端政治”。国会参议院多数党领袖、民主党人舒默则称此次弹劾调查“荒谬”。当地时间2022年11月15日，美国前总统特朗普在佛罗里达州海湖庄园发表演讲，正式宣布将参加2024年美国总统大选。在麦卡锡要求对拜登展开弹劾调查后不久，特朗普就与众议院共和党会议主席斯特凡尼克进行了交谈，后者多年来一直是特朗普在众议院中最坚定的捍卫者之一，也是众议院共和党最早支持对拜登进行弹劾的议员之一。特朗普虽然未第一时间就麦卡锡的决定表态，但他此前一直呼吁共和党人弹劾其2024年大选的潜在竞争对手拜登。这位前总统8月底在社交媒体上写道，共和党人应该弹劾拜登，否则他们会“被遗忘”。责任编辑：伍智超图片编辑：沈轲澎湃新闻报料：021-962866澎湃新闻，未经授权不得转载+1收藏我要举报#弹劾拜登
