2023-08-15 11:31，正文：原标题：河北省地质矿产勘查开发局党组成员、副局长李健接受审查调查央广网北京8月15日消息 据河北省纪委监委消息：河北省地质矿产勘查开发局党组成员、副局长李健涉嫌严重违纪违法，目前正接受河北省纪委监委纪律审查和监察调查。李健简历李健，男，汉族，1968年5月出生，河北唐山人，1988年7月参加工作，2002年5月加入中国共产党，大学学历。1984.09--1988.07 长春地质学校地质专业学习1988.07--1992.12 河北省地矿局第四地质大队一分队技术干部1992.12--2000.04 河北省地质勘查院承德工作部技术干部(其间:1997.06--1999.06在中国地质大学<北京>矿管专业学习) 2000.04--2000.12 河北省地矿局第四地质大队办公室干部2000.12--2001.12 河北省地矿局第四地质大队地质科副科长(主持工作) “虹膜通关”进入公开测试阶段 经过首阶段系统优化及试运行成功后，“虹膜通关”已具备条件进行更大型的测试。8月14日至25日的10:00、11:00、12:00及15:00，“虹膜通关”进入公开测试阶段，10条“虹膜自助通道”会开放给已预约的澳门居民登记及测试使用。本次测试也将被列入正式的出入境记录。 虹膜识别技术通过扫描人眼验证身份，查验时无须接触采集设备，为出入境服务提供更高卫生标准的通关查验模式，同时也解决了部分人士因指纹不清晰而不能使用自助过关的问题，大大提升了通关的安全性和效率。 虹膜识别技术将为澳门居民带来崭新的通关体验，结合“一户通”内的“通关二维码”，将可实现全程免接触式通关。责任编辑：
