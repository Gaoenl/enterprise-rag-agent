广州日报全媒体记者 杨敏昨天下午,第19届亚运会集体项目抽签仪式在杭州进行,抽签项目包括足球、排球、手球和藤球。根据抽签分组,中国女排在排位赛将提前对阵冲冠最强对手日本女排,而中国女足进入淘汰赛基本没有太大悬念,这两支女子国字号的目标均是在家门口的亚运会上夺冠。男足男排均被列入A组根据抽签安排,各亚洲(国际)单项体育组织对男、女子藤球,男、女子手球,男、女子排球,男、女子足球进行抽签分组。在手球项目上,中国女队与日本队、印度队、中国香港队、尼泊尔队分在B组,A组有韩国队、哈萨克斯坦队、泰国队和乌兹别克斯坦队。中国男队与科威特队、泰国队同处A组,其余三组还有卡塔尔队、巴林队、日本队等10支参赛队伍。藤球大项进行了男、女团,四人男、女子藤球,单组男、女子藤球六个小项的抽签。中国队在女团项目被分在B组,同组还有韩国队和老挝队。在四人女子藤球项目上,中国队被列入B组,同组还有菲律宾队、老挝队、印度队。在单组女子藤球项目,中国队与印度队、越南队同处A组。三个男子项目,中国队均没有参赛。一共有23支队伍参加杭州亚运会男足项目。在小组赛阶段,所有队伍分成6组展开单循环角逐,每组前两名和4个成绩最好的第三名晋级16强淘汰赛,中国亚运男足作为东道主进入A组,同组有孟加拉国队、缅甸队和印度队。B组有沙特队,C组有乌兹别克斯坦队,D组有日本队,E组有韩国队,F组有朝鲜队。一共有19支队伍参加杭州亚运会男排项目,中国男排位列A组,同组包括塔吉克斯坦队和哈萨克斯坦队。B组有伊朗队,C组有韩国队,D组有中国台北队,E组有卡塔尔队,F组有日本队。女排目标主场卫冕杭州亚运会女排比赛于9月28日到10月7日举行,决赛将于10月7日晚上打响。一共有13支队伍参赛,在小组赛阶段,全部队伍被分成4个小组展开单循环角逐。中国女排位列A组,B组有泰国队、中国台北队、蒙古队。C组包括韩国队、越南队和尼泊尔队。D组有日本队、哈萨克斯坦队、阿富汗队和中国香港队。每组前两名晋级8强后,再通过两轮排位赛决出前4名。按照中国女排的实力,要取得小组第一不在话下。A组小组第一将在排位赛对阵D组第一与第二。日本队为D组实力最强参赛队伍,预计该队将顺利以小组前两名挺进8强。因此,中国女排基本可以确定在排位赛阶段就与冲冠路上最强对手提前交手。中国女排主教练蔡斌此前表示,队伍将力争第一时间获得巴黎奥运会参赛资格,并且在家门口争取亚运金牌。女足力争主场夺冠一共有17支队伍参加杭州亚运会女足项目,在小组赛阶段,所有队伍分成5组展开单循环角逐。每组第一名和3个成绩最好的第二名晋级8强。作为东道主,中国女足落入A组,B组、C组、D组和E组的种子队伍分别是中国台北队、朝鲜队、日本队和韩国队。去年2月,中国女足时隔16年重夺亚洲杯冠军,这让外界对她们在家门口的亚运会夺冠更加期待。中国女足目前正在澳大利亚参加女足世界杯,杭州亚运会是队伍今年第二项重要比赛任务,目标就是全力争取主场夺冠。从目前分组来看,中国女足进入淘汰赛基本没有太大悬念,而日韩两队参加杭州亚运会的并非全主力阵容,这让中国女足在主场争冠的希望更大。(广州日报)【责任编辑:张依】
