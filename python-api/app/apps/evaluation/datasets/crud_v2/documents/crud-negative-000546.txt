2小时27分！68岁周润发征服半马，他的跑步人生还将继续澎湃新闻记者 马作宇2023-11-20 17:21来源：澎湃新闻∙私·奔>字号刚刚过去的这个周末，68岁的周润发又成了跑圈的一个热门话题。19日，首届港珠澳大桥香港段半程马拉松在中国香港地区举行，这也是首个在港珠澳大桥举办的大型体育赛事。就在8000多名参赛选手中，周润发成为了其中最受关注的一位。2小时27分56秒，周润发以这样的成绩完成了他人生中第一个半程马拉松。周润发参加半马比赛。 本文图片来源网络“发哥好嘢”和很多人迈开步子跑步的原因相似，周润发最初选择跑步也是为了拍电影而减肥，但跑着跑着，跑步就一点点成了他每天生活中不可缺少的一部分。周润发说，他每天跑得很慢，也不会跑得特别远，但这种坚持，让他和身边的人都发生了改变，“我过去的故事是电影，现在的是马拉松。”68岁完成人生首个半马，周润发说“他还有进步的空间”。在本场比赛中，“发哥”穿着黑色跑步服、头戴黑色运动帽，尽管在跑道上穿得一如既往的低调，但是当周润发站上赛场，他就自然而然成了人群中的焦点。从起跑开始，跑道上和跑道两旁就不停地有跑友和观众向他打招呼，并且喊着鼓励的话语，而周润发也满脸带笑地回应着周围的热情。而在冲过终点时，也有不少等待他的跑者大声地喊着“发哥好嘢！（发哥好棒）”。“跑的时候不累，沿途打招呼反而比较累。”在以2小时27分56秒完赛后，周润发这样开玩笑说道，“比赛安排得很不错，路况非常好，成绩也达到比赛目标时限，所以很满意。”周润发和跑友、观众热情地打招呼。“明年我还会考虑参赛”值得一提的是，早在今年2月份，周润发就站上了香港马拉松的跑道，只不过，当时他参加的是10公里的比赛，并且最终以1小时3分58秒完赛，在两万多名10公里参赛者中排名第5103位。而在那场比赛之后，周润发就被问及会不会参与半马或者全马，当时周润发的回答还颇为谨慎，认为10公里就是自己的极限，“迟几年再说，等我再练练，能力还需要加强。”但仅仅10个月时间不到，68岁的周润发就将自己的极限推到了新的高度——就在1个多月前的第28届釜山国际电影节上，获得亚洲电影人奖的周润发就“预告”了自己要参加半马的消息。“看下会不会真的跑死我。”彼时，他还这样开玩笑。而当他真的顺利完赛，周润发似乎又有了新的目标，“我认为自己还有很多进步空间，明年我还会考虑参赛。”不过，从目前周润发的跑步状态和能力来看，他还不会挑战全马，就如他自己所说，“现在的体力无法应付5个小时的运动，两个半小时已是极限。”“跑步是一种享受”不管周润发未来会不会站上全马跑道，但他和跑步的故事已经足够激励人心。过去7年，跑步已经成了周润发人生最重要的一部分。不管到哪里参加活动，他总会跑上几趟。此前在为电影《无双》做宣传期间，63岁的周润发就“宣传做到哪儿就跑到哪儿”，比如在北京做宣传时，他就和团队工作人员在朝阳公园里跑步。久而久之，“野生捕获周润发”也成了跑圈里的一个热词。而自从周润发与跑步结缘，他的这段运动故事就一直充满着温情和正能量。早在拍摄《澳门风暴3》期间，身体有些发福的周润发为了减肥，开始跑步和爬山——每天早上8点，他都会穿着运动服，在大帽山郊野公园跑步。周润发和刘嘉玲（左）一起爬山。最开始，从上山到下山，周润发要花掉将近两个小时。坚持半年多之后，周润发发现自己减掉了27斤，不仅身材变得好了，而且越跑越开心，也就是从那时起，跑步逐渐成了生活必备的一个环节，“每天不跑半个小时决不罢休。”由于依山傍海的地势，香港人喜欢“行山”，周润发也是爬山大军中的一分子。翻看周润发的社交账户，他所分享的不少照片和更新的状态，都是拉着演艺圈的朋友们一起跑步，其中有刘嘉玲、谭咏麟、杜德伟等。“感谢发哥的带领，能这样面对大自然，也是给我自己一个远离闹市喘息的机会。”杜德伟曾经这样感谢周润发带着他一起运动。的确，跑步不在于跑多快或者跑多远，而在于一直坚持，为自己跑出健康和快乐。就如周润发谈到跑步时一直传递的一种理念，“跑步不仅是生活的习惯，还是一种享受。”责任编辑：腾飞校对：刘威澎湃新闻报料：021-962866澎湃新闻，未经授权不得转载+1收藏我要举报#周润发
