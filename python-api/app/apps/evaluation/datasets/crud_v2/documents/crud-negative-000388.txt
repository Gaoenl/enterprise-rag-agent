“只要天气好，基本上每天中午吃完饭，我们就在绿道上散会步。”静安区彭越浦河岸一侧，在附近园区上班的白领们把在绿道散步当成了每天的“必修课”。静安区绿化管理中心介绍，彭越浦东西两侧滨河绿道长约0.86公里，今年在建设静安青年体育公园时增加了0.79公里，变成全长1.65公里的绿道。而根据市绿化和市容管理局今天最新发布的数据，今年完成绿道建设231.26公里，“200公里绿道建设”的年度目标顺利完成，申城绿道总长度达1769.04公里。串联零散城市生态空间，绿道成为散步赏景好去处绿道是一种线性绿色开敞空间，它串联起多样化的自然和人文景观节点，将破碎零散的城市生态系统连接起来，具有休闲健身、生态保护和文化旅游等多元功能。静安区彭越浦楔形绿地绿道就是这样一条串联多个景观和功能的绿道。今年，静安区绿化部门在建设康宁路、交城路东南角的静安青年体育公园时，考虑到公园紧邻已建成的彭越浦西侧绿道的情况，将公园里的步道与滨河绿道打通，增加了0.79公里绿道，使得绿道总长度延伸，并且形成环形，串连园内绿地、景观水系和足球场等空间。原先，滨河绿道没有厕所，这次公园建设时设置了管理房、厕所等，还有移动式饮品售卖车，提供矿泉水、饮料销售，为滨河绿道做功能补充，也为周边人群健身、遛娃遛狗提供了服务便利。春天，绿道两旁樱花、海棠、木本绣球盛开，秋天槭树、枫树、无患子变色，三季有花，四季有景，成为充满生机活力的高品质滨水空间。松江区鼎源路绿道全长1.67公里，利用原有绿地内的园路进行改造，同步对绿道两边绿化进行提升，设有雨水花园，并配置绿化小品、座椅及标识标牌等设施，周边企业员工也爱在绿道上休闲行走，观赏四季风景。闵行区梅陇镇莲花南路两侧（春申塘—向阳路）绿道的建成，也让附近居民有了享受“慢生活”的好去处。这条绿道总长5公里，结合原有地形地貌，进行景观和功能提升。通过种植朴树、乌桕、美国红枫、紫薇、樱花、垂丝海棠及梅花等等色叶和观花植物，形成四季皆有风景的全季绿道景观。沿线还设置了多处休闲景观节点，用心打造具有设计感的艺术廊架以及颜色亮丽的现代感休闲座椅，供往来居民休憩。今年完成230多公里绿道建设，完善服务设施根据今年年初发布的《2023年上海市为民办实事项目建设进度计划表》，今年的绿道建设计划是200公里。市绿化和市容管理局介绍，今年实际完成绿道建设231.26公里，至此，申城绿道总长度达1769.04公里。据介绍，一年来，市、区绿化部门相互配合，做好绿道设计、施工、养护全过程管理，保证绿道选线和设计的合理性，关注绿道施工质量，及时解决建设过程中的困难，建成后重视建成绿道管理维护，发现问题及时整改，有效维护了建成绿道的整体面貌。通过多年建设，绿道之间互相衔接，逐步实现网络化布局，充分联系城乡居民点和生态景观资源，让市民尽享绿色成果。市绿化市容局介绍，未来几年，上海将依托环城生态公园带和五个新城建设、长三角区域一体化发展、重点生态廊道及重点绿地建设等，加快推进绿道建设，到2025年全市绿道总长度达到2000公里左右。其中，五个新城基本建成“一区一环、互联互通”的区级绿道网络，强化社区绿道与市、区级绿道的联通、成网，全面提高绿道服务半径覆盖率，最终让绿道成为生态之道、休闲之道、健康之道。绿道从建设源头上还考虑配套完善的服务设施。社区绿道设置座椅、健身设施等满足居民基本的功能需求。市级和区级绿道增加厕所或者厕所指引、自助售卖机、驿站等满足居民更多需求，甚至还有便民服务箱、充电宝、饮水机等个性化的需求。比如，2021年贯通的苏州河中心城区段规划建设驿站42处，厕所数量70余处，基本250米服务半径内就布局一处，方便市民。举报/反馈
