2023-07-31 09:33，正文：原标题：淮滨县军地联合为二等功臣军人家庭送喜报淮滨县军地联合为二等功臣军人家庭送喜报 河南日报客户端记者 胡巨成 通讯员 周昌友“作为军属，我感受到实实在在的尊崇，心里暖暖的……我会鼓励儿子继续扎根军营、再立新功！”7月28日上午，信阳市淮滨县人武部上校政委郑磊、县退役军人事务局负责同志来到王家岗乡马关村现役军人唐其鸿家中，送上荣立二等功、三等功喜报和奖励金，其父亲唐开环高兴地说。为大力弘扬拥军优属、拥军爱民的优良传统，在“八一”建军节到来前夕，县人武部和县退役军人事务局组成“送喜报”慰问组，联合相关镇（街道）深入开展“为现役立功军人送喜报”活动。伴随着阵阵欢快的锣鼓声，唐其鸿父母收到喜报难掩激动，脸上洋溢着喜悦和自豪。“感谢你们为党、为祖国、为军队培养了这么优秀的人才，向你们表示热烈祝贺！”在现役军人唐其鸿家中，县人武部政委郑磊为唐其鸿父母佩戴“一人立功、全家光荣”绶带，颁发二、三等功喜报，并与及其家人共话强军伟业，致敬军人军属。奖状捧在手中，荣光映在脸上，家属们自豪、喜悦之情溢于言表。“儿子能有这样的成绩，要感谢党和国家的培养，感谢政府对我们家属的关心和帮助，作为军属我们将继续做好孩子的坚强后盾，鼓励孩子再接再厉，为部队和社会作出更大的贡献。”唐其鸿的父亲唐开环说道。唐其鸿现担任西部战区空军某部空中机械技师，入伍以来，安全保障5000多个飞行场次，累计安全飞行3100小时，排除各种故障500余起，积极践行强军实践，先后参加了多项急难险重任务。2020年、2022年因在战训任务中成绩突出，先后荣立三等功各一次，2023年在保障飞行工作中，功绩显著，荣立二等功。“八一节前送喜报活动对军人是激励，对军属是关心，喜报虽小，意义非凡，它承载着军人的至高荣誉，体现着军人家属的奉献付出，彰显着社会的高度认可。”该县人武部领导介绍道，下一步将继续秉持军地协同原则，深入推进军人荣誉体系建设，在全县进一步营造尊崇军人的浓厚氛围，激发广大群众的爱国拥军热情，激励适龄青年积极投身军营、建功立业。返回搜狐，查看更多责任编辑：
