近日，公安部推出公安机关服务保障高质量发展若干措施，西双版纳州公安交管部门积极精准落实，把便利群众、企业办事，促进汽车消费流通的措施，更好服务保障经济社会高质量发展。据了解，目前新措施只在全国部分城市地区试点推行，西双版纳州积极跟进新措施，最大限度优化简化车辆登记流程，减少群众办事排队等候时间，全力提升群众办理业务过程的体验感。西双版纳州公安局交警支队车辆管理所副所长 吴艳：“一是试点私家车新车上牌免查验。西双版纳虽然不是试点城市，但是只要是出厂时已查验的车辆，到窗口办理注册登记时均免予交验机动车，也就是办理注册登记时不用再查验机动车，更加便利群众办理新车登记。二是推行摩托车登记省内一证通办。也就是机动车所有人身份证地址是云南省内的，在省内任意地方异地办理摩托车注册登记、转让登记、住所迁入的情况，申请人只需要提交居民身份证，无需再提交暂住地居住证明，进一步简化群众办事手续，西双版纳已于8月21日开始执行该项措施。三是便利二手车交易和出口登记，确保便利二手车交易登记等已出台政策落地见效。比如二手小客车转让登记‘一证通办’，即2023年6月1日起，已注册登记的非营运小微型载客汽车，在办理转让登记、住所迁入、共同所有人变更登记业务时，只需要提交居民身份证，无需再提交暂住地居住证明。”除了认真落实新措施外，交警部门也在同步推进多项便民交管措施，不断优化业务办理流程，缩小服务半径。从提升公安交管服务的“小切口”，做好服务群众出行的“大文章”，让人民群众有更多的获得感、幸福感、安全感。“主动适应农村交通发展新形势，着力提升县乡全覆盖交管服务。积极推进交管业务向大队、中队及登记服务站延伸下放，同时优化摩托车考试组织工作，继续推进摩托车送考下乡服务，方便群众就近就地办理车驾管业务。简化优化机动车登记程序，更好促进汽车消费流通。在持续推进‘放管服’改革措施的同时，我们也会加强对大队、中队及登记服务站的业务监管工作，对发现违规查验、违规考试的严格追究责任；情节严重的按规定暂停或接管业务。”吴艳介绍说。请注意大家办理相关业务时，请注意提前准备和携带好相关资料，居民身份证需要原件。若不清楚流程和所需资料，可以在周一至周六的工作时间段，拨打车管所咨询电话0691-2126770、0691-2585129进行咨询。记者 乔得高 实习记者 谢雨薇 报道原标题：《【作风革命效能革命在西双版纳】西双版纳州积极落实公安部若干措施 持续优化机动车登记服务》阅读原文
