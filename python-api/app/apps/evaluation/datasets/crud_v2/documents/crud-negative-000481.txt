http://www.gd.chinanews.com    2023年08月15日 22:39    来源：中国新闻网，正文：【港澳台专线】首届穗港澳影视产业项目对接会在广州开幕中新社广州8月15日电 (记者 程景伟)为期三天的首届穗港澳影视产业项目对接会15日在广州开幕，主题分享会、专场推介、作品展映、项目签约、实地考察等一系列活动接连推出，推动开创穗港澳影视产业合作新局面。开幕式上，来自香港、澳门、广州三地共52家影视机构、行业协会及重点网络平台相关负责人参会，共同发出《加强穗港澳影视产业协作倡议书》。现场推介了电视剧《我在湾区等你来》《江海情》以及湾区题材纪录片等重点项目。以“映见广州”为主题的穗港澳影视作品展映活动当晚在广州举行，共有16家影视机构的36部作品参与展映。其中，电影《暗杀风暴》将于8月18日上映。据介绍，将于8月16日举办的穗港澳影视产业推介大会上，港澳影视专场推介、广州影视专场推介将陆续登场，并将举办影视创作生产创新与机遇主题分享会。8月17日则将举行穗港澳影视产业项目签约仪式。“穗港澳三地在影视行业方面的深度融合，形成协同效应，将拓宽中国电影的外销市场和区域融资渠道的深度和宽度，形成强势的国际影响力。”香港电影发展局主席王英伟称，穗港澳影视行业发展，需要在人才培训、影片质量、投资力度以及拓展市场观众这四个方向努力。香港电影制作发行协会理事长黄百鸣称，香港相对较早接入国际电影市场，而广州的文化积淀能够为电影继续繁荣提供动力。《粤港澳大湾区发展规划纲要》实施以来，一大批影视剧目在广州立项，英皇娱乐大湾区总部等多家头部企业相继落户广州。广州市文化广电旅游局局长刘瑜梅称，广州研究拟制《广州市促进电视和网络剧片创作生产实施办法》，力求形成产业相对完善、结构布局合理、整体技术水平先进、经济效益显著的影视产业发展格局。(完)
