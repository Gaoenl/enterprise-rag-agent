2023-07-22 18:18，正文：1905电影网讯 据灯塔专业版实时数据显示，截至7月22日11时54分，2023年暑期档（6月1日-8月31日）总票房（含预售）突破100亿，刷新中国影史暑期档票房最快破100亿纪录。这也是继2019年（177.78亿）后，暑期档票房重回百亿元时代。暂列2023暑期档前三位的电影分别为《消失的她》（34.47亿）、《八角笼中》（17.55亿）、《长安三万里》（10.04亿）。这三部影片不仅收获了高票房，也收获了超高口碑，高质量的国产影片激发电影市场活力的同时，也带动了观影热潮。位列暑期档第四至第十的电影分别是《变形金刚：超能勇士崛起》（6.5亿）、《我爱你！》（4.25亿）、《蜘蛛侠：纵横宇宙》（3.55亿）、《扫毒3：人在天涯》（2.77亿）、《碟中谍7：致命清算（上）》（2.7亿）、《茶啊二中》（2.12亿）、《闪电侠》（1.85亿）。暑期档过半，电影市场后半程仍将持续发力。截至目前，还有30余部影片等待上映，包括纪录电影《雪豹和她的朋友们》，黄渤、王一博主演励志题材电影《热烈》，吴京、杰森·斯坦森的深海巨兽影片《巨齿鲨2》，张艺兴、金晨主演的犯罪影片《孤注一掷》等都获得较高关注度。其中，《热烈》目前点映及预售总票房已突破2000万元，《巨齿鲨2》吸引超70万观众“想看”。2023暑期档票房将再创新高！
