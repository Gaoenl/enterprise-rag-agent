2023年07月27日 15:38:05，正文：四川新闻网-首屏新闻成都7月27日讯（记者 高诗嘉 周琼 许雨珂 摄影报道）成都第31届世界大学生夏季运动会（以下简称“成都大运会”）开幕在即。作为成都大运会期间媒体记者们的“大本营”，主媒体中心提供了办公、语言、交通、餐饮等完善的功能设施和服务保障。成都大运会主媒体中心媒体工作间主媒体中心由主新闻中心和国际广播中心组合而成，而主新闻中心主要包含媒体工作间、新闻发布厅、媒体采访间等区域。从西门进入主媒体中心，左侧便是媒体工作间，整个区域采用蓝绿白三色搭配，宽敞明亮，共有两台由15平方LED组成的电视墙和42台壁挂电视机，可实时直播开闭幕式、竞赛实况等，让记者们能够瞬间“跑”遍赛场、获取一线动态。同时，这里不仅为文字和摄影记者们提供了340个工作位置，每个工位上都配有充电和网线接口，还贴心地准备了竞赛信息查询、储物柜租用、资料打印等服务。记者发现，一旁的手绘展板上公布着每日天气、交通、餐饮、赛程等实用信息。媒体工作间LED大屏媒体工作间展板摄影记者工作区新闻发布厅不远处的新闻发布厅分为熊猫厅和银杏厅，在这“一大一小”两间发布厅的门口分别摆放着呆萌“蓉宝”和金灿灿的银杏，这里将举行每日例行新闻发布会、竞赛相关发布会等。据介绍，熊猫厅可容纳约220人同时参会，配有同声传译间。赛时，这里还将设有24小时运行服务台。位于4-5楼的国际广播中心则是大运会广播电视公用信号汇集、制作、分发的场所，向超过20家海外持权转播商及35家境内持权转播商提供转播服务，届时，大运会开闭幕式及各比赛项目的电视公用信号从这里向全球分发，充满青春风采的“大运故事”也将飞往世界各地。点击图片查看更多精彩内容本网（平台）所刊载内容之知识产权为四川新闻网传媒（集团）股份有限公司及/或相关权利人专属所有或持有。未经许可，禁止进行转载、摘编、复制及建立镜像等任何使用。
