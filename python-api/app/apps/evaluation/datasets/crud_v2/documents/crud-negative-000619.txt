2023-08-11 09:22，正文：原标题：库尔勒市梨香街道：健康义诊进小区中新网新疆新闻8月10日电（李娟娟汪亚）近日，库尔勒市梨香街道凌达社区残联联合凌达社区卫生服务站、医家医健康驿站工作人员开展关爱老残一体，健康义诊进小区送健康活动，进一步满足辖区老年、残疾群体的健康需求，让居民群众在家门口享受到便捷的医疗服务。活动现场，前来咨询的居民络绎不绝。医务人员为他们免费开展量血压、测血糖等义诊服务，耐心解答老人们提出的健康问题、指导残疾居民及一些老年人自我预防及自我保健生活小常识，并有针对性地提出安全用药及生活方式的健康指导，叮嘱他们在生活中注意合理膳食、科学锻炼身体，做到对疾病早预防、早发现、早治疗。社区干部为现场的居民协助退休资格认证、宣传全民免费体检、高温天气安全用电用气、燃气阻断器报警等惠民政策解答服务。“我平时腿脚不好，走不了远路，社区经常组织为我们测量血糖血压，把义诊带到家门口，还这么细心地给我看，和我讲健康常识，谢谢你们。”居民杨建国说。今后，梨香街道凌达社区将继续融合辖区服务资源，让居民不出小区就可以享受到便捷的健康服务，把关心关爱送至居民身边，切实发挥基层党组织凝聚力，切实提升辖区居民的幸福感。返回搜狐，查看更多责任编辑：
