大洋网讯 北京时间2023年8月2日,最新的《财富》世界500强排行榜全球同步发布。今年《财富》世界500强排行榜企业的营业收入总和约为41万亿美元,比上年上涨8.4%。进入排行榜的门槛(最低销售收入)也从286亿美元跃升至309亿美元。广州共有6家企业上榜《财富》世界500强。而广东范围内,首次上榜的有广新控股、广州工控、立讯精密三家公司。随着广州工控的首次上榜,广州市属国企中世界500强企业的数量也由3家增至4家。利润榜前五,科技企业占三席沃尔玛连续第十年成为全球最大公司。沙特阿美首次上升至第二位。中国的国家电网公司继续位列第三。排在第四和第五位的分别是亚马逊和中国石油。受全球经济下行影响,今年所有上榜公司的净利润总和同比减少6.5%,约为2.9万亿美元。然而,在世界500强整体利润下降的趋势下,仍有很多公司实现了利润大幅增长。在盈利方面,沙特阿美利润增长了51%,以约1590亿美元的利润位居利润榜榜首。利润榜前五位中有三家科技企业:苹果公司位居利润榜第二位,利润超过998亿美元;微软利润同比大增114亿美元,以727亿美元的利润上升至利润榜第三位;谷歌母公司Alphabet和美国邮政分列利润榜第四、第五位。利润榜前十位中的两家中国公司分别是中国工商银行和中国建设银行。暨南大学经济学院教授、博士生导师,自贸区研究院副院长谢宝剑认为,从全球来看,可以看到,在当前全球不确定性因素增加的时代,实体经济企业异军突起,推动实体经济的发展非常重要,是国内乃至全球经济向好发展的一个重要支撑。从全球产业链、供应链的角度来看,业务稳定、拥有自主核心技术的企业更具增长潜力。此外还可以看到,科技创新与人才真正成了创新驱动高质量发展的核心关键要素。广州国企发挥领头羊和火车头作用聚焦广东,19家粤企上榜。其中,广东省广新控股集团有限公司(下称“广新控股”)、广州工业投资控股集团有限公司(下称“广州工控”)、立讯精密工业股份有限公司(下称“立讯精密”)三家公司首次上榜2023年《财富》世界500强。具体来看,广新控股以353.68亿美元的营收位居第427名;广州工控以365.88亿美元的营收位居414位。在榜单细分类别排名中,广州工控位列“工业机械”类型企业中第4位;立讯精密以318.17亿美元的营收位居479名。值得注意的是,此次伴随广州工控的首次上榜,广州市属国企中世界500强企业的数量也从3家增加至4家。2023年《财富》世界500强榜单显示,广州汽车工业集团有限公司(下称“广汽集团”)、广州市建筑集团有限公司、广州工控、广州医药集团有限公司(下称“广药集团”)四家广州市属国企分别以773.44亿美元、392.57亿美元、365.88亿美元、353.83亿美元的营业收入,位列榜单165名、380名、414名、426名。其中,广汽集团排名上升21位,广药集团排名上升41位。“广州市属国企中,世界500强企业增至4家,对广州意义重大。”广州市社会科学院副院长、研究员尹涛分析认为,一方面,印证了广州国企改革三年行动非常成功,广州国企的影响力近年来在不断增强;另一方面,此次广州工控的上榜,与当前广州市提出的加快构建以实体经济为支撑的现代化产业体系,坚持产业第一、制造业立市的战略非常吻合,为建立新的产业体系提供了很好的支撑,大大增强了广州发展的信心。“此次广州工控进入世界500强,说明广州国有企业在推动实体经济发展方面,主责主业越来越清晰,支撑实体经济高质量发展的作用越来越明显。国有企业改革的成效,对社会经济贡献越来越大。”谢宝剑表示,从支撑现代产业体系高质量发展的角度来看,广州国企正充分发挥着领头羊和火车头的作用。文/广州日报全媒体记者赵方圆[ 编辑: 李鑫 ]
