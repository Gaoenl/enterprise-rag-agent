周四(12月9日)，现货黄金承压，因美元指数重新上涨，市场从早期数据中看到了乐观情绪，这些数据暗示新冠病毒Omicron变体可能不像人们担心的那样糟糕。但在美国11月通胀数据公布前，市场氛围偏谨慎。北京时间19:45，现货黄金下跌0.10%至1781.24美元/盎司；COMEX期金主力合约下跌0.20%至1781.9美元/盎司；美元指数上涨0.23%至96.116。接种三剂，防Omicron有效BioNTech和辉瑞(Pfizer)周三(12月8日)表示，实验室试验结果显示，接种三剂其新冠疫苗能够对新的Omicron变种起到中和作用，这是一个早期信号，表明加强针可能是预防感染该变种的关键。两家公司还表示，即便接种两剂疫苗产生的中和抗体明显要少，但仍可预防发展成重症。如果需要的话，它们可能会在2022年3月交付专门针对Omicron变种的升级版疫苗。BioNTech和辉瑞是最先就其疫苗针对Omicron的有效性发表官方声明的疫苗制造商。预计莫德纳、强生以及其他相关公司将在几周内公布疫苗针对新变种有效性的数据。支付公司Caxton的高级分析师Michael Brown在一份报告中表示示，“人们对Omicron的担忧似乎略有缓解，尤其是越来越多的数据表明，尽管未经证实，新变种造成的症状比之前想象的要轻。”市场上周被新冠变异病毒Omicron的消息搅乱，金价暂停了下行走势。但此后，有迹象表明最坏情况可能不会出现，感染者只出现了轻微的症状，金价也很难进一步走高。抗疫措施仍有必要世界卫生组织(WHO)周三表示，已有57个国家通报Omicron变体感染病例，包括津巴布韦在内的南部非洲国家的新冠病例在增加，随着病毒的传播，需要住院的病人数量可能会增加。英国首相约翰逊周三在英格兰实施更严格的新冠限制措施，要求人们在家工作、在公共场所戴口罩、使用疫苗通行证，以减缓Omicron变种的传播。在公共交通工具和商店重新使用口罩等措施已经在实施，WHO在流行病学周报中称，需要更多数据来评估Omicron变体引起的疾病的严重性，以及其变异是否可能降低疫苗产生的免疫力保护，“即使严重程度与Delta变体相同甚至可能更低，但如果更多的人被感染，预计住院人数将增加，并且在病例发生率增加和死亡发生率增加之间会有一个时间差，”汇丰银行全球外汇研究主管Paul Mackel说：“市场一会儿非常‘担心病毒’，一会儿又‘不是很担心病毒’了，我认为一段时间内还摆脱不了这样的情况，被Omicron消息牵着走的可能性很高，这让人非常困惑，也让走势相当不稳。”通胀高位运行料促使美联储更鹰派交易员关注焦点转向周五即将公布的美国11月通胀数据。市场调查预测，美国11月CPI年率料同比上升6.8%，核心CPI年率料同比上升4.9%，继续改写逾三十年新高。数据可能影响美联储在12月14-15日会议上的政策决定。澳新银行(ANZ)分析师表示，在Omicron相关消息持续不断涌现之际，影响市场走势的还有美国2022年加息预期，“美联储加快缩减刺激几乎被视为定局，但一个强劲的通胀数字可能会提高明年第二季度加息的预期。”ING首席国际经济学家JamesKnightley表示：“我们目前预测美联储明年9月和12月加息，但如果经济不会因为疫情进入新的黑暗时期，我们认为明年三次加息的可能性要大得多。”美银证券的全球经济学家Ethan Harris称：“我们预计美联储明年6月首次加息，但最早有可能3月就动手。我们希望等待看到更多数据，包括Omicron对经济的影响。”高盛经济学家Joseph Briggs指出：“旅游等行业需求减少可能会在短期内产生通货紧缩的影响，但之前的几轮疫情表明，随着需求复苏，这种压力只是暂时且逆转的。若Omicron毒株造成的供应链进一步中断或劳工返岗进一步推迟，或者新冠疫情结束，全球经济迎来强劲的周期性复苏，消费者释放被压抑的需求，都会产生更持久的通胀上行压力，美联储2022年加快升息的步伐值得期待，不排除美指重返100关口的可能。现货黄金或很快开启新一波跌势小时图上看，金价处于自1762美元开启的反弹(B)浪中，须尽快站稳(A)浪23.6%斐波那契回档位1789美元上方，才有望进一步上摸(A)浪38.2%斐波那契回档位1806美元；反之金价将重新转跌。(A)浪和(B)浪都是自1877美元开启的下行((Z))浪的子浪。日线图上看，金价仍运行在((Z))浪38.2%目标位1787美元附近，后市料跌向61.8%目标位1877美元。（责任编辑：陈状 ）
