2023-08-16 10:13，正文：来源：人民网－黑龙江频道中俄青年经贸发展大会签约仪式现场。人民网 尚城摄人民网黑河8月16日电 (尚城)为深化中俄青年务实交流与合作，助力中俄经济贸易发展，8月15日，由中华全国青年联合会指导、中国国际青年交流中心主办的中俄青年经贸发展大会在黑龙江省黑河市举办。据介绍，此次大会旨在推动中俄两国经贸合作“量质并进”，以务实合作的丰硕成果拉紧两国青年团结纽带，助力中俄青年锚定互补合作的新领域，不断深化装备制造、数字经济、农业产品、交通物流等领域合作，为两国务实合作增添新内容、新亮点、新活力。同时，此次大会呼吁中俄青年企业家积极拓展交流成果，确立长效合作机制，深入打造中俄青年经贸发展枢纽平台，更好助推中俄携手繁荣、共同振兴。会上，中国国际青年交流中心发布了“中俄青年创业孵化器”交流项目最佳实践案例征集计划，以征集中俄青年务实交流合作的典型示范项目，展示中俄青年企业家在促进中俄务实合作中的智慧和力量。围绕“开放发展、青创未来”的主题，此次大会设置了中俄经贸合作推介、主旨发言、洽谈、考察参观等环节，中俄青年企业家在农业、能源、文旅、数字经济等领域进行了多层次、多方面的交流互动，深化经贸互利合作战略，推进多领域投资合作，大会现场成功签约项目12个，签约金额38.6亿元。与黑河牵手，同世界交流。作为2023年“中俄青年创业孵化器”交流项目框架中的重要内容，此次大会进一步加强中俄青年交流互动，推动中俄两国和地方间加强经贸互通，为中俄两国携手发展、合作共赢提供了新的重要载体和坚韧纽带。
