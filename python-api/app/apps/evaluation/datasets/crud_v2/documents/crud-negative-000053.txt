2023-08-17，正文：近期以来，农民就业增收频迎利好。今年6月，中国人民银行、金融监管总局、中国证监会、财政部、农业农村部联合发布的《关于金融支持全面推进乡村振兴 加快建设农业强国的指导意见》要求，促进农民创业就业增收，持续加大对返乡入乡创业园、农村创业孵化实训基地建设信贷资源投入，深化银企对接，带动更多农民工、灵活就业人员等重点群体创业就业。8月初，农业农村部印发《关于进一步做好促进脱贫人口持续增收工作的通知》，要求推动脱贫人口稳岗就业，提高脱贫人口工资性收，帮扶产业提质增效，稳定脱贫人口经营性收入。8月中旬，商务部等9部门联合发布的《县域商业三年行动计划（2023-2025年）》确保到2025年建立起县域统筹，以县城为中心、乡镇为重点、村为基础的县域商业体系，促进农民增收和消费提质良性循环。业内人士表示，今年以来各地区各部门把促进农民增收摆在重要位置，多措并举发展产业、稳定就业、促进创业，拓宽农民增收渠道。国家统计局数据显示，上半年，农村居民人均可支配收入10551元，同比名义增长7.8%，实际增长7.2%。在山东菏泽，甄城县左营镇孙沙窝村积极引进康恒工艺品加工厂落地，孙沙窝村及周边村庄的留守妇女找到了就业岗位。随着今年效益持续向好，生产规模不断扩大，康恒工艺品加工厂已带动40多名村民实现了稳就业；石庙新村引进云晟户外用品有限公司生产车间，为周边200多名农民提供了稳定的收入来源。 在广西南宁，乡村振兴学院在南宁职业技术学院成立，通过深度整合政、校、企以及社会资源的方式，组织开展多层次的农村电商人才、直播带货人才培训培育，帮助乡村手工业者、传统艺人进行工艺提升，传承发展传统技艺，做好脱贫人口培训就业工作，不断拓宽农民就业创业渠道。在黑龙江齐齐哈尔，讷河市老莱镇拓宽各个乡村的万寿菊产业，引导全镇多个村的村民利用小园、空闲地发展轻劳力、低成本、高产量的万寿菊种植，全镇种植面积达200多亩，有力促进了农业增效、农民增收。也有业内人士认为，今年随着我国乡村振兴战略深入实施，各地对乡村建设持续加大投入，直接带来了村容村貌和乡村基础设施的改善，农业的休闲、旅游、教育等多元功能被越来越多地挖掘出来，为乡村带来了发展活力，也为农民增收提供了机遇。此外，针对农民的各项补贴政策也呈现越来越多、越来越好的趋势，将发挥重要的带动增收作用。分享让更多人看到
