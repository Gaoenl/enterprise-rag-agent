2023-08-18 21:46，正文：原标题：“益企荟企业基金会和志愿服务发展”沙龙在京举办8月17日，由和众泽益、德勤公益基金会、基金会中心网、志鲲基金会联合发起的“益企荟ESG背景下企业基金会和志愿服务发展”沙龙在北京举办。ESG 即环境、社会和治理三个单词首字母的缩写，ESG 指标分别从环境、社会以及公司治理角度，来衡量企业发展的可持续性。本次沙龙围绕“ESG背景下企业基金会和志愿服务发展”主题，基金会中心网的秘书长吕全斌分享了中国企业基金会的发展现状与趋势，并给出具体的行动建议。德勤公益基金会副秘书长申雅静着重介绍了基金会的公益合作策略和志愿服务体系；北京字节跳动公益基金会副秘书长秦楠介绍了在关爱困难群体、参与突发事件和助力公益数字化三个方面创新的可持续解决方案；北京蔚蓝公益基金会理事长李虹详细介绍了基金会的公益情怀和社会贡献；志鲲基金会秘书长艾晓宇讲述了公益项目如何动员企业及企业基金会参与。圆桌讨论环节，上述四位嘉宾就企业基金会该如何定位自己，是否必须依附在企业，企业基金会和志愿服务的关系是什么以及如何能实现协调发展等问题展开了激烈而精彩的讨论。和众泽益创始人、北京林业大学经济管理学院副教授王忠平博士围绕“企业基金会是面向未来的制度创新”议题进行总结发言，他指出企业基金会是企业可持续发展战略的重要实现途径；企业基金会应有独特的使命和远景，形成品牌合力；同时企业基金会应为产品和品牌塑造独特的价值，构建内部逻辑关系。多位参会人员表示，这次沙龙为企业志愿服务与企业基金会的创新发展提供创新思路，为企业公益/志愿服务的可持续发展贡献力量。文/北京青年报记者 李佳编辑/叶婉返回搜狐，查看更多责任编辑：
