2023-08-11 13:07，正文：原标题：公司出三只“搬仓鼠” 三个月骗取530余万元，警方快速破案利用贷款企业管理审批漏洞，员工联手陆续诈骗公司、客户款项累计530余万元。在近日夏季治安打击整治行动中，徐汇警方就破获这样一起诈骗案，3名犯罪嫌疑人均被依法刑事拘留。近日，市民陈先生来到虹梅派出所报案称，他是某二手汽车销售公司的负责人，为了方便自己公司的业务开展，与某贷款企业签订合作协议，由该企业负责本公司的车辆抵押、贷款购车等资金往来业务。近三个月来，公司在核对账目时发现该贷款企业发送的资金“打入”信息与银行方面的入账金额有较大出入。接报后，派出所立即会同分局网安支队前往该贷款企业开展侦查，经过多方查证，掌握汇总了大量确凿的证据后，成功锁定了贷款企业内部员工杨某等3名犯罪嫌疑人，并将其抓捕归案。到案后，犯罪嫌疑人杨某、陆某、浦某三人均对自己的犯罪事实供认不讳。杨某交代，三人在多次聚餐和聊天过程中，密谋利用职务便利骗取贷款企业以及客户的钱款。其中陆某、浦某利用贷款业务员的身份，在二手汽车销售、客户向其申请车辆抵押和贷款购车的过程中，以便于后续手续操作为由，要求客户把钱款打入个人账户。在将部分钱款转入企业账户后，其余钱款被三人均分。而杨某利用自己有权操作企业信息平台的便利，多次修改发给陈先生公司的转账信息，试图掩盖犯罪行为。三个月内，三人已累计作案50余起，造成公司和客户530余万元的损失。目前，警方已追回部分赃款，三名犯罪嫌疑人均因涉嫌诈骗被依法刑事拘留，案件仍在进一步调查中。警方提示，企事业单位应加强内部管理，完善企业内部的规章制度，定期开展内部风险自查，防止类似隐患爆发。作者：周辰通讯员：陈勇编辑：占悦*文汇独家稿件，转载请注明出处。返回搜狐，查看更多责任编辑：
