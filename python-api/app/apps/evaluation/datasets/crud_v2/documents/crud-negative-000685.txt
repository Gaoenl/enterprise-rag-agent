2023-08-01，正文：在今年6月18日举办的2023年江苏省健美健身锦标赛上，女运动员小阳（化名）因质疑评委打分的公平性，扔高跟鞋怒砸评委。几天后，江苏省健身健美运动协会（以下简称“江苏健协”）表示，赛事主办单位联合成立调查组，依规依纪调查比赛中的赛风赛纪问题，对违规情况进行严肃处理。7月31日，极目新闻（报料邮箱：jimu1701@163.com）记者从江苏健协获悉，此事已有调查结果。经查，未发现裁判不公情况。经专家评估，评分制度符合规定，评分统计过程及结果符合相关规定。经研究决定，两年内禁止该运动员参加由省健身健美运动协会举办的健身健美赛事，责成其所在市健身健美运动协会对其严肃批评教育。小阳表示，她已注意到调查结果，但她对该结果并不认可，不想过多评价，今后大概率也不会参加类似的赛事，希望此类赛事评判机制更健全，保证公平公正。女运动员将鞋扔向裁判席（视频截图）女运动员怀疑被“吹黑哨”扔鞋砸评委据极目新闻此前报道，2023年江苏省健美健身锦标赛由江苏省社会体育管理中心、江苏省健身健美运动协会、连云港市体育局共同主办，于6月16日至19日在连云港市举行。大赛共设传统健美、古典健美、男子健体、男子健身模特、女子健身比基尼、女子形体、女子健身模特等7个项目24个组别，全省14支代表队200余名运动员参赛。“扔鞋怒砸评委”迅速引发关注和热议。6月22日，江苏健协发布通报称，6月18日下午，在赛事全场冠军总决赛谢幕环节，出现某运动员因不满比赛成绩，在舞台上丢鞋砸裁判一事。主办单位高度重视，已联合成立调查组开展工作，将依规依纪调查比赛中的赛风赛纪问题，对违规情况进行严肃处理。记者注意到，网传小阳之所以扔鞋，是因为她疑似被主评委石某“潜规则”却未如愿进入决赛，从而认为比赛有黑幕。
