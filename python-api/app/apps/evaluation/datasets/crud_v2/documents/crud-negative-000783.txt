沈阳市沈河区挖掘皇城文旅资源,尝试把故宫和周边的商业区建设成新的经济增长点,以提高文化自信和打造东北经济发展新引擎。“我们拥有沈阳乃至东北最丰富的人文、历史资源和区位优势,这也是发展文化产业的主要资源和信心。”沈阳市沈河区区委书记王忠昆说。沈河区是沈阳市的中心城区,总面积58平方公里,是沈阳市商贸中心、金融中心、文化中心,旅游胜地和开放门户,是全国城区中第一个国家级可持续发展实验区。位于沈河区的故宫,是中国仅存的两座皇家建筑博物馆之一。虽然面积只是北京故宫的十二分之一,但却是中国唯一的、用汉族建筑表达游牧民族文化的皇家宫殿群。在世界文化和建筑历史上有独特地位。在2004年,沈阳故宫和两座皇陵一起被列入世界文化遗产目录。沈阳市文化和旅游局数据显示,过去3年沈阳故宫游客数量持续增长,2018年接待游客201.03万人,已经成为沈阳市主要名片。从沈河区发展起来的中街冰点,已经成为了全国冰激凌电商第一名。产品已经走出沈阳,成为全国知名品牌。伴随国际国内经济形势的变化,以及电商的兴起,沈河区传统的支柱产业面临日益严峻的挑战,亟需寻找新的经济增长点。与此同时,中央政府出台建设小康社会的要求,其中对文化产业增加值占GDP的比重有明确要求。沈河区又以独特的人文、历史资源和区位优势,成为沈阳市发展文化产业的主要支点。专家建议,伴随消费升级,故宫已经成为沈阳这个工业城市新亮点。城市管理者应该把构建新的经济增长点与建立文化自信结合起来。“沈阳市的主要文化就是由清初努尔哈赤父子和民国的张作霖父子定义的.这两对父子以及相关的人物,在沈河区留下了丰富的历史、文化、建筑、民俗的财富。这既是了解沈阳的钥匙,更是打造文化产业的基础。” 知名东北文化学者初国卿说。王忠昆书记介绍,沈河区正在全力挖掘文化资源,把文化产业建设成新的经济增长引擎,助力东北振兴。主要措施包括建设故宫5A级景区、建设中街全国高品质商业步行街等。除了皇城以外,沈河区对全区89处历史文化建筑进行了调查,确认能够再改造使用的22处。区委区政府正在对这22处进行调研,集中开展文化产业建设。(中国日报辽宁记者站)
