【CNMO新闻】近日，有德国媒体报道，欧盟委员会正在推动排除中国5G供应商，然而该委员会自己的统计数据显示，这显然会对网络扩展造成损害。一份统计数据评估报告显示，一些早期正式或非正式将中国5G供应商排除在移动通信网络扩展之外的国家，在27个欧盟成员国的数字化比较排名中大幅落后。5G　　具体来看，在这27个欧盟国家中，有5个国家在5G网络人口覆盖率排名中垫底。这些国家很早就将中国设备供应商华为和中兴排除在外或严格限制当地5G网络建设。爱沙尼亚和拉脱维亚的5G网络人口覆盖率分别约为43%和42%，远低于欧盟80%左右的平均水平。比利时和罗马尼亚更落后，分别约为30%和27%，瑞典以略高于20%的人口覆盖率排在所有27个国家的末尾。　　此外，在欧盟委员会的数字经济与社会指数（DESI）中，瑞典在互通性领域的排名从第二(2020年)下降到第九(2022年)，比利时从第6位跌至第27，爱沙尼亚从第14跌至第26，拉脱维亚从第4跌至第20，罗马尼亚从第11跌至第15。　　德媒称，这种排除(中企)的负面影响在英国也很明显。华为最初于2020年1月获得英国批准，但几个月后被排除在英国5G扩展之外。美国网速测试统计公司Ookla今年2月警告称，英国的平均下载速度继续向着相当低的水平缓慢下滑。　　丹麦电信分析师约翰·斯特兰德的市场研究显示，塞浦路斯是唯一一个100%从中国供应商(即华为和中兴通讯)获得5G天线的欧盟国家。在欧盟委员会5G观察报告中，塞浦路斯以100%的5G人口覆盖率位居欧洲第一。　　显然，欧盟一些国家排除中国5G供应商的做法并未带来预期的效果，反而使得这些国家的网络扩展受到影响。举报/反馈
