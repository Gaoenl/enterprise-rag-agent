2023-07-24 07:18，正文：【环球时报驻西班牙特派记者 n颜欢】“西班牙正处于悬崖边上。”“政治新闻网”欧洲版报道称，当地时间23日，选民们将决定这个国家是否会成为欧洲最新一个转向极右的国家，还是会在可预见的未来陷入看守政府的瘫痪状态。据英国广播公司（BBC）报道，这是西班牙现代史上首次在炎热的仲夏举行议会大选，全国约3750万选民将投票决定350个众议院席位和208个参议院席位归属。西班牙举行大选 首相桑切斯到投票站投票（IC photo）据报道，投票于23日9时开始，20时结束，计票结果预计当晚揭晓。西班牙全国共设立2.2万多个投票点。西班牙邮政系统22日发布的统计数据显示，由于许多选民正在度假，约247万人通过邮寄选票投票，法新社称，“这一数字创下了历史新高”。据多家西班牙媒体报道，多轮民意调查和权威人士都认为，由费霍领导的西班牙右翼政党人民党有望在本次选举中获胜，但预计难以达到独立组建政府所需的绝对多数席位。因此，人民党可能与极右翼党派呼声党结盟共同组阁。在2019年举行的议会选举中，西班牙中左翼政党工人社会党由于未能拿到议会绝对多数席位，最终与另一左翼政党“我们能”党组建了现任联合政府。今年5月28日，西班牙全国17个自治区中的12个以及8131个市镇举行地方议会和政府换届选举。在自治区选举中，人民党不仅在马德里和拉里奥哈获得地方议会绝对多数席位，还在巴伦西亚、阿拉贡、巴利阿里群岛、穆尔西亚和坎塔夫里亚成为得票率最高的政党。此外，人民党在市镇选举中以31.5%对28%的总得票率领先工人社会党。西班牙首相桑切斯在次日发表电视讲话说，作为工人社会党总书记，他本人对地方选举失利的结果负责，并决定将原定于12月的大选提前至7月23日举行。据法新社报道，呼声党于2013年从人民党内部分裂出来。对以温和派形象著称的费霍而言，与极右翼联手是个“真正的挑战”。呼声党领导人阿巴斯卡尔告诉人民党，若想获得呼声党的支持，在组建的政府中必须要有该党的一席之地。报道称，这意味着自1975年佛朗哥独裁统治结束以来，将首次有极右翼党派加入西班牙政府执政。
