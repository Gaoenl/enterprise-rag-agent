2023-08-07 19:33:43，正文：室外骄阳似火，室内共绘清凉。八月初的夏日午后，华师大附属卢湾辅读实验学校与黄浦区巨鹿路第一小学的师生携手相约南昌路137号心灯•画室，“点亮心灯，与爱同行”艺术系列活动之普特融合——共绘夏日清凉涂鸦创作正在火热进行中。艺术插画师李老师和上大美术学院油画系大二在读的吴同学两位专业的志愿者助力两校孩子们进行绘画创作，并耐心地引导着孩子们展开联想，启发了大家的创作思维。孩子们兴致勃勃地选择了自己心仪的扇面造型后，纷纷拿起画笔在扇面上作画，有的画大西瓜、有的画冰淇淋、有的画树木，给小小的绘画空间带来了阵阵清凉。绘画创作期间，两校学生不仅在作画过程中进行良好的互动交流，还在活动中互相增进了彼此友谊，整个画室氛围和乐融融。融合绘画活动结束后，大家来到南昌路沿线的137号、139号等处的艺术文化公益空间，既参观了华师大附属卢湾辅读实验学校学生们的系列作品，又体验了新媒体装置艺术带来的视觉冲击，感受着城市空间和不同艺术元素的相互交融，与自身所在的城市建立了更密切的联系。艺术是表达，也是疗愈。通过本次融合活动，两校的学生丰富了彼此的暑假生活，孩子们在心灵上、情感上和思想上获得了满足感、成就感和自信心，也促进了普校和特校之间的融合艺术交流。“心灯▪画室”艺术展是上海特殊关爱基金会在南昌路137号设立的展示智障人士艺术作品和衍生品的窗口，首轮展出作品是由华东师范大学附属卢湾辅读实验学校的特教学生提供。艺术展在南昌路137号持续展出，感兴趣的市民可以前往现场参观。
