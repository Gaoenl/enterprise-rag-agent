原标题:快乐暑假,从文化宫出发!银川市工人文化宫2023年暑期班于7月3日开课为丰富全市职工子女文化活动,营造快乐、健康的成长氛围,推动关心下一代工作高质量发展,切实增强服务职工、服务社会的职能,银川市工人文化宫2023年“七彩夏日·童心护航”职工子女暑期培训班将于7月3日开课。银川市工人文化宫现面向全市职工开设暑期职工子女文体艺术培训班,旨在全面提升职工子女综合素养,倡导德智体美劳全面发展,为广大职工子女提供定制化服务。课程内容涵盖声乐、舞蹈健身、文化、书画等类别,开设17门课程,已有370个孩子选择在文化宫接受培训。自报名以来,暑期培训班受到了广大职工和职工子女的热烈欢迎。首期暑期班将为孩子们提供良好的学习环境和安全、规范、科学的管理服务。教室宽敞明亮,环境清新优雅,设施齐全,训练场地专业化。一楼的图书馆365天免费向孩子们开放,提供了学习和阅读的场所。银川市工人文化宫将为广大职工子女提供一个学习知识、寓教于乐的综合平台,让孩子们在暑期拓展兴趣、相互交流、团结协作、健康成长,在文化宫度过一个愉快而又难忘的暑假。来源:银川市工人文化宫 朱瑞编辑:薛艺审核:刘斌返回搜狐,查看更多责任编辑:
