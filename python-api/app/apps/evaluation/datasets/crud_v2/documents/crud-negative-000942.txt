2023-08-02 16:30，正文：原标题：特朗普再遭刑事指控，美媒：小特朗普发声提到数次指控时机“可疑”【环球网报道】当地时间8月1日，美国前总统特朗普在美国司法部特别检察官调查中因涉嫌“试图推翻2020年总统选举结果”而受到刑事指控。据美国《新闻周刊》网站报道，特朗普的长子小特朗普当天晚些时候在推特上发帖，提到特朗普今年数次受到指控的时机“可疑”——都正好发生在拜登家族相关丑闻之后一天。对此，小特朗普称，美国已变成一个“香蕉共和国”。报道称，小特朗普当天在推特上分享的一张图显示：6月7日，美国联邦调查局向国会提交文件，指控拜登家族从乌克兰天然气公司布里斯马收受1000 万美元贿赂；6月8日，美国司法部指派的特别检察官杰克·史密斯就“海湖庄园涉密文件”一事起诉特朗普。7月26日，拜登的儿子亨特·拜登拒绝承认此前达成的一项认罪协议；7月27日，杰克·史密斯针对特朗普涉“不当处理涉密文件”案提出新指控。7月31日，亨特·拜登以前的商业伙伴向国会作证称，拜登曾与其儿子的商业伙伴通话超过20次，布里斯马还向这些商业伙伴施压；8月1日，杰克·史密斯就“国会山骚乱”事件对特朗普提出指控。小特朗普在给这张图的配文中称，“有人注意到这里的模式吗？每次拜登犯罪家族发生糟糕事件的第二天，拜登政府中的腐败官员就会对特朗普提出指控。对于拜登的儿辈和孙辈从我们敌人那里获得数百万美元，他们不去调查，而是对他们的政治敌人穷追猛打，知道一些媒体追随者会利用他们的虚假指控来掩护拜登，这个我们国家历史上最腐败的总统”。对此，小特朗普接着批评称，“没有这么巧合的事，如果大家注意的话，就会发现我们已经成为一个‘香蕉共和国’。真是令人作呕”。综合美国全国广播公司等多家美媒此前报道，当地时间8月1日，特朗普在美国司法部特别检察官调查中因涉嫌“试图推翻2020年总统选举结果”而受到刑事指控，这涉及2021年1月6日发生的“国会山骚乱”事件。特朗普因此面临4项刑事指控：密谋欺诈美国、密谋妨碍官方程序、妨碍及试图妨碍官方程序、密谋侵犯他人权利。对此，特朗普在社交媒体上发文，指责起诉书是基于“虚假指控”。返回搜狐，查看更多责任编辑：
