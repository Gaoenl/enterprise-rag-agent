2023-08-03 22:10:00，正文：        咱一向以“阿绿”为代称的OPPO，它，黑了...        就在这两天，有不少网友发现，包括OPPO官方在内的各大账号，logo都从原先的绿底，转为了黑色。但和之前小米logo时的大张旗鼓不同，OPPO这次更像是一种“暗中行动”。在改动之前，官方没有透露一点，哪怕是一丝的消息。        几乎就是同一时刻，几乎就是一夜之间，集体变黑。就连现在的OPPO官网，都已找不到一张之前的旧版绿底logo。        面对这般大刀阔斧的企业文化整改，机哥看到，不少网友都还很难接受这一现实。说来也是。咱从小看到大的绿色，突然，就变成了黑色...换作谁来，这一时半会儿也都看不习惯呐。        很快啊，OPPO官方就给出了这次换色事件的答复。原来啊，OPPO并没有打算彻底放弃绿色，而是希望以简约的黑白两色，更简洁高效地塑造自己的品牌形象。        另外OPPO官方也说，绿色，依然是它们非常重要的组成元素，未来也会以点缀的形式，出现在各个场景之中。所以，大家也不要太过紧张。这些年里，更换logo的也不止OPPO一家，放眼全球各大厂商，那换logo换色的可多了去了。再说，隔壁推特前两天不也换了吗，那程度可比这个大多咯~只是道理是这么个道理。机哥看到，还是不少网友心念念的在想...既然没有绿色了，那绿厂还能叫绿厂吗？图片来自网络小黑!!
