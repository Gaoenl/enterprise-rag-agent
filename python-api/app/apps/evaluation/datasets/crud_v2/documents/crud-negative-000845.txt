俗话说“知己知彼，百战不殆”，要想防蚊灭蚊，我们还是先来了解一下，蚊子是怎么选择“心仪”的对象呢？首先，跟血型无关。因为蚊子侦测和定位目标主要是靠二氧化碳、热量、挥发性化学物质等因素，跟血型没关系。而且各国的科学家和媒体都做过大量的实验，目前的结论证明，蚊子爱叮谁跟血型没有什么直接关系。也就是说甭管你是什么血型，只要你在呼吸、出汗或是散发热量，你的温度，你释放出的水蒸气、二氧化碳，你汗液中的丙酮、辛烯醇、乳酸等化学物质，就都在诱惑着蚊子，让它们循着踪迹找到你。当蚊子找到并飞向你后，视觉就开始起作用，蚊子的视觉系统在阴暗的环境中最活跃，所以反光效果较弱的黑色最吸引它们。因此我们可以总结出，蚊子对呼吸频率较快、出汗多、有体味、新陈代谢快、穿深色衣服以及经常喝酒吃肉的人“情有独钟”。就比如...正在街边穿着深色衣服大汗淋漓地喝酒撸串的你。了解了这些后，相信大家一定悟出了正确的防蚊姿势，那就是：勤洗澡，常换衣，穿浅色，憋住气（咳，开个小玩笑）。当然是用驱蚊剂了！驱蚊剂就是一种人工合成的，通过阻断或干扰蚊子的嗅觉受体，让蚊子找不到北的东西。图自网络根据美国食品药品监督管理局（FDA）和疾控中心（CDC）推荐，常见驱蚊剂的有效成分为四种：避蚊胺避蚊胺已经有60多年的历史了。早期，美国陆军首次使用避蚊胺来保护服务人员免受蚊虫的叮咬。避蚊胺能有效地击退所有种类的蚊子，除此之外，它还能有效预防蜱虫，恙螨，跳蚤，虱子和一些苍蝇。不过儿童对避蚊胺反应比较敏感，所以6个月内的婴儿不宜使用含有此成分的驱蚊水。2-12岁儿童使用含有避蚊胺驱的蚊水，浓度应低于10%，且一天不宜使用超过三次。驱蚊酯和避蚊胺相比，驱蚊酯安全性更高，刺激性更小，不过效果稍微差了那么一些，不过也算是避蚊胺很好的替代品。埃卡瑞丁最初是由德国拜耳药厂于1998年开发出来的活性成分，它相比避蚊胺对皮肤的相容性非常好，被美国疾病控制与预防中心评为除了避蚊胺最有效的驱蚊剂。但因为它的成本很高，目前还未引起国内品牌的追逐，而在一些欧洲国家特别是专为婴幼儿所研发的防蚊虫产品中已屡被应用，例如德国Autan、Zeckito、S-quitofree等。柠檬桉叶油近10年来，派卡瑞丁和柠檬桉叶油被认为是更安全、副作用更小的可替代避蚊胺的两种驱蚊产品。柠檬桉叶油也是美国疾病预防与控制中心推荐的驱蚊成分中唯一一种天然植物成分。不过，FDA警示柠檬桉叶油不能用于3岁以下的儿童，因其会引起眼睛疼痛。而派卡瑞丁更适用于儿童。去商场、药店购买驱蚊剂时，需注意其有效成分  图自网络另外在使用驱蚊剂时还需要注意：在驱蚊这件事上，“天然”不代表“安全有效”。不建议使用含有香茅油、柠檬草油、香柏油、香叶醇、迷迭香油、肉桂油等成分的驱蚊产品。其一是因为这些天然植物油易挥发，驱蚊效果只有一两个小时。其二是因为这些产品通常没有登记在案，即没有经过安全与有效性评估，潜在危害不明。给孩子使用之前，家长需先喷在手上，后给孩子涂抹，尽量不要用在小孩的手上，防止他们揉眼睛、接触食物。老人和孩子要注意，不要频繁使用驱蚊液，尤其是2个月以下的宝宝，皮肤特别娇嫩，毕竟避蚊胺是药物成分，在使用这类产品前请仔细阅读产品说明书，慎重选择。文章出处：蝌蚪五线谱
