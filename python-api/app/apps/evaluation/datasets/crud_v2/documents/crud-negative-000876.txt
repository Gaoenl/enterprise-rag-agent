上证报中国证券网讯(记者 陈其珏)记者从协鑫集团获悉,7月19日,全球能源互联网发展合作组织(以下简称“合作组织”)副秘书长李宝森携国网苏州供电公司一行赴协鑫集团调研座谈,与协鑫集团董事长朱共山围绕加快构建新型电力系统,助力实现碳达峰碳中和目标进行了深入交流。朱共山介绍了协鑫集团源网荷储、充换算售一体化战略布局,颗粒硅、钙钛矿、全液冷超充网络、能源算力中心、光储同寿系统解决方案等革命性技术应用,并表态希望双方充分发挥各自优势,依托新型电力系统技术创新联盟,携手推进科研合作,打造创新平台,推进能源数字化转型,提高国家能源安全和保障能力。李宝森表示,合作组织近日深入江苏一线调研,围绕加快构建新型电力系统,实地了解情况,研究解决问题。协鑫集团将先进的数字技术与能源技术深度融合应用,紧密对接国家电网公司“一体四翼”发展需求,未来可期。双方可进一步在换储充算等数字化、低碳化领域展开深入合作,携手推动新型电力系统构建。近日,中央深改委会议审议通过《关于深化电力体制改革加快构建新型电力系统的指导意见》,强调要加快构建清洁低碳、安全充裕、经济高效、供需协同、灵活智能的新型电力系统,更好推动能源生产和消费革命,保障国家能源安全。作为国内民营电力龙头,协鑫集团助力构建新能源占比逐渐提高的新型电力系统,是合作组织重要合作伙伴。合作组织以“推动构建全球能源互联网,以清洁和绿色方式满足全球电力需求”为宗旨,由国家电网有限公司发起成立,是中国发起成立的首个能源领域国际组织。
