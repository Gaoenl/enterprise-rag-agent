2023-07-25，正文：近日，不少网友在社交媒体平台表示，7月20日，在淘宝口碑生活服务旗舰店（以下简称“口碑生活”）直播间以1元秒杀到价值298元的儿童游乐场MELAND CLUB套票，在当晚遭强制退款。原因是消费者以1元秒杀到了其门票却不给核销，与此同时，“李佳琦meland票”也一度冲上热搜。随后，涉事店铺口碑生活服务旗舰店在店铺首页贴出致歉信，声称提前对秒杀链路进行测试时，出现了操作失误，会为已经购买了测试商品的朋友安排退款。有网友发帖称，“做不起活动可以不做，强制退票是什么意思。”还有网友发出了投诉维权的截图。此后，“李佳琦meland票”词条冲上热搜。据多家媒体报道，此次秒杀活动的订单量达90万单。7月21日凌晨，MELAND通过官方微信公众号发表声明，称买家凭退款凭证可无门槛抵用100元。网友晒出的交易记录MELAND CLUB门票原价是298，1元秒杀确实是非常大的优惠，基本上可以说是赔本赚吆喝了，按照商业规律，也不可能无限量秒杀。而据网友所述，当天这一门票被秒杀了90万张，商家可能不但难以承受这一经济损失，恐怕也很难有这样的接待能力。所以，商家解释说是提前测试时出现了操作失误，应该也是实情，并不是想故意赖账，很多网友也对此表示了理解。涉事商家客服此前的回复但是，对于消费者来说，看到这么便宜的商品，还抢到了，肯定是会有很高的期待。商家突然说不能使用，会有失望愤怒的情绪，也是很正常的。毕竟，出现失误的是商家，并不是消费者，无论什么理由，都难免给人“玩不起”的感觉。
