评论员 王晓娜人生的弓，拉得不满会掉队，拉得太满会疲惫。这两天，“休息羞耻”的话题登上热搜，引发热议。一些网友发文分享 “休息羞耻”带来的困扰，甚至还有人带病上学上班，这些人为什么会被“休息羞耻”困住呢？不少人一想到休息，就会产生愧疚、焦虑的心理，这就是“休息羞耻”。和之前网上热议的“请假羞耻”类似，都是源于“努力”和“放松”之间的纠结。但被“休息羞耻”困住的人，并不是真的不想休息，而是不敢、不好意思休息，所以才陷入纠结。有网友称，带病上班的自己看到这个词，仿佛被踹了一脚，明知道地球没了谁都照样转，却还是有一种“这个班没了我不行”以及“不想给其他同事添麻烦”的责任感，想改也改不掉。翻阅评论，这样的例子不在少数。大概是从小到大，家长、老师都告诉你要“上进”“奋斗”“不能懈怠”，却很少有人告诉你“快乐也很重要”，一些人休息时会觉得：“明明可以用这段时间让自己进步，我居然在摆烂……”但正是这样所谓的“上进”，让他们的身体、心理承受着持续的压力，反而影响了学习工作的良好状态。用“喝咖啡”“冷水洗脸”来驱赶疲惫，或许并没有“睡一觉”来得有效。饿了就吃，困了就睡，休息才是人的本能需求。与其对抗本能，不如顺应本能。被“奋斗”主题教育熏陶长大的孩子，该脱离固定思维的枷锁了。毕加索说：“我花了四年时间画得像拉斐尔一样，却需要一生的时间，才能画得像个孩子。”一名年轻人只需要几年就学会工作，却需要很长时间，才能在休息时感觉自由。发呆、散步、听歌，其实，你做的所有事不一定都要有用，“好玩”“放松”“快乐”也许更重要。举报/反馈
