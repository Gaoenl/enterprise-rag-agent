新华网北京1月20日电 当“大数据”深度渗入房地产领域时，北京这座拥有自身独特人居传统与居住态度的城市，将再度被重新解读和理解。“我比较意外的是上海在北京购房的人群里房价排在第一，因为北京和上海，传统意义上两个城市是有一定竞争关系的，但通过大数据的分析，我发现其实两个城市市民的互相认同感还是很强的。”1月13日，京投银泰执行总裁高一轩在网易房产年会上发言称，大数据的出现给予他的是关于市场的全新信息。北京开发商玩转“互联网+”和跨界过去一年，互联网+全面渗透了房地产从前期研发到营销售卖的每一个环节，大数据带来的海量房地产数据，通过互联网的交互分享，几乎改变了买房者和开发商之间的关系路径。“我有上百的微信圈子，也组织了各种线下活动，”高一轩在谈到如何使用互联网+促进楼盘销售时表示，“我们作为盖房子的人，房子的形态可以无限变化，但我真正是给大家创造一个好的生活方式。”伴随着互联网+崛起引申出的另一关键词就是跨界，“今年这个跨界，我的理解就是从供给端到需求端，把所有元素变小了，以前说的是一个城市的客户，现在变成一类客户，最后变成了个性客户，供给端，以前说我是什么家具的供应链，后来变成某一类家具的供应链，现在变成了我是某一类材料的家具供应商。”万科集团副总裁、北京区域首席执行官兼北京万科总经理刘肖表示，“房地产也好、其它行业也好，最大的特点是当这些元素变得可解构、可以自由组合的时候，生意模式都在发生变化。”大数据更能透视北京市场大数据时代的信息技术，实现了对市场对客群更为精细化的索引定位，而触及互联网发展前端的城市北京，其市场和客户则具有更为鲜明的特点。对此，金地集团华北区副总经理遇绣峰表示，北京既是一个理性的城市，又是一个感性的城市，“在北京我们做房地产，除了非常理性地告诉客户物理属性之外，在项目开发上，无论是建筑产品、风格还是定位客户上，你要有很鲜明的价值定位，你到底给客户提供什么样的生活方式，它需要在理性基础上有一种感性的认知，我觉得在北京房地产和客户来说，这种认知远远高于其它二三线城市。”泰禾集团总裁助理品牌总经理沈力男则表示，从所获得的大数据来看，不管是北京人还是外地人，在北京生活很重要的是在工作压力下有一种不安全感，其实就是“北漂”。而正是这种北漂背景下的奋进精神，令北京的居者不同于其他城市，他举例道：“北京的雾霾严重，但诞生了全国最大的跑步群落，深圳是50以上就不出去跑了，北京的100、甚至200还有人出去跑。在这个城市做房地产，它的产品是非常多元化的，每一个阶层都可以找到适合他的产品，只要你做的对路、只要你做得好。”房产周边延伸出更多互联网产品值得注意的趋势是，房地产全面触网后，似乎不止是开发商，其周边中介、地图、媒体等产业也相继研发出越来越多的互联网相关产品。包括网易在内的业内房产媒体，正在加快对大数据研究和运用，开发出助推房地产行业领域信息互通的互联网产品。正如一位业内人士所说，大数据解码“北漂儿”的生活习惯和“老炮儿”的精神风骨，听上去是件略显文化之事，但也可以是整个房地产界的另一商业起点。（来源：新华网）
