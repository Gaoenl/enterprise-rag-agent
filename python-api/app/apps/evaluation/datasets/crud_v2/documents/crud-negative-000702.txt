2023-08-19，正文：近日，网传北京师范大学出版社出版的一本历史书籍中，把中国踢出了四大文明古国之列，此事引发广泛热议。网传信息显示，上述历史书籍书名为《世界上下五千年》。在该本书籍中，提到人类初始文明源头时，称古埃及、古巴比伦、古印度、古希腊是人类初始文明的源头，没有包含中国。网友对该书籍的质疑很多网友对此表示质疑，四大文明古国不是古巴比伦、古埃及、古印度和中国吗？怎么把中国排除在外了？有网友认为，该书的此种说法不合理，容易误导公众。记者检索发现，该书籍在各大电商平台均有在售，书籍标签为青少年儿童文学读物。针对此事，8月17日上午，记者致电北京师范大学出版社，该出版社办公室一工作人员表示，上述书籍重点讲述的内容是世界其它文明兴衰更替的历程，“我们与这本书同时出版的还有《中华上下五千年》，这本是讲中国历史的，它们两个其实是相呼应的。”该工作人员说。该工作人员称，书本身内容应该是没有太大问题，可能读者存在一定的理解问题。网传该书存在争议的内容随后，顶端新闻记者又与本书的策划编辑刘姓工作人员取得联系。刘姓工作人员称，《世界上下五千年》这本书没有提到任何有关四大文明古国的说法。此外，针对人类初始文明起源都包含哪些地方，她解释，“人类初始文明起源其实是一个科学家们一直在探索的课题，实际上是没有定论的。”“近段时间，我们天天接到这样的投诉，网上的说法有点太断章取义了，对我们的声誉造成极大的影响，”刘姓工作人员表示，接下来，出版社也要采取进一步的措施，“去向平台申诉。”(责任编辑：张宏宾)
