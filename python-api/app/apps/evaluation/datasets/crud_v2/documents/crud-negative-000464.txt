中新网南宁7月25日电 (曲甲佳)广西壮族自治区党委农办专职副主任、自治区农业农村厅党组成员、新闻发言人韦波25日介绍,自国家种业振兴行动方案提出后,广西全面推进种质资源保护工作,大力支持并推动农业创新和企业发展,支持各地建设现代种业基地,为当地种业振兴奠定了良好的开端。图为新闻发布会现场。曲甲佳 摄种子是农业现代化的基础,广西壮族自治区人民政府新闻办公室当日举行新闻发布会,就广西实施种业振兴行动进展情况进行介绍。为抓好种业振兴顶层设计,广西出台系列规划,为“十四五”广西种业发展明确了目标方向及主要任务,并建立了种业振兴行动厅际工作协调机制,统筹协调推进全区种业振兴工作。据悉,目前广西已全面开展农业种质资源普查,农作物普查已通过国家验收,完成任务量的120%;畜禽、水产也已进入普查收尾工作阶段。初步建立国家级和省级相衔接的种质资源保存保护体系,建成国家级农业种质资源库、圃、场9个,保存农作物种质资源及中间材料10万余份、畜禽遗传资源约11万头(只)、水产种质资源32万尾(只)、蚕品种资源约700多份;野生稻、甘蔗、糯玉米种质资源保存量分别占全国的1/2、1/2、1/3,其中稻种资源数量居全国首位。建成广西首个国家级畜禽遗传资源基因库,成为全国三大地方鸡种活体基因库之一,保存禽类品种资源21个。在加强农业品种培育创新方面,广西新增国家级农作物品种展示评价基地5个,建成“部区市县”相衔接的农作物品种测试评价体系。大力实施良种联合攻关,加快培育高产优质品种。近年来,广西优势种业企业发展迅速,有12家企业入选国家种业阵型企业,数量全国排名第10。广西还举办了中国(广西)—东盟现代种业发展大会、“看禾选种”大会、“好种好品”擂台赛等系列活动,展示推介水稻、玉米等品种累计4647个(次),擂台赛获奖品种232个。在加强现代种业基地建设方面,2021年以来广西落实中央和自治区财政投资3.5亿元,支持建设一批良种繁育基地。博白县成为广西首个国家级水稻制种大县,杂交水稻年制种面积达3.2万亩。广西农业良种海南南繁育种基地提档升级项目获批准,40万份库容的广西作物种质资源库项目已开工建设。已建成国家级畜禽核心育种场11个,其中生猪核心育种场5个,排全国第8,占比5.2%,核心群母猪数量排全国第3;建成水产良种场国家级2个,自治区级28个。下一步,广西将持续推进种业振兴行动,着重聚焦品种培育和种业基地建设,统筹兼顾做好资源保护、企业扶优、市场净化等工作,着力推动种业振兴取得更大成效,为保障粮食和重要农产品安全供给提供种源支撑。(完)【编辑:姜雨薇】更多精彩内容请进入财经频道
