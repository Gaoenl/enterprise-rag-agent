2023-08-02，正文：k396有乘客被困三天后武警带出，乘坐接驳列车前往丰台站8月1日，总台记者跟随武警北京总队的先头救援力量，经过四个小时的长途跋涉，徒步12公里，挺进K396次列车受困的落坡岭站，给受困的乘客和周边村民发放食品、衣物、药品等物资。现场仍存在断水断电断信号的情况。k396有乘客被困三天后武警带出，本次先头救援力量的成功挺进，为后方通信畅通了联络渠道，助力接下来的救援工作顺利开展。随后，该总队持续增援救援力量前往受困地区，运送物资的同时，护送乘客平安转移。8月2日凌晨2时许，第一批328名受困乘客在武警官兵的护送下，开始有序转移。并于6时许成功转移至斜河涧站。目前所有乘客已乘坐接驳列车前往北京丰台站。k396有乘客被困三天后武警带出！7月30日中午，K396次列车被迫停车，乘客已被困超过两天两夜。8月2日上午，首批328名乘客安全抵达北京丰台站。关女士一家来自河北保定，她50多岁的父母7月29日从内蒙古临河站上车，打算从北京中转回保定。据关女士介绍，K396的乘客共分三个批次步行往外走，现在出来的第一批有300余人，分成了多个小队，她的父母是第6队。关女士称，当地信号还未完全恢复，电话打不出去。2日凌晨五六点才收到母亲发来的消息，称走了四五个小时，鞋都走烂了。关女士表示，武警部队应该把路探好了，选了较快的路下来，但道路仍然泥泞难行，救援人员采用了一对一帮扶的形式。她表示，第一批人员到丰台后被分到各个旅馆休息，剩余人员可能会派直升机去接，但具体要视情况而定。
