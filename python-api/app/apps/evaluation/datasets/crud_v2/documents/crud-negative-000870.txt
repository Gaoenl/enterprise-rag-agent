成宜高铁天府机场段项目工程全部顺利完工2023-07-25 14:36来源：澎湃新闻·澎湃号·政务字号7月24日，随着成宜高铁天府机场站站房装修主体工程完工，成宜高铁天府机场段（含天府机场站）工程全部顺利完工，正式进入静态验收阶段。成宜高铁是四川省境内一条连接成都市、自贡市与宜宾市的高速铁路，是我国“八纵八横”高速铁路网之京昆通道的重要组成部分，线路从成都引出，经自贡抵达宜宾，全长约260公里，设计时速350公里。沿线设成都东、天府、三岔湖、天府机场、资阳西、资中西、威远、自贡、沿滩、南溪北、宜宾东等车站。其中，天府机场段（含天府机场站）及配套相关工程正线长度7.84公里，包含车站主体二次建筑结构、装修、静态标识、电力、暖通空调、给排水及消防、设备安装等施工内容。“作为成都天府国际机场重要综合交通枢纽，成宜高铁天府机场站实现了‘空铁一体化，旅客零换乘’，为旅客出行提供了极大便利。”成自铁路有限责任公司副总经理许文忠表示，成宜高铁天府机场段工程的全部顺利完工，对于构建成都至昆明快速客运通道、成渝第二条快速客运通道，加强成都、重庆和昆明地区间经济交通联系，推进长江经济带发展具有十分重要的意义。据介绍，天府机场站站房地上两层，地下两层，车站总建筑面积111500平方米，其中车站两端咽喉区面积37669.092平方米，车站站房部分主体面积73830.91平方米。自项目进场施工以来，参建各单位全力克服明挖隧道深基坑、高边坡坍塌和天府国际机场内地下车站交叉作业、工期紧、协调单位多等难题，严格按照铁路建设实施流程，建立标准化项目管理运行机制，全面落实铁路建设标准化管理要求，严把工程建设质量、安全、环保关，确保优质高效完成工程建设。成宜高铁自2019年1月开建以来，目前已进入开通前的最后冲刺阶段。全线建成投用后将与渝昆高铁、成贵高铁、贵广铁路相接，形成成都至昆明、贵阳、广州的高速铁路大通道，进一步强化沿线地区间客运交流，缩短地区间的时空距离，完善铁路网结构，服务人民群众出行需求。原标题：《成宜高铁天府机场段项目工程全部顺利完工》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
