2023-08-07 17:22，正文：原标题：音乐剧《熊猫》闪耀成都大运会赛场新华社客户端成都8月7日电（记者 薛晨）“现在非常的激动，能够实地感受到运动员们给我们带来的正能量。也希望把我们音乐剧《熊猫》中的核心——相信与爱的力量带到现场，传递给赛场上的运动健儿，为他们加油！”在成都第31届世界大学生夏季运动会成都市电子科大清水河校区体育馆，中国VS日本男篮比赛现场，来自成都大熊猫繁育研究基地无限山丘·熊猫剧院音乐剧《熊猫》剧组的成员海椒面（余诗茹）对记者激动地说道。第 31届世界大学生夏季运动正在成都如火如荼进行。体育表演作为本次大会体育展示的重要环节，突出了国际表达、中国风格、巴蜀特色和青春风采。为此，成都大运会执委会体育竞赛部特邀熊猫剧院音乐剧《熊猫》剧组参与成都大运会部分比赛中场演出工作。《熊猫》剧组成员们不负众望，精彩的表演为本届大运会增色不少。比赛现场节目表演期间，作为啦啦队成员，《熊猫》剧组成员们组成表演方阵与大运会吉祥物蓉宝，一起在球馆动感的音乐声中为观众们奉献了精彩的演出。剧组成员们精彩的表演让国际友人们一起感受到了别具一格的巴蜀风情与中国韵律，获得了现场观众们热烈的掌声。结束表演后，剧组成员赞花花（谭钧元）表示：“我感受到了成都人民，还有现场的观众朋友们的热情，感觉是一起来完成了这场表演。还想再为我们的运动健儿多加加油，再多多演一些！”今夏的成都，除了让全世界瞩目的大运会之外，由中国著名音乐剧制作人李盾、著名编剧/导演周可、韩国著名作曲家张少瑛等国内外优秀艺术家联袂打造的中国首部熊猫主题驻场音乐剧《熊猫》备受关注。该音乐剧以精彩的表现给观众们带来不一样的惊喜。在演出中表现出色的剧组成员们成为了大运会的“常客”，在多个比赛场馆作为啦啦队队员为现场观众和体育健儿们奉上了精彩表演。来源：新华社返回搜狐，查看更多责任编辑：
