，正文：大众网记者 孔婷婷 潍坊报道为切实增强广大退休干部职工的荣誉感、归属感、幸福感，同时激励年轻干部职工踔厉奋发、笃行不怠。8月2日，寿光综合医院为郑学明、孙雪莲、丁学文3名同志举行了简约又不失温情的荣誉退休仪式。医院党委书记马家义、党委副书记张玉海、部分职能科室工作人员及相关科室主任参加仪式。马家义书记对3位老同志多年如一日的敬业奉献精神表示感谢。他表示，医院发展到今天，承载了一代又一代干部职工的辛勤汗水与无私奉献，每位退休干部职工都立足于本职岗位，踏实肯干、敬业奉献，青葱到白首，几十年如一日，投身于医院发展，以强烈的政治担当、高度的使命自觉、高度负责的责任感、勇往直前的事业心推动新阶段医院高质量发展，给全院干部职工树立了标杆和榜样。希望大家退休后继续为医院的发展出谋划策，从不同层面关注、帮助和支持医院的工作。医院也会尽最大努力做好服务和保障工作，从政治上尊重老同志，从思想上关心老同志，从生活上照顾老同志，切实解决他们遇到的实际问题，让退休干部职工感受到来自医院的关爱与温暖。广告 他只是个小司机，伺候的却是一个富太太，小人物一步步平步青云扶摇直上！ ×仪式上，3名退休同志依次分享了自己在工作岗位上的感想与体会，刚到医院工作报到时的情形仍记忆犹新，然而弹指一挥间，已立业躬耕三十余载。他们表示，很荣幸、很骄傲见证医院的成长和壮大，对医院的未来充满了信心。他们将秉承初心，一如既往地支持医院各项工作，心系医院发展，衷心祝愿医院再创辉煌。
