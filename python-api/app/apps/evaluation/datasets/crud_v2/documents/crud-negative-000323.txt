12月7日，据环球网消息，新加坡副总理兼财政部长黄循财在参加新中双边合作联合委员会（JCBC）会议时透露，在新中航班不断增加的基础上，双方将通过30天互免签证安排，加强两国人员往来。由此，新加坡也成为继泰国、马来西亚之后又一个对中国游客实施免签的国家。该消息一出，多家旅游平台相关搜索量应声上涨，旅游企业也随即筹划丰富“新马泰”旅游产品，为8天春节假期做准备。旅游搜索量环比增长八成在免签消息发布后，市场迅速作出反应。携程数据显示，截至12月7日13时，消息公布后，新加坡搜索量环比公布前一小时增长八成，机票搜索量增长九成，酒店搜索量增长五成。飞猪数据也显示，免签政策宣布后，新加坡机票瞬时搜索量环比增长超2倍。另据去哪儿数据，12月北京-新加坡直飞机票价格1200元，上海-新加坡950元，杭州-新加坡790元，广州-新加坡860元，厦门-新加坡1110元。与此同时，新加坡环球影城门票的搜索量环比增长四成。众信旅游集团媒介公关经理李梦然介绍，近期新加坡免签后，众信旅游新加坡产品咨询热度瞬间增加200%左右，游客较为关心的问题有免签政策具体落实时间及具体政策等，以及近期有哪些新加坡目的地产品。在同程研究院首席研究员程超功看来，中新互免签证政策的到来将是出入境旅行市场的又一重要利好。新加坡一直是中国公民重要的商务旅行和旅游度假目的地，互免签证政策将进一步带动中国游客赴新加坡旅游的热情。不仅如此，新加坡还是共建“一带一路”国家。春秋旅游副总经理周卫红表示，对于中国人来说，新加坡是一个云集公务、商务、探亲、求学、研学、旅游等需求的综合性目的地；而同样，新加坡人来华公务、商务、探亲、旅游的需求也很旺盛。“在没有互相免签时，中新交流往来已经很频繁，如果正式免签，需求将会被进一步激发。”同时，赴新需求的增长也将带动中新航班的恢复速率。根据航班管家数据，2023年以来，中新往返航班量逐步上升，近一周（11月27日—12月3日）中国大陆-新加坡航班量588班次，恢复至2019年的79.4%。“鉴于国际航班尚未全部恢复，中新之间存在的双方市场需求旺盛将有助于航司优先决定中新之间航线的布局。”周卫红说道。不过，具体免签政策将如何实施，仍需等待有关部门后续公布。商家筹备“新马泰”连线产品事实上，新加坡一直是今年以来我国出境游的热门目的地。此次免签消息的发布，将再次为东南亚旅游的热度添一把火。程超功分析，在新加坡对中国公民免签政策正式落地后，将与马来西亚、泰国连点成线，形成一条“新马泰”免签黄金线路。去哪儿大数据研究院研究员肖鹏也表示，此前马来西亚宣布对华免签后，从去哪儿度假订单来看，马来西亚单独一地的旅客增长并不明显。“一旦新加坡免签，其旅游线路的可玩性也将增加，马来西亚3日游可以延长至新马两地5—6日游，旅客单次出境游玩更具性价比。”多家旅行社负责人均表示，元旦及春节期间，新加坡及连线产品普遍受到游客青睐，后续也将根据免签政策继续上新相关产品。“截至目前，春秋旅游元旦期间的新马连线产品均成团，仅有少量余位；春节期间，春秋旅游赴‘新马泰’三国的产品选择面很广，新一地、马一地、泰一地、新马连线均有覆盖，能够满足不同游客的出游需求。”周卫红介绍，春秋旅游新加坡业务板块工作人员也将筹备“新马泰”十日连线产品，进一步丰富游客的出游选择。不过，周卫红也指出，免签对于自由行的利好要大于跟团游。免签之前，新加坡团签办理起来较为便捷，只需提供护照信息；但是对于自由行游客而言，原本需要至少提前7个工作日提交签证材料，确认出签后才能购买机票，免签将省去材料准备与办理的时间。一直以来，东南亚地区都是中国居民出境游的传统热门目的地，而互免签证的消息放出后，新加坡成为继泰国、马来西亚之后又一个对中国游客实施免签的国家。“预计2024年中国公民赴”新马泰“旅游将进一步升温。”程超功谈道。（文章来源：北京商报）
