广西贵港记者从广西贵港出入境检验检疫局了解到,近日,他们在对一批原产自南美洲的紫心木进行检疫查验时发现一种有害生物。经实验室鉴定和专家复核,该种有害生物为Stizocera vanzwaluwenburgi (Fisher) 1932(尚无中文名),是一种刺腿天牛,为国内首次截获。据介绍,此次截获的有害生物多分布于中、南美洲,具有很强的钻蛀能力,对农林树木危害较为严重,存在生物入侵风险。这是今年以来贵港出入境检验检疫局第三次从进口原木中截获国内此前未曾发现的有害生物。目前,贵港出入境检验检疫局已对这批原木实施了有效检疫处理。2016年以来,贵港口岸从南美洲苏里南进口原木及木材的数量和品种持续增加,是华南地区进口原木的重要口岸之一。对此,贵港出入境检验检疫局不断强化口岸检疫查验力度和实验室检测能力建设,已完成CNAS(中国合格评定国家认可委员会)认证检测能力44项,完全覆盖了病虫草等植物检疫各大类别,为维护贵港口岸国门生物安全提供了技术保障。贵港出入境检验检疫部门工作人员提醒,进口商在进口木材时,应要求出口商对木材进行相应处理,并在签订合同、信用证时不遗漏熏蒸证书和官方植物检疫证书等,以保护自己正当权益,共同维护国家生物安全。(原标题:广西贵港口岸连续截获多种外来有害生物)
