中新网湖北新闻5月4日电 (夷宣 郑莉莉)今年“五一”小长假民众出游热情持续高涨，旅游市场回暖明显。为应对“五一”假日旅游季，湖北省宜昌市夷陵区委区政府及各文旅企业在优化旅游环境、加强交通疏导、维护现场秩序、处理突发事件等方面做好充足准备，保障了旅游市场平稳有序，为建设世界旅游名城核心区打下坚实基础。“五一”假日期间，夷陵区共接待游客152.61万人次，同比2022年增长54.49%，同比2019年增长36.09%；综合收入12.76亿元，同比2022年增长151.73%，同比2019年增长89.04%。其中，A级景区的吸引力和影响力充分显现，为文旅发展注入“强心剂”。景区接待游客59.19万人次，同比2022年增长77.37%，与2019年持平；门票收入3298万元，同比2022年增长333.95%，同比2019年增长18.2%。三峡大坝、三峡人家、三峡大瀑布、蓝之美童梦小镇、知音畔岛、龙泉湖等景区旅游人气爆棚，其中老牌5A景区三峡大坝游客量达12.6万人次，三峡人家游客量达8.99万人次，恢复至2019年同期水平。新晋5A景区三峡大瀑布游客接待量达12.35万人次，实现“化蛹成蝶”的精彩蝶变。新业态A级景区童梦小镇、知音畔岛、龙泉湖等地游客量也刷新历史同期水平，A级景区的吸引力和影响力充分显现。夷陵乡村旅游火热，为文旅发展守稳“压舱石”。“五一”假日期间乡村旅游接待人数占比总接待人数约60%，观近郊乡村风光、品乡村美食、领略民俗风情依旧是人们度假的主要选择。三峡国际房车露营地举办“星星烧烤季”、809微度假小镇举办“第二届溪边啤酒节”、三峡茶旅小镇举办“理想森活节”、分乡镇背马山村举办“乡村游五一体验周”、三斗坪镇举办“首届桑蚕文化节”等活动，吸引了周边游客眼球。千山云舍、南岔湾石屋、金刚山洋房子等民宿火爆异常，“五一”期间客房爆满，乡村沉浸游氛围浓厚。夷陵开展丰富多彩的文化活动，为文旅发展筑牢“产业桥”。开展“大地欢歌 文润夷陵”历届精品文艺展演、“阅读百部经典 点亮历史星河”阅读、全国第九届曹灿杯青少年朗诵展示宜昌市级展示活动，举办《十年关注一个人：屈原新闻辑录》展、“凝聚精华 助力推广”公共图书馆服务宣传推广展、美术馆书画作品展，组织“非遗进景区”、“非遗进图书馆”等非遗传承文化活动近百场，吸纳游客近2万人参与，为“五一”小长假文旅市场发展注入新动力和新活力，给广大游客带来实实在在的文化获得感。假日期间，夷陵旅游环境有序，为文旅发展送上定心丸。“五一”小长假来临前期，该区成立联合整治专班，集中力量开展旅游市场专项整治行动。为全力保障景区交通需求，区直相关单位在金瀑路三峡大瀑布段进行现场办公，优化组织施工，加大设备人员投入，合理压缩工期，4月30日恢复道路双向通行，并在“五一”期间暂停矿车运输，有效提高车辆通过能力，缓解交通压力。“五一”期间，夷陵区委区政府多次组织相关部门召开应对“五一”长假旅游市场保障协调会，公安、文旅、综合执法、应急管理、交通运输、市场监管等部门及重点乡镇组建专班，先后近5000人次在“五一”期间投入景区及重要路段开展志愿服务活动，与移动、联通、电信三大运营商合作，向外地游客发布出游短信提示12.8万条，与交通广播台、高警进行联动，发布实时预警信息160条，为游客出行保驾护航。(完)举报/反馈
