2023-08-11，正文：近几年随着报名公务员考试的考生人数持续增多，也让考试的竞争压力和上岸难度增大，导致应届大学生如此向往公务员岗位的主要原因是因为这份工作社会地位高，薪资待遇好，工作性质稳定，对日后发展有极大的帮助。公务员的基本工资：办事员2800元，科员3000元，副科级3100元，正科级3300元，副处级3600元，正处级4000元，副厅级4400元，正厅级5000元，副部级5500元，正部级6000元。办事员三周年按照科员对待，科研五年按照副科级，对待副科级10周年，按照正科级，对待正科级10周年按照副处级，对待副处级10周年按照正处级对待，初次套改以累计年限对应的职务待遇，确定基本工资。每到年底不管是哪个行业，最受到大家关注的就是关乎自己收入的年终奖，公务员当然也不例外，在大部分人眼中，公务员就是工资不高，但是福利待遇很好的，一个铁饭碗工作。公务员的年终奖都有些什么？能发多少？1、十三薪每年一共有12个月，而公务员在年底会多发一个月的工资作为奖励，这就叫做13薪，不会因为各个地区的不同岗位级别的不同，所以发放的13薪工资也完全不同，有很多地方是发放全额工资，也有很多地，发放基本大约有1000多元左右，还有的地方则是发放应发的工资比全额工资高一点，所以实在性的发放有的高一些，有的会低一些。2、绩效奖绩效奖是作用假期当中最重要的，不同的地区绩效甲级的发放也完全不同，像一些经济发达的地区，他们的年终绩效奖一般都有几万块的收入，像上海有8~10万左右财政状况不好的地区，发放的绩效奖金差很多，虽然不同的地区差别很大，但是同一地区的绩效奖金基本相同，而且绩效奖金会有适当的发放梯度，基本上每个在职的公务员都会拥有。3、年度考核奖公务员的考核分为平时考核和定期考核，定期考核是以平时考核为基础，而定期考核关乎着公务员的年终奖，每到年底公务员都会进行年度考核，而对于一些考核成绩较高的员工和荣获一些优秀等级的员工，才能享受年度考核奖金。
