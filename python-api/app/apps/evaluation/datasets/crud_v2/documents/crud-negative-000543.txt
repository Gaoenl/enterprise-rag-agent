2023-08-16 09:02，正文：原标题：益阳市生态环境局南县分局开展首届“全国生态日”活动活动现场。活动参与人员前往环保场地。红网时刻益阳8月15日讯（通讯员 张科 陈郑慧娟）8月15日上午，益阳市生态环境局南县分局联合南县游泳协会、环保志愿者团体等共计50余人在南县三仙湖水库开展了“绿水青山就是金山银山”为主题的首届“全国生态日”活动。活动期间，生态环境局南县分局、游泳协会及环保志愿者在南县三仙湖水库沿湖堤岸悬挂相关宣传标语和展板，开展捡拾水岸垃圾、现场解答群众环境问题等教育活动，引导社会公众积极参与生态文明建设。此次活动的开展旨在教育、引导、激励社会各界进一步增强环保意识，弘扬生态文化、培育生态道德，倡导全社会遵循绿色低碳出行理念，希望通过此类活动让更多普通群众参与到保护三仙湖水库水环境中来，共同维护好我们的居住环境，每一个人都能做绿水青山就是金山银山理念的积极传播者和模范践行者，身体力行、久久为功，为共建清洁美丽世界作出更大贡献。来源：时刻新闻作者：张科 陈郑慧娟 编辑：赵佳妮 本文链接：https://yiyang.rednet.cn/content/646742/59/12957502.html返回搜狐，查看更多责任编辑：
