2023-08-10，正文：“真不敢相信，在有很多人的地方会发生这样的犯罪！”近日，韩国连续发生多起无差别袭击事件，引发民众恐慌。更令人担忧的是，网上还出现了近200篇“杀人预告”帖，“模仿犯罪”的阴影进一步笼罩着韩国社会。这种现象为何会“滚雪球”似的一发不可收拾？韩国又能否及时遏制这一趋势？“我很害怕明天的上班路”从7月21日到8月4日，短短半个月内，韩国多地已连续发生了多起无差别袭击事件。7月21日，在首尔新林站附近的商业街，33岁的赵某持刀冲向人群，导致一名20多岁男子死亡，另有3人受伤；8月3日，在京畿道城南市人群密集的盆唐区书岘站，一名男子开车冲向人群撞倒5人。嫌犯随后下车进入附近的百货商店，向市民挥舞凶器，造成多人受伤；8月4日，韩国大田市的一名男子自称毕业生，进入当地一所高中后刺伤了一名教师，受害者脸部和胸部被袭击数次；同样是在4日，一名男子持刀在首尔江南区大巴车站附近徘徊，后被警方逮捕。在被问及为何携带凶器到车站时，他表示“是为了自杀”。警方在随后的调查中发现，该男子当天凌晨曾在网上发文称，“我要刺死警察”。连续发生袭击案，在韩国社会产生了巨大负面影响。据《韩民族日报》报道，亲历8月3日书岘站袭击事件的一名目击者表示，“真不敢相信，在有很多人的地方会发生这样的犯罪。”事件发生后，大量现场画面迅速在网络上传播，引发民众担忧。在视频和照片中，看似受伤的市民倒在百货商店的地上，平时热闹的街道被围上了警戒线，显得很空旷。一名30多岁的上班族表示：“继新林站之后，又看到这次事件，我很害怕明天的上班路”。
