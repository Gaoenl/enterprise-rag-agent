2023-07-31 10:37:16，正文：IT之家 7 月 31 日消息，推特博主 Game Pass Tracker 今日凌晨发文称，在欧盟委员会发布的一份关于微软暴雪收购案的报告中，披露了微软旗下游戏订阅服务 Xbox Game Pass 的用户构成。        有关描述出现在这份报告中的第 161 页、第 680 章，里面是这样说的：“微软是首家在云游戏领域发力、投资的公司，这展现出该公司‘以玩家为中心、与设备无关’的远景和商业模式。Game Pass（包括顶级版本的 Game Pass Ultimate）云游戏服务的推出和发展，是这一战略的商业基石。其中，Game Pass Ultimate 在数百万 XGP 用户中占据了将近 70%-80% 的份额，微软在内部文件中讨论说，通过 Game Pass Ultimate，能够……”与此同时 Game Pass Tracker 还声称，XGP Ultimate 的用户有望在这项服务中玩到动视暴雪游戏。IT之家此前报道，微软 Xbox 部门近期公布了 2023 财年财报，累计收入 154.77 亿美元（当前约 1108.15 亿元人民币），在该部门营收历史中位列第二。        其中，Xbox Game Pass 的游戏时间比去年增长了近 25%，月度活跃用户数量也创下了历史新高，但微软和此前一样，并未公布 Game Pass 业务的营收和订阅用户规模。据 tweaktown 报道称，Xbox Game Pass 的订阅用户数量超过 2500 万。        另外，微软 XGP 本月下旬新增了 7 款游戏，分别为手绘风格解谜游戏《TOEM》、第一人称视角循环解谜游戏《Maquette》、动作冒险解谜游戏《虚构世界 2：信条谷》、生存建造经营游戏《漂泊牧歌》、FPS 射击游戏《英雄萨姆：西伯利亚狂想曲》、叙事性烹饪游戏《Venba》、横版动作游戏《蔚蓝》。还有《层层梦境》、《远征军：罗马》、《漫威复仇者联盟》、《上行战场》、《双点校园》共 5 款游戏于 7 月 31 日退出 XGP 服务。
