08-15 09:10，正文：日前，“绿景白石洲”项目发布会在深圳举办。据介绍，白石洲目前是深圳最具规模的城市更新体。为了打造全新的白石洲，绿景集团“十年磨一剑”，特邀全球约50家顶级设计团队参与共创。曾经的白石洲是深圳最具代表性的城中村，留下了无数深圳人的奋斗打拼印迹。发布会上，绿景集团董事长黄康境称：“对于白石洲来说，我一直有一个梦想，希望能给这座城市留下一个具有影响力的作品，梦想说说容易，真正实施真的很难，光是有梦想、情怀和拼搏是不够的，还要有一份坚持、责任和认识，二者缺一不可。”在绿景集团的规划中，未来的全新白石洲，是约500万平方米“无界之城”，集旗舰商业群、塔尖办公群、星级酒店群、高端居住群、大型公共配套群等丰盛业态于一体。项目规划有超40万平方米商业，约1.1公里中央绿轴由南至北串联各业态；项目规划有4所幼儿园、3所九年一贯制学校、以及约9万平方米社康、文体等配套设施，满足全维度生活需求。高级城市规划师、原中国城市规划设计研究院副总规划师朱荣远认为，白石洲恰位于深南大道与大沙河十字节点，深南大道是深圳现代城市的脊梁，而大沙河左岸右岸分别代表了深圳的感性和理性，全新白石洲既属于深南大道新故事一部分，也是大沙河创新流域的新地标。据介绍，在全新的白石洲，有全球一线都市的超级城市综合体形态，更有代表深圳未来的核心生活主张。全新的白石洲致力为深圳生活创造不一样的未来，以“七重立体之城+深圳超环系统+全场景智慧城区”，构筑从地下到地上的七层立体共享城市。此外，深圳首个移民博物馆也将在白石洲落地，该博物馆对标纽约埃利斯岛移民博物馆，以深圳和白石洲的移民文化为主题，致力于打造城市文化事件策源地、城市公共艺术发生地。来源：中国证券报·中证网 作者：董安琪温馨提示：最新动态随时看，请关注金投网APP。
