极目新闻记者 王佳文通讯员 曾建 黄璜 石琴实习生 程熊熙3月17日上午，在武汉市汉阳区凤凰巷的小巷里，汉阳古城历史风貌区重点项目汉阳树公园建设举行开工仪式，项目正式进入工程施工阶段，公园北园预计今年下半年建成开园。汉阳区委书记徐丽宣布开工，项目承建方中海企业集团武汉公司总经理潘承仕致辞。市园林和林业局党组书记、局长吴俊勤，汉阳区委副书记、区政府区长郭笑撰，区人大常委会主任万磊，区政协主席陈革鸿，区政府副区长王彬，区政府副区长李津，区政府副区长易雄才出席活动。开工仪式现场（摄影王晨亮）汉阳树公园位于汉阳古城（显正街片）历史风貌区，东侧毗邻武汉市第五医院与显正街天主堂。显正街区域历史上是汉阳古城核心区域，在如今的城市规划格局下，该区域也被定义为重要历史斑块和核心轴线。城市更新城市设计策略也是围绕显正街来打造汉阳古城文化复兴之路。汉阳树公园分为北园与南园两部分，本次开工建设的是北园据悉，汉阳树公园项目以显正街为分隔，分为北园与南园两部分，总面积约1.1平方公里，其中北园面积约0.58公顷，南园面积约0.53公顷。540余岁的汉阳树坐落在北园，南园东北侧规划有商业设施。汉阳树公园北园（效果图）俯瞰汉阳树公园北园（效果图）根据设计方案，一条紧邻汉阳树、贯穿南北园的“时间的长河”，与廊道尽头圆形下沉草坪广场形成的“时光之环”构成了公园的主要空间构造，打造360度的城市开敞界面，把“藏”在市井里的“汉阳树”和周边文化古迹充分展现给市民。汉阳树公园时空之廊（效果图）据了解，本次开工建设的是汉阳树公园北园，包括公园北入口、石之广场、时间的长河、林下休憩空间、古树广场等公共设施。公园建成后，游客从靠近汉阳大道一面的北入口“石之广场”步入公园，首先经过用天然整石搭建设计成的“正”字水景广场，呼应显正街历史。穿过“时空之廊”步道，即可站在宽阔的“古树广场”前打开视野，一览汉阳树的魅力。俯瞰汉阳树公园北园（效果图）古树广场以“汉阳树”为核心，三面种植高大的树木用来遮阴。此广场还利用场地高差，形成树下平台空间，观者可以近距离与百年银杏树互动。留白的广场空间开阔，分区灵活，设立完善步道，座椅等公园配套设施，平时可作为城市休闲空间。“树下的石阶可作为舞台，形成一个露天演绎剧场，同时还可以作为一个户外艺术展厅，供市民把汉阳树作为题材进行文艺创展。”设计团队负责人表示。汉阳古城文化轴六大景观节点示意图2022年5月，汉阳区发布汉阳古城文化轴建设项目计划，通过串联打造翠微路共享街道、却月天桥、凤山门广场、汉阳树公园、钟鼓楼广场，以及连接汉阳滨江公园的城市甲板的六大景观节点，复兴文化记忆，唤醒千年街巷，在武汉内环构建一条1800米古今交融的文化商业步行街区，搭建文化+生态城市文旅T台。项目方相关负责人表示，下一步将全力推进汉阳树公园建设，争取北园早日和大家见面。（来源：极目新闻）更多精彩资讯请在应用市场下载“极目新闻”客户端，未经授权请勿转载，欢迎提供新闻线索，一经采纳即付报酬。举报/反馈
