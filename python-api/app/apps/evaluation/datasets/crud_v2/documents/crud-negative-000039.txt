渐冻症患者仅用眼球转动和凝视，就能操作电脑打字；求职者打开手机就可以进入AI面试系统完成虚拟面试，并实时查看面试结果；走进超时空博物馆点击鼠标就能穿越到历史场景中，沉浸式体验历史文化……7月18日至20日，2023（第二十二届）中国互联网大会在北京召开，精彩纷呈的互联网应用在大会期间亮相，数实融合赋能千行百业的动能正在彰显。互联网行业实现突破性发展人工智能产业规模超过5000亿元，云计算产业规模达到4550亿元，网络安全产业规模达到2200亿元，工业互联网产业规模超过12000亿元……会上发布的《中国互联网发展报告（2023）》（以下简称《报告》）显示，我国网络基础设施建设全球领先，数字技术创新能力持续提升，数据要素价值备受重视，网络法治建设逐步完善，网络文明建设稳步推进，网络综合治理体系更加健全，数据安全保护体系更趋完备，网络空间国际合作有所进展，数字中国建设取得显著成效。“互联网行业在推动数字经济高质量发展、助力实体经济转型升级方面作出了积极贡献。”中国互联网协会理事长尚冰表示，信息革命的时代潮流正在加速向经济社会各个领域渗透，加快发展以互联网为代表的数字经济已经成为把握新一轮科技革命和产业变革新机遇的战略性选择。与此同时，互联网行业发展动能显著增强。数据显示，2022年，我国市值排名前100的互联网企业的研发投入总计达到3384亿元，同比增长9.1％。截至目前，我国已有9家互联网企业跻身全球互联网市值前30，独角兽企业累计达316家。互联网新技术新发展备受关注人工智能大模型、虚拟数字人、AI安全……当前火爆的互联网新技术新应用也成为本届大会备受关注的热点话题。“今天讲的大模型，实际上是从通用人工智能到真正的超人人工智能之间一个过渡的阶段，我们可以叫它准AGI或者Near AGI。”北京智源人工智能研究院院长、北京大学计算机学院教授黄铁军表示，未来3年，除了语言，大模型将迅速扩展视觉、听觉、具身、行动等通用智能，影响将更大。但黄铁军也指出，今天尽管已经训练出具有竞争力的模型，但是真正的效率很高、成本很低、大家用得很好的模型现在还没有出现，这需要长期的研究。中国工程院院士邬贺铨表示，5.5G+云计算+AI等新一代IT推动摩尔定律持续发展，健全透明可预期的常态化监管制度支持互联网平台做大做强。他呼吁，互联网企业不仅要降本增效，更积极的做法是加大创新力度，发挥经济新引擎的更大潜力。“千行百业都在向数据要效率、要发展，越来越多的数据被收集、分析和利用，一旦出现数据安全事故，将会出现‘一失万无’的严重后果。”奇安信集团董事长齐向东表示，数实融合，也必须绷紧数据安全防护这根“弦”，以“零事故”为目标，进行网络空间的安全建设。近年来，以AI技术为核心的数字人形象日趋逼真，交互更加顺畅，虚拟数字人正愈发频繁地出现在公众的视野中，在传媒、社交、营销等领域发挥着积极的作用。“数字人有望成为互联网典型的人机交互界面之一。”中国互联网协会常务副秘书长陈家春表示，数字人融合了人工智能、深度合成、虚拟现实等诸多新技术，虽然切口不大，但是产业链不短，必须加强产业合作和专业协同。互联网发展“大有可为”随着全社会数字化转型步伐的加快，互联网行业在推动高质量发展上的贡献将进一步提升。《报告》指出，预计至2023年底，5G基站将新增60万个，5G人口普及率过半；1000M及以上宽带接入用户超过1.5亿户；移动网络终端连接总数中，“物”连接数占比将超57％，万物互联的基础将进一步夯实；而随着工业互联网进入全面推进的增长期，其对经济社会发展的带动作用将日益增大。与此同时，随着数据基础制度的持续构建，数据要素价值释放的新时代即将开启；大模型相关技术和应用的快速迭代，将进一步促进人工智能产业的发展，成为数字经济发展的新的增长点。“未来是时空环境驱动的具身智能，智能载体将是类脑的脉冲神经网络，有望像生物大脑一样涌现出更强的智能。”黄铁军表示。日前，中共中央政治局常委、国务院总理李强在主持召开的平台企业座谈会上提出，要持续推动创新突破，更好赋能实体经济发展。这进一步释放了鼓励平台企业健康规范发展的重要信号，平台经济将进入快速发展新阶段，将为互联网行业发展注入新动能。对此，邬贺铨表示：“当前是我国互联网平台企业发展的新一轮机遇期，全社会的数字化转型为互联网企业发展开拓了新的蓝海。”“坚定不移走具有中国特色的互联网发展道路。”工业和信息化部党组成员、副部长张云明在会上表示，要坚持守正创新，加快新型信息基础设施建设，加大技术研发投入，充分发挥信息化驱动引领作用，赋能实体经济，增强高质量发展动能。统筹发展和安全，扩大开放合作，强化网络安全和数据安全管理，积极参与全球数字治理和国际规则制定，共筑网络空间命运共同体。
