拜“托”了，夏天！金汇镇爱心暑托班第一期结业啦2023-07-22 14:56来源：澎湃新闻·澎湃号·政务字号这个盛夏，我们如约相遇在这个特别的课堂以青春灌溉夏天用爱心“托”起童年金汇镇爱心暑托班第一期结业啦~# 01精选课堂 环境佳思言小学齐贤学校金汇学校# 02边玩边学 多童趣消防安全课夏季是火灾高发期，金汇镇消防站的消防员们特地为暑托班的孩子开设了一节消防安全课，普及了许多消防安全的小知识。例如遇到火灾时如何紧急自救、如何使用灭火器和消防栓等。左右滑动查看更多皮影制作课“双手对舞千古事，一帘灯影藏春秋。“中国皮影戏是多种艺术形式历经千年融合而成的一种独立艺术。课上，在老师的教导下，同学们了解了皮影戏的历史渊源，以及它是如何发展的。与此同时，同学们也自己动手进行了皮影人物的制作。首先，大家在画纸上设计了一个小兔子，然后把人物的各个部位分开画出。接着，仔细上色，耐心剪裁。很快，皮影人的各部位就散落在眼前。按照人物形象整齐摆放，再拿出打孔器，取合适的关节位置打洞、固定、串联，确保关节可以自由活动。看着自己亲手制作的皮影人，同学们的心里充满了自豪和喜悦。左右滑动查看更多扎染课扎染是汉族民间传统而独特的染色工艺。扎染课帮助提升小朋友们的动手能力和色彩搭配能力，让小朋友们在动手的过程中了解中国传统染色工艺。左右滑动查看更多农民街上小农人思言小学位于金汇镇农民街，在本期爱心暑托班中，孩子们体验了“农民街上小农人”特色课程，在课堂上体验了劳动的快乐。在农耕课程上，拔草、浇水、施肥等都锻炼了孩子们的劳动本领。相信辛勤的劳动能够让每个参加暑托班的学生能够收获满满。我是大侦探《我是大侦探》是一门锻炼学生逻辑思维的课程，侦探破案的形式是孩子们非常感兴趣的话题，上课期间，孩子们表现出很高的热情。课堂上，孩子们通过收集信息，对一系列案件进行还原推理，循序渐进，逐步找到答案。在探寻真相的过程中逐步学会排除法、假设分析法、矛盾分析法等推理方法，对孩子们的观察力、空间想象力、记忆力等进行针对性训练。左右滑动查看更多还有更多二十四节气课程、劳动教育类课程“我们生活的大自然”、特色击剑体验课、土布香包课程等特色课程精彩不停。# 03青年志愿 我先行沈杰妮：奉贤中学高中生志愿者“纸上得来终觉浅，绝知此事要躬行。”爱心暑托班的志愿服务让我亲身实践，开启志愿者的爱心之旅。在这一周的陪伴中，我关注同学们的状态与心情，不时给予鼓励与认可。期间我也收获了欢乐，感到自我实现的充实与心灵的丰盈。让我们怀揣一颗敏感的心灵，拥抱一份实践的踏实，体会志愿服务的快乐吧！方顾磊：上海电力大学大学生志愿者我很荣幸能够参与金汇学校暑期的爱心暑托班活动。从最初跟小朋友们以及其他志愿者小伙伴们的陌生，到现在的彼此熟悉，中间的经历是我这次收获最大的经验。在日常工作中，这锻炼了我的耐性还加强了我的沟通能力，我也会继续努力把自己最好的一面展示给小朋友们，起到一个榜样的作用，在未来我也将积极投身于志愿者工作。唐世伟：武汉工程科技学院大学生志愿者在为期五天的思言小学爱心暑托班志愿者活动中，我亲身参与到暑托班的管理中。我们关注着孩子们的状态，给他们帮助与鼓励，并用照片去记录下暑托班中孩子们充满欢笑的脸庞，课堂上专注的眼神以及授课老师们风趣的话语。在与小朋友的相处中，我也在此获得了一颗充实的心灵。同时我也体验到了老师们的不易。让我们满怀欢喜，将这次志愿者活动留存于心吧！# 04今天我们结业啦！左右滑动查看更多归来满载，步履如往。不知不觉本期爱心暑托班已接近尾声了，小朋友们也要与这段奇妙的学习之旅说再见了。在接下来的暑期生活中，希望同学们能继续保持好在暑托班时的健康作息，有一个快乐的暑假生活。夏日蝉鸣与童行希望这个夏天西瓜味的风也能穿过课堂吹拂到孩子们的童年~报送：林思辰（金汇镇）原标题：《拜“托”了，夏天！金汇镇爱心暑托班第一期结业啦》阅读原文特别声明本文为澎湃号作者或机构在澎湃新闻上传并发布，仅代表该作者或机构观点，不代表澎湃新闻的观点或立场，澎湃新闻仅提供信息发布平台。申请澎湃号请用电脑访问http://renzheng.thepaper.cn。+1收藏我要举报
