12月6日至8日，2023粤港澳大湾区服务贸易大会（以下简称“大湾区服贸会”）在珠海举行。本届大湾区服贸会除了各论坛之外，12月7日至8日期间，还设置了经贸产业考察配套活动，为大湾区各城市和企业提供更多的贸易洽谈和产业招商机会。今年大湾区服贸会围绕珠海产业现状，定制了数条产业考察路线，让企业充分深入珠海各区的产业一线，了解优势产业与发展土壤，推出香洲区、金湾区、斗门区、高新区及鹤州新区等考察线路，涉及信息技术产业、生物医药产业、新能源产业及物流供应链产业。此外，还特设横琴粤澳深度合作区（以下简称“合作区”）专线及外商专线，聚焦人工智能、中医药研发以及跨境贸易领域，实地走访合作区多家企业。据悉，本次产业考察吸引共280名境内外客商报名参与。珠海发展模式具有借鉴意义珠海高新区具有基础设施及配套完善、企业集聚、居住环境好的优势，目前已快速布局一批成长性高、创新力强、发展潜力大的项目和企业。信息技术产业考察团首先来到珠海市高新区科技创新展厅，与众多展厅不同的是，这里集展示、招商引资、企业服务、教育实践等多功能为一体，是促进高新区产业招商的重要平台。随后，考察团还重点考察了位于高新区的珠海市服务外包产业交流中心（南方软件园内），目前已入驻企业、政府、金融、商贸服务等各类机构240余家，形成以软件与集成电路设计、大数据应用、移动互联、智能机器人、智能电网、服务外包为核心的数字经济产业聚集区。在走访调研过程中，企业考察团深入了解珠海信息技术产业发展状况，同时也感受到珠海打造一流营商环境新高地的决心。接下来，珠海将进一步强化科技企业集聚、科技人才集聚的态势，让创新驱动成为香洲区、高新区产业集聚、成长、裂变、爆发式增长的核心推动力。新能源产业线考察团则重点考察了斗门大横琴5.0产业新空间规划建设展示厅，参观了珠海连片规模最大、全省单一项目建设总量领先的产业新空间。这里有纬景储能科技有限公司，其位于珠海的吉瓦级锌铁液流电池“超G工厂”，年产能超6吉瓦时，成为了全球液流电池行业首个已投产的吉瓦级工厂，是珠海加速走向新能源产业舞台中央的生力军。山海关临港经济开发区管委会副主任王冰特意从河北赶来参加本次大湾区服贸会，他向南方财经全媒体记者表示，珠海作为经济高质量发展的先行区和示范区，对他所在的地区无论从经验上、理论上还是模式上，都有很大的借鉴意义。感受琴澳一体化觅发展商机另一方面，珠海金湾区具有连片产业用地、厂房规模较大的优势，以大空间、大载体牵引大项目、大产业，推动用地高效集约、上下游配套企业加速聚集。目前，正积极布局一批新能源等新赛道大项目，打造珠江口西岸新能源产业链的创新阵地。生物医药产业考察团在金湾航空城规划展览馆一馆看遍金湾区的发展历程、建设成果、规划设计和美好前景。随后，考察团又来到集产、学、研、资、销、服等功能于一体的国际健康港，依托“自有资金直投+财政资金直投+产业基金投资”的模式已吸引开拓药业、百试通、迪普医疗、泰诺麦博、绿竹生物众多企业入驻园区。有考察团成员向南方财经全媒体记者表示，本次考察印象最深的项目是汤臣倍健透明工厂，“走进汤臣倍健透明工厂前，需要穿上消毒过的厂服和戴上一次性的帽套鞋套，与汤臣倍健的员工们一起进出”。考察团沿着箭头指向的旅游参观路线,从原料仓库到生产线、从生产环节到实验室检验，整个生产过程均实现“透明化”。物流供应链产业线考察团第一站首先来到珠海中心大厦70楼天际观光厅，远眺澳门全景，俯瞰合作区金融岛及鹤洲新区保税的规划建设情况，一览珠海十字门金融区全貌。此外，考察团还重点走访了粤港澳物流园，这里涵盖中转集拼、保税仓储、跨境电商、冷链物流、航空打板、供应链服务等业务，将助力珠海构建港珠澳大桥经贸新通道。特设的合作区专线和外商专线则重点聚焦人工智能、中医药研发以及跨境贸易领域，重点走访了粤澳合作中医药科技产业园、广东省智能科学与技术研究院及横琴澳门青年创业谷。数据显示，横琴专线是本次考察最火爆的线路。在调研走访的过程中，企业家们听取了合作区中医药和大健康产业的发展以及“澳门注册+横琴生产”的产业发展模式情况，深入认识合作区的区位优势、产业情况、优惠政策及琴澳一体化发展进程等，围绕合作区营商环境、公共服务、民生配套等话题与合作区有关人员进行了深入的交流。有考察团成员表示，“通过本次走访调研，让我们进一步了解横琴的发展趋势、营商环境以及相关产业政策，未来将在此寻求发展商机，期待与横琴开展进一步的合作。”（文章来源：21世纪经济报道）
