，正文：据预测，苹果公司将于本周四公布2023财年第三季度财报，可能出现自2016年以来第三季度营收最大幅度下滑。分析师们认为，这主要是由于iPhone在美国和南美市场的销售放缓，而中国市场的销售预计将“持平”。 据Refinitiv的数据，预计苹果2023财年第三季度的营收将同比下降1.6%，iPhone的营收将下降2%。相比之下，去年同期iPhone的营收增长了3%，上一季度增长了1.5%。分析师们表示，iPhone销售的疲软主要来自美洲地区，预计该地区的营收将下降6%。而在中国市场，苹果的表现相对较好，但由于经济复苏不平衡，预计该市场的营收将与去年同期持平。 除了iPhone，苹果的Mac和iPad产品线也面临着下滑的压力，预计这两个产品线的营收将分别下降10.6%和11.2%。然而，苹果的服务业务可能会成为一道亮丽的风景线。一些分析师认为，由于广告市场的回暖以及iCloud订阅价格的上调，苹果的服务业务将保持5.7%的增长率，这一业务目前占据了苹果总营收的四分之一左右。 2016年第三季度，苹果的利润为78亿美元，营收为423.6亿美元，同比分别下降了27%和14.6%。苹果即将在9月份发布和发售的iPhone 15系列，而在新款iPhone发布前，苹果的iPhone销售通常会出现下滑，因为消费者会等待新品的到来。然而，分析师们认为，今年的下滑将比往年更为严重。本文属于原创文章，如若转载，请注明来源：苹果将发布最慢的iPhone 15：今年营收预计最大幅度下滑https://news.zol.com.cn/827/8273806.html
