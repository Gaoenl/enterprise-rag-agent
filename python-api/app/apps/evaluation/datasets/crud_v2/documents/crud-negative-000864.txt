2023-08-14，正文：未满18岁的高一学生，在家长不知情的情况下，将家里的39万余元积蓄用来打赏主播。近日，学生父母将平台虎牙直播告上法庭，要求对相关费用进行返还。8月13日，记者联系了虎牙直播相关负责人，截至发稿，尚未获得回应。 最高一次打赏9万元这名高中生的妈妈林霞（化名）向记者讲述，他们一家是福建省福州市的一户普通人家。她和丈夫已经有60岁，均无业在家。儿子小胡（化名）是一名高中生，9月马上读高二，目前还未满18岁。前些年，家里一直欠了不少外债，2018年8月，林霞和丈夫将家里唯一的一套房产出售。还完债务后，余钱还剩50余万元，这也是家里的全部积蓄。“因为我跟孩子父亲岁数大了，平时也不会操作手机软件，所以就让儿子将这笔钱转到他爸爸的支付宝里。”林霞称，这样可以收点利息，准备等小胡过几年长大成年了，用这个钱来付买房的首付。让她没想到的是，2022年12月，夫妻两人查看存款数额时，发现里面的余额已经所剩无几。夫妻俩询问儿子才知道，这些钱孩子大部分都用来打赏主播了。8月13日，小胡告诉记者，自己以前偶尔会看一下直播。去年8月起，他在家里上网课，每天接触手机，看直播次数更多了。小胡知道父亲的支付宝账户里有钱，便开始用来打赏主播。每次打赏之后，主播跟他的互动就愈加频繁。“当时成为榜一大哥就很兴奋，然后就上头了。”他说。小胡说，自己看得多的是搞笑、密室逃脱、唱歌等类型的直播。那几个月，他打赏的主播共有数十个，每次打赏都有两三千元。金额最高的一次，小胡在一天给一个主播打赏超过10万元。那一次，为了绕过打赏通道的金额限制，小胡直接通过转账的方式，给主播的助理银行账号转账9万元。
