来源：中央广播电视总台央视文艺  |  2023年08月19日 00:20:25，正文：                                              8月18日，中央广播电视总台在京举办《2023太湖美音乐会》发布会。中央广播电视总台副台长王晓真，江苏省委常委、宣传部部长张爱军参加发布会，并与嘉宾共同为节目启动。由中央广播电视总台精心打造的《2023太湖美音乐会》将在素有“太湖明珠·江南盛地”美誉的江苏省无锡市录制。节目以“太湖美”为主题，邀请国家级文艺院团和深受大众喜爱的文艺工作者来到无锡，通过“实景演出+虚拟呈现”等多元艺术手段，描绘富有江南雅韵的太湖美景新画卷。中央广播电视总台文艺节目中心负责人张国飞介绍了节目的创新亮点。节目以无锡为原点，辐射环太湖经济圈，通过“主会场+分会场+多场景拍摄”的形式，吸引各年龄层观众共赴一场兼具思想性、艺术性、观赏性的文艺盛会，全景式呈现无锡“智能制造之城、幸福之都、美丽之地”的崭新形象。中央广播电视总台文艺节目中心负责人张国飞中央广播电视总台江苏总站站长季明表示，环太湖区域风景秀美、物产丰饶、人文荟萃、百姓富足，自古以来就是闻名遐迩的鱼米之乡，如今更成为改革开放热土和现代化建设先行区。节目以“太湖美”为主题策划专场音乐会，就是要通过总台“思想+艺术+技术”的融合创新，充分展现太湖的人文之美、生态之美、科技之美、发展之美。中央广播电视总台江苏总站站长季明江苏省无锡市委常委、宣传部部长李秋峰表示，《2023太湖美音乐会》将以富有江南风韵的艺术现场、融合创新的艺术表达，在光影与音乐珠联璧合、经典与新潮交融和鸣中，展现科创活力、弘扬文化自信、谱写生态华章。诚邀广大观众走进无锡，共赏“太湖明珠”的秀美画卷，感受“江南盛地”的繁荣景象。江苏省无锡市委常委、宣传部部长李秋峰江苏省无锡市锡山区区长顾文浩、海澜集团董事长周立宸、洋河股份总裁助理张学谦，中央广播电视总台相关部门负责人，以及江苏省无锡市相关部门负责同志参加启动活动。(摄影：傅博)
