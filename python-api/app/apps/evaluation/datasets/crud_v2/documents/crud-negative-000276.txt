2023-07-24 12:45，正文：                原标题：美国芝加哥又迎“血腥周末”：至少29人中枪6人死亡                            海外网7月24日电 据美国广播公司芝加哥频道7月23日报道，在刚刚过去的周末，美国芝加哥市发生多起致命枪击案，目前已造成至少29人中枪、6人死亡。  芝加哥警方对媒体公布了其中部分致命枪击案件的细节。21日晚10时15分左右，一名16岁的青少年在街头被发现，身上有多处枪伤，在被送往医院后宣布死亡；11时30分，一名男子中枪后逃到附近一家酒店，随后确认死亡。  22日凌晨1时45分左右，一名49岁男子在南科德齐大道被发现胸部中弹，当场被宣布死亡。同样是当天凌晨，5名男子在北朗代尔社区遭到枪击，其中一人死亡，另有一名男子情况危急。23日凌晨1时25分左右，一名男子在一辆翻倒的汽车中被发现，头部中弹。他在被送往医院后因医治无效去世。  芝加哥警方还介绍，此前一个周末，该市至少有40人中枪，其中4人死亡。芝加哥市市长约翰逊承认，在遏制枪支暴力方面，当地有关部门“还有很多工作要做”。美国广播公司23日报道，2023年美国大规模枪击事件已超400起。（海外网 张霓）  责编：张霓、李萌返回搜狐，查看更多                        责任编辑：
