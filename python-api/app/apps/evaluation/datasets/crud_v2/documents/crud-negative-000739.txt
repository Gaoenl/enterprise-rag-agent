2023-08-16 09:04，正文：原标题：报价78亿美元欲买下美国钢铁(X.US)后 Esmark大股东兼CEO称“拥有足够现金”智通财经APP获悉，美国钢铁加工及分销商Esmark大股东兼执行官James Bouchard周二在接受采访时表示，他的银行账户中有78亿美元收购美国钢铁公司(X.US)所需的现金。当地时间周一，Esmark提出以78亿美元(即每股35美元)现金收购美国钢铁(X.US)，这一报价超过了美国最大铁矿石生产商克利夫兰克里夫(CLF.US)提出的72.5亿美元(该收购要约已被美国钢铁拒绝)。克利夫兰克里夫表示，它有能力支付这笔交易，因为它将用自己的股票作为货币支付一半的费用，并向银行借款以帮助支付另一半的费用。相比之下，Bouchard表示，他手头有100亿美元可供使用，而Esmark本身没有债务。Bouchard 称：“我的银行账户里有100亿美元现金。”但他没有提供更多的细节来证明他能拿到这笔钱。Bouchard补充称，他正在听取一家"国际银行"的建议，该银行也愿意向他提供贷款，但他拒绝透露其名称。曾任美国钢铁公司高管的Bouchard表示，Esmark是“美国第三大钢铁制造商”，但他没有详细说明任何数据。2008年，他以13亿美元的价格将自己的另一家同名公司卖给了俄罗斯钢铁制造商OAO Severstal。随后，他买回了Esmark的名称、商标和知识产权，创建了他最新的钢铁公司。他说，这家公司的年收入超过5亿美元。更多港股重磅资讯，下载智通财经app更多港股及海外理财资讯，请点击www.zhitongcaijing.com（搜索“智通财经”）；欲加入智通港股投资群，请加智通客服微信(ztcjkf)来源：智通财经网返回搜狐，查看更多责任编辑：
