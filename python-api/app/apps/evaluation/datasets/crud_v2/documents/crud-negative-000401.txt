上证报中国证券网讯 8月5日上午，以“创新合作、绿色低碳，推动世界奶业可持续发展”为主题的世界奶业大会开幕式在呼和浩特市举行。本次大会由呼和浩特市政府、内蒙古自治区商务厅、内蒙古自治区农牧厅、内蒙古伊利实业集团股份有限公司等举办。据了解，此次大会主推伊利现代智慧健康谷、举行高峰论坛、开展招商推介等系列活动，系统展示近年来奶业振兴的创新实践，分享奶业发展的经验成就，为全球顶尖企业、专家学者搭建对话平台，建立沟通合作机制，共同探索奶业绿色可持续发展的新模式、新路径。来自世界乳业10强企业、国内乳业20强企业、国际乳业产业链知名企业、行业协会的嘉宾和两院院士、专家学者齐聚一堂，共商世界奶业绿色可持续发展大计。中国奶业协会授予呼和浩特市“中国奶业育种之都”称号，国际食品科学技术联盟授予呼和浩特市“世界乳业科技之都”称号。国家乳业技术创新中心也在开幕式上宣告落成启用，该中心坐落于伊利现代智慧健康谷。伊利集团是国家乳业技术创新中心重要的合作方和参与方，也是中心首个成员单位，从2019年开始就携手各方推动中心的各项建设工作。此次国家乳业技术创新中心的落成启用，向世界展示了奶业高质量发展的中国力量、中国样本、中国方案，赢得了全球奶业人的高度认可与赞誉。伊利集团董事长兼总裁潘刚在开幕式上表示，作为关系人类健康福祉的重要产业，奶业正在迈入新的发展阶段。面对新变局、新挑战，全球奶业要围绕“合作、创新、数字化和绿色发展”，加快构建富有韧性的产业链，实现奶业高质量发展。据介绍，“十四五”时期，我国奶业已步入发展新阶段，但技术弱、融资难等问题仍然存在，产业链上下游企业需要发挥各自资源优势，最大化创造全产业链协同价值，筑牢奶业高质量发展的基础。为此，伊利开创了利益联结机制，从技术、金融等多个方面给予合作伙伴支持。2014年至今，伊利帮助合作牧场奶牛的日单产由21公斤增加到33.2公斤，平均每年降低养殖成本4亿多元，“一升一降”帮助合作牧场增收近114亿元，带动全国560万养殖户和农牧民走上增收致富的道路。伊利通过成立“牧场合作伙伴发展学院”“供应商发展学院”和“经销商发展学院”，全方位帮助产业链合作伙伴成长。同时，伊利还发展产业链金融，为合作伙伴提供资金支持。截至今年7月底，伊利为约12000户产业链合作伙伴提供资金扶持，累计融资金额超1300亿元，不断强化产业链韧性，完善“从一棵草到一杯奶”的产业生态圈。另据了解，随着全球重大前沿技术快速突破，奶业最新技术、最新成果在大会上大放光彩。多年来，伊利围绕产业链布局创新链，持续开展奶业上、中、下游核心技术攻关，并通过构建“全球智慧链”打造创新高地。开幕式上，坐落于伊利现代智慧健康谷的国家乳业技术创新中心落成启用，理事单位伊利、君乐宝、三元，重要成员单位澳优、赛科星、西安银桥，以及蒙牛，参加了启用仪式。数字经济时代，推动数字化转型、加速数智化升级成为奶业高质量发展的必由之路。早在十几年前，伊利就在行业内率先推动全产业链的数字化转型。在上游，伊利建设了全球智能化程度领先的智慧牧场，此次世界奶业大会唯一观摩点——伊利全球乳业智能制造产业园，便是目前全球数字化程度领先的乳业智造标杆。在下游，伊利开发了与1.5亿消费者在线协同共创新品的智能洞察系统，还在今年3月正式发布业内首款GPT应用产品——YILI-GPT。面对全球气候变化问题，开幕式上宣读了世界奶业绿色可持续发展呼和浩特倡议，进一步深化了行业共识。伊利作为中国奶业绿色发展的先行者，到目前已连续13年开展企业内的全面碳盘查，建成行业数据最全的碳盘查数据库。站在中国奶业全产业链高质量发展的新阶段，世界奶业大会为行业发展带来了更多活力和希望。未来，伊利将继续引领和推动全球奶产业链合作联结，以科技创新提升产业链韧性，携手更广泛的全球奶业合作伙伴共建可持续发展生态圈，共同擘画奶业高质量发展蓝图，全面推动打造“世界乳业科技之都”，让世界共享健康。（贺建业）
