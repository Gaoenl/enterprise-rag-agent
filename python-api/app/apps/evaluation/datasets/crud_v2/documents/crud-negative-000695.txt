2023-08-17 09:45，正文：原标题：国内油价上调幅度降至60元/吨！预计下周三将搁浅【CNMO新闻】下周三（8月23日）24时，国内油价将迎来新一轮调整。目前油价“由涨转跌”，距离搁浅只差10元/吨，上调幅度降至60元/吨，逼近搁浅线（50元/吨），预计本轮油价将搁浅。以下是最近连续三个工作日的油价行情：8月15日，国内第4个工作日，参考原油变化率为2.33%，预计汽柴油上调105元/吨，折算为0.08-0.09元/升。8月16日，国内第5个工作日，参考原油变化率为1.85%，预计汽柴油上调80元/吨，折算为0.06-0.07元/升。8月17日，国内第6个工作日，参考原油变化率为1.37%，预计汽柴油上调60元/吨，折算为0.05元/升。原油市场方面，尽管上周美国商业原油库存环比大幅下降，但需求前景不明朗，美联储加息预期升温，以及美元保持强势等因素都令国际油价承压，在周三连续第三个交易日下跌。其中，纽约油价跌破每桶80美元整数关口。截至收盘，纽约商品交易所9月交货的轻质原油期货价格收于每桶79.38美元，跌幅为1.99%；10月交货的伦敦布伦特原油期货价格收于每桶83.45美元，跌幅为1.70%。油价上涨自然会增加出行成本。据据“杭州交通”官微消息，由于国内成品油价格调整，浙江省92号汽油最高零售价从7月12日24时调整为每升7.63元以来，已超过油运价格联动调整的启动点，并持续30天(含)以上。经决定，自2023年8月18日起，市区巡游出租车(电动车除外)收取每车次1元燃油附加费。也就是说，乘客每次打车需要多付1元钱。返回搜狐，查看更多责任编辑：
